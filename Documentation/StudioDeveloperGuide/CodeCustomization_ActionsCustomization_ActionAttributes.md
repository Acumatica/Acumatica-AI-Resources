# Action Customization: Action Attributes {#_d7f7a53e-2a1b-49a6-be49-d2b1844c5a00 .concept}

You can use attributes to configure a button or command that represents an action in the user interface.

You can use the following attributes:

-   [PXButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=1a7069c4-95d5-456b-41ec-5b19371358db): Serves as the base attribute for all other attributes, which give you the ability to configure buttons. The successor attributes only set the base class properties to specific values.
-   [PXSaveButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=f36aba39-86d7-bb68-3b04-50742c591eb7)
-   [PXSaveCloseButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=8e587838-5e75-70cf-d3f6-068b50dd2092)
-   [PXCancelButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=09aea1a2-3018-0b0d-01d5-7ca8c0da4336)
-   [PXCancelCloseButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=cf624a45-af43-4531-a945-59c0ecd5cff1)
-   [PXInsertButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=cf6019f6-f3ef-ea25-5ace-05b0f6754678)
-   [PXDeleteButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=6029ca1e-a44a-f486-99e4-00c2a2e28cdc)
-   [PXFirstButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=ce86e75b-b41e-f793-bc29-e02a598eccd1)
-   [PXPreviousButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=80af120b-cf5e-5e43-2e48-492b531476ad)
-   [PXNextButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=0f660436-4c4c-9ee1-933e-b12971e2419c)
-   [PXLastButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=385a66c4-2441-8f41-14e4-46a754ff2301)
-   [PXSendMailButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=f2ce4aae-8f54-eb1f-f92a-a4cd7f977be2)
-   [PXReplyMailButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=409f5596-39fc-5304-db55-63e5439f0e2f)
-   [PXForwardMailButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=c034403b-b93c-fe4a-9d2f-a2b8f621cec6)
-   [PXTemplateMailButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=3f82acef-ef45-b1f9-4cb4-fb51fd2044ad)
-   [PXLookupButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=62cf5258-d10e-13b6-ced6-bbcae691f80b)
-   [PXProcessButton](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=ffe82c46-61db-f988-9026-23611bb22c0b)

Also, you can use the following attributes:

-   [PXUIField](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=79a99243-7926-f570-87ed-536a04ccfe32): To configure the button layout and set access rights
-   [PXEntryScreenRights](https://help.acumatica.com/Help?ScreenId=ShowWiki&pageid=b1a7eacd-76b5-d304-f311-6b4808c4ee5a): On a [Lists as Entry Points](../UserGuide/SM_20_85_00.md) \(SM208500\) form, to define the inheritance of access rights for an action that is implemented in the appropriate entry screen
