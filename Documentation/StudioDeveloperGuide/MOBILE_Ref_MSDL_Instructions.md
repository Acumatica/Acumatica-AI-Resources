# Instructions {#_b3d87528-db27-4e8b-afb7-c1e2804215e8 .concept}

*Format:*

```
# comment
instructionName objectType "objectName" {
  attributeName1 = newValue1
  attributeName2 = newValue2
  ...
  instructionName1 objectType1 "objectName1" {
    ...
  }
}
```

MSDL provides the following instructions.

|Instruction|Description|
|-----------|-----------|
|[add](MOBILE_Ref_MSDL_Instr_ADD.md)|Appends the specified object as a child to the object that is referenced in the outer scope of this instruction.|
|[attachments](MOBILE_Ref_MSDL_Instr_ATTACHMENTS.md)|In a container, switches the MSDL interpreter to the mode of setting the attachment attributes.|
|[placeAfter](MOBILE_Ref_MSDL_Instr_PLACEAFTER.md)|In the mobile site map, moves the object that is referenced in the outer scope of this instruction after the specified object.|
|[placeAt](MOBILE_Ref_MSDL_Instr_PLACEAT.md)|In the mobile site map, moves the object that is referenced in the outer scope of this instruction to the specified position.|
|[placeBefore](MOBILE_Ref_MSDL_Instr_PLACEBEFORE.md)|In the mobile site map, moves the object that is referenced in the outer scope of this instruction to the position before the specified object.|
|[remove](MOBILE_Ref_MSDL_Instr_REMOVE.md)|Removes the specified object from the mobile site map.|
|[sitemap](MOBILE_Ref_MSDL_Instr_sitemap.md)|Switches the MSDL interpreter to the mode of editing of the mobile site map.|
|[selector](MOBILE_Ref_MSDL_Instr_SELECTOR.md)|In a field, switches the MSDL interpreter to the mode of editing the selector content.|
|[update](MOBILE_Ref_MSDL_Instr_UPDATE.md)|Switches the MSDL interpreter to the mode of editing the specified object.|
