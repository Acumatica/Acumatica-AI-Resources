# Overview of ASPX Pages in Acumatica Framework {#_c5b04643-bdef-43ed-aa69-2d72e396c899 .concept}

In Acumatica Framework-based applications, you can configure the appearance of forms from the front end \(that is, by configuring ASPX pages\) and from the back end \(that is, by using the attributes and events provided by the Acumatica platform\).

In this chapter of the guide, you can find information about how to create the ASPX code of the forms. This chapter also includes a technical overview of the user interface of an Acumatica Framework-based application. For information about the configuration of the UI from the back end, see [Configuring the UI from the Backend](BL__mng_Configuring_UI_from_Back_End.md).
