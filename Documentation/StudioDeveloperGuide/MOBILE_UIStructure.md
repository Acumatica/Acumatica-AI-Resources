# Configuring the Mobile Site Map by Using XML \(deprecated\) {#_9b2ae176-5ff6-4e27-9cd2-527da3aa34ad .concept}

**Note:** Using XML for customizing the Mobile Site Map is deprecated starting in Acumatica 2026 R1. Use [Configuring the Mobile Site Map](MOBILE_MSDL.md) instead.

The user interface of the Acumatica mobile app has the following structure:

-   [Main Menu](MOBILE_MainMenu.md#), which can include the sm:Folder and sm:Screen elements
-   [Sidebar Menu](MOBILE_SidebarMenu.md#), which can include links to favorite folders and screens
-   [Screens](MOBILE_Screens.md#), which can include sm:Container, sm:Field, sm:Action, and other elements

See [Mobile Site Map Reference](MOBILE_Reference.md#) for detailed descriptions of all tags.
