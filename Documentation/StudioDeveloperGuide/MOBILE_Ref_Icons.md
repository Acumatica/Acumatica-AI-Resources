# Icons

In the mobile site map, you can use the Icon attribute to set the icon that is displayed on the UI for the following MSDL objects:

-   containerAction
-   containerLink
-   listAction
-   recordAction
-   selectionAction
-   folder
-   item

For containerLink objects, as well as recordActionLink objects that are displayed as a container link, you can use the style attribute to define the icon color. For details about the values of this attribute, see [containerLink](mobile_ref_msdl_objtype_containerlink.md).

To specify an icon for an MSDL object, use the following format of the attribute value: `system://IconName`, where the `IconName` is one of the following values.
