# Object Types {#_f8ff0ca4-6fb3-49d2-b77c-b1491ff8f7c9 .concept}

An MSDL instruction can be applied to the following object types:

-   The following action object types:
    -   [containerAction](mobile_ref_msdl_objtypes_containeraction.md) \(applied to a whole container\)
    -   [listAction](mobile_ref_msdl_objtypes_lista.md) \(applied to a list view\)
    -   [recordAction](mobile_ref_msdl_objtypes_recordaction.md) \(applied a single opened record\)
    -   [selectionAction](mobile_ref_msdl_objtypes_seleciona.md) \(applied to a list of selected records\)
-   These link object types:
    -   [containerLink](mobile_ref_msdl_objtype_containerlink.md)
    -   [recordActionLink](MOBILE_ref_MSDL_objtypes_RecordActionLink.md)
-   [attributes](Mobile_Ref_MSDL_Instructions_Attributes.md)
-   [container](mobile_ref_msdl_objtype_container.md)
-   [field](mobile_ref_msdl_objtypes_field.md)
-   [folder](mobile_ref_msdl_objtype_folder.md)
-   [group](mobile_ref_msdl_objtype_group.md)
-   [item](mobile_ref_msdl_objtypes_item.md)
-   [screen](mobile_ref_msdl_objtypes_screen.md)
-   [type](mobile_ref_msdl_objtypes_.md)
-   [UDFields](MOBILE_Ref_MSDL_ObjTypes_UDFields.md)

Objects have attributes, and each attribute can have any number of possible values. If the attribute is an indicator, it can have only the *true* or *false* value.
