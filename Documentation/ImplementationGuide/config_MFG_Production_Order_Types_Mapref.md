# Configuring Production Order Types {#_6bb81ab7-9c92-4cc7-bbaa-a0577b60ef1e .concept}

When you configure Acumatica ERP Manufacturing Edition, you need to specify the default settings for production orders, such as which workflow an order is involved in \(production, planning, or disassembly\) and how the cost of produced items should be calculated. These settings are provided through the use of production order types, which are described in detail in this chapter.
