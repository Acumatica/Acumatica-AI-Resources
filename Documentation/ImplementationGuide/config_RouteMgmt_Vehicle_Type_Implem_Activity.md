# Vehicles: To Create a Vehicle Type {#_ef63751f-1f6e-44e3-96f7-0c8d4f1b5b2d .task}

In Acumatica ERP, *vehicle types* are used to group vehicles with similar characteristics that your company uses. For example, you can create separate vehicle types for limousines and vans.

## Story {#section_nqc_kw1_ldc .section}

Suppose that the SweetLife Equipment and Service Center has multiple types of vehicles that they use for providing route services. To register these vehicles in the system, at least one vehicle type must be created. Acting as an administrative user, you need to create a vehicle type record in Acumatica ERP.

## Process Overview { .section}

On the [Vehicle Types](../UserGuide/FS_20_42_00.md) \(FS204200\) form, you will create the *VAN* vehicle type.

## System Preparation {#section_xyr_cbv_3dc .section}

Before you start creating a vehicle type, do the following:

1.  On the Acumatica ERP website, sign in to a company with the *U100* dataset preloaded as a system administrator by using the *gibbs* username and the *123* password.
2.  On the Company and Branch Selection menu on the top pane of the Acumatica ERP screen, select the *SWEETEQUIP - Service and Equipment Sales Center* branch.

## Step: Creating a Vehicle Type {#section_mjq_kw1_ldc .section}

Perform the following instructions:

1.  On the [Vehicle Types](../UserGuide/FS_20_42_00.md) \(FS204200\) form, add a new record and specify the following settings:
    -   **Vehicle Type ID**: `VAN`
    -   **Description**: `Vans`
2.  On the form toolbar, click **Save**.

    You have created the *VAN* vehicle type; you can proceed to entering the specific vehicles \(vans\) that your company uses for executing routes.
