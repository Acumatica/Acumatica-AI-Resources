# Branch Locations: General Information {#_5e972c49-581a-425e-b7c4-b6c972e02f3e .concept}

In Acumatica ERP, branch locations represent physical locations \(such as offices\) from which your staff members depart to attend appointments. A branch of your company can have multiple branch locations or only one branch location.

## Learning Objectives { .section}

In this chapter, you will learn how branch locations are used in service management, and you will review and create them to become familiar with their settings.

## Applicable Scenarios { .section}

You create a branch location in the system in the following cases:

-   When you first implement the service management functionality.
-   When your company opens a new office within a branch and you need to add that office \(branch location\) to the system.
