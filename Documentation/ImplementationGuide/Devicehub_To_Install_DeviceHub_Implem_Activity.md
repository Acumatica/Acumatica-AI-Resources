# DeviceHub: To Install DeviceHub {#_86780b3b-a0b4-4cb0-839f-5e0748da464a .task}

In the following implementation activity, you will learn how to install the DeviceHub application.

## Story { .section}

Suppose that you are a technical specialist in your company. The warehouse manager of the company has requested a fast and reliable method of printing carrier labels and pick lists. To provide the ability to print these documents, you have decided to use DeviceHub, which is included in the Acumatica ERP installation package.

## Process Overview { .section}

In the Acumatica ERP Setup wizard, you will select the option to install DeviceHub.

## System Preparation { .section}

Before you begin the steps of the activity, download `AcumaticaERPInstall.msi` from the following folder: `http://acumatica-builds.s3.amazonaws.com/index.html?prefix=builds/<Version>/<buildNumber>/AcumaticaERP`, where *Version* and *buildNumber* are the version and build number that correspond to the build of Acumatica ERP that is installed in your company.

## Step: Installing DeviceHub { .section}

To install DeviceHub, do the following:

1.  On your computer, start `AcumaticaERPInstall.msi`. The Acumatica ERP Setup wizard starts.
2.  On the Welcome page, click **Next**.
3.  On the End-User License Agreement page, select the **I accept the terms in the License Agreement** check box.
4.  On the Main Software Configuration page, select the **Install DeviceHub** check box, and clear the other check boxes.
5.  On the Destination Folder page, modify the default destination folder, if needed, by clicking the **Change…** button.
6.  Continue the installation process.
7.  When the installation is finished, close the window of the Acumatica ERP Setup wizard.
