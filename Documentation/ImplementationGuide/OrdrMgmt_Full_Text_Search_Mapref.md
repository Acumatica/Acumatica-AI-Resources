# Full-Text Search {#_01bea519-ae96-432d-9124-f9ff2547a17e .concept}

The full-text search in Acumatica ERP uses a token-based index of the MS SQL Server database to quickly find matches in large databases \(over 1 million inventory item records\). You can search by the beginnings of words or inventory ID segments, or by full words in both the inventory ID and description. Unlike the standard search, it is optimized for speed in high-volume inventories. This chapter describes how to implement the full-text search in your instance of Acumatica ERP.
