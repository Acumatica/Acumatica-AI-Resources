# To Define a Book Calendar with Week-Based Periods {#_fc544309-3470-40d6-816b-8e923ac98ee2 .task}

You add a book calendar for each non-posting book you add to the system by using the [Book Calendar Setup](../UserGuide/FA_20_60_00.md) \(FA206000\) form. For each calendar, you have to specify the settings of the financial year, including its starting and ending dates and its periods.

## To Configure a Book Calendar with Week-Based Periods { .section}

1.  Open the [Book Calendar Setup](../UserGuide/FA_20_60_00.md) \(FA206000\) form.
2.  In the **Book** box, select the book for which you want to set up a book calendar.
3.  Set up the first year of the book calendar as follows:

    1.  In the **Year Starts On** box, specify the date for the start of the book's calendar year.
    2.  If the start date of the book year falls within the next financial year, select the **Belongs To Next Year** check box.
    The system then inserts the first calendar year in the **First Year** box.

4.  In the **Period Type** box, select one of the following:
    -   *Week*: Each period lasts one week, and there are 52 or 53 periods per year.
    -   *Two Weeks*: Each period lasts two weeks, and there are 26 or 27 periods per year.
    -   *Four Weeks*: Each period lasts four weeks, and there are 13 or 14 periods per year.
    -   *4-4-5 Weeks*: The year is divided into four quarters, and each quarter includes two four-week periods and a five-week period.
    -   *4-5-4 Weeks*: The year is divided into four quarters, and each quarter includes a four-week period, a five-week period, and a four-week period.
    -   *5-4-4 Weeks*: The year is divided into four quarters, and each quarter includes the following periods: a five-week period and two four-week periods.
5.  If the *Week* period type is selected, in the **Day of Week** box, select the day of week on which periods will start.
6.  If a period type other than *Week* is selected, in the **First Period Starts On** box, select the day of week on which periods will start.
7.  Select the **Has Adjustment Period** check box if you want the system to generate an adjustment period.
8.  On the form toolbar, click **Save**.
