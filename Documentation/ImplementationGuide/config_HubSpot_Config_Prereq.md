# Integration with HubSpot: Configuration Prerequisites {#_678e7ddd-992a-4aa3-a842-6394ec1abbd9 .concept}

Before you start to set up integration between HubSpot and Acumatica ERP, you must be sure that your HubSpot subscription meets the requirements and the system has been configured properly, as described in the following sections.

## Checking Requirements { .section}

For successful integration of Acumatica ERP with HubSpot, make sure that your organization uses one of the following Marketing Hub subscriptions in which the *Lists* feature is included:

-   Starter
-   Professional
-   Enterprise

For more information about these subscriptions, see [HubSpot Marketing Software Pricing](https://www.hubspot.com/pricing/marketing).

## Enabling the Needed Features { .section}

On the [Enable/Disable Features](../UserGuide/CS_10_00_00.md) \(CS100000\) form, the *HubSpot Integration* feature \(under the *Third-Party Integrations* group of features\) must be enabled. By enabling this feature, you can use different units of measure as base, sales, and purchase units for item classes and stock items.

## Configuring the System { .section}

On the [Customer Management Preferences](../UserGuide/CR_10_10_00.md) \(CR101000\) form, make sure that the basic customer management settings have been specified.
