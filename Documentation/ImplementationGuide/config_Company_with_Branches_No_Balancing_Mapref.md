# Company with Branches that Do Not Require Balancing

This chapter describes the configuration of a company that has multiple branches in which reports are prepared for the whole company. This configuration includes the minimum set of features that has to be enabled for this configuration. The chapter also contains an implementation checklist that users can refer to when they are preparing for implementation and configuring the basic Acumatica ERP functionality for the company.
