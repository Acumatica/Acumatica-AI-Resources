# DeviceHub: Configuration Prerequisites {#_03291c84-9e03-4111-beaf-eae428c2ba68 .concept}

Before starting to perform the initial configuration of DeviceHub, you should be sure that the needed feature has been enabled and the needed configuration has been performed in Acumatica ERP, as described in the following sections.

## Enabling the Needed Feature { .section}

On the [Enable/Disable Features](../UserGuide/CS_10_00_00.md) \(CS100000\) form, the *DeviceHub* feature must be enabled.

## Configuring the User { .section}

You need to make sure that on the [Users](../UserGuide/SM_20_10_10.md) \(SM201010\) form, a user account with the *Administrator* user role has been created for DeviceHub. You will need to grant access rights to specific forms for printing, scanning, and weighing by using the functionality of DeviceHub. See the [DeviceHub: Configuration of a DeviceHub User](DeviceHub_Configuration_of_Application_User.md) topic for details about the creation of this user and the configuration of its access rights.
