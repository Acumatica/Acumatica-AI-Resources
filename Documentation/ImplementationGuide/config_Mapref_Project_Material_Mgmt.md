# Implementing Project Material Management {#_15628391-fcde-4634-ba21-a3d2d686b310 .concept}

The topics of this chapter describe the minimum configuration of project material management.

Project material management lets you plan, track, and control the materials required for a project while keeping costs aligned with the project budget. To use this functionality, you need to perform the needed setup, including specifying how material-related quantities affect inventory availability.
