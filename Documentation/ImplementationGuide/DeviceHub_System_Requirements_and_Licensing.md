In this section, you will learn about the system requirements of the DeviceHub application.

## System Requirements { .section}

The environment where you install DeviceHub should meet the software requirements listed in the following table.

|Hardware/Software|Requirements|
|-----------------|------------|
|Operating systems|-   Microsoft Windows 7
-   Microsoft Windows 8
-   Microsoft Windows 8.1
-   Microsoft Windows 10
-   Microsoft Windows 11

|
|Microsoft .NET Framework|4.8|
