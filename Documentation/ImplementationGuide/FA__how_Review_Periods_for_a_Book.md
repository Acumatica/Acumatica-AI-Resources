# To Review the Periods of a Particular Book {#_ed20e5b1-e92d-4d55-9373-10c2646e7674 .task}

You can review the periods used for a particular depreciation book on the [Book Calendars](../UserGuide/FA_30_40_00.md) \(FA304000\) form.

## To Review the Periods for a Particular Book { .section}

1.  Open the [Book Calendars](../UserGuide/FA_30_40_00.md) \(FA304000\) form.
2.  In the **Book** box of the Selection area, select the book for which you want to review periods.
3.  In the **Company** box, select the company for which you want to review periods.

    **Note:** This box appears on the form only if the *Multiple Calendar Support* feature is enabled on the [Enable/Disable Features](../UserGuide/CS_10_00_00.md) \(CS100000\) form and the posting book is selected.

4.  In the **Financial Year** box, select the financial year for which you want to review periods.
5.  In the table, review the periods for the selected book, company \(if applicable\), and financial year.
