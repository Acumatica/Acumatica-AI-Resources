# To Change the Order of Columns {#_db4001d7-fedf-4492-b953-750a75b63011 .task}

As you work, you might want to change the order of columns so that the information is grouped to better fit your work and preferences. For example, you might want to make particular columns adjacent or move to the left the columns you consider the most important.

To rearrange the layout of columns in a table, you can use one of the following ways, described in detail below:

-   On the form, drag a column to a new position
-   Use the Column Configuration dialog box

## To Move Columns on the Form { .section}

1.  Drag the column header to the desired position. Note the red arrows, which indicate the exact position where you can drop the column between two other columns.
2.  Repeat this step for each column you want to move.

These changes are saved automatically by the system, that is, when you open the table in the future you will see this change.

## To Move Columns by Using Column Configuration Dialog Box { .section}

1.  In the table, click the Column Configuration button \(![](../Shared/Images/Icons_Column_Configuration.png)\) to open the **Column Configuration** dialog box.
2.  To shift a column to the left in the table, do the following:
    1.  In the **Selected Columns** list, click the column you want to move.
    2.  Click the Move Up \(![](../Shared/Images/Columns_Configuration_Move_Up.png)\) button to move the column one position to the left.
    3.  Repeat the previous substep until the column is in the appropriate place.
3.  To shift a column to the right in the table, do the following:
    1.  In the **Selected Columns** list, select the column you want to move.
    2.  Click the Move Down \(![](../Shared/Images/Columns_Configuration_Move_Down.png)\) button to move the column one position to the right.
    3.  Repeat the previous substep until the column is in the appropriate place.
4.  Click **OK** to save the layout changes.

## To Restore the Default Table Layout { .section}

1.  Click the Column Configuration button \(![](../Shared/Images/Icons_Column_Configuration.png)\).
2.  In the bottom left of the **Column Configuration** dialog box, click **Reset to Default**.

CAUTION:

All the changes that you have previously made to the table layout will be reset.
