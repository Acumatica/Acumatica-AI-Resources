# To Delete a Filter {#_4aa980db-baef-49ef-8f66-245ce2376116 .task}

You can delete a previously saved filter from the form it’s applied to, as described in this topic.

## To Delete a Filter { .section}

1.  Open the form.
2.  In the form's Filter List drop-down menu, select the filter you want to delete.
3.  On the table toolbar, click **Filter Settings** \(![](../Shared/Images/Icons_Add_Filter.png)\) to display the filtering area.
4.  In the filtering area, click **...** &gt; **Delete Filter**.
5.  Click **OK** to confirm the deletion.
