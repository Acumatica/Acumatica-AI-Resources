# Form Elements {#_c11be618-f8c5-4147-9b26-142dee670cd8 .concept}

In Acumatica ERP, you use the form elements to enter settings, which the system stores in the database or uses as criteria to select what is displayed on the form.

## Types of Form Elements { .section}

Acumatica ERP supports the following types of form elements:

-   Date box: You use a date box to enter a date. You can type the date or use the Calendar dialog box to select the date. For more information, see [Date Boxes](Using_Date_Fields.md) or [Calendar Dialog Box](Calendar.md).
-   Lookup box: You use this box to select a value from a list of predefined values or from another information table from the database. For more information, see [Lookup Boxes](Using_Lookup_Fields.md)
-   Currency box: A currency box is a type of lookup box that provides additional controls for currency manipulation. For more information, see [Currency Boxes](Using_Currency_Fields.md).
-   Check box: You select or clear a check box to turn on or turn off an option.
-   Text box: A box in which you can enter data.
-   Formula box: A text box on a small number of forms, which you can use to open the Formula Editor dialog box and construct a formula. For more information, see [Formula Boxes](UIG_Formula_Boxes.md).
-   Option button: A circle that you can click to turns on or turn off a setting. Option buttons are generally organized in groups, and you can select only one option from the group of option buttons.

If a box is marked with asterisk \(\*\), you must fill it in.

## Unavailable Elements { .section}

When you enter data on the Acumatica ERP forms, you may notice that some elements are unavailable. Some of these unavailable elements are *info boxes*: read-only boxes that contain system-generated values, such as document statuses and total amounts. Other unavailable elements can be used only if a specific option is selected in another element on this form or on another form.
