# To Share a Filter {#_3cd992e9-447c-4b61-84dc-292b65fe29d8 .task}

You can share a quick or advanced filter you’ve created, as described in this topic. For more information on working with shared filters, see [Advanced Filters: General Information](../Shared/../UserGuide/GI_Reusable_Filters_GeneralInfo.md).

## To Share a Filter { .section}

1.  Open the form.
2.  In the form's Filter List drop-down menu, select the filter you want to share.
3.  On the table toolbar, click **Filter Settings** \(![](../Shared/Images/Icons_Add_Filter.png)\) to display the filtering area.
4.  In the filtering area, click **...** &gt; **Edit Filter** to open the **Save Filter** dialog box.
5.  In the **Save Filter** dialog box, select the **Shared** check box.
6.  Click **Apply** to apply this change to the filter and save it.
