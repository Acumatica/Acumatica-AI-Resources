# Filters {#_fad0b170-9d7c-4851-8f73-4b841f977c0f .concept}

In Acumatica ERP, forms often use tables to present data in ways that users can easily comprehend. But when a single table spans multiple pages, you might find it challenging to glean the needed information from it. Filters give you the means to display only those records that you want to see at the moment.
