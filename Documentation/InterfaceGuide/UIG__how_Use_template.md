# To Create a Document with a Template {#_480487bd-b225-4065-9d82-97a3b68d7994 .task}

You can create a record \(a document, transaction, class, or profile\) by using a previously created template, as described in this topic. For more information about the creation of records, see [Record Entry: General Information](../Shared/../UserGuide/GS_Working_With_Data_Entry_Forms_GeneralInfo.md) and [Record Entry: Copy-and-Paste Options and Record Templates](../Shared/../UserGuide/SM__con_Copy-and-Paste_Options_and_Document_Templates.md).

## To Create a Document by Using a Template { .section}

1.  On the form toolbar of the appropriate form, click **Add New Record**.
2.  On the **Clipboard** menu, select the template from which you want to copy data.

    The data from the template is pasted into your record.

3.  Make sure that the record has the appropriate date, post period, and amounts. If required, make necessary changes.
4.  On the form toolbar, click **Save**.

Now you can process the new record according to your company's workflow.
