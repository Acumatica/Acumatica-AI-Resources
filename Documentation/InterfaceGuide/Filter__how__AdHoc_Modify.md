# To Modify a Filter on a Report Form {#_2513e10e-abb1-432e-85e0-a5e3f6cabf9c .task}

After you have run a report for which you configured an ad hoc filter, if you need to, you can modify the filter before you send or print the report, as described in this topic.

## To Modify a Filter on a Report Form { .section}

1.  If you are viewing the report, on the report toolbar of the report, click **Parameters**. The system opens the report form, and the **Parameters** button on the toolbar is highlighted.
2.  In the **Additional Filtering Conditions** table of the **Additional Sort and Filters** tab, modify the filter conditions. For more information, see [Reports: Process Activity](../Shared/../UserGuide/GS_Working_With_Reports_Process_Activity.md), [Managing Advanced Filters](../Shared/../UserGuide/GI_Reusable_Filters_Mapref.md).
3.  Click **Run Report**.
