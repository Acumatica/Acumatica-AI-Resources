# Acumatica ERP User Interface {#_77938adf-fcd0-4f5b-a7b3-30e3cfd55fc0 .concept}

In the user interface of Acumatica ERP, elements provide you with enhanced visualization and flexibility in configuring the navigation items. The user interface makes your work in the system convenient and easy, and you can configure it to better fit your working tasks.

This chapter describes the elements of the user interface.
