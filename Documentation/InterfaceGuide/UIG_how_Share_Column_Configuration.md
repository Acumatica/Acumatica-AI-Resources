# To Share a Column Configuration {#_a36bb6ed-6ecd-486e-b4e6-6585e826c41b .task}

You can configure a default layout of a table \(or multiple tables\) on a form and then define it as the default for other users in the system by sharing the configuration.

**Attention:** The ability to share a column configuration is available only to users with administrative access to the system.

## To Share a Column Configuration { .section}

1.  Navigate to the form and configure the appropriate layout of the table or tables on the form.
2.  On the form title bar, click **Tools** &gt; **Share Column Configuration**. The **Share Column Configuration** dialog box is opened. \(For details about the dialog box, see [Share Column Configuration Dialog Box](Form_Title_Bar.md#_a54385c8-f301-4412-8594-405f3ea1cc44).\)
3.  In the dialog box, do the following:
    1.  On Page 1, select the table or the tables for which you want to specify default settings.
    2.  On Page 2, do one of the following:
        -   Select the **Set as the Default** check box to make the table configuration or configurations the default settings for all users. Also, for users who have set up their own column configurations for the table or tables, if you want to replace their table layouts with the configuration you have defined as the default, select the **Override Users' Personal Configurations** check box.
        -   Clear the **Set as the Default** check box and select users with whom you want to share the table configuration or configurations. You can filter the list of users by selecting a role in the **User Role** box.
    3.  Click **Finish** to apply your changes.
