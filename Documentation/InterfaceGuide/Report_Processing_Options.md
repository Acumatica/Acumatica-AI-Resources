# Reports {#_a7c3a15e-77ba-493b-9507-1ee2ed301d89 .concept}

In addition to offering a comprehensive collection of reports, Acumatica ERP gives you a high degree of control over each report.

On a typical report form, described in [Report Form](Preparing_to_Run_a_Report.md), you can adjust the report settings to meet your specific informational needs. You can specify sorting and filtering options and select the data by using report-specific settings—such as financial period, ledger, and account—and configure additional processing settings for each report. The settings can be saved as a report template for later use. For details, see [To Run a Report](Report_Running.md) and [To Create a Report Template](Report_Template.md).

After you run a report, the prepared report appears on your screen. You can print the report, export the report to a file, or send the report by email.

This chapter describes a typical report form and the main tasks related to using reports.
