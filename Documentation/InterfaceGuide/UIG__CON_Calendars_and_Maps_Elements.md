# Calendar and Map Elements {#_a0296e8c-87c4-455c-9484-9e75943b7762 .concept}

You use the calendar and map elements to display elements or invoke actions on the calendar boards and maps.

## Types of Calendar and Map Elements { .section}

The calendar boards and maps support the following types of elements:

-   *Calendar*: You use the Calendar dialog box to select a date in a calendar. For more information, see [Calendar Dialog Box](UIG__CON_Calendar_Dialog_Box.md).
-   *Table*: The data in the calendars and maps is arranged in tables, where each row represents an object or detail, and each column shows a parameter of each object or detail. For more information, see [Calendar Board and Map Tables](UIG__CON_Calendar_Map_Tables.md).
-   *Hide Button*: You use this button to temporarily hide panes on the calendars and maps. For more information, see [Hide Button](UIG__CON_Hide_Button.md).
