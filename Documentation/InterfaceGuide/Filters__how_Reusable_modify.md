# To Modify a Saved Filter {#_36f82aa7-27ce-463b-a9f9-d81d5f855b73 .task}

You can modify a saved filter on the inquiry or processing form it is applied to, as described in this topic.

## To Modify a Saved Filter { .section}

1.  Open the form.
2.  In the form's Filter List drop-down menu, select the filter you want to edit.
3.  On the table toolbar, click **Filter Settings** \(![](../Shared/Images/Icons_Add_Filter.png)\) to display the filtering area.
4.  In the filtering area, click the existing filtering conditions to edit them or add new filtering conditions. For details, see [Filtering and Sorting Capabilities: To Create and Manage Quick Filters](../Shared/../UserGuide/GS_ModernUI_Filter_Quick_Activity.md) and [Filtering and Sorting Capabilities: To Create an Advanced Filter](../Shared/../UserGuide/GS_ModernUI_Filter_Advanced_Activity.md).
5.  Do one of the following to save your changes:
    -   In the filtering area, click **Save Filter**.
    -   If you want to save the filter under another name, in the filtering area, click **...** &gt; **Save As** and specify the new filter name.
