# Date Boxes

Date boxes are used to enter dates, as shown on the screenshot below.


To change any date, you can either type a specific date into the date box or select it by using the calendar dialog box, which you access from the date box. For more information, see [Calendar Dialog Box](Calendar.md).

By default, the current business date is displayed in the info area in the top right corner of a form. For more information, see [Info Area](UIG__con_New_UI_Info_Area.md).
