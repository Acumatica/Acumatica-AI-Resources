# To Change the Default Configuration of a Table {#_5cfae2f3-3268-4d6f-89aa-486d41f27470 .task}

If you have already set up a default configuration for one table or multiple tables on a form, you may later want to change this default configuration. To do this, you first delete the previously configured default configuration and then configure a new one.

**Attention:** The ability to change a default configuration of a table is available only to users with administrative access to the system.

## To Change the Default Configuration { .section}

1.  Navigate to the form, and while viewing the table for which you want to change the default layout, click ![](Images/column_configuration_button.png) to bring up the **Column Configuration** dialog box.
2.  In the bottom of the dialog box, click **Delete Default Configuration**.
3.  Configure the new table layout.
4.  Define this layout as the default layout by using the [Share Column Configuration Dialog Box](Form_Title_Bar.md#_a54385c8-f301-4412-8594-405f3ea1cc44).
