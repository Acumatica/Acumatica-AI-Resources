# Implementing Plug-Ins for Processing Credit Card Payments

To processes credit card and debit card payments, Acumatica ERP supports the Acumatica Payments plug-in and Authorize.Net API payment plug-in. For more information, see [Configuring and Using Acumatica Payments](../UserGuide/AR__MNG_Acumatica_Payments.md) and [Integration with Authorize.Net Through the API Plug-in](../UserGuide/CA__CON_Integration_AuthorizeNet_APIPlugin.md).

In a customized Acumatica ERP application, you can implement payment plug-ins that work with credit card payment processing centers other than Acumatica Payments or Authorize.Net. In this chapter, you can find information about how to develop custom plug-ins and use them in Acumatica ERP.

-   **[Credit Card Processing Plug-In: Additional Functionality](../PlugInDevelopmentGuide/PlugIn_CCProcessing_AdditionalInterfaces.md)**
