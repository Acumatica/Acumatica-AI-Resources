# Implementing Real-Time Synchronization for a Connector {#_f8be8615-c76b-4afc-87bc-82c25e9e88c3 .concept}

With real-time synchronization between Acumatica ERP and an external system, Acumatica ERP attempts to prepare data or to prepare and process data as soon as a change occurs in either system. Depending on the entity involved and your company's processes, real-time synchronization can involve import or export, or it can be bidirectional. Real-time import relies on webhooks that Acumatica ERP receives from an external system, and real-time export makes use of the push notification mechanism available in Acumatica ERP.
