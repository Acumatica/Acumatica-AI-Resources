# Lot/Serial Classes {#_9806d94b-097e-4082-9f01-9ca66d031ab7 .reference}

Form ID: \(IN207000\)

**Attention:** This form appears only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to define or modify lot or serial classes. A lot or serial class is used to group inventory items with lot or serial numbers and to provide default settings for new items of the class. For details on configuring and using lot and serial numbers, see [Items with Lot and Serial Numbers: General Information](Lot_and_Serial_Numbers_GeneralInfo.md).

If the *Lot and Serial Tracking* feature is not enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, *DEFAULT* is inserted in the **Lot/Serial Class** box for all item classes and individual stock items; lot and serial numbers are not assigned and tracked for items of the *DEFAULT* class.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

In this area, you can enter basic information about a new lot or serial class and view information about an existing class.

|Element|Description|
|-------|-----------|
|**Class ID**|The unique alphanumeric identifier of the lot or serial class; a string of up to 10 characters may be used.|
|**Description**|A brief description of the lot or serial class.|
|**Tracking Method**|The tracking method for the inventory lot or serial class. You can select one of the following options: -   *Not Tracked*: No tracking of lot or serial numbers will be performed for items of the class.
-   *Track Lot Numbers*: Tracking of lot numbers will be performed for items of the inventory lot/serial class.
-   *Track Serial Numbers*: Tracking of serial numbers will be performed for items of the inventory lot or serial class.

|
|**Track Expiration Date**|A check box that indicates \(if selected\) that the system will track the expiration date for inventory items of this lot or serial class. This element is not used for classes with *Not Tracked* selected as their tracking method.|
|**Required for Drop Shipments**|A check box that indicates \(if selected\) that the system will apply the selected tracking method to items of this class when the items are listed on drop shipments. If the check box is not selected, the system will not require specifying lot or serial numbers for items in drop-ship orders.

 For information on drop-ship orders, see [Processing Sales with Drop Shipping](OrderMgmt_Drop_Shipment_Sale_Mapref.md).

|
|**Assignment Method**|The method of assigning lot or serial numbers to the items. You can select one of the following options: -   *When Received*: Assigns lot or serial numbers to the items when the items are received.
-   *When Used*: Assigns lot or serial numbers to the items when the items are used. If an item is returned by a customer, the item can be issued again with the same lot or serial number.

If *Not Tracked* is selected in the **Tracking Method** box, the *When Received* option is selected in this box and it is unavailable for changing.

**Attention:** You cannot change an assignment method selected for the lot or serial class for another assignment method if there are any historical inventory transactions with any item of the class, any unreleased documents that include an item of the class, or any nonzero quantity of any item of the class at any location.

|
|**Issue Method**|The method used to issue the items of this lot or serial class, which is not applicable for items of the class for which the *Not Tracked* tracking method is selected. You can select one of the following issue methods: -   *FIFO*: A first-in-first-out \(FIFO\) issue method
-   *LIFO*: A last-in-first-out \(LIFO\) issue method
-   *Sequential*: A sequential issue method
-   *Expiration*: An issue method based on the expiration date; to use this method, select the **Track Expiration Date** check box for this class
-   *User-Enterable*: A custom, user-defined issue method

If *Not Tracked* is selected in the **Tracking Method** box, the *FIFO* option is selected in this box and it is unavailable for changing.

|
|**Share Auto-Incremental Value Between All Class Items**|A check box that indicates \(if selected\) that the same auto-incremental value should be used for all inventory items in the lot or serial class. If it is cleared, for each item, an individual auto-incremental value may be specified on the [Stock Items](IN_20_25_00.md) \(IN202500\) form; if such a number is not specified, the initial value for each item will be *0000* by default.|
|**Auto-Incremental Value**|For a newly created class, the initial value to be used for generating new values \(incremented by 1\) in the lot or serial number segment that has the *Auto-Increment Value* option selected in the **Type** column on this form. The value will change as follows: -   If the **Share Auto-Incremental Value Between All Class Items** check box is selected, the value will be incremented each time a new lot of any item of the class is received. The number of digits in the specified value determines the maximum value of the auto-incremental sequence. For example, if the value is set to *001*, the maximum value can be *999*.
-   If the **Share Auto-Incremental Value Between All Class Items** check box is not selected for the class, the box will be blank. For different items of the class, individual auto-increment values will be used as follows:
    -   For an item of the class, if the initial auto-increment value is specified on the [Stock Items](IN_20_25_00.md) \(IN202500\) form, that value will be used for the lot segment.
    -   For an item of the class, if the initial auto-increment value is not specified on the [Stock Items](IN_20_25_00.md) \(IN202500\) form, the default value *0000* will be used as the initial auto-increment value.

|
|**Auto-Generate Next Number**|A check box that indicates \(if selected\) that the system will automatically generate the next number for items of the class with an auto-increment segment. If the check box is not selected, users should manually enter serial numbers.|
|**Max. Auto-Generate Numbers**|The maximum number of lot or serial numbers that can be generated at once for items of this lot or serial class. If a larger quantity of the item is specified for a document, only the maximum number of lot or serial numbers will be generated, with the excess quantity remaining with unassigned numbers. You can initiate the assignment of lot or serial numbers for an unassigned quantity of the item manually.|

## Numbering Settings Section {#2 .section}

In this section, you can specify the structure of the lot or serial numbers on this tab. Each table row represents a segment of the lot or serial numbers to be used for items of the class.

**Important:** The total number of characters in all segments of a serial or lot number must not exceed 100; unicode characters may be used.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Segment Number**|The segment number of the lot or serial number, which is assigned automatically by the system.|
|**Type**|The type of segment value to be used for this segment of the lot or serial number. You can use one of the following options: -   *Auto-Incremental Value*: Generates incremented values for the segment, using as the initial value either the **Auto-Incremental Value** for this class or the value specific to the inventory item if the **Share Auto-Increment Value Between All Items of the Class** check box is not selected. This option can be selected for only one of the segments.
-   *Constant*: Uses a constant in the segment.
-   *Day*: Uses the day \(from the date when the lot or serial number is generated\) in the segment.
-   *Month*: Uses the two-digit month \(from the date when the lot or serial number is generated\) in the segment.
-   *Month Long*: Uses the month name in the segment.
-   *Year*: Uses the two-digit year in the segment.
-   *Year Long*: Uses the four-digit year in the segment.
-   *Custom Date Format*: Uses the date in the custom date format in the segment.

|
|**Value**|The specific value to be used in the lot or serial number segment; you enter this value if the segment has the *Constant* or *Custom Date Format* type. \(Values are not required for other types of segments.\) In this column, you enter the value as follows:

 -   For the *Constant* type, you specify a constant to be used as the segment value.
-   For the *Custom Date Format* type, you specify a date format by using custom date specifiers from .NET. \(For details, see [Custom Date and Time Format Strings](https://docs.microsoft.com/en-us/dotnet/standard/base-types/custom-date-and-time-format-strings)\). For example, for a date that consists of two digits of a month, two digits of a day, and four digits of a year without separators, you use `MMddyyyy`.

|

## Attributes Section { .section}

In this section, you can add the lot or serial attributes to be used for items of the lot or serial class. Attributes are qualities or characteristics that are defined on the [Attributes](CS_20_50_00.md) \(CS205000\) form. Lot or serial attributes are those specified for units of an item with particular lot or serial numbers.

In this section, you can also indicate whether users can specify the sales price and description for a unit of a stock item of the class.

**Attention:** This section is shown only if the *Lot/Serial Attributes* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can add attributes and specify their values for an item of a lot or serial class only if the tracking method of this class is either *Track Serial Numbers* or *Track Lot Numbers* and the assignment method is *When Received*. If the item has a different tracking method or assignment method \(or both\), the **Add** and **Delete** buttons are unavailable in the section.

**Important:**

-   If you add or delete attributes for a particular lot or serial class in this section, the system adds or deletes them for each existing item of this class. Also, if you change the state of the **Active** or **Required** check box for an attribute in the lot or serial class, the system changes the state of the respective check box for all the items of this class on the [Stock Items](IN_20_25_00.md) \(IN202500\) form.
-   You cannot delete a lot or serial attribute from the [Stock Items](IN_20_25_00.md) \(IN202500\) form or the current form if at least one unit with a lot or serial number has been received to stock and values have been specified for its attributes. If you no longer plan to use a lot or serial attribute, you can make it inactive.

|Element|Description|
|-------|-----------|
|**Specify Lot/Serial Price and Description**|A check box that indicates \(if selected\) that you can specify the sales price and description for a unit of a stock item on the [Lot/Serial Details](IN_20_96_00.md) \(IN209600\) form. The system will insert the price and description in sales documents that include these items on the [Sales Orders](SO_30_10_00.md) \(SO301000\) and [Invoices](SO_30_30_00.md) \(SO303000\) forms.If the check box is selected for an item’s lot or serial class, you cannot specify a sales price for this item on the [Sales Prices](AR_20_20_00.md) \(AR202000\) form or add the item to a price worksheet on the [Sales Price Worksheets](AR_20_20_10.md) \(AR202010\) form.

**Attention:** You cannot change the state of the check box if at least one unit with a lot or serial number has been added to an order on the [Sales Orders](SO_30_10_00.md) \(SO301000\) form and the order's status is not *Completed* or *Canceled*.

|

|**Attribute ID**|The name of the attribute, which serves as its unique identifier.

 In this column, you can select an attribute that has been created on the [Attributes](CS_20_50_00.md) \(CS205000\) form.

|

|**Sort Order**|A number representing the order of this attribute in the list of attributes on the **Attributes** tab \(**Lot/Serial Attributes** table\) of the [Stock Items](IN_20_25_00.md) \(IN202500\) form. By default, the attributes are arranged in ascending order by attribute ID. You should specify 1 for the first attribute you want to be listed, 2 for the second, and so on.|
|**Required**|A check box that indicates \(if selected\) that a user must specify a value for this attribute for an item of this lot or serial class.|
|**Control Type**|The type of control \(element\) that has been defined for the attribute, which is one of the following: *Text*, *Number*, *Combo*, *Multi Select Combo*, *Check box*, *Datetime*, or *Selector*.|
