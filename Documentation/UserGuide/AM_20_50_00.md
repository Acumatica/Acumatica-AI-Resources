# Shifts {#_5c53e402-782c-4ce2-98fb-6ec877a2675c .reference}

Form ID: \(AM205000\)

You use this form to manage shifts, which, along with work calendars, define capacity in work centers managed on the [Work Centers](AM_20_70_00.md) \(AM207000\) form. You must create at least one shift to be able to configure a work center. The system also displays shifts on the [Labor](AM_30_10_00.md) \(AM301000\) form, which you use to post employee hours against a production order.

**Attention:** You cannot delete a shift if it is used in a work center.

## Table { .section}

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Shift**|The shift identifier, which can be any numeric code up to 4 characters in length.|
|**Description**|The description of the shift.|
|**Differential Type**|The shift differential that can be set as a fixed *Amount* per hour for time recorded for this shift, or as a *Rate* per hour.**Attention:** Multiple shifts can be set up to take care of special weekend or holiday work, different daily work shifts, or special times when needed shifts are added. A Shop Floor Calendar can also be set up along with any special shifts to keep items separate.

|
|**Shift Differential**|Amount of the shift differential which will be entered as an hourly amount or a rate depending on the differential type selected. For planned costs, the work center standard cost is used as the labor rate. For transactions, either the work center standard cost or employee cost rate is used depending on the value of the **Use Labor Rate** box on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form as follows:-   The *Amount* will be added to the labor rate for the operation.
-   The *Rate* is multiplied by the labor rate for the operation; that is, enter `1.00` to use the operation labor rate as is.

|
|**Crew Size**|The default number of employes per shift. The system displays this value on the [Work Center Crew Schedule](AM_40_51_00.md) \(AM405100\) form, which you can use to monitor the schedule of the work center crew.

 This box is displayed only when the *Advanced Planning and Scheduling* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|

**Tip:** If you do not want to charge labor set the **Differential Type** to *Rate* and set **Shift Differential** to `0`. This way when you want to start charging labor you can just change the shift without having to change the work center standard cost or employee cost rates.
