# Edit Project Items

You use the Edit Project Items page to edit and review the items of a customization project.

**Tip:** You open the page by clicking **File** &gt; **Edit Project Items** on the main menu of the Customization Project Editor.

## Page Toolbar

The page toolbar includes standard and page-specific buttons. The page-specific buttons are listed below.

</td></tr></tbody>
</table>
