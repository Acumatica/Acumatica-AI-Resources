# Cost Projection by Date {#_af5f55d4-ec4f-4b42-a400-71330107edaa .reference}

Form ID: \(PM305500\)

**Important:** This form is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to create date-sensitive cost projections for a project. These projections help you track expenses throughout the project's completion and compare actual costs with initial estimates so that you can stay on budget. For more information, see [Project Cost Projections: Date-Sensitive Cost Projections](Construction_Cost_Projection_CostProjections_byDate.md).

## Form Toolbar { .section}

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Approve**|Approves the cost projection and changes its status from *Pending Approval* to *Open*.

 When you click this command, the **Enter Reason** dialog box opens if on the **Rule Actions** tab of the [Approval Maps](EP_20_50_15.md) \(EP205015\) form, *Is Optional* or *Is Required* is selected in the **Reason for Approval** box. In the dialog box, you can \(if *Is Optional* is selected\) or must \(if *Is Required* is selected\) enter the reason the cost projection is being approved.

 This command is available if the *Approval Workflow* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and the cost projection has the *Pending Approval* status.

|
|**Copy Projection**|Creates a cost projection from the current one sets the new projection’s date and projection date to the current business date.|
|**Hold**|Changes the status of the cost projection to *On Hold* so that the cost projection can be edited.

 This command appears if the cost projection:

 -   Has the *Open*, *Pending Approval*, or *Rejected* status
-   Has the *Released* status and the **Update Project Budget** check box is cleared

|
|**Load Lines**|Loads cost budget lines on the **Details** tab based on the budget level settings in the Summary area of the form.|
|**Reassign**|Opens the **Reassign Approval** dialog box, in which you can specify a new approver for this cost projection.

 This command is available if the cost projection has the *Pending Approval* status and the reassignment of approvals is allowed in the related rule of the approval map on the [Approval Maps](EP_20_50_15.md) \(EP205015\) form.

|
|**Refresh**|Updates the budgeted values in the cost budget lines with the most recent values from the project budget.

 This command appears if the cost projection has the *On Hold* status.

|
|**Reject**|Rejects the cost projection and changes its status from *Pending Approval* to *Rejected*.

 When you click this command, the **Enter Reason** dialog box opens if on the **Rule Actions** tab of the [Approval Maps](EP_20_50_15.md) \(EP205015\) form, *Is Optional* or *Is Required* is selected in the **Reason for Approval** box. In the dialog box, you can \(if *Is Optional* is selected\) or must \(if *Is Required* is selected\) enter the reason the cost projection is being approved.

 This command is available if the *Approval Workflow* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and the cost projection has the *Pending Approval* status.

|
|**Release**|Releases the cost projection and assigns it the *Released* status.

 This command appears if the cost projection has the *Open* status.

|
|**Remove Hold**|Changes the status of the cost projection to *Open*, which indicates that it is ready for processing, or to *Pending Approval* if cost projection approval is configured on the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form.

 This command appears if the cost projection has the *On Hold* status.

|
|**Upload from Projection**|Opens a dialog box in which you select a cost projection for the selected project. When you click **OK**, the system uses the selected cost projection to fill in the **Projected Cost at Completion** column in the current cost projection by date.

 The system copies the **Projected Cost at Completion** to each line on the **Details** tab in which the **Anticipated Cost** does not exceed the **Projected Cost at Completion** being copied.

|

|Element|Description|
|-------|-----------|
|**Reason**|The reason explaining why the cost projection is being approved or rejected.|
|This dialog box has the following buttons.|
|**OK**|Saves the specified reason and closes the dialog box.|
|**Cancel**|Closes the dialog box without saving the specified reason.|

## Summary Area {#1 .section}

In this area, you can specify or view the basic settings of a cost projection by date for a particular project and view its details.

|Element|Description|
|-------|-----------|
|**Reference Nbr.**|The reference number of the cost projection.

 The system assigns the reference number based on the numbering sequence specified on the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form.

|
|**Project**|The project for which the cost projection is prepared.|
|**Project Currency**|The project currency that is specified for the project on the [Projects](PM_30_10_00.md) \(PM301000\) form.|
|**Project Manager**|The project manager that is specified for the selected project on the [Projects](PM_30_10_00.md) \(PM301000\) form.|
|**Status**|The status of the cost projection, which can be one of the following:

 -   *On Hold*: The user can edit the cost projection but cannot release it.
-   *Pending Approval*: The cost projection has been taken off hold and is awaiting approval.

This status is available if the approval map has been specified in the **Cost Projection by Date Approval Map** box on the **Approval** tab of the [Projects Preferences](PM_10_10_00.md) \(PO101000\) form.

-   *Rejected*: The employee who was assigned to approve the cost projection has rejected it.

This status is available if an approval map has been specified in the **Cost Projection by Date Approval Map** box on the **Approval** tab of the [Projects Preferences](PM_10_10_00.md) form.

-   *Open*: The employee who was assigned to approve the cost projection has approved it. If no approval is configured for cost projections, the system assigns this status to the cost projection when **Remove Hold** is clicked on the form toolbar.
-   *Released*: The cost projection has been released.

|
|**Date**|The date when the cost projection was created. By default, the system inserts the current business date.|
|**Projection Date**|The date that the system uses for the calculation of the projected values in the cost projection. By default, the system inserts the current business date.|
|**Description**|A brief description of the cost projection.|
|**Budget Level** section|
|**Project Task**|A check box that indicates \(if selected\) that the cost projection includes the cost task level of detail. The check box is selected by default in a newly created cost projection.|
|**Account Group**|A check box that indicates \(if selected\) that the cost projection includes the account group level of detail. The check box is selected by default in a newly created cost projection.|
|**Inventory ID**|A check box that indicates \(if selected\) that the cost projection includes the inventory item level of detail. The check box is selected by default in a newly created cost projection if the cost budget level of the project includes inventory items.This check box can be selected or cleared only if the cost budget level of the project includes inventory items.

|
|**Cost Code**|A check box that indicates \(if selected\) that the cost projection includes the cost code level of detail. The check box is selected by default in a newly created cost projection if the cost budget level of the project includes cost codes.This check box is shown if the *Cost Codes* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and can be selected only if the cost budget level of the project includes cost codes.

|
|**Calculation Settings** section|
|**Include Pending CO in Calculations**|A check box that indicates \(if selected\) that the system includes the unreleased change order amounts when calculating the **Revised Cost Budget**, **Revised Revenue Budget**, and **Open Commitments** amounts of the current cost projection.

 The system copies the default state of the check box from the **Include Pending CO in Cost Projections by Date** check box on the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form.

 The check box appears if the **Change Order Workflow** check box is selected for the corresponding project on the **Summary** tab of the [Projects](PM_30_10_00.md) \(PM301000\) form.

|
|**Update Project Budget**|A check box that indicates \(if selected\) that the system will update the **Projected Quantity to Complete**, **Projected Quantity at Completion**, **Projected Cost to Complete**, **Projected Cost at Completion**, and **Completed \(%\)** values of the specified project on release of this cost projection. These values will be updated on the **Cost Budget** tab of the [Projects](PM_30_10_00.md) \(PM301000\) form.

 You can select this check box only if the structure of the cost projection matches the structure of the cost budget of the corresponding project.

 If the check box is cleared, the system does not update any values in the project on release of the cost projection. In this case, you can assign the released cost projection the *On Hold* status and continue editing it.

|
|**Calculate Projected Cost by Quantity**|A check box that indicates \(if selected\) that projected costs are calculated by quantity and unit rate for the cost projection lines.

 If this check box is selected for the project on the [Projects](PM_30_10_00.md) \(PM301000\) form, the system selects this check box in the cost projection. If it’s cleared for the project, you can select it manually.

 If the **Account Group** check box is selected, the system selects this check box for each line with an account group for which the **Calculate Projected Cost by Quantity** check box is selected on the [Account Groups](PM_20_10_00.md) \(PM201000\) form.

 With this check box selected, on the **Details** tab of the current form, the system displays the following columns with values based on quantity and unit rate: **Calculate by Quantity**, **Projected Quantity to Complete**, **Projected Unit Rate to Complete**, **Projected Quantity at Completion**, **Projected Unit Rate at Completion**, **Revised Budgeted Quantity**, **Revised Budgeted Unit Rate**, **Actual Quantity to Date**, **Actual Unit Rate to Date**, **Open Committed Quantity**, **Open Committed Unit Rate**, **Completed by Quantity \(%\)**, **UOM**, **Pending CO Quantity**, **Pending CO Unit Rate**, **Anticipated Quantity**, **Anticipated Unit Rate**, **Quantity Performance \(%\)**, **Anticipated Quantity Performance \(%\)**, **Projected Quantity Variance**, and **Projected Cost Variance**.

|
|**Summary** section|
|**Revised Budget Revenue**|The total revised amount of the revenue budget lines of the project, which the system calculates by using the following formula. ``` {#codeblock_w11_rpj_h2c}
SUM Original Budgeted Amount + SUM of Revenue Budget Change Total
```

In this formula, `SUM of Revenue Budget Change Total` is calculated for the closed revenue change orders that have a change date that is earlier than or same as the cost projection date.

|
|**Pending CO Revenue**|The pending amount of change orders for the revenue budget lines of a project. The system calculates this amount as the sum of the revenue change orders with the *Open*, *On Hold*, and *Pending Approval* status with a change date that is earlier than or same as the cost projection date.

 The box appears if the **Include Pending CO in Calculations** check box is selected for the current cost projection.

|
|**Billed Revenue**|The billed revenue amount of a project, which the system calculates as the sum of the amounts of project transactions. It includes the relevant project transactions with the *AR* type on the [Project Transactions](PM_30_40_00.md) \(PM304000\) form that have the date that is earlier than or same as the cost projection date.|
|**Revenue Budget Backlog**|The revised budgeted amount for the revenue lines of the project, which the system calculates depending on the state of the **Include Pending CO in Calculations** check box as follows:-   If the check box is cleared, the system calculates the amount by using the following formula.

    ``` {#codeblock_by4_nsj_h2c}
Revised Budget Revenue – Billed Revenue
    ```

-   If the check box is selected, the system calculates the amount by using the following formula.

    ``` {#codeblock_p3w_qsj_h2c}
Revised Budget Revenue + Pending CO Revenue – Billed Revenue
    ```


|
|**Expected Current Revenue**|The amount of the projected revenue, which the system calculates depending on the state of the **Include Pending CO in Calculations** check box as follows:

 -   If the check box is cleared, the system calculates the amount by using the following formula.

    ``` {#codeblock_wv3_mtj_h2c}
Revised Budget Revenue * Total of Completed (%)
    ```

-   If the check box is selected, the system calculates the amount by using the following formula.

    ``` {#codeblock_xv3_mtj_h2c}
(Revised Budget Revenue + Pending CO Revenue) * Total of Completed (%)
    ```


 In this formula, `Total of % Completed` is the sum of the amounts in the **Completed \(%\)** column on the **Details** tab.

|
|**Overbilling or Underbilling**|The overbilling or underbilling amount of the project, which the system calculates by subtracting the **Expected Current Revenue** amount from the **Billed Revenue** amount.|
|**Projected Margin**|The amount of the projected margin, which the system calculates depending on the state of the **Include Pending CO in Calculations** check box as follows:-   If the check box is cleared, the system calculates the amount by using the following formula.

    ``` {#codeblock_jtr_xvj_h2c}
Revised Budget Revenue + Pending CO Revenue – Total of Projected Cost at Completion
    ```

-   If the check box is selected, the system calculates the amount by using the following formula.

    ``` {#codeblock_ktr_xvj_h2c}
Revised Budget Revenue – Total of Projected Cost at Completion
    ```


In this formula, `Total of Projected Cost at Completion` is the sum of the amounts in the **Projected Cost at Completion** column on the **Details** tab.

|
|**Projected Margin \(%\)**|The percentage of the projected margin, which the system calculates depending on the state of the **Include Pending CO in Calculations** check box as follows:-   If the check box is cleared, the system calculates the value by using the following formula.

    ``` {#codeblock_wty_3xj_h2c}
Projected Margin / (Revised Budget Revenue + Pending CO Revenue)
    ```

-   If the check box is selected, the system calculates the value by using the following formula.

    ``` {#codeblock_xty_3xj_h2c}
Projected Margin / Revised Budget Revenue + Pending CO Revenue
    ```


If **Revised Budget Revenue** is *0*, **Projected Margin \(%\)** is also set to *0*.

|

## Details Tab {#3 .section}

On this tab, you can add the cost budget lines of the project to the cost projection.

|Button|Description|
|------|-----------|
|**View Transactions**|Opens the [Project Transaction Details](PM_40_10_00.md) \(PM401000\) form. This form shows the list of project transactions that correspond to the selected cost budget line.|
|**View Commitments**|Opens the [Commitments](PM_30_60_00.md) \(PM306000\) form. This form shows the list of all commitments that correspond to the selected cost budget line.|
|**View Open Commitments**|Opens the **Open Commitments** dialog box, which lists open commitments that correspond to the selected cost budget line.|
|**View Finance Chart**|Opens the [Project Financial Vision](PM_40_50_00.md) \(PM405000\) form.|
|**Upload from Projection**|Opens a dialog box in which you select a cost projection for the selected project. When you click **OK**, the system uses this cost projection to fill in the **Projected Cost at Completion** column in the current cost projection by date.

 The system copies the **Projected Cost at Completion** to each line on the **Details** tab in which the **Anticipated Cost** does not exceed the **Projected Cost at Completion** being copied.

|

|Column|Description|
|------|-----------|
|**Project Task**|The project task in the cost budget line.This column appears if the **Project Task** check box is selected in the Summary area.

|
|**Account Group**|The expense account group in the cost budget line.This column appears if the **Account Group** check box is selected in the Summary area.

|
|**Calculate by Quantity**|A check box that indicates \(if selected\) that the projected costs for the line are calculated by quantity and unit rate.

 If this check box is selected for the line, the **Projected Cost to Complete** and **Projected Cost at Completion** columns are read-only. To adjust these costs, you change the underlying values related to quantity and unit rate, such as **Projected Quantity to Complete** and **Projected Unit Rate to Complete**.

 If this check box is cleared for the line, the columns that show values related to quantity and unit rate are empty and unavailable for editing.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Description**|The description of the project's cost budget line associated with the cost projection line.

 If the project's cost budget level and cost projection's budget level are the same \(for example, account group, cost code, and project task\), the system uses the description of the cost budget line.

 If the project cost budget level and cost projection budget level are different, the system uses the first available description in the following order: cost code, account group, inventory item, or project task. If none of these descriptions is available, this column is empty.

|
|**UOM**|The unit of measure of the project's cost budget line associated with the cost projection's line, which is populated as follows:

 -   If the cost projection line is based on a single cost budget line and a unit of measure is specified in the cost budget line, the system displays the unit of measure in this column.
-   If the cost projection line is aggregated from multiple cost budget lines with different units of measure, the column is empty.

 If the **Calculate by Quantity** check box is cleared for the line, the column is empty and unavailable for editing.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Projected Quantity to Complete**|The projected quantity to complete for the cost projection line.

 If the **Calculate by Quantity** check box is selected for the line, you can change this value. If you change this value, the system recalculates the projected values related to quantity and unit rate.

 If the **Calculate by Quantity** check box is cleared for the line, this column is empty and unavailable for editing.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Projected Unit Rate to Complete**|The projected unit rate that the system uses to calculate projected costs for the remaining work for the line.

 If the **Calculate by Quantity** check box is selected for the line, you can change this value to adjust the projected costs based on quantity and unit rate. If you change this value, the system recalculates projected values.

 If the **Calculate by Quantity** check box is cleared for the line, this column is empty and unavailable for editing.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Cost Code**|The cost code in the cost budget line.This column appears if the **Cost Code** check box is selected in the Summary area.

|
|**Inventory ID**|The stock or non-stock inventory item that is associated with the cost budget line, or the empty item code that is specified on the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form.

 This column appears if the **Inventory ID** check box is selected in the Summary area.

|
|**Projected Cost to Complete**|The line's projected remainder of the budgeted cost, which is calculated by subtracting the line's actual cost to date from its projected cost at completion.

 If the status of the project task specified in the **Project Task Status** column is *Completed*, the cost is set to *0*.

|
|**Projected Quantity at Completion**|The projected total quantity at completion for the line.

 If the **Calculate by Quantity** check box is selected for the line, the system calculates this quantity as the sum of the **Actual Quantity to Date** and **Projected Quantity to Complete** values. If you change this quantity, the system recalculates the related projected values.

 If the **Calculate by Quantity** check box is cleared for the line, this column is empty and unavailable for editing.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Projected Unit Rate at Completion**|The projected unit rate at completion for the line.

 If the **Calculate by Quantity** check box is cleared for the line, this column is empty.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Projected Cost at Completion**|The line's projected final cost on project completion. The system calculates this cost depending on the state of the **Include Pending CO in Calculations** check box as follows:

 -   If the check box is cleared, the system calculates the amount by using the following formula.

    ``` {#codeblock_skg_zzj_h2c}
MAX of ((Revised Budgeted Cost + Pending CO Cost) or Anticipated Cost)
    ```

-   If the check box is selected, the system calculates the amount by using the following formula.

    ``` {#codeblock_tkg_zzj_h2c}
MAX of ((Revised Budgeted Cost) + Pending CO Cost) or Anticipated Cost)
    ```


 In this formula, `MAX` means that the system calculates the amounts and uses the maximum one.

 If you change the **Projected Cost to Complete** in the line, the system recalculates this amount by using the following formula.

 ``` {#codeblock_obr_41k_h2c}
Projected Cost to Complete + Actual Cost to Date
```

 If you change the **Completed \(%\)** in the line, the system recalculates this amount by using the following formula.

 ``` {#codeblock_zf5_r1k_h2c}
Actual Cost to Date / Completed (%)
```

 Suppose that you create a new cost projection for the same project with the same budget level, load the budget lines, and click **Copy Projection** on the form toolbar; then you select the released cost projection to be copied. The system copies the projected cost at completion if the line's anticipated cost is less than or the same as the projected cost at completion being copied.

|
|**Completed by Quantity \(%\)**|The projected percentage of completion for the cost budget line, which the system calculates by using the following formula.

 ``` {#codeblock_completed_by_qty}
Actual Quantity to Date / Projected Quantity at Completion
```

 If the projected quantity at completion is *0*, this quantity is also set to *0*.

 If the **Calculate by Quantity** check box is cleared for the line, this column is empty and unavailable for editing.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Completed \(%\)**|The projected percentage of completion for the cost budget line, which is calculated by using the following formula.

 ``` {#codeblock_o2y_bbk_h2c}
 Actual Cost to Date / Projected Cost at Completion 
```

 If **Projected Cost at Completion** is *0*, **Completed \(%\)** is also set to *0*.

|
|**Revised Budgeted Quantity**|The revised budgeted quantity for the cost projection line.

 If the **Change Order Workflow** check box is selected on the [Projects](PM_30_10_00.md) \(PM301000\) form, the system calculates this quantity as the sum of the following:

 -   **Original Budgeted Quantity** from the project cost budget
-   The sum of quantities from the Cost Budget tab of released change orders whose change date is earlier than or the same as the projection date

 If the check box is cleared, the system uses the revised budgeted quantity from the project's cost budget.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Revised Budgeted Unit Rate**|The revised budgeted unit rate of the cost budget line, which the system calculates as **Revised Budgeted Amount** divided by **Revised Budgeted Quantity**.

 If the **Calculate by Quantity** check box is cleared for the line, this column is empty.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Revised Budgeted Cost**|The revised budgeted amount of the cost budget line, which the system calculates depending on the state of the **Change Order Workflow** check box on the Summary tab of the [Projects](PM_30_10_00.md) \(PM301000\) form as follows:

 -   If the check box is cleared, the system calculates the amount as the sum of the revised budgeted amounts of the cost budget lines.
-   If the check box is selected, the system calculates the amount by using the following formula.

    ``` {#codeblock_r22_zdk_h2c}
SUM of Original Budgeted Amount + SUM of Cost Budget Change Total
    ```

In this formula, `SUM of Original Budgeted Amount` is the sum of the revised budgeted amounts of the cost budget lines. The `SUM of Revenue Budget Change Total` is calculated for the released cost change orders with a change date that is earlier than or same as the cost projection date.


|
|**Pending CO Cost**|The pending amount of the unreleased change orders for the cost budget lines of a project. The system performs these calculations on cost change orders with the *Open*, *On Hold*, and*Pending Approval* status that have a change date earlier than or the same as the projection date.

 The column appears if the **Include Pending CO in Calculations** check box is selected for the current cost projection.

|
|**Actual Quantity to Date**|The actual quantity of the cost budget line recorded to date.

 If the **Calculate by Quantity** check box is selected for the line, the system uses this value in quantity-based calculations, such as calculating **Projected Quantity at Completion** and **Completed by Quantity \(%\)**.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Actual Unit Rate to Date**|The actual unit rate of the cost budget line recorded to date.

 If the **Calculate by Quantity** check box is selected for the line, the system calculates this amount based on the actual quantity and actual amount recorded to date.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Actual Cost to Date**|The line's total amount of released cost transactions. The system performs these calculations on expense project transactions that have a date earlier than or the same as the projection date.

 The amount is calculated in the project currency.

|
|**Open Committed Quantity**|The open committed quantity for the line.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Open Committed Unit Rate**|The open committed unit rate for the line.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Open Commitments**|The line's total amount of released project commitments. The system performs these calculations on only the purchase orders and subcontracts that have a document date earlier than or the same as the projection date.

 The amount is calculated in the project currency.

|
|**Pending CO Quantity**|The quantity from the cost budget lines of change orders with the *On Hold*, *Open*, or *Pending Approval* status whose change date is earlier than or the same as the projection date.

 This column appears if the *Change Orders* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and the **Include Pending CO in Calculations** check box is selected in the Summary area.

|
|**Pending CO Unit Rate**|The unit rate, which is calculated as the pending change order cost divided by the pending change order quantity for the line.

 If **Pending CO Quantity** is *0*, this column is empty.

 This column appears if the *Change Orders* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and the **Include Pending CO in Calculations** check box is selected in the Summary area.

|
|**Pending CO Commitments**|The pending amount of change orders to the project commitments. The system calculates the amount as the sum of the commitment change totals in change orders. The total includes change orders to commitments with the *Open*, *On Hold*, and *Pending Approval* status that have a change date earlier than or the same as the projection date.

 The column appears if the **Include Pending CO in Calculations** check box is selected for the current cost projection.

|
|**Anticipated Quantity**|The anticipated quantity based on existing commitments, such as purchase orders, subcontracts, and project drop-ships. The system calculates this quantity as the sum of the **Actual Quantity to Date** and **Open Committed Quantity**.

 If the **Include Pending CO in Calculations** check box is selected, the system also adds the committed quantity from pending change orders.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Anticipated Unit Rate**|The anticipated unit rate based on existing commitments, such as purchase orders, subcontracts, and project drop-ships. The system calculates this rate as **Anticipated Cost** divided by **Anticipated Quantity**. If **Anticipated Quantity** is *0*, this column is empty.

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

|
|**Anticipated Cost**|The anticipated cost of the cost budget line, which the system calculates depending on the state of the **Include Pending CO in Calculations** check box as follows:

 -   If the check box is cleared, the system calculates the cost by using the following formula.

    ``` {#codeblock_jrc_mck_h2c}
Actual Cost to Date + Open Commitments
    ```

-   If the check box is selected, the system calculates the value by using the following formula.

    ``` {#codeblock_krc_mck_h2c}
Actual Cost to Date + Open Commitments + Pending CO Commitments
    ```


|
|**Cost Budget Backlog**|The amount of the revised budgeted costs that is available for the project, which the system calculates depending on the state of the **Include Pending CO in Calculations** check box as follows:

 -   If the check box is cleared, the system calculates the amount by using the following formula.

    ``` {#codeblock_t2r_3ck_h2c}
Revised Budgeted Cost - Actual Cost to Date
    ```

-   If the check box is selected, the system calculates the amount by using the following formula.

    ``` {#codeblock_u2r_3ck_h2c}
Revised Budgeted Cost + Pending CO Cost - Actual Cost to Date
    ```


|
|**Quantity Performance \(%\)**|The projected quantity-based performance percentage for the cost projection line, which the system calculates based on the state of the **Include Pending CO in Calculations** check box.

 If the check box is selected, the system calculates the percent by using the following formula.

 ```
Actual Quantity to Date / (Revised Budgeted Quantity + Pending CO Quantity)
```

 If the check box is cleared, the system calculates the percent by using the following formula.

 ```
Actual Quantity to Date / Revised Budgeted Quantity
```

 This column appears if the **Calculate Projected Cost by Quantity** check box is selected in the Summary area.

## Approvals Tab {#section_qqp_rgh_smb .section}

This tab displays the approval details for the cost projection. If approval is configured, the cost projection is automatically assigned for approval when it is taken off hold. Authorized users approve or reject cost projection either from the current form or by using the [Approvals](EP_50_30_10.md) \(EP503010\) form.

This tab displays the approval entries associated with the selected record. If the record has existing *Approved* or *Rejected* entries and is put on hold for editing, these entries are preserved on the tab and the **Obsolete** check box is selected for them. Approval entries with a *Pending* decision are deleted. When the record is resubmitted for approval, new approval entries are created for this approval cycle.

This tab is available only if the *Approval Workflow* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and an approval map is specified for cost projections in the **Cost Projection by Date Approval Map** box on the **Approval** tab of the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form. If no map is specified in this box, cost projections do not require approval.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Assignee**|The identifier of the employee who is assigned to approve the record.|
|**Assignee Name**|The name of the employee who is assigned to approve the record.|
|**Workgroup**|The workgroup of the employee who is assigned to approve the record.|
|**Reviewer**|The identifier of the employee who actually reviewed the record.|
|**Reviewer Name**|The name of the employee who actually reviewed of the record.|
|**Date**|The review date.|
|**Decision**|The approval decision made for the record, which can be *Pending*, *Approved*, or *Rejected*, depending on the approval action performed.|
|**Reason**|The reason the record has been approved or rejected \(if applicable\).|
|**Obsolete**|A check box that indicates \(if selected\) that the approval decision belongs to a previous approval cycle. The system selects the check box for all *Approved* and *Rejected* approval entries when the record is put on hold for editing.|
