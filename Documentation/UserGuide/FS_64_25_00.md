# Appointments in Service Order

Form ID: \(FS642500\)

This report displays summary information about the completed appointments of a service order. The report provides the company information \(in the top left\), contact information, customer information, general information about the appointments, and the total price of the appointments.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Service Order Type**: The service order type related to the service order for which you want to display data. You must specify the type.
-   **Service Order Number**: The number of the service order to which the appointments are related. You must specify the number of the service order.
