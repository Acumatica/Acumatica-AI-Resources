# Print/Email Project Quotes

Form ID: \(PM504545\)

On this form, you can print or email multiple project quotes. You can process all quotes listed in the table at once or only the ones you select. Before processing, you can narrow the range of listed quotes by selecting a specific owner, workgroup, or business account.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the selected processing \(based on the **Action** that you select\) for the project quotes that you have selected in the table.|
|**Process All**|Initiates the selected processing \(based on the **Action** that you select\) for all project quotes that are listed in the table.|

## Selection Area

In this area, you can specify the criteria for the project quotes to be displayed in the table below, as well as the action to be applied if you click **Process** or **Process All**.

A check box that indicates \(if selected\) that the system adds the documents as attachments to a single email to be sent to the customer during processing.

**Attention:** You can attach up to 100 documents to one email. If more than 100 documents of a recipient are included in processing, the system creates multiple emails, keeping each email’s attachments within this limit. For example, if 225 documents are being processed for a recipient, the system creates three emails: two emails with 100 documents attached, and one email with 25 documents attached.

 This check box appears only if *Send* is selected in the **Action** box.

**Combine Documents into One File**

A check box that indicates \(if selected\) that the system combines the processed documents into a single file and attaches it to the email.

**Attention:** You can combine up to 100 documents into one file attached to an email. If more than 100 documents of a recipient are included in processing, the system creates multiple emails, keeping the documents of each attachment within this limit. For example, if 225 documents are being processed for a recipient, the system creates three emails: two emails with 100 documents combined into a single file, and one email with 25 documents combined.

 This check box is available only if *Send* is selected in the **Action** box and the **Send Documents in One Email** check box is selected.

 This check box appears on the form only if both of the following conditions are met:

 The box is available if the **Define Printer Manually** check box is selected.
