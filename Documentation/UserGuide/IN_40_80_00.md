# Inventory by Item Class {#_e118c254-2b92-4dae-ba9e-b697b0598694 .reference}

Form ID: \(IN408000\)

**Attention:** This form is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

On this form, you can browse the hierarchy of item classes. You can select a particular inventory item and view the item class to which it belongs. You can also review the entire list of inventory items that belong to a particular item class: either the items that belong to only the selected item class or the items that belong to the selected item class and to child item classes. Also, you can move inventory items from one item class to another.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Item Class Tree Pane { .section}

In this pane, you can view the hierarchy of item classes that are defined in the system, and click any item class to view its inventory items. The number of nested levels in the tree is defined by the configuration of the *INITEMCLASS* segmented key on the [Segmented Keys](CS_20_20_00.md) \(CS202000\) form. For more information, see [Managing Hierarchical Item Classes](IN__mng_Managing_Hierarchical_Item_Classes.md).

|Element|Description|
|-------|-----------|
|**Class ID**|The ID of the item class for which the items belonging to the class are listed in the right pane. You can select an ID manually in this box, or if you click an item class in the tree, the box will be filled in with the item class you have clicked.|

## Right Pane: Selection Area {#1 .section}

By using the elements in this area, you can view in the table the data that is most relevant to your needs for information.

|Element|Description|
|-------|-----------|
|**Inventory ID**|The ID of the inventory item for which you want to view the item class to which it belongs.|
|**Show Items**|A group of option buttons that defines which items are listed in the table. Select one of the following buttons:-   **Related to Only the Current Item Class**: If this button is selected, the table shows only the items of the item class selected in the **Class ID** box.
-   **Related to the Current and Child Item Classes**: If this button is selected, the table shows the items of the item class selected in the **Class ID** box along with the items of the child item classes of the selected item class.

|

## Right Pane: Item Class Members Table {#2 .section}

In this area, you can view the details of the inventory items that meet the criteria you have specified in the Selection area.

|Button|Description|
|------|-----------|
|**Cut**|Cuts selected table row or rows \(those for which you have selected the Included check box\) to the clipboard.|
|**Paste**|Inserts the row or rows from the clipboard to the table—that is, moves the selected items to the item class that is currently selected. When you move an item or multiple items to another item class, you can select whether to update the settings of the item or items to be the default settings of the destination item class, or leave the item settings unchanged.|

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to move the selected row to another item class if you click**Cut Selected Records** on the table toolbar.|
|**Inventory ID**|The ID of the inventory item.|
|**Description**|The item description.|
|**Item Class**|The ID of the item class to which the inventory item belongs.|
|**Description**|The item class description.|
|**Item Status**|The status of the inventory item.|
