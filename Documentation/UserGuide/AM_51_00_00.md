# Create Production Orders

Form ID: \(AM510000\)

You use this form to create production orders for supported production demand, including eligible project material demand. You can process project material demand together with other supported production demand.

This process includes the creation of multiple production orders for sales order lines which have **Mark for Production** check box selected. The **Mark for Production** check box is automatically selected when a sales order line is entered for a stock item having **Make to Order Item** check box selected on the **Manufacturing** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form. This enables you to defer the creation to a later time or assign the creation of production orders to another user. The **MTO Order** check box must be selected on the [Order Types](SO_20_10_00.md) \(SO201000\) form also to auto check the **Mark for Production** check box on the sales order line.

The sales order must meet the following conditions:

-   On the [Order Types](SO_20_10_00.md) \(SO201000\) form, the **Enable Linking to Production Orders** check box must be selected for the order type.
-   The sales order must have one of the statuses specified for the order type in the **Linkable Sales Order Statuses** list.

The stock item must have the **Source for Production Order** set to *Production* on the [Stock Items](IN_20_25_00.md) \(IN202500\) form. This will select the **Mark for Production** check box in the *Materials* line on the [Production Order Details](AM_20_90_00.md) \(AM209000\) form. You can also manually select this check box. The plan type is *Production to Production*.

**Attention:** This process does not support the creation of production orders when manual numbering is selected for the numbering sequence specified on the [Production Order Types](AM_20_11_00.md) \(AM201100\) form.

## Table

The table lists all sales order lines where:

-   The **Marked for Production** check box is selected
-   A production order has not been created

This is a list of the sales orders lines for which a production order can be created based on the selection criteria specified. The sales order line must have the **Mark for Production** check box selected. Other than the Selected column, none of the columns can be changed. You must change the data on the sales order line.

For project material demand, the table includes material lines from active projects for which *Production Order* is selected as the provisioning source, the material line has the *Pending Procurement* status, and the material line is not already linked to production supply. For these lines, quantities are displayed in the inventory item's base unit of measure. If the project material line uses a different unit of measure, the system converts the quantity to the base unit.

The table toolbar has only standard buttons.
