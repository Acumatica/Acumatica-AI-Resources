# Campaign Classes {#_0b3a17bb-3d7a-49f9-be8d-cb25993ef609 .reference}

Form ID: \(CR202500\)

You use this form to create and modify campaign classes. Each campaign class represents a particular type of marketing campaigns and provides a list of attributes that can be used as additional elements for sorting marketing campaigns of the class. For each attribute, you can specify whether this attribute is required and what its position is in the list of attributes for the class. For more details, see [Managing Attributes and User-Defined Fields](CS__con_Attributes_and_User_Defined_Fields.md).

## Form Toolbar { .section}

The table toolbar has only standard buttons.

## Summary Area { .section}

This area contains the identifier and description of the campaign class.

|Element|Description|
|-------|-----------|
|**Campaign Class ID**|The unique identifier of the campaign class. When creating a new campaign class, you can specify an alphanumeric string of up to 10 characters. To view an existing class, you select its identifier in this box.|
|**Description**|A brief description of the campaign class.|

## Table { .section}

This table contains the list of campaign attributes associated with the class. When this class is selected on the [Marketing Campaigns](CR_20_20_00.md) \(CR202000\) form, the attributes specified for the class are listed on the **Attributes** tab of that form.

When you add a row to this table, you can select an attribute from the list of attributes defined in your system. To add a new attribute to the system, use the [Attributes](CS_20_50_00.md) \(CS205000\) form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that the attribute is available for all campaigns of the class.

 You can deactivate an obsolete attribute by clearing the check box—in this case, the deactivated attribute will no longer be displayed for campaigns of the class, but all attribute values that have already been specified for existing records still will be stored in the database, so if you reactivate the attribute, its values will become visible in the system again.

|
|**Attribute**|The name of the attribute, which serves as its identifier.|
|**Description**|Read-only. A detailed description of the attribute.|
|**Sort Order**|The number that represents the order of the attribute as it will appear on the **Attributes** tab of the [Marketing Campaigns](CR_20_20_00.md) \(CR202000\) form.|
|**Required**|A check box that indicates \(if selected\) that the attribute value is required for all marketing campaigns of the class.|
|**Default Value**|The default value of the attribute, which may be overridden for any particular marketing campaign of the class on the **Attributes** tab of the [Marketing Campaigns](CR_20_20_00.md) \(CR202000\) form.|
|**Internal**|Read-only. A check box that indicates \(if selected\) that the attribute is not available for portal users.|
|**Contains Personal Data**|A check box that indicates \(if selected\) that the system should treat the value of this attribute as personal data related to a marketing campaign of this campaign class.

 The check box is selected or cleared when the attribute is defined on the [Attributes](CS_20_50_00.md) \(CS205000\) form. The state of the check box is then copied to each campaign class that includes the attribute, as well as to the marketing campaign of this campaign class.

 If access to personal data for an entity record, such as a campaign, is restricted on the [Restrict Personal Data](GD_10_20_10.md) \(GD102010\) form and this check box is selected for attributes associated with this campaign, access to personal data \(including specified attributes\) of this campaign will be restricted for users. For more details, see [Handling Personal Data](GD__MNG_Handling_Personal_Data.md).

 The check box is displayed on the form if the *GDPR Compliance Tools* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Control Type**|Read-only. The type of control for the attribute, which may be one of the following: *Text*, *Combo*, *Multi Select Combo*, *Lookup*, *Checkbox*, or *Datetime*.|
