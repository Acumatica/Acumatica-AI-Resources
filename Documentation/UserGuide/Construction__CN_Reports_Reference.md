# Construction Reports {#_91aa94f3-55e3-4753-8cc2-fd6d5960fbc3 .concept}

With Acumatica ERP Construction Edition reports, you can get detailed information about various aspects of construction projects. If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All construction-related reports can be generated in different formats, including PDF and HTML, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
