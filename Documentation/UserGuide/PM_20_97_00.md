# Union Locals {#_3bcc9979-ef23-4331-9085-19edc8babe83 .reference}

Form ID: \(PM209700\)

You can use this form to define local branches of unions. You can add each union local manually or upload a list of union locals from an Excel file.

This form is available if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table { .section}

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that the union local is available for selection on data entry forms. If the check box is cleared, the union local is inactive and is unavailable for selection on any data entry form.|
|**Union Local ID**|The unique identifier of the union local.|
|**Description**|A more detailed description of the union local.|
