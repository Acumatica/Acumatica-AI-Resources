# Exposing Generic Inquiries to AI Assistant {#_06ba1070-cbd2-4292-b7b9-d964583f43fb .concept}

*AI Assistant* is a chat window inside Acumatica ERP where you can ask questions in plain language and quickly explore your data. Instead of checking multiple forms and reports to find answers, you can get answers immediately and act on them with just a click.

Behind the scenes, AI Assistant relies on a defined set of generic inquiries and their descriptions. You can add more generic inquiries to this set or remove them from it, and modify the descriptions. By default, the most popular generic inquiries are used as sources.

In this chapter, you’ll learn how to configure generic inquiries so that AI Assistant can use them.
