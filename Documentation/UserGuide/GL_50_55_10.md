# Release Budgets {#_a29ba31c-cf25-416c-a253-7de75fe54d31 .reference}

Form ID: \(GL505510\)

This form can be used to release budget articles. Once released, budget articles are stored in the appropriate ledger and are available for reports, budget consolidation, and comparison with the actual data.

When you open the form, it lists all budget articles that have not yet been released. To release particular budget articles, select the check boxes for those you want to release, and click **Release** on the form toolbar. To release all budget articles at once, click **Release All**.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Release**|Initiates the release process for the budget articles you have selected in the table.|
|**Release All**|Initiates the release process for all budget articles listed in the table.|

## Table { .section}

The list contains all budget articles that have not been released. You can release all articles or select particular articles for release.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include this budget article for release if you click **Release** on the form toolbar.|
|**Branch**|The branch whose budget article is shown in the table row.

 This column appears on the form only if the *Multibranch Support* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md#) \(CS100000\) form.

|
|**Ledger**|The ledger where the budget is stored.|
|**Financial Year**|The financial year for which the budget has been created.|
|**Account**|The account of the budget article.|
|**Subaccount**|The subaccount of the budget article.

 This box appears on the form only if the *Subaccounts* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md#) \(CS100000\) form.

|
|**Description**|The description provided for the budget article.|
|**Amount**|The budget amount for the article.|
