# Restricted Personal Data {#_50f6d383-0e62-46dc-8c1b-027aa997ac30 .reference}

Form ID: \(GD102030\)

This form is available only if the *GDPR Compliance Tools* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can view, restore, or erase previously pseudonymized records.

For more information about how you can handle personal data in Acumatica ERP, see [Handling Personal Data](GD__MNG_Handling_Personal_Data.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Restore**|Restores the obfuscated personal data contained in those records in the table for which you have selected the unlabeled check box.|
|**Erase**|Permanently obfuscates the personal data contained in those records in the table for which you have selected the unlabeled check box.|

## Summary Area { .section}

By using the elements in this area, you can set up the data restoration process so that any personal data that cannot be restored is permanently deleted from the database.

|Element|Description|
|-------|-----------|
|**Restore Options Section**|
|**Delete Data That Cannot Be Restored**|A check box that indicates \(if selected\) that any personal data that cannot be restored \(for instance, orphan data\) will be permanently deleted for the selected records when you click **Restore** on the form toolbar.|

## Table { .section}

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that indicates \(if selected\) that the obfuscated personal data contained in the record will be either permanently obfuscated if you click **Erase** on the form toolbar or restored if you click **Restore** on the form toolbar.|
|**Key**|The system identifier of the contact record.|
|**Entity**|The type of the entity to which the contact record is related and the personal data that has been obfuscated for this contact.|
|**Created On**|The date and time when the personal data was obfuscated for the entity.|
