# Non-Depreciated Fixed Assets {#_340b36f0-335e-49d6-a09b-694f90d79f7e .reference}

Form ID: \(FA652100\)

By using this report, you can view the assets that must be depreciated before you can close a financial period.

**Attention:** In addition to running this report from the site map, you can run it along with other reports to find unposted documents, by clicking **Unposted Documents** on the form toolbar of the [Manage Financial Periods](GL_50_30_00.md) \(GL503000\) form as preparation for closing a financial period in the subledgers and in the general ledger.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Company**: The company for which you want to view information. You can select a company or make no selection to view information about all companies in the tenant. By default, the current company is selected. The report shows a list of fixed assets for all branches of the selected company, which are displayed in the **Branch** column of the generated report.
-   **From Period**: The starting financial period of the range of periods the report will cover. You must select a period.

    By default, the current financial period is used.

-   **To Period**: The ending financial period of the range of periods the report will cover. You must select a period.

    By default, the current financial period is used.
