# Blanket Sales Order {#_19ae2eb8-4e86-4f7b-87df-544c6f14857b .reference}

Report ID: \(SO641040\)

By using this report, you can display the selected blanket sales order as a ready-to-print document. The document provides the company information \(in the top left\), the ship-to and bill-to addresses of the customer, the pertinent shipping information, and the itemized information about goods shipped.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Order Type**: The type of the sales order you want to view. The default type is *BL* \(a predefined type for blanket sales orders\), but you can select another type that has the *Blanket Order* automation behavior .
-   **Order Number**: The reference number of the order.
