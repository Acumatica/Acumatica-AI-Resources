# Unbilled Project Revenue Aging {#_40bb4160-a6ba-4961-87b1-8c9e7b80aa06 .reference}

Form ID: \(EP408100\)

On this inquiry form, you can review unbilled project revenue across projects and their project tasks, with revenue broken down by aging period. The data includes project tasks with the *Active*, *In Planning*, or *Completed* status.

To determine the expected revenue amount, the system uses the billing rule assigned to the project task. It simulates the billing procedure used when you click **Run Billing** on the [Projects](PM_30_10_00.md) \(PM301000\) form.

**Important:** The system calculates data only for project tasks of the *Cost and Revenue Task* type. These project tasks must also use a billing rule with no *Progress Billing* steps.

The system calculates the expected revenue amount based on the state of the **Create Pro Form Invoice on Billing** check box on the [Projects](PM_30_10_00.md) form:

-   Selected: The expected revenue is the sum of the **Billed Amount** values in the lines of the simulated pro forma invoice.
-   Cleared: The expected revenue is the sum of the **Ext. Price** values in the lines of the simulated AR invoice.

**Attention:** This form is available only if the *Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes standard and form-specific buttons. The form-specific buttons are listed in the following table.

|Button|Description|
|------|-----------|
|**Calculate**|Calculates the expected revenue for projects and their project tasks and groups it into aging periods.

 The button is available if at least one project is selected in the **Projects** box or the **Show All Active Projects** check box is selected.

|

## Selection Area {#1 .section}

You can use the settings in this area to control how the system calculates and displays unbilled project revenue in the table. These settings determine which projects are included, along with their project tasks.

|Element|Description|
|-------|-----------|
|**Projects**|The active projects for which the unbilled revenue is calculated.|
|**Show All Active Projects**|A check box that you select to calculate unbilled revenue for the project tasks of all active projects.|

## Table {#2 .section}

This table shows the distribution of unbilled revenue across projects and their project tasks broken down by aging period. Aging is based on the project transaction date compared with the current business date.

|Column|Description|
|------|-----------|
|**Project**|The project ID, which is also a link.|
|**Project Description**|The project description.|
|**Project Task**|The project task ID, which is also a link.|
|**Project Task Description**|The project task description.|
|**Project Task Status**|The status of the project task.|
|**Project Manager**|The project manager.|
|**Total Unbilled Revenue**|The total unbilled revenue for the project task.|
|**0-29 Days**|The amount of unbilled project task revenue in project transactions aged 0 to 29 days.|
|**30-59 Days**|The amount of unbilled project task revenue in project transactions aged 30 to 59 days.|
|**60-89 Days**|The amount of unbilled project task revenue in project transactions aged 60 to 89 days.|
|**90-119 Days**|The amount of unbilled project task revenue in project transactions aged 90 to 119 days.|
|**120+ Days**|The amount of unbilled project task revenue in project transactions aged 120 days or more.|
