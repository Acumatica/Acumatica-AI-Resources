# Scan Warehouse Path {#_6b36fb14-3df6-4055-a506-194419515250 .reference}

Form ID: \(IN204025\)

On this form, you can set up the path layout of warehouse locations during the initial configuration. You can scan locations one by one following a warehouse worker's optimal route. For the first scanned location, the system assigns 1 as the initial path value, and each subsequent location increases this value by 1. For example, if you scan three locations, their path values will be 1, 2, and 3.

After initial setup, you can adjust the values assigned to the location path on the [Warehouses](IN_20_40_00.md) \(IN204000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Reset**|Resets any unsaved changes and the selected warehouse.|
|**Set Next Path Index**|Lets you enter the path value to assign to the next scanned warehouse location.|

## Summary Area {#1 .section}

This area contains the basic settings of warehouse locations.

|Element|Description|
|-------|-----------|
|**Warehouse**|The warehouse in which you set up the values of location paths.|
|**Next Path Index**|The path value that will be assigned to the next scanned warehouse location.|

## Warehouse Tab {#2 .section}

On this tab, you can review the list of locations and their path values for a selected warehouse.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Location ID**|The unique identifier of the warehouse location.|
|**Description**|A brief description of the warehouse location.|
|**Path**|A value that indicates the position of each location in the warehouse. Higher values correspond to distant locations. The values specified for all locations define the linear map of a warehouse. The system uses this map to calculate the best path for each picker to use when picking items in a batch or in a wave.|

## Scan Log { .section}

This tab displays the history of the most recent performed operations in the current working mode. The log is cleared when you close the form or switch to another working mode.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Time**|The date and time when the operation was performed.|
|**Mode**|The working mode that was active when the system was performing the operation.|
|**Prompt**|The message describing the operation to be performed \(as was shown in the notification area\).|
|**Scan**|The command that was entered in the **Scan** box, or the barcode that was scanned.|
|**Message**|The result of the operation \(as was shown in the notification area\).|
