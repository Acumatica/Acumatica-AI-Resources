# Document Management Reports {#_6a0e6c60-3c10-4311-939e-54b4f38d655f .concept}

With the Acumatica ERP audit reports on document management, you can view statistics on wiki articles, which can be filtered by author, time interval, and type of article content. If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All document management reports can be generated in different formats, including PDFs, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
