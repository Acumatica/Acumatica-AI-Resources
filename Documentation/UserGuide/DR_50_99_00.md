# Recalculate Deferred Balances {#_f66f9e95-a537-4727-9580-14874b030767 .reference}

Form ID: \(DR509900\)

You can use this form to recalculate the balances of deferrals. Balances are recalculated based on the history records and are matched to the deferral schedules stored in the database.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Recalculates deferral balances for the types of deferrals that you have selected in the table.|
|**Process All**|Recalculates balances for all listed deferrals.|

## Table {#Selection .section}

This table contains the list of deferral types for which the balances can be recalculated.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include this deferral type in the recalculation if you click **Process**.|
|**Balance Type**|The deferral type, *Expense* or *Revenue*.|
