# Materials {#_bac20b22-8f5c-4252-8a7a-f022e0471c91 .reference}

Form ID: \(AM300000\)

You use the form to create, modify, and release a material transaction, which contains rows for the materials to be issued on release of the corresponding inventory issue transaction. The materials can be entered directly on this form or populated by using the [Select Production Orders](AM_30_00_10.md) \(AM300010\) form.

When the material transaction is released, the system also creates and releases an inventory issue on the [Issues](IN_30_20_00.md) \(IN302000\) form to update both the production order and the on-hand inventory.

**Attention:** To reverse a material transaction, you can copy the transaction by clicking **Clipboard** &gt; **Copy** on the form toolbar, creating a copy of the transaction you need to reverse, and changing all the quantities to negative in the detail lines of the new transaction. You should not use the [Issues](IN_30_20_00.md) \(IN302000\) form to initiate this reversal because reversing an issue transaction does not cause the reversal of the corresponding material transaction; thus, the production orders specified for the material transaction are not updated.

## Insufficient Material Quantity { .section}

When a user releases a material transaction, the system typically creates and releases an inventory issue transaction. If there is insufficient item quantity in a warehouse location, the lot, or both, the issue transaction is created but is not released. The system assigns the *On Hold* status to the material transaction and you cannot update it. The material transaction is also not released, and the system displays an error message. Once you have determined the cause of the error, you can do any of the following to the material transaction:

-   Delete the unneeded line. The system will delete the corresponding line from the inventory issue transaction when you save the material transaction.
-   Add a new line, if required, with the correct information. This will add the line to the corresponding inventory issue transaction when you release the material transaction.
-   Delete the entire material transaction. This will delete the corresponding inventory issue transaction.

Once you update the material transaction, you release it. If it has been released without errors, the inventory issue transaction will be released.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

**Attention:** If the material transaction has been created for backflushed materials by using the [Labor](AM_30_10_00.md) \(AM301000\) or [Move](AM_30_20_00.md) \(AM302000\) form, that is, the identifier of the labor or move transaction is specified in the **Orig. Batch Nbr.** box of the Summary area, the material transaction cannot be released or deleted on this form. For this transaction, the **Release** and **Delete** buttons are unavailable even if the transaction has the *On Hold* or *Balanced* status.

|Command|Description|
|-------|-----------|
|**Release**|Initiates the release of the material transaction, which changes the status of the transaction to *Released* and causes an issue transaction to be created and released on the [Issues](IN_30_20_00.md) \(IN302000\) form.|
|**Add Materials**|Opens the [Select Production Orders](AM_30_00_10.md) \(AM300010\) form to populate this form with the desired materials.|

## Summary Area { .section}

In this area, you can select an existing material transaction by its reference number or provide summary settings for the new transaction.

|Element|Description|
|-------|-----------|
|**Batch Nbr.**|The reference number of the material transaction.

 The number is assigned automatically or you enter the number manually, depending on the settings of the numbering sequence specified in the **Material Numbering Sequence** box on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form.

|
|**Status**|The status of the transaction set by the system.

 The value in this box can be one of the following:

 -   *On Hold*: The transaction is a draft and can be edited. You cannot release the transaction.
-   *Balanced*: The transaction has been validated by the system and is ready to be released. You can put the transaction on hold to modify or delete it.
-   *Released*: The transaction has been released. You cannot modify or delete the transaction.

|
|**Hold**|A check box that indicates \(if selected\) that the transaction has the *On Hold* status and can be modified or deleted. When you clear the check box the status is changed to *Balanced*.

 The check box is selected for new transactions automatically if the **Hold Documents on Entry** check box is selected on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form.

|
|**Date**|The date when the transaction was created. By default, the system inserts the business date, but you can change this date.

 You can enter only a date that corresponds to a financial period that has been generated on the [Master Financial Calendar](../Shared/../UserGuide/GL_20_10_00.md) \(GL201000\) form. If the date that you enter belongs to a financial period that has not yet been generated in the system—for example, for a date in the distant future or past—the system will display an error message, and you will not be able to save the record.

|
|**Post Period**|The financial period to which the transaction amount is posted. By default, the period is calculated based on the date and the defined financial periods in the system, but you can change the period.|
|**Orig. Batch Nbr.**|Read-only. The reference number of the original transaction that caused the creation of the material transaction \(if applicable\), which can be a labor transaction created on the [Labor](AM_30_10_00.md) \(AM301000\) form or a move transaction created on the [Move](AM_30_20_00.md) \(AM302000\) form. You can click the link to open the corresponding form and view the details of the original transaction. This box is empty if you enter the material transaction directly on the current form.|
|**Orig. Doc. Type**|Read-only. The type of the original transaction whose reference number is displayed in the **Orig. Batch Nbr.** box. The transaction type can be any of the following:-   *Labor*
-   *Move*

|
|**Total Qty.**|The total quantity of the transaction, which is the sum of the values in the **Quantity** column.|
|**Control Qty.**|The control quantity of the transaction. You enter this quantity, and then the system validates whether it is equal to the value of the **Total Qty.** box. If the quantities differ, an error message is displayed and you cannot release the transaction.

 This box is displayed only if the **Validate Document Totals on Entry** check box is selected on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form.

|
|**Total Amount**|The total amount of the transaction, which is the sum of the values in the **Ext. Cost** column.|
|**Control Amount**|The control amount of the transaction. You enter this amount, and the system makes sure that it is equal to the value of the **Total Amount** box. If the amounts differ, an error message is displayed and you cannot release the transaction.

 This box is displayed only if the **Validate Document Totals on Entry** check box is selected on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form.

|
|**Description**|A brief description of the material transaction.|

## Table { .section}

This table contains lines for the materials to be issued, along with the corresponding production order and other details of each material.

In the table footer, the **On Hand**, **Available**, and **Available for Shipping** quantities \(availability buckets\) are displayed. If the production order is integrated with a project \(that is, if the **Update Project** check box is selected in the **Project** section of the **References** tab of the [Production Order Maintenance](AM_20_15_00.md) form\), the system shows two values separated by a slash:

-   The first value is the quantity of project-specific inventory or project inventory tracked by location.
-   The second value is calculated as the first value increased by the quantity of free stock. \(*Free stock* refers to inventory that is not reserved for projects that use the *Track by Project Quantity* or *Track by Project Quantity and Cost* inventory tracking mode.\)

 This button appears on the form if the *Project-Specific Inventory* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. The line can be split if the project selected in the line allows the issuing of items from free stock.
