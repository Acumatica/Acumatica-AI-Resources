# Release Equipment Time Cards

Form ID: \(EP505020\)

**Attention:** This form is available only if the *Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This form lists all equipment time cards that have the *Approved* status. You can release either selected equipment time cards or all the listed time cards. After successful completion of the release, the status of the equipment time cards changes to *Released*.

**Attention:** When you release an equipment time card, the following branches are inserted for the generated project and GL transaction lines:

-   The project branch for the project transaction on the [Project Transactions](PM_30_40_00.md) \(PM304000\) form
-   The project branch for the debit GL transaction line on the [Journal Transactions](GL_30_10_00.md) \(GL301000\) form
-   The user’s current branch—the branch to which the user is signed in, which is shown in the top pane—for the credit GL transaction line and the Summary area

With the following settings specified on the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form, the equipment time card can't be released if the project has no branch specified or if you don't have access to the project branch:

-   **Branch in Project Documents** box: *Use Project Branch* or *Use Project Branch in Lines Only*
-   **Block Doc. Processing on Branch Mismatch** check box: Selected

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Release**|Releases the equipment time cards you have selected in the table.|
|**Release All**|Releases all the equipment time cards listed in the table.|

## Table

This area of the form contains the list of equipment time cards that are ready to be released.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include the record in the release process.|
|**Ref. Nbr.**|The time card reference number, as assigned by the numbering sequence specified in the **Equipment Time Card Numbering Sequence** box on the [Time and Expenses Preferences](EP_10_10_00.md) \(EP101000\).|
|**Equipment ID**|The equipment whose time card is listed.|
|**Week**|The week number of the equipment time card.|
|**Setup**|The time \(in hours and minutes\) spent on preparing the equipment for regular run.|
|**Run**|The time \(in hours and minutes\) during which the equipment was running.|
|**Suspend**|The time \(in hours and minutes\) during which the equipment was suspended.|
|**Total**|The total time \(setup time, run time, and suspend time\) during which the equipment was used.|
|**Billable Setup**|The billable time \(in hours and minutes\) spent on preparing the equipment for regular run.|
|**Billable Run**|The billable time \(in hours and minutes\) during which the equipment was running.|
|**Billable Suspend**|The billable time \(in hours and minutes\) during which the equipment was suspended.|
|**Billable Total**|The total billable time \(setup time, run time, an suspend time\) during which the equipment was used.|
|**Approver ID**|The ID of the person who approved the equipment time card.|
|**Approval Date**|The date when the equipment time card was approved.|
