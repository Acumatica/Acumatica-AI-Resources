# Production Summary

Form ID: \(AM000006\)

On this form, you can find a list of production orders filtered by status. From the list you can drill down to the [Production Order Maintenance](AM_20_15_00.md) \(AM201500\) form.

## Selection Area

<table><thead><tr><th>

</th><th>

</td><td>
