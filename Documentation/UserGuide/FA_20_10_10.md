# Fixed Asset Types {#_579dbf8b-ef34-4186-85d5-401282d07a4e .reference}

Form ID: \(FA201010\)

By using this form, you can maintain the list of the fixed asset types available in the system. You can create new fixed asset types and delete any existing types. You can also edit the settings of the existing fixed asset types.

**Attention:** You can delete a fixed asset type only if it has not been used \(which means that it is not specified for any fixed asset or fixed asset class\).

By default, the list of predefined fixed asset types is available on this form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table { .section}

This table holds the list of fixed asset types defined in the system.

|Column|Description|
|------|-----------|
|**Asset Type ID**|An alphanumeric string of up to 10 characters identifying the asset type.|
|**Description**|A brief description of the asset type.|
|**Tangible**|A check box that indicates \(if selected\) that a fixed asset is tangible. This setting \(selected or cleared\) is displayed in the **Tangible** check box on the **General** tab of the [Fixed Assets](FA_30_30_00.md) \(FA303000\) and [Fixed Asset Classes](FA_20_10_00.md) \(FA201000\) forms when this asset type is selected in the **Asset Type** box.|
|**Depreciable**|A check box that indicates \(if selected\) that a fixed asset is depreciable. This setting \(selected or cleared\) is displayed in the **Depreciable** check box on the **General** tab of the [Fixed Asset Classes](FA_20_10_00.md) \(FA201000\) form when this asset type is selected in the **Asset Type** box.|
