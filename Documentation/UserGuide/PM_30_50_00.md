# Cost Projection {#_430caf8b-46fe-47e3-bd5e-90feb70b41eb .reference}

Form ID: \(PM305000\)

**Important:** This form is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to create revisions of cost projections for a project. Cost projections are used for tracking the project costs during project completion in comparison to the initially estimated costs. For more information, see [Project Cost Projections: General Information](Construction_Cost_Projection_GeneralInfo.md).

## Form Toolbar {#section_v2y_3dh_smb .section}

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Approve**|Approves the cost projection and changes its status from *Pending Approval* to *Open*.

 When you click this command, the **Enter Reason** dialog box opens if *Is Optional* or *Is Required* is selected in the **Reason for Approval** box on the **Rule Actions** tab of the [Approval Maps](../Shared/../UserGuide/EP_20_50_15.md) \(EP205015\) form for the map. In the dialog box, you can \(if *Is Optional* is selected\) or must \(if *Is Required* is selected\) enter the reason the document is being approved.

 This command is available if the cost projection has the *Pending Approval* status.

 For more information, see [Approval Configuration: Approval Maps](../ImplementationGuide/config_Approvals_Create_Approval_Maps.md).

|
|**Copy Revision**|Opens the **Copy Revision** dialog box, where you can create a copy of the cost projection revision and specify the ID to be used for the new revision.|
|**Hold**|Changes the status of the cost projection revision to *On Hold*.

 This command appears if the cost projection revision has the *Open*, *Pending Approval*, or *Rejected* status.

|
|**Project WIP Detail**|Opens the [Project WIP Detail](PM_65_25_00.md) \(PM652500\) report for the current financial period. The report is generated at the account group level of detail with the planned costs estimated based on the last released cost projection revision.|
|**Reassign**|Opens the [Reassign Approval](#_4306f063-87e6-4b8c-bd61-8b84079a70c1) dialog box, in which you can specify a new approver for this cost projection if the reassignment of approvals is allowed in the related rule of the approval map on the [Approval Maps](EP_20_50_15.md) \(EP205015\) form.

 This command appears if the *Approval Workflow* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) form, an approval map for cost projection revision has been configured on the [Approval Maps](EP_20_50_15.md) form, this map is selected in the **Cost Projection Approval Map** box on the **Approval** tab of the [Projects Preferences](PM_10_10_00.md) form, and the cost projection revision has the *Pending Approval* status.

|
|**Refresh and Recalculate**|Updates the budgeted values in the cost budget lines with the most recent values from the project. The system also recalculates each cost projection line’s projected values based on the budgeted values according to the mode specified in the line:

 -   If the line has the *Auto* mode, the system recalculates all projected values.
-   If the line has the *Manual Cost* mode, the system recalculates the **Projected Quantity to Complete**, **Projected Quantity at Completion**, and **Projected Variance Quantity** values.
-   If the line has the *Manual Quantity* mode, the system recalculates the **Projected Cost to Complete**, **Projected Cost at Completion**, and **Projected Variance Cost** values.

 This command appears if the cost projection revision has the *On Hold* status.

|
|**Reject**|Rejects the cost projection and changes its status from *Pending Approval* to *Rejected*.

 When you click this command, the **Enter Reason** dialog box opens if on the **Rule Actions** tab of the [Approval Maps](../Shared/../UserGuide/EP_20_50_15.md) \(EP205015\) form for the applicable map, *Is Optional* or *Is Required* is selected as the reason for rejection. In the dialog box, you can \(if *Is Optional* is selected\) or must \(if *Is Required* is selected\) enter the reason the document is being rejected.

 This command is available if the cost projection has the *Pending Approval* status.

 For more information, see [Approval Configuration: Approval Maps](../ImplementationGuide/config_Approvals_Create_Approval_Maps.md).

|
|**Release**|Releases the cost projection revision and updates the **Projected Quantity to Complete**, **Projected Quantity at Completion**, **Projected Cost to Complete**, **Projected Cost at Completion**, and **Completed \(%\)** values in the cost budget lines of the specified project. The cost projection revision is assigned the *Released* status.

 This command appears if the cost projection revision has the *Open* status.

|
|**Remove Hold**|Changes the status of the cost projection revision to *Open*, which indicates that the cost projection is ready for processing, or to *Pending Approval* if cost projection approval is configured on the [Projects Preferences](PM_10_10_00.md) form.

 This command appears if the cost projection revision has the *On Hold* status.

|

|Element|Description|
|-------|-----------|
|**New Revision**|The identifier of the new revision of the cost projection.

 The length of the identifier, which can consist of only alphanumeric characters and spaces, can be 10 or fewer characters.

|
|**Refresh Budget**|A check box that indicates \(if selected\) that when it creates a new cost projection revision, the system should add the cost budget lines with the latest budgeted values. If the check box is cleared, the system will create a new cost projection revision with the budgeted values from the revision that is being copied.|

|**Copy Files**|A check box that indicates \(if selected\) that the system should copy any files attached to the current cost projection revision and attach them to the newly created cost projection revision.|
|This dialog box has the following buttons.|

|**Cancel**|Cancels the creation of a copy of the selected cost projection revision, and closes the dialog box.|

## Reassign Approval Dialog Box {#_4306f063-87e6-4b8c-bd61-8b84079a70c1 .section}

In this dialog box, you can specify the new approver to whom you want to reassign the selected record or records. The dialog box opens when you click **Reassign**.

|Element|Description|
|-------|-----------|
|**New Approver**|The name of the employee to whom you want to reassign the selected record or records.|
|**Ignore Approver's Delegations**|A check box that indicates \(if selected\) that the system will assign the selected records to the specified new approver but not to their delegate, even if the new approver is unavailable and has a delegate specified for the current business date.

 If the check box is cleared and if the new approver is not available and has a delegate specified for the current date, the system will reassign the selected records to the delegate if they’re available. If the delegate is unavailable, the system will reassign the requests to the delegate of the delegate. The system will continue the search in this way until:

 -   It assigns an approver with no active delegations set up for the current date.
-   It detects a loop in the chain of delegations. In this case, the system will prompt you to specify a different approver.

|
|This dialog box has the following buttons.|
|**Reassign**|Closes the dialog box and reassigns the selected record or records to the specified new approver if the reassignment of approvals is allowed in the related rule of the approval map on the [Approval Maps](../Shared/../UserGuide/EP_20_50_15.md) \(EP205015\) form.|
|**Cancel**|Closes the dialog box and cancels the reassignment of the selected record or records to the new approver.|

## Summary Area {#1 .section}

In this area, you can specify or view the basic settings of a revision of a cost projection for a particular project and view its details.

|Element|Description|
|-------|-----------|
|**Project**|The project for which the revision is projecting costs.|
|**Revision**|The revision identifier of the cost projection. If you are creating a new revision, enter an identifier, which must be unique within the project. The length of the identifier, which can consist of only alphanumeric characters and spaces, can be up to 10 characters.

 To view an existing revision, select the revision identifier after you select the project.

|
|**Status**|The status of the cost projection revision, which can be one of the following: -   *On Hold*: The user can edit the cost projection revision but cannot release it.
-   *Pending Approval*: The cost projection revision has been taken off hold \(that is, **Remove Hold** was clicked\) and is awaiting approval.

This status is available if the approval map has been specified in the **Cost Projection Approval Map** box on the **Approval** tab of the [Projects Preferences](PM_10_10_00.md) \(PO101000\) form.

-   *Rejected*: The employee who was assigned to approve the cost projection revision has rejected it.

This status is available if an approval map has been specified in the **Cost Projection Approval Map** box on the **Approval** tab of the [Projects Preferences](PM_10_10_00.md) form.

-   *Open*: The employee who was assigned to approve the cost projection revision has approved it. If no approval is configured for cost projections, the system assigns this status to the cost projection revision when **Remove Hold** is clicked on the form toolbar.
-   *Released*: The cost projection revision has been released and cannot be edited.

|
|**Description**|The description of the cost projection.|
|**Cost Projection Class**|The cost projection class of the cost projection revision. The class is defined on the [Cost Projection Classes](PM_20_35_00.md) \(PM203500\) form and defines the detail level of the cost projection.

 The cost projection revision can include the same level of detail as the cost budget of the project for which the revision is created, or it can have less detail. Only a cost projection of a cost projection class with the same level of budget detail can be released. For more information, see [Project Cost Projections: General Information](Construction_Cost_Projection_GeneralInfo.md).

|
|**Revision Date**|The date when the cost projection revision was created. By default, the system inserts the current business date.|
|**Totals by Revision** section|
|**Budgeted Cost to Complete**|The remainder of the budgeted cost for all cost budget lines added on the **Details** tab. This cost is calculated as the sum of the **Cost to Complete** amounts for all revision lines.|
|**Projected Cost to Complete**|The projected remainder of the budgeted cost for all cost budget lines added on the **Details** tab. This cost is calculated as the sum of the **Projected Cost to Complete** amounts for all revision lines.|
|**Budgeted Cost at Completion**|The budgeted final cost at the moment of project completion for all cost budget lines added on the **Details** tab. This cost is calculated as the sum of the **Budgeted Cost** amounts for all revision lines.|
|**Projected Cost at Completion**|The projected final cost at the moment of project completion for all cost budget lines added on the **Details** tab. This cost is calculated as the sum of the **Projected Cost at Completion** amounts for all revision lines.|
|**Cost Variance**|The cost variance between the projected and budgeted costs for the current revision. This cost is calculated as the difference between the **Projected Cost at Completion** and the **Budgeted Cost at Completion**.|
|**Totals by Project** section|
|**Budgeted Revenue**|The budgeted revenue of the project, which is calculated as the sum of the **Revised Budgeted Amount** of all project revenue budget lines of the project for which the cost projection revision is created.|
|**Actual + Committed Costs**|The total of the actual and committed costs for all cost budget lines of the project for which the cost projection revision is prepared. The system calculates this amount by using the following formula.``` {#codeblock_w1x_zbb_4fc}
Actual Amount + Revised Committed Amount – Invoiced Committed Amount)
```

|
|**Cost to Complete**|The remainder of the budgeted cost that is currently available for the completion of all cost budget lines of the project. The system calculates this amount by using the following formula. ``` {#codeblock_qgx_1cb_4fc}
Revised Budgeted Cost – (Actual Cost + Revised Committed Cost – Invoiced Committed Cost)
```

|
|**Cost at Completion**|The projected final cost at the moment of project completion for all cost budget lines. This cost is calculated as the sum of the revised budgeted costs for all cost budget lines of the project.|
|**Gross Profit**|The calculated gross profit of the project, which is calculated as the difference between the **Budgeted Revenue** and the **Cost at Completion**.|
|**Cost Variance**|The cost variance by all cost budget lines of the project. The system calculates this amount by using the following formula. ``` {#codeblock_pnm_bcb_4fc}
Projected Cost at Completion – Revised Budgeted Cost + Cost Variance (Totals by Revision)
```

|
|**Projected Gross Profit**|The projected gross profit of the project. The system calculates this amount by using the following formula.``` {#codeblock_e43_ccb_4fc}
Gross Profit – Cost Variance (Totals by Project)
```

|

|**Actual + Committed Open Quantity**|The sum of the actual quantity and committed open quantity of the cost budget line specified in the project.|
|**Actual + Committed Open Cost**|The sum of the actual cost and committed open cost of the cost budget line specified in the project, including the inclusive taxes.|
|**Quantity to Complete**|The remainder of the budgeted quantity of the cost budget line that is currently available for completion. The system calculates this quantity by using the following formula. ``` {#codeblock_cmm_ddb_4fc}
Budgeted Quantity – (Actual Quantity + Revised Committed Quantity – Invoiced Committed Quantity)
```

|
|**Cost to Complete**|The remainder of the budgeted cost of the cost budget line that is currently available for completion. The system calculates this amount by using the following formula. ``` {#codeblock_udz_ddb_4fc}
Budgeted Cost – (Actual Cost + Revised Committed Cost – Invoiced Committed Cost)
```

|
|**Projected Quantity to Complete**|The projected remainder of the budgeted quantity for the cost budget line. The system calculates this amount by using the following formula. ``` {#codeblock_ssx_2db_4fc}
Budgeted Quantity - (Actual + Unbilled Committed Quantity)
```

If the calculated value is negative, this quantity is set to *0*.

The system recalculates this quantity if you change any other projected value in the line and the recalculation mode in the **Mode** column in the line is set to *Auto* or *Manual Cost*. If you override this value, the corresponding values in the cost budget line will be recalculated based on the recalculation mode of the line.

|
|**Projected Cost to Complete**|The projected remainder of the budgeted cost for the cost budget line. The system calculates this amount by using the following formula. ``` {#codeblock_qyd_rfb_4fc}
Budgeted Cost - (Actual + Unbilled Committed Cost)
```

If the calculated value is negative, this amount is set to *0*.

The system recalculates this cost if you change any other projected value in the line and the recalculation mode in the line is set to *Auto* or *Manual Quantity*. If you override this value, the corresponding values in the cost budget line will be recalculated based on the recalculation mode of the line.

|
|**Projected Quantity at Completion**|The projected final quantity at the moment of project completion for the cost budget line. The system calculates this quantity by using the following formula. ``` {#codeblock_rdh_5fb_4fc}
Projected Quantity to Complete + Actual Quantity + Revised Committed Quantity – Invoiced Committed Quantity
```

If you override this value, the corresponding values in the cost budget line will be recalculated based on the recalculation mode of the line.

|
|**Projected Cost at Completion**|The projected final cost at the moment of project completion for the cost budget line. The system calculates this amount by using the following formula. ``` {#codeblock_cbl_vfb_4fc}
Projected Cost to Complete + Actual Cost + Revised Committed Cost – Invoiced Committed Cost
```

If you override this value, the corresponding values in the cost budget line will be recalculated based on the recalculation mode of the line.

|
|**Projected Variance Quantity**|The difference between the **Projected Quantity at Completion** and the **Budgeted Quantity**. If you override this value, the corresponding values in the cost budget line will be recalculated based on the recalculation mode of the line.

|
|**Projected Variance Cost**|The difference between the **Projected Cost at Completion** and the **Budgeted Cost**. If you override this value, the corresponding values in the cost budget line will be recalculated based on the recalculation mode of the line.

|
|**Projected Completed \(%\)**|The projected percentage of completion for the cost budget line. The system calculates this percentage by using the following formula. ``` {#codeblock_dgd_xfb_4fc}
(Actual + Committed Open Cost) / Projected Cost at Completion * 100%
```

If you override this value, the corresponding values in the cost budget line will be recalculated based on the recalculation mode of the line.

|
|**Mode**|The mode that specifies how the amounts and quantities are recalculated for the cost budget line. The following options are available:-   *Auto*: If any projected value in the cost budget line is changed, the system automatically recalculates the other projected quantities and costs.
-   *Manual*: If any projected value in the cost budget line is changed, the system does not recalculate the other projected quantities and costs.
-   *Manual Quantity*: If any projected value in the cost budget line is changed, the system automatically recalculates the projected costs; the **Projected Quantity to Complete**, **Projected Quantity at Completion**, and **Projected Variance Quantity** values are preserved.
-   *Manual Cost*: If any projected value in the cost budget line is changed, the system automatically recalculates the projected quantities if any other projected value in the cost budget line is changed; the **Projected Cost to Complete**, **Projected Cost at Completion**, and **Projected Variance Cost** values are preserved.

## Approvals Tab {#section_qqp_rgh_smb .section}

This tab displays the approval details for the cost projection revision. If approval is configured, the cost projection revision is automatically assigned for approval when it is taken off hold. Authorized users approve or reject cost projection revisions by using the [Approvals](EP_50_30_10.md) \(EP503010\) form.

This tab displays the approval entries associated with the selected record. If the record has existing *Approved* or *Rejected* entries and is put on hold for editing, these entries are preserved on the tab and the **Obsolete** check box is selected for them. Approval entries with a *Pending* decision are deleted. When the record is resubmitted for approval, new approval entries are created for this approval cycle.

This tab is available only if the *Approval Workflow* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and an approval map is specified in the **Cost Projection Approval Map** box on the **Approval** tab of the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form. If no map is specified in this box, cost projections do not require approval.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Assignee**|The identifier of the employee who is assigned to approve the record.|
|**Assignee Name**|The name of the employee who is assigned to approve the record.|
|**Workgroup**|The workgroup of the employee who is assigned to approve the record.|
|**Reviewer**|The identifier of the employee who actually reviewed the record.|
|**Reviewer Name**|The name of the employee who actually reviewed of the record.|
|**Date**|The review date.|
|**Decision**|The approval decision made for the record, which can be *Pending*, *Approved*, or *Rejected*, depending on the approval action performed.|
|**Reason**|The reason the record has been approved or rejected \(if applicable\).|
|**Obsolete**|A check box that indicates \(if selected\) that the approval decision belongs to a previous approval cycle. The system selects the check box for all *Approved* and *Rejected* approval entries when the record is put on hold for editing.|
