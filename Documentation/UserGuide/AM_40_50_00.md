# Work Center Capacity

Form ID: \(AM405000\)

This form shows the capacity available and current load.

If the *Advanced Planning and Scheduling \(Optimized\)* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, you can use this form to compare the capacity planned for infinitely scheduled operations with the capacity reserved for finitely scheduled operations.

## Form Toolbar

The form toolbar has only standard buttons.

The period of detail to display; the options are the following:-   *Daily:* Shows the capacity for each working calendar day.

-   *Monthly:* Shows the capacity for each calendar month.

The starting date for displaying capacity in the following table. The default value of this box is the current business date.

</td></tr><tr><td>

**To Date**

The ending date for displaying capacity in the following table. The default value of this block is the current business date plus 30 days.
