# Archive Documents

Form ID: \(SM500400\)

On this form, you can review the list of dates and the number of documents that are ready to be archived. You can run the archival process for all documents listed in the table or select documents in the list to be archived. You can also change the default duration of the archival process, if needed.

## Form Toolbar

The form toolbar includes standard and form-specific buttons. The form-specific buttons are listed in the following table.

|Button|Description|
|------|-----------|
|**Process**|Initiates the archival process of the documents that you have selected in the table.|
|**Process All**|Initiates the archival process of all listed documents.|

## Selection Area

In this area, you can change the default duration of the archival process that has been initially specified on the [Archival Policy](SM_20_04_00.md) \(SM200400\) form.

|Element|Description|
|-------|-----------|
|**Archiving Process Duration \(Hours\)**|The maximum duration time \(in hours\) of the archival process. By default, the system inserts the default value that has been specified on the [Archival Policy](SM_20_04_00.md) \(SM200400\) form. You can override the default value on the current form.|
