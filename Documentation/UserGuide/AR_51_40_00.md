# Update Processing Status

Form ID: \(AR514000\)

You use this form to update the **Processing Status** for existing credit card and ACH payment records created after an upgrade to Acumatica ERP 2026 R2 or later. Until they’re updated, these payments do not have a stored processing status and show a status of *Not Calculated* on data entry forms.

This form groups payments by payment date so that you can process them in manageable batches, starting with the most recent payments.

The form is available only if the *Third-Party Integrations* and *Integrated Card Processing* features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the generation of the processing status for the payment groups for which you have selected the Included check box in the table.|
|**Process All**|Initiates the generation of the processing status of all the payment groups listed in the table.|

## Table

This table displays the payment groups that meet the selection criteria you have specified. You can process all the groups listed in the table or only those for which you select the Included check box.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include this payment group in processing if you click **Process**.|
|**Payment Date**|The date on which the payments in this group were made.|
|**Payment Count**|The number of payments made on this date.|
