# Payroll Summary {#_2edc7dc3-f9b4-4ce4-a74a-ff33c5936777 .reference}

Form ID: \(PR645012\)

This report provides an easy way to review the results of one or multiple pay runs before or after release. The results include payroll funding, check counts, advice counts, wages, employer taxes, employee taxes, hours, earnings, deductions, and benefits.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

**Attention:** This report appears only if the *Canadian Payroll* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Tax Registration ID**: The EIN for which you want to view information.

    You enter EINs that are specified for companies and branches in the **Tax Registration ID** box on the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form and on the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form, respectively.

-   **Company/Branch**: The company or branch for which you want to view information. By default, the current company or branch is selected.
-   **CRA Payroll Account Number**: The CRA payroll account for which or which you want to view information.

    You enter CRA payroll accounts that are specified for companies and branches on the **Canadian Tax Reporting** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) and [Branches](../Shared/../UserGuide/CS_10_20_00.md) form.

-   **Select By**: The date to which the specified date range should be applied, with the following options available: *Transaction Date* and *Period Start/End Date*.
-   **Date From**: The start date of the date range.
-   **Date To**: The end date of the date range.
-   **Include Data From Unreleased Paychecks**: A check box that you select if the data from unreleased paychecks should be included in the report.
-   **Payment Method**: The payment method for which you want to view information. Select a payment method, or make no selection to request information for all payment methods used in paychecks.
-   **Cash Account**: The cash account for which you want to view information. Select a cash account, or make no selection to request information for all cash accounts used in paychecks.
-   **Employee**: The employee for which you want to view information. Select an employee, or make no selection to request information for all employees.
-   **Pay Group**: The pay group for which you want to view information. Select a pay group, or make no selection to request information for all pay groups used in paychecks.
