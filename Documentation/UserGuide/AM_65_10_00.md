# Work Center Dispatch {#_747aef18-1041-49ba-aa9c-27b93d578e4e .reference}

Form ID: \(AM651000\)

This report is used to show what production orders need to be worked on at each work center. It shows how much of each product is required, the start/end dates. This report can be printed each day or week for each work center so they know what order needs to be processed next.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Work Center ID**: A particular work center. Select a work center ID to view the production orders for only this work center, or leave it blank to view to view all work centers.
