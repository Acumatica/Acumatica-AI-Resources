# To Configure New Zealand Depreciation Methods {#_fee9600c-7325-44dd-8431-6282b48f7a0d .task}

On the [Depreciation Methods](FA_20_25_00.md) \(FA202500\) form, you can configure formula-based depreciation methods by using any of the available depreciation calculation methods, which are described in detail in [Predefined Depreciation Methods](FA__con_Depreciation_Methods.md).

This procedure describes how to configure depreciation methods that are commonly used in New Zealand.

**Attention:** The formulas used by the system to calculate the depreciation expenses by using these depreciation method are described in [New Zealand Depreciation Methods](FA__con_NewZealand_Depreciation_Methods.md).

## To Configure the New Zealand Straight-Line Depreciation Method {#section_nbc_ljv_vxb .section}

1.  Open the [Depreciation Methods](FA_20_25_00.md) \(FA202500\) form.
2.  On the form toolbar, click **Add New Record**.
3.  In the **Depreciation Method ID** box, type the name of the new method.
4.  In the **Calculation Method** box, select *New Zealand Straight-Line*.
5.  In the **Description** box, enter a description of the depreciation method that will help users to easily find this method in the list of available depreciation methods.
6.  In the **Percent per Year** box, specify the part of the asset's depreciation base \(as a percent\) that should be depreciated each year.
7.  On the form toolbar, click **Save**.
