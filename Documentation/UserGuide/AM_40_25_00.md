# Where Used in Production

Form ID: \(AM402500\)

On this form, you can view the parent items and subassemblies of a specific lot- or serial-tracked item—that is, a material that has been used in the production of items or materials. You can view either the immediate parent assembly or all levels of subassemblies of the item.

In addition, you can find the reference number of the production order where the material is used and the sales order linked to the production order \(if this order has been created\), as well as links you can click to view these orders. By using this information, you can find the customer that ordered the produced item with the specified material.

## Selection Area

In this area, you specify the inventory ID of the item and the lot or serial number for which you want to view the details of parent items and subassemblies, as well as any criteria for which you want to view details.
