# Notify About Expiring Cards {#_c7a2193a-9a8f-46af-9cee-67eb1df55917 .reference}

Form ID: \(AR512000\)

You can use this form to view information about customers with credit cards that will soon expire and to select customers to notify them by email about the approaching expiration date. When you send emails to customers about expiring credit cards, the system uses the settings specified for the *CCEXPIRENOTE* mailing on the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR101000\) form, under the **Mailing &amp; Printing** tab. For details on processing credit cards, see [Automatic Payment Collection](AR__con_Automatic_Payment_Collection.md).

**Attention:** This form appears in the system if the *Integrated Card Processing* feature has been enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Notify**|Generates emails for selected customers \(that is, those for which you select the Included check box in the table\) about credit cards that will expire in the specified time interval. Emails will be generated only for customers with the Included check box selected in the table.|
|**Notify All**|Generates emails to all listed customers about credit cards that will expire in the specified time interval.|

## Selection Area {#1 .section}

You can use this area to define the criteria the system should use to list the customers that may be notified about the approaching card expiration dates.

|Element|Description|
|-------|-----------|
|**Starting**|The date that starts the date range for which you want to display data for card expiration dates.|
|**Expire in \(Days\)**|The duration of the date range, which begins on the **Starting** date.|
|**Customer Class**|The class of customers with similar settings. Leave the box blank to view information on all customer classes.

 The list of classes may be limited based on the roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. With the feature enabled, the **Restrict Visibility To** box appears on the **General** tab of the [Customer Classes](../Shared/../UserGuide/AR_20_10_00.md) \(AR201000\) form. You can select a customer class if one of the following is true:

-   The **Restrict Visibility To** box is empty for the customer class—that is, the visibility of the customer class is not restricted.
-   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer class, and your user account is assigned to the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.

|
|**Active Only**|A check box that you select to display information about only active credit cards.|
|**Default Payment Method Only**|A check box that you select to display information on only expiring cards associated with the customer's default payment method.|

## Table {#2 .section}

This table displays information about all cards that match the criteria you specified in the Selection area. By using form toolbar buttons, you can generate emails for all listed customers or for only the selected ones. To generate emails, the system uses the settings for the *CCEXPIRENOTE* mailing specified for each particular customer. You can select a customer with an expiring card and view customer details, or you can view information about the payment method the card is associated with.

The system loads the documents of customers visible in the current branch \(those for which the **Restrict Visibility To** box on the **Financial** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form contains the current branch, company, company group, or is empty\).

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include the card for notification if you click **Notify**.|
|**Customer**|The ID of the customer owning the card. If you click the name, the [Customers](AR_30_30_00.md) \(AR303000\) form opens, on which you can view the details of the customer.|
|**Customer Name**|The name of the customer.|
|**Customer Class**|The customer class the customer is assigned to.

 The list of classes may be limited based on the roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. With the feature enabled, the **Restrict Visibility To** box appears on the **General** tab of the [Customer Classes](../Shared/../UserGuide/AR_20_10_00.md) \(AR201000\) form. You can select a customer class if one of the following is true:

-   The **Restrict Visibility To** box is empty for the customer class—that is, the visibility of the customer class is not restricted.
-   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer class, and your user account is assigned to the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.

|
|**Payment Method**|The payment method the card is associated with. If you click the method name, the [Customer Payment Methods](AR_30_30_10.md) \(AR303010\) form opens, on which you can see the details of the payment method.|
|**Card/Account Nbr.**|The card display name.|
|**Active**|A check box that indicates \(if selected\) that the card is active.|
|**Expiration Date**|The date when the card expires.|
|**Email**|The email address of the customer.|
|**Phone 1**|The phone number of the customer.|
|**Fax**|The fax number of the customer.|
|**Web**|The URL of the customer website.|
