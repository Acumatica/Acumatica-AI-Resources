# Manage Project Files by Tag

Form ID: \(PM509000\)

**Attention:** This form appears only if the *Document Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can manage the files attached to a project and its related records. These files are organized by tag. The system shows the files you have permissions to work with, based on your access rights to their assigned tags. You can view not only files attached to a record—such as a bill, purchase order, or subcontract—but also files attached to the record's detail lines.

For details, see [Managing Project Files: General Information](Projects_File_Management_GeneralInfo.md).

**Attention:** The visible and available tags, buttons, and menu commands depend on your user role's access level.

## Left Pane: Tags

In this pane, you can select a node to view a list of files in the central pane:

-   Click **All Files** to view files with all tags, as well as untagged files.
-   Click **All Tags** to display files with all tags; untagged files are not shown.
-   Click any tag under **All Tags** to see files with that tag. These tags may be organized hierarchically.
-   Click **Untagged** to view files with no tags.

For details, see [Managing Project Files: Tag and File Access Setup](Projects_File_Management_Configuration.md).
