# Project Template Tasks

Form ID: \(PM208010\)

You can use this form to create tasks for project templates. If the **Automatically Include in Project** check box is selected on the current form for a template task, it is included in any created project that uses the specified project template.

## Form Toolbar

The form toolbar has only standard buttons.

## Summary Area

You use the elements in this area to add a new template task, or to view the settings of an existing template task.

## Recurring Billing Tab

By using the **Recurring Billing** tab, you can implement a regular flat-rate billing model for the project template task—for example, to provide a particular number of hours of service to a customer for a flat monthly rate. Each recurring billing line defines the rules the system uses to create the corresponding invoice line during the project billing. For more information, see [Project Billing Preparation: Recurring Billing](Projects_Project_Billing_Preparation_Recurring_Billing.md).

The table toolbar has only standard buttons.

<table><thead><tr><th>

Column

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Inventory ID**

</td><td>

The non-stock item that designates the service or labor that is associated with the recurring billing.

</td></tr><tr><td>

**Description**

</td><td>

The description of the service or labor that is associated with the recurring billing.

</td></tr><tr><td>

**Amount**

</td><td>

The flat price for the service or labor.

</td></tr><tr><td>

**Account Source**

</td><td>

The source of the account for the recurring billing, which can be one of the following:-   *AR Default*: To use the sales account that the system inserts as the default in a line of an accounts receivable invoice
-   *Recurring Item*: The account specified for the row in the **Account** column
-   *Project*: The sales account associated with the project
-   *Task*: The default sales account specified for the task in the **GL Accounts** section on the **Summary** tab of this form
-   *Inventory Item*: The sales account associated with the non-stock item specified for the row
-   *Customer* \(default\): The sales account associated with the customer

</td></tr><tr><td>

**Subaccount Mask**

</td><td>

The rule for selecting segment values for the subaccount to be used for the recurring billing. To set up the rule for selecting segment values, select a segment, press F3, and select a source of the segment value, which is one of the following options:

 -   *B*: The subaccount specified for the row in the **Subaccount** column
-   *J*: The subaccount associated with the project
-   *T*: The subaccount associated with the project template task

</td></tr><tr><td>

The branch to be used in the recurring billing.

 By default, the branch is empty.

 This column is displayed only when the *Multibranch Support* feature or the *Multicompany Support* feature is enabled \(or both features are enabled\) on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

</td></tr><tr><td>

**Account**

</td><td>

The account to be used in the recurring billing if *Recurring Item* is selected as the **Account Source** for the row.

</td></tr><tr><td>

**Subaccount**

The subaccount to be used in the recurring billing if the **Subaccount Mask** specified for the row uses *B*.

</td></tr><tr><td>

-   *On Billing*: The recurring billing is used each time the project billing is performed.

## Attributes Tab

By using the **Attributes** tab, you can specify attributes for this template task. The attributes on this tab are those with the *Task* type on the [Project Attributes](PM_20_20_00.md) \(PM202000\) form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Attribute ID**|The attribute used for the template task.|
|**Required**|A check box that you select to indicate that this is a mandatory attribute for the tasks created based on this template task.|
|**Value**|The default value to be assigned as the default value for the attribute in the project tasks that are created based on this project template task.|
