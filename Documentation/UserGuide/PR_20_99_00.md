# Certified Projects {#_801f9df3-c1d8-489f-81da-f8edc89be008 .reference}

Form ID: \(PR209900\)

Certified projects require additional configuration to be compliant with the law. By using this form, you can do the following:

-   Link earning rates with labor items. When creating a paycheck and an employee has the combination of the project and labor item, the system will compare this rate to the other rates available in the system and take the highest one.
-   Create specific deductions and benefits. When an employee has an earning line linked to this project, the deductions and benefits will appear in the paycheck using the certified project as a source. The code and its rate \(percent of gross\) will be applied only on the earning lines linked with the project.
-   Input the fringe benefit rate and the benefits that reduce this rate. The system will calculate the amount to be paid using the number of hours worked on the project and the rate specified in this screen. The rate will be reduced using the benefit code specified on the right side of the tab. The system will handle the calculation and pro-ration of the benefit rate. An earning line will be added automatically to the paycheck during calculation so the user won’t have to do the math and the employee will be paid the fringe benefit.

This form is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area { .section}

In this area, you can configure and then review details of a particular project.

|Element|Description|
|-------|-----------|
|**Project ID**|The unique identifier of the certified project. Only projects marked as certified on the [Projects](PM_30_10_00.md) \(PM301000\) form are available for selection.|
|**Description**|A read-only box with the description of the project as defined on the [Projects](PM_30_10_00.md) \(PM301000\) form.|
|**Status**|A read-only box with the current status of the project.|
|**File Empty Report**|A check box that indicates \(if selected\) that Aatrix can generate an empty *DOL WH-347 Report*. This setting may be useful if no employees were working on the certified project on a certain week but the company still needs to file a report on that project.|

## Earning Rates Tab { .section}

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Labor Item**|A labor item associated with the project pay rate.|
|**Description**|A description of the project pay rate, which is by default is the description of the labor item.|
|**Project Task**|A project task associated with the rate.|
|**Wage Rate**|A pay rate for the combination of the labor item and project task.|
|**Effective Date**|A date when the pay rate becomes effective.|

## Deductions and Benefits Tab { .section}

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Deduction and Benefit Code**|A deduction or benefit code associated with the project. You use the [Deduction and Benefit Codes](PR_10_10_60.md) \(PR101060\) form to create new codes or review existing codes.|
|**Labor Item**|A labor item associated with the project pay rate.|
|**Description**|A description of the code as defined on the [Deduction and Benefit Codes](PR_10_10_60.md) \(PR101060\) form.|
|**Contribution Type**|A contribution type of the code as defined on the [Deduction and Benefit Codes](PR_10_10_60.md) \(PR101060\) form.|
|**Deduction Calculation Method**|The calculation method used for determining the deduction amount, which can be one of the following: *Fixed Amount*, *Percent of Gross*, *Percent of Custom*, *Percent of Net*, or *Amount per Hour*.|
|**Deduction Amount**|The deduction amount that is used if the deduction calculation method is set to either *Fixed Amount* or *Amount per Hour*.|
|**Deduction Percent**|The deduction percentage that is used if the deduction calculation method is set to either *Percent of Gross*, *Percent of Net*, or *Percent of Custom*.|
|**Contribution Calculation Method**|The calculation method used for determining the contribution amount, which can be one of the following: *Fixed Amount*, *Percent of Gross*, *Percent of Custom*, *Percent of Net*, or *Amount per Hour*.|
|**Contribution Amount**|The contribution amount that is used if the contribution calculation method is set to either *Fixed Amount* or *Amount per Hour*.|
|**Contribution Percent**|The contribution percentage that is used if the contribution calculation method is set to either *Percent of Gross*, *Percent of Net*, or *Percent of Custom*.|
|**Effective Date**|A date when the deduction or benefit rate becomes effective.|

## Fringe Benefits Tab { .section}

You use this tab to set up fringe benefits that your organization is required to pay the employees who work on certified projects.

|Element|Description|
|-------|-----------|
|**Excess Pay Rate Annualization Exception**|A check box that indicates \(if selected\) that the excess pay rate is calculated as an hourly rate. If you clear the check box, the excess pay rate will be annualized.|
|**Use Overtime Multiplier for Fringe Rate**|A check box that indicates \(if selected\) that if an employee has worked overtime on a certified project, the fringe benefit paid to the employee includes the multiplier for the overtime hours spent on the project.|
|**Benefit Code to Use for Fringe Rate**|The deduction and benefit code to which the fringe benefits are added. You can see this information on the **Deductions** tab of the [Paychecks and Adjustments](PR_30_20_00.md) \(PR302000\) form after the paycheck has been calculated.

 If this box is empty, the calculated fringe benefits are included in the earning details of the paycheck—a separate earning line is created for each combination of labor item, project, and project task on the **Earnings** tab of the [Paychecks and Adjustments](PR_30_20_00.md) \(PR302000\) form.

 **Note:** In this box, you can select only a deduction and benefit code with the *Certified Project* option selected in the **Associated With** box on the [Deduction and Benefit Codes](PR_10_10_60.md) \(PR101060\) form.

|**Description**|A description of the code as defined on the [Deduction and Benefit Codes](PR_10_10_60.md) \(PR101060\) form.|
|**Certified Reporting Type**|A reporting type used for certified reporting.|
|**Annualization Exception**|A check box that indicates \(if selected\) that the system uses hours worked on the project to calculate the employer contribution rate instead of using the total hours worked during the pay period.|
