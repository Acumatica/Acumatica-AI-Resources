# Dead Stock {#_953e62d9-48ef-45d0-a9ce-559aa8d29ffb .reference}

Form ID: \(IN405500\)

On this form, you can search for inventory items in stock that have not been moved—that is, the items that have not been added to sales orders, transfers, IN issues, kit assemblies, and other documents that affect the quantity on hand—during the period of time specified in the Selection area of the form.

**Attention:** Before you review the results on the current form, we recommend that you to recalculate inventory on the [Recalculate Inventory](IN_50_50_00.md) \(IN50500\) form with the **Rebuild Item History Since** check box selected on the form toolbar. The history should be rebuilt for all the financial periods that include the time period in which you need to review the dead stock. The recalculation should be performed for a warehouse or stock items for which you want to review the dead stock. This process will ensure greater accuracy in the results.

To calculate the quantity of the dead stock items, the system deducts the quantity of items in sales orders \(including field service orders and production orders\), shipments, and other documents that affect the quantity on hand from the quantity of items that have remained in stock for the specified time period.

The following rules apply to the stock items that can be listed on this inquiry form:

-   If the **Cost Separately** check box is selected on the **Locations** tab of the [Warehouses](IN_20_40_00.md) \(IN204000\) form for a warehouse, the system calculates the cost of an item for the warehouse, not for the location.
-   If a stock item has subitems, the system shows information without subitem details.

This form is available only if the *Inventory* feature within the *Inventory and Order Management* group of features is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The table toolbar has only standard buttons.

## Selection Area {#1 .section}

By using this area, you can specify criteria for the inventory items to be shown in the table.

|Element|Description|
|-------|-----------|
|**Warehouse**|The warehouse in which the items are situated, by ID.This box is empty by default. The box is mandatory to view the list of items.

|
|**Item Class**|The class of the items to be shown.|
|**Inventory ID**|The identifier of the item.|
|**Select By**|The mode of filtering. The following options are available:-   *By Days*: The time period by days for which the items that have been in stock.
-   *By Date*: The time period starting from the specified date.

|
|**In Stock For**|Number of days the stock items defined as a dead stock are stored in the warehouse.The box is shown only if *Days* is selected in the **Select By** box.

|
|**No Sales For**|Number of days the stock items defined as a dead stock have not been sold.The box is shown only if *Days* is selected in the **Select By** box.

|
|**In Stock Since**|A date from which the system defines the stock items stored in the warehouse as a dead stock.The box is shown only if *Date* is selected in the **Select By** box.

|
|**No Sales Since**|A date from which the system defines the stock items that are not sold as a dead stock.The box is shown only if *Date* is selected in the **Select By** box.

|

|Column|Description|
|------|-----------|
|**Warehouse**|The ID of the warehouse in which the stock items are situated.|
|**Inventory ID**|The identifier of the stock item.|
|**Description**|The description of the stock item.|
|**In Stock Qty.**|The quantity of stock item on hand.

 If the *Project-Specific Inventory* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the system shows this quantity only for stock items whose quantities are not tracked for a project. That is, if a stock item is included in a project for which on the **Summary** tab of the [Projects](PM_30_10_00.md) \(PM301000\) form, *Track by Project Quantity* or *Track by Project Quantity and Cost* is selected in the **Inventory Tracking** box, the project's item quantity is excluded from this quantity.

|
|**Dead Stock Qty.**|The quantity of stock items calculated as a dead stock.

 If the *Project-Specific Inventory* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the system shows this quantity only for stock items whose quantities are not tracked for a project. That is, if a stock item is included in a project for which on the **Summary** tab of the [Projects](PM_30_10_00.md) \(PM301000\) form, *Track by Project Quantity* or *Track by Project Quantity and Cost* is selected in the **Inventory Tracking** box, the project's item quantity is excluded from this quantity.

|
|**Base Unit**|The base unit of measure \(UOM\) in which the quantity of the stock item is specified.|
|**In Dead Stock \(Days\)**|The average number of days the stock items are located in stock.|
|**Last Purchase Date**|The date of the last purchase receipt that was released for the stock item.|
|**Last Sale Date**|The date of the last sales document that was released for the stock item and for which a transaction of the *Invoice* or *Debit Memo* type was posted.|
|**Last Cost**|The cost of a stock item in the last released inventory receipt.|
|**Total Dead Stock Cost**|The total cost of the dead stock items.|
|**Dead Stock Item Average Cost**|The average cost of stock items calculated as a dead stock.|
|**Currency**|The base currency of the stock item.|
