# Subcontract \(SF\)

Form ID: \(SC641000\)

By using this report, you can look through, print, and email the subcontracts. You can select a reference number of the particular subcontract you want to view.

The subcontracts are displayed as they will be printed.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters

On the **Report Parameters** tab, use the following parameter to select the information to be displayed on the report:

-   **Subcontract Number**: The number of the subcontract to be displayed. Select a number of the subcontract for which you want to prepare the printable document.
