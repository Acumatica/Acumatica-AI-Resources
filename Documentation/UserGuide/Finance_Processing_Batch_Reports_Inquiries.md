# GL Transactions: Related Reports and Inquiries {#_56165257-3daa-4c8a-9524-9e44ad1fbb42 .concept}

This topic describes the reports, inquiries, and forms you may review to gather information about batches.

**Attention:** If you do not see a report or inquiry, this could mean that you have signed in to the system with a user account that does not have access rights to the form.

## Finding a Batch on the Journal Transactions Form {#section_hwg_mjv_vxb .section}

To find and view a batch, you can use the [Journal Transactions](../Shared/../UserGuide/GL_30_10_00.md) \(GL301000\) form. On this form, you can click the selector button in the **Batch Number** box and locate the batch by doing one of the following:

-   Clicking any column header to arrange the items in ascending or descending order based on the values in the column. You can navigate between pages to locate the specific batch.
-   Clicking the column header for any column you may want to search, and then typing a string in the search box at the bottom of the dialog box that pops up. As you type, the system filters the listed batches to display only those containing the entered text in the selected column.
-   Creating a filter to find the batch by its details. To do this, you click **Filter Settings** on the table toolbar of the lookup table, and specify a condition based on the batch details.

## Viewing an Unreleased Batch {#section_iwg_mjv_vxb .section}

On the [GL Edit Summary](../Shared/../UserGuide/GL_61_15_00.md) \(GL611500\) form, you can run a report for a particular ledger and financial period; you then review the list of unreleased batches, find the necessary batch, and review it. From the report, you can navigate to the [Journal Transactions](../Shared/../UserGuide/GL_30_10_00.md) \(GL301000\) form to view more details of the batch.

Similarly, you can find and view an unreleased transaction by using the [GL Edit Detailed](../Shared/../UserGuide/GL_61_05_00.md) \(GL610500\) and [GL Edit Account Distribution](../Shared/../UserGuide/GL_61_10_00.md) \(GL611000\) reports.

## Viewing a Released Batch {#section_jwg_mjv_vxb .section}

On the [GL Register](../Shared/../UserGuide/GL_62_05_00.md) \(GL620500\) form, you can run a report for a particular ledger and financial period, and then review the list of released batches and find the necessary batch. You can navigate to the [Journal Transactions](../Shared/../UserGuide/GL_30_10_00.md) \(GL301000\) form from the report to view more details of the batch.

Similarly, you can find and view a released transaction by using the [GL Register Detailed](../Shared/../UserGuide/GL_62_10_00.md) \(GL621000\) report.

## Printing Transactions for a Particular Account {#section_kwg_mjv_vxb .section}

You can print transactions for a particular account by using the [Transactions for Account](../Shared/../UserGuide/GL_63_35_00.md) \(GL633500\) report. To run a report, you specify the ledger, the financial period, and the account for which you want the system to generate the report.

## Printing Transactions for a Particular Period {#section_lwg_mjv_vxb .section}

You can print transactions for a particular period by using the [Transactions for Period](../Shared/../UserGuide/GL_63_30_00.md) \(GL633000\) report. To run a report, you specify the ledger and the financial period for which you want the system to generate the report.
