# Scales {#_545288d3-adda-4ee6-bd9a-4e19e68b86a1 .reference}

Form ID: \(SM206530\)

**Note:** This form is available only if the *Warehouse Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can review the list of scales that have been configured in Acumatica ERP through integration with DeviceHub.

## Form Toolbar { .section}

The table toolbar has only standard buttons.

## Table { .section}

This table displays the list of digital scale devices that have been configured in Acumatica ERP through integration with DeviceHub.

**Note:** A scale that has been configured in DeviceHub appears in this table when Acumatica ERP receives a nonzero weight from the scale for the first time. Scales that are disconnected or switched off are not shown on the form.

|Column|Description|
|------|-----------|
|**DeviceHub**|The unique identifier of the DeviceHub application in which the scale has been configured.|
|**Scale ID**|The identifier of the scale; you can use an alphanumeric string of up to 10 characters.|
|**Description**|The brief description that was provided for the scale.|
|**Last Weight**|The last weight the system received from the digital scale.|
|**UOM**|The unit of measure used for the item. The value is copied from the **Weight UOM** box on the [Companies](CS_10_15_00.md) \(CS101500\) form.|
|**Last Updated**|The date and time when the system received the most recent scale information.|
