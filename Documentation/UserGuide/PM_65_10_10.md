# Project Cash Flow

Form ID: \(PM651010\)

**Attention:** This generic inquiry form is available if the *Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This generic inquiry form provides visibility into your project's cash flow as of the date you specify. You can identify potential shortfalls or surplus funds and ensure that each project has enough cash to cover its expenses.

Initially, the form shows projects with all statuses, but you can filter the data in the table to show projects with any status.

## Form Toolbar

The form toolbar has only standard buttons.

## Selection Area

In this area, you select the date through which the system shows projects in the table.

|Element|Description|
|-------|-----------|
|**Date**|The date through which the data is displayed—that is, you’ll see project data up to and including this date. By default, the system inserts the current business date.|

## Table

In the table, you can view each project’s date-specific cash flow, revenue budget backlog, and cost budget backlog. You can also see the total amounts across all listed projects. Each row represents a project.

Below you can find information about the columns that contain the project’s calculated values, along with the formulas that the system uses for these calculations.

**Attention:**

-   The leftmost columns of the table aren't described in this topic. These columns display the project's basic information—such as project manager, description, status, company, branch, currency, and start and end dates. If you need information about these UI elements, see their descriptions on the [Projects](PM_30_10_00.md) \(PM301000\) form.
-   The values are calculated **in the project currency**. The form shows values in the base currency and the project currency if the *Multicurrency Accounting* and *Multicurrency Projects* features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

The table toolbar has only standard buttons.
