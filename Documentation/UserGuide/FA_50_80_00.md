# Delete Unreleased Transactions

Form ID: \(FA508000\)

By using this form, you can delete Fixed Assets documents that contain unreleased transactions before these transactions can be released on the [Release FA Transactions](FA_50_30_00.md) \(FA503000\) form. We generally recommend that you delete empty transaction documents that may be generated by the system.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Delete**|Deletes the transactions you have selected in the table.|
|**Delete All**|Deletes all the listed transactions.|

## Table
