# Storage Details by Item Warehouse Location {#_f106256f-7396-4248-a259-0ac3bcb5be1a .reference}

Form ID: \(IN408055\)

On this form, you can browse the information about various quantities of inventory items available in different warehouses and warehouse locations. You can select a particular warehouse and view the stock items that are available in the locations of this warehouse.

**Attention:** This form is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

In this area, you can select a warehouse to narrow the list of stock items to be displayed in the table.

|Element|Description|
|-------|-----------|
|**Warehouse**|The warehouse for which information about item quantities should be displayed. If no warehouse is selected, information for all warehouses is shown.|

## Table { .section}

This table lists the stock items for the warehouse that is selected in the Selection area, or for all warehouses if no warehouse is selected.

|Element|Description|
|-------|-----------|
|**Inventory ID**|The ID of the stock item.|
|**Warehouse ID**|The ID of the warehouse.|
|**Qty. On Hand in Warehouse**|The on-hand quantity of the item in the warehouse.|
|**Qty. Available in Warehouse**|The available quantity of the item in the warehouse.|
|**Qty. Available for Shipping in Warehouse**|The item's quantity available for shipping from the warehouse.|
|**Qty. Available for Issue in Warehouse**|The item's quantity available for issue from the warehouse.|
|**Last Modified Date of Warehouse Qty.**|The date on which the stock item's quantity was last modified in the warehouse.|
|**Location ID**|The ID of the warehouse location.|
|**Qty. On Hand in Location**|The on-hand quantity of the item in the warehouse location.|
|**Qty. Available in Location**|The available quantity of the item in the warehouse location.|
|**Qty. Available for Shipping in Location**|The item's quantity available for shipping from the warehouse location.|
|**Qty. Available for Issue in Location**|The item's quantity available for issue from the warehouse location.|
|**Last Modified Date of Location Qty.**|The date on which the stock item's quantity was last modified in the warehouse location.|
|**Inventory Description**|The description of the stock item.**Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Inventory NoteID**|The NoteID that uniquely identifies the stock item record in the database.**Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Location Description**|The description of the warehouse location.**Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Row Number**|The number of the row in the table.**Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Warehouse Description**|The description of the warehouse.**Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).
