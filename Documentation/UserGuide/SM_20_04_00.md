# Archival Policy

Form ID: \(SM200400\)

On this form, you can configure the archival of documents by the entity type. In the table, you can add a row in which you specify the type of the documents that you want to be archived and the retention period to be used for them. You can also specify the maximum duration of the archival process.

## Form Toolbar

The form toolbar has only standard buttons.

## Processing Settings Section

In this section, you can specify the duration to be used for the archival process by default.

**Archiving Process Duration \(Hours\)**

</td><td>

The maximum duration time \(in hours\) of the archival process to be performed on the [Archive Documents](SM_50_04_00.md) \(SM500400\) processing form.

 The duration that you specify in this box will be displayed as the default value in the **Archiving Process Duration \(Hours\)** box on the [Archive Documents](SM_50_04_00.md) \(SM500400\) form. This default value can be overridden before a user runs the process on the [Archive Documents](SM_50_04_00.md) \(SM500400\) form.

</td></tr></tbody>
</table>

In this table, you specify the entity type or types of the documents to be archived and the retention period for each entity type.

The table toolbar has only standard buttons.
