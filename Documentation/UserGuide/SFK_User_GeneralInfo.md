# Shop Floor Kiosk: General Information {#_af209193-3961-4844-86c0-7126c727cd0f .concept}

The Shop Floor Kiosk gives you a focused workspace for selecting production work and recording production activity directly from the production floor. You can use it to report labor, quantities, materials, and operation progress without working in standard ERP forms.

## Kiosk Users { .section}

The Shop Floor Kiosk is intended for the following user types:

-   **Shop floor employees**: Use the kiosk to record daily production activity, including clocking in and out of operations, reporting completed and scrap quantities, issuing materials, and reviewing recent activity.
-   **Supervisors**: Use the kiosk to monitor active operations, review production progress, and support employees in resolving production issues.

## User Access Requirements { .section}

To use the Shop Floor Kiosk, you must meet the following access requirements:

-   Have a user account in Acumatica ERP.
-   Have your user account linked to an employee record that identifies you as a production employee.
-   Have the predefined *SFK User* role assigned to your user account.
-   Have a shop floor shift specified in your employee record.
-   Have access to the kiosk. You do not need individual access to standard ERP forms to perform kiosk workflows.

## Kiosk Workflows { .section}

When using the kiosk, you can select your work in a way that fits your production environment. For example, you can choose from scheduled dispatch lists \(“pull”\) or select production orders directly \(“push”\). The kiosk supports both paperless and paper-based processes.

## Kiosk Capabilities { .section}

With the Shop Floor Kiosk, you can:

-   **Start work quickly** with a focused, low-training interface
-   **Select work** using flexible workflows \(“pull” or “push”\)
-   **Clock in to and out of production operations** to capture direct labor data in real time
-   **Report production results**, including completed quantities, scrap, and finish times
-   **Issue materials** through backflushing, with lot and serial numbering supported
-   **Access operation details, required materials, and related documents**, such as steps, images, and attachments, directly at the kiosk
