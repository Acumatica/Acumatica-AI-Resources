# General Ledger Reports {#_7fd4ea75-9f29-41b7-8380-4b9dd8d7b550 .concept}

With the wide variety of Acumatica ERP reports related to the general ledger, you can promptly get vital information, analyze financial data by various criteria, and review transactions efficiently. If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All general ledger reports can be generated in different formats, including PDFs, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
