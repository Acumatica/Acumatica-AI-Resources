# Mobile Workspace {#_769f34f8-f804-43ec-97a7-ae98c679d4f0 .reference}

Form ID: \(AU220013\)

You use this form to configure a workspace for the Acumatica mobile app, including specifying the screens and widgets it includes and the order in which they are shown.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

In this area, you can fill in the settings for a new workspace or select an existing workspace to view and possibly modify its settings.

|Element|Description|
|-------|-----------|
|**Workspace ID**|The identifier of the workspace.|
|**Display Name**|The name of the workspace, which is displayed on the main menu of the mobile app.|
|**Icon**|The icon that is displayed in the tile with the workspace on the main menu of the mobile app.For the list of available icons, see [Icons](../StudioDeveloperGuide/MOBILE_Ref_Icons.md).

|
|**Visible**|A check box that indicates \(if selected\) that the workspace will be visible on the main menu of the mobile app.|

## Screens Tab {#2 .section}

On this tab, you can add screens to the workspace, remove screens from the workspace, and change the order in which screens are displayed in the workspace.

|Button|Description|
|------|-----------|
|**Move Row Up**|Moves up the row, which causes the tile with the selected screen to move up in the workspace.|
|**Move Row Down**|Moves down the row, which causes the tile with the selected screen to move down in the workspace.|

|Column|Description|
|------|-----------|
|**Visible**|A check box that indicates \(if selected\) that the screen will be visible in the workspace.|
|**Item Name**|The item ID or the screen ID.|
|**Display Name**|The name of the screen as it is displayed in the workspace.|
|**Item Type**|The type of the screen, which is one of the following:

 -   *Simple Screen*: A data entry form
-   *HubFolder*: A list of screens with a filter
-   *Dashboard*: A dashboard
-   *Report*: A report

|

## Widgets Tab { .section}

On this tab, you can add widgets to the workspace, remove widgets from the workspace, and change the order in which widgets are displayed in the workspace.

**Tip:** In the mobile app, these elements are displayed as follows: first the widgets in the specified order, then the list of screens in the specified order.

|Button|Description|
|------|-----------|
|**Move Row Up**|Moves up the row, which causes the tile with the selected widget to move up in the workspace.|
|**Move Row Down**|Moves down the row, which causes the tile with the selected widget to move down in the workspace.|

|Column|Description|
|------|-----------|
|**Visible**|The check box that indicates \(if selected\) the widget will be visible in the workspace.|
|**Dashboard**|The dashboard on which the widget is based.

 **Note:** Only dashboards without parameters are supported.

|
|**Widget**|The widget that will be displayed in the workspace. In the Acumatica mobile app, scorecard, meter, and trend card widgets are supported, so only widgets of these types are available for selection.|
