# Item Settings {#_04923bc4-8c8e-4a6a-90f1-c5a54a7af5cb .reference}

Form ID: \(AM000008\)

This form lists some of the relevant data used by Acumatica ERP Manufacturing Edition from the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

You can enter any combination of the selection criteria to filter the list.

|**Element**|**Description**|
|-----------|---------------|
|**Inventory ID**|Select a specific inventory item or leave blank to list all.|
|**Warehouse**|Select a specific warehouse or leave blank to list all.|
|**Default**|This is checked if the warehouse is the default for the stock item.|
|**Replenishment Source**|Select a specific replenishment source or leave blank to list all.|
|**Item Class**|Select a specific item class or leave blank to list all.|

## Item Settings Table { .section}

All replenishment settings are maintained on the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form.

The table toolbar has only standard buttons.

|Element|Description|
|-------|-----------|
|**Inventory ID**|The stock item, which may have specific properties in different warehouses. Select the item from this list.|
|**Warehouse**|The specific warehouse where the selected stock item is stocked.|
|**Replenishment Class**|The replenishment class to be used for this item at this warehouse.|
|**Replenishment Source**|The replenishment source to be used for this stock item in this warehouse. By default, it is the replenishment source associated with the item. The following values are available:-   *Purchase*: For the stock replenishment, the item will be purchased in the quantities calculated based on the replenishment settings for this warehouse.
-   *Manufacturing*: The item for the stock replenishment will be manufactured.
-   *Transfer*: The item will be transferred from a source warehouse to replenish its stock in this warehouse. \(This value appears only if the *Multiple Warehouses* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.\)

|
|**Override Replenishment Settings**|A check box you select if you want to override the replenishment settings for this item at this warehouse defined by the selected replenishment class.|
|**Preferred Vendor**|The vendor from which the item will be purchased for stock replenishment in this warehouse. By default, the preferred vendor specified on the Stock Items form appears here.|
|The following columns are used only when the **Replenishment Source** is *Manufacturing*.|
|**Default BOM ID**|This is the bill of material used for this Item and Warehouse.|
|**Default Receipt To**|The default location to receive the stock items at this warehouse.|
|**Min. Order Qty.**|The Minimum Order Quantity is the minimum quantity used for MRP Planning and Production Orders.|
|**Max. Order Qty.**|The *Maximum Order Quantity* is the maximum quantity used for MRP Planning and Production Orders.|
|**Lot Size**|The *Lot Size* is the order multiple for MRP Planning and Production Orders.|
|**Manufacturing Lead Time**|This is the fixed Manufacturing Lead Time and is used during MRP Planning if enabled on the [Inventory Planning Preferences](AM_10_00_00.md) \(AM100000\) form and for production orders if enabled on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form or for an individual production order. For details, see [Inventory Planning Configuration: System-Wide Settings](../ImplementationGuide/config_Inventory_Planning_System_Settings.md).|
|The following columns are used for all items.|
|**Days of Supply**|The number of days that the system uses for the consolidation of demand documents containing the item during inventory planning. When the number of days is more than zero, the system groups into a single planned order all items with this ID from all demand documents \(such as sales orders\) with the requested date within the specified number of days starting from the current date.|
|**Reorder Point**|MRP can use either the Reorder Point for Safety Stock as the minimum level to maintain on hand and will generate a planned order when required.|
|**Max. Qty.**|The maximum stock level for the replenishment only when the **Replenishment Source** is *Purchase*. MRP will generate planned orders no greater than this quantity but may generate multiple planned orders to cover requirements.|
|**Safety Stock**|MRP can use either the Reorder Point for Safety Stock as the minimum level to maintain on hand and will generate a planned order when required.|
|**Replenishment Method**|The replenishment method to be used for this stock item for the selected replenishment source in this warehouse. By default, it is the replenishment method associated with the item. The method can be one of the following:-   *None*: No replenishment will be performed for the stock item.
-   *Min./Max.*: The system will compute the replenishment quantity as the difference between the maximum and minimum quantities with the quantity on supply deducted. The quantity on supply is the quantity of the item on unreleased purchase orders, purchase receipts, and quantities in transit.
-   *Fixed Reorder Qty.*: The system will initiate replenishment for the item once the minimum stock level is reached and the quantity on replenishment request is equal to the Economical Order Quantity \(EOQ\) value specified for the chosen vendor.

|
