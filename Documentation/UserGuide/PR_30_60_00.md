# PTO Adjustments {#_90d65855-af32-4a3f-b836-05dd53a5100a .reference}

Form ID: \(PR306000\)

On this form, you can create and process PTO adjustments to modify PTO balances for specific employees.

## Form Toolbar { .section}

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Release**|Releases the PTO adjustment, causing the year-to-date available hours of the selected PTO bank to be corrected by the number of adjustment hours for the selected employee. The status of the PTO adjustments changes to *Released* as a result.

 This command is available only for a PTO adjustment with the *New* status.

|
|**Void**|Generates a PTO adjustment with the *Voiding Adjustment* type, mirroring the original PTO adjustment but with reversed values in the **Adjustment Hours** column. The original PTO adjustment is assigned the *Voided* status as a result.

 This command is available only for a PTO adjustment with the *Released* status.

|

## Summary Area {#1 .section}

In this area, you can specify the settings for a new PTO adjustment or select an existing PTO adjustment for viewing and possible modification. The elements of this area are summarized below.

|Element|Description|
|-------|-----------|
|**Type**|The type of the document, which can be one of the following options:-   *Adjustment*: The PTO adjustment
-   *Voiding Adjustment*: The voiding document for a PTO adjustment

|
|**Reference Nbr.**|The unique identifier for the PTO adjustment. This number may be automatically generated by the system based on the settings specified on the [Payroll Preferences](PR_10_10_00.md) \(PR101000\) form.|
|**Status**|The current status of the document, which can be one of the following:-   *New*: The document has been created. For a document with this status, the **Release** command is available on the More menu of the form. Only PTO adjustments with the *New* status can be deleted from the system.
-   *Released*: The PTO adjustment has been released and the year-to-date available hours of the selected PTO bank have been corrected by the number of adjustment hours for the selected employee. For a document with this status, the **Void** command is available on the More menu of the form.
-   *Voided*: A PTO adjustment with the *Voiding Adjustment* type has been created based on this PTO adjustment.

|
|**Date**|The date of the document. When you save a new PTO adjustment, the system inserts the current system date in this box. This date is non-editable to prevent adjustments to PTO balances in the past or future.|
|**Description**|The description of the document.|

## Table {#2 .section}

When creating a PTO adjustment, you must fill in this table. You can import PTO adjustments from an Excel file by using the **Load Records from File** button on the table toolbar. The system does not allow the entry of multiple rows for the same combination of employee and PTO bank.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Employee**|The identifier of the employee whose PTO balances are to be adjusted.|
|**Employee Name**|The name of the employee, as defined on the [Employees](EP_20_30_00.md) \(EP203000\) form.|
|**PTO Bank**|The PTO bank whose balance is to be adjusted.|
|**Initial Balance**|The balance of the PTO bank before the adjustment. The box is read-only.|
|**Adjustment Hours**|The number of hours \(positive or negative\) by which the balance of the PTO bank is to be adjusted.|
|**Adjustment Reason**|A reason for the PTO adjustment, which can be one of the following:-   *Initial Balance Correction*
-   *Bonus or Incentive Allocation*
-   *Accrual Modification*
-   *Time Card Usage Correction*
-   *Accrual Earned Correction*
-   *Data Entry Correction*
-   *Carryover Correction*
-   *Maximum Accrual Correction*
-   *Other*

If you select the *Other* reason, the **Reason Details** column becomes editable for custom input.

|
|**Reason Details**|A custom reason for the PTO adjustment. This box is available for editing only if *Other* is selected in the **Adjustment Reason** box.|
|**New Balance**|The adjusted balance of the PTO bank. The box is read-only.|
|**Balance Limit**|The established balance limit for the PTO bank. The box is read-only.|
