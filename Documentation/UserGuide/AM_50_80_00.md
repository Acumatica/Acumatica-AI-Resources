# Process Cost Rollup Results

Form ID: \(AM508000\)

You use this form to process cost rollups generated on the [Generate Cost Rollups](AM_51_80_00.md) \(AM518000\) form. This includes updating pending standard costs of the BOM items, updating costs of materials used in the BOMs, and archiving cost rollups. You can also create automation schedules to process generated cost rollups as frequently as needed.

For more information about the cost rollup process and updating standard costs, see [Bills of Material: Updating Standard Costs](BOM_CostRoll.md).

**Attention:** When it updates the pending standard costs of items assigned to the BOMs, the system typically updates the pending costs of the stock item on the **Price/Cost** tab of the [Stock Items](../Shared/../UserGuide/IN_20_25_00.md) \(IN202500\) form. The system instead updates the pending cost of the item–warehouse pair on the **Price/Cost** tab of the [Item Warehouse Details](../Shared/../UserGuide/IN_20_45_00.md) \(IN204500\) form if the following conditions are met:

-   A warehouse is specified in the **Warehouse** box on the [Bill of Material](../Shared/../UserGuide/AM_20_80_00.md) \(AM208000\) form.
-   A record for the item–warehouse pair exists on the [Item Warehouse Details](../Shared/../UserGuide/IN_20_45_00.md) form.
-   The **Override Std. Cost** check box is selected on the **Price/Cost** tab of the [Item Warehouse Details](../Shared/../UserGuide/IN_20_45_00.md) form.

## Selection Area

You can use the settings in this area to select an action that will be performed during processing of cost rollups as well as to narrow the range of cost rollup results listed in the table. For example, you may want to process rolled up costs for items in a particular warehouse or assigned to a particular item class..

<table><thead><tr><th>

</th><th>

</th></tr></thead><tbody><tr><td>

**Action**

</td><td>

The action that the system performs when processing the cost rollup results.

 You can select any of the following actions:

 -   *Update Pending Costs*: Updates the pending costs of the stock items with the *Standard* valuation method that are used in the BOMs for which costs have been rolled up with the calculated costs.

The system searches the items based on the value in the **Default BOM ID** box on the [Stock Items](IN_20_25_00.md) \(IN202500\) or [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form.

**Attention:** This action is available if the **Allow Archive when Updating Pending Costs** check box is cleared on the [BOM Preferences](AM_10_10_00.md) \(AM101000\) form.

**Important:** This action updates only the item's pending cost. To update the standard cost, use the **Update Cost** command on the [Stock Items](IN_20_25_00.md) form or use the [Update Standard Costs](IN_50_20_00.md) \(IN502000\) form.

-   *Update Material Costs*: Updates the unit costs of the materials used in the BOMs.

During the update, the system copies the material cost from the **Price/Cost** tab of the [Stock Items](IN_20_25_00.md) or [Item Warehouse Details](IN_20_45_00.md) form to the **Unit Cost** column of the **Materials** tab on the [Bill of Material](AM_20_80_00.md) form depending on the valuation method of the material as follows:

    -   *Standard*: The current standard cost
    -   *Average* or *FIFO*: The average cost
    -   *Specific*: The last cost
For purchased components, the system uses costs from the [Stock Items](IN_20_25_00.md) or [Item Warehouse Details](IN_20_45_00.md) based on its valuation method. If the **Use Pending Standard Cost for Purchased Items** check box is selected, for items with the *Standard* valuation method, pending costs are used instead.

For subassemblies, the costs are updated based on the level of cost rollup:

    -   *Single*: The system uses costs from the [Stock Items](IN_20_25_00.md) or [Item Warehouse Details](IN_20_45_00.md) based on its valuation method.
    -   *Multi*: The system uses the cost calculated for the subassembly's bill of material.
-   *Archive*: Archives the results of the cost rollup, which can then be viewed on the [Archived Cost Rollups](AM_40_80_00.md) \(AM408000\) form.

This action is available only if the **Allow Archive Without Updating Pending Costs** check box is selected on the [BOM Preferences](AM_10_10_00.md) form.

-   *Update Pending Costs and Archive*: Updates the pending costs of the stock items with the *Standard* valuation method that are used in the BOMs for which costs have been rolled up with the calculated costs; then archives the cost rollup results.

This action is available if the **Allow Archive when Updating Pending Costs** check box is selected on the [BOM Preferences](AM_10_10_00.md) form.


 The system archives BOM records for the current date. If you archive the results multiple times on the same date, the system overrides the previous data for this date.

 **Attention:** The [Item Warehouse Details](../Shared/../UserGuide/IN_20_45_00.md) \(IN204500\) form is used only if the *Multiple Warehouses* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form and the warehouse-specific settings have been specified for the item.

## Table

The table lists the bills of material for which the system has rolled up costs and match the criteria specified in the Selection area.

If a BOM does not have a warehouse specified on the [Bill of Material](AM_20_80_00.md) \(AM208000\) form and the production item has multiple warehouses, the table displays one row for each item–warehouse pair associated with this BOM. You can choose the warehouse for which you want to process the cost rollup.

The table toolbar has only standard buttons.
