# Project Cost Spread by Month

Form ID: \(PM305700\)

**Attention:** This form appears only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to forecast a project’s costs by calendar month over the project timeline by:

-   Comparing the baseline, projected, and actual costs by month
-   Adjusting the projected monthly amounts for the effective period and future periods
-   Viewing variance amounts by month
-   Viewing a chart that compares the baseline, projected, and actual costs

The projected monthly amounts are based on the project’s S-curve type and the projected cost at completion from the latest released date-sensitive cost projection. If no such cost projection exists, the system uses the revised budgeted amount from the project cost budget.

## Details Tab

On this tab, you can review how the project costs are expected to change over the project’s duration. The table shows baseline, projected, actual, cost-to-complete, and variance amounts by month.

The table’s rows cover the time frame from the project’s start date through its end date, with each row representing one calendar month. For the periods before the effective period—that is, the period selected in the **Effective Period** box of the Summary area, the table shows actual costs. For the effective period and future periods, the projected monthly costs are calculated based on the project's S-curve type and the remaining amount to be spent.

## Approvals Tab

This tab displays the approval details for the project monthly cost spread. If approval is configured, the cost spread is automatically assigned for approval when it’s taken off hold. Authorized users approve or reject the project cost spread either from the current form or by using the [Approvals](EP_50_30_10.md) \(EP503010\) form.

This tab displays the approval entries associated with the selected record. If the record has existing *Approved* or *Rejected* entries and is put on hold for editing, these entries are preserved on the tab and the **Obsolete** check box is selected for them. Approval entries with a *Pending* decision are deleted. When the record is resubmitted for approval, new approval entries are created for this approval cycle. You can filter the approval entries on the tab by selecting one of the following filters: *All Records*, *Approved*, *Current* \(default\), *Pending*, or *Rejected*.

This tab is available only if an approval map is specified for project monthly cost spreads in the **Cost Spread Approval Map** box on the **Approval** tab of the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form. If no map is specified in this box, monthly cost spreads don’t require approval.

The table toolbar has only standard buttons.
