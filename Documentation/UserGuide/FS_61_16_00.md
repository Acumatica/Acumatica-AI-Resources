# Route Summary {#_fe8ba24a-1fe7-45fa-886e-7843906d31fa .reference}

Form ID: \(FS611600\)

This report displays detailed or summarized information about routes, grouped by route definition. You can select routes by the route definition and by the date range for which you want to view data.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report-Specific Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Report Format**: The format in which the report will be displayed. The following options are available:
    -   *Summary*: The summary information for all routes of a route definition will be displayed.
    -   *Detailed* \(Default\): The information on each route will be displayed.
-   **Start Date**: The start date for which you want to view information.
-   **End Date**: The end date for which you want to view information.
-   **Route**: The route definition for which you want to view data
