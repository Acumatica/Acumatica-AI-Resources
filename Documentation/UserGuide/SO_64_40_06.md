# Worksheet Pick List {#_add647d5-ecbf-4daa-ac2e-9de894325f28 .reference}

Form ID: \(SO644006\)

**Note:** This report is available only if the *Advanced Picking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This report displays pick lists for the pickers of the selected worksheet \(or a pick list for the selected picker, if applicable\) as a ready-to-print document. Each pick list provides the list of items to be picked from various locations for the selected shipment. Quantity, weight, and volume information is provided for each item, and the total weight and volume are specified at the bottom of the document.

The following barcodes are available for scanning in each generated pick list: the barcode of a worksheet part assigned to a picker, and the barcode to be used to confirm the items being picked.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Worksheet Number**: The picking worksheet number. Select the number of an open picking worksheet to prepare the pick lists for all its pickers \(or only the selected picker if you select a picker number\).
-   **Picker Nbr.**: The number of a picker; select the number of a picker included in the worksheet to prepare the pick list for this picker.
