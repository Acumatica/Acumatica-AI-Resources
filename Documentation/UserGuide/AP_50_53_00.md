# Synchronize External Payments

Form ID: \(AP505300\)

You use this form to synchronize multiple payments with the external payment processor in which they are being processed. During synchronization, the system requests the current state of each selected payment from the external payment processor and updates the payment in Acumatica ERP with the processing status, disbursement method, and other details that it receives. Depending on the details received, the system can also release the payment or change its status to *Voided*.

You can run the synchronization manually, or you can schedule it so that the system synchronizes the payments automatically. The system company includes two predefined schedules, *AvidXchange Payments Sync* and *BILL Payments Sync*, which are inactive. You can activate a schedule on the [Automation Schedules](SM_20_50_20.md) \(SM205020\) form.

This form appears in the system only if the *BILL Integration* feature or *AvidXchange Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar includes standard buttons and form-specific buttons and commands. For the list of standard buttons, see [Form Toolbar and More Menu](../InterfaceGuide/Form_Toolbar.md). The form-specific commands can be shown as buttons on the form toolbar, as commands on the More menu, or in both places. These commands are listed in the following table in alphabetical order.

|Button|Description|
|------|-----------|
|**Synchronize**|Initiates the synchronization of the payments you have selected in the table.|
|**Synchronize All**|Initiates the synchronization of all the payments listed in the table.|
