# Print Jobs {#_cbed1982-291a-45da-9e27-7c35650c3651 .reference}

Form ID: \(SM206500\)

**Note:** This form is available only if the *DeviceHub* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can review the list of printing operations that have been initiated in the system.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Preview**|Opens for preview the print job or print jobs you have selected in the table.|
|**Reprint**|Starts the reprinting of the print job or print jobs you have selected in the table.|

## Selection Area { .section}

You use this area to select the print jobs to be listed in the table by their date or status.

|Element|Description|
|-------|-----------|
|**Start Date**|The start date of the date range for which you want to display print jobs.|
|**End Date**|The end date of the date range for which you want to display print jobs.|
|**Hide Processed**|A check box that indicates \(if selected\) that only non-processed print jobs are shown in the table. If this check box is cleared, all print jobs are listed.|

## Table { .section}

This table lists print jobs performed in the system.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include this print job if you click **Preview** or **Reprint**.|
|**Job ID**|The identifier of a print job.|
|**Description**|The description of a print job.|
|**Report ID**|The ID of the report to be printed.|
|**DeviceHub ID**|The unique identifier of the DeviceHub application in which the printer is configured.|
|**Printer**|The name of the printer to which the report was sent for printing.|
|**Number of Copies**|The number of copies of the document to be printed via DeviceHub.|
|**Created By**|The username of the user who ran the printing operation.|
|**Creation Date and Time**|The date and time when the printing operation was run.|
|**Status**|The processing status of the print job, which can be one of the following:-   *Processed*: The print job has been processed successfully.
-   *Pending*: The print job is waiting for processing.
-   *Failed*: The print job failed to process.

|
