# File Tags {#_33800b23-ae02-4aec-abf3-fc5dbf949927 .reference}

Form ID: \(SM202560\)

On this form, you create custom tags to label file attachments. Later you can use these tags to organize files or to configure access setup role-based access to files. For details, see [Managing Project Files: General Information](Projects_File_Management_GeneralInfo.md).

## Form Toolbar {#section_qv3_ft2_f3c .section}

The form toolbar has only standard buttons.

## Summary Area {#section_dnr_gt2_f3c .section}

This area has the name and description of the tag selected in the **Tags** pane.

|Element|Description|
|-------|-----------|
|**Tag Name**|The name of the tag selected in the **Tags** pane, which you can change.

 If you click **Add** in the pane toolbar of the **Tags** pane, you can enter the name and description for a new tag.

 **Attention:** Tag names can contain Latin letters, numbers, spaces, hyphens, underscores, periods, and tildes.

|
|**Description**|The description of the tag.|

## Left Pane: Tags {#section_m5t_wt2_f3c .section}

In this pane, you create tags that will be assigned to files to control role-based access to them. To create a new tag, click **Add** in the pane's toolbar and specify the tag’s name. To remove an existing tag, select it and click **Delete**.

An out-of-the-box system includes the default **Untagged** tag, which cannot be deleted. The system uses it to mark files that have no other tags assigned. You assign access rights to this node, and the system applies these access rights to all untagged files.

## Right Pane: Access Rights {#section_uxl_ty2_f3c .section}

In this pane, you can assign each user role’s access level to the tag selected in the **Tags** pane. If the *Document Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, users with the role have this level of access to files with the selected tag.

|Column|Description|
|------|-----------|
|**Role**|The name of the role.|
|**Guest Role**|A check box that indicates \(if selected\) that the role is a guest role.|
|**Description**|The description of the role.|
|**Access Rights**|The role’s access level, which determines the actions users with the role can perform.

 For all file tags, the access level controls actions on the tag itself. For project and construction documents, it also controls what users with that role can do with files that have this tag.

 You can assign one of the following access levels:

 -   *Revoked*: Users can't access the tag. For project and construction documents, they can’t access files with the tag.
-   *View Only*: Users can view the tag. For project and construction documents, users can also download files with the tag.
-   *Edit*: Users can view and assign the tag—as well as view, download, check out, and upload new files or versions with the tag for project and construction documents.
-   *Create Version \(Project Files\)*: For project and construction documents, users can view, download, check out, and upload new files or versions with the tag.
-   *Edit and Upload \(Project Files\)*: For project and construction documents, users can view, download, check out, and upload new files or versions with the tag, as well as assign it.
-   *Delete \(Project Files\)*: For project and construction documents, users can perform all actions on files or versions with the tag, as well as delete them.

 The options that determine the access level to project files are shown only if the *Document Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 **Attention:** If a file related to a project and construction document has multiple tags with different access levels, the system applies the most permissive access level.
