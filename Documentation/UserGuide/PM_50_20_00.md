# Run Allocations by Tasks {#_af1a3f6e-402e-4197-bcac-4892907ccb68 .reference}

Form ID: \(PM502000\)

By using this form, you can allocate all the project tasks or only selected ones. When you run allocations, Acumatica ERP uses active allocation rules specified for the selected project tasks.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Command|Description|
|-------|-----------|
|**Allocate**|Processes the project tasks you have selected and performs allocation of transaction amounts.|
|**Allocate All**|Processes all listed project tasks and performs allocation of transaction amounts.|

## Selection Area {#1 .section}

You can use the elements in this area to filter the project tasks for which you might want to run the allocation procedure.

|Element|Description|
|-------|-----------|
|**Allocation Rule**|The allocation rule whose tasks you want to list. If you do not select any value here, the list in the table will include all the active project tasks to which an allocation rule is assigned.|
|**Posting Date**|The date to assign all the allocation transactions that will be generated when running the allocation procedure.|
|**Project**|The identifier of the project for which you want to allocate transactions.|
|**Project Task**|The identifier of the project to which the project task belongs.|
|**Date Range Restrictions** section|
|**From**|The start of the date range for which you want to allocate transactions. The system will allocate only transactions from the date range specified in the **Date Range Restrictions** section. If you do not select any value here, the system will allocate transactions starting with the oldest allocation transaction in the system.|
|**To**|The end of the date range for which you want to allocate transactions. The system will allocate only transactions from the date range specified in the **Date Range Restrictions** section. If you do not select any value here, the system will allocate transactions up to the last allocation transaction in the system.|

## Table {#2 .section}

The table contains the list of project tasks matching the criteria specified in the Selection area.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you can use to select the project task for processing.|
|**Project**|The identifier of the project to which the project task belongs.|
|**Task ID**|The identifier of the project task.|
|**Description**|The description of the project task.|
|**Allocation Rule**|The allocation rule associated with the project task. This allocation rule will be used for the allocation operation.|
|**Customer**|The customer associated with the project.|
|**Customer Class**|The customer class of the customer associated with the project.|
