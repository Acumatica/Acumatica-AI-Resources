# Undo Project Transaction Rollup

Form ID: \(PM505500\)

**Attention:** This form is available only if the *Parent-Child Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can undo the rollup of project transactions from child projects to their parent projects. The system removes the link between the original child project transaction and the parent project and marks the transaction as not rolled up.

## Form Toolbar

The form toolbar includes the buttons described below.

<table id="_34d339d5-304b-4382-87db-e71909ddd241"><thead><tr><th>

Button

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Undo**

</td><td>

Undoes the rollup of the project transactions which you have selected in the table.

 For each processed transaction, the system removes the link between the original child project transaction and the parent project and clears the **Rolled Up** check box on the [Project Transactions](PM_30_40_00.md) \(PM304000\) form.

 The rollup can't be undone if the project transaction has already been billed in the parent project. If the transaction has been billed in the child project, the rollup can be undone.

</td></tr><tr><td>

**Undo All**

</td><td>

Undoes the rollup of all project transactions listed in the table.

 For each processed transaction, the system removes the link between the original child project transaction and the parent project and clears the **Rolled Up** check box on the [Project Transactions](PM_30_40_00.md) \(PM304000\) form.

 The rollup can't be undone if the project transaction has already been billed in the parent project. If the transaction has been billed in the child project, the rollup can be undone.

</td></tr></tbody>
</table>

## Selection Area

In this area, you can specify the parent or child project and other criteria to limit the rolled-up project transactions listed in the table. If neither a parent project nor a child project is specified, the table is empty.

Element

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Parent Project**

</td><td>

The parent project for which you want to view rolled-up child project transactions. You can select a project with the *Parent* project hierarchy position and the *Active* or *Completed* status.

 By default, this box is empty. If you select a parent project, the table lists rolled-up transactions of its related child projects that meet the other specified criteria.

</td></tr><tr><td>

**Child Project**

</td><td>

The child project whose rolled-up project transactions you want to view. You can select a project with the *Child* project hierarchy position and the *Active* or *Completed* status.

 By default, this box is empty. If a project is specified in the **Parent Project** box, you can select only a child project of that parent project.

</td></tr><tr><td>

**Child Task**

</td><td>

The child project task whose rolled-up transactions you want to view.

 By default, this box is empty. Read-only until you select a project in the **Child Project** box.

</td></tr><tr><td>

**Account Group**

</td><td>

The account group of the project transactions to be listed. You can select an *Income* or *Expense* account group, or an *Off-Balance* account group for which the **Expense** check box is selected.

</td></tr><tr><td>

**Cost Code**

</td><td>

The cost code of the project transactions to be listed in the table.

 This box appears if the *Cost Codes* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

</td></tr><tr><td>

**Inventory ID**

</td><td>

</td></tr><tr><td>

**Date Range**

</td><td>

The start and end dates of the project transactions to be listed in the table.

 If both dates are empty, transactions for all dates are displayed.

</td></tr></tbody>
</table>
