# Project AP Details {#_4f15de24-4dc4-4401-880f-2acd2b499ca2 .reference}

Form ID: \(PM651001\)

**Attention:** This generic inquiry form is available if the *Extended Financial Data Collection* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this generic inquiry form, you can view the AP amounts—such as unbilled amounts, paid amounts, and unreleased retainage—for each listed document line. The system calculates these values as of the date you specify; you can also select a project and vendor to view only their document lines.

You can use the form to verify the AP amounts the system has calculated on the [Project Cash Flow](PM_65_10_10.md) \(PM651010\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

In this area, you select the date through which the system shows document lines in the table. By specifying a particular project or vendor \(or both\), you can narrow the range of document lines listed in the table.

|Element|Description|
|-------|-----------|
|**Date**|The date through which data is displayed—that is, you’ll see document lines up to and including this date. By default, the system inserts the current business date.|
|**Project**|The project for which you want to view the AP amounts.|
|**Vendor**|The vendor for which you want to view the AP amounts. If you select a vendor, you’ll see data for the vendor whose items or services were purchased for the project.|

## Table {#2 .section}

In the table, you can view the AP data for the selection criteria you’ve specified. You can use this information to verify the AP amounts that the system has calculated on the [Project Cash Flow](PM_65_10_10.md) \(PM651010\) form. Each row represents a document line.

Below you’ll find descriptions of the columns that show information about the listed documents, their currency rates, and their calculated values, along with calculation formulas the system uses.

**Attention:**

-   The leftmost columns of the table aren't described in this topic. These columns display the document's basic information—such as company, branch, project, project task, account group, and cost code. If you need information about these UI elements, see their descriptions on the document's data entry form.
-   The values are calculated in **the project currency**. The form shows values in the base, project, and document currencies if the *Multicurrency Accounting* and *Multicurrency Projects* features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Date**|The document date, which can be one of the following:-   The approval date for a change order
-   The application date for a document on the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form
-   The creation date for a document on the [Purchase Orders](PO_30_10_00.md) \(PO301000\), [Subcontracts](SC_30_10_00.md) \(SC301000\), or [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) form

|
|**Inventory ID**|The stock or non-stock item specified in the document line.|
|**Record Type**|The type of the record, which is created on the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) or [Checks and Payments](AP_30_20_00.md) \(AP302000\) form.|
|**Document Type**|The specific type of the document created on the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) or [Checks and Payments](AP_30_20_00.md) \(AP302000\) form.|
|**Ref. Nbr.**|The reference number of the document.|
|**Line Nbr.**|The line number of the document.|
|**AP Document Type**|The type of the AP document, such as *Bill*, *Credit Adj.*, *Debit Adj.*, or *Prepayment*.|
|**AP Document Ref. Nbr.**|The reference number of the AP document—such as bill, credit adjustment, debit adjustment, or prepayment**—**in the system.|
|**AP Document Line Nbr.**|The line number of the AP document.|
|**Commitment Doc. Type**|The type of the subcontract or purchase order related to the project associated with this document line, which is *Normal*, *Project Drop-Ship*, or *Subcontract*.|
|**Commitment Ref. Nbr.**|The reference number of the subcontract or purchase order.|
|**Commitment Line Nbr.**|The line number of the subcontract or purchase order.|
|**Base Currency**|The base currency used for accounting in the branch associated with the project specified in this document line.|
|**Document Currency**|The currency of the document.|
|**Vendor**|The vendor specified in the subcontract, change order, purchase order, bill, or payment.|
|**Retainage Document**|A check box that indicates \(if selected\) that the AP document with a withheld retainage amount from the original document has been released. The system copies the state of the check box from the document on the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) form.|
|**Rate \(Project Curr.\)**|The rate used to convert document amounts to the project currency.The system uses the applicable rate on one of these dates:

-   The creation date for a commitment on the [Purchase Orders](PO_30_10_00.md) \(PO301000\) or [Subcontracts](SC_30_10_00.md) \(SC301000\) form
-   The document date for a document on the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) form
-   The date of the original document for a retainage bill, debit adjustment, or credit adjustments
-   The original payment date for an original or voided payment on the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form

|
|**Rate \(Base Curr.\)**|The rate used to convert document amounts to the base currency of the project.The system uses the applicable rate on one of these dates:

-   The creation date for a commitment on the [Purchase Orders](PO_30_10_00.md) \(PO301000\) or [Subcontracts](SC_30_10_00.md) \(SC301000\) form
-   The document date for a document on the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) form
-   The date of the original document for a retainage bill, debit adjustment, or credit adjustment
-   The original payment date for an original or voided payment.

|
|**UOM**|The unit of measure specified in the line of the purchase order, subcontract, or bill specified in this document line.|
|**Committed Qty.**|The committed quantity, which is either of the following:-   The order quantity specified in the line of the released subcontract on the [Subcontracts](SC_30_10_00.md) \(SC301000\) or purchase order on the [Purchase Orders](PO_30_10_00.md) \(PO301000\) form
-   The quantity specified on the **Commitments** tab of the released change order on the [Change Orders](PM_30_80_00.md) \(PM308000\) form

|
|**Committed Unit Cost \(Project Curr.\)**|The committed unit cost, which the system calculates by using this formula: `Committed Amount (Project Curr.) / Committed Qty.`**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Committed Unit Cost \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Committed Amount \(Project Curr.\)**|The extended cost specified in the line of any of the following documents:-   The released subcontract or purchase order
-   The amount specified on the **Commitments** tab of the released change order on the [Change Orders](PM_30_80_00.md) \(PM308000\) form

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Committed Amount \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Committed Retainage \(Project Curr.\)**|The committed retainage amount, which the system calculates by using this formula: `Retainage Amount * Rate (Project Curr.)`.`Retainage Amount` is the retainage amount specified on the **Details** tab of the [Subcontracts](SC_30_10_00.md) \(SC301000\) form for the line.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Committed Retainage \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Billed Qty.**|The quantity of the items that have been billed on the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) form, which is one of the following:-   For a released document of the *Bill* or *Credit Adj.* type, it’s the quantity specified in the document line.
-   For a released document of the *Debit Adj.* type, it’s the quantity specified in the document line is shown as a negative value.

|
|**Unit Cost \(Project Curr.\)**|The cost per UOM of the inventory item specified in the line, which the system calculates by using this formula: `Extended Cost (Project Curr.) / Billed Qty.`**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Unit Cost \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Extended Cost**|The extended cost specified in the line of the released document of the *Bill* or *Credit Adj.* type on the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) form. For a document of the *Debit Adj.* type, the cost is shown as a negative value.|
|**Extended Cost \(Project Curr.\)**|The extended cost in the project currency, which the system calculates by using this formula: `Extended Cost * Rate (Project Curr.)`.If the project currency is the same as the document’s base currency, the system shows the extended cost in the base currency.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Extended Cost \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Billed Inclusive Tax \(Project Curr.\)**|The billed inclusive tax amount applied to the project's original AP bills, which the system proportionally spreads across the lines of the bill.**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Billed Inclusive Tax \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Billed Tax \(Project Curr.\)**|The billed exclusive tax amount applied to the project's original AP bill, which the system proportionally spreads across the lines of the bill with the tax category that requires this tax calculation.For a document of the *Debit Adj.* type, the amount is shown as a negative value.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Billed Tax \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**AP Retained Amount \(Project Curr.\)**|The AP retainage amount, which the system calculates by using one of these formulas depending on the type of the document:-   For an original bill, `Retainage Amount * Rate (Project Curr.)`.

`Retainage Amount` is the retainage amount of each line of the bill.

-   For a retainage bill, `Ext. Cost * Rate (Project Curr.) * (-1)`.
-   For a debit adjustment, `Retainage Amount * Rate (Project Curr.) * (-1)`.
-   For a retainage debit adjustment, `Ext. Cost * Rate (Project Curr.)`.

`Ext. Cost` is the extended cost of each line of the retainage debit adjustment.


**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **AP Retained Amount \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**AP Retained Taxes \(Project Curr.\)**|The retained tax amount applied to the project's original AP bills and retainage debit adjustments, which the system proportionally spreads across the lines of the bill.This amount doesn't include the use tax, whose amount you can review in the **Use Tax \(Project Curr.\)** column.

For a document of the *Debit Adj.* type or retainage bill, the amount is shown as a negative value.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **AP Retained Taxes \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**AP Amount**|The sum of the amounts specified in the lines of the released bill or credit adjustment and the billed tax amount, which the system calculates in the document currency.|
|**AP Amount \(Project Curr.\)**|The amount of the bill, which the system calculates by using this formula: `AP Amount / Rate (Project Curr.)`.If the project currency is the same as the document currency, this value is the same as the **AP Amount**.

If the project currency is the same as the document base currency, the system multiplies the **AP Amount** by the base currency rate specified on the document's data entry form.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **AP Amount \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**AP Paid Amount**|The paid amount of the bill, which can be either of the following depending on the state of the **Pay by Line** check box on the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) form:-   If the check box is cleared: The amount paid specified in the **Application History** tab of the document on the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form. The system proportionally spreads this amount across the lines of the original bill.
-   If the check box is selected: The amount paid specified in the **Application History** tab of the document on the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form applied to the original bill's line specified in **Line Nbr.** column.

|
|**AP Paid Amount \(Project Curr.\)**|The paid amount of the bill, which the system calculates by using this formula: `AP Paid Amount * Rate (Project Curr.)`.**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **AP Paid Amount \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**AP Cash Discount \(Project Curr.\)**|The cash discount, which can be either of the following depending on the state of the **Pay by Line** check box on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form:-   If the check box is cleared: The cash discount specified on the **Application History** tab of the document on the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form. The system proportionally spreads this amount across the lines of the original bill and multiplies the amount by the rate in the project currency.
-   If the check box is selected: The cash discount specified on the **Application History** tab of the document on the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form applied to the original bill's line specified in **Line Nbr.** column and multiplied by the rate in the project currency.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **AP Cash Discount \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Withheld Tax Amount \(Project Curr.\)**|The withheld tax amount, which can be either of the following depending on the state of the **Pay by Line** check box on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form:-   If the check box is cleared: The withheld tax amount specified on the **Application History** tab of the document on the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form. The system proportionally spreads this amount across the lines of the original bill and multiplies the amount by the rate in the project currency.
-   If the check box is selected: The withheld tax amount specified on the **Application History** tab of the document on the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form applied to the original bill's line specified in **Line Nbr.** column and multiplied by the rate in the project currency.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Withheld Tax Amount \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Paid Inclusive Tax \(Project Curr.\)**|The paid inclusive tax amount, which the system calculates by using this formula: `(Amount Paid + Cash Discount Taken) * Billed Inclusive Tax (Project Curr.) of each paid bill line / Amount of the paid bill`.-   `Amount Paid` and `Cash Discount` are specified on the **Application History** tab of the document on the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form.
-   `Amount` is specified in the Summary area of the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) form.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Paid Inclusive Tax \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Exclusive Taxes on Paid AP \(Project Curr.\)**|The tax amount on the paid amount of the bill, which the system calculates by using this formula: `(Amount Paid + Cash Discount Taken) * Billed Tax (Project Curr.) of each paid bill line / Amount of the paid bill`.-   `Amount Paid` and `Cash Discount Taken` are specified on the **Application History** tab of the document on the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form.
-   `Amount` is specified in the Summary area of the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) form.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Exclusive Taxes on Paid AP \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Use Tax \(Project Curr.\)**|The billed use tax amount applied to the project's original AP bills, which the system proportionally spreads across the lines of the bill.**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Use Tax \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Realized Gain/Loss \(Project Curr.\)**|The realized gain or loss, which the system calculates by using this formula: `AP Paid Amount * Rate (Project Curr.) on the original bill's date - Rate (Project Curr.) on the payment date`.If the project currency is the same as the bill's currency, the realized gain or loss is *0*.

If the project currency is the same as the bill's base currency, the realized gain or loss is the same as the one specified in the GL transaction.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Realized Gain/Loss \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.
