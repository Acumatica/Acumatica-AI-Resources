# Manage Exempt Customers {#_10a2720a-3ec3-4e66-a47c-91b1b5464594 .reference}

Form ID: \(TX505000\)

On this form, you can add customers that exist in Acumatica ERP to the Avalara ECM provider account and update customer settings in the account. You can perform these actions on any number of customers simultaneously.

**Tip:** This form is available only if the *Exemption Certificate Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

For details, see [Exception Certificate Management: General Information](config_Exception_Certificate_Management_GeneralInfo.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the selected processing \(based on the **Action** you select\) for the customers you have selected in the table.|
|**Process All**|Initiates the selected processing \(based on the **Action** you select\) for all customers listed in the table.|

## Selection Area {#1 .section}

In this area, you can select the action to be applied to the processed customers. If you are adding the listed customers to the ECM account, you can also select the company code to be associated with the customers.

|Element|Description|
|-------|-----------|
|**Action**|The action to be applied to the selected customer or customers if you click **Process** or **Process All** on the form toolbar.

 -   *Create Customer in ECM Provider*: Adds customers that have been defined in Acumatica ERP to the Avalara ECM account.
-   *Update Customer in ECM Provider*: Updates the customer settings in the Avalara ECM account with any settings have been changed in Acumatica ERP.

 For details, see [Exception Certificate Management: General Information](config_Exception_Certificate_Management_GeneralInfo.md).

|
|**Company Code**|A company code that corresponds to a company in the ECM account and linked to a branch or multiple branches in Acumatica ERP.

 If only one company code has been assigned to Acumatica ERP branches in the tax provider settings on the **Company Code Mapping** tab on the [Tax Providers](TX_10_20_00.md) \(TX102000\) form, the system inserts this code in this box by default and makes the box unavailable for editing. If multiple company codes has been linked to branches in Acumatica ERP, they are available in this box, and you can select any number of company codes.

 This box is not shown if you select *Update Customer in ECM Provider* in the **Action** box.

|

## Table {#2 .section}

This table displays the list of customers defined in Acumatica ERP that can be selected for processing.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include this customer in processing if you click **Process**.|
|**Customer ID**|The identifier of the customer. The system copies this value from the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Customer Name**|The name of the customer. The system copies this value from the **Account Name** of the **General** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Tax Registration ID**|The customer's taxpayer identifier associated with the location. The system copies this value from the **Tax Registration ID** box of the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Address Line 1**|The first line of the billing address. The system copies this value from the **Address Line 1** of the **Bill-To Address** section of the **Billing** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Address Line 2**|The second line of the billing address. The system copies this value from the **Address Line 2** of the **Bill-To Address** section of the **Billing** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**City**|The customer's city. The system copies this value from the **City** of the **Bill-To Address** section of the **Billing** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**State**|The customer's state or province. The system copies this value from the **State** of the **Bill-To Address** section of the **Billing** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Postal Code**|The customer's postal code. The system copies this value from the **Postal Code** of the **Bill-To Address** section of the **Billing** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Country**|The customer's country. The system copies this value from the **Country** of the **Bill-To Address** section of the **Billing** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Primary Contact**|The name of the primary contact associated with the customer.

 The system copies this value from the **Name** of the **Primary Contact** section of the **General** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form.

|
|**Phone Number**|The customer's phone number. The system copies this value from the **Business 1** box of the **Bill-To Info** section of the **Billing** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Account Email**|The customer's email address. The system copies this value from the **Account Email** box of the **Bill-To Info** section of the **Billing** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Fax**|The customer's fax number. The system copies this value from the **Fax** box of the **Bill-To Info** section of the **Billing** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Company Code**|The company code corresponding to the company in the ECM account to which the customer is added. If you are adding customers to the ECM account \(the *Create Customer in ECM Provider* action is selected in the Selection area of this form\), the company codes to which the customer has already been added will be listed in this box.

If you are updating the customer's settings \(the *Update Customer in ECM Provider* action is selected in the Selection area of this form\), and the customer is added to multiple companies, all their company codes will be listed in this box, and the settings will be updated for all companies.

|
