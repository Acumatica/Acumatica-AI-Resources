# Daylight Saving Settings {#_e368aa84-87f3-47cb-9aeb-75be0e848996 .reference}

Form ID: \(CS209020\)

You use this form to view and manually adjust the current daylight saving time calendar for various time zones.

Each Acumatica ERP instance uses the Daylight Saving Time \(DST\) settings of a server \(which are settings of an operating system, such as Windows\) on which the instance is installed. If Acumatica ERP is integrated with any third-party service, DST settings of the Acumatica ERP and service servers may differ, which may result in synchronization errors. To adjust the discrepancy, on the [Daylight Saving Settings](../Shared/../UserGuide/CS_20_90_20.md) \(CS209020\) form, you can select the **Custom** check box for all timezones to make the DST settings of the Acumatica ERP instance completely independent from the server settings.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Period Area { .section}

You can select the current year for editing or select a previous year and view details about it.

|Element|Description|
|-------|-----------|
|**Year**|The year for which you want to edit a calendar.|

## Table { .section}

This table holds the time zones with detailed information about time shifts.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Time Zone**|A time zone that has a time shift.|
|**Custom**|A check box that indicates \(if selected\) that this time zone shift is specified manually.|
|**From \(Date\)**|The date when the shift goes into effect.|
|**From \(Time\)**|The time when the shift goes into effect.|
|**To \(Date\)**|The date until which the shift is in effect.|
|**To \(Time\)**|The time until which the shift is in effect.|
|**Shift \(Minutes\)**|The time shift in minutes.|
