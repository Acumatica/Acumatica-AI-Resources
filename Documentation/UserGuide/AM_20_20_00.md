# Forecast

Form ID: \(AM202000\)

**Important:** This form is available only if the *Material Requirements Planning* or *Distribution Requirements Planning* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to manually add forecasts used by the process of inventory planning regeneration performed on the [Regenerate Inventory Planning](AM_50_50_00.md) \(AM505000\) form and view generated forecasts. You can use the [Generate Forecasts](AM_50_20_00.md) \(AM502000\) form to generate forecasts.

Before you can start creating forecasts on the current form, you should make sure that the following tasks have been completed:

-   A numbering sequence for forecasts has been created on the [Numbering Sequences](CS_20_10_10.md) \(CS201010\) form.
-   The numbering sequence has been specified on the [Inventory Planning Preferences](AM_10_00_00.md) \(AM100000\) form.

**Tip:** If you want to delete some forecasts, you can use a filter to select the records to delete and then use the **Delete** button on the form toolbar.

## Side Panel

By using the side panel, you can compare the forecasted demand with the actual demand for dependent forecasts.

The side panel has two tabs, each of which you can view by clicking the tab's icon. For ease of comparison, the ordered quantities displayed on the tabs are converted to the forecast's unit of measure.

|Tab|Description|
|---|-----------|
|**Forecast vs. Sales**|You use this tab to review the forecasted quantity, the ordered quantity, and the quantity variance for each forecast interval of the selected forecast.|
|**Forecast vs. Sales Details**|You use this tab to explore which sales orders consumed the forecasted demand. The table on this tab lists all sales orders that have been created for the item during the selected forecast interval, along with the ordered quantities and additional details from the corresponding sales order lines.|
