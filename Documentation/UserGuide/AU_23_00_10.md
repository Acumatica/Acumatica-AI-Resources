# UI Configurations {#_c94b7b43-83d1-47f0-9cd2-48e4c0a30d7a .reference}

Page ID: \(AU230010\)

Acumatica ERP provides the ability to quickly make some types of changes to a form to meet users' needs. A *form configuration*—a set of these changes to a particular form—can be done system-wide or by individual users to personalize the form for their use.

You can incorporate a form configuration in a customization project as a *UI configuration*—that is, a *ScreenConfiguration* item that corresponds to the form configuration. On this page, you manage these items in the customization project.

**Tip:** You open this page by clicking **UI Configurations** in the navigation pane of the Customization Project Editor.

## Page Toolbar { .section}

The page toolbar includes standard buttons and a page-specific button. These commands are listed in the following table in alphabetical order.

|Button|Description|
|------|-----------|
|**Reload from Database**|Updates all listed *ScreenConfiguration* items in the customization project if the form configurations that correspond to these items have been modified on the appropriate Acumatica ERP form.|

|Element|Description|
|-------|-----------|
|The table toolbar has only standard buttons.

 It also contains the Search box, which you can use to search for the needed form.

 The table in this dialog box has the following columns.

|
|Included|A check box that you select to add this configuration to the customization project.|
|**Screen ID**|The ID of the screen \(form\) associated with the configuration.|
|**Screen Name**|The screen \(form\) name as it’s displayed on the form in Acumatica ERP.|
|This dialog box has the following buttons.|
|**Save**|Adds the selected configurations to the table on the page and closes the dialog box.|
|**Cancel**|Closes the dialog box without making any changes on the page.|

## Table {#1 .section}

This table contains the list of UI configurations included in the customization project and the basic settings of each of them. The columns of the table are described below.

|Element|Description|
|-------|-----------|
|**Screen ID**|The ID of the screen \(form\) associated with the configuration.|
|**Screen Name**|The screen name as it is displayed on the form in Acumatica ERP.|
|**User-Defined Fields**|The user-defined fields that have been added to the form|
|**Description**|The description of the screen configuration.|
|**Last Modified By**|The name of the user who last modified the screen configuration in the customization project.|
|**Last Modified On**|The date when the screen configuration was last modified in the customization project.|
