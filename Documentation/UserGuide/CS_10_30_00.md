# Address Providers {#_a1f9fd43-38aa-4514-b1bb-aae5925c0b8e .reference}

Form ID: \(CS103000\)

You use this form to configure the plug-in for the integration with each address provider. This form appears in the system when the *Address Validation Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Test Connection**|Tests the connection with the website of the selected address provider.|

## Summary Area { .section}

This area displays the summary settings of the selected address provider.

|Element|Description|
|-------|-----------|
|**Provider ID**|The ID of the address provider.|
|**Description**|The description of the address provider.|
|**Plug-In**|The predefined type of the address provider's plug-in type. When you select a value in this box, the parameters of the selected plug-in are added to the **Plug-In Parameters** table on this form.|
|**Active**|A check box indicating whether the selected address provider is active.|

## Plug-In Parameters Table { .section}

In this table, you specify the values of the parameters for the selected address provider. This table is populated with parameters based on the plug-in you selected in the **Plug-In** box.

|Column|Description|
|------|-----------|
|**ID**|The ID of the parameter of the plug-in.|
|**Description**|The description of the parameter of the plug-in.|
|**Value**|The value of this plug-in parameter.|
