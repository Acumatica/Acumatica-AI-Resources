# External File Storage {#_13998c62-3e59-473e-bf6c-37aba350b47f .reference}

Form ID: \(SM202540\)

In Acumatica ERP, the imported files are stored in the Acumatica ERP database by default. Alternatively, you can use this form to select where files should be stored—in a local folder on the machine running the Acumatica ERP website or in a public storage service, such as Azure Blob or Amazon S3. For more information, see [External Storage: General Information](SA_External_Storage_Management_GeneralInfo.md).

On this form, you configure external file storage providers, specify the location for storing newly imported files, and move the files between the database and the external file storage.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Enable Provider**|Enables the provider you have configured. After you click this button, you cannot change provider settings, and from now on, all newly imported files will be stored in the specified folder.|
|**Switch Direction**|Toggles between the database and external storage without disabling the current provider. When the files are stored to the database, the **Allow Saving Files** check box in the Selection area is cleared. When the files are stored to the external storage, the **Allow Saving Files** check box is selected.|
|**Disable Provider**|Disables the currently enabled provider, so you can either modify the current provider settings or configure settings for an alternate provider. This button is available when all the files are moved to the database.

|
|**Move Files to Database**|Moves all the files from the current external storage to the Acumatica ERP database. This button is available when you switch the storage direction to the database and the external storage stores at least one file.

|
|**Move Files to Storage**|Moves all the files from the Acumatica ERP database to the current external storage. This button is available when you switch the storage direction to the external storage.

|

## Selection Area {#1 .section}

You use this area to specify which provider will be used and whether saving files is permitted.

|Element|Description|
|-------|-----------|
|**Provider**|The provider of the external file storage. Acumatica ERP supports the following built-in providers: -   *Azure Blob Storage*

**Note:** Your company must have an Azure account with the configured blob in Azure Blob storage. For more information, see [Introduction to Microsoft Azure Storage: Blob Storage](https://azure.microsoft.com/en-us/documentation/articles/storage-introduction/#blob-storage) and [About Azure Storage Accounts](https://azure.microsoft.com/en-us/documentation/articles/storage-create-storage-account/#create-a-storage-account).

-   *Amazon S3 Storage*

**Note:** Your company must have an Amazon Web Services \(AWS\) account with the configured storage bucket in Amazon S3 storage. For more information, see [Amazon S3](http://aws.amazon.com/s3/) and [AWS Security Credentials](http://docs.aws.amazon.com/general/latest/gr/aws-security-credentials.html).

-   *Local File Folder*

**Note:** The account used to run the Acumatica ERP website must have *write* access to the storage folder.


To use the selected provider, specify the provider settings in the table.

|
|**Allow Saving Files**|A check box that indicates whether files are being saved to this provider. If it is selected, the system saves files to this provider as specified in the **Provider Settings** table. If it is cleared, the system saves files to the default storage in the Acumatica ERP database.

 The check box is unavailable when the provider is enabled. To select or clear the check box without disabling the current provider, click **Switch Direction** on the form toolbar.

|

## Provider Settings Table {#2 .section}

This table holds detailed information about the selected provider.

|Column|Description|
|------|-----------|
|**Name**|The setting for the selected provider. The system fills in these settings based on the provider you have selected.|
|**Value**|The values for the setting in the **Name** column. The values depend on the provider you selected in the **Provider** box in the Selection area.

 If the files will be stored in the Azure Blob storage, provide the following values:

 -   *Account*: The name of the storage account in the Azure Blob storage service—such as *myaccount*
-   *Container*: The name of the container to store files in the Azure Blob storage service—for example, *files*
-   *Key*: The 512-bit storage access key to your account in the Azure Blob storage service—for example, *ubYUHyb8PUdy7R7yDITILMp5NN9usQYeS5?0RPAO70ikBO09t4nVYbJeuGILN/qS72p9AmOtXb4MUh+wMu$GKnwC*

 If the files will be stored in the Amazon S3 storage, provide the following values:

 -   *AWSAccessKey*: The access key ID of the storage bucket—for example, *AKIAIOSFODNN7EXAMPLE*
-   *AWSRegionEndpoint*: The short name of the AWS region—such as *us-east-1*
-   *AWSSecretKey*: The secret access key of the storage bucket—for example, *wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY*
-   *BucketName*: The name of the storage bucket to be used to store Acumatica ERP files—for example, *files*
-   *PathPrefix*: The root folder in the selected storage bucket that is used to group the stored files—such as *mycompany/acumatica*

 If the files will be stored in a local folder, specify the following value:

 -   *Local Folder*: The path to the folder—for example, *C:\\Temp*

|
