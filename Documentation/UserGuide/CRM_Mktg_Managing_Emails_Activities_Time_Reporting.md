# Emails and Activities: Time Reporting {#_c717048a-7b0f-4edf-b7ca-665c2ad54263 .concept}

Acumatica ERP gives you the ability to track your working time as you perform your work tasks.

## Time Reporting { .section}

You can report time spent on activities, tasks, events, and emails if the *Time Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, which makes the **Track Time and Costs** check box available on the [Activity](CR_30_60_10.md) \(CR306010\) form. When a user selects this check box, multiple elements appear on the [Activity](CR_30_60_10.md) form, which you can use to report the total time spent on the activity. You can also select the **Billable** check box to indicate that the activity is billable and specify the information required for billing—that is, the duration of billable time and the earning type of the activity; the earning type determines how the system calculates the cost of employee labor. For details, see [Entering Employee Time](TimeExpenses_Entering_Employee_Time_Mapref.md).
