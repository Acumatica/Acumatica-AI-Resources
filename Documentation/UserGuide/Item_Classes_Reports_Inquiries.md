# Item Classes for Stock Items: Related Reports and Inquiries

In the following section, you can find information about an inquiry with information about item classes.

## Viewing the List of Stock Items of a Particular Class

If you want to view the list of inventory items of a particular item class, you can use the [Inventory by Item Class](IN_40_80_00.md) \(IN408000\) form. On this form, you can also browse the hierarchy of item classes, select a particular inventory item and view the item class to which it belongs, and move inventory items between classes \(if needed\).
