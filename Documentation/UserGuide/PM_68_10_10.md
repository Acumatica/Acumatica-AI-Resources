# Project Profit &amp; Loss by Month {#_8708390d-9310-4564-8193-f1b7a84f7ff9 .reference}

Report ID: \(PM681010\)

**Attention:** This report is available only if the *Projects* group of features is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. The report is available only for the users with the *Financial Supervisor* or *Project Accountant* role assigned on the [Users](SM_20_10_10.md) \(SM201000\) form.

This report displays the revenue and expenses of a project on a monthly basis.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Financial Period**: The financial period for which you want to view information. You must select a period from the list, which contains all the periods defined in the system, including the closed ones.

    By default, the current financial period is selected.

-   **Start Project**: The project for which you want to view information.
