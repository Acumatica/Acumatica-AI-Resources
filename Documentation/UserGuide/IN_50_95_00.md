# Apply Replenishment Parameters

Form ID: \(IN509500\)

**Attention:** This form is available only if the *Inventory Replenishment* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. This form only displays items where *Inventory Replenishment* has been specified as the planning method.

You use this form to apply to stock items the replenishment parameters the system has calculated according to the forecast models used. You can initiate this calculation by using the [Calculate Replenishment Parameters](IN_50_85_00.md) \(IN508500\) form. After you apply the replenishment parameters, you can use the [Prepare Replenishment](IN_50_80_00.md) \(IN508000\) form to view whether stock replenishment for the item is needed and in what quantities. For an overview of this functionality, see [Configuration of Replenishment: Replenishment Methods](../ImplementationGuide/config_OrderMgmt_Replenishment_Methods.md) and [Configuration of Replenishment: Demand Forecast Model](../ImplementationGuide/config_OrderMgmt_Replenishment_Demand_Forecast_Model.md).

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Updates the replenishment parameters with the calculated values for the items you have selected in the table.|
|**Process All**|Updates replenishment parameters \(by replacing them with the calculated values\) for all the items listed in the table to determine whether they should be replenished and in what quantities.|
