# To Link an Article to a Form {#_bdabadfb-b464-463d-abe9-502f883aa9a6 .task}

In Acumatica ERP, you can add a new form when you want to, and then document the form—its toolbar actions and the elements and actions of all areas, tabs, and dialogs—by using wikis. To link the reference article to a form, base the article ID on the number of the form, with underscores replacing periods. For example, if the form number is *AP101000*, the ID of its form reference topic is *AP\_10\_10\_00*.

1.  Open the reference article.
2.  On the wiki toolbar, click **Edit Current Article** to open the Wiki Editor form.
3.  On the **Content** tab, in the **Article ID** box, specify the ID of the form reference based on the article ID on the number of the form, with underscores replacing periods.
4.  On the form toolbar, click **Save**.
