# Manage Cross-Selling Suggestions {#_014d85f8-32b9-4922-a6bf-aa47a94bf145 .reference}

Form ID: \(IN503500\)

On this form, you can approve or delete cross-selling suggestions generated by the Cross-Sell Assistant. You can specify selection criteria to narrow the list of suggestions. You can then process all the listed cross-selling suggestions or only the ones you select.

This form is available only if the *Related Item Assistant* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

For more information about the automated generation of suggestions for cross-sell items, see [Related Items in Sales Orders: Automated Suggestions for Cross-Sell Items](OrderMgmt_Automated_Suggestions_for_Cross_Sell_Items.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the processing for the cross-selling suggestions you’ve selected in the table based on the action you select.|
|**Process All**|Initiates the processing for all cross-selling suggestions in the table based on the action you select.|

## Selection Area {#1 .section}

You can use the settings in this area to select the action to be performed during processing. You can also narrow the range of cross-sell suggestions listed in the table.

|Element|Description|
|-------|-----------|
|**Action**|The action to be taken on each processed cross-sell suggestion if you click **Process** or **Process All** on the form toolbar.

 Select one of the following options:

 -   *Approve*: The selected suggestions are approved. For each approved suggestion, the system does the following:
    -   Shows it as a cross-sell item in the **Add Related Items** dialog box on the [Sales Orders](SO_30_10_00.md) \(SO301000\) form when a user creates a sales order with the original item.
    -   Selects the **Accepted ML Suggestion** and **Active** check boxes for the cross-sell item on the **Related Items** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) or [Non-Stock Items](IN_20_20_00.md) \(IN202000\) form.
    -   Sends positive feedback about the suggestion to the ML model.
-   *Delete*: The system deletes each processed suggestion from the **Related Items** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) or [Non-Stock Items](IN_20_20_00.md) \(IN202000\) form for the original item. It also sends negative feedback to the ML model.

|
|**Original Item Class**|The item class that includes the original items whose suggestions you want to display.|
|**Original Item**|The original item—that is, the item whose suggestions you want to display.|
|**Cross-Sell Item**|The cross-sell item by which you want to filter suggestions.|

## Table {#2 .section}

This table contains a list of cross-selling suggestions generated by the Cross-Sell Assistant. This table may list all generated suggestions or only those that meet the selection criteria you’ve specified.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include this suggestion in processing if you click **Process**.|
|**Original Item ID**|The identifier of the original stock or non-stock item—that is, the item for which the suggestion has been generated.|
|**Original Item Description**|The description of the stock or non-stock item for which the suggestion has been generated.|
|**Cross-Sell Item ID**|The identifier of the stock or non-stock item suggested as the cross-sell item.|
|**Cross-Sell Item Description**|The description of the stock or non-stock item suggested as the cross-sell item.|
|**Rank**|The read-only rank of the cross-sell item. The rank indicates the order in which the cross-sell item in is displayed among the listed related items on the [Stock Items](IN_20_25_00.md) \(IN202500\) or [Non-Stock Items](IN_20_20_00.md) \(IN202000\) form.|
|**Tag**|The read-only tag of the cross-sell item.|
|**UOM**|The unit of measure of the cross-sell item. You can change the UOM if the *Approve* action is selected in the Selection area. The column is read-only if the *Delete* action is selected.|
|**Quantity**|The quantity of the cross-sell item. You can change the quantity if the *Approve* action is selected in the Selection area. The column is read-only if the *Delete* action is selected.|
|**Effective Date**|The effective date of the cross-sell item. You can change the date if the *Approve* action is selected in the Selection area. The column is read-only if the *Delete* action is selected.|
|**Expiration Date**|The expiration date of the cross-sell item. You can change the date if the *Approve* action is selected in the Selection area. The column is read-only if the *Delete* action is selected.|
|**Relevance Score \(%\)**|The read-only relevance score of the cross-sell suggestion.|
