# Vehicle Types

Form ID: \(FS204200\)

You use this form to add, view, and edit the types of vehicles that your company uses.

## Form Toolbar

The form toolbar has only standard buttons.

## Summary Area

The Summary area of the form contains summary information about the vehicle type.

|Element|Description|
|-------|-----------|
|**Vehicle Type ID**|The identifier of the vehicle type.|
|**Description**|A brief description of the vehicle type.|

## Attributes Tab

On this tab, you can add, view, and modify the attributes to be listed \(if they are active\) for vehicles of this type on the [Vehicles](FS_20_36_00.md) \(FS203600\).

For an attribute to be added on this tab, it must first be defined in the system on the [Attributes](CS_20_50_00.md) \(CS205000\) form.
