# Physical Inventory Locked Items

Form ID: \(IN409000\)

**Attention:** This form is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

On this form, you can view the list of inventory items that have been added to all physical inventories in progress in a particular warehouse. The system locks \(or freezes\) location-item pairs—that is, particular inventory items in specific warehouse locations—when a physical inventory count containing these pairs is in progress. This means that a user cannot release an inventory document \(such as an inventory receipt or issue\) that includes a locked item at the specific location; they also cannot run a physical inventory count if it includes the locked items at the specific locations. In these cases, the system displays an error message. Users can open this form to view the list of locked items.

## Form Toolbar

The form toolbar has only standard buttons.

In this area, you select a warehouse in which physical inventory counts may be in progress. You can narrow the data to be displayed in the table by selecting an inventory item ID or a reference number of the physical inventory document.

## Table

In this table, the system lists the items that meet the criteria you have specified in the Selection area as follows:

-   If you have selected only the warehouse, the table lists items included in physical inventories of all types except *Full*. For physical inventories of the *Full* type, the system displays one aggregated row for all included items and a separate row for each excluded item.
-   If you have selected a reference number of a particular physical inventory, the table lists items included in this inventory.
-   If you have selected an inventory item, the table lists a row or rows for this item. \(An item can be included in multiple physical inventories in progress if the item is stored in multiple locations in the warehouse.\)

The table toolbar has only standard buttons.
