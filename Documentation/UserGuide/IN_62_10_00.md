# Physical Count Tags {#_c7bebc82-f45c-417b-ba77-634203111916 .reference}

Form ID: \(IN621000\)

**Attention:** This report is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

This report displays the physical count tags generated for the physical inventory. You run this report to preview and print the physical count tags you will use for the physical inventory.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameter to select the information to be displayed on the report:

-   **Reference Nbr.**: The reference number of the physical inventory for which you want to display physical count tags.
