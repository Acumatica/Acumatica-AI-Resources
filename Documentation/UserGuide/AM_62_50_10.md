# Production Ticket with Barcode {#_a38654cc-74db-46f3-8ad2-7534c2aefab9 .reference}

Form ID: \(AM625010\)

This report is the primary production paperwork report. It is used as a router and generally accompanies the production order or job around the shop floor. This report can be run for multiple production orders by using the [Print Production Orders](AM_51_10_00.md) form.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Order Type:** Select the particular order type to be displayed in the report. You can blank this box to remove the filter.
-   **Production Order**: A particular production order. You can select a single order or leave blank to print all open production orders.
