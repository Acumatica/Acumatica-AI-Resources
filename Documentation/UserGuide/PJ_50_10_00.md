# Assign Request for Information {#_623c16bc-8ff0-4ad9-977c-a942a5cc5d7e .reference}

Form ID: \(PJ501000\)

**Attention:** This form is available if the *Construction Project Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can assign owners to project issues if the assignment map is selected in the **RFI Assignment Map** box of the [Project Management Preferences](PJ_10_10_00.md#) \(PJ101000\) form. You create assignment maps on the [Assignment Maps](EP_20_50_10.md#) \(EP205010\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Command|Description|
|-------|-----------|
|**Process**|Initiates the assigning owners to the requests for information you have selected \(by using the unlabeled check boxes\) in the table.|
|**Process All**|Initiates the assigning owners to all requests for information in the table.|

## Table {#2 .section}

The table contains the list of all requests for information that are not closed. You can assign owners to all requests for information or only to those you select.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you can use to include the request for information in processing if you click **Process**.|
|**RFI ID**|The request for information, by its identifier.|
|**Summary**|The summary of the request for information.|
|**Status**|The status of the request for information.|
|**Reason**|The reason of the request for information creation.|
|**Priority**|The priority of the request for information.|
|**Answer Due Date**|The due date when the answer for the request for information has to be received.|
|**Class ID**|The identifier of the class to which the request for information is related.|
|**Business Account**|The business account who requested the information.|
|**Contact**|The contact of the business account.|
|**Owner**|The currently assigned owner.|
|**Creation Date**|The date when the request for information was created in the system.|
