# Create Manifest {#_1ea752d1-29e5-4fe9-85c4-87e9c3048058 .reference}

Form ID: \(SO506000\)

**Note:** This form is available only if the *Shipping Carrier Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to create shipping manifests required by some carriers. The shipping manifest is a printable document that contains the list of shipments to be delivered by the carrier.

**Note:** A shipping manifest for the ShipEngine carrier service cannot be processed if it includes shipments that have more than 500 packages. Such shipments should be split to reduce the number of packages.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Command|Description|
|-------|-----------|
|**Create**|Creates shipping manifests for selected shipments.|
|**Create All**|Creates shipping manifests for all shipments in the list.|

## Selection Area {#1 .section}

By using this area, you can specify the criteria of shipments which the system displays in the table below.

|Element|Description|
|-------|-----------|
|**Carrier**|The carrier for whom the shipment manifest will be created. This box is required.

 Only carriers with the *PX.EasyPostCarrier.EasyPostCarrier* or *PX.ShipEngineCarrier.ShipEngineCarrier* value specified in the **Plug-In** box on the [Carriers](CS_20_77_00.md) \(CS207700\) form can be selected in this box.

|
|**Shipment Date**|The date of the shipment. By default, the system inserts the current business date.|
|**Printing with DeviceHub**|Indicates whether a DeviceHub printer will be used to print the manifest.|
|**Printer**|Defines the printer for printing the manifest.|

## Table Columns {#2 .section}

|Column|Description|
|------|-----------|
|Selected|A check box you can select to indicate that a shipping manifest will be created for the shipment when you click **Process** on the form toolbar.|
|**Shipment Nbr.**|The reference number of the shipment. You can click this number to view the shipment on the [Shipments](SO_30_20_00.md) \(SO302000\) form.|
|**Customer**|The identifier of the customer specified in the shipment.|
|**Customer Name**|The description of the customer specified in the shipment.|
|**Ship Via**|The ship via code specified for the shipment in the **Ship Via** box \(the **Shipping** tab\) on the [Shipments](SO_30_20_00.md) \(SO302000\) form.|
