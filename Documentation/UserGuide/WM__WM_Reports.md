# Warehouse Management Reports {#_a2b2a798-d4c8-4a71-ac0d-48917357ff1b .concept}

The Acumatica ERP reports related to warehouse management provide information that can be useful for warehouse workers who perform automated operations using barcode scanners or mobile devices with barcode scanning support.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All reports related to warehouse management can be generated in different formats, including PDF and HTML, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
