# Managing Scenarios {#_313d450d-9210-4c37-83fb-1412b092c0fa .concept}

Some processes in Acumatica ERP require multiple tasks to be executed to complete the whole process. These include the processes of implementing Acumatica ERP functionality \(one-time processes\) and business processes performed in different functional areas, such as closing financial periods \(recurrent processes\).

The business process scenarios tool gives you the ability to simplify the execution of such complex processes. By using this tool, you can create a scenario that contains the list of tasks required for completing some process. By executing the scenario based on these tasks, you can control the execution of the whole process.

Each scenario has a hierarchical structure. You can create the tasks and subtasks, and specify the order of their execution \(if needed\), which may depend on the system configuration, your enabled features, and your business needs.

While configuring a scenario, you can apply the role-based approach by specifying an access role for each scenario. By using this approach, you can manage the access to every scenario, so that it can be accessed by only the users to which this role is assigned.

This chapter describes the functionality of the business process scenarios tool and provides details about using this tool by considering the example of a recurrent process that is performed in Acumatica ERP.
