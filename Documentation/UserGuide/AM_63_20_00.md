# Inventory Planning Display {#_9ad4369a-5a17-4c91-baa3-5abdb8b2dc81 .reference}

Form ID: \(AM632000\)

This report is a printable version of the [Inventory Planning Display](AM_40_00_00.md) \(AM400000\) form. It shows the planner exactly what needs to be purchased and what needs to be produced.

The items are sorted on the report by action date. Therefore, the items that need to be acted on immediately are listed at the top. The action date is the date the production order should be started or the purchase order placed. This action date is based on the lead times entered for those items in inventory.

The report does not contain parameters.
