# Prepare Dunning Letters

Form ID: \(AR521000\)

On this form, you can generate dunning letters \(letters of payment collection\) for customers that have unpaid and overdue invoices. The intervals between successive dunning letters of different levels are defined on the **Dunning** tab of the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR101000\) form. After you generate dunning letters by using the current form, you can review and process them further on the [Print/Release Dunning Letters](AR_52_20_00.md) \(AR522000\) form. For details on the settings involved, see [Dunning Process Setup: General Information](CreditPolicy_Dunning_Process_Setup_GeneralInfo.md).

The form is available if the *Dunning Letter Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the process of generating dunning letters for the selected records—those for which you have selected the unlabeled check boxes in the table.|
|**Process All**|Initiates the process of generating dunning letters for all the records in the table.|

## Table

The table contents depends on the option selected in the **Dunning Process** box on the **Dunning** tab of the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR101000\) form:

-   *By Customer*: The table lists the customer accounts that have at least one overdue document.
-   *By Document*: The table lists the overdue documents grouped by customer and by document dunning level. For instance, if a customer account has two overdue documents with different levels, the system will display two rows in the table. If a customer account has two documents with the same level, the system will group the documents into one row.

If the *Parent-Child Customer Relationship* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, in the table, a single row for a parent and its child customers is shown with the customer class of the parent customer and the balances and number of documents totaled from the documents of all these customers. When the system processes the documents of these customers, to populate the table and create dunning letters, the system uses the dunning levels configured for the customer class of the parent customer. Thus, the dunning levels configured for the child customers will be ignored. When one of these dunning letters is released, the system applies the dunning fee from the customer class of the parent customer.

The table toolbar has only standard buttons.
