# To Change a Ledger ID {#_92246c90-4cae-49b2-a815-2dae3c4fbda6 .task}

You can use the [Ledgers](GL_20_15_00.md) \(GL201500\) form to change the identifier of a particular ledger.

## To Change a Ledger ID {#section_qr2_mjv_vxb .section}

1.  Open the [Ledgers](GL_20_15_00.md) \(GL201500\) form.
2.  In the **Ledger ID** box, select the ledger whose identifier you want to change.
3.  On the form toolbar, click **Change ID**.
4.  In the **Ledger ID** box of the **Specify New ID** dialog box, which opens, specify the new identifier of the ledger, and click **OK**.
5.  On the form toolbar, click **Save** to save your changes.
