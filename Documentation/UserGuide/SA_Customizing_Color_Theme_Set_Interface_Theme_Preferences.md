# Color Theme: To Specify Theme Preferences

The following activity will walk you through the process of selecting the color theme for a tenant and selecting the theme to be used for an individual user account.

## Setting the Theme for a Tenant

To set the theme for a tenant, do the following:

1.  Open the [Site Preferences](SM_20_05_05.md) \(SM200505\) form.
2.  In the **General Defaults** section, in the **Interface Theme** box, select the needed theme.
3.  On the form toolbar, click **Save**.


The selected theme applies to all companies and branches in the tenant. It applies to users whose **Default Theme** setting on the [User Profile](SM_20_30_10.md) \(SM203010\) form is set to *Default*. Users see the selected theme after they refresh the current page or navigate to another page.


## Selecting an Individual Theme

Individual users can select a theme for their user accounts to override the theme selected for the tenant.

To select an individual theme, do the following:

1.  Open the [User Profile](SM_20_30_10.md) \(SM203010\) form.
2.  On the **General Info** tab \(Item 1 in the following screenshot\), in the **Personal Settings** section, in the **Default Theme** box, select one of the following options \(Item 2\):
    -   *Default*: The theme selected for the tenant on the [Site Preferences](SM_20_05_05.md) \(SM200505\) form. If the tenant theme is changed, the theme for your user account changes accordingly.
    -   *Dark*: The dark theme for your user account, overriding the theme selected for the tenant.
    -   *Light*: The light theme for your user account, overriding the theme selected for the tenant.
3.  On the form toolbar, click **Save** \(Item 3\).


The selected theme takes effect immediately.
