# Project Profit Analysis {#_8083950f-9f1e-40b2-ad0a-c711878a201a .reference}

Form ID: \(PM656000\)

**Note:** This report is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This report helps you to estimate the expected original profit of the selected project as the difference between the budgeted revenues and costs \(which are calculated based on the original budgeted values\) and the expected revised profit \(which is calculated based on the revised budgeted values\). The report also shows the following:

-   The project profit markup, which is calculated as the ratio of profit to cost
-   The original markup, which is based on the original budgeted values
-   The change order markup, which is based on the change order values
-   The revised markup, which is based on the revised budgeted values

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameter {#section_dj2_zwc_tmb .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Project**: The project whose profit and markups you want to review. You can select a project to view the report for this project, or leave the box blank to view the report for all projects. Projects with the *Active*, *Suspended*, and *Completed* status are available for selection.
-   **Customer**: The identifier of the customer for whom you want to view the report. Select a customer to view the profit and markups of projects related to this customer, or leave the box blank to view the report for projects of all customers.

    The list of customers available for selection may be limited based on the role or roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. In this case, the **Restrict Visibility To** box appears on the **Financial** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form. With the feature enabled, a customer is available for selection if one of the following is true:

    -   The **Restrict Visibility To** box is empty for the customer—that is, the customer’s visibility is not restricted.
    -   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer, and your user account has the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.
-   **Project Manager**: The project manager for which you want to view information. You can select a project manager to view the profit and markups of projects assigned to this project manager, or leave the box blank to view the report for projects of all project managers.
-   **Show Active Projects Only**: A check box that you select to include only active projects and their details in the report.
