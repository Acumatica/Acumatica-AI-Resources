# Trial Balance Detailed

Form ID: \(GL632500\)

This period-end report displays the balances for accounts, including subaccount details, for the selected period range.

Types of accounts are listed in the order specified on the [General Ledger Preferences](GL_10_20_00.md) \(GL102000\) form. Accounts of the same type are listed in alphanumeric order, and subaccounts are listed in alphanumeric order of segment values, starting with the leftmost segment.

See the *Report Parameters* section for a description of each parameter on the **Report Parameters** tab of the report form. For more information about using other elements on the report form, see [Reports](../InterfaceGuide/Report_Processing_Options.md).

## Report Size and Performance

This report calculates account balances while the report is being generated, so the generation time depends on the number of detail lines in the report and on the number of financial periods in the range. A page holds about 40 to 55 lines. The number of financial periods in the range affects the generation time as much as the page count does. A report of that covers a single period may be generated successfully at a page count that would cause a report for 12 periods to fail.

The following table shows what you can expect for reports of different sizes.

|Approximate Size of the Report|Approximate Line Count|What to Expect|
|------------------------------|----------------------|--------------|
|Up to 300 pages|About 15,000|The report is generated within a reasonable time.|
|300 to 800 pages|About 15,000 to 40,000|The report takes noticeably longer to generate, and on sites with limited memory, it may fail to be generated.|
|More than 800 pages|More than 40,000|The report may fail to be generated, even if the execution timeout and the memory allocated to the website have been increased.|

To keep the report to a manageable size and reduce its generation time, you can do any of the following:

-   Run the report for a single branch or company instead of all companies in the tenant.
-   Select the **Suppress Zero Balances** check box to exclude accounts that have no balances and no activity in the period range.
-   Specify a shorter range of financial periods.
-   Run the report for a single financial period first to see how many pages it produces, and then decide how wide a range of periods to use.
-   Run the [Trial Balance Summary](GL_63_20_00.md) \(GL632000\) report instead if you do not need balances by subaccount.

Alternatively, you can view account and subaccount balances on the [Account Details](GL_40_40_00.md) \(GL404000\) form and export the results to Excel.

## Report Parameters

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Company/Branch**: The company or branch for which you want to view information. You can select a company or make no selection to view information about all companies in the tenant.

    By default, the system inserts the company or branch selected on the Company and Branch Selection menu.

-   **Ledger**: The ledger to be reported on. You must select a ledger.

    By default, the actual ledger is selected.

-   **From Period**: The first financial period of the period range the report will cover. The list of periods available for selection contains all the periods defined in the system, including the closed ones. By default, the current financial period is selected.
-   **To Period**: The last financial period of the period range the report will cover. By default, the current financial period is selected.
-   **Suppress Zero Balances**: A check box that you select to remove from the report accounts that have all zero values for the beginning and ending balances, credits, and debits.

    If this check box is cleared, the accounts that have all zero values are shown in the report if at least one transaction has been posted to the accounts in the periods before the period for which the report is displayed.

-   **Use Master Calendar**: A check box that you select to use the financial periods from the master calendar. If the check box is cleared, the report will use the financial periods from the company calendar.

    This check box appears on the form only if the *Multiple Calendar Support* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) form.

    For details on running consolidated reports and inquiries, see [Consolidated Reports for Companies with Different Calendars](GL__CON_Consolidated_Reports_for_Companies_with_Different_Calendars.md).
