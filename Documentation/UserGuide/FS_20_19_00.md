# Service Areas {#_db06f16a-f18c-4733-b586-07f1ae89c59c .reference}

Form ID: \(FS201900\)

You use this form to create the service areas for which a branch location can provide a service. A service area is defined by the ZIP codes it contains. Also, you can use this form to add the staff members who can provide services to a determined geographical zone.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area { .section}

In this area, you can enter information for a new service area or select an existing one to view its settings.

|Element|Description|
|-------|-----------|
|**Service Area ID**|The identifier of the service area.|
|**Description**|A description of the service area.|
|**Country**|The country of the service area.|

## Employees Tab { .section}

On this tab, you can add and view the staff members of the *Employee* type who can provide services in the selected service area.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Employee ID**|The unique identifier of the staff member of the *Employee* type.|
|**Employee Name**|The name of the staff member related to the employee ID.|

## Postal Codes Tab { .section}

On this tab, you can add and view the ZIP codes that belong to the selected geographical zone.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Postal Code**|A ZIP code included in the selected service area.|
