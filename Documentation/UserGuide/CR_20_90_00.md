# Opportunity Classes {#_a693134c-6e77-47f1-a6ec-3fec4d23913f .reference}

Form ID: \(CR209000\)

On this form, you create and modify opportunity classes. By modifying the settings of an opportunity class, you can control some of the default behavior and settings of opportunities of the class \(such as how the owner is assigned to an opportunity of the class and whether activities assigned to the lead are copied to the associated opportunity of the class\). You can also define default settings that will be used for the creation of contacts and business accounts associated with an opportunity of the class.

Each opportunity class includes a list of attributes that will be used as additional elements for opportunities of the class. For each attribute, you can specify whether this attribute is required and what its position in the list of attributes for the class will be. When a user creates an opportunity of the class, these attributes will be among the elements for data entry. For more details, see [Managing Attributes and User-Defined Fields](CS__con_Attributes_and_User_Defined_Fields.md).

For each class, you can specify the relations between opportunity stages and probabilities of deal closure. You can rearrange the default order of predefined stages, modify the number of stages by adding or removing items, and adjust probabilities. For more information, see [Opportunity Management: Opportunity Stages](CRM_Sales_Managing_Opportunities_Stages.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

You use the elements in this area to create a new class to be used for opportunities or to select one of the existing classes to view or edit its settings.

|Element|Description|
|-------|-----------|
|**Opportunity Class ID**|The unique identifier of the opportunity class. An alphanumeric string of up to 10 characters can be used.|
|**Internal**|A check box that indicates \(if selected\) that the class is hidden from the Self-Service Portal users and only Acumatica ERP users can use it.|
|**Description**|A detailed description of the opportunity class.|

## Details Tab {#2 .section}

This tab contains elements that determine how opportunities of the class are to be processed and how the system assigns the default owner of an opportunity of the class.

|Element|Description|
|-------|-----------|
|**Default Owner**|An option that controls how the system determines the default owner of an opportunity of the class; it inserts the owner in the **Owner** box of the [Opportunities](CR_30_40_00.md) \(CR304000\) form \(Summary area\).

 You can select one of the following options:

 -   *Do Not Change* \(default\): The system leaves the box empty. If a user either inserts some value in the **Owner** box or leaves it empty, and then changes the class in the **Opportunity Class** box for this opportunity, the system will not change the initial value in the **Owner** box \(including a blank value\) for this opportunity.
-   *Creator*: The system fills in the username of the employee who created the current opportunity.
-   *Assignment Map*: The system fills in the owner based on the assignment map of the opportunity class, which is also specified in this section.
-   *From Source Entity*: If an opportunity has been created from another entity \(such as a lead\), the system copies the owner and workgroup \(if specified\) from the source entity.

 The user can override the default option in any opportunity.

|
|**Assignment Map**|The assignment map that is used to assign the default owner and workgroup to a newly created opportunity of this class on the [Opportunities](CR_30_40_00.md) \(CR304000\) form.

 This box is available only if the *Assignment Map* option is selected in the **Default Owner** box. If you specify an assignment map in this box, the system uses it instead of the assignment map specified in the **Opportunity Assignment Map** box on the **General** tab of the [Customer Management Preferences](CR_10_10_00.md) \(CR101000\) form.

 **Tip:** If the option in the **Default Owner** box of the current form is *Assignment Map* and no option has been selected in the **Assignment Map** box of this form, you cannot save the opportunity class, and the system displays an error message.

|

|Element|Description|
|-------|-----------|
|**Contact Class**|The identifier of the contact class that the system will insert as the default if a user creates a contact to be associated with an opportunity of the class by using the **Create Contact** or **Create Account** dialog box on the [Opportunities](CR_30_40_00.md) \(CR304000\) form. The system will insert this class identifier in the **Contact Class** box of either dialog box; the user can override it.

 If you specify a contact class in this box, the system uses it instead of any default contact class that has been specified in the **Default Contact Class** box on the **General** tab of the [Customer Management Preferences](CR_10_10_00.md) \(CR101000\) form.

|
|**Business Account Class**|The identifier of the business account class that the system will insert as the default if a user creates a business account to be associated with an opportunity of the class by using the **Create Account** dialog box on the [Opportunities](CR_30_40_00.md) \(CR304000\) form. The system will insert this class identifier in the **Business Account Class** box of the dialog box; the user can override it.

 If you specify a business account class in this box, the system uses it instead of any default business account class that has been specified in the **Default Business Account Class** box on the **General** tab of the [Customer Management Preferences](CR_10_10_00.md) \(CR101000\) form.

|

|Element|Description|
|-------|-----------|
|**Default Email Account**|The system email account to be used for communication with opportunities of the class.

 For emails to opportunities of the class, the system uses the system email account specified in this box if for the signed-in user, the **Default Email Account** box of the **Email Settings** tab of the [User Profile](SM_20_30_10.md) \(SM203010\) form is empty. \(If the box is filled in, the user's email account is used instead.\)

 If you specify a system email account for the class in this box, it is used instead of the value that is specified in the **Default Email Account** box of the [Email Preferences](SM_20_40_01.md) \(SM204001\) form.

|
|**Show Activities from Source Lead**|A check box that indicates \(if selected\) that activities on the **Activities** tab of the [Leads](CR_30_10_00.md) \(CR301000\) form for the source lead of an opportunity of the class are copied to the **Activities** tab of the [Opportunities](CR_30_40_00.md) \(CR304000\) form for this opportunity.

 By default, the check box is cleared.

|

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that the stage is active and may be used in opportunities of the class. At least one stage should be active for an opportunity class.

 If you clear the check box for a stage that has been used in any opportunity of the class, this stage becomes excluded from the list of available stages for opportunities of the class, but it still will be shown in reports.

|
|**Opportunity Stage**|The identifier of the opportunity stage.|
|**Name**|The display name of the stage.|
|**Probability**|The probability \(expressed as a percentage\) that the opportunity will result in a sale at this stage.|
|**Sort Order**|An integer that indicates the order in which the stage appears in the **Stage** box on the [Opportunities](CR_30_40_00.md) \(CR304000\) form for a particular opportunity of the class.|

## Attributes Tab {#3 .section}

You use the **Attributes** tab to associate attributes with the opportunity class—that is, to define the set of attributes for which the user can specify values for each opportunity of the class. You can define any attribute as being required for an opportunity of the class.

You can select any attribute that has been defined in the system. To define a new attribute, use the [Attributes](CS_20_50_00.md) \(CS205000\) form.

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that the attribute is available for all opportunities of the class.

 You can deactivate an obsolete attribute by clearing the check box. In this case, the deactivated attribute will no longer be displayed on the **Attributes** tab of the [Opportunities](CR_30_40_00.md) \(CR304000\) form for opportunities of the class, but all attribute values that have already been specified for existing records will still be stored in the database; thus, if the attribute is later reactivated, its values will become visible in the system again.

|
|**Attribute**|The name of the attribute, which is also a link you can click to view the settings of the attribute on the [Attributes](CS_20_50_00.md) \(CS205000\) form.|
|**Description**|A detailed description of the attribute.|
|**Sort Order**|A number that represents the order of the attribute in the list of attributes of the class.|
|**Required**|A check box that indicates \(if selected\) that the attribute value is required for an opportunity of the class.|
|**Internal**|A read-only check box that indicates \(if selected\) that the attribute is not available for Self-Service Portal users and that only Acumatica ERP users can use it.

 The state of the check box is copied from the [Attributes](CS_20_50_00.md) \(CS205000\) form.

|
|**Contains Personal Data**|A check box that indicates \(if selected\) that the system should treat the value of this attribute as personal data related to an opportunity of this opportunity class.

 The check box is selected or cleared when the attribute is defined on the [Attributes](CS_20_50_00.md) \(CS205000\) form. The state of the check box is then copied to each opportunity class that includes the attribute, as well as to the opportunity of this opportunity class.

 If access to personal data for an entity record, such as an opportunity, is restricted on the [Restrict Personal Data](GD_10_20_10.md) \(GD102010\) form and this check box is selected for attributes associated with this opportunity, access to personal data \(including specified attributes\) of this opportunity will be restricted for users. For more details, see [Handling Personal Data](GD__MNG_Handling_Personal_Data.md).

 The check box is displayed on the form if the *GDPR Compliance Tools* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Control Type**|The read-only control type of the attribute.

 This box contains one of the following options: *Text*, *Combo*, *Multi Select Combo*, *Lookup*, *Checkbox*, or *Datetime*. The option that is shown in the column is copied from the [Attributes](CS_20_50_00.md) \(CS205000\) form.

|
|**Default Value**|The default value of the attribute.|
