# CA Reversing Transactions {#_2a0ffd98-5d9c-4147-b452-386368da7cc3 .reference}

Form ID: \(CA659000\)

This report lists reversing transactions created for the same cash transaction on the [Cash Transactions](CA_30_40_00.md) \(CA304000\) form.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Tran. Type**: The transaction type for which you want to review reversing transactions: *Transfer Out*, *Transfer In*, *Expense Entry*, or *Cash Entry*.
-   **Reference Nbr.**: The reference number of the document for which you want to review reversing transactions.
