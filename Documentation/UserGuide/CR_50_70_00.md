# Release Cases {#_c3e683bf-4182-44dc-b87c-7ad5931c34bb .reference}

Form ID: \(CR507000\)

You can use this form to select resolved cases for release and further billing.

This form is available only if the *Case Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

A case is displayed on the form if it does not have the *Released* status and the following settings are specified on the **Additional Info** tab of the [Cases](CR_30_60_00.md) \(CR306000\) form:

-   The **Active** check box is cleared
-   The **Billable** check box is selected

For details, see [Managing Cases](CRM_Support_Managing_Cases_Mapref.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Releases the cases you have selected for further billing.|
|**Process All**|Releases all the cases in the table for further billing.|

## Selection Area {#1 .section}

By using the elements in this area, you can filter the case activities to be viewed in the table by case class, business account class, business account, and contract.

|Element|Description|
|-------|-----------|
|**Case Class**|The case class for which you want to view cases. You can leave the box blank to view the cases of all case classes.|
|**Business Account Class**|The customer class for which you want to view cases; these classes are defined on the [Customer Classes](AR_20_10_00.md) \(AR201000\) form. You can leave the box blank to view the cases of all customer classes.|
|**Business Account**|The identifier of the business account for which you want to view cases. You can leave the box blank to view the cases of all customers.|
|**Contract**|The identifier of the contract for which you want to view case activities. You can leave the box blank to view the cases related to all contracts.

 The list of values may be limited based on the current user's access role and the customer's visibility. You can select a contract of a customer whose settings permit the use of branch, company, or company group that contains the branch to which the user's role is assigned \(the **Restrict Visibility To** box on the **Financial** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form contains this branch, company, company group, or is empty\).

 If the *Multiple Base Currencies* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and a contract is specified for the case, when you click **Process** on the form toolbar to release the case and create contract usage, the system verifies whether the current branch has the same base currency as the bill-to customer specified for the contract. If these base currencies are different, the system displays an error message.

 If the contract has a bill-to customer without a base currency—that is, if the customer has been extended from a branch—the case can be released regardless of the current branch.

|

## Table {#2 .section}

This table contains the list of cases that match the criteria you specified in the Selection area.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Selected|An unlabeled check box that you select to include the activity for release when you click **Process**.|
|**Case ID**|The unique reference number of the case.|
|**Subject**|The subject of the case.|
|**Contract**|The contract to which the case is related.|
|**Billable Time**|The number of billable work hours spent on the case.|
|**Billable Overtime**|The number of billable overtime hours spent on the case.|
