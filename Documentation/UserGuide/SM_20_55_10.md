# Audit {#_195ffb01-c0eb-4b4d-a48f-6b0c04f1a3ca .reference}

Form ID: \(SM205510\)

You can use this form to configure, turn on, and turn off the auditing of specific forms.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area { .section}

You use this area to select a form for auditing and to specify summary data about auditing of this form.

|Element|Description|
|-------|-----------|
|**Screen Name**|The name of the form \(screen\) for which auditing is configured.|
|**Description**|The description of auditing of this form.|
|**Show Fields**|An option that determines which fields of the database table will be displayed in the **Fields** table for all database tables. You select one of the following options for all database tables in the **Show Fields** column in the **Tables** table:-   *All Fields*: All fields of the selected database table, including hidden fields, will be shown in the **Fields** table.
-   *UI Fields*: Only the visible fields \(that is, those shown on the user interface\) of the selected database table will be displayed in the **Fields** table.

You can select one of these options for each table individually as well.

|
|**Active**|A check box that you select to turn on auditing of the form when you click **Save**. Clear the check box and click **Save** to quickly turn off auditing of the form.|

## Tables Table { .section}

This table contains the database tables associated with the selected form. You can turn on or off auditing of each database table individually.

|Column|Description|
|------|-----------|
|**Active**|A check box you select to audit the database table.|
|**Table**|The name of the database table you want to audit.|
|**Description**|A description of the database table you want to audit.|
|**Show Fields**|An indicator of which fields of the database table will be displayed in the **Fields** table. Select one of the following options:

 -   *All Fields*: All fields of the selected database table, including hidden fields, will be shown in the **Fields** table.
-   *UI Fields*: Only the fields of the selected database table shown on the user interface will be shown in the **Fields** table.

|

## Fields Table { .section}

In this table, you can view the fields of the selected database table. You can turn on or off auditing of each field individually.

|Column|Description|
|------|-----------|
|**Active**|A check box you select to audit the field.|
|**Field**|The name of the field in the selected database table.|

## Update History Dialog Box { .section}

If auditing is turned off for a form and you click **Settings** &gt; **Audit History** on the form title bar, the **Update History** dialog box opens instead of the **Audit History** page. In this dialog box, you can see information about the creation and last modification of the selected record. You can click **Enable Field Level Audit** to turn on auditing of the form.

|Element|Description|
|-------|-----------|
|**Created By**|The user who created the selected record.|
|**Created Through**|The ID of the form used to create the selected record.|
|**Created On**|The date and time when the selected record was created.|
|**Last Modified By**|The user who made the last modifications to the selected record.|
|**Last Modified Through**|The ID of the last form used to modify the selected record.|
|**Last Modified On**|The date and time of the last modification to the selected record.|
|The dialog box has the following buttons.|
|**Enable Field Level Audit**|Opens the [Audit](../Shared/../UserGuide/SM_20_55_10.md) \(SM205510\) form for the selected form.|
|**Cancel**|Closes the dialog box.|
