# Compliance by Vendor {#_3a28a8db-3c92-4ff7-8ca0-554565cd412f .reference}

Form ID: \(CL644000\)

**Note:** This report is available only if the *Construction* and *Construction Project Management* features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

By using this report, you can review compliance items matching the report parameters in the following three categories grouped by vendor:

-   Non-Project/Commitment Items
-   Project/Non-Commitment Items
-   Project/Commitment Items

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Date**: The date for which the report is shown. By default, the current business date is selected.
-   **Document Status**: The status of the documents to be displayed in the report. You can select the status to view only compliance items of this status, or leave the box blank to view the report for all statuses.
-   **Vendor**: The vendor for which you want to view compliance information. You can select the vendor to view only compliance items created for this vendor, or leave the box blank to view the report for all vendors.
-   **Project**: The project for which you want to view compliance information. You can select the project to view only compliance items related to this project, or leave the box blank to view the report for all projects.
-   **Project Status**: The status of the projects for which you want to view compliance information. You can select one of the following statuses to view only compliance items related to this project status:

    -   *In Planning*
    -   *Active* \(default\)
    -   *Completed*
    -   *Canceled*
    -   *Suspended*
    -   *Pending Approval*
    -   *Pending Upgrade*
    Leave the box blank to view the report for all project statuses.

-   **Project Task**: If the project is selected in the **Project** box, you can select the task for which you wan to view the report. You can leave this box blank to view the report for all project tasks.
-   **Compliance Doc Type**: The type of compliance documents for which you want to view the report. You can select one of the following types:

    -   *Certificate*
    -   *Insurance*
    -   *Lien Waiver*
    -   *Notice*
    -   *Status*
    You leave this box blank to view the report for all types.
