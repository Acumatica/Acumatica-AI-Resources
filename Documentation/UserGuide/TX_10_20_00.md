# Tax Providers {#_e56ee66b-7ff5-4322-b3bc-bdd989a6931d .reference}

Form ID: \(TX102000\)

On this form, you can set up and activate the integration between Acumatica ERP and external tax providers, such as the AvaTax service by Avalara or Vertex Tax Calculation. For an overview of the built-in tax provider functionality, see [Integrating Acumatica ERP with Avalara Avatax](config_Avalara_Integration_Mapref.md) and [Integrating Acumatica ERP with Vertex Tax Provider](config_Vertex_Integration_Mapref.md).

**Tip:** This form is available only if the *External Tax Calculation Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

Acumatica ERP uses the integration with external tax providers for calculating sales taxes on transactions in the United States. Before you configure this integration, you should get an appropriate license from Avalara or another tax provider and configure your organization's account on Avalara's or another tax provider's website.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Test Connection**|Tests the connection to the selected tax provider's website and displays a message indicating the success or failure of the connection.|

## Summary Area {#1 .section}

You use the Summary area of the form to specify the summary settings of the tax provider.

|Element|Description|
|-------|-----------|
|**Provider ID**|The ID of the external tax provider.|
|**Description**|The description of the external tax provider.|
|**Plug-In \(Type\)**|The type of the tax provider's plug-in. When you select a value in this box, the parameters of the selected plug-in are added to the **Plug-In Parameters** table on this form.|
|**Default Tax Calculation Mode**|The provider's default tax calculation mode The following options are available:-   *Gross*: Taxes are included in the price \(inclusive taxes\).
-   *Net*: Taxes are not included in the price \(exclusive taxes\).

|
|**Active**|A check box that you select to activate integration with the tax provider.|

## Plug-In Parameters Table { .section}

In this table, you specify the values of the parameters for the selected tax provider. This table is populated with parameters based on the plug-in you selected in the **Plug-In \(Type\)** box.

|Column|Description|
|------|-----------|
|**ID**|The ID of the parameter of the plug-in.|
|**Description**|The description of the parameter of the plug-in.|
|**Value**|The value of this plug-in parameter.|

## Company Code Mapping Table { .section}

In this table, you map the branches of your organization to the companies you have configured on the tax provider's website by using your account with this tax provider. You can create a company for each branch and configure separate reporting for all or some of the companies, depending on your tax reporting needs. For details on the configuration of companies and available tax reporting options, refer to the documentation on the tax provider's website.

|Column|Description|
|------|-----------|
|**Branch**|The ID of a branch in your organization, as specified on the [Branches](CS_10_20_00.md) \(CS102000\) form.|
|**Company Code**|The company code of the company you created for this branch on the tax provider's website by using your account.|
