# Equipment Management Reports {#_27c6c21e-9a60-4f4e-90b0-bcedf75b4faf .concept}

With the Acumatica ERP reports related to equipment management, you can promptly get detailed information about service contracts and equipment. You can also analyze the contract-related and equipment-related data by various criteria, and track service operations for different customers and locations. If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All equipment management reports can be generated in different formats, including PDFs, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
