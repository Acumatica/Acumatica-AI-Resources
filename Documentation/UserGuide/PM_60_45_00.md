# Project Quote {#_91174336-b7ba-4db1-8134-e36712bcce11 .reference}

Form ID: \(PM604500\)

This report is available only if the *Project Quotes* group of features is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

With this report form, you can display the selected quote as a ready-to-print document. You can search for or navigate to this report form directly. You can also invoke this form by clicking **Print** on the form toolbar of the [Project Quotes](PM_30_45_00.md) \(PM304500\) form, or by selecting a project quote on the **Quotes** tab of the [Opportunities](CR_30_40_00.md) \(CR304000\) form and clicking **Print Quote** on the table toolbar.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

You use the following parameter to select the information to be displayed on the report:

-   **Quote Number**: The reference number of the document. You must select a document.
