# Refresh Currency Rates {#_71a76164-b14c-4554-a208-3b229dd7570c .reference}

Form ID: \(CM507000\)

On this form, you can refresh the currency rates from the online service for any currencies you select on the specified effective date.

**Attention:** The table on the form shows \(in the **From Currency** column\) only currencies for which the online currency rate refreshing functionality is enabled—that is, the currencies whose currency rate types have the **Refresh Online** check box selected on the [Currency Rate Types](CM_20_10_00.md) \(CM201000\) form.

The system uses the [Open Exchange Rates API](https://openexchangerates.org) service to get the updated currency exchange rates.

## Form Toolbar {#1 .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the process of refreshing the currency rates for the selected currencies in the table \(that is, those for which you have selected the unlabeled check boxes\).|
|**Process All**|Initiates the process of refreshing the currency rates for all currencies listed in the table.|

## Selection Area { .section}

In this area, you need to select the **To Currency**, which is the target currency for which rates will be shown in the table below, and the effective date on which the currency rates will be updated. Optionally, you can select a rate type to further filter the records to be listed in the table.

|Element|Description|
|-------|-----------|
|**To Currency**|The ID of the target currency, for which the rates of the source currencies will be shown in the table.|
|**Currency Effective Date**|The effective date for the currency rate. By default, the current business date is specified, but you can select a past business date.**Attention:** Before it requests the effective currency rates, the system adjusts the selected date based on the user's time zone.

|
|**Rate Type**|The rate type according to which the records are filtered in the table. By default, this box is empty and the system lists active currency rates with their rate types as long as the online rate synchronization functionality has been turned on for the rate type on the [Currency Rate Types](CM_20_10_00.md) \(CM201000\) form. You can select a rate type or leave this box blank to show all the currencies of all the rate types that can be updated.

|

## Table {#2 .section}

This table contains the list of list of source currencies for which rates have been defined for the selected target currency \(and that meet other selection criteria you have specified\). The currency rates appear in the table after the refresh currency process has been run.

|Column|Description|
|------|-----------|
|Included|A check box that you select to refresh the currency rate for the **From Currency**-**To Currency** pair when you click **Process**. To select all the pairs listed on the page, click the check box in the table header.|
|**From Currency**|The currency whose exchange rate is shown in the **Currency Rate** column in respect to the currency selected as the **To Currency**.|
|**Currency Rate Type**|The currency rate type for the currency in this row.|
|**Currency Rate**|The currency rate that indicates how many units of the quote currency \(**To Currency**\) equate to one unit of the currency of the current row. This rate is downloaded by using the currency rate update service and has six decimal places.

 For details, see [Configuration of Rate Types and Rates: Ability to Refresh Rates](../ImplementationGuide/config_Multicurrency_Configuring_Rates_Refresh_CurrencyRates.md).
