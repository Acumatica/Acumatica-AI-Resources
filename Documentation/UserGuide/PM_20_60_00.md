# Rate Tables {#_09894686-e56f-4f33-8e95-2b6e9f6a1752 .reference}

Form ID: \(PM206000\)

You use this form to specify particular rates for different sequences of rate tables. For details on using rates, see [Billing Rules: General Information](Billing_Rules_GeneralInfo.md). For details on configuring rate tables, see [Billing Rates: General Information](Billing_Rates_GeneralInfo.md).

**Tip:** Do not confuse the term *rate* as it applies to rate tables with other rates in Acumatica ERP, such as employee hourly rates or equipment run rates. In the context of rate tables, a rate is a parameter \(*@Rate*\) that you can use in billing and allocation rules as a multiplier, addend, or constant.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

In this area, you can select a rate table code, rate type, and rate table sequence, as well as the applicable rate code, so that you can specify particular rates on the **Rate** tab.

|Element|Description|
|-------|-----------|
|**Rate Table Code**|The rate table code, which is initially created on the [Rate Table Codes](PM_20_42_00.md) \(PM204200\) form.|
|**Rate Type**|The rate type for which you want to define rates. Rate types, which are defined on the [Rate Types](PM_20_41_00.md) \(PM204100\) form, are associated with particular steps of the billing or allocation rules.|
|**Rate Table Sequence**|The sequence of the rate table code for which you want to define rates. You define the factors that can affect rate selection within the sequence on the [Rate Table Sequences](PM_20_50_00.md) \(PM205000\) form.|
|**Rate Code**|The rate code for which you want to define rates. You can create a new rate code on the fly by typing its identifier in this box. By using multiple rate codes with one sequence, you can specify for this sequence as many different rates \(for different sets of particular factors defined by the sequence\) as there are rate codes. For more information, see [Billing Rates: General Information](Billing_Rates_GeneralInfo.md).|
|**Description**|The brief description of the rate code.|

## Rate Tab { .section}

On this tab, you add lines for the specific rates to be used as a *@Rate* parameter value, as well as the date ranges when these rates are effective. You can specify multiple date ranges for a single rate.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Start Date**|The start date of the range when the rate is effective.|
|**End Date**|The end date of the range when the rate is effective.|
|**Rate**|The value of the rate for the selected rate table sequence and rate code. When you bill a project or run allocation, the system assign this value is assigned the *@Rate* variable. The assigned value is used in the formulas of billing rule steps and allocation rule steps. The *@Rate* value can be used in formulas as a multiplier, a constant, or an addend. For more information, see [Billing Rates: Rate Selection Rules](Billing_Rates_Rate_Selection.md).|

## Projects Tab { .section}

On this tab, you add the projects for which the particular rate value is applied. This tab appears only if the rate table sequence includes the project as a rate factor \(that is, a type of factor to which this rate is applied\); the types of factors are specified on the [Rate Table Sequences](PM_20_50_00.md) \(PM205000\) form.

**Attention:** A rate application condition is defined as follows: Conditions on particular projects, tasks, items, employees, or account groups are joined by OR operators, while conditions on different types of factors are joined by AND operators. For instance, suppose that a special rate is valid for tasks *1*, *2*, and *3* of Project *1* and Project *2* if employee *JOHN* or *JACK* is involved. The resulting condition is expressed as follows.

```
((Project=Project1) OR (Project=Project2))AND  
((Employee=JOHN) OR (Employee=JACK))AND
((Task=Task1) OR (Task=Task2)OR(Task=Task3))
 
```

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Project**|The project for which you want to apply the rate specified on the **Rate** tab.|
|**Description**|The description of the project, as specified in the project’s settings.|
