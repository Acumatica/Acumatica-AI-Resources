# Upload from Teams {#_26f8eabd-c7fc-40d5-8386-c713bba00fa5 .reference}

Form ID: \(SM404000\)

You use this form to upload to the record the files that have been shared with you in Microsoft Teams. The form opens when you click **Upload from Teams** in the **Files** dialog box.

This form is available in the system only if the *Teams Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

**Tip:** You cannot open the form by typing its ID in the Search box.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Upload &amp; Close**|Uploads the selected files and closes the form. This button becomes available when you select a file or files in the table.|

## File Selection Area {#1 .section}

You can use the settings in this area to narrow the range of files listed in the table. The area contains the following elements.

|Element|Description|
|-------|-----------|
|**File Name**|The name of the name of the file to be uploaded. You can also type any part of the name and select the name from the list of names that match your search string.|

## Table {#2 .section}

You use the table to select files that you want to upload. The table contains the following elements.

|Column|Description|
|------|-----------|
|Selected|A check box that you select to indicate that the file should be uploaded.|
|**File Name**|The name of the shared file.|
|**Last Date**|The date when the shared file was last modified.|
|**Picture**|The picture of the user who shared the file.|
|**Shared By**|The name of the user who shared the file.|
