# To Turn On Validation of Translations {#_dccf6db9-54d7-45d5-818f-67f123375581 .task}

To make sure you have translated all strings on forms, you can turn on validation of the translations by using the [System Locales](SM_20_05_50.md) \(SM200550\) form. With validation turned on for a locale, when you sign in with the language corresponding to the locale and open the forms whose translation you want to review, you can see the warnings about the untranslated strings. For more information, see [Translation Process](SM__con_Translation_Process.md).

## To Turn On Validation of Translations { .section}

1.  Open the [System Locales](SM_20_05_50.md) \(SM200550\) form.
2.  To display the **Show Validation Warnings Column** which is hidden by default, use the **Column Configuration** dialog box.
3.  In the **Show Validation Warnings** column, select the check boxes for the locales that correspond to the languages whose translations you want to be able to validate.
4.  On the form toolbar, click **Save**.
