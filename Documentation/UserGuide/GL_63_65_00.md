# Cash Flow {#_3b04587e-dc23-4252-9d8d-74453c4e619e .reference}

Form ID: \(GL636500\)

This report displays the cash flow statement of your company.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Ledger**: The ledger to be reported on. You must select a ledger.
-   **Start Financial Period**: The first financial period of the period range the report will cover. You must select a period.

    By default, the current financial period is selected.

-   **End Financial Period**: The last financial period of the period range the report will cover. You must select a period.

    By default, the current financial period is selected.
