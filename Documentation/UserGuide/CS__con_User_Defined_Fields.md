# User-Defined Fields {#_96dd287d-b37f-4f23-b401-b3122cf8a0a1 .concept}

The functionality of attributes is not available for all entities. For some of these entities, your organization may want to add user-defined fields directly to their corresponding data entry forms. Also, attributes can be added as boxes to an additional tab \(the **User-Defined Fields** tab\) of a data entry form.

If you add user-defined fields, the original information of a record is displayed on the **Document** tab of the applicable form, and the added user-defined fields are displayed on the **User-Defined Fields** tab.

## User-Defined Fields { .section}

You use the [Attributes](CS_20_50_00.md) \(CS205000\) form to create new attributes that will serve as the user-defined fields, or you can use attributes already defined in the system. To add an attribute as a user-defined field to a data entry form, you need access to the **Customization** menu on the form toolbar; this access is provided by the *Customizer* user role. For details, see [To Add User-Defined Fields to a Form](Admin_HOW_AddUserField.md).
