# External Payment Processor

Form ID: \(AP205500\)

You use this form to create a payment processor and specify its settings, such as companies, users, and funding accounts.

**Attention:** You can create only one active BILL payment processor and one active AvidXchange payment processor on this form. An active payment processor has the **Active** check box selected in the Summary area.

You also use this form to onboard companies to BILL by using API calls and a widget.

Users assigned to the *Administrator* and *AP Admin* roles have the *Delete* access rights to this form. Users assigned to the *AP Clerk*, *AP Viewer*, and *AcumaticaSupport* roles have the *View Only* access rights. These users cannot perform any action, click any button in the left or right pane, or on any tab.

This form appears in the system if the *BILL Integration* or *AvidXchange Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

**For Production Use**

</td><td>

A check box that indicates \(if selected\) that the payment processor is configured for production use. If this check box is cleared, payment requests are sent to the BILL or AvidXchange sandbox environment.

 If this check box is selected, the system displays a banner about using a live production environment. The banner appears only if a valid license has been applied on the [Activate License](SM_20_15_10.md) \(SM201510\) form.

 **Attention:** If you select this check box while the license is invalid, the system will not display the warning banner but will save the check box state. If the license becomes valid later, the processor will be active for production use with no banner or notification.

 This check box becomes unavailable as soon as the **Onboarding Status** box is filled in.

</td></tr><tr><td>

**Bill Upload Tag**

</td><td>

A tag that identifies bill scans. When a value is selected in this box, only AP document files with the selected tag are uploaded to BILL during payment processing. The max. allowed file size is 6 MB.

 When recognition runs on the [Incoming Documents](AP_30_11_10.md) \(AP301110\) form and a tag has been selected in the current box, the system automatically adds the tag to the file after the AP document is created and the file is attached.

</td></tr><tr><td>

**Upload Untagged Single File**

</td><td>

A check box that indicates, if selected, that a single file will be uploaded if an AP document has only one attached file without a tag.

</td></tr><tr><td>

**Onboarding Status**

</td><td>

The status of the enrollment application of your organization in AvidXchange. AvidXchange maintains this status; the system displays the status it received the last time you clicked **Onboard Organization** or **Refresh** on the form toolbar. This box is read-only, and it is empty until the enrollment has been started.

 The status can be one of the following:

 -   *Draft*: The application has been created with partial data about the organization. AvidXchange uses this status only for partner enrollment flows.
-   *New*: AvidXchange has notified the organization about the application.
-   *In Progress*: The application is being completed in the AvidXchange portal.
-   *Under Review*: AvidXchange has flagged the data of the application for review.
-   *Completed*: AvidXchange has approved the data of the application. The activation steps have not been completed yet.
-   *Enrolled*: AvidXchange has completed all the activation steps for the organization. The organization can be used for payments.
-   *Expired*: The application was not completed within the lifetime AvidXchange defines for an application.
-   *Rejected*: AvidXchange has reviewed the data of the application and rejected it.
-   *Canceled*: The organization has canceled the application.

 If the status is *Expired*, *Rejected*, or *Canceled*, the application can no longer be continued. To enroll the organization, you must create another payment processor.

</td></tr><tr><td>

**Organization**

</td><td>

The name of the organization in AvidXchange, which was specified in the **Organization Name** box of the **Onboard to AvidXchange** dialog box when the enrollment was started. This box is read-only. If the name has been changed in AvidXchange, the system updates the box when you click **Refresh** on the form toolbar.

</td></tr><tr><td>

**Tenant ID**

</td><td>

The identifier of your organization's tenant in AvidXchange, which the system receives from AvidXchange when the enrollment application is created. This box is read-only. You might need this identifier when you contact AvidXchange support.

</td></tr></tbody>
</table>

## Left Pane: Companies Table

This table lists all companies that have been added to the selected payment processor. The table displays only the companies to which the current user has access in Acumatica ERP.

This table appears on the form only if *BILL* is selected in the **Plug-In** box.

<table id="_4ed316ea-ed02-49ba-9063-59f7ef4c7298"><thead><tr><th>

Button

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Onboard**

</td><td>

Onboards the selected company. This button is available if a company is selected in the table.

 Once you click this button, the system does the following:

 1.  Creates a BILL organization by using an API call to BILL. The system saves the organization ID from the response to the database and maps the organization to the selected company.
2.  Creates a BILL user by using an API call to BILL. The system saves the user ID from the response to the database and maps the new BILL user to the current user in Acumatica ERP.
3.  Starts the **Onboarding Organization** widget. You can use this widget to enter the detailed address and other info, register the user's phone number and verification code received by SMS, and create one funding account under the organization.

 Once the onboarding is complete, the system creates a webhook for the company.

</td></tr><tr><td>

**Create Webhook**

</td><td>

Creates a webhook for a company that was onboarded but not subscribed to a webhook. This button is available if the selected company has the check box in the **Onboarded** column selected.

 Once you click this button, the system creates a webhook on the [Webhooks](SM_30_40_00.md) \(SM304000\) form and fills in its name in **Webhook** column.

</td></tr><tr><td>

**Delete Webhook**

</td><td>

Deletes the webhook for the selected company. This button becomes available if the company has been subscribed to a webhook.

 Once you click this button, the system does the following:

 1.  Unsubscribes the webhook from the organization ID by using an API call to BILL.
2.  Empties the webhook ID and subscription ID in the BILL organization that is mapped to the selected company. The **Webhook** column of the table becomes empty for the company.
3.  Deletes the webhook and the history related to it.

</td></tr></tbody>
</table>

|**Company Name**|The full company name in Acumatica ERP.|
|**Onboarded**|A check box that indicates \(if selected\) that the company has been onboarded.|
|**Webhook**|The name of the webhook, is the concatenation of the external payment processor ID and the company ID.|
|**Webhook Activated**|A check box that indicates \(if selected\) that the webhook for the company is active. This check box is read-only and displays the state of the **Active** check box for the webhook on the [Webhooks](SM_30_40_00.md) \(SM304000\) form.|

## Funding Accounts Tab for AvidXchange

On this tab, you can add the funding accounts \(the bank accounts you want to pay from\), onboard them in AvidXchange, and map each of them to a cash account in Acumatica ERP. You can add a funding account at any time, but a funding account can be registered only after the enrollment of the organization has been started.

Above the table, the system displays a reminder to ask your bank to allow ACH debits from the authorized originators of AvidXchange; otherwise, the debits can fail.

This tab appears on the form only if *AvidXchange* is selected in the **Plug-In** box.

**Onboard Account**

</td><td>

Registers the funding account selected in the table with AvidXchange. When you click this button, the system saves the table and sends the bank details of the selected row to AvidXchange. If the registration succeeds, the status of the funding account changes from *Pending Onboarding* to *Pending* or *Active*. If it fails, the status remains *Pending Onboarding* and the system displays an error message.

 This button is available if you have selected a row whose **Status** column contains *Pending Onboarding*.

 The system displays an error message in any of the following cases:

 -   The enrollment of the organization has not been started yet.
-   The **Onboarding Status** box contains *Under Review*, *Expired*, *Rejected*, or *Canceled*.
