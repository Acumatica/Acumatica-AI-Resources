# Generate Staff Schedules {#_f43242a2-6b31-47a2-89e4-d4778823570f .reference}

Form ID: \(FS500400\)

By using this form, you can generate or renew a staff member's schedule in a specific period of time based on the staff member's schedule rule, which is created on the [Staff Schedule Rules](FS_20_20_01.md) \(FS202001\) form.

## Form Toolbar { .section}

The form toolbar includes standard and form-specific buttons. The form-specific buttons are listed below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the process of generation staff schedules for the selected schedule rules.|
|**Process All**|Initiates the process of generation staff schedules for all listed schedule rules.|

## Selection Area { .section}

By using the elements in this area, you can filter the staff member's schedule rules that will be displayed on the **Schedules** tab, and you can define the period of time when the schedule will be active in the system.

|Element|Description|
|-------|-----------|
|**Employee Name**|The name of the staff member for whom you want to view the schedule rules.|
|**Branch**|The identifier of the branch for which you want to view the schedule rules.|
|**Branch Location**|The identifier of the branch location for which you want to view the schedule rules.|

|Element|Description|
|-------|-----------|
|**Generate Up To**|The end date of schedule generation. The schedule will be active from the start date specified for the schedule on the [Staff Schedule Rules](FS_20_20_01.md) \(FS202001\) form until the date specified in this box. By default, the current business date is selected.|

## Schedules Tab { .section}

The table contains the list of schedule rules that match the criteria specified in the Selection area. You can process all the rules by invoking **Process All** or select the rules you want to generate and click **Process**.

The table toolbar includes only standard buttons.

|Column|Description|
|------|-----------|
|**Included**|A check box that you can use to select the schedule for generation.|
|**Staff Schedule Nbr.**|The unique identifier of the schedule rule related to the staff member.|
|**Description**|A description of the staff schedule rule.|
|**Staff Member**|The unique identifier of the staff member.|
|**Employee Name**|The name of the staff member.|
|**Schedule Type**|The type of the schedule, which is *Availability* or *Unavailability*.|
|**Start Date**|The date when the staff member can start to perform services \(according to the contract\) and the schedule is active.|
|**End Date**|The last date when the schedule is active.|
|**Start Time**|The time when the staff member can start to perform services and the schedule is active.|
|**End Time**|The time up to which the schedule is active.|
|**Recurrence Description**|The description of the recurrence setting of the staff member schedule rule.|
|**Last Generated Schedule**|The last time the schedule was generated.|

## Run History Tab { .section}

The table contains the history of generated schedules.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Generation ID**|The identifier of the generation process.|
|**Up to Date**|The last day when the schedules generated during the generation process are active in the system.|
|**Generation Date**|The date when the generation process took place.|
