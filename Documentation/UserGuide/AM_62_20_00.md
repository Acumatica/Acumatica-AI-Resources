# Production Batch Register

Form ID: \(AM622000\)

This report lists all of the labor and material batches in detail.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Doc Type**: Leave blank for all or select one of the following: Move, Labor, Material, WIP Adjustment, or Cost.
-   **Batch Nbr:** Leave blank for all or select a specific batch number. The selector will only show batches for the document type selected.
