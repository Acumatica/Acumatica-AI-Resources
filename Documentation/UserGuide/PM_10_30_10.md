# Restriction Groups by Account Group

Form ID: \(PM103010\)

On this form, you can view the restriction groups that contain the account group you select. You can also change the visibility of project transactions with particular account groups in the system by including this account group in other restriction groups or excluding it from groups that currently contain it.

**Attention:** You can create restriction groups with account groups for managing the visibility of project transactions by using the [Project Transaction Visibility by Account Group](PM_10_30_00.md) \(PM103000\) form.

For more information on restriction groups, see [Restriction Groups in Acumatica ERP](SM__con_Overview_of_Restriction_Groups.md).

## Form Toolbar

The form toolbar has only standard buttons.

## Table

In this table, you can view the full list of restriction groups in the system, along with the basic settings of each group. The check box in the unlabeled Included column is selected for each group that contains the account group specified in the Selection area. You can select and clear these check boxes to change the membership of the account group in restriction groups.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that indicates \(if selected\) that the selected account group is included in the restriction group.|
|**Restriction Group Name**|Read-only. The name of the restriction group.|
|**Restriction Group Description**|Read-only. The description of the restriction group.|
|**Active**|Read-only. A check box that indicates \(if selected\) that the restriction group is active. The system does not enforce restrictions imposed by inactive groups.|
|**Restriction Group Type**|Read-only. The type of the restriction group: *A*, *A Inverse*, *B*, or *B Inverse*. For more information, see [Types of Restriction Groups](SM__con_Types_of_Restriction_Groups.md).|
