# Calendar Preferences {#_400107bc-4a63-4969-aa7e-1840a629381c .reference}

Form ID: \(FS100500\)

You use this form to customize the visibility options of the user interface elements on the calendar board forms. On this form, you can specify the number of columns that will be shown in the tables on the **Service Orders** and **Unassigned Appointments** tabs of the calendar board forms, and define the order of these columns.

On this form, you can specify the list of the fields that will be shown in the appointment boxes on the calendar dashboards, define the order of these fields, and set up a custom icon next to each field of the appointment box.

## Form Toolbar { .section}

The form toolbar includes only standard buttons.

## Status Color Tab { .section}

On this tab, you can set up the color layout of the appointment boxes that the system shows on the calendar dashboards. You specify the visibility of the appointment boxes depending on the status of the appointment.

## Selected Status Area { .section}

In this area, you select the background color and the text color for the appointment boxes of the status selected in the table below.

|Element|Description|
|-------|-----------|
|**Background Color**|A color picker that you can use to define the background color of the appointment box for the selected status in the table below. This helps visually differentiate appointment statuses on the calendar.**Important:** This applies only to the legacy calendar board.

|
|**Text Color**|A color picker that you can use to set the color of the text displayed in the appointment box for the selected status. This ensures text visibility against the background color.**Important:** This applies only to the legacy calendar board.

|
|**Bar Color**|A color picker that you can use to define the color of the vertical status bar displayed on the left side of the appointment box. This bar provides a quick visual indicator of the appointment's status.**Important:** This applies to the modern calendar board.

|

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**ID**|An identifier of the status.|
|**Status**|The status of the appointment.|
|**Background Color**|The background color of the appointment box for the status of this row. You select this color in the **Background Color** box in the **Selected Status** area on this tab.|
|**Text Color**|The color of the text in the appointment box for the status of this row. You select this color in the **Text Color** box in the **Selected Status** area on this tab.|
|**Visible**|A check box that indicates \(if selected\) that the appointment box will be visible on the calendar dashboards.|

## Appointment Box Tab {#2 .section}

On this tab, you modify the fields that will be displayed in the appointment boxes on the calendar dashboards. You also can change the default order of the fields to be displayed in the appointment boxes by moving the rows up or down in this table, and set up an icon to be displayed next to selected field.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Icon**|An icon to be displayed next to the current field in the appointment boxes on the calendar dashboards.|
|**Object**|An attribute that defines the set of values that can be displayed on the current field. The following options are available: *FSServiceOrder*, *FSAppointment*, *FSContact*, *FSAddress*.|
|**Field Name**|The field to be displayed in the appointment boxes. You select the needed field from the list. The list of options is defined by the attribute selected in the **Object** column of the current row.|
|**Visible**|A check box that indicates \(if selected\) that the current field is visible in the appointment boxes.|

## Service Order Tab { .section}

On this tab, you can add new columns, or delete or hide any of the existing columns that are shown on the **Service Orders** tab on the calendar board forms. You can also define the order of the columns by moving the rows in the table on the current form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Object**|An attribute that defines the set of values that can be displayed in the current column on the **Service Orders** tab on the calendar board forms. The following options are available: *FSServiceOrder*, *FSContact*, *FSAddress*.|
|**Field Name**|The value that is displayed in the current column on the **Service Orders** tab on the calendar board forms. You select the needed value from the list. The list of options is defined by the attribute selected in the **Object** box of the current row.|
|**Visible**|A check box that indicates \(if selected\) that the current column is visible on the **Service Orders** tab on the calendar board forms.|

## Unassigned Appointment Tab { .section}

On this tab, you can add new columns, or delete or hide the existing columns shown on the **Unassigned Appointments** tab on the calendar board forms. You can also define the order of the columns by moving the rows in the table on the current form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Object**|An attribute that defines the set of values to be displayed in the current column on the **Unassigned Appointment** tab on the calendar board forms. The following options are available: *FSServiceOrder*, *FSAppointment*, *FSContact*, *FSAddress*.|
|**Field Name**|The value that is displayed in the current column on the **Unassigned Appointment** tab on the calendar board forms. You select the needed value from the list. The list of options is defined by the attribute selected in the **Object** box of the current row.|
|**Visible**|A check box that indicates \(if selected\) that the current column is visible on the **Unassigned Appointment** tab on the calendar board forms.|
