# Payment Processing Log {#_618b7c1b-a855-4f3c-b77a-40d5f56fcf8e .reference}

Form ID: \(AR406500\)

You can use this form to view failed card transactions \(or all transactions\) by customer class, customer, processing center, and time period.

**Attention:** This form appears in the system if the *Integrated Card Processing* feature has been enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

You can use this area of the form to select the period, processing center, customer class, and particular customer for which you want to view data.

|Element|Description|
|-------|-----------|
|**Date Range**|Start and end dates that define the range of data to display. By default, both dates are set to the current business date.|
|**Display Transactions**|The type of transactions you want to display in the list below: *All Transactions* or *Failed Only*.|
|**Proc. Center ID**|The card processing center used to process the transactions.|
|**Customer Class**|The customer class. Leave the box blank to view transactions related to all customer classes.

 The list of classes may be limited based on the roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. With the feature enabled, the **Restrict Visibility To** box appears on the **General** tab of the [Customer Classes](../Shared/../UserGuide/AR_20_10_00.md) \(AR201000\) form. You can select a customer class if one of the following is true:

-   The **Restrict Visibility To** box is empty for the customer class—that is, the visibility of the customer class is not restricted.
-   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer class, and your user account is assigned to the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.

|
|**Customer**|The specific customer, by account ID. Leave the box blank to view transactions related to all customers that meet the other specified criteria.

 The list of customers available for selection may be limited based on the role or roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. In this case, the **Restrict Visibility To** box appears on the **Financial** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form. With the feature enabled, a customer is available for selection if one of the following is true:

-   The **Restrict Visibility To** box is empty for the customer—that is, the customer’s visibility is not restricted.
-   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer, and your user account has the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.

|

## Table {#2 .section}

This table contains the list of transactions matching the criteria specified in the Selection area. The specific columns shown below depend on the payment method defined on the [Payment Methods](CA_20_40_00.md) \(CA204000\) form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Customer ID**|The customer identified by account ID. You can click the link to navigate to the [Customers](AR_30_30_00.md) \(AR303000\) form and view the details of the customer owning the selected card.|
|**Customer Name**|The name of the customer.|
|**Payment Method**|The identifier of the payment method. You can click the link to navigate to either of the following forms:

 -   [Customer Payment Methods](AR_30_30_10.md) \(AR303010\) where you can view the details of the payment method with which the card is associated
-   [Payment Methods](CA_20_40_00.md) \(CA204000\) where you can view the payment method, if the payment was made without saving the customer payment method

|
|**Card/Account Type**|The type of card or account used for the payment.|
|**Doc. Type**|The type of document to be paid.|
|**Doc. Reference Nbr.**|The identifier of the payment document as assigned by the system. You can click the link to navigate to the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form and view the details of the payment.|
|**Orig. Doc. Type**|The type of the original document to be paid.|
|**Orig. Doc. Ref. Nbr.**|The reference number of the original document to be paid.|
|**Proc. Center**|The processing center that processed the transaction operation.|
|**Tran. Nbr.**|The number assigned by Acumatica ERP to a transaction, created when you click **Capture** on the form toolbar or click **Authorize** on the More menu.|
|**Tran. Type**|The type of the transaction operation. The following values can be displayed in this column:

 -   *Authorize Only*: The **Authorize** command was performed.
-   *Authorize and Capture*: The **Capture** command was performed for an unauthorized transaction.
-   *Capture Authorized*: The **Capture** command was performed for an authorized transaction.
-   *Capture Manually Authorized*: The **Record and Capture Preauthorization** command was performed and the processing center authorization number was specified. This operation captures the transaction authorized on the processing center side by using the transaction authorization number.
-   *Void*: The **Void** command was performed.
-   *Refund*: The **Refund** command was performed.

|
|**Tran. Amount**|The amount of the transaction.|
|**Proc. Status**|The status of the processing of the transaction operation, such as *Open*, *Completed*, or *Error*.|
|**Tran. Status**|The status of the transaction operation. The following values can be displayed in this column:

 -   *Approved*: The operation on the transaction was approved.
-   *Declined*: The operation on the transaction was declined.
-   *Error*: An error has occurred during the processing of the transaction operation.
-   *Held for Review*: The operation is pending review in the processing center.
-   *Unknown*: The current status of the transaction operation is unknown.

|
|**Proc. Center Tran. Nbr.**|The number assigned by the processing center to uniquely identify a transaction.|
|**Proc. Center Response Reason**|The response received for the transaction operation from the processing center.|
|**Tran. Time**|The time when the card transaction related to the document was performed.|
|**Proc. Center Card Type**|The type of card used for the payment, as it is defined in the processing center. **Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
