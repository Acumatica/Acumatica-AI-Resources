# Approve Time Activities {#_adcdcd28-f66c-468f-88b2-e842c7ff8e05 .reference}

Form ID: \(EP507010\)

You can use this form to approve or reject time activities submitted for approval.

This form is available only if the *Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Approve All**|Approves all the listed time activities and changes their status to *Approved*.|
|**Reject All**|Rejects all the listed time activities and changes their status to *Rejected*.|

## Selection Area {#2 .section}

By using the elements in this area, you can narrow the range of time activities to be displayed.

|Element|Description|
|-------|-----------|
|**Approver**|The ID of the person authorized to approve time activities.|
|**From Date**|The start date of the date range for which you want to view time activities.|
|**Until Date**|The end date of the date range for which you want to view time activities.|
|**Project**|The contract or project for which you want to list time activities.|
|**Project Task**|The project task for which you want to list time activities.|
|**Employee**|The ID of the employee whose time activities you want to list.|

|Element|Description|
|-------|-----------|
|**Time Spent**|The total working time \(regular and overtime\) spent on the time activities listed in the **Details** tab.|
|**Billable**|The total billable working time \(regular and overtime\) spent on the time activities listed in the **Details** tab.|

## Details Tab { .section}

This tab contains the table with the list of time activities that are ready for approval.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Approve**|A check box you can use to select the time activities you want to approve.|
|**Reject**|A check box you can use to select the time activities you want to reject.|
|**Date**|The date when the time activity was created.|
|**Owner**|The identifier of the employee whose time activity is listed.|
|**Employee Name**|The name of the employee whose time activity is listed.|
|**Workgroup**|The workgroup to which the employee belongs.|
|**Earning Type**|The type of the work time spent by the employee.|
|**Task**|The task associated with the time activity.|
|**Project**|The project associated with the time activity.|
|**Project Task**|The project task associated with the time activity.|
|**Cost Code**|The cost code that is associated with the time activity.

 The column is shown if the *Cost Code* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Shift Code**|The work shift during which the time activity was performed. This column appears only if the *Shift Differential* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Time Spent**|The total time spent by the employee on the time activity.|
|**Billable**|A check box that indicates that the time activity is billable.|
|**Billable Time**|The total billable time spent by the employee on the activity.|
|**Summary**|The description of the time activity.|
|**Approver**|A person authorized to approve the time activity. \(Another person who can approve the time activity is the project manager assigned to the related project.\)|
|**Time Card Ref.**|The time card associated with the time activity. If this column is empty, the time activity is not yet included in any time card.|
|**Case ID**|The identifier of the case associated with the time activity.

 This column is available only if the *Case Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Contract ID**|The identifier of the contract associated with the time activity.|
|**Reported in Time Zone**|The original time zone in which the time activity was created.|
|**Reported On**|The reported date in the original time zone.|
|**Reported At**|The reported time in the original time zone.|

## Totals Tab { .section}

On this tab, you review the total hours spent by employees on the regular and overtime work.

|Element|Description|
|-------|-----------|
|**Time Spent**|The regular work hours spent on the time activities listed in the **Details** tab.|
|**Billable**|The billable work hours spent on the time activities listed in the **Details** tab.|

|Element|Description|
|-------|-----------|
|**Time Spent**|The overtime spent on the time activities listed in the **Details** tab.|
|**Billable**|The billable overtime spent on the time activities listed in the **Details** tab.|
