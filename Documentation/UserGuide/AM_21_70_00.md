# Manufacturing Departments {#_35c5fd99-e921-4deb-9ea7-50fd5a5cd1e6 .reference}

Form ID: \(AM217000\)

A manufacturing department is a way of grouping work centers by production area. This gives you a clearer, more structured way to organize and navigate your work centers.

By using this form, you can:

-   Create new manufacturing departments for a specific warehouse or review existing ones
-   Group work centers into manufacturing departments
-   Filter the work center list by department to see only the resources that belong to a specific production area

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

This area contains the basic settings of the manufacturing department.

|Element|Description|
|-------|-----------|
|**Manufacturing Department ID**|The identifier of the manufacturing department. Manufacturing departments associated with the same warehouse must have unique IDs.|
|**Description**|The description of the manufacturing department, typically indicating the production area of its work centers.|
|**Warehouse**|The warehouse associated with the manufacturing department.|

## Work Centers Table {#2 .section}

By using this table, you can manage the list of work centers included in the manufacturing department. Only work centers associated with the warehouse selected in the Summary area of this form can be added to the table. One work center can belong to only one department.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Work Center**|The identifier of the work center.|
|**Description**|The description of the work center, which typically represents its function.|
|**Warehouse**|The warehouse associated with the work center.|
|**Active**|A check box that indicates \(if selected\) that the work center is included in the manufacturing department. You can clear the check box if you want to temporarily exclude the work center from the department.|
|**Standard Cost**|The cost of one hour of work in operations performed in the work center.|
|**Basis for Capacity**|The setting that the system uses to define the capacity of the work center when the system schedules operations.|
|**Scrap Action Default**|The default scrap action for operations added on the [Bill of Material](AM_20_80_00.md) \(AM208000\) form.|
|**Outside Process**|A check box that indicates \(if selected\) that the processing takes place at another organization—that is, the process is outsourced.|
|**Backflush Labor**|A check box that indicates \(if selected\) that the system backflushes the cost of labor hours spent for operations that are assigned to the work center.|
|**Backflush Materials**|A check box that indicates \(if selected\) that the system backflushes materials used for operations that are assigned to the work center.|
|**Control Point**|A check box that indicates \(if selected\) that operations that are assigned to the work center are control points. If they are, for these operations, workers must record the quantity of completed items.|
|**Allow Clock Entry for Multiple Production Orders**|A check box that indicates \(if selected\) that on the [Multiple Production Clock Entry](AM_31_60_00.md) \(AM316000\) form, a production employee can record labor time simultaneously for multiple operations of production orders when the operations are assigned to any work center with this check box selected. If the check box is cleared, the employee can clock in for only a single operation assigned to this work center.|
