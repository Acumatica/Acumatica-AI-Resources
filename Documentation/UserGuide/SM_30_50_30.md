# Teams Members {#_3148aed3-c576-4938-b747-0a83ea7e67a9 .reference}

Form ID: \(SM305030\)

You use this form to map contacts \(members\) in Microsoft Teams with the contacts available in Acumatica ERP. That is, when the same person is defined as a contact in both Acumatica ERP and Microsoft Teams, you use this form to map the contacts to each other.

The table is filled in automatically when you invoke the mapping \(that is, when you click **Map Contacts &amp; Employees** on the form toolbar\). By default, the system tries to match the contacts and employees in Acumatica ERP with members in Teams by using the email address of each contact or employee. If the system cannot find a contact in Acumatica ERP for a Teams member, the system leaves the **Acumatica ERP Contact/Employee** column empty. You can then map a Teams member to an Acumatica ERP contact manually by selecting the needed contact in the **Acumatica ERP Contact/Employee** column. This can be helpful if a Teams contact does not use the same email address as the one entered on the [Contacts](CR_30_20_00.md) \(CR302000\) or [Employees](EP_20_30_00.md) \(EP203000\) form. If multiple contacts with the same email address have been found, the system uses the record it has found first but displays a warning that multiple matches have been found.

You perform the mapping when you initially configure the integration. After that, you might need to invoke the mapping again if new users have been added to Teams channels, to Acumatica ERP, or both.

This form is available in the system only if the *Teams Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Map Contacts &amp; Employees**|Starts the process of mapping the Teams contacts with the Acumatica ERP contacts.|

## Table {#2 .section}

This table contains the names and IDs of the members of the Teams channel and the Acumatica ERP contacts that correspond to them.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Active**|A check box that you select to indicate that the user is active in Teams and in Acumatica ERP.

 This check box is selected by default.

|
|**Picture**|The picture of the user in Teams.|
|**Teams ID**|The email address with which the user is signed in to Teams.|
|**Teams Member**|The name of the user in Teams.|
|**Acumatica ERP Contact/Employee**|The Acumatica ERP contact or employee with which the Teams member is associated.

 If the system has not found a match, you can click the magnifier button in this column to open the lookup table with the list of contacts and selected the needed one.

|
