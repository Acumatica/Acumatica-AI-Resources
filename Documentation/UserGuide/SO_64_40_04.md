# Pick List – Confirm Picked with Barcodes {#_7047acb9-ac01-428a-8a4e-e6d63b377a39 .reference}

Form ID: \(SO644004\)

**Note:** This form is available only if the *Warehouse Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This form displays a pick list for the selected shipment as a ready-to-print pick list. The document provides a list of the items to be picked from various locations for the selected shipment. For each item, you can view the quantity, weight, and volume information. The bottom of the document shows the total weight and volume.

The following linear barcodes are available for scanning in the pick list: the shipment number barcode, the location barcode for each of the items in the pick list, the inventory ID barcodes, and the barcode for confirming the shipment.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameter to select the information to be displayed on the report:

-   **Shipment Number**: The number of the shipment for which you want to generate a ready-to-print pick list.
