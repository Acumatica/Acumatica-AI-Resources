# To Release a Deposit {#_3042538f-1483-4ac2-ad5b-93829bf0ea57 .task}

To release a particular deposit, use the [Bank Deposits](CA_30_50_00.md) \(CA305000\) form, as described below.

## To Release a Deposit {#section_r3d_kjv_vxb .section}

1.  Open the [Bank Deposits](../Shared/../UserGuide/CA_30_50_00.md) \(CA305000\) form.
2.  Check the **Tran. Type** box, and change it, if needed.
3.  In the **Reference Nbr.** box, select the deposit you want to release.
4.  Check the status of the deposit \(it should be *Balanced*\).
5.  On the form toolbar, click **Release**. The released document is assigned the *Released* status.
