# Cost Projection Classes

Form ID: \(PM203500\)

**Attention:** This form is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to create cost projection classes, which define the detail level of cost projection revisions. A cost projection revision can include the same level of detail as or less detail than the cost budget of the project for which the revision is created. Only a cost projection with the same level of budget detail can be released. For more information, see [Project Cost Projections: General Information](Construction_Cost_Projection_GeneralInfo.md).
