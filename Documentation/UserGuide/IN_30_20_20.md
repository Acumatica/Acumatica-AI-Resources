# Scan and Issue {#_589455a2-a6bd-4d0e-ac5a-1a4f5a0d9dee .reference}

Form ID: \(IN302020\)

When you scan the appropriate barcode, the system brings up this form for a new inventory issue. You then scan the barcode of the warehouse from which items are being issued and the barcode of each item being issued \(and the barcodes of the item's quantity, storage location, and optional settings\). All of this information is reflected on the form as you work. When you have scanned all items and the information on the form is correct, you scan the barcode to release this inventory issue. You can view the released issue on the [Issues](IN_30_20_00.md) \(IN302000\) form.

**Note:** This form is available only if the *Inventory Operations* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Reset**|Resets the processing flow for the current inventory issue document, keeping the warehouse and reference number, and preserving the lines on the**Issue** tab. The system does not preserve any unconfirmed lines that were in progress.|
|**OK**|Confirms the line that is currently being processed.

 This button is displayed only when the **Use Explicit Line Confirmation** check box is selected on the [Inventory Preferences](IN_10_10_00.md) \(IN101000\) form.

|
|**Remove**|Activates Remove mode, in which you can remove the specified item quantity for the currently selected line.|
|**Set Qty.**|Specifies the quantity you have entered as the quantity for the currently selected line if the **Use Default Quantity in Issues** check box is cleared on the [Inventory Preferences](IN_10_10_00.md) \(IN101000\) form; specifies the quantity you have entered for the current line as the default quantity to be used in all lines of the current document if the **Use Default Quantity in Issues** check box is selected on the form.|
|**Release**|Releases the inventory issue document you are currently processing.|
|**User Settings**|Opens the [Settings](#table_es1_dyj_wgb) dialog box, in which you can specify your personal user settings for the current working mode.|

|Element|Description|
|-------|-----------|
|**Default Warehouse from User Profile**|A check box that indicates \(if selected\) that the system copies a warehouse to the **Warehouse** box from the **Default Warehouse** box of the [User Profile](SM_20_30_10.md) \(SM203010\) form for the user account to which you are signed in.

 The default value of this check box is copied from the check box of the same name on the [Inventory Preferences](IN_10_10_00.md) \(IN101000\) form. You can change the check box value for this form.

|
|The dialog box provides the following buttons.|
|**Save**|Applies your selected options and closes the dialog box.|
|**Cancel**|Closes the dialog box without applying any changes you have made.|

## Summary Area { .section}

This area displays the warehouse you scanned, the reference number of the inventory issue \(when the system fills it in\), and the results of barcode scanning as you work.

|Element|Description|
|-------|-----------|
|**Scan**|A box in which you can enter commands to initiate operations and switch between working modes. The results of barcode scanning are also entered automatically into this box. This is the only entry box on the form.

 For the list of commands supported in each mode, see [Working Modes and Supported Commands](WMS_Commands_List.md).

|
|**Reference Nbr.**|The reference number of the inventory issue document. The system inserts this number for a new inventory issue document after you add lines and click **Save** or **Release** on the form toolbar.|
|**Warehouse**|The warehouse in which you are issuing inventory items. If the default warehouse is specified in your user profile on the [User Profile](SM_20_30_10.md) \(SM203010\) form, the system inserts your default warehouse in this box.|
|Notification Area|An area that displays information that is pertinent to what you are doing, which can be any of the following:-   The result of the last operation
-   The next suggested operation

|

## Issue Tab { .section}

This tab shows the lines of the inventory issue document that is currently being processed.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Inventory ID**|The identifier of the inventory item in the inventory issue you are currently processing.|
|**Description**|The description of the inventory item.|
|**Lot/Serial Nbr.**|The lot or serial number of the inventory item \(if applicable\).

 This column is displayed only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Expiration Date**|The expiration date of the item \(if applicable\).

 This column is displayed only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Location**|The location in the selected warehouse where the inventory item is stored.|
|**Reason Code**|The reason code for the inventory issue.|
|**Quantity**|The quantity of the inventory item that is being issued. It is always *1* for items with serial numbers.|
|**UOM**|The unit of measure for the inventory item.|

## Scan Log { .section}

This tab displays the history of the most recent performed operations in the current working mode. The log is cleared when you close the form or switch to another working mode.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Time**|The date and time when the operation was performed.|
|**Mode**|The working mode that was active when the system was performing the operation.|
|**Prompt**|The message describing the operation to be performed \(as was shown in the notification area\).|
|**Scan**|The command that was entered in the **Scan** box, or the barcode that was scanned.|
|**Message**|The result of the operation \(as was shown in the notification area\).|
