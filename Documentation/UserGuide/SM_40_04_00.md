# Document Archival History {#_3ec5a053-0d33-4fb6-9c2e-c14a741978eb .reference}

Form ID: \(SM400400\)

On this form, you can view all results of the document archive execution process performed on the [Archive Documents](SM_50_04_00.md) \(SM500400\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

In this area, you can specify the date range of the archival processes whose records you want to view.

|Element|Description|
|-------|-----------|
|**From**|The date of execution of the document archival process from which you would like to review the records.|
|**To**|The date of execution of the document archival process until which you would like to see the records.|

## Executions Pane {#2 .section}

On this pane, you can view the list of archival process execution records performed within the specified date range.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Execution Date**|The date when the document archival process was run.|
|**Duration**|The duration of the execution process.|
|**Executed By**|The username of the user who executed the archival process.|
|**All Documents**|The total number of documents that were archived during the execution process in this row.|

## Execution Details Pane {#section_fsc_msp_vsb .section}

On this pane, you can view the detailed information about the archival process whose row is selected in the **Executions** pane.

The table toolbar has only standard buttons.

|Element|Description|
|-------|-----------|
|**Ready-to-Archive Date**|The date when the document or documents satisfied the archival policy settings and became eligible for archival \(that is, the date when the retention period was over\).|
|**Duration**|The duration of the archival process of the selected row.|
|**All Documents**|The total number of documents that were archived.|
|**Shipment**|The total number of archived documents of the *Shipment* type.|
|**Sales Order**|The total number of archived documents of the *SO - Sales Order* type.|
