# Service Order {#_5f7c8485-b190-4621-96ea-32a1f42199dc .reference}

Form ID: \(FS641000\)

This report displays the selected service order as a ready-to-print document. The document provides the company information \(in the top left\), contact information, customer information, included services \(and their quantities and prices\), inventory item information, information about the staff members who perform the services, and the total price of the service order.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report-Specific Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Service Order Type**: The service order type related to the service order you want to display. You must specify the type.
-   **Service Order Number**: The number of the service order you want to display. You must specify the number of the service order.
