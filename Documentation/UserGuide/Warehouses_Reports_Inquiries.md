# Warehouses: Related Report and Inquiry Forms {#_33913396-8529-4dfc-ab7d-de52a7c7850f .concept}

In the following sections, you can find details about report and inquiry forms that provide information related to warehouses.

## Viewing Items by Warehouse { .section}

If you want to view the list of items in a particular warehouse, you use the [Storage Summary](IN_40_90_10.md) \(IN409010\) form.

## Reviewing Inventory Valuation by Warehouse { .section}

To review the quantities on hand and the total cost of inventory by inventory account, with details for different warehouses or for only a particular warehouse, you use the [Inventory Valuation](IN_61_55_00.md) \(IN615500\) report.
