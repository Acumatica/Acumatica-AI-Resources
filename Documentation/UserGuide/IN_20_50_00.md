# Subitems {#_85430345-0c18-4ecf-8990-da6c37b2c2f0 .reference}

Form ID: \(IN205000\)

This form is available only if the *Inventory Subitems* feature is enabled in your system on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

**Important:** The **Inventory Subitems** check box has been removed from the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form because the functionality associated with the *Inventory Subitems* feature will be phased out. If you have this feature enabled in your system, the associated functionality remains available. To disable the feature, contact your Acumatica support provider.

You use this form to add or delete subitems used in the system. Although subitems can be created on the fly on particular documents, you maintain this list as the information source about all the subitems used in your system. For details on using subitems, see [Inventory Subitems](IN__con_Inventory_IDs_and_Subitem_Codes.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table { .section}

This table contains the list of subitems used with inventory IDs.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Subitem**|A subitem. The structure of identifiers is defined by the *INSUBITEM* segmented key, see [Segmented Keys](CS_20_20_00.md) \(CS202000\).|
|**Description**|The detailed description of the subitem to be used in auto-generated transactions.|
