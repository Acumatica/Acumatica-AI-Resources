# Unreleased IN Documents {#_23bcc83d-cc1c-4cce-8a69-92fb026894b7 .reference}

Form ID: \(IN656600\)

By using this report, you can view the inventory documents that have not been released in the selected financial period or periods.

**Note:** You cannot run this report from the site map. You run this report, along with other reports to find unposted documents, by clicking the **Unposted Documents** button on the form toolbar of the [Manage Financial Periods](GL_50_30_00.md) \(GL503000\) form as preparation for closing a financial period in the subledgers and in the general ledger.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Company**: The company for which you want to view unreleased inventory documents.

    By default, the current company is selected.

-   **Branch**: The branch of the selected company for which you want to view unreleased inventory documents.

    By default, the current branch is selected.

-   **From Period**: The starting financial period of the range of periods the report will cover. You must select a period.

    By default, the current financial period is used.

-   **To Period**: The ending financial period of the range of periods the report will cover. You must select a period.

    By default, the current financial period is used.
