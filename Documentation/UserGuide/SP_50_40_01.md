# Catalog

Form ID: \(SP504001\)

**Who uses this form:** An authorized portal user of a company using the Modern Customer Portal.

On this form, you can browse a catalog of items and add items directly to the cart. The form displays items with their main details—such as name, price, and real-time inventory visibility—as you shop. You can browse and search for items available for ordering, filter the list of items, and add selected items to the cart.

In the **Item Details** dialog box, you can view or change an item’s quantity, select a warehouse and unit of measure \(if applicable\), and add the item to the cart without leaving the form.

This form is available if the following are true in Acumatica ERP for the portal owner:

-   The *Inventory and Order Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.
-   This portal has the **B2B Ordering** check box selected and the ordering functionality configured on the [Portals](SP_70_10_00.md) \(SP701000\) form.

## Form Toolbar

The form toolbar has only standard buttons.

## Item Cards Area

In this area, you can view catalog items. Items are displayed as cards, each showing the item’s name, image, price, and stock availability.

You can add an item to the cart:

-   Directly from the form by clicking **Add to Cart** at the bottom of the card.
-   From the **Item Details** dialog box, which opens when you click the item's card. In this dialog box, you can review or change basic item information and then add the item to the cart.

The information on each card is described below. When you’re done adding items to the cart, you can complete the order on the [Cart](SP_50_40_03.md) \(SP504003\) form.
