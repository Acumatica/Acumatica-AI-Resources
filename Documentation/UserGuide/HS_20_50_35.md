# HubSpot Data Resync {#_cd004ef9-3e3f-4122-96dc-4045831a5c02 .reference}

Form ID: \(HS205035\)

You use this form to synchronize entity records that have become out of sync because of processing failures.

This form is available in the system only if the *HubSpot Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the process selected in the **Sync to Start** box for records of the entity types selected in the table.|
|**Process All**|Initiates the process selected in the **Sync to Start** box for records of all the entity types listed in the table.|

## Selection Area { .section}

In this area, you select the operation the system will execute during processing, which determines the extent of the synchronization.

|Element|Description|
|-------|-----------|
|**Sync to Start**|The operation you want the system to execute when you click **Process** or **Process All** on the form toolbar. The following options are available:

 -   *Failed &amp; Missed Data Resync*: Synchronizes only the data that is out of sync either because of previous failures of the synchronization process or because a connection failure caused one of the systems to be temporarily unavailable.
-   *Full Data Resync*: Checks all the HubSpot synchronization records for updated data and synchronizes those that are out of sync.

|

## Table { .section}

This table lists all of the types of entities whose records can be synchronized in real time between Acumatica ERP and HubSpot—that is, the table has a row for each entity type that has been listed on the [HubSpot Sync](HS_20_50_20.md) \(HS205020\) form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that indicates \(if selected\) that the process selected in the **Sync to Start** box will be initiated for records of the particular entity type if you click **Process** on the form toolbar.|
|**Entity**|Read-only. The entity type of the records that you can process, which is one of the following: *Business Account*, *Contact*, *Lead*, or *Marketing List*. A row is copied to the current form for each entity type that has been listed on the [HubSpot Sync](HS_20_50_20.md) \(HS205020\) form.

|
|**Master Source**|Read-only. The ssource that is used during synchronization if there are conflicting changes in both HubSpot and Acumatica ERP.This column contains the master source specified for this entity type on the [HubSpot Sync](HS_20_50_20.md) \(HS205020\) form.

|
|**Latest Failed &amp; Missed Data Resync Attempt**|Read-only. The date of the latest attempt to synchronize records of the type that previously was missed or failed to synchronize.|
|**Latest Full Data Resync Attempt**|Read-only. The date of the latest attempt to resynchronize all records of the entity type.|
