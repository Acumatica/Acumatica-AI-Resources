# Resource Equipment List {#_dff9ae42-60ae-4c0a-bf9f-f5ccae39c052 .reference}

Form ID: \(FS656000\)

This report displays information about resource equipment registered in the system. You can select equipment by its type.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameter to select the information to be displayed on the report:

-   **Equipment Type**: The equipment type for which you want to view information. Leave the box blank to view information on all equipment types.
