# HubSpot Sync {#_f846d1a1-56a1-4e95-acfb-0d21001b861a .reference}

Form ID: \(HS205030\)

You use this form to initiate or stop real-time data synchronization between Acumatica ERP and HubSpot for records of particular entity types or for records of all entity types that can be synchronized.

This form is available only if the *HubSpot Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Table { .section}

This form consists of a table that lists all of the types of entities whose records can be synchronized in real time between Acumatica ERP and HubSpot—that is, the table has a row for each entity type that has been listed on the [HubSpot Sync](HS_20_50_20.md) \(HS205020\) form. \(All of the settings in the rows on the current form are read-only except for the Included column, where you can select or clear the check box.\) The table toolbar has actions you can perform to start or stop real-time synchronization for records of all of the listed entity types or for records of the entity types you have selected.

|Button|Description|
|------|-----------|
|**Start**|Initiates real-time synchronization for records of the entity types for which you have selected the unlabeled check boxes in the table.|
|**Start All**|Initiates the real-time synchronization process for all records of all entity types that can be synchronized \(that is, for records of all of the listed entity types\).|
|**Stop**|Stops real-time synchronization from HubSpot to Acumatica ERP for records of the entity types for which you have selected the unlabeled check boxes in the table.**Note:** To stop real-time synchronization from Acumatica ERP to HubSpot for records of a particular entity type, in the table on the [HubSpot Sync](HS_20_50_20.md) \(HS205020\) form, you need to clear the **Export Scenario** column in the row for this entity type.

|
|**Stop All**|Stops real-time synchronization from HubSpot to Acumatica ERP for all records of all entity types listed in the table.**Note:** To stop real-time synchronization from Acumatica ERP to HubSpot for records of all supported entity types, you need to do either of the following:

-   On the [HubSpot Sync](HS_20_50_20.md) \(HS205020\) form, remove all export scenarios from the table by clearing the **Export Scenario** column for all rows.
-   On the [Data Providers](SM_20_60_15.md) \(SM206015\) form, clear the **Active** check box for the *HubSpot Enhanced* data provider.

|

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that indicates \(if selected\) that the real-time synchronization process will be initiated or stopped for records of the particular entity type selected for the row if you click **Start** or **Stop** on the form toolbar.|
|**Status**|Read-only. The current status of the real-time synchronization process, which is one of the following options.-   *Stopped*
-   *Running*
-   *Running \(no polling\)*
-   *Is Empty*

|
|**Entity**|Read-only. The entity type of the records for which you can initiate or stop the real-time synchronization process, which is one of the following: *Business Account*, *Contact*, *Lead*, or *Marketing List*. A row is copied to the current form for each entity type that has been listed on the [HubSpot Sync](HS_20_50_20.md) \(HS205020\) form.|
|**Import Scenario**|Read-only. The import scenario to be used for real-time synchronization of records of this entity type. This column contains the import scenario specified for this entity type on the [HubSpot Sync](HS_20_50_20.md) \(HS205020\) form.|
|**Export Scenario**|Read-only. The export scenario to be used for real-time synchronization of records of this entity type. This column contains the export scenario specified for this entity type on the [HubSpot Sync](HS_20_50_20.md) \(HS205020\) form.|
|**Master Source**|Read-only. The master source of the entity type, which is the source that will be used during synchronization, if there are changes in both HubSpot and Acumatica ERP. This column contains the master source specified for this entity type on the [HubSpot Sync](HS_20_50_20.md) \(HS205020\) form.|
|**Latest Real-Time Attempt**|Read-only. The date and time of the latest synchronization attempt for the entity type.|
