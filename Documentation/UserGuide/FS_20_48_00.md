# Manufacturer Models {#_cb2c3ad4-70b8-45ab-95fb-c53ff4a187c7 .reference}

Form ID: \(FS204800\)

On this form, you can enter, view, and edit the settings for manufacturer models. A manufacturer model refers to equipment produced by a specific manufacturer. For details, see [Manufacturers: General Information](EquipMgmt_Manufacturers_GeneralInfo.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

In this area, you can specify and view the properties of a manufacturer model, including the manufacturer's name, the model identifier, and its description.

|Element|Description|
|-------|-----------|
|**Manufacturer ID**|The identifier of the manufacturer that has produced the model.|
|**Manufacturer Model**|The identifier of the model set by manufacturer.|
|**Description**|A description of the manufacturer model.|
|**Equipment Type**|The equipment type to which the model is related.|
