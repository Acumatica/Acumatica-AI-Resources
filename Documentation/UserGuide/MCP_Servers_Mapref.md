# Configuring MCP Servers

With Model Context Protocol \(MCP\) servers, you can give MCP-compatible clients, such as AI clients and custom applications, secure access to selected Acumatica ERP data.

In this chapter, you'll learn how to configure MCP servers so that external clients can discover and call tools based on published generic inquiries. You will also learn how to connect an MCP client to the server by using OAuth 2.0.
