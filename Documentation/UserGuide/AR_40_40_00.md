# Statement History Summary {#_fc2e457c-36e6-46b5-ac4c-5515aca933bc .reference}

Form ID: \(AR404000\)

On this form, you can view the history of statements for each statement cycle during the specified period of time. You can easily drill down to the details of each statement.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Statement History Details**|Navigates to the [Statement History Details](AR_40_43_00.md) \(AR404300\) form.|
|**Print Statements**|Navigates to the [Print Statements](AR_50_35_00.md) \(AR503500\) report.|

## Selection Area {#1 .section}

In this area, you can select the statement cycle and the date range for which you want to display data.

|Element|Description|
|-------|-----------|
|**Statement Cycle ID**|The statement cycle for which data will be displayed. If you leave the box blank, information for all statement cycles will be displayed.|
|**Date Range**|The start and end dates of the date range. By default, the start date is set to the first day of the current financial year, and the end date is set to the current business date.|
|**Include On-Demand Statements**|A check box that \(if selected\) causes on-demand statements to be shown in the table below. If this check box is cleared \(the default setting\), the table shows only the statements that were prepared according to the schedule.|

## Table {#2 .section}

This table displays the list of statements issued during the specified period of time.

|Column|Description|
|------|-----------|
|**Statement Cycle ID**|The identifier of the statement cycle.|
|**Statement Date**|The date of the statement.|
|**Description**|The description of the statement cycle.|
|**Number of Documents**|The number of documents included into the statement.|
|**To Print**|The number of statements requiring printing in accordance with the settings on the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Printed**|The number of statements printed in accordance with the settings on the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**To Email**|The number of statements requiring printing in accordance with the settings on the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Emailed**|The number of statements emailed in accordance with the settings on the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**No Action**|The number of statements requiring no action in accordance with the settings on the [Customers](AR_30_30_00.md) \(AR303000\) form.|
|**Email Completion %**|The percentage of statements that have been emailed \(among all statements to be emailed\).|
|**Print Completion %**|The percentage of statements that have been printed \(among all statements to be printed\).|
