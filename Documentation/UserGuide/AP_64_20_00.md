# Additional Remittance Form

Form ID: \(AP642000\)

You can use this report to print or email check stubs.

To use this report, on the [Payment Methods](CA_20_40_00.md) \(CA204000\) form, select the **Print Remittance Report** check box and select this report as the **Remittance Report**. The report includes the printed checks of the payment method and cash account that you specify on the **Report Parameters** tab.

If a check has more applications than the number specified in the **Lines per Stub** box on the **Settings for Use in AP** tab of the [Payment Methods](CA_20_40_00.md) form for the payment method, the check has multiple stubs, and the additional remittance report is printed for the check along with the [Check Form](AP_64_05_00.md) \(AP641000\) report.

You can print or email the report for multiple checks or for a single check, depending on the parameters you specify:

-   **Multiple checks**: You specify both **From Check Number** and **To Check Number**. The report includes only the checks in this range that have more applications than the **Lines per Stub** value of the payment method. If no check in the range has more applications than this value, the report is blank.
-   **A single check**: You specify only **From Check Number**. The report includes the check regardless of its number of applications.

For example, suppose that the **Lines per Stub** value is *2*, and checks 0001 and 0002 each have one application. If you specify `0001` as the **From Check Number** and `0002` as the **To Check Number**, the report is blank. If you specify only `0001` as the **From Check Number**, the report includes check 0001.

**Tip:** If you need to print this report for every check in a range regardless of its number of applications, you can customize this report. For details on modifying the report, see the [Acumatica Report Designer](ReportDesigner_Main.md).

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Cash Account**: A cash account associated with a payment method that requires printing of checks.
-   **Payment Method**: A payment method that requires printing of checks.
-   **From Check Number**: The number of the single check to be included in the report, or the starting number of the range of checks if you also specify **To Check Number**.
-   **To Check Number**: The ending number of the range of checks to be included in the report. If you do not specify this parameter, the report includes only the check specified in **From Check Number**.
