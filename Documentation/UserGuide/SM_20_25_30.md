# File Synchronization {#_bd97994c-9ada-420d-9821-6a45ed2dd5a9 .reference}

Form ID: \(SM202530\)

You use this form to process the files that you want to synchronize with external files or folders. You can configure synchronization for certain files by using the [Search in Files](SM_20_25_20.md) \(SM202520\) and [File Synchronization](SM_20_25_30.md) \(SM202530\) forms. For more information, see [To Set Up Automatic File Synchronization](SM__how_How_to_Set_Up_Automatic_Synchronization_of_Files.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process File**|Initiates the synchronization of the selected files.|
|**Process All Files**|Initiates the synchronization of all listed files.|

## Selection Area {#RestrictionGroup .section}

In this area, you select the type of synchronization to be performed for the files.

|Element|Description|
|-------|-----------|
|**Operation**|The operation to be performed for the files you want to synchronize. You can select one of the following options: *Import File* or *Export File*.|

## Table {#2 .section}

In this table, you can view and edit the files for which synchronization of the selected type should be performed.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Name**|The name of the file to be synchronized.|
|**Synchronization Type**|The type of synchronization to be performed for the file.|
|**Path**|The path to the file to be synchronized.|
|**Synchronize Folder Content**|A check box that indicates \(if selected\) that the file will be synchronized with the folder.|
|**Last Import Date**|The date when an import operation was last performed.|
|**Last Export Date**|The date when an export operation was last performed.|
