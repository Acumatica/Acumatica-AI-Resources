# Salesforce Data Resync {#_78670264-f4ff-416b-9797-9056831a9dc5 .reference}

Form ID: \(SF205035\)

This form is available only if the *Salesforce Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to synchronize records that have become out of sync because of processing failures. For details, see [Overview of Synchronization with Salesforce](IS__con_Integration_with_Salesforce.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the process selected in the **Sync to Start** box for records of the selected types.|
|**Process All**|Initiates the process selected in the **Sync to Start** box for records of all the types listed in the table.|

## Selection Area { .section}

|Element|Description|
|-------|-----------|
|**Sync to Start**|The operation you want to execute when you click **Process** or **Process All** on the form toolbar.

 The following options are available:

 -   *Failed &amp; Missed Data Resync*: Starts synchronization of only the data that is out of sync either because of previous failures of the synchronization process or because one of the systems was temporarily unavailable because of a connection failure.
-   *Full Data Resync*: Checks all supported records for updated data and synchronizes those that are out of sync.

|

## Table { .section}

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Selected|An unlabeled check box that indicates \(if selected\) that the process selected in the **Sync to Start** box will be initiated for records of a particular type if you click **Process** on the form toolbar.|
|**Entity**|The type of records that you want to process.|
|**Latest Failed &amp; Missed Data Resync Attempt**|The date of the latest attempt to synchronize records of the type that previously was missed or failed to synchronize.|
|**Latest Full Data Resync Attempt**|The date of the latest attempt to resynchronize all records of the type.|
