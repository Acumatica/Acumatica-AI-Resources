# To Create a Localized Version of an Article {#_cf509ab6-7ad4-4e91-9068-9cc89f9dad3b .task}

For a newly added locale, all articles will be displayed in the locale's base language until you create locale-specific versions of the articles. You can translate wiki articles to the languages defined in the system by using the [Wiki Editor Form for Articles](DM__con_Wiki_Wiki_Editor_Form_for_Articles.md).

For more information, see [Managing Wikis](DM__mng_Wikis.md) and [Translation Process](SM__con_Translation_Process.md).

## To Create a Localized Version of a Wiki Article { .section}

1.  Sign in to the system with the locale selected.
2.  Locate the article in the wiki, and click **Edit** on the wiki toolbar to open the article in the [Wiki Editor Form for Articles](DM__con_Wiki_Wiki_Editor_Form_for_Articles.md).
3.  Replace the article name in English with an article name in the locale language.
4.  Translate the text into the locale language.
5.  Save the article.
