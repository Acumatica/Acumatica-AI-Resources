# Restriction Groups by Item Class {#_afd5cb59-df5f-4823-b646-edad8e6abef7 .reference}

Form ID: \(IN103010\)

On this form, you can view the restriction groups that are assigned by default to the items of an item class. You can also change the visibility of the items that belong to this item class in the system by including the item class in other restriction groups or excluding it from groups that currently contain it.

**Note:** The visibility restrictions configured for an item class are applicable only to the inventory items of this class and do not affect the visibility of the item classes on the [Item Classes](IN_20_10_00.md) \(IN201000\) form.

For more information on restriction groups, see [Restriction Groups in Acumatica ERP](SM__con_Overview_of_Restriction_Groups.md).

**Note:** You can create restriction groups for managing the visibility of item classes by using the [Inventory Item Access](IN_10_30_00.md) \(IN103000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

In this area, you can select the item class for which you want to view or edit the list of restriction groups that will be assigned by default to created items of this item class. You can also view the description of the selected item class.

|Element|Description|
|-------|-----------|
|**Class ID**|The item class \(by its identifier\) whose membership in restriction groups you want to view \(and edit, if needed\) in the table.|
|**Description**|Read-only. The description of the selected class.|

## Table {#2 .section}

In this table, you can view the full list of restriction groups in the system, along with basic information about each groups. The check box in the unlabeled Included column is selected for each group that should be assigned by default to the items of this item class.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that indicates \(if selected\) that the new items of the item class will be included in this restriction group by default.|
|**Group Name**|Read-only. The name of the restriction group.|
|**Description**|Read-only. The description of the restriction group.|
|**Active**|Read-only. A check box that indicates \(if selected\) that the restriction group is active. The system does not enforce restrictions imposed by inactive groups.|
|**Group Type**|Read-only. The type of the restriction group: *A*, *A Inverse*, *B*, or *B Inverse*. For more information, see [Types of Restriction Groups](SM__con_Types_of_Restriction_Groups.md).|
