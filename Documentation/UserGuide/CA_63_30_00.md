# Cash Account Summary {#_37fa36c5-6e41-491a-ac25-78713d684055 .reference}

Form ID: \(CA633000\)

This report displays summary information about cash account balances during the specified date range. \(The date range you specify does not need to coincide with financial periods.\) Information can be detailed up to the cash transactions incurred during the specified date range. Accounts are listed in the order of their account numbers or IDs.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Company/Branch**: The company or branch for which you want to view information. You can select a company or make no selection to view information about all companies in the tenant.

    By default, the system inserts the company or branch selected on the Company and Branch Selection menu.

-   **From Date**: The start date of the date range for which you want to obtain information.

    By default, the first date of the current period is selected.

-   **To Date**: The end date of the date range.

    By default, the current business date is selected.

-   **Cash Account**: The cash account for which the report will display information. Leave the box blank to obtain information on all cash accounts.
-   **Include Non-Cleared Transactions**: A check box that you select to include transactions not cleared by the reconciliation.
-   **Include Unreleased Transactions**: A check box that you select to include transactions that were not released during the specified date range.
-   **Hide Details**: A check box that you select to display only summary lines for cash accounts and hide the details of the cash transactions.
