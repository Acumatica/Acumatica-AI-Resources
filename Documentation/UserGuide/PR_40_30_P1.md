# Employment History {#_794cb466-060a-471e-aec3-433dff2c7795 .reference}

Form ID: \(PR4030P1\)

On this form, general information is listed for all employees, including settings reflecting their employment history and settings used in payroll calculations and reporting.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

By using the elements in the Selection area of the form, you can specify a period for which information should be displayed and choose whether only the latest change in the employment history \(if applicable\) should be displayed for each listed employee. The following table summarizes the elements of this area.

|Element|Description|
|-------|-----------|
|**Period Start Date**|The start date of the period for which information should be displayed in the table.|
|**Period End Date**|The end date of the period for which information should be displayed in the table.|
|**Show Only Last Employment Change**|A check box that indicates \(if selected\) that only the latest change in the employment history \(if applicable\) should be displayed for each listed employee.|

## Table { .section}

The table displays general information for a list of employees, including their employment history.

Above the table is the Filter List drop-down menu. It contains a list of the following filters to display the employees of a specific status in the table:

-   **All Records**: The filter displays the list of all available employees within the specified period. The filter is applied by default when you open the form.
-   **New Hires**: The filter displays information about only the employees who were hired within the specified period.
-   **Position Changes**: The filter displays the list of employee position changes \(such as promotions or demotions\) within the specified period.
-   **Terminations**: The filter displays the list of employees whose employment was terminated within the specified period.

|Column|Description|
|------|-----------|
|**Branch**|The branch or location of your organization where the employee works.|
|**Department**|The department, as defined on the [Departments](EP_20_15_00.md) \(EP201500\) form, that the employee works for.|
|**Employee ID**|The identifier of the employee.|
|**Employee Name**|The name of the employee, as defined on the [Employees](EP_20_30_00.md) \(EP203000\) form.|
|**SSN**|The Social Security Number of the employee.|
|**Status**|The status of the employee, which can be one of the following: -   *Active*: The employee currently works for the company.
-   *On Hold*: The employee account has not yet been activated.
-   *Hold Payments*: Payments should be held for some reason.
-   *One-Time*: The employee is defined as a one-time employee.
-   *Inactive*: The employee has finished his or her work for the company.

|
|**Phone**|The phone number of the employee.|
|**Address**|The address of the employee.|
|**Hire Date**|The date when the employee was hired for the position specified in the **Position** column.|
|**Change Date**|The date when the employee was appointed to another position. If the employee is still actively employed in this position or if the employee's employment in the company has been terminated, the box is empty.|
|**Position**|The position, as defined on the [Positions](EP_20_10_00.md) \(EP201000\) form, that the employee held in the company between the hire date and the termination date.|
|**Termination Date**|The date when the employee's employment in the company was terminated. If the employee is still actively employed in this position, the box is empty.|
|**Payroll Employee**|A check box that indicates \(if selected\) that the employee has a linked payroll record.|
