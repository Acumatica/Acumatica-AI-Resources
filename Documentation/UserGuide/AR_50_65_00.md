# Close Commission Period {#_1299b2ac-e6c5-486b-9240-54b92577cdd8 .reference}

Form ID: \(AR506500\)

On this form, you can view information about commissions earned by salespeople during the selected commission period. You can also close a commission period for which commissions have been calculated on the [Calculate Commissions](AR_50_55_00.md) \(AR505500\) form.

Also, you can reopen the last closed period and void any prepared commissions. Before you open the latest closed period, make sure the commission for the current period has not been calculated or has been voided.

The form is available if the *Commissions* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Void Commissions**|Removes information about prepared commissions from the document database. Reopen a period if you need to void commission for the closed period.|
|**Close Period**|Closes the selected commission period. Only a period for which commission has been prepared \(calculated\) can be closed.|
|**Reopen Period**|Reopens the last closed period, so that the commission for the period can be voided and recalculated.|

## Selection Area {#1 .section}

In this area, you can select a commission period to view its details or to close it.

|Element|Description|
|-------|-----------|
|**Commission Period**|The period for which commissions should be calculated. Commission periods are defined on the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR101000\) form.|
|**Status**|A read-only box that displays the status of the commission period. The following values are used:

 -   *Prepared*: Commission was calculated for the period.
-   *Closed*: The period is closed.
-   *Open*: The commission was not yet calculated for the period.

|
|**From**|A read-only box that shows the start date of the commission period.|
|**To**|A read-only box showing the end date of the commission period.|

## Table {#2 .section}

In this table, you can view the list of salespeople, which includes summary information about commissions they have earned during the selected period.

|Column|Description|
|------|-----------|
|**Salesperson ID**|The unique identifier of the salesperson whose commission is shown in the row.|
|**Name**|The name of the salesperson as specified on the [Salespersons](AR_20_50_00.md) \(AR205000\) form.|
|**Commissionable Amount**|The total amount of the documents used as the basis for commission calculation.|
|**Commission Amount**|The total commission amount earned by the salesperson during the specified period.|
|**Currency**|The currency in which the commission amounts are calculated and displayed.The column appears on the form if the *Multiple Base Currencies* feature has been enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
