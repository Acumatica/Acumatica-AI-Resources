# Revised Contract vs. Approved CO {#_5fd2df43-130c-43d2-a5ff-cd05df15225a .reference}

Form ID: \(PMGI0040\)

**Note:** This form is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This inquiry provides information about the total amount of the revenue change orders approved for the projects and the revised budgeted amounts for these projects.

## Table Toolbar {#section_lkm_nfz_tmb .section}

The table toolbar has only standard buttons.

## Table {#section_hd4_yfz_tmb .section}

The table displays the list of projects along with the information about the revised and approved project amounts. The table has the following columns.

|Column|Description|
|------|-----------|
|**Project**|The identifier of the project.|
|**Description**|The brief description of the project.|
|**Type**|The type of the amount in the line shown for the project:-   *Approved Change Order*: The total revenue change order amount is shown in the **Revised Contract/Change Order Amount** column.
-   *Revised Contract*: The total revised budgeted amount is shown in the **Revised Contract/Change Order Amount** column.

|
|**Revised Contract/Change Order Amount**|The total revenue change order amount for the project, or the total revised budgeted amount for the project, depending on the type of the line.|
