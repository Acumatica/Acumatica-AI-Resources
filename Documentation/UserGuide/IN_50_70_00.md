# Manage Turnover History

Form ID: \(IN507000\)

**Attention:** This form is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

By using this form, you can create new calculations of the inventory turnover and manage the calculations that already exist in the database.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the processing for selected entries in the table based on the action you select.|
|**Process All**|Initiates the processing for all entries in the table based on the **Action** you select.|

## Selection Area

In this area, you can define the period range and company, branch, or group of companies for the entries to be displayed in the table below, as well as the action to be applied if you click **Process** or **Process All**.

-   *Selected Range*: The system creates a single calculation of the inventory turnover for the specified range of periods.

 This box is available only if the *Calculate Turnover* option is selected in the **Action** box in the Selection area of this form.
