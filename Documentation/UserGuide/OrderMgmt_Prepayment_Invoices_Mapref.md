# Processing Prepayment Invoices for Sales Orders {#_e3fd90a2-b37f-4b2a-8b43-aef40de2c86d .concept}

In certain countries, when a company requests a prepayment for a sales order, they must record taxes on the received prepayment. To meet these requirements, in Acumatica ERP, you can create prepayment invoices containing the same items as a particular sales order, as well as the taxes calculated based on the prepayment amount.

You can create a prepayment invoice directly from the sales order; alternatively, if a prepayment invoice has been created manually, you can link it to a sales order.

In this chapter, you will learn how to create prepayment invoices for a sales order in both ways:

-   By creating a new prepayment invoice directly from the sales order.
-   By linking an already-created prepayment invoice to a sales order.
