# Translation History {#_54e7a1be-b218-49fc-8402-242db036afd6 .reference}

Form ID: \(CM401000\)

You can use this form for quick inquiries about translations that were performed in the system.

**Attention:** This form is available only if the *Translation of Financial Statements* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#Selection .section}

In the Selection area, you can select criteria that controls which translations are displayed.

|Element|Description|
|-------|-----------|
|**Translation ID**|The identifier of a translation definition that has been configured on the [Translation Definition](CM_20_30_00.md) \(CM203000\) form.|
|**Fin. Period**|The financial period for which the translation was prepared. If this box is empty, the translations for all periods are shown in the table.|
|**Include Unreleased**|A check box that indicates \(if selected\) that unreleased transactions are shown in the table.|
|**Include Released**|A check box that indicates \(if selected\) that released transactions are shown in the table.|

## Table {#TranslationList .section}

This table contains the list of translations that meet the selection criteria.

|Column|Description|
|------|-----------|
|**Translation Number**|The translation number.|
|**Status**|The status of the translation, which can be *Released* or *Balanced*.|
|**Description**|The description of the translation.|
|**Translation Date**|The date when the translation was prepared.|
|**Translation ID**|The identifier of the translation definition that was used for preparing the translation worksheet.|
|**Branch**|The branch of the company.

 This column appears on the form only if the *Multibranch Support* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md#) \(CS100000\) form.

|
|**Destination Ledger ID**|The identifier of the destination ledger in which the result of translation is stored.|
|**Fin. Period**|The financial period for which the translation was prepared.|
|**Currency Effective Date**|The effective date for the currency exchange rates that were used in the translation.|
|**Translation Batch Number**|The number of the Currency Management batch that was generated when the translation was released.

 This box is empty for the translations with the *Balanced*status.

|
