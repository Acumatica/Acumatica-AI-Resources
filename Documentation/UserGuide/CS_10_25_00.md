# Company Groups

Form ID: \(CS102500\)

On this form, you can create a company group—an entity that includes multiple companies that have access to the same set of customer and vendor records and have the same base currency. For reporting purposes, a company can be included in more than one group.

This form appears in the system if the *Multicompany Support* and *Customer and Vendor Visibility Restriction* features have been enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

**Attention:** Users with the *CS Admin* and *Administrator* roles have the *Delete* rights to this form.

## Form Toolbar

The form toolbar has only standard buttons.

This area contains the summary information about the company group. You can select a company group by its ID to view or edit its information.
