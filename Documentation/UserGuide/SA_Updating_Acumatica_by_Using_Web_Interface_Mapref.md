# Updating Acumatica ERP by Using the Web Interface {#_755cb8d7-426b-46b2-85b6-41aadebcda3e .concept}

Updates for Acumatica ERP provide functional enhancements and new functionality. You need to use an installation package to update your Acumatica ERP instances.

The easiest way of updating Acumatica ERP to a minor product version is by using the web interface.

Alternatively, you can update Acumatica ERP by using the Configuration Wizard if you cannot update it by using the web interface \(for example, for security reasons\). For details, see [Upgrading Acumatica ERP](INST_Upgrading_Mapref.md).
