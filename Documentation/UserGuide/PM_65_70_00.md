# Project Progress Report

Report ID: \(PM657000\)

**Attention:** This report is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this report to analyze the completion progress of the project. The report collects information about the units that were installed or used during the execution of each project task for a particular construction project during the specified period of time.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Project**: Required. The project for which you need to analyze the current progress.
-   **Budget Type**: The type of budget lines to include in the report.
    -   Empty \(default\): Includes both cost and revenue budget lines
    -   *Cost*: Includes only cost budget lines
    -   *Revenue*: Includes only revenue budget lines
-   **Start Date**: The date starting from which the system will collect information from the progress worksheets for the selected project. If this box is empty, the system will collect information from all the progress worksheets for the specified project, starting from the earliest progress worksheet.
-   **End Date**: The end date of the date range for which the system will collect information from the progress worksheets for the specified project. By default, the current business date is inserted.
