# Parent-Child Project Management: Undoing Project Transaction Rollup

If a child project transaction has been rolled up by mistake, you can undo the rollup before the rolled-up transaction is billed from the parent project. This clears the parent-related rollup information from the original child project transaction.

You can undo the rollup on the [Undo Project Transaction Rollup](PM_50_55_00.md) \(PM505500\) mass-processing form, which shows rolled-up transactions of child projects with the *Active* or *Completed* status. You search for the needed project transaction lines, select them, and click **Undo** on the form toolbar. When the processing has been completed, you can view the cleared **Rolled Up** check box, parent project, parent task, parent account group, and parent cost code on the [Project Transactions](PM_30_40_00.md) \(PM304000\) form.

Then you can proceed with correcting the costs recorded for the child project.
