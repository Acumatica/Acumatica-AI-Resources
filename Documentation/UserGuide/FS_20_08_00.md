# Equipment Types

Form ID: \(FS200800\)

On this form, you can add, view, and edit the settings of the type of equipment needed to perform a service.

## Form Toolbar

The form toolbar includes only standard buttons.

## Summary Area

The Summary area contains general information on the equipment type.

|Column|Description|
|------|-----------|
|**Equipment Type**|The unique identifier of the equipment type.|
|**Description**|A description of the equipment type.|
|**Require Branch Location**|A check box that indicates \(if selected\) that the resource can be used in only a specific branch location. Branch locations are defined on the [Branch Locations](FS_20_25_00.md) \(FS202500\) form.|

## Attributes Tab

On this tab, you can add, view, and modify the attributes to be listed \(if they are active\) for equipment of this type on the **Attributes** tab of the [Equipment](FS_20_50_00.md) \(FS205000\) form.

**Note:** On this tab, you can deactivate the attribute and then delete it by using the **Delete Row** button on the table toolbar. In this case, the attribute will be permanently deleted from the service order type, and all attribute values will be deleted from the database.

For an attribute to be added on this tab, it must first be defined in the system on the [Attributes](CS_20_50_00.md) \(CS205000\) form.

The table toolbar has only standard buttons.
