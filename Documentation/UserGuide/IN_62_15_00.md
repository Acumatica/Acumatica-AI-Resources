# Physical Count Variance Preview {#_a918d639-5125-4bc3-9e24-401d9a604794 .reference}

Form ID: \(IN621500\)

**Attention:** This report is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

This report lists the inventory items included into physical inventory, and displays the book quantities \(the on-hand quantities from which the quantities on unreleased issues and the quantities on confirmed shipments are deducted\) and count results for the items.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameter to select the information to be displayed on the report:

-   **Reference Nbr.**: The reference number of the physical inventory document for which you want to list inventory items.
