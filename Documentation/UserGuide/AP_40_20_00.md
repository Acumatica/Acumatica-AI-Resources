# Vendor Details

Form ID: \(AP402000\)

This form is intended for quick inquiries about a specific vendor's outstanding balance. You can view the balance for a particular financial period and a specified currency. If no currency is selected, all amounts are displayed in the base currency.

**Attention:** Amounts of debit adjustments, which have the negative sign, are considered in the calculation of the vendor's balance.

By default, the form displays the list of open vendor documents \(that is, those with the *Open* status\), but you can add to the list closed documents and unreleased documents by selecting the **Show All Documents** and **Include Unreleased Documents** check boxes, respectively.

## Selection Area

You use the elements in this area to specify the criteria of the vendor documents you want to view.

<table><thead><tr><th>

Element

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Company/Branch**

</td><td>

The company or branch for which you want to view information. By default, the current company or branch is selected.

 This box is required if the *Multiple Base Currencies* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

</td></tr><tr><td>

**Vendor**

</td><td>

Required. The vendor, by its ID, for which documents will be displayed.

 The list of values may be limited as follows:

 -   If a branch is selected in the **Branch** box, a vendor is listed \(and available for selection\) if the **Restrict Visibility To** box on the **Financial** tab of the [Vendors](../Shared/../UserGuide/AP_30_30_00.md) \(AP303000\) form is empty or contains this branch or the company of this branch.
-   If the **Branch** box is empty, a vendor is listed \(and available for selection\) if one of the following is true:

    -   The **Restrict Visibility To** box is empty for the vendor—that is, the vendor’s visibility is not restricted.
    -   A branch or company is specified in the **Restrict Visibility To** box for the vendor, and your user account is assigned to the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company.
**Attention:** These visibility restrictions are applicable only if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.


</td></tr><tr><td>

**Period**

</td><td>

The financial period for which vendor documents will be displayed. If you select no period, vendor documents for all open periods will be displayed.

</td></tr><tr><td>

**AP Account**

</td><td>

The AP account used in operations with the vendor for which vendor documents will be displayed. You don't need to select an account.

</td></tr><tr><td>

**AP Subaccount**

</td><td>

The corresponding subaccount for which vendor documents will be displayed. You don't need to select a subaccount.

</td></tr><tr><td>

**Currency**

</td><td>

The currency of the documents to be included in the list. Leave the box empty to display all documents that meet the other criteria you have selected.

</td></tr><tr><td>

**Show All Documents**

</td><td>

A check box that indicates \(if selected\) that closed documents \(that is, those with the *Closed* status\) are included in the list.

 The check box is displayed if no financial period is selected in the **Period** box.

</td></tr><tr><td>

**Include Unreleased Documents**

</td><td>

A check box that indicates \(if selected\) that unreleased documents \(that is, those with the *On Hold* and *Balanced* statuses\) are included in the list.

 If this check box is selected, the balances of unreleased documents will be included in the amount of the **Balance by Documents** box, and the **Balance Discrepancy** box will show the total amount of the unreleased documents of this vendor.

</td></tr><tr><td>

**Use Master Calendar**

</td><td>

A check box that indicates \(if selected\) that the data in the table will be shown for the master calendar. That is, when the check box is selected, the table will show the vendor details posted for the master calendar. If the check box is cleared, the data in the table will be shown for the company calendar.

 If the **Company/Branch** box is blank, this check box is selected by default.

 This check box appears on the form only if the *Multiple Calendar Support* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 For details on running consolidated reports and inquiries, see [Consolidated Reports for Companies with Different Calendars](GL__CON_Consolidated_Reports_for_Companies_with_Different_Calendars.md).

</td></tr><tr><td>

**Balance by Documents**

</td><td>

Read-only. The vendor’s accumulated open balance, which is calculated based on documents of all types \(including prepayments\) for the vendor at the end of the selected period. \(If no period is specified, the balance is calculated at the end of the latest activity period.\) If the **AP Account** and **AP Subaccount** are specified, this box shows the balance accumulated for the specified combination of account and subaccount.

 The system calculates the amount in this box by adding the **Prepayment Balance** and **Current Balance** amounts, but this calculation may be inaccurate if the **Include Unreleased Documents** check box is selected.

 If the **Include Unreleased Documents** check box is selected, the unreleased documents are loaded to the table, and their amounts are included in the amount in this box. In this case, the **Balance by Documents** may differ from the **Current Balance** minus the **Prepayment Balance**. The **Balance Discrepancy** box will show the total amount of the unreleased documents of this vendor.

</td></tr><tr><td>

**Current Balance**

</td><td>

Read-only. The vendor’s balance for the selected period \(or for the latest activity period if no period is specified\). Prepayments are excluded from this amount. If the **AP Account** and **AP Subaccount** are selected, this box shows the balance accumulated for the specified combination of account and subaccount.

 **Attention:** The value of this box is retrieved from the `APHistory` database table. Thus, this balance has nothing to do with posting to the general ledger.

The balances of the vendor's documents will be included in the amount of this box if either of the following is true:

-   The corresponding GL batches are unposted or reversed.
-   The documents were created in migration mode and do not update the general ledger at all.

 The system calculates the amount in this box by subtracting the **Prepayment Balance** from the **Balance by Documents**. This value will be inaccurate if the **Include Unreleased Documents** check box is selected, however, because the balances of unreleased documents are not included in the **Current Balance** and **Prepayment Balance** amounts.

 If you have no selection criteria specified on the current form other than the vendor, the value in this box is the same as the value displayed in the **Balance** box on the [Vendors](AP_30_30_00.md) \(AP303000\) form.

</td></tr><tr><td>

**Prepayment Balance**

</td><td>

Read-only. The total amount of open prepayments for the selected period \(or for the latest activity period if no period is specified\). If the **AP Account** and **AP Subaccount** are selected, this box shows the prepayment balance accumulated for the specified combination of account and subaccount.

 **Attention:** The value of this box is retrieved from the `APHistory` database table. Thus, this balance has nothing to do with posting to the general ledger.

The balances of the vendor's documents will be included in the amount of this box if either of the following is true:

-   The corresponding GL batches are unposted or reversed.
-   The documents were created in migration mode and do not update the general ledger at all.

</td></tr><tr><td>

**Balance Discrepancy**

</td><td>

Read-only. The balance discrepancy, if applicable. This is the difference between the **Balance by Documents** value and the sum of the **Current Balance** and **Prepayment Balance** values. If unreleased documents are not included \(that is, if the **Include Unreleased Documents** check box is cleared on this form\), the **Balance Discrepancy**value should be *0*. If the value is nonzero, there may be errors in the database. In this case, we recommend running the [Recalculate Vendor Balances](AP_50_99_00.md) \(AP509900\) process to find discrepancies in records.

</td></tr><tr><td>

**Retained Balance**

</td><td>

Read-only. The total amount of unreleased retainage withheld from the vendor bills in the selected branch at the end of the period \(if specified\) or at the end of the last activity period \(if the period is not specified\).

 This box appears on the form if the *Retainage Support* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

</td></tr></tbody>
</table>
