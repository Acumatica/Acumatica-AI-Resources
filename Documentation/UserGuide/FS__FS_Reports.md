# Service Management Reports {#_f53b004e-fa47-466d-b3b6-8acc0330e9de .concept}

With the wide variety of Acumatica ERP reports related to service management, you can promptly get detailed information about appointments and service orders. You can also analyze the data by various criteria, and track service operations for different customers and locations. If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All service management reports can be generated in different formats, including PDF and HTML, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
