# Carrier Labels and Tracking Numbers {#_264f8cc4-60da-4230-b7cb-b0605f196f41 .concept}

With integration between Acumatica ERP and carriers, you can initiate printing carrier labels for particular packages \(boxes\) by using the [Shipments](SO_30_20_00.md) \(SO302000\) form. If RMA orders are used in your system, you can also print carrier labels for RMA orders. Labels are generated by the carrier services and are received \(through the integration between the carrier and Acumatica ERP\) as images ready for printing. In Acumatica ERP, labels are printed by using the [Carrier Labels](SO_64_50_00.md) \(SO645000\) report.

**Note:** Any information you type in the **Custom Ref. Number 1** and **Custom Ref. Number 2** columns on the **Packages** tab of the [Shipments](SO_30_20_00.md) form will be printed on the labels.

## Process of Generating Tracking Numbers and Labels { .section}

The general process of generating tracking numbers and labels is the following:

1.  A user confirms a shipment in Acumatica ERP.
2.  The carrier's service generates a tracking number and a label for each package of a shipment and sends this information to Acumatica ERP.

    Users can view the generated tracking numbers in the **Tracking Number** column on the **Packages** tab of the [Shipments](SO_30_20_00.md) form. Labels can be found in the **Files** column of each shipment line.

3.  A user initiates printing labels in Acumatica ERP by using the [Shipments](SO_30_20_00.md) form, as described in [To Print a Label](SO__How_Print_Label.md).

## Configuration of Label Printing { .section}

To configure the printing of carrier labels, you do the following:

1.  Register file extensions for labels as described in [To Register the Label File Extension](SO__How_Set_UP_Regular_Printer.md).
2.  Configure printing in one of the following ways:
    -   If you use DeviceHub, configure printing as described in [Printers: To Add a Printer to DeviceHub](../ImplementationGuide/DeviceHub_To_Add_Printers_to_DeviceHub_Implem_Activity.md).

        In addition, if a carrier you work with uses labels of specific size, you can configure the system so that it uses a particular printer for printing the labels of this carrier. These settings are specified on the [User Profile](SM_20_30_10.md) \(SM203010\) form. For more information, see [Printers: Specification of Default Printers](../ImplementationGuide/DeviceHub_Configuration_of_Default_Printers.md).

    -   If you do not use DeviceHub, you configure printing as described in [To Set Up the Printing of Carrier Labels on a Thermal Printer](SO__How_Set_Label_Printing.md).
