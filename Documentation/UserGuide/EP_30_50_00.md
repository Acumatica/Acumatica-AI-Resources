# Employee Time Cards

Form ID: \(EP305000\)

You use this form to enter new time cards or review and adjust existing ones. Each time card spans a period that the system defines based on the employee frequency, and a new time card can be entered only when the previous time card has been released. For more details about time cards, see [Employee Time Entry: Time Cards](TimeExpenses_Entering_Employee_Time_Time_Cards.md).

**Attention:** You can create, view, or adjust time cards if the username you are signed in with is associated with an employee—that is, if the employee has the username specified in the **Employee Login** box on the **General Settings** tab of the [Employees](EP_20_30_00.md) \(EP203000\).

This form is available only if the *Advanced Financials* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Details Tab

This tab displays the employee’s time activities for the period of the time card, along with detailed information about the work hours and any associated projects and project tasks. Non-canceled time activities are listed if their **Reported On** date on the [Email Activity](CR_30_60_15.md) \(CR306015\) or [Activity](CR_30_60_10.md) \(CR306010\) form—the date when the time activity was reported in the original time zone—falls within the specified period.

If any listed activity is associated with a project that has the **Restrict Employees** check box selected on the **Summary** tab of the [Projects](PM_30_10_00.md) \(PM301000\) form, the employee must be included on the **Employees** tab for that project. Otherwise, an error may occur when the time card is processed.

If an error occurs, add the employee to the list so that the time card can be released. \(After the time card has been released, you can remove the employee from the list again.\)

You should not use this tab to adjust the time in a corrective time card; for this purpose, use the **Summary** tab.

**Attention:** If you delete a detail row in a time card, the corresponding activity is deleted from the system.

## Approvals Tab

This tab displays information about the employee time card approvals or rejections. The system automatically performs assignment for approval when time cards are taken off hold, in accordance with the approval map specified for employee time cards on the [Time and Expenses Preferences](EP_10_10_00.md) \(EP101000\) form. Authorized users approve employee time cards, along with documents of other types, by using the [Approvals](EP_50_30_10.md) \(EP503010\) form. For details, see [Employee Time Entry: Time Cards](TimeExpenses_Entering_Employee_Time_Time_Cards.md).

This tab displays the approval entries associated with the selected record. If the record has existing *Approved* or *Rejected* entries and is put on hold for editing, these entries are preserved on the tab and the **Obsolete** check box is selected for them. Approval entries with a *Pending* decision are deleted. When the record is resubmitted for approval, new approval entries are created for this approval cycle. You can filter the approval entries on the tab by selecting one of the following filters: *All Records*, *Approved*, *Current* \(default\), *Pending*, or *Rejected*.

This tab is available only if the *Approval Workflow* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.
