# Statement History {#_cc0212e1-d172-4eb3-8161-77121bdb7103 .reference}

Form ID: \(SP324010\)

**Who uses this form:** An authorized portal user of a company using the Modern Customer Portal.

On this form, you can view your company's statement reports prepared by the vendor at the end of each statement cycle. Each report provides a record of your company’s financial activity for a specific period and shows the ending balance. You can use this information to review and reconcile your account balance.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Statement Reports Tiles { .section}

You can view your company's statement reports and their balances as of different dates. The statement reports are shown as a set of tiles, each showing particular data \(described below\) about the report.

By default, all statement reports are visible when you open the form. You can use filtering and search capabilities to view a smaller set of reports.

|Element|Description|
|-------|-----------|
|Date|The statement date, which is displayed as a link. When you click the link with a statement date, the system opens the statement report with this date. You can save or print it, if needed.|
|**Branch**|Your company's branch for which the statement report is created.|
|**Statement Balance**|The statement balance as of the report creation date.|
