# Calendar Week Codes {#_1338c424-196e-4466-b126-31594230894c .reference}

Form ID: \(FS205900\)

On this form, you can generate the calendar week codes for later use in route management.

**Attention:**

We recommend the following for generating week codes by using this form:

-   Generate the week code calendar in the period of time it will be used.
-   Do not leave days between generation.
-   Do not manually edit, add, or eliminate the rows in the calendar week code table.

## Form Toolbar { .section}

The form toolbar includes standard buttons and form-specific menu. The form-specific button is listed below.

|Buttons|Description|
|-------|-----------|
|**Generate Week Codes**|Opens the **Calendar Week Code Generation Options** dialog box, so you can generate the week codes for the specified time interval.|

|Elements|Description|
|--------|-----------|
|**Default Start Date**|By default, the starting date of the calendar in the system.|
|**Initial Week Code**|By default, the starting week code for the default start date of the calendar in the system. The calendar week code will be generated based on the initial week code of the default start date.|
|**From Date**|The starting date of the generation of week codes in the system.|
|**To Date**|The end date of the generation of week codes in the system.|
|The following buttons are located at the bottom of the dialog box.|
|**Generate Week Codes**|Opens the **Confirm Calendar Week Code Generation** confirmation box, where you review the dates and click one of the following buttons:-   **OK**: To proceed with the week code generation.
-   **Cancel**: To cancel the operation.

|
|**Close**|Closes the dialog box without taking any action.|

## Table { .section}

This table displays the generated week codes.

|Column|Description|
|------|-----------|
|**Date**|The date in the calendar week code.|
|**Week Code**|The week code corresponding to the date.|
|**Week Code P1**|The first digit in the week code, indicating a recurrence every four weeks.|
|**Week Code P2**|The second digit in the week code, with the combination of the first and second digits occurring every eight weeks.|
|**Week Code P3**|The third digit in the week code, with the combination of the first, second, and third digits occurring every 16 weeks.|
|**Week Code P4**|The fourth digit in the week code, with the combination of the first, second, third, and fourth digits occurring every 32 weeks.|
|**Day of Week**|The day of the week in the calendar week code.|
|**Week of Year**|The week of the year in the calendar week code.|
|**Start Date of Week**|The Monday of the week in the calendar week code.|
|**End Date of Week**|The Sunday of the week in the calendar week code.|
