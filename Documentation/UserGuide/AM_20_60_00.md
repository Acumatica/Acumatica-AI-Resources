# Estimate Classes {#_b925b22f-8a4a-4eb5-8e9a-c516ff46b1c7 .reference}

Form ID: \(AM206000\)

Estimate classes are required when creating an estimate on the [Estimate](AM_30_30_00.md) \(AM303000\) form and are used for defaults and reporting of estimates.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area { .section}

|Element|Description|
|-------|-----------|
|**Class ID**|The unique identifier of the estimate class.|
|**Description**|A description of the estimate class.|

## General Settings Section { .section}

|Element|Description|
|-------|-----------|
|**Item Class**|The item class to be defaulted to the estimate when the estimate class is selected.|
|**Tax Category**|Required for reference. Used on sales orders and opportunities indicating the tax status for the line.|
|**Engineer**|Default user ID responsible for engineering the estimate.|
|**Lead Time \(Days\)**|Default lead time for items of this class.|
|**Order Qty.**|Default order quantity for items of this class.|

## Default Markups Section { .section}

|Element|Description|
|-------|-----------|
|**Labor Markup \(%\)**|Default estimate price markup percentage for labor costs.|
|**Machine Markup \(%\)**|Default estimate price markup percentage for machine costs.|
|**Material Markup \(%\)**|Default estimate price markup percentage for material costs.|
|**Subcontract Markup \(%\)**|Default estimate price markup percentage for subcontract costs.|
|**Tool Markup \(%\)**|Default estimate price markup percentage for tool costs.|
|**Overhead Markup \(%\)**|Default estimate price markup percentage for overhead costs.|
