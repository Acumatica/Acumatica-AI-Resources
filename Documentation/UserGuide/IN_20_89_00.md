# Physical Inventory Types {#_b83fc037-f166-499e-8a32-cbb560e91ee5 .reference}

Form ID: \(IN208900\)

**Attention:** This form is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

On this form, you can define the types of physical inventory counts to be used at your company warehouse or warehouses.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

You use this area to create a new type of physical inventory count. You can also select an existing type to modify it or view its details.

|Element|Description|
|-------|-----------|
|**Type ID**|The unique identifier of the type of the physical inventory counts.|
|**Description**|A description of the type.|
|**Generation Method**|The method to be used to generate counting lists for the type. Select one of the following options: -   *Full Physical Inventory*: To include all the items available at the specified warehouse or locations.
-   *By Inventory*: To count only particular inventory items, which you specify on the **Inventory Item Selection** tab.
-   *By Movement Class*: To include only the items for which counting is due based on the counting frequency associated with their movement classes. If you select this generation method, choose the movement class on the **Movement Class Selection** tab. The count frequency of a movement class is the number of counts per year required for its items, as set on the [Movement Classes](IN_20_86_00.md) \(IN208600\) form.

This option appears only if the *Advanced Physical Counts* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

-   *By ABC Code*: To include only the items associated with the specific code or items for which counting is due based on the counting frequency associated with items' ABC codes. You can select the code using the appropriate tab. The count frequency is determined by the counts per year value, as set on the [ABC Codes](IN_20_85_00.md) \(IN208500\) form.

This option appears only if the *Advanced Physical Counts* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

-   *By Cycle*: To include only the items for which counting is due based on the assigned PI cycles. You can select the cycle by using the appropriate tab.

This option appears only if the *Advanced Physical Counts* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

-   *By Item Class*: To include only items belonging to the specific class. You can select the class by using the appropriate tab.

|
|**Include Items with Zero Book Quantity in PI**|A check box that indicates \(if selected\) that the system must include items with a zero book quantity in a PI document for a physical inventory of the selected type. When this check box is selected, location-item pairs \(from the generation method\) in which items have a book quantity of zero \(except lot-tracked or serial-tracked items\) are added to a PI document on the [Physical Inventory Review](IN_30_50_00.md) \(IN305000\) form if the items have been stored in the locations for the past year. For physical inventory types with the *By Inventory* generation method and the *Last Count On or Before* selection method, the date of the last physical inventory count is also checked. If the date is more than one year ago and there were item movements in a warehouse location since the last physical inventory, the location is included in the current physical inventory count.

 This check box is available for all types of physical inventory except types with the *Full Physical Inventory* generation method and types with the *By Inventory* generation method and the *Items Having Negative Book Qty.* selection method.

 By default, the check box is cleared.

|
|**Unfreeze Stock When Counting Is Finished**|A check box that indicates \(if selected\) that inventory items included in a physical inventory of this type become available for warehouse operations after the counting is finished \(that is, when the physical inventory document has the *Data Entering* or *In Review* status on the [Physical Inventory Review](IN_30_50_00.md) \(IN305000\) form\).

 **Important:** Unfreezing stock items before releasing an adjustment may cause discrepancies in the quantity or cost of stock items.

|
|**Hide Book Qty. on PI Count**|A check box that indicates \(if selected\) that the **Book Quantity** column is not displayed on the [Physical Inventory Count](IN_30_50_10.md) \(IN305010\) form.

 By default, this check box is selected for new physical inventory types.

|

## Warehouse/Location Selection Tab {#2 .section}

By using this tab, you can view or define the warehouse where physical inventories of this type take place. This tab appears only if the *Multiple Warehouses* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. If this feature is enabled in your system, you can specify locations. If no warehouse and locations are specified for this type of physical inventory counting, the type can be used at any warehouse and any locations. You can select the particular warehouse and locations for generating count sheets on the [Prepare Physical Count](IN_50_40_00.md) \(IN504000\) form.

|Element|Description|
|-------|-----------|
|**Warehouse**|The particular warehouse where counting of this type will take place. You can leave the box blank to apply this type at any warehouse.|

|Button|Description|
|------|-----------|
|**Add**|Opens the dialog box that you can use to enter a scope of locations. Select the start location in the **Start Location** box, select the end location in the **End Location** box, and then click **Add** to add the selected scope of locations to the **Locations** table.|

|Column|Description|
|------|-----------|
|**Location**|The location where counting of the type will take place.|
|**Description**|The description of the location.|
|**Pick Priority**|The pick priority specified for the location.|

## Inventory Item Selection Tab {#5 .section}

You use this tab, which appears when you select the *By Inventory* generation method, to create a list of particular inventory items for counts of this physical inventory type; you can instead select items at random, by their previous count date, or if they have negative quantities at one or more locations.

The table toolbar has only standard buttons.

|Element|Description|
|-------|-----------|
|**Selection Method**|The option to be used for selecting inventory items for counting of the type: -   *Items Having Negative Book Qty.*: Includes in the count items that have a negative quantity at one or more locations.
-   *Random Items*: Includes items selected at random up to the specified number of items. You specify the **Max. Number of Items**; this element appears once the option is selected.
-   *List of Items*: Includes the specific items you list in the **Items** table.
-   *Last Count On or Before*: Includes items that were counted before the specified number of days from the current business date. Specify the number of days in **Last Count Before \(Days\)**; this element appears if you select this option.

|

|Button|Description|
|------|-----------|
|**Add**|Opens the dialog box that you can use to add multiple items to the **Items** table.|

|Column|Description|
|------|-----------|
|**Inventory ID**|The identifier of the inventory item.|
|**Description**|The description provided for the inventory item.|
|**Item Status**|The status of the inventory item.|
|**Item Class**|The item class associated with the item.|

## Movement Class Selection Tab {#6 .section}

This tab, which appears only if you select the *By Movement Class* generation method, provides item selection options associated with movement classes.

|Element|Description|
|-------|-----------|
|**Movement Class**|The movement class whose items will be included in the count of the type.|
|**By Frequency**|A check box that indicates \(if selected\) that the items will be selected for counting from those that are due by frequencies associated with all movement classes.|

## ABC Code Selection Tab {#7 .section}

This tab, which appears when you select the *By ABC Code* generation method, provides item selection options associated with ABC codes.

|Element|Description|
|-------|-----------|
|**ABC Code**|The ABC code whose items will be included in the count of the type.|
|**By Frequency**|A check box that indicates \(if selected\) that the items will be selected for counting from those that are due by frequencies associated with all ABC codes.|

## PI Cycle Selection Tab {#8 .section}

This tab, appearing only when you select the *By Cycle* generation method, provides two alternative item selection options associated with the physical inventory cycles.

|Element|Description|
|-------|-----------|
|**Cycle ID**|The physical inventory cycle whose items will be included in the count of the type. If you select the cycle, leave the **By Frequency** check box clear.|
|**By Frequency**|A check box that indicates \(if selected\) that the items will be selected for counting from those that are due by frequencies associated with all PI cycles. Selecting this check box disables the **Cycle ID** box.|

## Item Class Selection Tab {#9 .section}

By using this tab \(shown only if you select the *By Item Class* generation method\), you can select the item classes for counts of this physical inventory type.

|Element|Description|
|-------|-----------|
|**Item Class ID**|The item class for which the physical inventory count should be performed. If you add an item class that has child item classes to this table, the physical inventory count is performed for the selected item class and all of its children as well.|
|**Description**|The description of the item class.|
