# Release Schedules {#_1d4039a3-2ea1-4153-8583-eab6afca0f68 .reference}

Form ID: \(DR503000\)

On this form, you release custom deferral schedules. Custom deferral schedules are the schedules that you create manually by using the [Deferral Schedule](DR_20_15_00.md) \(DR201500\) form. You can link a custom schedule to the required document at the time of creating the schedule or at any later time.

You may need to create custom schedules manually for documents that were imported to Acumatica ERP from third-party software or that were released without deferral codes specified. For details, see [Custom Deferral Schedules](DR__con_Custom_Deferral_Schedules.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Processes the schedules that you have selected in the table.|
|**Process All**|Processes all the listed schedules.|

## Selection Area {#1 .section}

You use the elements in this area to select custom schedules for processing by the deferral account, deferral code, and customer or vendor. Also, you can select schedules linked to specific components. For details about packages and components, see [Managing Recognition for Packages](DR__con_Revenue_Recognition_for_Packages.md).

|Element|Description|
|-------|-----------|
|**Code Type**|The type of deferral codes for which you want to process deferral schedules.|
|**Deferral Code**|The particular deferral code for which you want to review and process transactions.

 You can change the deferral code in this column manually, if needed. When you click the selector button in the column, the lookup table that opens shows only the deferral codes for which the **Active** check box is selected in the Summary area of the [Deferral Codes](DR_20_20_00.md) \(DR202000\) form.

|
|**Deferral Account**|The account used to record the deferred amounts.|
|**Deferral Sub.**|The subaccount used to record the deferred amounts.|
|**Branch**|The branch for which the deferred amounts are recorded.

 This box appears on the form when the *Multibranch Support* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Component**|The particular component for which you want to view deferral transactions.|
|**Business Account**|A business account \(which can be, for example, a customer or a vendor\) whose deferral transactions you want to view.

 In this box, you can select a customer or vendor whose settings permit the use of the branch selected in the document—that is, a customer or vendor for which the **Restrict Visibility To** box on the **Financial** tab of the [Customers](AR_30_30_00.md) \(AR303000\) or [Vendors](AP_30_30_00.md) \(AP303000\) form is empty or contains the branch specified in this document \(or the company or company group that contains this branch\) and your user account is assigned to the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company or a company of the company group.

 **Attention:** These visibility restrictions are applicable only if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|

## Table {#2 .section}

This table includes all the unreleased custom schedules created for documents released with no deferral codes assigned. You can create custom schedules on the [Deferral Schedule](DR_20_15_00.md) \(DR201500\) form.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include the schedule in processing when you click **Process**.|
|**Schedule Number**|The unique number of the deferral schedule, which was automatically generated by the system when you created a custom schedule for the document released without a deferral code assigned. When you click this number, the [Deferral Schedule](DR_20_15_00.md) \(DR201500\) form opens in a pop-up window.|
|**Deferral Code**|The deferral code used for the document line \(or item component, if the line item is a package\).|
|**Doc. Type**|The type of the original document, the schedule transactions are based on.|
|**Ref. Nbr.**|The reference number of the original document. When you click this number, the system navigates you to the form where the document was created, on which you can view the document details.|
|**Branch**|The branch of the document line.|
|**Component ID**|The component of the line item if the line item is a package and consists of components; otherwise, the inventory ID of the line item.|
|**Total Amount**|The amount of the document line.|
|**Currency**|The currency of the schedule. This setting is copied from the schedule currency specified on the [Deferral Schedule](DR_20_15_00.md) \(DR201500\) form.

 This column appears on the form if the *Multiple Base Currencies* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Deferral Account**|The account to record the unrecognized \(deferred\) amount.|
|**Deferral Sub.**|The subaccount used for the deferral.|
|**Date**|The date when the original document was created.|
|**Post Period**|The period to post transactions.|
|**Business Account**|The customer or vendor associated with the original document.|
|**Deferred Amount**|The deferred amount for the document line.

 **Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Line Nbr.**|The line in the original document for which the deferral schedule was created.

 **Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
