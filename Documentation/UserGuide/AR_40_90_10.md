# Discrepancies by Account {#_0fb1dda9-64b4-433e-970c-76ab2bec7737 .reference}

Form ID: \(AR409010\)

You can use this form to find any discrepancies between AR and GL accounts in a particular range of financial periods. This table shows the list of accounts that meet the criteria you have specified and that were updated within the specified range of periods.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

In this area, you select the settings that determine the AR accounts \(and their discrepancies, if applicable\) to be listed in the table.

|Element|Description|
|-------|-----------|
|**Branch**|Required. The branch for which you want to display data. By default, the system inserts the branch you are currently signed in to.

|
|**From Period**|Required. The starting financial period in the range of periods during which the accounts to be listed were updated.|
|**To Period**|Required. The ending financial period in the range of periods during which the accounts to be listed were updated.|
|**Account**|Required. The AR account for which you want to display data.|
|**Subaccount**|Optional. The subaccount of the selected account. You can specify a subaccount to see account data for only the particular account-subaccount pair or enter a subaccount mask to see account data for all account-subaccount pairs that meet the selection criteria. You can also leave the box blank to view the account data broken down by all subaccounts of the selected account.

 This box appears on the form if the *Subaccounts* feature has been enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Show Only Documents with Discrepancies**|A check box that indicates \(if selected\) that the table should list only accounts to which documents \(meeting the other selection criteria\) with discrepancies were posted.|
|**Total GL Amount**|The turnover for the selected account \(or all accounts if the **Account** box is left blank\) within the specified range of financial periods according to the general ledger records. This amount is the sum of the amounts in the **GL Turnover** column of the table.|
|**Total AR Amount**|The turnover for the selected account \(or all accounts if the **Account** box is left blank\) within the specified range of financial periods. This amount is the sum of the amounts in the **AR Turnover** column of the table.|
|**Total Discrepancy**|The total discrepancy for all the listed accounts, which is the sum of the amounts in the **Discrepancy** column for each row in the table.|

## Table { .section}

This table contains the list of accounts that were updated within the specified range of financial periods, one row for each account that was updated and each financial period of update, including any discrepancies associated with each account in the range.

|Column|Description|
|------|-----------|
|**Account**|The selected account for which you want to find discrepancies.|
|**Subaccount**|Optional. The subaccount of the selected account for which you want to find discrepancies.

 This column appears on the form if the *Subaccounts* feature has been enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Financial Period**|The financial period for which data is displayed. This box is hidden by default.|
|**GL Turnover**|The turnover for the account \(and subaccount, if applicable\) in the row within the financial period displayed in the row, according to the general ledger transactions posted in this period.|
|**AR Turnover**|The turnover for the account \(and subaccount, if applicable\) listed in this row within the financial period displayed in the row; this amount is calculated based on the accounts receivable documents updated in this period.|
|**Non-AR Transactions**|The amount of the transactions posted to the account listed in this row by subledgers other than accounts receivable.|
|**Discrepancy**|The discrepancy between the GL turnover, according to GL records, and the AR turnover, which is based on accounts receivable documents \(excluding the amount of the transactions posted by non-AR subledgers, which is displayed in the **Non-AR Transactions** column\).

 If you click this link, the system opens the [Discrepancies by Customer](AR_40_90_20.md) \(AR409020\) form in a separate window, where you can review the list of customers for which at least one document has been created that caused this discrepancy.

|
