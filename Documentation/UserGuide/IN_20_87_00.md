# Physical Inventory Cycles {#_bbacc11f-a3a9-41f9-adaf-d507371eaab2 .reference}

Form ID: \(IN208700\)

**Attention:** This form is available only if the *Advanced Physical Counts* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to define physical inventory cycles \(PI cycles\) used in your company. The physical inventory cycles are used to group the inventory items for periodic counting with the class-specific period. For more details on using PI cycles, see [Configuration of Physical Inventory](IN__con_Planning_for_Physical_Inventory.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Physical Inventory Cycles { .section}

This table displays the physical inventory cycles defined in the system. You can edit the inventory cycles and define new cycles.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Cycle ID**|The ID of the physical inventory cycle. An alphanumeric string of up to 6 characters can be used.|
|**Description**|A brief description of the physical inventory cycle.|
|**Counts Per Year**|The number of counts per year for the physical inventory cycle.|
