# Manage Credit Holds

Form ID: \(AR523000\)

By using this form, you can place customers that have overdue invoices and have received the final dunning letters on credit hold; you can also remove the credit hold for the customers after they have paid.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the processing, based on the selected action, of the customer accounts you have selected.|
|**Process All**|Initiates the processing of all customer accounts listed in the table.|

## Selection Area

In this area, you can select the action to be performed if you click **Process** or **Process All**. Also, you can specify the time interval during which the final dunning letters were generated.

**Action**

</td><td>

The operation the system performs if you click **Process** or **Process All**. The following options are available: -   *Credit Hold*: Prevents users from creating any new sales orders for the selected customers.

If you select this option, the table will include only the customers eligible for a credit hold to be applied. That is, the table will include the customers for which the final dunning letters were generated *and* to which a credit hold was not applied. This rule applies only when the **Show All** check box is cleared.

-   *Remove Credit Hold*: Takes the selected customer accounts off hold so that new sales orders can be created.

If you select this option, the table will include only the customers eligible for removing the credit hold, that is, customers with the *Credit Hold* status. If this option is selected, the **Start Date** and **End Date** boxes are not shown on the form.

**Date Range**

The starting and ending dates of the date range within which the final dunning letters were generated. The box is empty by default. If the start date is specified, the table shows only the customer records with the *Active* or *One-Time* status whose final dunning letter date is the same as or later than the specified date. If the end date is specified, the table shows only the customer records with the *Active* or *One-Time* status whose final dunning letter date is earlier than or the same as the specified date.

 This box appears on the form if the *Credit Hold* option is selected in the **Action** box.

## Table

This table contains the list of customers for which the final dunning letters were generated in the specified date range or the customers that are eligible for removing the credit hold. The list of customers may be limited based on the current user's access role. The system displays customers whose settings permit the use of the branch, company, or a company in a company group to which the user's role is assigned \(the **Restrict Visibility To** box on the **Financial** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form contains this branch, company, company group, or is empty\).

The table toolbar has only standard buttons.
