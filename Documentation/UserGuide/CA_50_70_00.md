# Import Settlement Batches

Form ID: \(CA507000\)

On this form, you can start the process of importing settlement batches by selecting the processing center and clicking **Import Batches** on the form toolbar. The import of settlement batches can be started if no previous import is in progress for the selected processing center.

**Attention:** This form appears in the system if the *Integrated Card Processing* feature has been enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Import Batches**|Starts the import of settlement batches.|

## All Records Tab

The table on this tab displays a list of all settlement batches for the processing center selected in the **Proc. Center ID** box of the Summary area.

**Attention:** Each EFT batch includes only one transaction.

<table id="_e5e360bd-e259-4301-b1c5-d464c9fe92f2"><thead><tr><th>

Column

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Reference Number**

</td><td>

The reference number of the settlement batch. You can click this link to open the settlement batch on the [Settlement Batches](CA_30_70_00.md) \(CA307000\) form.

</td></tr><tr><td>

**Status**

</td><td>

The processing status of the settlement batch, which can be one of the following:-   *Pending Import*: A batch has been created, and the import of transactions has not yet started or has ended without all the transactions being imported.
-   *Pending Processing*: The processing of transactions has resulted in an error, and the batch should be processed again.
-   *Processing*: Transactions are being imported from the processing center or matched to transactions in Acumatica ERP.
-   *Pending Review*: Automatic processing has finished, but some transactions are missing.
-   *Processed*: All transactions in the settlement batch have been matched to transactions in Acumatica ERP or hidden.
-   *Deposited*: A bank deposit based on the settlement batch has been created, or there are no payments to deposit.
-   *Error*: An error has occurred during import.

</td></tr><tr><td>

**Ext. Batch ID**

</td><td>

The batch ID in the processing center.

 For an EFT settlement batch, this value is the same as the transaction ID in the processing center.

</td></tr><tr><td>

**Settlement State**

</td><td>

The state of the batch in the processing center. The state can be one of the following:

 -   *Settled Successfully*: The batch has been approved and successfully settled.
-   *Settlement Error*: An error occurred when the system tried to settle the batch.
-   *Pending Settlement*: The batch has been submitted for settlement and will be settled at the transaction cutoff time.
-   *Unknown*: The processing center couldn’t determine the batch settlement status.
-   *Rejected*: The EFT transaction in the batch has been rejected by the processing center.
-   *Voided*: The EFT transaction in the batch has been voided in the processing center.

 **Attention:** Only transactions with the *Settled Successfully*, *Refund Settled Successfully*, and *Rejected* states can be included in a bank deposit.

## Unprocessed Batches Tab

The table on this tab lists settlement batches that have a status other than *Deposited*. These batches are also listed on the **All Records** tab. \(The same columns are displayed on both tabs.\)
