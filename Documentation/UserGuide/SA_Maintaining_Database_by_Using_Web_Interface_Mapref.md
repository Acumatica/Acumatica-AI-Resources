# Maintaining Database by Using the Web Interface {#_4987b898-7881-43fa-b43a-c74eeff844dc .concept}

In Acumatica ERP, the data for all tenants and snapshots is stored in the database and may take a lot of space. To prevent uncontrolled growth of the database \(for example, if you create many snapshots\), the database size available for your Acumatica ERP instance is limited in your license.

The topics of this chapter explain how you can monitor and manage the usage of the database space by using the web interface.
