# Route Details by Service {#_4b8f7984-f23c-4ee4-bf6d-d3a210fc7fa4 .reference}

Form ID: \(FS611500\)

This report displays information about all routes, grouped by service. You can select the routes to be viewed by any of the following: customer, customer location, and date range.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report-Specific Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Start Date**: The start date for which you want to view information.
-   **End Date**: The end date for which you want to view information.
-   **Customer**: The customer for which you want to view data.
-   **Location**: The location of the customer for which you want to view data.
