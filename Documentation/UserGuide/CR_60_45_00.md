# Sales Quote {#_381a6d25-6bde-445d-aa8f-d403e5617617 .reference}

Form ID: \(CR604500\)

With this report, you can display the selected quote as a ready-to-print document. You can open this report either directly \(through a workspace or a search\) or by clicking **Print Quote** on the More menu of the [Sales Quotes](CR_30_45_00.md) \(CR304500\) form.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters Tab { .section}

On the **Report Parameters** tab, you can specify the following settings, which determine the quote to be displayed in the report:

-   **Opportunity ID**: The identifier of the opportunity to which the quote belongs.
-   **Quote Number**: The identifier of the quote.
