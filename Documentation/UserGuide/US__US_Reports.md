# User Security Reports {#_b8980154-8fea-4b1a-8de5-defffe86bd7b .concept}

The Acumatica ERP reports related to user security provide information that can be useful for employees who manage users, roles, and access rights to system objects. You can use these reports for analyzing, optimizing, and restructuring user accounts, user roles, and access rights. If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All reports related to user security can be generated in different formats, including PDF and HTML, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
