# Construction Reports: Project Status {#_0c42943c-9710-419d-aa40-2488ca9645c7 .concept}

Acumatica ERP Construction Edition includes the [Project Status](PM_30_15_00.md) \(PM301500\) form, which puts all of a project’s information in one place—from high-level metrics to financials, documents, and project reports. These reports help you stay on top of the project’s cash flow, committed and forecasted costs, variance versus plan, and work in process \(WIP\).

By using this form, you can monitor KPIs, review project-related records, and drill down into details.

**Attention:** The form is available in the Modern UI only if the *360 Dashboards* feature in the *Construction* feature group is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Explore a Full Project View { .section}

On the [Project Status](PM_30_15_00.md) \(PM301500\) form, you have a unified view that offers you access to:

-   An overview of the project settings in the Summary area
-   The *Summary* dashboard with key project metrics and drill-down capabilities
-   Various project-related records by using the navigation pane and links on the pages
-   Details about the customer, project contacts, and activities via the side panel
-   Key financial reports, documents, and transactions through the More menu

## View Key Metrics { .section}

On the *Summary* dashboard of the [Project Status](PM_30_15_00.md) \(PM301500\) form, you can track the project's performance. The upper part of the dashboard shows general, revenue, and cost metrics. You can view the status of your budget, profit, and project completion.

Here are some things you can do:

-   Monitor general KPIs, such as completion percentage, projected margin, and gross profit to date
-   Compare budgeted to billed revenue to identify overbilling or underbilling
-   Stay on top of budgeted versus actual costs, commitments, and the remaining available budget

Each scorecard displays a key metric—and you can click the metric to view the full data.

## Follow Up on Operational Details { .section}

The lower part of the *Summary* dashboard of the [Project Status](PM_30_15_00.md) \(PM301500\) form gives you access to additional insights that help you stay on top of project activity, follow up on pending items, and respond to open questions or delays. You can:

-   Assess cost performance over time by using the **Budget vs. Actual** chart. Click the chart title to open the latest date-sensitive cost projection on the [Cost Projection by Date](PM_30_55_00.md) \(PM305500\) form.
-   Review **Unpaid AP Bills** to track and manage your company's outstanding obligations.
-   Track **Potential Change Orders** that haven’t been approved yet—including those on hold or still open.
-   Check **Open Project Issues** and **Open RFIs**, and take action to avoid delays.
-   If you’ve set up approvals of project-related documents, use the **Documents to Approve** table to see which project-related documents are still waiting for approval. Click the table title to open the full list.

    The table is shown only if the *Approval Workflow* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

-   Review the **Recent Invoices** table to see the last five invoices created for the project. Click the table title to open the full list of invoices and follow up, if needed.

## Dive Into Project Financials and Documents { .section}

On the [Project Status](PM_30_15_00.md) \(PM301500\) form, you can click the nodes on the navigation pane to access pages with the corresponding project-related documents—such as change orders, purchase orders, or daily field reports. The nodes are organized by the following project areas:

-   **Financials**: Review cost and revenue budgets, manage project tasks, and access lists of change orders, change requests, cost projections, and pro forma invoices. In tables that show document amounts, you’ll find totals in the first row for quick reference.
-   **Subcontracts and Purchases**: View lists of project-related subcontracts, purchase orders, and inventory items.
-   **Project Management**: Access project progress records, including daily field reports, RFIs, project issues, drawing logs, photo logs, submittals, and compliance documents.

    The node is shown only if the *Construction Project Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

-   **Production**: View the list of production orders related to the project.

    The node is shown only if the *Manufacturing* feature group is enabled on the [Enable/Disable Features](CS_10_00_00.md) form.


While viewing a list of project-related records, you can create a record on the fly by clicking the needed button on the table toolbar.
