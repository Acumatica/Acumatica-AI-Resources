# To Create a Folder {#_fb299b66-92f8-48d7-a6b8-2c1972b52368 .task}

When an article is also a folder, the article appears as a node in the wiki tree and may contain articles.

## To Define an Article as a Folder { .section}

You can define a new or existing article as a folder. For more information about creating a new folder—that is, creating an article and defining it as a folder—see [To Add an Article](DM__how_Wiki_Creating_a_New_Article.md). To define an existing article as a folder, do the following:

1.  Open the article.
2.  On the wiki toolbar, click **Edit** to open the Wiki Editor form.
3.  On the **Content** tab, select the **Folder** check box.
4.  On the Wiki Editor form toolbar, click **Save**.

After you have defined an article as a folder, if you open the article in the Wiki Editor form, you can see the **Subarticles** tab.

## To Add Articles to a Folder { .section}

You can populate a folder with articles by moving existing articles into the folder or by creating new articles in the folder. To move existing articles to the folder, use the [Wiki Site Map](SM_20_20_10.md) \(SM202010\) form. If you're creating a new article, open the article in the Wiki Editor form, and on the **Contents** tab, specify the folder in the **Parent Folder** box.

## To Convert a Folder into an Article { .section}

A folder can be converted to an article only if the folder doesn't contain any articles. For more information about moving the articles to another folder, see [To Move an Article](DM__how_Wiki_Moving_an_Article_to_Another_Folder.md).

To convert a folder into an article, do the following:

1.  Open the folder you want to convert.
2.  On the wiki toolbar, click **Edit Current Article** to open the Wiki Editor form.
3.  On the **Content** tab, clear the **Folder** check box.
4.  On the Wiki Editor form toolbar, click **Save**.
