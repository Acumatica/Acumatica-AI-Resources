# To Create a Wiki Template {#_2237ae0b-fde1-404f-a8a2-19502f846e69 .task}

A template is a wiki article with a specific ID identifying it as a template and with wiki markups defined in the text area of the **Content** tab. You create the template in the wiki you want to apply it to. To create a template, follow the steps below:

## To Create a Wiki Template { .section}

1.  Open the wiki in the node that you specified for it.
2.  On the wiki toolbar, click **Add New Article** to open the Wiki Editor form for a new article or folder.
3.  On the **Content** tab, in the **Article ID** box, specify the ID for the template as follows:
    -   If this is an article template or print template, type `ContainerTemplate:` and then specify a text string identifying the template; do not use any spaces in the line.
    -   If this is a header or footer template, type `GenTemplate:` and then specify a text string identifying the template; do not use any spaces in the line.
4.  In the **Name** box, type the name of the template. You can use the same value in the **Article ID** and **Name** boxes.
5.  In the **Parent Folder** box, select the folder in which you want to save the template from the list of the available ones.

    **Note:** We recommend that you store templates in their own separate folder of the selected wiki. For more information about creating a folder, see [To Create a Folder](DM__how_Wiki_Creating_a_Folder.md).

6.  Clear the **Hold** check box to cause the wiki to have the *Published* status.
7.  In the text area at the bottom of the **Content** tab, depending on the type of the template, specify the code that will define the style and contents of the article, the printed article, the header, or the footer. For more information about wiki markup, see [Wiki Markup Reference](DM__con_Wiki_Using_Wiki_Markup.md).
8.  On the Wiki Editor form toolbar, click **Save**.
