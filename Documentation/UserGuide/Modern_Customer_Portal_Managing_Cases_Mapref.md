# Managing Cases {#_0a63f48b-09bd-4108-9ce5-998407c15363 .concept}

You can create and manage cases in the Modern Customer Portal.

In this chapter, you'll learn how to:

-   Create a case for assistance with the portal or the catalog
-   Update the case in the Modern Customer Portal

**Important:**

This functionality is available if the following conditions are met in Acumatica ERP:

-   The *Modern Customer Portal* and *Case Management* features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form
-   The **Case Management** check box is selected and the functionality has been configured on the [Portals](SP_70_10_00.md) \(SP701000\) form.

If the expected functionality isn’t available, contact your company’s portal manager. The portal manager can work with the portal owner to review configuration settings, if needed.
