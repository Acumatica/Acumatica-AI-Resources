# Production Order Performance {#_67d8f1fd-dc00-4e92-975a-11695e26d6b5 .reference}

Form ID: \(AM652000\)

This report lists the planned, actual, and variances by cost element for each production order in a summary form. It also includes detailed information about labor hours, costs, overhead by operation, and all transactions related to materials and labor. This is a good report to use as part of the closing process. This report provides you with comprehensive access to all relevant data in a single, consolidated view, enabling more granular reviews and easier investigation of anomalies. Printing a Production Order performance report on all of the completed production orders can allow someone to easily verify that all the costs were applied to the production order correctly.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Prod. Order Type:** Select the particular order type to be displayed in the report. You can blank this box to remove the filter.
-   **Production Nbr**: A particular production order. Select a production order to view the details for only this order, or leave it blank to view all orders.
-   **Include Production Transaction Details**: A check box that indicates \(if selected\) that the **Subcontract Transactions**, **Material Transaction**, and **Operation Transactions** sections are added to the resulting report. The check box is cleared by default.
-   **Inventory ID**: A particular inventory item. Select an inventory item to view the details of all production orders for this item, or leave it blank to view all inventory items.
-   **Sales Order Type**: A particular sales order type. Select a sales order type to generate a report by sales order demand to review the cost of the related production orders.
-   **Sales Order Nbr.**: A particular sales order. Select a sales order to generate a report for production orders associated with this sales order.
