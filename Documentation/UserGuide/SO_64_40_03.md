# Pick List – Confirm Picked with Item Barcodes {#_fa910142-eee3-46af-9ceb-b76442934a28 .reference}

Form ID: \(SO644003\)

**Note:** This form is available only if the *Warehouse Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This form displays a pick list for the selected shipment as a ready-to-print document. The document provides a list of items to be picked from various locations for the selected shipment. Quantity, weight, and volume information is provided for each item, and the total weight and volume are specified at the bottom of the document.

The following barcodes are available for scanning in a pick list: the shipment number barcode, the location barcode for each of the items in the pick list, and the barcode for confirming items being picked.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameter to select the information to be displayed on the report:

-   **Shipment Number**: The shipment number; select the number of an open shipment to prepare the pick list for it.
