# Revising a Budget {#_4714e9e9-0e63-4b0d-abec-d3ea0f449020 .concept}

A budget revision is a process that gives budget specialists the ability to make changes to a budget in order to improve the company's financial standing.

In this chapter, you will find general information on modifying budgets, a checklist of implementation tasks that have to be performed before you start modifying a budget, and an activity that walks you through the steps of modifying a budget.
