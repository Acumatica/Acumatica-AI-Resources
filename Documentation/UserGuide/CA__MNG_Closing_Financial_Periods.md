# Closing Financial Periods in Cash Management {#_0912eae1-5a08-4fdb-9732-8a54a79b5e1e .concept}

The closing of each financial period in the cash management subledger is a technical procedure that you must perform before closing the same period in the general ledger. You close financial periods to prevent users from posting transactions to these periods. For details, see [Closing Financial Periods: General Information](Finance_ClosingPeriods_GeneralInfo.md).
