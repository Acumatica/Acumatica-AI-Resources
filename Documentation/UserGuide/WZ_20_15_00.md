# &lt;Scenario Name&gt; {#_c9a75978-0bdd-4acc-84e3-f2c130b56431 .reference}

Form ID: \(WZ201500\)

**Note:** The actual form name is the scenario name you have specified on the [Scenarios](WZ_20_10_00.md) \(WZ201000\) form.

On this form, you can view the list of tasks of the particular scenario and the status of each task, the name of the user responsible for execution of the task \(if any\), the dates when the tasks were started and completed, and other parameters.

For details, see [Scenario Execution](CS__con_Scenario_Execution.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Start Task**|Opens the selected task for execution. \(The [&lt;Scenario Name&gt; - &lt;Task Name&gt;](WZ_20_15_10.md) \(WZ201510\) form then opens, and the task status changes to *In Progress*.\)|
|**Mark As Completed**|Changes the status of the selected task to *Completed*. After that, the successor tasks \(if any\) become *Open* and available for execution.|
|**Actions**|Provides the following menu commands:-   **Assign**: Brings up the **Assign Task To** dialog box, so that you can assign the selected task to any user for execution. If the task has subtasks that should be assigned to the same user, you can select the **Override Subtasks** check box. The task and all its subtasks will be assigned to the selected user at once.
-   **Reopen**: Reopens the selected task, and changes the task status from *Completed* to *Open*.
-   **Complete Scenario**: Completes the scenario. If you select this command, the system assigns the scenario the *Completed* status. In this case, all the tasks that have not been completed are assigned the *Skipped* status, and pending tasks retain the *Pending* status.

|

## Table {#1 .section}

The table area contains the following tabs, each of which has a different list of tasks:

-   **All Records**: The list of all tasks included in the scenario
-   **My Tasks**: The list of tasks assigned to the currently signed in user
-   **Not Completed Tasks**: The list of tasks that are not executed yet

The table columns are the same for each tab.

|Column|Description|
|------|-----------|
|**Name**|The name of the task.|
|**Status**|The current status of the task, which is assigned by the system. The following statuses are available:-   *Pending*: The task has never been executed and is pending for execution. This status is assigned to the task after the scenario activation if all features required for task execution are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.
-   *Skipped*: The task is skipped. This status is assigned to the task after you click the **Skip** button on the [&lt;Scenario Name&gt; - &lt;Task Name&gt;](WZ_20_15_10.md) \(WZ201510\) form \(for example, if the task is optional and its execution is not required for completing the scenario\), or if the scenario was completed by clicking the **Complete Scenario** button.
-   *In Progress*: The task is in progress. This status is assigned to the task after you click the **Start Task** button on the [&lt;Scenario Name&gt; - &lt;Task Name&gt;](WZ_20_15_10.md) \(WZ201510\) form.
-   *Disabled*: The task is not available for execution and is disabled by the system during scenario activation if the features required for task execution are not enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. You need to specify these features on the **Features** tab of the [Tasks](WZ_20_20_00.md) \(WZ202000\) form.
-   *Completed*: The task is completed. This status is assigned to the task after clicking the **Mark As Completed** button on the [&lt;Scenario Name&gt; - &lt;Task Name&gt;](WZ_20_15_10.md) \(WZ201510\) form.
-   *Open*: The task is open and available for execution. This status is assigned to the task if the task has no predecessors, or the predecessor tasks have the *Completed*, *Skipped* or *Disabled* statuses.

|
|**Assigned To**|The user \(if any\) to whom the task is assigned \(responsible for executing the task\).|
|**Completed By**|The user who has completed the task.|
|**Started**|The date when task execution was started.|
|**Completed**|The date when task execution was completed.|
|**Optional**|Defines \(if selected\) that execution of this task is not required for completing the scenario.|
