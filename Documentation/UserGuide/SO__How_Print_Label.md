# To Print a Label {#_13529cf2-fb19-45cc-b758-ce0e40de5165 .task}

If you need to print labels for the stock items in a particular shipment, you can do this from the [Shipments](SO_30_20_00.md) \(SO302000\) form, as described in the instructions below.

## To Print a Label { .section}

1.  Open the [Shipments](../Shared/../UserGuide/SO_30_20_00.md) \(SO302000\) form.
2.  In the **Shipment Nbr.** box, select the reference number of the needed shipment.
3.  Confirm the shipment if it has not been confirmed.
4.  On the More menu \(under **Labels**\), click **Print Labels**.
5.  On the [Carrier Labels](../Shared/../UserGuide/SO_64_50_00.md) \(SO645000\) report, which opens, review the generated label.
6.  On the form toolbar, click **Print** to print the label.
