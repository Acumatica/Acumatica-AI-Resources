# Routes on Map {#_552bd083-b7e4-4ee3-9270-7be6b7292a01 .reference}

Form ID: \(FS300900\)

On this form, you can view on a map the routes and their details for a particular day. On the **Routes** pane of this form, you can also change the order of appointments for a particular route execution.

## Routes Pane { .section}

On this pane, you can view a table with the routes and information about the related appointments. You can also move an appointment on this tab by dragging its line to the required place.

The toolbar includes standard elements.

|Column|Description|
|------|-----------|
|**Route List**|The list of route executions and the appointments to which they are assigned. You can view the appointment details of a particular route execution if you click the arrow button left of the route execution number.|
|**Route/Customer**|The name of the route created on the [Routes](FS_20_37_00.md) \(FS203700\) form or the customer with which the appointment takes place.|
|**Location**|The identifier of the appointment location.|
|**Service Duration**|The total expected time of performing the services of the appointment in this row.|

|Element|Description|
|-------|-----------|
|**Show or Hide Route Appointment Information on the Map**|Shows or hides the appointment information on the map for the route of the staff member you have selected.|

|Element|Description|
|-------|-----------|
|**Appointment Information**|Opens the [Appointments](FS_30_02_00.md) \(FS300200\) form, where you can view and modify the details of the selected appointment.|

## Map Pane { .section}

In the map area, you can view the routes for the date and branch selected on the map toolbar. You can also click the appointment icon \(a number within a circle\) to view information about a particular appointment of the route.

The map toolbar includes standard and form-specific elements. The form-specific element is listed below.

|Button|Description|
|------|-----------|
|**Branch**|A box in which you can select the branch for which routes are shown on the map.

 A staff member's routes will be shown on the map if for the staff member, this branch is selected in the **Branch** box of the [Route Document Details](FS_30_40_00.md) \(FS304000\) form.

|

## Route Information Pane { .section}

On this pane, you can view data on the route duration, distance, number of appointments, driver, vehicle, and status for the route execution that you have selected in the **Routes** pane of the form. You have to select a route execution to view this data.

**Note:** Initially, the name of this pane is **Route Information**, and the pane contains no data. When you select a route execution, the system changes the name of the pane to a combination of the following: the route execution number, the description of the related route, and the name of the driver assigned to the route execution. For example, if the route execution number is *000012*, the description of the route is *New York City Supply*, and the staff member name *Andrews Michael*, the combination displayed as the name of this pane is *000012-New York City Supply-Andrews Michael, Mr.*.

## Appointment Information Tab { .section}

On this tab, you can view data on each appointment on the route of the selected route execution on the **Route** tab. You have to select a route to view this data.

**Note:** Initially, the name of this pane is **Appointment Information**, and the pane contains no data. When you select a route execution, the system changes the name of the pane to *Appointments on the Route:* followed by the route execution reference number, with the number of appointments in parentheses. For example, if the route execution number is *000012* and it has three appointments with customers \(this means five appointments overall, including the start and end locations of the route execution\), the updated name of this pane is *Appointments on the Route: 000012 \(5\)*.

|Column|Description|
|------|-----------|
|**Appointment**|The number of the appointment, as specified on the [Appointments](../Shared/../UserGuide/FS_30_02_00.md) \(FS300200\) form, or the start or end location of the route specified in parenthesis.|
|**Route/Customer**|The name of the customer with which the appointment takes place.|
|**Service Type**|A description of the service.|
|**Travel Time**|The time that is needed to get from the appointment location listed in this row to the next appointment location.|
|**Service Duration**|The total time that performing the services of the appointment is expected to take.|
|**Actual Start Time**|The actual time when the appointment started.|
|**Actual End Time**|The actual time when the appointment ended.|
|**Location**|The identifier of the appointment location.|
|**Postal Codes**|The postal code of the appointment location.|
|**Address**|The address of the appointment location.|
