# Automation Schedule History {#_139ed654-f91a-4b8a-9560-616260719f21 .reference}

Form ID: \(SM205035\)

On this form, you can view and delete the logged entries in the history of schedule executions. \(An entry is a line in the table that corresponds to a particular execution of a schedule, whether or not it was successful, and provides relevant details about the execution.\) Also, you can select a particular entry and view the records processed when the automation schedule was executed.

**Attention:** The form is available only if the *Scheduled Processing* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Delete**|Removes the entry or entries you have selected in the table from the schedule history.|
|**Delete All**|Removes all records displayed in the table from the schedule history.|

## Selection Area { .section}

In the Selection area, you can select a form of Acumatica ERP and a schedule for which you want to view the history. You can also select a date range for schedule execution.

|Element|Description|
|-------|-----------|
|**Screen**|The name of the Acumatica ERP form that is the object of automation. You click the magnifier icon in the box to open the lookup table, where you can select the form by searching or filtering by its title, screen ID, workspace, or category.|
|**Schedule**|The automation schedule for which you want to see execution history.|
|**From**|The earliest execution date of the entries to be displayed.|
|**To**|The latest execution date of the entries to be displayed.|

## Table { .section}

This table contains the list of entries of schedule execution that meet any selection criteria you have specified.

|Element|Description|
|-------|-----------|
|**Status**|An icon indicating the status of the execution of the automation schedule.A check box within a green circle reflects successful execution, an exclamation mark within a yellow circle reflects execution with warnings, and an X within a red circle reflects execution with errors.

|
|**Screen ID**|The name of the Acumatica ERP form that is the object of automation.|
|**Schedule ID**|The description that has been provided for the automation schedule. You can click the description to open the corresponding automation schedule on the [Automation Schedules](SM_20_50_20.md) \(SM205020\) form.|
|**Execution Date**|The date and time when the automation schedule was executed.|
|**Total Records**|The number of records that were processed. You can click the number to open the **Processing Results** dialog box.|
|**Processed**|The number of records that were processed successfully.|
|**Warnings**|The number of records that were processed with warnings during the execution of the automation schedule.|
|**Errors**|The number of records that were processed with errors during the execution of the automation schedule.|
|**Execution Result**|The result of the execution of the automation schedule: successfully, with warnings, or with errors.|

|Element|Description|
