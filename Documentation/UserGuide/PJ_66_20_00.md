# Project Issue Form {#_dda86c76-cd8a-4740-b454-2f0039ecdeda .reference}

Form ID: \(PJ662000\)

By using this report, you can look through, print, and email the project issue. You select a reference number of the particular project issue you want to view.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameter to select the information to be displayed on the report:

-   **Project Issue ID**: The identifier of the project issue to be displayed. Select a number of the project issue for which you want to build the report.
