# Wave Packing Slip {#_82be9eb8-3053-4c33-861e-4c028b6035eb .reference}

Form ID: \(SO644007\)

**Note:** This report is available only if the *Advanced Picking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This report displays each packing slip as a ready-to-print document for the selected wave picking worksheet or for the selected shipment of the worksheet. The document provides the list of items that have been picked from warehouse locations and are currently being packed. Quantity, weight, and volume information is provided for each item, and the total weight and volume are specified at the bottom of the document.

The following barcodes are available for scanning in each generated packing slip: the shipment number barcode, and the barcode to be used to confirm the shipment being packed.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Worksheet Number**: The wave picking worksheet number. Select the number of an open picking worksheet to prepare the packing slips for all shipments included in this worksheet \(or only the selected shipment if you select a shipment number\).
-   **Shipment Number**: The shipment number; select the number of a shipment included in the worksheet to prepare a packing slip for this particular shipment.
