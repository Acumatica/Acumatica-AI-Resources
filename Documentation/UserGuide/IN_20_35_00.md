# Create Matrix Items {#_2753aef0-f0b1-423a-8275-474750aaef93 .reference}

Form ID: \(IN203500\)

**Attention:** This form is available only if the *Matrix Items* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

You can use this form to create matrix items by selecting the required template item and the attributes whose values will be used in the columns and the rows of the matrix table.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Create Matrix Items**|Creates matrix items based on the settings specified on this form.|

## Selection Area { .section}

The Selection area contains boxes that you use to select the settings the system will use for generating matrix items for the template item.

|Element|Description|
|-------|-----------|
|**Template ID**|The identifier of the template item whose settings will be used for creating matrix items.|
|**Column Attribute ID**|The identifier of the attribute whose values the system displays in the columns of the matrix table when you create matrix items for the template item. By default, the system populates this box with the value of the **Default Column Attribute ID** box on the **Configuration** tab of the [Template Items](IN_20_30_00.md) \(IN203000\) form.

|
|**Row Attribute ID**|The identifier of the attribute whose values the system displays in the columns of the matrix table when you create matrix items for the template item. By default, the system populates this box with the value of the **Default Row Attribute ID** box on the **Configuration** tab of the [Template Items](IN_20_30_00.md) \(IN203000\) form.

|

## Additional Attributes Table { .section}

This table displays the attributes that were assigned to the template item in the **Attributes** table on the **Configuration** tab of the [Template Items](IN_20_30_00.md) \(IN203000\) form and were not selected as column or row attributes. For each attribute, you must select the value that the system will use for creating matrix items.

## Main Attributes Table { .section}

In this table, values of the attribute selected in the **Column Attribute ID** box are displayed in the columns of the matrix, and the values of the attribute selected in the **Row Attribute ID** box are displayed in the rows of the matrix. In each cell of the table, to create an item with the combination of attribute values in the column and the row, you select the check box. You can also use the **Select Column** and **Select Row** check boxes \(described below\) to cause all the check boxes in a particular column or row, respectively, to be selected.

The table toolbar has only standard buttons.

|Element|Description|
|-------|-----------|
|**Select Column**|A row in which you select a check box if you want to create items with all attribute values specified in rows of this column. If you select a check box in a column, all check boxes in this column become selected.|
|**Select Row**|A column in which you select a check box if you want to create items with all attribute values specified in columns of this row. If you select a check box in a row, all check boxes in this row become selected.|
