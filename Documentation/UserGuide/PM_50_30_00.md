# Run Project Billing

Form ID: \(PM503000\)

You can use this form to perform billing for projects. Invoices are generated for each project and for each customer involved. For more information about billing settings and procedures, see [Project Billing Preparation: General Information](Projects_Project_Billing_Preparation_GeneralInfo.md).

**Important:** The form displays projects to which your user has sufficient access rights.

## Form Toolbar

The form toolbar includes the buttons described below.

|Command|Description|
|-------|-----------|
|**Process**|Initiates billing processing for the projects you have selected \(using the unlabeled check boxes\) in the table.|
|**Process All**|Initiates billing processing for all the projects listed in the table.|

## Selection Area

By making specifications in this area, you can select the criteria the system uses to list projects that you can bill. For more information about the conditions that the system uses for selection of the projects to be shown in the table, see [Project Billing Preparation: Mass Processing](Projects_Project_Billing_Preparation_MassProcessing.md).

For more information about the conditions that the system uses for selection of the projects to be shown in the table, see [Project Billing Preparation: Mass Processing](Projects_Project_Billing_Preparation_MassProcessing.md). If multiple billing periods were not billed for the project, you should run the billing process once for each unbilled period.
