# Production Schedule Board {#_c03a4712-ba0a-48c9-a168-826684b26403 .reference}

Form ID: \(AM215555\)

**Attention:** This form is available only if the *Advanced Planning and Scheduling* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can view the production schedule in a graphical format. The schedule for the production orders that meet the selection criteria is displayed over time as a Gantt chart. You can adjust the timescale, assign color coding of chart bars, and view missed commitment dates. In addition, you can reschedule and firm production orders directly on this form.

For additional information about this form and its use, see [Advanced Planning and Scheduling: Production Schedule Board](MFG_APS_Production_Schedule_Board.md).

## Unscheduled Tab { .section}

The **Unscheduled** tab lists all production orders that have not been scheduled yet.

To view a production order’s details, click the reference number on its tile to open a quick view panel. From there, you can click the order number to open the [Production Order Maintenance](AM_20_15_00.md) \(AM201500\) form.

|Command|Description|
|-------|-----------|
|**Refresh**|Reloads the list to reflect the latest data.|
|**Filter Settings**|Displays the filter bar, which you can use to create a quick or advanced filter. The created filter will narrow the data displayed on the current pane.

 Multiple filter criteria are available, including *Constraint*, *Customer ID*, *Dispatch Priority*, *Firm Schedule*, *Schedule Status*, *Start Date*, and *Work Center*.

|
|**Search**|Initiates a search for production orders based on the search string you enter.|

## Scheduled Tab { .section}

The **Scheduled** tab lists all scheduled production orders in the system.

You can filter the list by various criteria and use the Search box to find a specific production order.

By clicking an order's reference number in the list, you can open the quick view panel. From there, clicking the order's number opens the [Production Order Maintenance](AM_20_15_00.md) \(AM201500\) form.

The color of the order's tile reflects the order’s state at a glance.

|Command|Description|
|-------|-----------|
|**Refresh**|Reloads the list to reflect the latest data.|
|**Firm**|Firms the production orders selected in the table.|
|**Schedule**|Schedules the production orders selected in the table.|
|**Undo Firm**|Undoes the firm action for the production orders selected in the table. You can perform this command for only production orders that were firmed previously.|
|**Filter Settings**|Displays the filter bar, which you can use to create a quick or advanced filter. The created filter will narrow the data displayed on the current pane.

 Multiple filter criteria are available, including *Constraint*, *Customer ID*, *Dispatch Priority*, *Firm Schedule*, *Schedule Status*, *Start Date*, and *Work Center*.

|
|**Search**|Initiates a search for production orders based on the search string you enter.|

## Calendar Pane { .section}

The calendar pane visually displays graphical bars that represent top-level production orders and all their dependent subassemblies. Expand or collapse the view to show or hide child orders.

By default, the **All Records** filter tab appears, showing all available orders. You can add custom filter tabs to display specific data. These tabs appear to the right of the default tab, with the name that you specify.

Each time interval is displayed as a cell in the calendar, with production orders shown as colored tiles that indicate the order's state at a glance.

|Element|Description|
|-------|-----------|
|**Refresh**|Reloads the data to display the most up-to-date information on the calendar.|
|**Narrow Down**| |
|**Full Screen**|Switches the calendar display to full screen mode or exits this mode.|
|Calendar|A box that displays a date, week range, or month name, depending on the button \(**Day**, **Week**, or **Month**\) selected to the right of this box. When you click this box, the calendar picker opens, where you can select any date, week, or month.|
|**Day**|A button you click to show a specific date in the calendar box and a single day, broken down by hour, in the calendar pane.|
|**Week**|A button you click to show a specific week interval in the calendar box and the entire week in the calendar pane.|
|**Month**|A button you click to show a specific month in the calendar box and the entire month in the calendar pane.|
|**Filter Settings**|A button you click to display the filter bar, which you can use to create a quick or advanced filter. By applying a filter, you can customize the appointment view and narrow down the information shown on the calendar board based on various criteria.|

## Work Centers Pane { .section}

On this pane, you can view the work centers involved in production and the histograms with details for the available and scheduled capacity for each work center.

## Machines Pane { .section}

On this pane, you can view the machines involved in production and the histograms with details for the available and scheduled capacity for each machine.
