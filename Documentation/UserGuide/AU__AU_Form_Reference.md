# Customization Tool Reference Guide {#_bd53c0c9-c01b-4cec-a70f-28482c47e861 .concept}

Each topic in this guide provides reference information about a particular Acumatica ERP page or form related to customization tools. The reference information includes details about the use of the page or form and all of the parts of it, including areas, tabs, and toolbars. Each user interface element on the page or form is described, including buttons, commands, boxes, and check boxes.
