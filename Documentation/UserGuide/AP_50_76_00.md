# Create CRA E-File {#_cd7b4859-4443-4ae3-a27d-a3a3d866ce87 .reference}

Form ID: \(AP507600\)

**Attention:** This form appears in the system only if the *Canadian Localization* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

By using this form, you can generate a T5018 or T4A form in XML format to be submitted to the Canada Revenue Agency \(CRA\). You can also review the data that you submit to the CRA in a human-readable format, view the previous years' submissions, and amend or cancel a T5018 or T4A report.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Prepare Report**|Populates and saves the data for the report. When you click this button, the system shows the total of all the transactions for all the individual subcontractors on the **Details** tab.

 This button is visible on the form if the original report \(revision 1\) hasn’t been prepared. Once it has been prepared, the button becomes hidden.

 **Tip:** If you need to prepare another original report, you have to delete the already-prepared report.

|
|**Amend Report**|Amends the current report revision. You click this button when you’ve added or voided any payment to a particular subcontractor and require an amended report.

 This button appears on the form after the original report \(revision 1\) has been prepared. You can prepare an amendment by clicking this button after you submit the original report to the CRA by selecting the **E-File Submitted to CRA** check box and saving the changes on the form. Likewise, you’ll be able to prepare an amended report after the previously amended report has been submitted to the CRA.

|
|**View Validation Report**|Runs the [T5018 Preview Report](AP_60_76_00.md) \(AP607600\) for the transmitter, T5018 tax year, and revision that are specified on the current form. In this report, you can review the T5018 data prepared on the current form.

 This button appears on the form if *T5018* is selected in the **Tax Form** box.

 The button is available only if a specific revision number is selected in the **Revision** box of the Selection area.

|
|**Create E-File**|Creates an electronic T5018 or T4A e-file. If a file is created for the first time, when you click this button, the system generates a report with the *Original* type.

 If a file has been already created, when you click this button, the system will create a report with the *Amended* or *Canceled* type. Reports of these types will be generated one at a time or both at the same time, depending on the **Total Service Amount** for vendors after they’ve amended or voided their payments.

 If the **Total Service Amount** has been changed for a particular vendor and the new amount is less than the **Threshold Amount**, the system will include the vendor in a cancellation report and an amended summary. It only applies to already submitted T5018 e-files. If the new **Total Service Amount** is greater than the **Threshold Amount**, the system will include the vendor in an amended report and an amended summary.

 The system generates an XML file with information for all vendors displayed on the **Details** tab. The generated file is attached to the current form, and you can review it by clicking **Files** on the form title bar.

 This button is available only if a specific revision number is selected in the **Revision** box of the Selection area.

|
|**Download E-File**|Downloads the generated T4A XML file.

 If a T4A report is generated after amendments were made to the T4A vendors payments and the vendor information is included in the T4A Amended and T4A Canceled reports, the system will generate two XML files—one for the T4A Amended report and one for the T4A Canceled report. Both XML files will be downloaded when you click this button.

 This button appears on the form if *T5018* is selected in the **Tax Form** box.

|
|**Print/Email T4A Slips**|Opens the [Print/Email T4A Slips](AP_50_76_10.md) \(AP507610\) form, where you can print the T4A slip.

 This button appears on the toolbar if *T4A* is selected in the **Tax Form** box and the **E-File Submitted to CRA** check box is selected for revision 1 of the e-file.

|

## Selection Area {#1 .section}

You can use the settings in this area to narrow the range of payments to T5018 vendors that are listed in the table. The elements of this area are summarized below.

|Element|Description|
|-------|-----------|
|**Tax Form**|Required. The tax form to be prepared for submission to CRA. One of the following options can be selected: -   *T5018*
-   *T4A*

|
|**Payer**|Required. The company filing the T5018 or T4A report.

 This box displays only companies and branches for which *Canada* is selected in the **Localization** box on the [Companies](CS_10_15_00.md) \(CS101500\) form. You can select a branch in this box if this branch belongs to a company with the *Canada* localization and the **File Taxes by Branch** check box is selected.

|
|**Year**|Required. The year that will be used in the T5018 or T4A report. For a T4A report, the calendar year is always used.

 If the year type selected on the **Canadian Tax Reporting** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company is *Calendar Year*, the previous calendar year is specified in this box. If the year type is *Fiscal Year*, the system inserts the financial year whose end date is closest to the current business date but is earlier than it.

 You can select a financial year from the company calendar of the company selected in the **Transmitter** box.

|
|**Revision**|Required. The revision number of the data prepared on the current form and shown on the **Details** and **Summary** tabs. This data will be exported as an XML file if you click **Create E-File** or displayed on the [T5018 Preview Report](AP_60_76_00.md) \(AP607600\) form if you click **View Validation Report**.

 Every time you save new data, the system creates a new revision. Each new revision contains the data from the previous revision and all new transactions that were added in the system after the previous revision was created.

|
|**E-File Submitted to CRA**|A check box that indicates \(if selected\) that the e-file with the T5018 or T4A data of the selected revision has been submitted to the CRA.

 The check box is always selected and unavailable for the original report \(revision 1\) if an amendment \(revision 2\) has been created for the original report. To clear the check box for the amended report \(revision 2\), you’ll have to delete the subsequent amended report \(revision 3\).

|
|**Filing Type**|Read-only. The type of the e-file shown for informational purposes. The possible options are:

-   *Original* \(default\): The file will include the original T5018 or T4A slip.
-   *Amendment*: The file will include an amended T5018 or T4A return.

|
|**Threshold Amount**|Read-only. The threshold amount of the T5018 or T4A file. The **Details** tab shows only payment transactions of vendors that are the same as or greater than the entered amount.

 The value is copied from the **Threshold Amount** box on the **Canadian Tax Reporting** tab of the [Accounts Payable Preferences](AP_10_10_00.md) \(AP101000\) form \(from the **T5018 Settings** or **T4A Settings** section, depending on the selected tax form\).

 Once a report is prepared, you won’t be able to override the value in the **Threshold Amount** box for already prepared reports with the *Original*, *Amended*, and *Canceled* types. The **Threshold Amount** box on the [Accounts Payable Preferences](AP_10_10_00.md) \(AP101000\) form will still be editable.

|
|**Date Range**|Read-only. The start date and end date of the reporting period.

 For a T5018 report, when a new year is selected in the **Year** box, the system populates this box based on the selected year and year type for the company specified as the **Transmitter** as follows:

 -   If *Calendar Year* is selected in the **Year Type** box on the **Canadian Tax Reporting** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form, this box shows January 1 of the selected year.
-   If *Fiscal Year* is selected in the **Year Type** box on the **Canadian Tax Reporting** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form, this box shows the start date of the financial year in the company calendar.

 For a T4A report, this start date is always January 1 of the selected year, and the end date is always December 31 of the selected year.

|

## Details Tab { .section}

This tab displays one row for each vendor that has the **T5018 Vendor** check box selected on the [Vendors](AP_30_30_00.md) \(AP303000\) form and that has a payment during the selected year.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Vendor**|The identifier of the vendor.|
|**Vendor Name**|The full name of the vendor.|
|**Payer**|The company that paid the vendor. This column is always populated with the company selected in the **Transmitter** box \(for T5018\) in the Selection area.

 This column appears in the table if *T5018* is selected in the **Tax Form** box.

|
|**Total Service Amount**|The sum of all amounts paid to the vendor for services.

 This column appears in the table if *T5018* is selected in the **Tax Form** box.

|
|**SIN**|The social insurance number of the vendor if the vendor is an individual.

 This value is copied from the **SIN** box on the **General** tab \(**Vendor Properties** section\) of the [Vendors](AP_30_30_00.md) \(AP303000\) form.

 This column appears in the table if *T4A* is selected in the **Tax Form** box.

|
|**Program Account Number**|A 15-character payroll account number that’s used for dealing with the CRA.

 This value is copied from the **CRA Payroll Account Number** box \(**Vendor Properties** section\) on the **General** tab of the [Vendors](AP_30_30_00.md) \(AP303000\) form.

 This column appears in the table if *T4A* is selected in the **Tax Form** box.

|
|**T4A Box**|The type of T4A payments.

 This value is copied from the **T4A Box** on the **General** tab \(**Vendor Properties** section\) of the [Vendors](AP_30_30_00.md) \(AP303000\) form.

 This column appears in the table if *T4A* is selected in the **Tax Form** box.

|
|**Amount to Report**|The sum of the payments that include services only or mixed goods and services that will be included in the T5018 report. Payments for goods only are excluded from this amount.

 If *T4A* is selected in the **Tax Form** box, this column shows to the total amount to report.

 If you click this link, the system opens a separate page with the [T5018 Report Details](AP_40_76_00.md) \(AP407600\) or [T4A Report Details](AP_40_77_00.md) \(AP407700\) form. These forms list all the documents whose amounts are included in the T5018 or T4A report, respectively.

|
|**Report Type**|The type of the T5018 or T4A report.

 The system automatically inserts one of the following options in this column:

 -   *Original*: The vendor information is included in the original report when it is prepared for the first time.
-   *Amended*: The vendor information is included in an amended report that’s prepared after amendments are made to the vendor payments and their new **Total Service Amount** is still greater than the **Threshold Amount**.
-   *Canceled*: The vendor information is included in a canceled report that’s prepared after amendments are made to the vendor payments and their new **Total Service Amount** is less than the **Threshold Amount**.

|
|**Tax Registration ID**|The vendor's **SIN** or **Program Account Number**, which is specified on the **General** tab \(**Vendor Properties** section\) of the [Vendors](AP_30_30_00.md) \(AP303000\) form.

 This column appears in the table if *T5018* is selected in the **Tax Form** box.

|

## Summary Tab { .section}

This tab displays summary information about the transmitter company and the contact.

|Element|Description|
|-------|-----------|
|**Language**|Required. The language that will be used for the *Language of communication* element in the *T619* section of the T5018 file or in the T4A file.

 The following options are available:

 -   *English* \(default\)
-   *French*

|
|**Program Number**|Required. The program account number of the transmitter.

 The number can be up to 15 alphanumeric characters. The default value is copied from the **Program Number** box on the **Canadian Tax Reporting** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company selected in the **Transmitter** box of the Selection area.

|
|**Transmitter RepID**|The alphanumeric code that the CRA assigns to identify a representative when they register with the Represent a Client service.

 The box is required. Its default value is copied from the **Transmitter RepID** box on the **Canadian Tax Reporting** tab of the [Companies](CS_10_15_00.md) \(CS101500\) or [Branches](CS_10_20_00.md) \(CS102000\) form.

|
|**Transmitter Number**|Required. The transmitter number that will be used in the *Transmitter number* element of the *T619* section in the T5018 file or in the T4A file.

 This number can be up to eight alphanumeric characters. The default value is copied from the **Transmitter Number** box on the **Canadian Tax Reporting** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company that is selected in the **Transmitter** box of the Selection area. If the **Transmitter Number** box on the [Companies](CS_10_15_00.md) \(CS101500\) form is empty for the company, the default value is *MM555555*.

|

|Element|Description|
|-------|-----------|
|**Company Name**|Required. The full company name that will be used in the *Transmitter name* element of the *T619* section in the T5018 file or in the T4A file.

 The default value is copied from the **Company Name** box on the [Companies](CS_10_15_00.md) \(CS101500\) form for the company that’s selected in the **Transmitter** box of the Selection area.

|
|**Address Line 1**|The first address line of the company's address. This value will be used in the T5018 file as follows: in the *Transmitter address* element of the *T619* section, and in the *Payer address* element in the *T5018 Summary* section.

 The default value is copied from the **Address Line 1** box on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company selected in the **Transmitter** box of the Selection area.

|
|**Address Line 2**|The second address line of the company's address. This value will be used in the T5018 file as follows: in the *Transmitter address* element of the *T619* section, and in the *Payer address* element of the *T5018 Summary* section.

 The default value is copied from the **Address Line 2** box on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company selected in the **Transmitter** box of the Selection area.

|
|**City**|The city of the company address. This value will be used in the T5018 file as follows: in the *Transmitter city* element of the *T619* section, and in the *Payer city* element of the *T5018 Summary* section.

 The default value is copied from the **City** box on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company selected in the **Transmitter** box of the Selection area.

|
|**Province**|The province of the company address. This value will be used in the T5018 file as follows: in the *Transmitter province* element of the *T619* section, and in the *Payer province* element of the *T5018 Summary* section.

 The default value is copied from the **State** box on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company selected in the **Transmitter** box of the Selection area.

|
|**Country**|The country of the company address. This value will be used in the T5018 file as follows: in the *Transmitter country* element of the *T619* section, and in the *Payer country* element of the *T5018 Summary* section.

 The default value is copied from the **Country** box on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company selected in the **Transmitter** box of the Selection area.

|
|**Postal Code**|The postal code of the company address. This value will be used in the T5018 file as follows: in the *Transmitter postal code* element of the *T619* section, and in the *Payer postal code* element of the *T5018 Summary* section.

 The default value is copied from the **Postal Code** box on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company selected in the **Transmitter** box of the Selection area.

|

|Element|Description|
|-------|-----------|
|**Name**|Required. The full name of the transmitter's contact. This value will be used in the *Contact name* element in the *T619* and *T5018Summary* sections of the T5018 file.

 The default value is copied from the **Attention** box in the **Main Contact** section on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company selected in the **Transmitter** box of the Selection area.

|
|**Contact Area Code**|Required. The area code of the transmitter's contact. This value will be used in the *Contact area code* element in the *T619* and *T5018 Summary* sections of the T5018 file. This value should be three numeric characters.

 The default value is copied from the area code in the **Phone 1** box in the **Main Contact** section on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company selected in the **Transmitter** box of the Selection area.

|
|**Phone**|Required. The phone number of the transmitter's contact. This value will be used in the *Contact telephone number* element in the *T619* and *T5018 Summary* sections of the T5018 file. The allowed value is three numeric characters followed by *-* and then four more numeric characters.

 The default value is copied from the phone number in the **Phone 1** box in the **Main Contact** section on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company selected in the **Transmitter** box of the Selection area.

|
|**Extension Number**|The phone extension number of the transmitter's contact. This value will be used in the *Contact extension number* element in the *T619* and *T5018 Summary* sections of the T5018 file.

 The value can be up to seven numeric characters.

|
|**Email**|Required. The email address of the transmitter's contact. This value will be used in the *Contact e-mail address* element in the *T619* and *T5018 Summary* sections of the T5018 file.

 The default value is copied from the **Email** box in the **Main Contact** section on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form for the company selected in the **Transmitter** box of the Selection area.

|
|**Second Email**|The second email address of the transmitter's contact. This value will be used in the *Contact e-mail address 2* element in the *T619* and *T5018 Summary* sections of the T5018 file.|
