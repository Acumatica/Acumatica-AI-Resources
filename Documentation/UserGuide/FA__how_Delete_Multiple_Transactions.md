# Fixed Asset Troubleshooting: To Delete Multiple Unreleased Fixed Asset Transactions {#_81a47252-c217-491f-9ba9-5e40de3d40b2 .task}

You can use the [Delete Unreleased Transactions](FA_50_80_00.md) \(FA508000\) form to delete the transactions that have not been released. On this form, you can delete one transaction or multiple transactions at once.

## How to Delete Multiple Unreleased Fixed Asset Transactions {#section_blh_ljv_vxb .section}

1.  Open the [Delete Unreleased Transactions](FA_50_80_00.md) \(FA508000\) form.
2.  To delete only particular listed transactions, do the following:
    1.  For each transaction that you want to delete, select the appropriate Selected check box.
    2.  On the form toolbar, click **Delete**.
3.  To delete all listed transactions, click **Delete All** on the form toolbar.
