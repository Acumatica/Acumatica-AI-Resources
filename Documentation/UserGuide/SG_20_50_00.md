# SendGrid Connections

Form ID: \(SG205000\)

On this form, you can create and manage SendGrid connections. For each connection, you can:

-   Specify the subscription preferences it tracks
-   Synchronize and map SendGrid unsubscribe groups to marketing categories used in mass emails
-   View all email accounts that use this connection

This form is available if the *SendGrid Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar includes the buttons described below.

|Command|Description|
|-------|-----------|
|**Reload Default Settings**|Reloads the default SendGrid settings \(except the API key\) on the **General** tab.|
|**Test Connection**|Confirms that the API key specified on the **General** tab is valid and has permissions that allow the integration by using this connection.|
|**Sync Unsubscribe Groups**|Retrieves unsubscribe groups from SendGrid by using the API key and updates the local unsubscribe groups in Acumatica ERP. This is a one-way synchronization from SendGrid to Acumatica ERP.|

## General Tab

On this tab, you can specify the settings of the SendGrid connection and select the subscription preferences it tracks.

|Element|Description|
|-------|-----------|
|**API Key**|The unique API key that is used for sending emails through this SendGrid connection.|
|**API Key Name**|The name of the API key.|
|**Email Categories**|The SendGrid email categories \(with a comma used as the separator\) that are applied to emails sent through this connection. The categories can be used for statistical analysis and reporting purposes in the company's SendGrid portal.|

|Element|Description|
|-------|-----------|
|**Receive SendGrid Events via Webhooks**|A check box that indicates \(if selected\) that the system receives SendGrid events through webhooks.|
|**Webhook ID**|The identifier of the webhook registered in SendGrid.|
|**URL of the Webhook Registered in Acumatica ERP**|The URL of the Acumatica ERP webhook endpoint that receives SendGrid events.|
|**TrackEmailOpens**|A check box that indicates \(if selected\) that SendGrid includes a single-pixel image in the body of email to track whether a recipient opened the email.|
|**TrackClicksInEmail**|A check box that indicates \(if selected\) that SendGrid collects information about navigation to all links included in the body of email.|
|**ProcessedEvent**|A check box that indicates \(if selected\) that the system receives a *processed event* when SendGrid has received an email and prepared it for delivery to a recipient.|
|**DeferredEvent**|A check box that indicates \(if selected\) that the system receives a *deferred event* when SendGrid cannot deliver an email because the receiving mail server has temporarily rejected it.|
|**DeliveredEvent**|A check box that indicates \(if selected\) that the system receives a *delivered event* when SendGrid has successfully delivered an email to the receiving mail server.|
|**DroppedEvent**|A check box that indicates \(if selected\) that the system receives a *dropped even*t when SendGrid has not delivered an email and has stopped attempting to deliver it.|
|**BouncedEvent**|A check box that indicates \(if selected\) that the system receives a *bounced event* when a receiving mail server has permanently rejected an email and SendGrid cannot deliver it to the recipient.|
|**OpenEvent**|A check box that indicates \(if selected\) that the system receives an *open event* when an email has been opened by a recipient.|
|**ClickEvent**|A check box that indicates \(if selected\) that the system receives a *click event* when a recipient has clicked a link in an email.|
|**SpamReportEvent**|A check box that indicates \(if selected\) that the system receives a *spam report event* when a recipient has marked an email as spam.|
|**UnsubscribeEvent**|A check box that indicates \(if selected\) that the system receives an *unsubscribed event* when a recipient has clicked the *Global Unsubscribe* link and unsubscribed from all SendGrid groups.|
|**Group Unsubscribes**|A check box that indicates \(if selected\) that the system receives a *group unsubscribe event* when a recipient has clicked the *Group Unsubscribe* link and unsubscribed from the particular SendGrid group.|
|**Group Resubscribes**|A check box that indicates \(if selected\) that the system receives a *group resubscribe event* when a recipient has resubscribed to a SendGrid group.|

## SendGrid Unsubscribe Groups Tab

On this tab, you can map the synchronized SendGrid unsubscribe groups with marketing categories created on the [Marketing Categories](CR_30_50_00.md) \(CR305000\) form and view the synced status of the mappings.

The form toolbar has only standard buttons.

A check box that indicates \(if selected\) that the mapping is active. If the mapping is active, when sending mass emails, the system associates the selected marketing category with the mapped SendGrid unsubscribe group. When the system processes SendGrid unsubscribe events, it updates unsubscribe preferences on the **Marketing Unsubscribes** tab of the [Leads](CR_30_10_00.md) \(CR301000\), [Contacts](CR_30_20_00.md) \(CR302000\), or [Business Accounts](CR_30_30_00.md) \(CR303000\) form based on the mapped SendGrid unsubscribe group. By default, the mapping is inactive for new unsubscribe groups—that is, the check box is cleared. You can activate the mapping after selecting a marketing category for the group.

If an unsubscribe group has the *Missing in SendGrid* status, the system automatically clears the check box. You can't activate the mapping while the group has this synchronization status.

-   *Missing in SendGrid*: The unsubscribe group that was previously added to Acumatica ERP hasn't been found in SendGrid during the last successful sync.
-   *Error*: The status of the unsubscribe group couldn't be confirmed during the last synchronization or this synchronization failed.

## Email Accounts Tab

On this tab, you can view all email accounts that use the selected SendGrid connection. All columns on the tab are read-only.

The form toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Email Account ID**|The identifier of the email account.|
|**Account Name**|The name of the email account.|
|**Email Address**|The email address specified for the email account.|
|**Active**|A check box that indicates \(if selected\) that the email account is active.|
