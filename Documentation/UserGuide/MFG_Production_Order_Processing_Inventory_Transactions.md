# Production Processing: Processing of Inventory Transactions {#_b16e411e-b103-4429-87df-fa5f83a74ddf .concept}

Acumatica ERP allows switching to a unified approach to releasing manufacturing-related inventory transactions. The system can release a full manufacturing document and update production within a single, connected transaction—making the release faster, more reliable, and easier to manage. This unified process also improves traceability across inventory, costing, and GL entries.

## Enabling the Unified Release Process { .section}

To start using the unified release process, perform these steps:

1.  Select the **Use New Release Process** check box on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form.

    **Important:** Once the **Use New Release Process** check box is selected and saved, it can't be cleared. This change is irreversible, and you won't be able to switch back to the legacy process.

2.  Create a new numbering sequence on the [Numbering Sequences](CS_20_10_10.md) \(CS201010\) form.

    The system needs this numbering sequence for transactions of a new type—production-linked inventory transactions—to make it easier to distinguish them from transactions created using the legacy process.

3.  Specify this new numbering sequence in the **Production Numbering Sequence** box on the [Inventory Preferences](IN_10_10_00.md) \(IN101000\) form.

## Releasing Inventory Transactions { .section}

Once you have enabled the unified release process, all inventory transactions generated by manufacturing—both stock and non-stock—are consolidated, allowing you to release them as a single document through the [Release IN Documents](IN_50_10_00.md) \(IN501000\) form. Production is updated in the same transaction scope, reducing the risk of data gaps or out-of-sync processes.

## Reviewing Transactions { .section}

Use the [Production Transactions](IN_30_80_00.md) \(IN308000\) form to see exactly which transactions were processed—inventory movements, journal transactions, and any linked cost transactions. This form simplifies transaction traceability and improves auditability.
