# Production Processing: Processing of Inventory Transactions

Acumatica ERP uses a unified approach to releasing manufacturing-related inventory transactions. The system releases a full manufacturing document and updates production within a single, connected transaction. This process also provides traceability across inventory, costing, and GL entries.

## Preparing a Numbering Sequence

Normally, the system automatically specifies a predefined numbering sequence for production-linked inventory transactions in the **Production Numbering Sequence** box on the [Inventory Preferences](IN_10_10_00.md) \(IN101000\) form. If no numbering sequence is specified, perform these steps:

1.  Create a new numbering sequence on the [Numbering Sequences](CS_20_10_10.md) \(CS201010\) form.
2.  Specify this new numbering sequence in the **Production Numbering Sequence** box on the [Inventory Preferences](IN_10_10_00.md) \(IN101000\) form.

## Releasing Inventory Transactions

All inventory transactions generated by manufacturing—both stock and non-stock—are consolidated, allowing you to release them as a single document through the [Release IN Documents](IN_50_10_00.md) \(IN501000\) form. Production is updated in the same transaction scope, reducing the risk of data gaps or out-of-sync processes.

## Reviewing Transactions

Use the [Production Transactions](IN_30_80_00.md) \(IN308000\) form to see exactly which transactions were processed—inventory movements, journal transactions, and any linked cost transactions. This form simplifies transaction traceability and improves auditability.
