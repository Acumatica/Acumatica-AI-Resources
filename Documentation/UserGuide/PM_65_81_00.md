# Project Profitability {#_d3e846b2-f834-4223-b8a9-44d9bc1c3ee5 .reference}

Form ID: \(PM658100\)

**Attention:** This generic inquiry form is available if the *Extended Financial Data Collection* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this form to view project profitability as of the date you specify.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

In this area, you can select the project whose data you want to view in the table and the date through which profitability data will be calculated.

|Element|Description|
|-------|-----------|
|**Through Date**|The date as of which data is displayed. By default, the system inserts the current business date.|
|**Project**|The project for which you want to view profitability information. By default, this box is empty.|

## Table {#2 .section}

If no project is selected, the table lists all projects with the *Active* or *Completed* status, but you can select a specific project to see only its data. Each row represents a project.

**Important:** The leftmost columns of the table aren't described in this topic. These columns display the project's basic information—such as project identifier, description, owner, start and end dates, and status. If you need information about these UI elements, see their descriptions on the [Projects](PM_30_10_00.md) \(PM301000\) form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Original Contract**|The original budgeted amount of the revenue budget lines of the project, which the system calculates by adding all the **Original Budgeted Amount** values.|
|**Original Budget**|The original budgeted amount of the cost budget lines of the project, which the system calculates by adding all the **Original Budgeted Amount** values.|
|**Original Profit**|The expected profit amount, which the system calculates based on the originally budgeted amounts by subtracting the **Original Budget** amount from the **Original Contract** amount.|
|**Original Margin \(%\)**|The expected margin percentage, which the system calculates based on the originally budgeted amounts by using this formula: `(Original Profit / Original Contract) * 100%`.If the **Original Contract** amount is *0*, the **Original Margin \(%\)** is left empty.

|
|**Revised Contract**|The revised budgeted amount for the revenue budget lines of the project, which the system calculates by adding all the **Revised Budgeted Amount** values.|
|**Revised Budget**|The revised budgeted amount for the cost budget lines of the project, which the system calculates by adding all the **Revised Budgeted Amount** values.|
|**Revised Profit**|The revised profit amount, which the system calculates by subtracting the **Revised Budget** amount from the **Revised Contract** amount .|
|**Revised Margin \(%\)**|The margin percentage calculated based on the revised budget amounts, which the system calculates by using this formula: `(Revised Profit / Revised Contract) * 100`.|
|**Billed Amount to Date**|The accumulated revenue amount up to the **Through Date**, which the system calculates by adding the **Amount** values.These **Amount** values the amounts of the project transactions with the *AR* source on the [Project Transactions](PM_30_40_00.md) \(PM304000\) form.

The project transactions that originate from AR invoices and debit memos increase the calculated amount; the project transactions that originate from AR credit memos decrease the calculated amount.

|
|**Actual Costs to Date**|The cost amount accumulated up to the **Through Date**, which the system calculates by summing the **Amount** values. These **Amount** values are the amounts of the expense project transactions on the [Project Transactions](PM_30_40_00.md) \(PM304000\) form.|
|**Profit to Date**|The profit amount to date, which the system calculates by using this formula: `Billed Amount to Date - Actual Costs to Date`.|
|**Margin to Date \(%\)**|The margin percentage to date, which the system calculates by using this formula: `(Profit to Date/Actual Costs to Date) * 100%`.|
