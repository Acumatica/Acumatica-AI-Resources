# Access Rights to Generic Inquiries: To Configure Access Rights to the Export to Excel Action of a Generic Inquiry {#_2d3e577f-1c1f-45ad-af2f-c4e670d4c8f1 .task}

You can configure access rights to the **Export to Excel** action of only those generic inquiries that substitute a data entry form or for which a workspace and category have been specified on the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form. Do the following:

1.  If the generic inquiry has been added to a workspace as a separate form, do the following:
    1.  Open the [Access Rights by Screen](SM_20_10_20.md) \(SM201020\) form.
    2.  In the left pane, expand the nodes to the necessary level to find the generic inquiry to which you want to set up access rights.
    3.  Expand the generic inquiry.
    4.  Expand the *Generic Inquiry Result* container.
    5.  Click the *Export* action.
    6.  In the right pane, select the required access rights level for all necessary user roles. For details, see [User Roles: Restriction Level Options](User_Roles_Access_Levels.md).
    7.  On the form toolbar, click **Save**.
2.  If the generic inquiry is configured to replace an entry form, do the following:
    1.  Open the [Access Rights by Screen](SM_20_10_20.md) form.
    2.  In the left pane, expand the nodes to the necessary level to find the entry form that has been replaced with the generic inquiry to which you want to set up access rights.
    3.  Expand the entry form.
    4.  Expand the container of the entry form.
    5.  Click the *Export* action.
    6.  In the right pane, select the required access rights level for all necessary user roles. For details, see [User Roles: Restriction Level Options](User_Roles_Access_Levels.md).
    7.  On the form toolbar, click **Save**.
