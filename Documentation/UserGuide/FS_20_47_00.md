# Master Contracts {#_2432ce61-06a6-4301-91fc-b141eb1bfc8e .reference}

Form ID: \(FS204700\)

By using this form, you can create master contracts.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

By using the elements in the Summary area, you can create a new master contract or select an existing master contract for editing.

|Element|Description|
|-------|-----------|
|**Master Contract ID**|The identifier of the master contract.|
|**Customer**|The customer associated with the master contract.

 The list of values is limited based on the current user's access role. You can select a customer whose visibility is not restricted for the branch or company to which the user's role is assigned \(the **Restrict Visibility To** box on the **General Info** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form contains this company or branch, or is empty\).

|
|**Branch**|The branch that handles the service order.|
|**Description**|A description of the master contract.|
