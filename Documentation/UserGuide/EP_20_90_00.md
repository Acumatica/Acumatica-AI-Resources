# Time Log Types

Form ID: \(EP209000\)

You use this form to add, view, edit, and delete time log types that employees can use to track their working time. You select a time log type when you use the timer on the [Project Tasks](PM_30_20_00.md) \(PM302000\) form.

You cannot delete a type if either condition is met \(or both are met\):

-   The type is specified in the **Default Time Log Type** box on the [Time and Expenses Preferences](EP_10_10_00.md) \(EP101000\) form.
-   At least one time log has been created for this type.

**Important:** The form is available if the *Clock In and Clock Out* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar has only standard buttons.
