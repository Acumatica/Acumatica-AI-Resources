# Time Log Types {#_81a5acb8-2f90-46b6-90b5-ae4d530fdaf1 .reference}

Form ID: \(EP209000\)

You use this form to add, view, edit, and delete time log types that employees can use to track their working time. You select a time log type when you use the timer on the [Project Tasks](PM_30_20_00.md) \(PM302000\) form.

You cannot delete a type if either condition is met \(or both are met\):

-   The type is specified in the **Default Time Log Type** box on the [Time and Expenses Preferences](EP_10_10_00.md) \(EP101000\) form.
-   At least one time log has been created for this type.

**Important:** The form is available if the *Clock In and Clock Out* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table { .section}

In this table, you can view the existing time log types and add new types, if needed.

|Column|Description|
|------|-----------|
|**Type**|The unique code for the time log type, which can be up to 15 alphanumeric characters. The following options are predefined for common types of time:

 -   *Work*: For work time
-   *Break*: For break time
-   *Travel*: For travel time

|
|**Description**|A brief description of time type.|
|**Earning Type**|The earning type code, which determines how labor costs are calculated for time of this type. You can select any earning type defined on the [Earning Types](EP_10_20_00.md) \(EP102000\) form.**Important:** By default, the earning type is not specified for predefined types of time. If you want the logged time to be recorded as a project cost, you must specify an earning type; otherwise, the system cannot create time activities. For internal time tracking, you can leave this column blank.

|
