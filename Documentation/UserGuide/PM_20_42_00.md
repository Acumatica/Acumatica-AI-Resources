# Rate Table Codes

Form ID: \(PM204200\)

You use this form to add new rate table codes that can be used in projects for building pricing models. Also, you can delete obsolete rate table codes. For more information, see [Billing Rates: General Information](Billing_Rates_GeneralInfo.md).

## Form Toolbar

The form toolbar has only standard buttons.

## Table

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Rate Table Code**|The unique identifier for the rate table code, which is an alphanumeric string of up to 10 characters.|
|**Description**|A short description of the rate table code. An alphanumeric string of up to 50 characters may be used.|
