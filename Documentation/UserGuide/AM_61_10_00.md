# BOM Summary {#_98c8294d-9277-4b06-b611-13666809259d .reference}

Form ID: \(AM611000\)

The report lists a parent inventory item and all of its first level component material requirements with their costs and a total material cost.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **BOM ID**: A particular bill of material. You select a BOM ID to view the bill of material for only this BOM ID, or leave it blank to view all bills of material.
-   **Revision:** A revision of the selected bill of material. You select a specific revision when selecting a BOM ID to view the details about this revision only.
-   **Inventory ID:** A specific inventory item. You select an inventory ID to view all bills of material for this item, or leave it blank to view all bills of material.
-   **Display Materials:** A check box that you select to display the material lines. The check box is selected by default.
-   **Display Tools:** A check box that you select to include all of the tool details.
-   **Display Overheads:** A check box that you select to include all of the overhead details.
-   **Display Notes:** A check box that you select to display the bill of material header notes and the notes associated with the detail records selected.
-   **Display Costs:** A check box that you select to include the unit cost \(from the bill which may not be the current cost\) and extended cost for materials.
