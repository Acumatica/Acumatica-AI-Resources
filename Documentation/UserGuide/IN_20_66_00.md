# Replenishment Seasonality {#_3e6270b0-6f43-42b3-9e20-a03a1ab75a9c .reference}

Form ID: \(IN206600\)

**Note:** This form is available only if the *Inventory Replenishment* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to create, view, and modify the seasonality settings for replenishment. For details on how the seasonality settings are used for the configuration of replenishment, see [Replenishment for Stock Items](../ImplementationGuide/config_OrderMgmt_Replenishment_Mapref.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

This area contains summary information about a particular set of seasonality settings.

|Element|Description|
|-------|-----------|
|**Seasonality ID**|The unique identifier of the set of seasonality settings. An alphanumeric string of up to 10 characters may be used.|
|**Description**|A brief description of the seasonality settings.|
|**Calendar**|The calendar to be used for determining low seasons and for gathering sales statistics.|

## Table {#2 .section}

This area has a table containing the seasons for product replenishment \(usually related to lower sales\), which have non-intersecting date ranges. When you select the start date and end date for each period, these dates should belong to one year.

**Attention:** We strongly recommend that you configure replenishment seasonality for only one year.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that this low season record is active.|
|**Season Start Date**|The start date of the season.|
|**Season End Date**|The end date of the season.

 **Attention:** Seasons should not intersect.

|
|**Factor**|The factor \(coefficient\) used to reduce or increase the item replenishment quantity if replenishment is performed during the low season.

 **Attention:** Do not set the factor equal to zero.

|
