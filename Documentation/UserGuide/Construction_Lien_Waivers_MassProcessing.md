# Lien Waivers: Mass Processing {#_b5177ede-6bd5-46d4-80bc-5b1604e92ee9 .concept}

The following sections explain how to process multiple lien waivers at a time.

## Mass-Printing Lien Waivers { .section}

You can mass-print lien waivers by using the [Print/Email Lien Waivers](CL_50_20_00.md) \(CL502000\) form. On this form, you select the *Print Lien Waivers* action, select the category of the lien waivers, and select the unlabeled check boxes in the rows of the lien waivers to be printed. Then you click **Process** on the form toolbar. The system prepares printable forms for the selected documents. For joint payments, the printable form is generated both for the main vendor and for the joint payee in the payment.

## Mass-Emailing Lien Waivers { .section}

You can mass-email lien waivers by using the [Print/Email Lien Waivers](CL_50_20_00.md) \(CL502000\) form. On this form, you select the *Email Lien Waivers* action, select the category of the lien waivers, and select the unlabeled check boxes in the rows of the lien waivers to be sent by email. Then you click **Process** on the form toolbar. The system prepares printable forms for the selected documents. For joint payments, the email is prepared both for the main vendor and for the joint payee in the payment.

## Mass-Marking Lien Waivers as Final {#section_lpm_vv5_22c .section}

You can mass-mark lien waivers as final ones by using the [Print/Email Lien Waivers](CL_50_20_00.md) \(CL502000\) form. On this form, you select the *Set as Final* action and select the unlabeled check boxes in the rows of the lien waivers to be marked as final. Then you click **Process** on the form toolbar.
