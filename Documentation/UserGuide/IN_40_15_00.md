# Matrix Inventory Summary {#_c171666e-6bb2-4cde-a22b-c3ea8bd4a721 .reference}

Form ID: \(IN401500\)

**Attention:** This form is available only if the *Matrix Items* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

You use this form to view detailed information about the availability of matrix stock items in warehouses. You can specify selection criteria to filter the data to be displayed.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

## Selection Area { .section}

By selecting appropriate values in the boxes of this area, you can view the quantity of each matrix item in the Matrix table.

|Element|Description|
|-------|-----------|
|**Template ID**|The identifier of the template item whose matrix items are displayed in the Matrix table of this form.|
|**Column Attribute ID**|The attribute identifier to be used in matrix columns. By default, for the template selected in the **Template ID** box, the system populates this box with the value of the **Default Column Attribute ID** box on the **Configuration** tab of the [Template Items](IN_20_30_00.md) \(IN203000\) form.

|
|**Row Attribute ID**|The attribute identifier to be used in matrix rows. By default, for the template selected in the **Template ID** box, the system populates this box with the value of the **Default Row Attribute ID** box on the **Configuration** tab of the [Template Items](IN_20_30_00.md) \(IN203000\) form.

|
|**Warehouse**|The warehouse for which you want to view data. You can select a warehouse to view only its data, or leave the box blank to view the data of the items at all warehouses. This box appears only if the *Multiple Warehouses* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Location**|The warehouse location for which you want to view data. You can select a location, or make no selection to view data for all locations.

 This box appears only if the *Multiple Warehouse Locations* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Plan Type**|The plan type—that is, the item status that affects the availability of items in the warehouse—whose item quantities are to be displayed in the Matrix table of this form.|

## Additional Attributes Table { .section}

This table displays the attributes with the *Variant* category that were assigned to the template item in the **Attributes** table on the **Configuration** tab of the [Template Items](IN_20_30_00.md) \(IN203000\) form and were not selected in the **Column Attribute ID** and **Row Attribute ID** boxes of the current form.

For each attribute in this table, you must select the value that the system uses to display quantities for matrix items in the Matrix table of this form.

## Main Attributes Table { .section}

In this table, the values of the attribute selected in the **Column Attribute ID** box are displayed in the columns of the matrix, and the values of the attribute selected in the **Row Attribute ID** box are displayed in the rows of the matrix. Each cell of the matrix displays the quantity of the matrix item based on the settings specified in the Selection area and in the Additional Attributes table.

You can click the quantity in any cell to open the [Inventory Allocation Details](IN_40_20_00.md) \(IN402000\) form for the matrix item.
