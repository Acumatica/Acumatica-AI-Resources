# Item Warehouse Details

Form ID: \(IN204500\)

**Attention:** This form is available only if the *Multiple Warehouses* features is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

By using this form, you can provide each item’s default storage settings, cost and price information, and replenishment settings that are specific to the warehouses where the item is stored.

For more details about stock items, see [Stock Items: General Information](Stock_Items_GeneralInfo.md). For more information about warehouses, see [Warehouses: General Information](Warehouses_GeneralInfo.md).

## Inventory Planning Tab

You use this tab to specify the replenishment settings for the item at this warehouse. You select a replenishment class, and by default, the settings that were specified for the class on the **Inventory Planning** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form are inserted. You can override most of these settings by selecting the **Override Replenishment Settings** check box.

This tab is shown only if either of the following conditions is met:

-   The *Distribution Requirements Planning* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and *DRP* is selected in the **Planning Method** box \(**General** tab\) on the current form.
-   The *Distribution Requirements Planning* and *Inventory Replenishment* features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, and *DRP* or *Inventory Replenishment* is selected in the **Planning Method** box \(**General** tab\) on the current form.
-   The *Material Requirements Planning* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.
-   The *Inventory Replenishment* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and *Inventory Replenishment* is selected in the **Planning Method** box \(**General** tab\) on the [Stock Items](IN_20_25_00.md) \(IN202500\) form.
