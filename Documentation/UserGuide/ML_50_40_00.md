# Generate Cross-Selling Suggestions

Form ID: \(ML504000\)

You use this form to start the generation of cross-selling suggestions. You can select the needed frequency for a predefined schedule to run this process. You can also run the process manually—such as when you need to test updated settings.

This form is available only if the *Related Item Assistant* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

When the process is started, the cloud service generates suggestions for related items and uploads them to Acumatica ERP. Once it completes, a product manager reviews the generated results on the [Manage Cross-Selling Suggestions](IN_50_35_00.md) \(IN503500\) form and approves or rejects them.

</td><td>

The status of the generation process, which is one of the following options:

 -   *New* \(0% progress\): Generation hasn’t started.
-   *Data Uploaded* \(20% progress\): The system has uploaded data to the cloud service.

## Calculation Summary Section

In this section, you can view the generation settings that have been specified on the **Machine Learning** tab of the [Sales Orders Preferences](SO_10_10_00.md) \(SO101000\) form. If the calculation is in progress, the section displays the generation settings used for it. If the previous calculation has completed and a new one hasn't yet started, it displays the generation settings used for the last calculation.
