# Generate Cross-Selling Suggestions {#_c6100056-6875-4746-a2bd-b36bab33b1de .reference}

Form ID: \(ML504000\)

You use this form to start the generation of cross-selling suggestions. You can select the needed frequency for a predefined schedule to run this process. You can also run the process manually—such as when you need to test updated settings.

This form is available only if the *Related Item Assistant* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

When the process is started, the cloud service generates suggestions for related items and uploads them to Acumatica ERP. Once it completes, a product manager reviews the generated results on the [Manage Cross-Selling Suggestions](IN_50_35_00.md) \(IN503500\) form and approves or rejects them.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Cancel Processing**|Cancels the current generation process.

 This button appears only when the process is running.

|
|**Process**|Starts the generation of cross-selling suggestions. You can run the next step manually or wait for the system to run it automatically.

 You can click this button only if *On Demand* is selected in the **Frequency** box on the form. The system starts the generation immediately in this case. If any other frequency is selected, the system displays a warning and starts the processing at the scheduled time.

|
|**View History**|Opens the [Automation Schedule History](SM_20_50_35.md) \(SM205035\) form, where you can view the history of the predefined *Cross-Selling ML Generation* schedule.|

## Frequency Settings Section {#section_fsc_msp_vsb .section}

In this section, you can select the frequency with which the process runs and view the time of the next run.

|Element|Description|
|-------|-----------|
|**Frequency**|The frequency with which the generation process runs. The following options are available:

 -   *Weekly*
-   *Monthly*
-   *On Demand* \(default\)

|
|**Next Run**|The time of the next run of the generation. If *On Demand* is selected in the **Frequency** box, this box also contains *On Demand*.|

## Processing Summary Section {#section_kyt_qsn_bgc .section}

In this section, you can monitor the progress of the generation process.

|Element|Description|
|-------|-----------|
|**Progress**|The stage of the suggestion generation process.|
|**Status**|The status of the generation process, which is one of the following options:

 -   *New* \(0% progress\): Generation hasn’t started.
-   *Data Uploaded* \(20% progress\): The system has uploaded data to the cloud service.
-   *Calculation in Progress* \(20–80%\): Suggestions are being calculated.
-   *Ready to Download* \(80%\): The cloud service has finished the calculation, and the results are ready to be uploaded to the system.
-   *Finalizing Data* \(90%\): The results have been saved to the Acumatica ERP database.
-   *Complete* \(100%\): The results have been uploaded to the [Manage Cross-Selling Suggestions](IN_50_35_00.md) \(IN503500\) form.

|
|**Last Started On**|The date and time when the generation was last started.|
|**Last Executed On**|The date and time when the generation was last performed.|
|**Rows Uploaded**|The number of rows in the dataset uploaded to the cloud service.|
|**Suggestions Imported**|The number of cross-selling suggestions that have been imported from the cloud service into Acumatica ERP.|

## Calculation Summary Section {#section_qtn_rsn_bgc .section}

In this section, you can view the generation settings that have been specified on the **Machine Learning** tab of the [Sales Orders Preferences](SO_10_10_00.md) \(SO101000\) form. If the calculation is in progress, the section displays the generation settings used for it. If the previous calculation has completed and a new one hasn't yet started, it displays the generation settings used for the last calculation.

|Element|Description|
|-------|-----------|
|**Min. Relevance Score \(%\)**|The minimum relevance score items must have for the system to suggest them as cross-sells. This can be a value from *50* to *100*.|
|**Data Period for Analysis**|The analysis period for AR transactions used in the analysis of data and generation of suggestions.|
