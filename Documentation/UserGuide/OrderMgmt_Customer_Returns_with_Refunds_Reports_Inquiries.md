# Customer Returns with Refunds: Related Reports and Forms {#_53e4e321-d7fc-42d4-80ad-2f1e93ec615e .concept}

In the following sections, you can find details about ways to gather information about the returns of items that have been processed or are being processed in the system.

**Attention:** If you don’t see a particular report or form that is described, you may have signed in to the system with a user account that doesn’t have access rights to the report or form. Contact your system administrator to obtain access to any needed reports or forms.

## Printing Return Orders { .section}

To prepare a printable version of the return order that is being processed, you use the [Sales Order](SO_64_10_10.md) \(SO641010\) report. While you are viewing a return order on the [Sales Orders](SO_30_10_00.md) \(SO301000\) form, you can print the sales order by clicking **Print Sales Order** on the More menu. The system opens the [Sales Order](SO_64_10_10.md) report with the printable version of the return order; then you can view the return order and print it by clicking **Print** on the report toolbar.

## Finding Shipments Related to a Return Order { .section}

If you need to view a shipment that is linked to a particular return order, you open the return order on the [Sales Orders](SO_30_10_00.md) \(SO301000\) form and go to the **Shipments** tab, which lists all the shipments that have been prepared for the order. To view the details of a listed shipment, you click its reference number in the **Document Nbr.** column; the system opens the shipment on the [Shipments](SO_30_20_00.md) \(SO302000\) form.

## Printing Invoices { .section}

To prepare a printable form of the credit memo that is being processed, you use the [Invoice &amp; Memo](SO_64_30_00.md) \(SO643000\) report. While you are viewing a credit memo on the [Invoices](SO_30_30_00.md) \(SO303000\) form, you can go to this report by clicking **Print Invoice** on the More menu. The system opens the [Invoice &amp; Memo](SO_64_30_00.md) report with the printable version of the credit memo; then you can view the credit memo and print it by clicking **Print** on the report toolbar.
