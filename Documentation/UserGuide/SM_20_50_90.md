# Cloud Service Diagnostics {#_166718af-2f26-46b8-8481-856d240b7e9b .reference}

Form ID: \(SM205090\)

On this form, you can collect diagnostic information that may be required for troubleshooting about the cloud service or services used by Acumatica ERP. If issues occur, you can use this form to run diagnostics for the connected cloud services and get results in the text file.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Run Diagnostics**|Starts the diagnostic process.|
|**Export Results**|Exports results to a text file \(that is, a file with the `.txt` extension\) and downloads the file to your computer.

 The button is available only if you have run diagnostics and the diagnostic results are available.

|

## Summary Area {#1 .section}

In the Summary area, you can view the read-only values of the key Acumatica ERP cloud properties. Note that if your license does not contain some property, the corresponding box in the Summary area will be empty.

|Element|Description|
|-------|-----------|
|**Discovery URI**|The URL to the service that identifies and returns URLs of the Acumatica ERP cloud services.|
|**Cloud Tenant ID**|The identifier of the tenant.|
|**Client ID**|The Acumatica ERP cloud authorization ID.|
|**Client Secret**|The Acumatica ERP cloud secret value. For security purposes, only the first two and last two characters of the secret value are shown, and the other values are replaced by asterisks, as shown in the following example: *ed\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*57*.|

## Table {#2 .section}

In this table, you can view the list of supported services, whose names typically correspond to the features on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. The table has the following buttons.

|Column|Description|
|------|-----------|
|**Enabled**|A check box that indicates \(if selected\) that the feature that uses a cloud service is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. The system selects this check box automatically when the feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.|
|**Service**|The service name.|
|**Step**|The name of the diagnostic stage. After diagnostics are run, the system updates the step name in this column.|
|**Status**|The status of the service diagnostic.

 This status can be one of the following:

 -   *Not Executed*: The service is enabled, but diagnostics have not yet been run.
-   *Disabled*: The service is disabled.
-   *Succeeded*: The diagnostic was successfully executed for the service.
-   *Failed*: The diagnostic was failed to execute.

 After diagnostics have been executed, the system updates the status according to the execution results.

|
|**Message**|The informational message.

 The message can provide information as follows:

 -   If the service is not enabled \(that is, the check box is cleared in the **Enabled** column\), the message tells which feature should be enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form to activate the service.
-   If the service is enabled and diagnostic has been failed, the system shows the message with execution results.

|
