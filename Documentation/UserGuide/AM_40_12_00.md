# Inventory Planning Requirements by Item {#_3e3614ae-4275-444d-98ba-9da22efbca4b .reference}

Form ID: \(AM401200\)

On this form, you can view item quantities that the system calculates based on the results of inventory requirements planning for a specific item in a specific warehouse. The quantities are grouped by buckets, which are periods defined on the [Inventory Planning Buckets](AM_20_12_00.md) \(AM201200\) form. The system aggregates the quantities from the last inventory planning regeneration by period starting with the current business date. Past-due supply and demand documents are considered for buckets with a negative value \(which correspond to past-due periods\) specified in the **Value** column of the [Inventory Planning Buckets](AM_20_12_00.md) form.

**Tip:** This form is available only if the *Material Requirements Planning* or *Distribution Requirements Planning* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|**Inventory Allocation Details**|Opens the [Inventory Allocation Details](IN_40_20_00.md) \(IN402000\) form for the item and warehouse specified in the Selection area.|

## Selection Area { .section}

In this area, you can select the bucket, item, and warehouse for which you would like to view the results of inventory planning regeneration. You can also view item settings, which are read-only.

|Element|Description|
|-------|-----------|
|**Bucket ID**|The identifier of the bucket for whose periods you would like to view data.|
|**Inventory ID**|The identifier of the item for which you would like to view data.|
|**Warehouse**|The warehouse in which the item is stored. By default, the system inserts the default warehouse specified for the item on the **General** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form. You can select another warehouse, if needed.

 This box is visible only if the *Multiple Warehouses* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

|
|**Qty. on Hand**|The on-hand quantity of the item that the system used for the last inventory planning regeneration, which may differ from the current on-hand item quantity.|
|**Product Mgr.**|The product manager assigned to the item.

 If the item is stored in only one warehouse, the system inserts the product manager specified for the item in the Summary area of the [Stock Items](IN_20_25_00.md) \(IN202500\) form. If the item is stored in multiple warehouses, the system inserts the product manager specified for the item and warehouse in the Summary area of the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form.

|
|**Safety Stock**|The safety stock specified for the selected item and warehouse.

 If the item is stored in only one warehouse, the system inserts the safety stock specified for the item on the **Manufacturing** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form. If the item is stored in multiple warehouses, the system inserts the safety stock specified for the item and warehouse on the **Manufacturing** tab of the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form.

|
|**Replenishment Source**|The replenishment source specified for the selected item and warehouse.

 If the item is stored in only one warehouse, the system inserts the replenishment source specified for the item on the **Manufacturing** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form.

|
|**Preferred Vendor**|The default vendor of the item with the *Purchase* replenishment source.

 The system inserts the vendor specified for the item on the **Vendors** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form.

|
|**Lead Time**|The lead time in days for the vendor displayed in the **Preferred Vendor** box.

 The system calculates this value as the sum of the **Lead Time \(Days\)** and **Add. Lead Time \(Days\)** columns for the vendor row on the **Vendors** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form.

|

## Table { .section}

In the table, you can view the quantities the system calculated based on the results of inventory planning for the item and warehouse you specified in the Selection area. The quantities are grouped by periods of the bucket you also specified in the Selection area.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**From Date**|The starting date of the period.|
|**To Date**|The ending date of the period.|
|**Start Qty.**|The on-hand item quantity at the start of the period. For the first bucket, it is the current on-hand quantity.|
|**Actual Supply**|The available item quantity. The system calculates the quantity as the sum of the beginning quantity and the item quantities in open purchase orders, production orders, and transfer orders within the period.|
|**Actual Demand**|The item quantity that is on demand. The system calculates the quantity as the sum of item quantities in production orders for materials, sales orders, shipments, and transfer orders within the period.|
|**Net Qty.**|The beginning quantity plus the difference between the actual supply quantity and actual demand quantity.|
|**Planned Supply**|The sum of item quantities in planned orders created by inventory planning regeneration and MPS \(master production schedule\) in the period.|
|**Planned Demand**|The sum of item quantities in forecasts and planned orders that generate demand for other production orders in the period.|
|**End Qty.**|The projected on-hand quantity of the item at the end of the period. The system calculates this quantity as follows: `Begin Qty + Actual Supply - Actual Demand + Planned Supply - Planned Demand`.

 This quantity becomes the beginning quantity for the next period.
