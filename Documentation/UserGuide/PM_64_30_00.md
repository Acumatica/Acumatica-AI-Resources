# Change Order {#_9019409d-9807-492b-8d98-a999f5c1f6a4 .reference}

Form ID: \(PM643000\)

**Attention:** This report is available only if the *Change Orders* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

By using this report, you can view and print the selected change order. The printed form of a change report always lists only the revenue budget lines of the document, because only the change orders that affect revenues are subject to printing.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

You use the following parameter to select the information to be displayed on the report:

-   **Reference Number**: The reference number of the change order document. You must select a document.
