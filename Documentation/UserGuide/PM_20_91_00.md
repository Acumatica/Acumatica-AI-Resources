# Time Entry {#_09cd2553-0e9e-2222-804d-106159f9a5b6 .reference}

Form ID: \(PM209100\)

You can use this form to import the time spent on the tasks of projects to Acumatica ERP from an external system through the contract-based REST and SOAP APIs.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Command|Description|
|-------|-----------|
|**Complete**|Changes the approval status of the time entry to *Completed*.|
|**Open**|Changes the approval status of the time entry to *Open*.|

## Summary Area {#2 .section}

In this area, you enter or view details of a time entry.

|Element|Description|
|-------|-----------|
|**ID**|The identifier of the time entry, which is assigned automatically.|
|**Approval Status**|The status of the time entry, which can be one of the following:

 -   *Open*: The time entry can be edited.
-   *Completed*: The time entry has been accepted.

|
|**Date** and **Time**|The start date and time of the time entry.|
|**Employee**|The employee responsible for this time entry.|
|**Approver**|The person that is responsible for approving the time entry. The box is read-only.|
|**Project**|The project associated with this time entry \(or the non-project code, which indicates that this time entry is not associated with any project defined in the system\).|
|**Certified Job**|A check box that indicates \(if selected\) that the time entry is a certified job.

 The system automatically selects the **Certified Job** check box in the time entry if for the associated project, the **Certified Job** check box is selected in the **Project Properties** section on the **Summary** tab of the [Projects](PM_30_10_00.md) \(PM301000\) form.

 This box is shown on the form if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Project Task**|The project task with which this time entry is associated. You can select only a project task that relates to the project selected in the **Project** box. If you select a project that has the default project task, this task is automatically populated in the column.|
|**Cost Code**|The cost code with which this time entry is associated to track project costs and revenue.

 The box is available if the *Cost Code* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Labor Item**|The non-stock item of the *Labor* type associated with the time entry.

 By default, the system selects the labor item associated with the employee of this time entry.

|
|**Union Local**|The union local associated with the time entry.

 The system automatically populates the **Union Local** box in the time entry based on the employee of the time entry and its associated project as follows:

 -   If the employee has an associated union local and the project has no associated union local, the system selects the union local of the owner.
-   If the employee has an associated union local that is one of the union locals associated with the project, the system selects the union local of the owner.
-   If the employee has an associated union local that is not any of the union locals associated with the project, the system leaves the box blank.
-   If the employee has no associated union local, the system leaves the box blank.

 The box is shown on the form if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Summary**|A description of the time entry.|
|**Earning Type**|The earning type for the time entry, which determines how labor is costed. The options are defined on the [Earning Types](EP_10_20_00.md) \(EP102000\) form.|
|**WCC Code**|The work class compensation code associated with the time entry.

 This box appears on the form only if the *Construction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

|
|**Time Spent**|The time \(in hours and minutes\) spent on the time entry.|
|**Overtime**|The overtime the employee spent on the project and task. The box is read-only.|
|**Billable**|A check box that you select if the time spent on the time entry is billable.|
|**Billable Time**|The billable time \(in hours and minutes\) spent on the time entry. This time cannot be equal to zero or exceed the time specified in the **Time Spent** box.|
|**Billable Overtime**|The billable overtime \(in hours and minutes\) spent on the time entry. This time cannot be equal to zero or exceed the time specified in the **Overtime** box.|
|**Cost Rate**|The employee's rate. The box is read-only.|
