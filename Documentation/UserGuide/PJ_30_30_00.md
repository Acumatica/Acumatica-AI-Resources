# Drawing Log {#_2ab927f9-e485-4e02-a6ef-e337c73f09c2 .reference}

Form ID: \(PJ303000\)

**Attention:** This form is available only if the *Construction Project Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

A drawing log is used to store all the drawings and designs \(further drawings\) available on a project. You can use this form to create, view, and edit a drawing log.

## Form Toolbar { .section}

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Create Project Issue**|Opens the [Project Issue](PJ_30_20_00.md#) \(PJ302000\) form with the new project issue and adds the current drawing log to this project issue.|
|**Create Revision**|Opens the current form with the details of the drawing log and with the number of the original drawing log in the **Original Drawing** box of the Summary area.|
|**Create RFI**|Opens the [Request for Information](PJ_30_10_00.md#) \(PJ301000\) form with the new request for information and links the current drawing log to this request for information.|
|**Email**|Opens the [Email Activity](CR_30_60_15.md#) \(CR306015\) form. On this form, the files of the drawing log can be attached to the email by using the **Attach** button.|
|**Export Drawings**|Downloads a zip file with the files of the drawing log.|
|**Link Project Files**|Opens the **Link Project Files** dialog box, in which you select the project files and link them to the drawing log by clicking **Add Link**. In the dialog box, you can select another project and link its files to the drawing log.

 This command appears only if the *Document Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|

## Summary Area {#1 .section}

Here you can create a new drawing log or select an existing drawing log for modification. The following table summarizes the elements of this area.

|Element|Description|
|-------|-----------|
|**Drawing Log ID**|The unique identifier of the drawing log, which the system automatically assigns according to the numbering sequence selected for drawing logs on the [Project Management Preferences](PJ_10_10_00.md) \(PJ101000\) form.|
|**Project**|The project to which drawings are related.|
|**Project Task**|The project task to which drawings are related.|
|**Discipline**|The discipline related to the drawing log. You can select the discipline from the list of disciplines that are defined on the **Drawing Logs** tab of the [Project Management Preferences](PJ_10_10_00.md) \(PJ101000\) form.|
|**Owner**|The owner of the document.|
|**Title**|The title of the drawing log.|
|**Description**|A brief description of the drawing log.|
|**Sketch**|The reference number of the sketch.|
|**Original Drawing**|The identifier of the preceding version of the drawing log.|
|**Drawing Number**|The number of the drawing.

 This box is not editable if the drawing log is a revision or sketch of the existing drawing log.

|
|**Revision**|The revision number of the drawing log.|
|**Drawing Date**|The business date when the drawing log was created. By default, the current business date is selected.|
|**Received Date**|The business date when the drawing log was received. By default, the current business date is selected.|
|**Status**|The status of the drawing log, which can be one of the statuses specified on the **Drawing Logs** tab of the [Project Management Preferences](PJ_10_10_00.md) \(PJ101000\) form.|
|**Latest Revision**|A check box that indicates \(if selected\) that this revision of the drawing log is the latest one.|

## Drawings Tab { .section}

On this tab, you can upload a file to the drawing log.

|Button|Description|
|------|-----------|
|Upload Files|Opens the **Files** dialog box by using which you attach files to the drawing log.|

|Column|Description|
|------|-----------|
|**File Name**|The name of the file.|
|**Comment**|The comment to a file.|
|**Tags**|The tags that are assigned to the file.

 You can add or delete tags if you have a user role with the *Edit* access level to a tag assigned to the file. User roles’ access rights to tags are specified on the [File Tags](SM_20_25_60.md) \(SM202560\) form.

|
|**Current**|A check box that indicates \(if selected\) that the uploaded version of the file is up to date.|
|**Created By**|The name of the user who uploaded the file.|
|**Creation Time**|The date and time when the file was created.|

## Attributes Tab {#734 .section}

On this tab, you can view, add, change, or delete attribute values for the drawing log.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Attribute**|The name of the attribute used for the drawing log.|
|**Required**|A check box that indicates \(if selected\) that this attribute is defined as required; that is, you must specify the appropriate value.|
|**Value**|The value of the attribute for the drawing log.|

## Activities Tab {#2 .section}

This tab has a table with the list of activities associated with the drawing log. You can associate particular tasks, events, emails, and other activities with the drawing log. Acumatica ERP provides you with a list of predefined activity types; you can add new activity types by using the [Activity Types](CR_10_20_00.md) \(CR102000\) form. To create an activity, email, event, or task, click the appropriate command and fill in the dialog box.

The tab includes, in addition to the columns described below, columns \(labeled with icons\) that you can use to attach notes and files to the activity, see if it is completed, check its priority level, and notice whether there are associated reminders. For descriptions of these columns, see [Managing Emails and Activities](../Shared/../UserGuide/CRM_Mktg_Managing_Emails_Activities_Mapref.md).

|Button|Description|
|------|-----------|
|**Create Task**|Opens the [Task](../Shared/../UserGuide/CR_30_60_20.md) \(CR306020\) form, on which you can create a new task.|
|**Create Event**|Opens the [Event](../Shared/../UserGuide/CR_30_60_30.md) \(CR306030\) form, on which you can create a new event.|
|**Create Email**|Opens the [Email Activity](../Shared/../UserGuide/CR_30_60_15.md) \(CR306015\) form, on which you can create a new email.|
|**Create Activity**|Contains a menu with commands that correspond to the list of activity types configured on the [Activity Types](../Shared/../UserGuide/CR_10_20_00.md) \(CR102000\) form.

 By clicking a menu command, you open the [Activity](../Shared/../UserGuide/CR_30_60_10.md) \(CR306010\) form to create an activity of the corresponding type. The following commands are available by default: **Create Chat**, **Create Escalation**, **Create Message**, **Create Phone Call**, **Create Work Item**, and **Create Note**.

 To change the list of menu commands, you can add or remove activity types by using the [Activity Types](../Shared/../UserGuide/CR_10_20_00.md) \(CR102000\) form.

|

|Column|Description|
|------|-----------|
|**Type**|The type of the activity.|
|**Summary**|The brief description of the activity.|
|**Status**|The status of the activity.|
|**Start Date**|The start date and time of the activity.|
|**Created On**|The date and time when the activity was created.|
|**Category**|The category of the activity.|
|**Owner**|The name of the user to whom the activity is assigned.|
|**Created By**|The name of the employee who created the activity.

 **Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|

The tab also has the Activity Description area below the table. The area displays the full description provided for the activity selected in the table. To edit the description, click the link in the **Summary** column of the activity. On the [Activity](../Shared/../UserGuide/CR_30_60_10.md) \(CR306010\) form that opens, you add a description and edit other settings corresponding to the activity.
