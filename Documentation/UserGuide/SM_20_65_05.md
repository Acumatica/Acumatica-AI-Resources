# Scan Jobs {#_92550f71-8ac3-417a-8e94-6baed62fa17e .reference}

Form ID: \(SM206505\)

**Note:** This form is available only if the *DeviceHub* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can review the list of scan jobs that have been initiated in the system and details about the document for which any listed scan job was initiated.

## Form Toolbar { .section}

The table toolbar has only standard buttons.

## Selection Area { .section}

You use this area to select the scan jobs to be listed in the table by their date or status.

|Element|Description|
|-------|-----------|
|**Start Date**|The start date of the date range for which you want to display scan jobs.|
|**End Date**|The end date of the date range for which you want to display scan jobs.|
|**Hide Processed**|A check box that indicates \(if selected\) that only incomplete scan jobs are shown in the table. If this check box is cleared, all scan jobs are listed.|

## Scan Jobs Table { .section}

This table lists the scan jobs that have been performed in the system.

|Column|Description|
|------|-----------|
|**Job ID**|The identifier of the scan job.|
|**DeviceHub ID**|The unique identifier of the DeviceHub application in which the applicable scanner is configured.|
|**Scanner ID**|The unique identifier of the scanner that performs the scan job.|
|**Description**|The description of the scanner that performs the scan job.|
|**Form ID**|The ID of the Acumatica ERP form from which the scan job was initiated.|
|**Paper Source**|The paper source that is used for scanning.|
|**Color Mode**|The color mode that is used for scanning.|
|**Resolution**|The resolution that is used for scanning.|
|**File Type**|The type of the file to which the scanned document will be saved.|
|**File Name**|The name of the file to which the scanned document will be saved.|

## Document Parameters Table { .section}

For any scan job you select in the upper table \(by clicking it\), this table lists information about the document for which the scan job was initiated.

|Column|Description|
|------|-----------|
|**Parameter Name**|The name of the parameter that identifies the document for which the scan job was initiated. \(For example, for a sales order, the lines with the *ORDERTYPE* and *ORDERNBR* parameters—which correspond to the order type and order reference number, respectively—will be shown.\)|
|**Parameter Value**|The value of the parameter that identifies the document for which the scan job was initiated. \(For example, for a sales order of the *SO* type, the *ORDERTYPE* parameter value is *SO*, and the *ORDERNBR* parameter value is the reference number of this sales order.\)|
