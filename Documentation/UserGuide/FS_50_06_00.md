# Run Service Order Billing {#_4df1e52f-392a-4342-a219-335b86dcdd18 .reference}

Form ID: \(FS500600\)

On this form, you can run billing for multiple service orders simultaneously. Only service orders for customers with a billing cycle set to run billing for service orders on the [Billing Cycles](FS_20_60_00.md) \(FS206000\) form will be displayed.

Also, note that only service orders with the **Allow Billing** check box selected on the **Billing Documents** tab of the [Service Orders](FS_30_01_00.md) \(FS300100\) form can be processed on this form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Apply Filters**|Applies the filters of the Selection area. By default, with this check box selected, the table on the current form does not display documents until this action is applied.

 This button is available when the **Require Manual Filtering on Billing Forms** check box is selected on the [Service Management Preferences](FS_10_01_00.md) \(FS100100\) form.

|
|**Fix Service Orders Without Billing Settings**|Continues the process of billing cycle updating of the service orders after the details of the billing cycle have been changed on the [Billing Cycles](FS_20_60_00.md) \(FS206000\) form or the billing cycle settings have been changed for a customer on the [Customers](AR_30_30_00.md) \(AR303000\) form if the process has been stopped abruptly.

 This button is available only if the process of updating billing cycles is stopped abruptly. For example, a power issue has occurred on the server.

|
|**Process**|Initiates the process for the selected service orders.|
|**Process All**|Initiates the process for all service orders in the list.|
|**View Temporary Batches**|Opens the [Delete Temporary Batches](FS_50_02_02.md) \(FS500202\) form. On this form, you can delete a batch or multiple batches of the *Temporary* status. Once a temporary batch is deleted, a new billing process can be run for the service documents, and the newly created billing documents can be processed in the system.This button appears on the form if documents with the *Temporary* status exist in the system.

|

## Selection Area { .section}

In the Selection area, you can make selections that filter the documents shown in the table. You can also specify the type of the billing documents that the system will generate, and the billing date and period to be used.

If you select sales orders as the billing documents to be generated, you can also specify the actions to be performed on sales orders and invoices related to sales orders.

|Element|Description|
|-------|-----------|
|**Generated Billing Documents**|The billing document to be generated during the processing. You can select one of the following options: -   *AR Documents and/or AP Bills*: During the generation process, on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form, an AR invoice is created if the service order balance is positive, and a credit memo is created if the service order balance is negative. If the **Create AP Bills for Negative Balances** check box is selected for the service order type of the service order on the [Service Order Types](FS_20_23_00.md) \(FS202300\) form, a bill is created on the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) form if the service order balance is negative.
-   *Sales Orders*: A sales order is created on the [Sales Orders](SO_30_10_00.md) \(SO301000\) form during the generation process.

You can select this option only if the *Inventory and Order Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md#) \(CS100000\) form.

-   *SO Invoices*: An SO invoice is created on the [Invoices](SO_30_30_00.md) \(SO303000\) form during the generation process.

You can select this option only if the *Advanced SO Invoices* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md#) form.

-   *Project Transactions*: A project transaction is created on the [Project Transactions](PM_30_40_00.md) \(PM304000\) form during the generation process. Also, if a service order contains stock items, an issue with the stock items is generated on the [Issues](IN_30_20_00.md) \(IN302000\) form.

For each service order, one project transaction batch and one issue \(if the service order contains stock items\) is created regardless of the option button selected under **Group Billing Documents By** on the [Billing Cycles](FS_20_60_00.md#) \(FS206000\) form.

You can select this option only if the *Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md#) form.


|
|**Billing Cycle**|The billing cycle for which you want to view the service orders.|
|**Billing Customer**|The customer for which you want to view the service orders.

 The list of customers available for selection may be limited based on the role or roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. In this case, the **Restrict Visibility To** box appears on the **Financial** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form. With the feature enabled, a customer is available for selection if one of the following is true:

-   The **Restrict Visibility To** box is empty for the customer—that is, the customer’s visibility is not restricted.
-   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer, and your user account has the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.

|
|**Date Range**|The start and end dates of the range for which service orders will be displayed. By default, the system sets the start date to the first day of the month and the end date to the last day of the month for the specified business date.This box is hidden if the **Use Time Frame Grouping** check box is selected in the current Selection area.

|
|**Use Time Frame Grouping**|A check box that indicates \(if selected\) that the system filters the records in the table based on the **Cut-Off Date** and processes them according to the customer's billing cycle settings on the [Billing Cycles](FS_20_60_00.md) \(FS206000\) form. This applies if **Time Frame** is selected in the **Group Billing Documents** section on the [Billing Cycles](FS_20_60_00.md) form.If the check box is cleared, the records in the table are filtered based on the **Actual End Date**. Also, the system processes the records without considering the state of the **Time Frame** option button in the customer's billing cycle settings on the [Billing Cycles](FS_20_60_00.md) \(FS206000\) form.

This check box is cleared by default.

This check box is hidden if *Project Transactions* is selected as the generated billing document.

|

|Element|Description|
|-------|-----------|
|**Billing Date**|The date on which the billing documents are generated for the service orders you process. By default, the current business date is selected, but you can override this value.

 You can enter only a date that corresponds to a financial period that has been generated on the [Master Financial Calendar](../Shared/../UserGuide/GL_20_10_00.md) \(GL201000\) form. If the date that you enter belongs to a financial period that has not yet been generated in the system—for example, for a date in the distant future or past—the system will display an error message, and you will not be able to save the record.

|
|**Billing Period**|The financial period in which the billing documents are generated for the service orders you process. By default, the period of the current business date is selected.|

|Element|Description|
|-------|-----------|
|**Prepare Invoice**|A check box that indicates \(if selected\) that the related invoice will be generated for each sales order that is created by the processing on this form.

 This check box is available only if the **Use Sales Order Quick Processing** check box is cleared.

|
|**Release Invoice**|A check box that indicates \(if selected\) that the system should release the invoice related to each sales order created by the processing on this form.

 This check box is available only if the **Prepare Invoice** check box is selected.

|
|**Email Sales Order/Quote**|A check box that indicates \(if selected\) that each generated sales order will be sent by email to the customer.|
|**Use Sales Order Quick Processing**|A check box that indicates \(if selected\) that each generated sales order should be processed by using the quick processing settings specified for the sales order type on the [Order Types](../Shared/../UserGuide/SO_20_10_00.md) \(SO201000\) form. For details, see [Sales Order Types: Quick Processing of Sales Orders](../Shared/../ImplementationGuide/config_Sales_Order_Types_Quick_Process_Workflow.md).

 This check box is available only if the **Prepare Invoice** check box is cleared.

|

## Table { .section}

The table displays the service orders that meet the selection criteria you have specified. You can process all service orders or only those you select.

|Column|Description|
|------|-----------|
|**Included**|A check box that you select to include this service order in processing if you click **Process**.|
|**Order Type**|The type of the service order.|
|**Order Nbr.**|The reference number of the service order.|
|**Billing Customer**|The identifier of the customer for which the document is generated.|
|**Billing Location**|The customer location where the services were performed.|
|**Billing Cycle ID**|The billing cycle related to the customer.|
|**Cut-Off Date**|The date when the documents should be generated for the customer.|
|**Branch Location**|The identifier of the branch location of the service order.|
|**Status**|The status of the document.|
|**Description**|The description of the document.|
|**Batch Nbr.**|The reference number of the batch of documents that is created during generation process. The batch number appears in this column after the generation process is finished.|
