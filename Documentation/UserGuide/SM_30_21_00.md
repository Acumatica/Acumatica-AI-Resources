# MCP Servers

Form ID: \(SM302100\)

You use this form to configure Model Context Protocol \(MCP\) servers and expose selected generic inquiries as callable tools for MCP clients.

This form is available only if the *MCP Server* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

For details, see [Configuring MCP Servers: General Information](MCP_Servers_GeneralInfo.md).

## Form Toolbar

The form toolbar has only standard buttons.

The **Clipboard** menu has the following key menu commands:

-   **Export as XML**: Exports the current MCP server configuration to XML.
-   **Import from XML**: Imports any number of MCP server configurations from XML.

**Attention:** The preceding menu commands do not export/import the generic inquiries used by the Generic Inquiry tools configured on this form. Generic inquiry definitions should be exported/imported separately from the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form.

## Tool Settings for Generic Inquiry Pane

In this pane, you specify the settings of the *Generic Inquiry* tool selected in the **Tools** table.

|Element|Description|
|-------|-----------|
|**Generic Inquiry**|Required. The published generic inquiry that the tool uses as its data source.|
|**Shared Filter to Apply**|Optional. The shared filter that is applied to the selected generic inquiry when the tool is called.|
|**Tool Name**|Required. The name that the MCP client uses to identify and call the tool.|
|**Tool Title**|The human-readable title of the tool. By default, the box is populated with the site map title of the selected generic inquiry.|
