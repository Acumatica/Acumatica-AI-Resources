# Calculate Grams {#_1598cf0e-a9ba-415c-967e-1cb8284bfe36 .reference}

Form ID: \(CR503400\)

On this form, you can initiate the calculation of grams for each contact, lead, or business account record. Grams are used for the calculation of validation scores.

Each record has a number of related parameters, such as *Last Name*, *Email*, *Postal Code*, and *Class ID*. The grams value assigned to a particular record is defined by the total number of parameters that are involved in the calculation of the validation score.

Note that you cannot use the duplicate validation feature if you have not calculated grams for all records of the type that you want to validate.

This form is available only if the *Duplicate Validation* feature is enabled in your system on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Performs calculation for the records that you have selected.|
|**Process All**|Performs calculation for all the records that are currently in the list.|

## Table { .section}

This table contains the list of all records for which grams should be recalculated based on the modified duplicate validation rules.

|Column|Description|
|------|-----------|
|Selected|An unlabeled check box that indicates \(if selected\) that the record is selected.|
|**Business Account**|The business account that the record is associated with.|
|**Account Name**|The name of the company.|
|**Type**|The type of the record, which can be one of the following: *Contact*, *Business Account*, and *Lead*.|
|**Contact**|The full name of the lead or contact.|
