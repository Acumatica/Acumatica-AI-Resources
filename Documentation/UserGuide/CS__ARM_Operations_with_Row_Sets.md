# To Create, Modify, or Delete a Row Set {#_24a4be74-6c8a-41b4-a708-d12563cbc758 .task}

Row sets, which you work with on the [Row Sets](CS_20_60_10.md) \(CS206010\) form, are used to define the rows to be included in the report and the data to be displayed in each row. A row set can be used in multiple reports that use similar data selection rules and a similar report layout structure. Once a row set has been defined, you can include it in an analytical report it was designed for by using the [Report Definitions](CS_20_60_00.md) \(CS206000\) form.

To specify the set of rows for a group of analytical reports or a single report, you can create new row sets or modify the existing ones. To remove the row sets that are no longer used, you can delete the row sets associated with them. This topic describes the steps involved in these operations.

## To Create a Row Set { .section}

1.  Open the [Row Sets](CS_20_60_10.md) \(CS206010\) form.
2.  On the form toolbar, click **Add New Record**.
3.  In the **Code** box of the Summary area, enter the code to be used for the row set.

    **Tip:** The row set code must be unique within the whole system. The length of the code can be up to 10 alphanumeric characters.

4.  In the **Description** box, enter the description of the row set. \(The row description is not displayed in the printed report and is used only to add a descriptive comment on this form about the row set.\)
5.  On the form toolbar, click **Save**. The rows can be added to the created row set at this time or later; see [To Define the Rows of the Row Set](CS__ARM_Defining_the_Rows_to_be_Included_in_the_Row_Set.md).

## To Modify an Existing Row Set { .section}

1.  Open the [Row Sets](CS_20_60_10.md) \(CS206010\) form.
2.  In the **Code** box of the Summary area, select the code of the row set you want to work with.
3.  Change the attributes of the row set as required.
4.  On the form toolbar, click **Save** in the form toolbar.

## To Delete a Row Set { .section}

1.  Open the [Row Sets](CS_20_60_10.md) \(CS206010\) form.
2.  In the **Code** box of the Summary area, select the code of the row set you want to delete.
3.  On the form toolbar, click **Delete**.
