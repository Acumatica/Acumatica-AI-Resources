# Vendor Shipment Pick List {#_7eca42ff-a118-48f0-8d21-50a39042f14d .reference}

Form ID: \(AM644000\)

This report is used to pick the items being shipped to a vendor for an outside process. The [Vendor Shipments](AM_31_00_00.md) \(AM310000\) form is used to create and process the shipment and this report can be printed from that form.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Shipment Nbr**: Select the vendor shipment you wish to print.
-   **Print Bar Code?:** If selected, the barcode for the shipment number, inventory ID, and if required, the lot or serial number is printed.
