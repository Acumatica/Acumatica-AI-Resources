# Calculate Overdue Charges {#_c775a447-ef48-4a29-be2d-a72196d06044 .reference}

Form ID: \(AR507000\)

You can use this form to find documents that are subject to overdue charges, calculate the exact amounts of overdue charges, and create appropriate documents for the charges. The overdue documents can be selected by statement cycle, customer class and customer. As a result of processing, the system generates Accounts Receivable documents of the *Overdue Charge* type with the *Balanced* or *On Hold* status depending on the value of the **Hold Documents on Entry** check box on the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR101000\) form. You can further process generated documents by using the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form. For details, see [Overdue Charges: Process Activity](Finance_Overdue_Charges_Process_Activity.md).

**Attention:** The system calculates overdue charges for all customer accounts for which overdue charges are assigned, except for the following:

-   Accounts with the *Inactive* and *On Hold* status
-   Accounts whose visibility is restricted to a particular branch or a company, if you are signed in to a different branch.

This form is available if the *Overdue Charges* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Calculate**|Finds the overdue documents that meet the selection criteria and calculates the amounts of overdue charges for the documents in accordance with the overdue charge code settings on the [Overdue Charges](AR_20_45_00.md) \(AR204500\) form.|
|**Process**|Processes the overdue charges for the documents you have selected, creating new Accounts Receivable documents of the *Overdue Charge* type with the *Balanced* or *On Hold* status depending on the value of the **Hold Documents on Entry** check box on the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR301000\) form.|
|**Process All**|Processes the overdue charges for all the listed documents, creating new Accounts Receivable documents of the *Overdue Charge* type with the *Balanced* or *On Hold* status depending on the value of the **Hold Documents on Entry** check box on the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR301000\) form.|
|**View Last Charge**|Navigates to the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form and displays the details of the unreleased overdue charge document that had been generated for the selected overdue document.|

## Selection Area {#1 .section}

You can use the elements in this area \(described in the following table\) to select the date and the financial period for the charges, and the criteria for the overdue documents to be displayed.

|Element|Description|
|-------|-----------|
|**Statement Cycle**|The statement cycle for which you want to display data. Leave the box blank if you want to calculate charges for all cycles. If the **Set Default Overdue Charges by Statement Cycle** check box is selected on the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR101000\) form, you must specify the statement cycle.|
|**Overdue Charge Date**|The date when overdue charges are calculated and appropriate documents are created.|
|**Fin. Period**|The financial period to which the document's transactions should be posted.|
|**Customer Class**|The customer class for which you want to display data. The box is available if the **Set Default Overdue Charges by Statement Cycle** check box is cleared on the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR101000\) form.|
|**Customer**|The customer account for which you want to display data. The box is available if the **Set Default Overdue Charges by Statement Cycle** check box is cleared on the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR101000\) form.|

## Table {#2 .section}

This table contains the list of overdue documents with relevant details for each document, including the amounts of overdue charges.

If the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the list of documents loaded in the table may be limited based on their customers' visibility restriction. A document is loaded if for the document's customer the **Restrict Visibility To** box on the **Financial** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form is empty, contains the current branch to which you are signed in, the company of the branch, or a company within a company group.

**Attention:** Overdue documents appear in the table only after you click **Calculate** on the form toolbar to find overdue documents and calculate overdue charges for them.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include the document for processing.|
|**Type**|The type of Accounts Receivable document for which overdue charges were calculated: *Invoice*, *Debit Memo*, or *Overdue Charge*.|
|**Reference Nbr.**|The reference number of the document, which was assigned by a numbering sequence. By clicking the number, you can navigate to the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form, where you can view document details.|
|**Date**|The date of the document.|
|**Due Date**|The date when payment for the document is due, in accordance with the credit terms.|
|**Customer**|The customer for whom this document is intended, by its ID.|
|**Customer Name**|The customer's complete name as it appears in the system.|
|**Currency**|The currency of the original document.|
|**Amount**|The amount of the original document.|
|**Open Balance**|The amount of the original document to which payments were not applied.|
|**Last Payment Date**|The date of the last applied payment.|
|**Last Charge Date**|The date of the last overdue charge document generated for this document.|
|**Overdue Days**|The number of days this document is past due since its due date or, if overdue charges were previously calculated, since the last charge date.|
|**Charge Currency**|The currency used for the overdue charges.|
|**Charge Amount**|The amount of the charge.|
