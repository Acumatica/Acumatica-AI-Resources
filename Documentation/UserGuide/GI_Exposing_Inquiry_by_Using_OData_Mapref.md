# Exposing Inquiry Results by Using OData {#_46d3beed-0faf-4908-b5f4-1c282a110c4d .concept}

You can use generic inquiry forms to expose data in Acumatica ERP by using the Open Data Protocol \(OData\).

In the topics of this chapter, you will learn how to expose the results of a generic inquiry through the generic inquiry–based OData interface.

**Tip:** Acumatica ERP provides the following types of OData interfaces:

-   *Generic inquiry–based*: Retrieves data from generic inquiries
-   *DAC-based*: Retrieves data from data access classes \(DACs\)

This chapter describes the generic inquiry–based OData interface. For details about the DAC-based OData interface, see [Accessing DACs Through OData](../Shared/../UserGuide/RPT_DAC_OData_Mapref.md).
