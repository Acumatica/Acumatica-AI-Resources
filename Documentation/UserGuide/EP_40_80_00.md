# Employee Utilization {#_6016f279-619e-437e-8b37-fea50e5c3aac .reference}

Form ID: \(EP408000\)

On this inquiry form, you can analyze how employees allocate their time between projects and other tasks. The form helps you understand of how employees allocate their time between released billable and non-billable time activities.

**Attention:** This form is available only if either the *Time Management* feature or the *Advanced Financials* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

You can use the settings in this area to control how the system displays and calculates the employee utilization data in the table. These settings determine the range of dates and the employees for which utilization data is shown.

|Element|Description|
|-------|-----------|
|**Start Date**|The start date of the date range when the employee logged the time activity. By default, the system inserts the first day of the current year.|
|**End Date**|The end date of the date range when the employee logged the time activity. By default, the current business date is inserted.|
|**Show Employees**|An option that defines which employees are shown in the table. You can select one of the following: -   *All Employees* \(default\): Displays all employees created on the [Employees](EP_20_30_00.md) \(EP203000\) form.
-   *Employees with Activities*: Displays only the employees with at least one time activity logged within the specified date range.

|

## Table {#2 .section}

This table shows the time-allocation values calculated for each employee based on their released time activities. These values indicate how employees divide their time between billable and non-billable activities, including both project and non-project work.

|Column|Description|
|------|-----------|
|**Employee**|The employee’s name.|
|**Position**|The employee’s position in the company.|
|**Supervisor**|The name of the employee's direct superior.|
|**Organization**|The name of the organization the branch is belong to.|
|**Branch**|The branch of the organization to which the employee is assigned.|
|**Total Logged Hours**|The total number of hours the employee logged for all activities.|
|**Total Available Hours**|The total number of hours the employee is available to work, based on the employee's assigned work calendar.|
|**Project Billable Hours**|The number of billable hours spent on all project-related activities.|
|**Project Utilization \(%\)**|The percentage of the employee’s total available working hours spent on billable project work. The metric is calculated as follows.```
**Project Billable Hours** / **Total Available Hours** x 100
```

|
|**Total Billable Hours**|The total number of billable hours.|
|**Total Utilization \(%\)**|The percentage of the employee’s total available working hours spent on billable work. The metric is calculated by using the following formula.```
**Total Billable Hours** / **Total Available Hours** x 100
```

|
|**Project Non-Billable Hours**|The number of non-billable hours spent on project-related activities. This metric is calculated as the total number of hours logged for all project-related activities minus the number of billable hours spent on those activities \(**Project Billable Hours**\).|
|**Total Non-Billable Hours**|The total number of non-billable hours the employee spent on all activities. This metric is calculated as **Total Logged Hours** minus **Total Billable Hours**.|
|**Total Holiday Hours**|The total number of holiday hours spent by the employee.|
|**Total Billable Holiday Hours**|The number of billable holiday hours spent by the employee.|
|**Total Vacation Hours**|The total number of vacation hours taken by the employee.|
|**Total Billable Vacation Hours**|The number of billable vacation hours taken by the employee.|
