# Submittal Form {#_bbbf956f-ecb2-4e94-be6a-1890ce133f68 .reference}

Form ID: \(PJ663000\)

The report displays details of a submittal. this form can be printed or send by email.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Submittal ID**: The submittal for which you want to view report. Select the submittal from the list of submittals created in the system.
-   **Revision ID**: The revision number of the submittal for which you want to view subcontract information. By default, *0* is selected.
