# To Validate Addresses {#_32623b8f-a5b9-4c8d-a189-203a25315ea0 .task}

If you need to validate the addresses of branches, warehouses and customers, you can do this on the [Companies](CS_10_15_00.md) \(CS101500\), [Branches](CS_10_20_00.md) \(CS102000\), [Warehouses](IN_20_40_00.md) \(IN204000\), and [Customers](AR_30_30_00.md) \(AR303000\) forms as described in the instructions below.

## To Validate the Addresses of Companies { .section}

1.  Open the [Companies](CS_10_15_00.md) \(CS101500\) form.
2.  For each of the companies, do the following:
    1.  Make sure that the following information is provided on the **General Info** tab: company name, country, state, city, postal code, phone number \(**Phone 1**\), and address.
    2.  If the *Validate Addresses* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, click **Validate Addresses** on the form toolbar. If the feature is not enabled, click the **View on map** button and validate the address manually.

## To Validate the Addresses of Branches { .section}

1.  Open the [Branches](CS_10_20_00.md) \(CS102000\) form.
2.  For each of your organization's branches, do the following:
    1.  Make sure that the following information is provided on the **General Info** tab: company name, country, state, city, postal code, phone number \(**Phone 1**\), and address.
    2.  If the *Validate Addresses* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, click **Validate Addresses** on the form toolbar. Otherwise, click the **View on map** button and validate the address manually.

## To Validate the Addresses of Warehouses { .section}

1.  Open the [Warehouses](IN_20_40_00.md) \(IN204000\) form.
2.  For each warehouse defined in the system, perform the following:
    1.  On the **Address Information** tab, make sure the required address is specified.
    2.  If the *Validate Addresses* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, click **Validate Addresses** on the More menu. Otherwise, click the **View on map** button and validate the address manually.

## To Validate the Addresses of Customers { .section}

1.  Open the [Customers](AR_30_30_00.md) \(AR303000\) form.
2.  For each customer to which shipments will be sent via the integrated carrier, perform the following steps:
    1.  Open the **General Info** tab, and make sure that the main address is specified.
    2.  On the More menu, click **Validate Addresses** if the *Address Validation* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. If the *Address Validation* feature is not enabled, validate the addresses manually.

        You can run validation for multiple business accounts at once by using the [Validate Addresses in Profiles](../Shared/../UserGuide/CR_50_90_20.md) \(CR509020\) form.

    3.  Open the **Locations** tab, and make sure that the address information is specified for each customer location.
    4.  On the More menu, click **Validate Addresses** if the *Address Validation* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) form. If the *Address Validation* feature is not enabled, validate the addresses manually.
