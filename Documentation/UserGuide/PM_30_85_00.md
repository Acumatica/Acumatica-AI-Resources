# Change Requests

Form ID: \(PM308500\)

**Attention:** This form is available only if the *Change Requests* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this form to view, modify, add, or delete a change request.

</td></tr><tr><td>

**Ignore Approver's Delegations**

</td><td>

A check box that indicates \(if selected\) that the system will assign the selected records to the specified new approver but not to their delegate, even if the new approver is unavailable and has a delegate specified for the current business date.

 If the check box is cleared and if the new approver is not available and has a delegate specified for the current date, the system will reassign the selected records to the delegate if they’re available. If the delegate is unavailable, the system will reassign the requests to the delegate of the delegate. The system will continue the search in this way until:

 -   It assigns an approver with no active delegations set up for the current date.

</td><td>

The status of the change request, which can be one of the following:

 -   *On Hold*: The user can edit or delete the change request with this status but cannot link the change request to a change order or create a change order based on the change request. The amounts and quantities in this change request are not included in the potential amounts and quantities of the project budget.
-   *Pending Approval*: The change request has been taken off hold \(that is, **Remove Hold** was clicked\) and is awaiting approval. The amounts and quantities in this change request are not included in the potential amounts and quantities of the project budget.

This status is available if the approval map has been specified in the **Change Request Approval Map** box on the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form.

**Tip:** On the [Approvals](EP_50_30_10.md) \(EP503010\) form, a change request with this status is visible to the employee who has been assigned to approve the change request.

-   *Rejected*: The employee who was assigned to approve the change request has rejected it. The change request can be put on hold for further editing. The amounts and quantities in this change request are not included in the potential amounts and quantities of the project budget.

This status is available if the approval map has been specified in the **Change Request Approval Map** box on the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form.

-   *Open*: The employee who was assigned to approve the change request has approved it. If no approval is configured for change requests, the system assigns this status to the change request immediately after a user clicks **Remove Hold** on the form toolbar. The user can create a change order for the change request, link the change request to a change order, or assign it the *On Hold* status for further editing. The amounts and quantities in this change request are included in the potential amounts and quantities of the project budget.
-   *Canceled*: The change request has been canceled. The change request cannot be edited and change orders cannot be based on it. The amounts and quantities in this change request are not included in the potential amounts and quantities of the project budget.
-   *Closed*: The change request has been processed in full; it cannot be edited. The amounts and quantities in this change request are not included in the potential amounts and quantities of the project budget.

**Unit Price Source**

    ```

    ```

-   *Sales Prices*: The unit price is copied from the sales price of the selected inventory item. The system:

    1.  Searches for the sales price on the [Sales Prices](AR_20_20_00.md) \(AR202000\) form. The price must be effective on the date specified in the **Change Date** box of the current form.
    2.  If no applicable sales price is found, uses the default price specified in the **Default Price** box on the **Price/Cost** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) or [Non-Stock Items](IN_20_20_00.md) \(IN202000\) form.
**Tip:** For more details on how the price is selected, see [Sales Prices: Rules of Price Selection](Prices_Sales_Price_Selection_GeneralInfo.md).


 When you create a change request, the system inserts the unit price source specified for the selected project. You can change the option if the change request has the *On Hold* status.

 If *Sales Prices* is selected:

 -   The **Markup Total** box is hidden and excluded from the **Price Total** calculation.
-   The **Price Markup \(%\)** and **Line Markup \(%\)** columns are hidden.
-   The **Line Amount** is equal to the **Ext. Price**.
-   The **Markups** tab is hidden and its existing markup lines are cleared.
-   On the **Taxes** tab, the taxable amount is calculated only from estimation lines.

 If you change the selected option after estimation lines have been added, the system updates the unit prices of the existing estimation lines according to the newly selected source.

</td></tr><tr><td>

</td></tr><tr><td>

**Line Total**

</td><td>

</td></tr><tr><td>

**Markup Total**

</td><td>

</td></tr><tr><td>

**Gross Margin \(%\)**

</td><td>

The gross margin percentage. The system calculates this percentage by using the following formula: `Gross Margin (%) = (Price Total – Cost Total) / Price Total * 100`.

</td></tr><tr><td>

**Price Total**

</td><td>

The sum of the **Line Total** and **Markup Total**.

</td></tr><tr><td>

**Tax Total**

</td><td>

The total tax amount of the change request. The system calculates this amount as the sum of the **Tax Amount** values on the **Taxes** tab.

 For built-in tax calculation, this amount is updated when you do any of the following:

 -   Modify the **Change Date**
-   Add, modify, or delete an estimation or markup line
-   Change an amount or tax category in an estimation or markup line
-   Change the tax zone, tax calculation mode, or tax lines on the **Taxes** tab

 For external tax calculation, this amount is updated when you save the change request, remove it from hold, create a change order for this change request or recalculate external taxes.

</td></tr><tr><td>

**Change Total**

</td><td>

The total amount of the change request, including taxes. The system calculates this amount as follows:

 -   If only exclusive taxes apply or the *Net* option is selected in the **Tax Calculation Mode** box: `Price Total + Tax Total`
-   If only inclusive taxes apply or the *Gross* option is selected in the **Tax Calculation Mode** box: **Price Total**
-   If both inclusive and exclusive taxes apply: **Price Total** plus the exclusive tax amounts

 For built-in tax calculation, this amount is updated when you do any of the following:

 -   Modify the **Change Date**.
-   Add, modify, or delete an estimation or markup line.
-   Change an amount or tax category in an estimation or markup line.
-   Change the tax zone, tax calculation mode, or tax lines on the **Taxes** tab.

 For external tax calculation, this amount is updated when you save the change request, remove it from hold, create a change order for this change request or recalculate external taxes.
