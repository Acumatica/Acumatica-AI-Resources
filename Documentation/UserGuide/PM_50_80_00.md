# Transfer Project Inventory to Free Stock {#_a5f04a16-481d-4874-85ba-3cc7390bc40d .reference}

Form ID: \(PM508000\)

**Important:** The form is available if the *Project-Specific Inventory* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can mass-transfer of inventory items that are allocated in the project inventory of a particular project to free stock. You need to do this, for example, if a project has been completed and some inventory items left unused. You do not open this form directly \(through a workspace or a search\). Instead, you open a particular project on the [Projects](PM_30_10_00.md) \(PM301000\) form and click **Transfer Inventory to Free Stock** on the More menu of the form.

**Tip:** If you want to access this form directly, add it to the needed workspace on the [Site Map](SM_20_05_20.md) \(SM200520\) form. For more information, see [UI Navigation Options: Site Map](SA_Customizing_UI_Site_Map_Concept.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates processing for the inventory items that you have selected in the table. The system creates and releases inventory transfer transactions that will move the selected stock items from the project cost layer to the normal cost layer of the same warehouse and warehouse location.|
|**Process All**|Initiates processing of all the inventory items listed in the table. The system creates and releases inventory transfer transactions that will move all the stock items reserved for the project from the project cost layer to the normal cost layer of the same warehouse and warehouse location.|

## Selection Area {#1 .section}

You use the elements in this area to filter the items by project task and inventory ID.

|Element|Description|
|-------|-----------|
|**Project**|The project for which you want to clear the project inventory.|
|**Project Task**|The project task for which you want to clear the project inventory. If you want to view the items associated with all project tasks of the selected project, leave this box blank.|
|**Inventory ID**|The inventory item that you want to transfer to free stock. If you want to view all items associated with the selected project, leave this box blank.|

## Table {#2 .section}

This table contains the list of inventory items that matches the criteria you have specified in the Selection area. These are the items that are reserved for the selected project.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that, if selected, lets you choose the inventory item for processing.|
|**Inventory ID**|The identifier of the stock item to be transferred to free stock from the project stock.|
|**Warehouse**|The warehouse in which the stock item is stored for the project.|
|**Location**|The warehouse location in which the item is stored for the project.|
|**Cost Layer Type**|The type of the cost layer on which the item is stored:-   *Normal*: Indicates that the items are moved from the project that has the *Track by Project Quantity* inventory tracking mode.
-   *Project*: Indicates that the items are moved from the project that has the *Track by Project Quantity and Cost* inventory tracking mode.

|
|**Project**|The project for which the item is allocated.|
|**Project Task**|The project task for which the item is allocated.|
|**Total Qty. on Hand**|The total quantity of item on hand that is allocated for the project.|
|**Total Cost**|The total cost of item on hand that is allocated for the project. This value is shown only for the projects that have the *Track by Project Quantity and Cost* inventory tracking mode.|
