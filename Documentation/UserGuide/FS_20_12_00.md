# Problem Codes

Form ID: \(FS201200\)

By using this form, you can add, view, and modify the codes that represent problems and their descriptions.

## Form Toolbar

The form toolbar includes only standard buttons.

## Table

|Column|Description|
|------|-----------|
|**Problem ID**|The unique identifier of the specific problem. You can specify an identifier of up to 15 characters.|
|**Description**|A description of the problem that the customer has. You can specify a description of up to 60 characters.|
