# Processing Adjusting Transactions {#_6874481f-0fcc-43cf-a4bc-34e02922f8f9 .concept}

Sometimes you may need to adjust transactions to be posted to the specific period and then reversed in the period after that.

In this chapter, you will find general information on how to process adjusting transactions, a checklist for system implementation, an activity that describes how to process and adjusting transaction in the system, and report and inquiries that can be useful to find and view related transactions.
