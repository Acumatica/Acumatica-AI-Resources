# Assigning Roles to Portal Users {#_fa9e969d-6a39-4444-81fb-9c3b17ece992 .concept}

*Roles* determine which forms and actions are available to each portal user in the Modern Customer Portal. Each role includes a defined set of access rights, and every portal user must have at least one role assigned. Roles can be assigned by:

-   An administrator in Acumatica ERP
-   An authorized portal user directly in the Modern Customer Portal

When you create a contact of the customer, the new contact becomes visible in both Acumatica ERP and the Modern Customer Portal. After you select a user type and assign one or more roles to the contact, the system creates a portal user for the contact on the [Users](SM_20_10_10.md) \(SM201010\) form of Acumatica ERP. This user can then sign in to the portal and access forms based on the assigned roles.

In this chapter, you’ll learn:

-   Which predefined user roles are provided in the Modern Customer Portal and what access rights they include
-   How to assign roles to contacts who will use the portal

**Important:** This functionality is available only if the *Modern Customer Portal* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form in Acumatica ERP.
