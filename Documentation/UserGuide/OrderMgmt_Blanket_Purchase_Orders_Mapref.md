# Processing Blanket Purchase Orders {#_d6c620cc-762d-41a5-acd6-dea9fb5b1f5e .concept}

In Acumatica ERP, you can create a blanket purchase order if you need to record your company's intention to buy a large quantity of goods during a long period of time. You may use a blanket order to order goods in larger volumes if a vendor offers a considerable volume discounts or the specified goods are not always available from the vendor. A blanket order is not directly fulfilled or billed. Instead, the blanket order is fulfilled through a number of child orders, and each child order is billed.
