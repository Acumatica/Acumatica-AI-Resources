# Automated Shipping Operations

In Acumatica ERP, you can specify shipping options for a shipment in an automated mode by using barcode scanners or mobile devices with a scanning option on the [Pick, Pack, and Ship](SO_30_20_20.md) \(SO302020\) form or the Pick, Pack, and Ship screen in the Acumatica mobile app. This functionality becomes available when the *Fulfillment* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

The topic of this chapter describes the automated shipping workflow.
