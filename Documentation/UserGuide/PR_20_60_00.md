# Payroll Calendar {#_2bec17ec-be26-41bb-bc3e-396108fc0911 .reference}

Form ID: \(PR206000\)

Payroll is run according to a schedule. By using this form, you can define a template the system uses to generate a schedule for a pay group. One schedule template can be assigned to one pay group.

**Note:** For a payroll calendar with the *Semimonthly*, *Monthly*, *Bimonthly*, *Quarterly*, or *Custom Number of Periods* pay frequency selected in the **Period Type** box, it is mandatory that you create calendar periods before you save the changes.

## Form Toolbar { .section}

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Create Periods**|Creates calendar periods according to the settings specified in the Summary area.

 The system uses these calendar periods as a template schedule to generate pay periods for a particular year on the [Pay Periods](PR_20_10_00.md) \(PR201000\) form.

 This command is not available if the weekly or biweekly period type is selected in the Summary area of this form because in this case the number of pay periods may be different for different years, which cannot be reflected in a template schedule.

|
|**Delete Pay Group Periods**|Deletes the calendar periods created for the specific pay group. You delete pay group periods if you need to delete the calendar or the pay group.|
|**Shift First Year**|Shifts the first year to one year earlier.

 The command is available if pay periods were created on the [Pay Periods](PR_20_10_00.md) \(PR201000\) form for the pay group. You may need to shift the first year if you created a payroll calendar for a wrong year.

|

## Summary Area { .section}

You use the elements in this area to specify details of a template for a schedule creation.

|Element|Description|
|-------|-----------|
|**Pay Group**|The unique identifier of a pay group for which the template of a pay schedule is defined.|
|**First Year**|The starting year of the schedule.|
|**Year Starts On**|The starting date of the schedule.|
|**Period Type**|The pay frequency, which can be one of the following: *Semimonthly*, *Monthly*, *Bimonthly*, *Quarterly*, *Weekly*, *Biweekly*, or *Custom Number of Periods*.

 With the *Custom Number of Periods* option selected, the **Number of Periods** box is available for editing. You specify the needed number of periods in this box.

 With the *Weekly* or *Biweekly* option selected, the user specifies additional settings.

|
|**Length of Period \(Days**\)|The length of the pay period in days. The box is read-only.

 The box appears if the *Weekly* or *Biweekly* option is selected in the **Period Type** box.

|
|**Week Starts On**|The week day when the pay period starts.

 The box appears if the *Weekly* or *Biweekly* option is selected in the **Period Type** box.

|
|**Paid On**|The week day when the payment is paid.

 The box appears if the *Weekly* or *Biweekly* option is selected in the **Period Type** box.

|
|**Payment Released**|Determines when the payment is sent to the employees. The following options are available:-   *4 Weeks Before Period Start*
-   *3 Weeks Before Period Start*
-   *2 Weeks Before Period Start*
-   *1 Week Before Period Start*
-   *Same Week As Period Start*
-   *1 Week After Period Start*
-   *2 Weeks After Period Start*
-   *3 Weeks After Period Start*
-   *4 Weeks After Period Start*

The box appears if the *Weekly* or *Biweekly* option is selected in the **Period Type** box.

|
|**First Period Starts On**|The date when the first pay period starts.

 The box is available for editing if the *Semimonthly*, *Monthly*, *Bimonthly*, *Quarterly*, or *Custom Number of Periods* option is selected in the **Period Type** box.

|
|**2nd Period Starts On**|The date when the second pay period starts.

 The box appears if the *Semimonthly* option is selected in the **Period Type** box.

|
|**First Transaction Date**|The date of the first transaction. The box is read-only.

 The box is available for editing if the *Semimonthly*, *Monthly*, *Bimonthly*, *Quarterly*, or *Custom Number of Periods* option is selected in the **Period Type** box.

|
|**2nd Transaction Date**|The date of the second transaction. The box is read-only.

 The box appears if the *Semimonthly* option is selected in the **Period Type** box.

|
|**Occurs on Second Week of Year**|A check box that indicates \(if selected\) that the first transaction date is on the second week of the period. The system automatically adjusts the date in the **First Period Starts On** and **First Transaction Date** boxes.

 The box is available if the *Biweekly* option is selected in the **Period Type** box.

|
|**Number of Periods**|The number of periods created for the pay group.

 The box is available for editing if the *Custom Number of Periods* option is selected in the **Period Type** box. You specify the needed number of periods in this box.

|

## Table { .section}

After you completed specifying settings in the Summary area, you click the **Create Periods** command. The system fills in the table with the details of each generated pay period.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Period Nbr.**|The sequential number of a pay period.|
|**Start Date**|The start date of a pay period.|
|**End Date**|The end date of a pay period.|
|**Transaction Date**|The date of a transaction date for a period.|
|**Description**|The description of a pay period.|
