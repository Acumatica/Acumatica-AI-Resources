# Item Lookup {#_fb6bf977-22e7-4f00-b88d-f49a6f89f649 .reference}

Form ID: \(IN202520\)

By using this form, you can scan an item barcode and view the item location and the availability information about the item.

**Note:** This form is available only if the *Inventory Operations* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Reset**|Resets the selected warehouse and stock item and clears the table.|

## Summary Area { .section}

In this area, you can enter the inventory item and view system-generated information about the previous and suggested operations and about the working mode.

|Element|Description|
|-------|-----------|
|**Scan**|A box in which you can enter commands to initiate operations and switch between working modes. The results of barcode scanning are also entered automatically into this box. This is the only entry box on the form.

 For the list of commands supported in each mode, see [Working Modes and Supported Commands](WMS_Commands_List.md).

|
|**Inventory ID**|The identifier of the entered inventory item.|
|Notification Area|An area that displays information that is pertinent to what you are doing, which can be any of the following:-   The result of the last operation
-   The next suggested operation

|

## Item Tab { .section}

On this tab, you can view information about the selected inventory item. The tab has a Summary area and a table with location and availability information about the inventory item.

|Element|Description|
|-------|-----------|
|**Item Class**|The item class to which the stock item is assigned.|
|**Type**|The type of stock item, which is one of the following:-   *Finished Good*
-   *Component Part*
-   *Subassembly*

|
|**Is a Kit**|A check box that indicates \(if selected\) that this stock item is a kit.

 This check box is displayed only if the *Kit Assembly* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Valuation Method**|The method used for the item for inventory valuation, which is one of the following: -   *Average*
-   *Standard*
-   *FIFO*
-   *Specific*

|
|**Lot/Serial Class**|The lot/serial class to which the stock item is assigned.

 This box appears only if the *Lot/Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Product Workgroup**|The product workgroup to which the stock item is assigned.|
|**Product Manager**|The product manager to whom this stock item is assigned for processing.|
|**Base Unit**|The unit of measure \(UOM\) used as the base unit for this stock item.|
|**Sales Unit**|The UOM to be used as the sales unit for the stock item.

 This box is displayed only if the *Multiple Units of Measure* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Purchase Unit**|The UOM to be used as the purchase unit for the stock item.

 This box is displayed only if the *Multiple Units of Measure* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|

|Column|Description|
|------|-----------|
|**Location**|The location where the inventory item is stored.|
|**Available**|The quantity of the inventory item available in the location.|
|**Available for Shipment**|The quantity of the item available for shipping from this location.

 For details on the calculation of the quantity that is available for shipping, see [Availability Calculation Rules: General Information](Availability_Calculation_Rules_GeneralInfo.md).

|
|**Expired**|The quantity of the inventory item that has expired, based on the expiration date specified for the lot.

 This column appears only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**On Hand**|The quantity on hand for the inventory item.|
|**Base Unit**|The UOM used as a base unit for this inventory item.|
|**Lot/Serial Number**|The lot or serial number of the inventory item.

 This column is displayed only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Expiration Date**|The expiration date of the item \(if applicable\).

 This column is displayed only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|

## Scan Log { .section}

This tab displays the history of the most recent performed operations in the current working mode. The log is cleared when you close the form or switch to another working mode.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Time**|The date and time when the operation was performed.|
|**Mode**|The working mode that was active when the system was performing the operation.|
|**Prompt**|The message describing the operation to be performed \(as was shown in the notification area\).|
|**Scan**|The command that was entered in the **Scan** box, or the barcode that was scanned.|
|**Message**|The result of the operation \(as was shown in the notification area\).|
