# Reporting Settings {#_af0480fa-c978-4327-8a65-14cc7b791c4b .reference}

Form ID: \(TX205100\)

On this form, you can configure the elements of a tax report that are required to set up the accumulation of the appropriate tax and taxable amounts in the tax report. You perform this configuration as follows:

1.  On the **Report Lines** tab, configure the required report lines. The tax report is represented as a table in Acumatica ERP, so you should create the required number of rows, referred to as *report lines* in Acumatica ERP, in which the appropriate values \(tax or taxable amounts\) will be recorded.

    **Tip:** Report lines correspond to the fields that should be filled with the appropriate amounts in the tax report forms.

2.  On the **Reporting Groups** tab, create the required reporting groups. A reporting group is an entity that will act as a link between a particular tax and particular lines of the tax report. You will later add the appropriate report lines to the reporting group on the [Reporting Groups](TX_20_52_00.md) \(TX205200\) form, and then will assign each reporting group to the appropriate tax on the [Taxes](TX_20_50_00.md) \(TX205000\) form. Thus, tax and taxable amounts calculated in documents based on a particular tax will be recorded by the system on the fly to the appropriate lines of the tax report.

    You need to create at least one output reporting group for the taxes to be paid to the tax agency, and at least one input reporting group for the taxes to be claimed from the tax agency.


For details, see [Tax Report](../ImplementationGuide/Taxes_TaxReport_Mapref.md).

## Form Toolbar { .section}

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Reload Tax Zones**|Initiates the process of regenerating the lines itemized by tax zones in the tax report. You can use this functionality if you have created new tax zones after you have configured a tax report that contains lines detailed by tax zone. As a result, the report lines for newly created tax zones will be added to the tax report.**Attention:** You use this command if you have configured the report with lines itemized by tax zones \(that is, if the **Detail by Tax Zones** check box is selected for any line in the table\).

|
|**Add New Version**|Creates an empty version of the tax report for the selected tax agency. The new version will not have report lines specified. This version will include the set of reporting groups specified on the **Reporting Groups** tab for the current version.

 The system will display the number of the created report version \(which is the current version number incremented by 1\) in the **Report Version** box in the Summary area.

|
|**Copy Version**|Copies the selected report version and pastes it as a new version for the selected tax agency. The records on the **Report Lines** and **Reporting Groups** tabs are copied too.

 In the Summary area, the system will display the number of the created report version \(which is the current number incremented by 1\) in the **Report Version** box and the current business date in the **Valid From** box; you can override the inserted date.

|
|**Delete Version**|Deletes the selected report version.

 Only a newly added version can be deleted. This command is available if the selected report version does not have tax transactions posted for it.

|

## Selection Area {#1 .section}

In this area, you can select the tax agency for which you want to configure or modify the tax report. In Acumatica ERP, tax agencies or authorities are defined as vendors.

|Element|Description|
|-------|-----------|
|**Tax Agency**|The tax agency for which you want to configure or modify the tax report.

 The list of vendors available for selection may be limited based on the role or roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. In this case, the **Restrict Visibility To** box appears on the **Financial** tab of the [Vendors](../Shared/../UserGuide/AP_30_30_00.md) \(AP303000\) form. With the feature enabled, a vendor is available for selection if one of the following is true:

-   The **Restrict Visibility To** box is empty for the vendor—that is, the vendor’s visibility is not restricted.
-   A branch, company, or a company group is specified in the **Restrict Visibility To** box for the vendor, and your user account has the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the selected branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the selected company or a company within the company group.

|
|**Report Version**|The report version for the selected tax agency.

 For the initial report configuration for any agency, the system inserts *1*. The system increments this setting by *1* automatically each time you create a new report version by using the **Add New Version** or **Copy Version** command.

 When you select a version in this box, the system displays the **Valid From** setting associated with the selected version, as well as the records specified for the version on the **Report Lines** and **Reporting Groups** tabs.

 When you select a tax agency in the **Tax Agency ID** box, this box displays the latest version of the tax report, but you can select another version.

|
|**Valid From**|The date when the selected report version becomes valid. If a tax report has been prepared on the [Prepare Tax Report](TX_50_10_00.md) \(TX501000\) form for the selected report version, this box becomes unavailable.

 When a tax report is configured for the first time on the [Reporting Settings](TX_20_51_00.md) \(TX205100\) form, the system inserts *1/1/1900*for version 1 of the tax report, and this box becomes unavailable.

|
|**Show Tax Zones**|A check box that you select to view the tax zones included in the tax report. The tax zones are shown only if the **Detail by Tax Zones** check box is selected for a required report line.

 **Tip:** If you have created new tax zones after you configured the tax report, which contains the lines detailed by tax zones, you need to regenerate the lines in the tax report by using the **Reload Tax Zones** button. Otherwise, the newly created tax zones will not be added to the configured tax report.

If the **Show Tax Zones** check box is selected, you cannot move or drag report lines.

|

## Report Lines Tab {#2 .section}

This tab lists the report lines configured for the tax report and their settings.

**Tip:** One line should have the **Net Tax** check box selected, so that it will show the total tax amount that you have to report to the tax agency.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Report Line Order**|The number representing the order of the report line. These system-generated numbers are assigned as you add new lines. To change the order of lines in the report, you can edit the values in this column, or you can drag report lines. Alternatively, you can click the **Move Row Up** and **Move Row Down** buttons to change the order of report lines.|
|**Description**|A detailed description of the report line. This can be an alphanumeric string of up to 60 characters.|
|**Update With**|An indicator of whether the amount that will be used to update the line is a *Tax Amount* or *Taxable Amount*.|
|**Update Rule**|The rule of updating the report line. Two options are available:

 -   *+ Output – Input*: The difference between the tax amounts or taxable amounts \(depending on the **Update With** option selected\) of the tax for which the appropriate *Output* and *Input* groups are specified. This rule can also be defined only for groups of the *Output* and *Input* types. If it is defined for groups with the *Input* type, the line will contain an amount with the minus sign \(that is, a negative amount\).
-   *+ Input – Output*: The difference between the tax amounts or taxable amounts \(depending on the **Update With** option selected\) of the tax for which the appropriate *Input* and *Output* groups are specified. This rule can also be defined only for groups of the *Input* and *Output* types. If it is defined for groups with the *Output* type, the line will contain an amount with the minus sign \(that is, a negative amount\).

|
|**Tax Zone ID**|The tax zone that includes the list of taxes. Only the tax or taxable amounts calculated based on the taxes included in the selected tax zone will be accumulated in this line.

 You can select a tax zone for a report line if the **Detail by Tax Zones** check box is cleared for this line.

|
|**Detail by Tax Zones**|A check box that initiates \(if selected\) the process of generating the report lines itemized by tax zones. That is, the line in which this check box is selected will be split into multiple lines for each tax zone created in the system. Later, when you prepare the tax report on the [Prepare Tax Report](TX_50_10_00.md) \(TX501000\) form, the appropriate tax or taxable amount will be split by tax zones and shown in separate lines.

 If this check box is selected for a line, the **Tax Zone ID** cell for this line becomes unavailable.

 **Tip:** You can view the lines detailed by tax zone by selecting the **Show Tax Zones** check box in the Selection area of this form. If the **Show Tax Zones** check box is selected, you cannot move or drag report lines.

|
|**Net Tax**|A check box that indicates \(if selected\) that the line shows the net tax amount. Only one line for each report can be selected as containing the net amount. If no report line is specified as the net tax, no bill will be generated upon release of the tax report. Tax adjustment amounts entered for the open tax period adjust the net tax.|
|**Hide Report Line**|A check box that indicates \(if selected\) that the line will not be included in the tax report during its generation.|
|**Tax Box Number**|The number of the corresponding box on the tax report form provided by the tax authority.|
|**Calc. Rule**|The numbers of those report lines whose amounts will be used for calculating the amount in this line.

 This box is filled in by the system automatically if it is an *aggregate* line and the appropriate settings are specified. For details, see [Tax Report](../ImplementationGuide/Taxes_TaxReport_Mapref.md).

|

## Reporting Groups Tab {#3 .section}

On this tab, you can create reporting groups for accumulating input and output tax amounts for various taxes to be included in the tax report. When the reporting groups are created, you associate them with the specific taxes on the [Taxes](TX_20_50_00.md) \(TX205000\) form.

|Button|Description|
|------|-----------|
|**Group Details**|Opens the [Reporting Groups](TX_20_52_00.md) \(TX205200\) form for the selected group so that you can edit the group settings.|

|Column|Description|
|------|-----------|
|**Name**|The name of the reporting group or a description. An alphanumeric string of up to 60 characters may be used.|
|**Group Type**|The type of the reporting group, *Input* or *Output*.|
