# Release Time Cards

Form ID: \(EP505010\)

This form lists all time cards that are ready for release. You can release either selected time cards or all of them. After successful completion of the release, the system changes the status of the processed time cards to *Released*.

**Attention:** When a time card is released, the generated transactions can record project costs and related liabilities under different branches. This happens if *Use Project Branch* or *Use Project Branch in Lines Only* is selected in the **Branch in Project Documents** box on the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form. In this case, the project branch is used for project costs, and the employee branch is used for related liabilities. And when the **Block Doc. Processing on Branch Mismatch** check box is also selected, the time card can't be released if the project has no branch specified or if you don't have access to the project branch.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Release**|Releases the time cards you have selected in the table and changes their status to *Released*.|
|**Release All**|Releases all the time cards listed in the table and changes their status to *Released*.|

## Table

This area of the form contains the list of time cards that are ready to be released.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include the record in the release process.|
|**Ref. Nbr.**|The time card reference number, which the system assigns based on the numbering sequence specified on the [Time and Expenses Preferences](EP_10_10_00.md) \(EP101000\) form.|
|**Employee**|The identifier of the employee.|
|**Employee Name**|The name of the employee.|
|**Period**|The time card period.|
|**Frequency**|The time card frequency.|
|**Time Spent**|The number of regular work hours spent by the employee according to the time card.|
|**Overtime**|The total overtime spent by the employee according to the time card.|
|**Total Time Spent**|The total time spent by the employee according to the time card.|
|**Time Billable**|The billable regular work hours spent by the employee according to the time card.|
|**Billable Overtime**|The billable overtime spent by the employee according to the time card.|
|**Total Time Billable**|The total of billable hours spent by the employee according to the time card.|
|**Approved By**|The ID of the employee who approved the time card.|
|**Approver Name**|The name of the employee who approved the time card.|
|**Approve Date**|The date when the time card was approved.|
