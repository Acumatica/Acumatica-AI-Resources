# Subcontract Summary {#_a9348a1c-337d-46e5-9d9f-9b9b1c1f84d2 .reference}

Form ID: \(SC610500\)

This report shows summary information about the subcontracts for a particular date range broken down by project or by the vendor to which these subcontracts relate. The information presented for each subcontract includes the subcontract's reference number, date, status, currency, ordered quantity, line total, open values, and unbilled values. The report also includes the total values for all subcontracts included in the report for the ordered quantity, line total, open values, and unbilled values.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Group Results**: The way the subcontracts are grouped. Select one of the following options:
    -   *By Project*: To view summary information for subcontracts at the project level of detail.
    -   *By Vendor* \(default\): To view summary information for subcontracts at the vendor level of detail.
-   **Start Date**: The start date of the date range for which subcontracts will be displayed. By default, the first date of the current financial period is specified.
-   **End Date**: The end date through which subcontracts will be displayed. By default, the current business date is specified.
-   **Project**: The project for which you want to view subcontracts. You can select a project to view only subcontracts created for this project, or leave the box blank to view subcontracts for all projects.
-   **Vendor**: The vendor for which you want to view subcontract information. You can select a vendor to view only subcontracts created for this vendor, or leave the box blank to view a broader range of data.

    The list of vendors available for selection may be limited based on the role or roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. In this case, the **Restrict Visibility To** box appears on the **Financial** tab of the [Vendors](../Shared/../UserGuide/AP_30_30_00.md) \(AP303000\) form. With the feature enabled, a vendor is available for selection if one of the following is true:

    -   The **Restrict Visibility To** box is empty for the vendor—that is, the vendor’s visibility is not restricted.
    -   A branch, company, or a company group is specified in the **Restrict Visibility To** box for the vendor, and your user account has the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the selected branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the selected company or a company within the company group.
-   **Inventory ID**: The non-stock item for which you want to view subcontract information. You can select a non-stock item to view only subcontracts that include this item, or leave the box blank to view the report for all items.
-   **Show Open Subcontracts Only**: A check box that you select to include only the open subcontracts and their details in the report. If the check box is cleared, the report includes all subcontracts that are neither closed nor canceled.
