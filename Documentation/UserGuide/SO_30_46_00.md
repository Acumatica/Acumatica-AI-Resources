# Orchestration Plans {#_6f87f3a0-215e-41fd-a21b-4a0187788d51 .reference}

Form ID: \(SO304600\)

On this form, you can create orchestration plans the system uses to orchestrate sales orders. An orchestration plan is a template for fulfillment of an order.

**Attention:** This form is available only if the *Order Orchestration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

In this area, you can select an orchestration plan by its ID to view its information or create a new plan.

|Element|Description|
|-------|-----------|
|**Plan ID**|The unique plan identifier.|
|**Active**|A check box that indicates \(if selected\) that the orchestration plan is active. The system can use this plan for order orchestration.|
|**Description**|The description of the orchestration plan.|
|**Fulfillment Strategy**|The strategy of the orchestration plan. During orchestration, the system matches the type of the sales order with an orchestration plan by its strategy and additional settings. These settings become available if you select one of the following options:

 -   *Destination Priority*: You can select a shipping zone of the orchestration plan.
-   *Warehouse Priority*: You can select a source warehouse of the orchestration plan.

|
|**Shipping Zone**|The shipping zone associated with the orchestration plan. During orchestration, the system uses this value to match the plan to sales orders with the same shipping zone.

 This box is available only if the *Destination Priority* option is selected in the **Fulfillment Strategy** box.

|
|**Source Warehouse**|The source warehouse associated with the orchestration plan. During orchestration, the system uses this value to match the plan to sales orders with the same warehouse in the sales order lines.

 This box is available only if the *Warehouse Priority* option is selected in the **Fulfillment Strategy** box.

|
|**Include Source Warehouse**|A check box that indicates that the source warehouse will be added to the list of warehouses in the table below with the highest priority, which is *0*. By default, this check box is cleared.

 This box is available only if the *Warehouse Priority* option is selected in the **Fulfillment Strategy** box.

|

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Warehouse**|The warehouse that may be selected for the sales order within the current orchestration plan.|
|**Description**|The description of the warehouse that may be used in orchestration.|
|**Priority**|The priority of the warehouse in order orchestration. During orchestration, the system uses warehouse priority rankings to select the optimal fulfillment warehouse.

 You can manually change the priority of any warehouse except for the source warehouse. The system automatically adds it to the table with a priority of *0*—the highest priority level—if you select the **Include Source Warehouse** check box in the Summary area.

|
|**Maintain Safety Stock**|You select this check box to prevent the quantity of a stock item in the warehouse from dropping below the safety stock during orchestration. You specify the safety stock for each item-warehouse pair on the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form.|
