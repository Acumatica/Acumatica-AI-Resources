# To Make a Wiki Article Visible in Acumatica ERP {#_a770c51f-a810-4eff-ac79-a52f4f7468c7 .task}

You can make a wiki article that was created on Self-Service Portal visible in Acumatica ERP as well by using the [Wiki](SM_20_20_05.md) \(SM202005\) form, as described in this topic. \(For the procedure that describes how to add a new wiki, see [To Add a Wiki](DM__how_Wiki_Setting_Up_a_New_Wiki.md).\)

At a later time, you can remove the visibility of the wiki article that you made visible in Acumatica ERP.

## To Make a Wiki Article Visible in Acumatica ERP { .section}

1.  Open the [Wiki](SM_20_20_05.md) \(SM202005\) form.
2.  In the Summary area, do the following:
    1.  In the**ID** field, select the ID of the wiki that contains the article to be displayed in Acumatica ERP.
    2.  In the **Title** box, type the name of the wiki that will be displayed in Acumatica ERP.
    3.  In the **Site Map Location** box, select the node of the site map where the wiki will be located.
    4.  In the **Site Map Title** box, type the wiki title on the site map.
    5.  On the form toolbar, click **Save** to save the settings you have specified for the wiki so far.
3.  Configure access rights for the wiki, as described in [Wiki Access Management](SM__con_Wiki_Access_Setup.md).
4.  Sign out from your Acumatica ERP instance, and then sign in again to view the wiki in the main menu.
5.  If you have not done it before, create an article that you want to share in the wiki. The article can be created either in Self-Service Portal or in Acumatica ERP. For a procedure that describes how to add a new wiki article, see [To Add an Article](DM__how_Wiki_Creating_a_New_Article.md).

Now you can view the same wiki article both in Acumatica ERP and on Self-Service Portal.

## To Hide a Wiki From the Acumatica ERP Main Menu { .section}

1.  Open the [Wiki](SM_20_20_05.md) \(SM202005\) form.
2.  In the **ID** box, select the wiki that you want to hide from the main menu.
3.  In the **Site Map Location** box, delete the location.
4.  On the form toolbar, click **Save** to remove the wiki from the Acumatica ERP main menu.
5.  Reload the webpage in the browser to apply changes in the site map of Acumatica ERP.
