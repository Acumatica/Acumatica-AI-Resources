# Reporting Groups

Form ID: \(TX205200\)

On this form, you can view and edit reporting groups created for a particular tax agency. You can add or delete report lines that should be updated by the taxes associated with selected reporting group. You associate the reporting groups with the particular taxes by using the [Taxes](TX_20_50_00.md) \(TX205000\) form.

Report lines were initially defined on the [Reporting Settings](TX_20_51_00.md) \(TX205100\) form.

## Form Toolbar

The form toolbar has only standard buttons.

## Table

This table contains the list of those report lines configured for the tax agency that are updated by the reporting group specified in the Summary area.

The table toolbar has only standard buttons.

<table><thead><tr><th>

Column

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Report Line**

</td><td>

The report line that should be updated by the tax associated with the selected reporting group. Select the value from the list of the report lines configured for the tax agency.

</td></tr><tr><td>

**Update With**

</td><td>

The type of the amount that should be accumulated in the selected report line. This amount is initially set on the [Reporting Settings](TX_20_51_00.md) \(TX205100\) form. It is one of the following options: *Tax Amount* or *Taxable Amount*.

</td></tr><tr><td>

**Update Rule**

</td><td>

The rule of updating the report line. Two options are available: -   *+ Output – Input*: The difference between the tax amounts or taxable amounts \(depending on the **Update With** option selected\) of the tax for which the appropriate *Output* and *Input* groups are specified. This rule can be also defined only for the *Output* type groups and for the *Input* type groups. If it is defined for the *Input* type groups, the line will contain the amount with the minus sign.
-   *+ Input – Output*: The difference between the tax amounts or taxable amounts \(depending on the **Update With** option selected\) of the tax for which the appropriate *Input* and *Output* groups are specified. It can be also defined only for the *Input* type groups and for the *Output* type groups. If it is defined for the *Output* type groups, the line will contain the amount with the minus sign.

</td></tr></tbody>
</table>
