# To Add an Article to a Dashboard {#_bacfcc95-ecf2-4478-88d4-dc35a63a01dc .task}

Dashboards can be configured for each module. If no components were added to the dashboard for a particular module, the default help article will be displayed.

To add an article to a dashboard, do the following:

1.  Open the article.
2.  On the form title bar, click **Dashboard** and select **Add Wiki**.
3.  In the **Widget Properties** dialog box, select the target dashboard.
4.  Click **OK**.
