# Picking Worksheets {#_7692237d-e46d-48a3-9e19-60b551f261f8 .reference}

Form ID: \(SO302500\)

**Note:** This form is available only if the *Advanced Picking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this form to view the details of any existing picking worksheet.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Cancel Worksheet**|Cancels the currently selected worksheet.

 The command is available if the selected worksheet is one of the following:

 -   A wave picking worksheet with the *Picking* status
-   A batch picking worksheet with the *Picking* status if no shipments of this batch worksheet have been completely picked yet \(that is, if the **Picked** check box is cleared for all the shipments included in this batch worksheet on the **Shipments** tab of the form\)

 When a picking worksheet is canceled, the system assigns the *Canceled* status to it, cancels all the created pick lists, and removes all the related shipments from the picking worksheet. For all rows on the **Details** tab, the **Picked Qty.** becomes *0*.

|
|**Hold**|Changes the status of the picking worksheet to *On Hold*. You click this button when you want to make changes to the worksheet or to pause its processing.|
|**Pick All Shipments**|Marks all shipments as picked.|
|**Print Packing Slips**|Prints packing slips for all the shipments included in the picking worksheet.

 For worksheets of the *Batch* type, the system applies the following rules based on the shipment settings on the **Shipments** tab:

 -   The command is available only if at least one shipment has the **Picked** check box selected.
-   The system doesn't print packing slips for shipments with the **Non-Shippable** check box selected.

|
|**Print Pick Lists**|Prints pick lists for all the pickers of the picking worksheet.|
|**Remove Hold**|Changes the status of the picking worksheet from *On Hold* to *Open*. You click this button when the worksheet is ready for further processing.|
|**Unlink All Shipments**|Removes the link to all shipments in a picking worksheet. That is, the shipments are no longer associated with the worksheet and can be added to another worksheet.

 The unlinked shipments can still be reviewed on the **Shipments** tab.

 This command is available only if the worksheet has the *Wave* type and the *Picked* status.

|

## Summary Area {#1 .section}

The Summary area contains general information about the selected picking worksheet.

|Element|Description|
|-------|-----------|
|**Worksheet Nbr.**|The number that identifies the picking worksheet in the system, as generated by the system based on the numbering sequence assigned to documents of this type on the **General** tab of the [Sales Orders Preferences](SO_10_10_00.md) \(SO101000\) form.|
|**Type**|The type of picking worksheet: *Wave* or *Batch*.|
|**Status**|The status of the picking worksheet, which is set by the system. The status can be one of the following options:

 -   *On Hold*: The worksheet is on hold and is not available for picking.
-   *Open*: The picking worksheet is ready for processing.
-   *Picking*: The picking of items for the worksheet is currently in progress.
-   *Picked*: All items from all the pick lists of the worksheet have been picked.
-   *Completed*: All the shipments in the worksheet have been confirmed or unlinked.

|
|**Date**|The creation date of the picking worksheet.|
|**Warehouse ID**|The warehouse from which the items are being shipped.|
|**Picking Started On**|The date and time when the picking started \(that is, when the first item in the picking worksheet was picked\).|
|**Picking Finished On**|The date and time when the last pick list in the picking worksheet was confirmed.|
|**Shipped Quantity**|The total quantity of the items of all shipments included in the worksheet.|
|**Shipped Weight**|The total weight of the items of all shipments included in the worksheet.|
|**Shipped Volume**|The total volume of the items of all shipments included in the worksheet.|

## Details Tab { .section}

This tab displays a list of the items included in the wave or batch, with summary information about each item.

|Button|Description|
|------|-----------|
|**Line Details**|Opens the **Line Details** dialog box, in which you can review information about the quantities of the selected item that are allocated for picking from warehouse locations. You select the row of the item in the table and then click this button.|

|Element|Description|
|-------|-----------|
|**Inventory ID**|The identifier of the item to be picked.|
|**Location**|The warehouse location in which the item is allocated for picking.|
|**Lot/Serial Nbr.**|The serial number for the unit of a stock item or the lot number for the units of the stock item.|
|**Picked Quantity**|The quantity of the item that has been picked.|
|**Quantity**|The quantity of the item allocated in the location.|
|**UOM**|The unit of measure for the item.|
|**Expiration Date**|The expiration date for the item with the specified lot number.|

|Element|Description|
|-------|-----------|
|**Warehouse**|The warehouse from which the item in this row is being picked for shipping.|
|**Location**|The warehouse location in which the item is allocated for picking.|
|**Inventory ID**|The identifier of the item to be picked.|
|**Lot/Serial Nbr.**|The serial number for the unit of a stock item or the lot number for the units of the stock item.|
|**Expiration Date**|The expiration date for the item with the specified lot number.|
|**UOM**|The unit of measure for the stock item.|
|**Shipped Qty.**|The total quantity of this item to be shipped.|
|**Ordered Qty.**|The total quantity of this inventory item in the related sales order.|
|**Open Qty.**|The quantity of this item that has not been shipped.|
|**Picked Qty.**|The quantity of this item that has been picked.|
|**Description**|The short description of the related shipment line.|

## Shipments Tab { .section}

This tab shows a list of the shipments included in the wave or batch, with summary information about each shipment.

|Button|Description|
|------|-----------|
|**View Pickers**|Opens the **Pickers of a Shipment** dialog box, in which you can review information about the pickers who are picking the items for the selected shipment. You select the row of the shipment in the table and then click this button.|

|Element|Description|
|-------|-----------|
|**Confirmed**|A check box that indicates \(if selected\) that the picker has confirmed the pick list for the shipment.|
|**Picker Nbr.**|The number of the picker.|
|**User**|The username of the user who is assigned to the worksheet as a picker with the picker number specified in the **Picker Nbr.** box.|
|**Cart ID**|The identifier of the cart in which the items have been picked.|

|Element|Description|
|-------|-----------|
|**Picked**|A check box that indicates \(if selected\) that the picker has confirmed the pick list for the shipment.|
|**Non-Shippable**|A check box that indicates \(if selected\) that the shipment cannot be confirmed with the currently picked quantities because its shipment rules don't allow a shortage for one or more lines.

 The system selects the check box for a picked shipment if both of the following are true:

 -   On the [Picking Worksheets](SO_30_25_00.md) \(SO302500\) form, **Picked Qty.** in the shipment line is less than **Shipped Quantity**.
-   On the [Shipments](SO_30_20_00.md) \(SO302000\) form, the shipment line with the short pick quantity has the *Ship Complete* shipping rule.

|
|**Shipment Nbr.**|The reference number of a shipment included in the picking worksheet.|
|**Type**|The type of the shipment, which can be one of the following:

 -   *Shipment*
-   *Transfer*
-   *Material Shipment*
-   *Material Issue*

 This column appears only if the *Material Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Picked Qty.**|The quantity of items that has been picked for the shipment.|
|**Shipped Quantity**|The total quantity of the items included in the shipment.|
|**Shipped Weight**|The total weight of the items included in the shipment.|
|**Shipped Volume**|The total volume of the items included in the shipment.|
|**Status**|The status of the shipment document.|
|**Unlinked**|A read-only check box that indicates \(if selected\) that the shipment is no longer linked to the picking worksheet. You can add this shipment to another picking worksheet.

 If this check box is cleared, you cannot add this shipment to another picking worksheet when you create a worksheet on the [Create Pick Lists](SO_50_30_50.md) \(SO503050\) form.

|

|**Shipment Nbr.**|The reference number of a shipment which items are displayed in the lower table.|
|The lower table of the dialog box, which displays the items of the selected shipment, has the following columns.|
|**Location**|The warehouse location in which the item of the shipment is allocated for picking.|
|**Inventory ID**|The identifier of the item to be picked.|
|**Lot/Serial Nbr.**|The serial number for the unit of a stock item or the lot number for the units of the stock item.|
|**Quantity**|The quantity of the item allocated in the location.|
|**UOM**|The unit of measure for the stock item.|
|**Expiration Date**|The expiration date for the item with the specified lot number.|
|**Picked Quantity**|The quantity of the item that has been picked.|
|**Tote ID**|The tote in which the items for the shipment are being picked.|

|Element|Description|
|-------|-----------|
|**Location**|The warehouse location in which the item is allocated for picking.|
|**Inventory ID**|The identifier of the item to be picked.|
|**Lot/Serial Nbr.**|The serial number for the unit of a stock item or the lot number for the units of the stock item.|
|**Quantity**|The quantity of the item allocated in the location.|
|**UOM**|The unit of measure for the stock item.|
|**Expiration Date**|The expiration date for the item with the specified lot number.|
|**Picked Quantity**|The quantity of the item that has been picked.|

|Element|Description|
|-------|-----------|
|**Confirmed**|A check box that indicates \(if selected\) that the picker has confirmed the pick list for the shipment.|
|**Picker Nbr.**|The number of the picker assigned to the picking worksheet.|
|**User**|The username of the user who performs picking.|
|**Path Length**|The total length of the path that a picker will pass while picking the pick list.|
|**Cart ID**|The identifier of the cart in which the picker picks items.|
