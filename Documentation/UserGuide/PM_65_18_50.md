# Project WIP Adjustment {#_65f1be2a-dbba-4230-aec2-57873fd58734 .reference}

Report ID: \(PM651850\)

**Attention:** This report is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

By using this report, you can prepare a printable document for a project WIP adjustment on the [Project WIP Adjustment](PM_30_56_00.md) \(PM305600\) form with document details and total amounts. On the report form, you select the reference number of a particular project WIP adjustment you want to view.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Document**: The reference number of the project WIP adjustment for which you want to prepare the printable document; this is a required element.
