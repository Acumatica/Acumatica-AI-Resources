# Equipment

Form ID: \(EP208000\)

You use this form to define a piece of equipment that can be used for projects, fixed assets, and service management, and the rates for using this equipment.

## Summary Area

You use the elements in this area to add a new piece of equipment, or to view the details of existing equipment.

|Element|Description|
|-------|-----------|
|**Equipment ID**|A unique identifier for the equipment.|
|**Description**|The description provided for the equipment.|
|**Active**|A check box that indicates \(if selected\) that the equipment is active and is available for selection on data entry forms.|

## Project Rates Tab

On this tab, you can specify the rates to be used for this equipment on different projects.

This tab is available if the *Projects* feature group is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Project**|The project for which this equipment is used.|
|**Description**|The description of the project.|
|**Run Rate**|The rate for running the equipment.|
|**Setup Rate**|The rate for keeping the equipment setup.|
|**Suspend Rate**|The rate for reserving \(suspending\) the equipment.|

## Attributes Tab

By using this tab, you can specify which attributes can be used to categorize this piece of equipment. You can create new attributes for use with equipment by using the [Attributes](CS_20_50_00.md) \(CS205000\) form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Attribute**|The attribute name.|
|**Required**|A check box that indicates \(if selected\) that this attribute is required.|
|**Value**|The value of the attribute specific for this equipment.|
