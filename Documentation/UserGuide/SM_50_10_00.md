# Refresh Application Access Tokens {#_08b03dd6-880a-4415-ad1e-8aafcc947601 .reference}

Form ID: \(SM501000\)

You can use this form to refresh access tokens for integrated external applications so that you can continue to access integrated resources. You can refresh these tokens manually or schedule this process. When you integrate Acumatica ERP with an external application by using the OAuth 2.0 protocol, an access token is provided, which has a short lifetime for security reasons. Therefore, you may need to refresh the access token periodically. We recommend that you refresh the access token at least once a day.

For more information, see [Integration with External Applications](SM__con_Integration_External_Applications.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Refresh Tokens**|Refreshes the access tokens that you have selected in the table.|
|**Refresh All Tokens**|Refreshes all access tokens listed in the table.|

## Table { .section}

In this table, the list of tokens for integrated applications is displayed. The list includes only tokens that are about to expire or are expired. You can refresh any number of tokens from this list.

|Column|Description|
|------|-----------|
|**Selected**|A check box that you select to include the token for refreshment if the **Refresh Token** action is invoked.|
|**Application ID**|The identifier of the integrated application.|
|**Application Type**|The type of the integrated application.|
|**Application Name**|The name of the integrated application.|
|**Expires On**|The date and time of expiration of the access token for the application.|
|**Bearer**|The email address of the user who is signed in to the external application.|
|**Entity**|The type of entity for which the token was requested.|
|**Requested For**|The entity for which the token was requested.|
|**Token Description**|An arbitrary description of the token.|
