# Change Order Classes

Form ID: \(PM203000\)

You use this form to add, view, edit, and delete the change order classes that are used in change orders. For more information, see [Tracking Changes to the Project Budget](Projects_CO_Mapref.md).

This form is available if the *Change Orders* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar has only standard buttons.

## Summary Area

In this area, you can specify or view the basic settings of a change order class.
