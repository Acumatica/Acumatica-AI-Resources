# Payroll Reports {#_edaf51ef-38e3-484f-b97e-1c5bd8310204 .concept}

With the wide variety of Acumatica ERP reports related to payroll, you can analyze payroll data by various criteria and generate various government forms.

If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All purchasing-related reports can be generated in different formats, including PDF and HTML, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
