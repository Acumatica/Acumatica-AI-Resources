# Appointment {#_24c69c0a-cc06-41c4-9f4a-7672fe74c3f7 .reference}

Form ID: \(FS642000\)

By using this report, you can display the selected appointment as a ready-to-print document. The document provides the company information \(in the top left\), contact information, customer information, included services \(and their quantities and prices\), inventory item information, information about the staff members performing the services, and the total price of the appointment.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report-Specific Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the data to be displayed on the report:

-   **Service Order Type**: The service order type related to the appointment you want to display. You must specify the type.
-   **Appointment Number**: The number of the appointment you want to display. You must specify the number of the appointment.
