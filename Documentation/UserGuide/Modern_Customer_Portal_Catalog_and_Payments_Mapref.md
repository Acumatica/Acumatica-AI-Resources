# Browsing the Catalog and Placing Orders {#_fe69c33c-f8fc-4821-9c67-294bf4145d9b .concept}

In the Modern Customer Portal, authorized portal users can browse the catalog, view available items and their details, add items to the cart, and place orders.

In this chapter, you’ll learn how to:

-   Browse the catalog and view item details
-   Place an order
-   Review order details in the Modern Customer Portal

**Important:**

This functionality is available if the following conditions are met in Acumatica ERP:

-   The *Modern Customer Portal* and *Inventory and Order Management* features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form
-   The **B2B Ordering** check box is selected and the functionality has been configured on the [Portals](SP_70_10_00.md) \(SP701000\) form.

If expected functionality isn’t available, contact your company’s portal manager. The portal manager can work with the portal owner to review configuration settings, if needed.
