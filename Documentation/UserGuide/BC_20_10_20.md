# Amazon Stores {#_ee59fc83-0ed9-48cc-97f3-4916332de559 .reference}

Form ID: \(BC201020\)

You use this form to set up a connection to your Amazon seller account \(which is referred to as a *store* in Acumatica ERP\). After the connection has been established, on this form, you specify the marketplace settings, activate the entities that need to be synchronized between Acumatica ERP and the Amazon store, and define the synchronization settings for the active entities.

**Important:**

-   This form is available only if the *Retail Commerce* and *Amazon Connector* features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.
-   The number of Amazon seller accounts to which you can establish a connection on this form is limited by your license.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Test Connection**|By using the information specified on the **General** tab, tests the ability to connect to the Amazon seller account via the API.|
|**Authorize**|Invokes the Sign-In screen for the Amazon Seller Central, in which you provide the credentials for the Amazon seller account and establish the connection to it.|

## Summary Area {#1 .section}

In this area, you specify the basic settings of a particular Amazon store, or select a store to view and edit its settings.

|Element|Description|
|-------|-----------|
|**Connector**|A read-only box with the name of the ecommerce connector \(*Amazon*\) of a store configured on this form.|
|**Store Name**|The name of the Amazon store to which the connection is being established. The store name is specified when the connection is first configured; you cannot change it later.|
|**Active**|A check box that indicates \(if selected\) that the store configuration is active and the entities activated and configured for this store are synchronized between Acumatica ERP and the Amazon store.

 For inactive stores, you can modify the store settings on the current form, but entities are not synchronized; you can see the history of the synchronization of entities on the [Sync History](BC_30_10_00.md) \(BC301000\) form.

|
|**Default**|A check box that you select to indicate that this store is the default store in Acumatica ERP.

 If multiple stores have been configured on this form, on the [BigCommerce Stores](BC_20_10_00.md) \(BC201000\) form, or on the [Shopify Stores](BC_20_10_10.md) \(BC201010\) form, if applicable, when you open other commerce-related forms, the store you have defined as the default is automatically inserted in the **Store** box.

 The system requires a store to be defined as the default store. When you are defining the first store in the system—on this form, on the [BigCommerce Stores](BC_20_10_00.md) form, or on the [Shopify Stores](BC_20_10_10.md) form—this check box is selected automatically. When you define another store, this check box is cleared by default; if you select this check box for the store being defined, the system clears this check box for the store that was previously defined as the default store.

|

## General Tab { .section}

On this tab, you specify the information that is required to establish the connection to an Amazon seller account \(that is, create a new Amazon store in Acumatica ERP\), or view general settings of an existing Amazon store.

|Element|Description|
|-------|-----------|
|**Region**|The region to which the Amazon seller account belongs.|
|**Marketplace**|The marketplace to which the Amazon seller account belongs.|

|Element|Description|
|-------|-----------|
|**Locale**|The locale of Acumatica ERP to be synchronized with the Amazon seller account.

 If multiple locales have been configured in Acumatica ERP and data is maintained in multiple languages, in this box, you select the locale that will be synchronized with the Amazon seller account.

|
|**Administrator**|The administrator of the Amazon store, which is the user who receives notifications about aborted synchronization that are triggered by predefined business events. For more information about predefined business events for aborted synchronization records, see [Automated Synchronization: Business Events for Aborted Records](Commerce_BC_Automated_Sync_Business_Events_for_Aborted_Sync_Records.md).|

|Element|Description|
|-------|-----------|
|**Max. Number of Stores**|The maximum number of Amazon stores that can be created in the Acumatica ERP instance.

 The number of Amazon seller accounts to which you can establish a connection on this form is limited by your license.

 If the number of stores exceeds the limit, the system prepares and processes data for only the stores within that limit. Stores beyond the limit are not supported. To determine eligibility, the system sorts the stores in alphabetical order and includes the first ones from the list.

|

## Entities Tab { .section}

The table rows on this tab are automatically populated with the entities that can be synchronized between Acumatica ERP and the Amazon seller account. You can activate the entities that you need to synchronize between the systems; you can also view and specify synchronization settings for these entities.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that the entity is synchronized between Acumatica ERP and the Amazon seller account.**Important:** If an entity requires other entities to be synchronized along with it, when you select this check box for the entity, the system also selects the **Active** check box for these required entities.

|
|**Entity**|The entity that can be synchronized between Acumatica ERP and the Amazon seller account, which is one of the following:

 -   *Product \(Linking Only\)*
-   *Product Availability*
-   *Sales Order*
-   *Marketplace-Fulfilled Order*
-   *Payment*
-   *Payment \(Obsolete\)*
-   *Non-Order Fees*
-   *Shipment*
-   *Seller-Fulfilled Refund*
-   *Marketplace-Fulfilled Refund*
-   *Marketplace Transfer Order*
-   *Marketplace Transfer Receipt*
-   *Settlement Report*

 You can click the link with each entity name to open the [Entities](BC_20_20_00.md) \(BC202000\) form in a pop-up window and specify the mapping and filtering settings for the entity.

|
|**Sync Direction**|The direction in which the entity should be synchronized. The direction can be either of the following:

 -   *Export*: Data is exported from Acumatica ERP to the Amazon seller account.
-   *Import*: Data is imported to Acumatica ERP from the Amazon seller account.

 The direction of the synchronization is predefined by the system as follows:

 -   *Product \(Linking Only\)*, predefined as *Import*
-   *Product Availability*, predefined as *Export*
-   *Sales Order*, predefined as *Import*
-   *Marketplace-Fulfilled Order*, predefined as *Import*
-   *Payment*, predefined as *Import*
-   *Payment \(Obsolete\)*, predefined as *Import*
-   *Non-Order Fees*, predefined as *Import*
-   *Shipment*, predefined as *Export*
-   *Seller-Fulfilled Refund*, predefined as *Import*
-   *Marketplace-Fulfilled Refund*, predefined as *Import*
-   *Marketplace Transfer Order*, predefined as *Import*
-   *Marketplace Transfer Receipt*, predefined as *Import*
-   *Settlement Report*, predefined as *Import*

|
|**Primary System**|The system that is used as the source of data during the synchronization of entities. If bidirectional synchronization is selected for the entity, the data of the primary system takes precedence if any conflicts arise during the synchronization.

 The primary system can be either of the following:

 -   *ERP* \(that is, Acumatica ERP\)
-   *External System* \(that is, the Amazon seller account\)

 The primary system is determined based on the **Sync Direction** setting as follows:

 -   For *Export*, *ERP* is set to be the primary system and cannot be changed.
-   For *Import*, *External System* is set to be the primary system and cannot be changed.

|
|**Max. Failed Attempts**|The maximum number of errors allowed during the import or export of data before the sync record is excluded from \(that is, excluded from further synchronization\).

 By default, the column contains *5*: That is, the system allows 5 failed attempts before excluding the synchronization record from further processing.

|

## Inventory Tab { .section}

On this tab, you can define which item quantities should be exported to the Amazon seller account.

|Element|Description|
|-------|-----------|
|**Availability Mode**|The type of item quantity that is exported to the Amazon seller account during the synchronization of the *Product Availability* entity. You can select one of the following options:

 -   *Available*: The item's available quantity in Amazon is based on the entire available quantity of the item in Acumatica ERP.
-   *Available for Shipping*: The item's available quantity in Amazon is based on the quantity available for shipping in Acumatica ERP.
-   *On Hand*: The item's available quantity in Amazon is based on the on-hand quantity of the item in Acumatica ERP.

 For information about availability calculation in Acumatica ERP, see [Availability Calculation Rules: General Information](Availability_Calculation_Rules_GeneralInfo.md).

|
|**Warehouse Mode**|An option that determines whether all warehouses or specific warehouses and locations are used for determining the available quantity of the item in the Amazon seller account.

 You can select one of the following options:

 -   *All Warehouses*: The available quantity of the item is calculated based on the on-hand quantity of the item in all warehouses.
-   *Specific Warehouses*: The available quantity of the item is calculated based on the on-hand quantity in the selected warehouses and warehouse locations. If this option is selected, a list of warehouses and warehouse locations to be used should be specified.

|

|Column|Description|
|------|-----------|
|**Warehouse**|The identifier of the warehouse in Acumatica ERP whose item quantity should be used for calculating the item's available quantity in the Amazon seller account.

 You can select a warehouse from the list, which contains all active warehouses that have been created on the [Warehouses](IN_20_40_00.md) \(IN204000\) form.

|
|**Location ID**|The identifier of the warehouse location in Acumatica ERP that contains inventory items whose availability data should be exported to the Amazon seller account.

 If you specify a location, only this specific location of the selected warehouse is used. If no location is selected, the system exports the availability data for items stored in all locations of the selected warehouse.

 You can select a warehouse location from the list of locations that have been created on the [Warehouses](IN_20_40_00.md) \(IN204000\) form for the warehouse selected in the **Warehouse** column. The list displays only the locations that are active and sales from which are allowed—that is, the locations for which the **Active** and **Sales Allowed** check boxes are selected on the **Locations** tab of the [Warehouses](IN_20_40_00.md) \(IN204000\) form.

|

|Element|Description|
|-------|-----------|
|**Order Type for Import**|The order type in Acumatica ERP that is assigned to inbound shipments imported from Amazon as marketplace transfer orders.

 The list of available types contains only the order types that are based on the *TR - Transfer* template on the [Order Types](SO_20_10_00.md) \(SO201000\) form.

|
|**Earliest Shipment Date**|The earliest creation date of inbound shipments included in synchronization. Inbound shipments created in Amazon earlier than this date are not imported to Acumatica ERP.|
|**Source Warehouse**|The warehouse that is inserted as the source warehouse of the imported marketplace transfer orders from Amazon.

 This warehouse must differ from the warehouse specified in the **Marketplace Warehouse** box of the **Orders** tab for the store.

|

|Element|Description|
|-------|-----------|
|**Ship-Via Codes to Carriers**|The substitution list to be used for mapping carrier names defined in the Amazon seller account with ship-via codes in Acumatica ERP.|

## Orders Tab { .section}

On this tab, you define the default settings for the import of seller-fulfilled and marketplace-fulfilled orders placed on Amazon. You also specify if taxes should be imported to Acumatica ERP from the Amazon seller account.

|Element|Description|
|-------|-----------|
|**Branch**|The branch that is inserted in the sales orders and payments imported to Acumatica ERP from the Amazon seller account.|
|**Generic Customer**|The generic customer that is inserted in all orders imported from Amazon.|

|Element|Description|
|-------|-----------|
|**Seller-Fulfilled Order Type**|The order type in Acumatica ERP that is assigned to seller-fulfilled orders imported from Amazon.

 The list shows only the order types that are based on the *SO - Sales Order* template and have the **Protect Personal Data** check box selected on the [Order Types](SO_20_10_00.md) \(SO201000\) form.

|
|**Marketplace-Fulfilled Order Type**|The order type in Acumatica ERP that is assigned to marketplace-fulfilled orders imported from Amazon.

 The list shows only the order types that are based on the *IN - Invoice* template on the [Order Types](SO_20_10_00.md) \(SO201000\) form.

|
|**Order Time Zone**|The time zone the system will use for each order imported from Amazon when it is created in Acumatica ERP. The order time zone is needed to determine the correct date and time of the order if Acumatica ERP and the Amazon seller account belong to different time zones.

 By default, this box displays the time zone of the server on which the Acumatica ERP instance is deployed.

|
|**Show Discounts As**|The level on which discounts appear in each order imported from Amazon.

 This box displays *Document Discounts*, which indicates that discounts are aggregated for the order and displayed on the **Discounts** tab of the [Sales Orders](SO_30_10_00.md) \(SO301000\) form.

 This box cannot be edited.

 **Important:** For the correct import of discounts, the *Customer Discounts* feature must be enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Earliest Order Date**|The earliest order creation date included in synchronization. Orders created in Amazon earlier than this date are not imported to Acumatica ERP.|
|**Gift Wrapping Item**|The non-stock item in Acumatica ERP that is used to represent gift wrapping in orders imported from Amazon.

 On the [Non-Stock Items](IN_20_20_00.md) \(IN202000\) form, this non-stock item has the *Non-Stock Item* or *Service* type \(the **Type** box in the **Item Defaults** section of the **General** tab\) and the *Active*, *No Purchases*, or *No Request* status \(**Item Status** box in the Summary area\).

|
|**Shipping Price Item**|The non-stock item in Acumatica ERP that is used to represent the shipping price in orders imported from Amazon.|

|Element|Description|

 This warehouse must differ from the warehouse specified in the **Source Warehouse** box of the **Inventory** tab for the store.

|**Shipping Account**|The GL account that is debited for the shipping prices included in imported marketplace-fulfilled orders.|
|**Shipping Subaccount**|The subaccount of the shipping account.

 This box is displayed only if the *Subaccounts* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|Element|Description|

|**Seller-Fulfilled Return Type**|The order type in Acumatica ERP that is assigned to seller-fulfilled returns imported from Amazon.

 The list shows only the order types that are based on the *RC - Return for Credit* template on the [Order Types](SO_20_10_00.md) \(SO201000\) form.

|
|**Marketplace-Fulfilled Return Type**|The order type in Acumatica ERP that is assigned to marketplace-fulfilled returns imported from Amazon.

 The list shows only the order types that are based on the *CM - Credit Memo* template on the [Order Types](SO_20_10_00.md) \(SO201000\) form.

|
|**Charge Item**|The non-stock item that is used to represent additional charges in imported seller-fulfilled and marketplace-fulfilled returns, such as refund shipping, restocking fees, and other fees that Amazon charges customers during refunds.

 The selected item should have the **Require Shipment** check box cleared on the **General** tab of the [Non-Stock Items](IN_20_20_00.md) \(IN202000\) form,

|
|**Refund Reason Code**|The reason code that the system will insert in each return order line for a refund or return imported from the Acumatica ERP store. The reason code must have the *Issue* usage type specified on the [Reason Codes](CS_21_10_00.md) \(CS211000\) form.|

|Element|Description|

|Element|Description|

 Also, the system import non-order fees only from settlement periods closed on or after this date.

## Payments Tab { .section}

On this tab, in the upper table, you map the payment methods defined in Amazon with the payment methods and cash accounts defined in Acumatica ERP. Also, in the **Payment Fees** table, you map Amazon fees related to processing orders and refunds with entry types defined in Acumatica ERP to track charges separately.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that payment processing is enabled for the payment method.

 If this check box is cleared for a payment method, when an order is placed on Amazon and this payment method is selected at checkout, the corresponding payment is not imported from the Amazon seller account to Acumatica ERP.

 This check box is cleared by default.

|
|**Store Payment Method**|The payment method defined in Amazon.|
|**Store Currency**|The currency for which the store payment method has been defined in Amazon.|
|**ERP Payment Method**|The identifier of the payment method in Acumatica ERP. This payment method is used to create payment documents in Acumatica ERP for imported payments based on the mapped store payment method.

 If you click this identifier, the system opens the payment method on the [Payment Methods](CA_20_40_00.md) \(CA204000\) form.

|
|**Cash Account**|The identifier of the cash account associated with the payment method in Acumatica ERP. You can select only cash accounts in the store currency.

 If you click this identifier, the system opens the cash account on the [Cash Accounts](CA_20_20_00.md) \(CA202000\) form.

|
|**Proc. Center ID**|The identifier of the processing center configured in Acumatica ERP for the card-based payment method selected in the **ERP Payment Method** column and the cash account selected in the **Cash Account** column.

 If you click this identifier, the system opens the processing center on the [Processing Centers](CA_20_50_00.md) \(CA205000\) form in a pop-up window.

 This column is displayed if the *Integrated Card Processing* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Release Transactions**|A check box that you select to indicate that payments and cash transactions should be automatically released as soon as they are imported to Acumatica ERP.|

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that the fees of this fee type should be imported to Acumatica ERP with payments or refunds.

 During the import of settlement reports, the system imports settlement transactions associated with all the fees listed in the table, including inactive ones.

|
|**Fee Type**|The type of the Amazon fee. You can select one of the following options:

 -   *Order Fee*: Fees related to processing orders.
-   *Non-Order Fee*: Additional fees that are not directly tied to processing orders.
-   *Refund Fee*: Fees related to processing refunds.

|
|**Fee Description**|The description of the fee type.|
|**ERP Entry Type**|An entry type that has been defined on the [Entry Types](CA_20_30_00.md) \(CA203000\) form. The selected entry type must comply with the following requirements:

 -   On the [Entry Types](CA_20_30_00.md) \(CA203000\) form, the entry type has the following type depending on the fee type:
    -   *Order Fee*: *Disbursement*
    -   *Non-Order Fee*: *Disbursement* or *Receipt*
    -   *Refund Fee*: *Disbursement*
-   On the [Cash Accounts](CA_20_20_00.md) \(CA202000\) form, the entry type is linked with the cash account associated with the store payment method and selected in the **Cash Account** column in the upper table.

|
|**Entry Type Description**|The description of the entry type.

 The column is populated automatically based on the **ERP Entry Type** column and is not available for editing.

|
|**Transaction Type**|The type of the transaction the entry type was created for.

 The column is populated automatically based on the **ERP Entry Type** column and is not available for editing.

|

## Shipment Tab { .section}

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that the system should use the mapped Ship Via code, shipping zone, and shipping terms when importing orders from the Amazon seller account.|
|**Store Shipping Zone**|The shipping zone that has been set up in the Amazon seller account.|
|**Store Shipping Method**|The shipping method for the specified shipping zone that has been set up in the Amazon seller account.|
|**Ship Via**|The Ship Via code in Acumatica ERP that is mapped to the combination of the store shipping zone and the store shipping method.

 The value selected in this column is assigned to orders imported into Acumatica ERP and is displayed on the **Shipping** tab of the [Sales Orders](SO_30_10_00.md) \(SO301000\) form for these orders.

 If you click code, the system opens the [Ship via Codes](CS_20_75_00.md) \(CS207500\) form, on which you can review the Ship Via code's details.

|
|**Shipping Zone**|The identifier of the shipping zone in Acumatica ERP, which is defined on the [Shipping Zones](CS_20_75_10.md) \(CS207510\) form, that is mapped to the combination of the store shipping zone and the store shipping method. The value selected in this column is assigned to each sales order imported to Acumatica ERP with the store shipping zone and store shipping method specified in this row. This value is also inserted on the **Shipping** tab of the [Sales Orders](SO_30_10_00.md) \(SO301000\) form for the sales order.

 This value is optional. If you leave it empty, the **Shipping Zone** box on the **Shipping** tab of the [Sales Orders](SO_30_10_00.md) \(SO301000\) form will not be populated when a sales order with the store shipping zone and store shipping method specified in the row is imported.

 If you click this identifier, the system opens the shipping zone on the [Shipping Zones](CS_20_75_10.md) \(CS207510\) form.

|
|**Shipping Terms**|The identifier of the shipping terms in Acumatica ERP, which is defined on the [Shipping Terms](CS_20_80_00.md) \(CS208000\) form, that is mapped to the combination of the store shipping zone and store shipping method. The value selected in this column is assigned to each sales order imported to Acumatica ERP with the store shipping zone and store shipping method specified in this row. This value is also inserted in the **Shipping Terms** box on the **Shipping** tab of the [Sales Orders](SO_30_10_00.md) \(SO301000\) form for the sales order.

 This value is optional. If you leave it empty, the **Shipping Terms** box on the **Shipping** tab of the [Sales Orders](SO_30_10_00.md) \(SO301000\) form will not be populated when a sales order with the store shipping zone and store shipping method specified in the row is imported.

 If you click this identifier, the system opens the shipping terms on the [Shipping Terms](CS_20_80_00.md) \(CS208000\) form.

|
