# Encryption Certificates {#_12789ddf-44cf-4ddf-bd23-46ecd673f475 .reference}

Form ID: \(SM200530\)

Acumatica ERP requires security certificates for users to digitally sign PDF files generated in the system. Also, these certificates can be used to encode sensitive information stored in the database. Each certificate requires a password. The system uses the password to access the uploaded certificate and use it for data encryption. For more information on using certificates in the system, see [Digital Certificates: General Information](SA_Data_Encryption_GeneralInfo.md).

On this form, you can add new certificates, import certificate files, manage existing certificates, and remove outdated certificates.

**Tip:** Digital certificates used by Acumatica ERP have the `.pfx` extension. Before you can import digital certificates into the system, make sure `.pfx` is on the list of allowed extensions on the [File Upload Preferences](../Shared/../UserGuide/SM_20_25_50.md) \(SM202550\) form.
