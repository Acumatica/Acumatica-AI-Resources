# Batch for Submission {#_f457fb5b-9ebe-4a37-8207-9aaad21dd554 .reference}

Form ID: \(PR304000\)

By using this form, you can do the following:

-   Prepare the slips in XML format to submit them to the government authorities.
-   Generate PDFs of the tax forms included in the batch.
-   Publish or unpublish tax forms for selected employees. Marking a tax form as published indicates that it has been submitted to the government authorities.

**Attention:**

You can open a batch created for a CRA payroll account only if you have access to all the companies and branches associated with this CRA account.

This form appears only if the *Canadian Payroll* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Publish All**|Marks all forms in the batch as published, which indicates that they have been submitted to the government authorities.

 The employee has access to published tax forms through the [My Payroll Documents](PR_40_50_00.md) \(PR405000\) form.

|
|**Download XML**|Prepares the tax forms in XML format. Downloaded forms are ready to be submitted to the government authorities.|
|**Download T4 Batch Summary**|Downloads the T4 Batch Summary report for the batch as an Excel file named `T4 Batch Summary` followed by the batch identifier.

 The report consolidates employment income, deductions, and CRA contribution totals from all T4 slips from the batch into a single summary. You can run this report throughout the year to confirm annual totals,

|
|**Print All**|Generates PDFs of the tax forms included in the batch.|
|**Unpublish All**|Unpublishes all forms in the batch.|

## Summary Area {#1 .section}

In this area, you can select an existing batch to view its settings and publish the documents included in this batch.

|Element|Description|
|-------|-----------|
|**Batch ID**|The identifier of the batch for submission.|
|**Form Name**|The name of the tax forms included in the batch.|
|**Year**|The reporting year.|
|**Company/Branch**|The company or branch that has been reported on, if the *Multicompany Support*, *Multibranch Support*, or both features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 The box appears only for the following batches:

-   *Releve1* batches
-   *T4* batches created in Acumatica ERP 2025 R2 or earlier versions that do not have a CRA payroll account associated with them

|
|**CRA Payroll Account Number**|The CRA payroll account number defined for companies or branches that have been reported on.

 The box appears only for *T4* batches that have a CRA payroll account associated with them.

|
|**Legal Entity for Payroll Tax Reporting**|The company or branch that has been reported on.

 The box appears only for *T4* batches that have a CRA payroll account associated with them.

|
|**Province of Employment**|The Canadian province of employment for which the tax form included in the batch were prepared.

 The box appears only for historical batches that have a province assigned.

|
|**Document Type**|The type of the document, which can be *Original*, *Amendment*, or *Cancellation*.|
|**Downloaded On**|The date when the batch was last time downloaded in XML format.|
|**Number of Employees**|The number of employees included in the batch.|

|Button|Description|
|------|-----------|
|**Publish**|Marks the selected form as published, which indicates that it has been submitted to the government authorities.|
|**Unpublish**|Unpublishes the selected form if it was previously published.|

|Column|Description|
|------|-----------|
|**Employee ID**|The identifier of the employee.|
|**Employee Name**|The full name of the employee.|
|**Branch**|The company branch to which the employee belongs.|
|**Pay Group**|The pay group of the employee.|
|**Province of Employment**|The Canadian province of employment for which the tax form was prepared.|
|**Published**|A check box that indicates \(if selected\) that the batch has been published.|
|**Published From**|The identifier of the employee's last published batch for submission.|
