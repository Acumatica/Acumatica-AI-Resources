# Detect Anomalies in Generic Inquiries {#_786a81e1-cd79-42b1-99e4-8b724607f5f9 .reference}

Form ID: \(ML502000\)

You use this form to run the anomaly detection process and view the results of this process. You can open this form by clicking **Detect Anomalies** on the form toolbar of the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form or on the form toolbar of the corresponding generic inquiry form. \(You can also open the form directly from search results or a workspace.\)

**Attention:** The total number of records in all generic inquiries that the administrator can send for processing, which may be reduced by conditions specified on the **Conditions** tab of the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form for each inquiry, is 1 million per day. This limit is calculated in the UTC time zone for all tenants.

The form is available only if the *Detection of Numeric Anomalies in Generic Inquiries* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Process**|Initiates the anomaly detection process for the generic inquiries that you have selected in the table.

 You can use this command only if *On Demand* is selected in the **Update Frequency** box on the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form for each selected generic inquiry. The system starts the processing immediately in this case. If any other value is selected in this box, the system displays a warning and starts the processing at the scheduled time.

|
|**Process All**|Initiates the anomaly detection process for all generic inquiries listed in the table. If any value other than *On Demand* is selected in the **Update Frequency** box on the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form for a generic inquiry, the system will start the processing of this generic inquiry according to the scheduled time.|
|**Reset Data**|Opens the **Reset Data** dialog box, in which you can confirm that you want to delete the data related to anomaly detection. You first click a row in the table and then click this command.|

|Button|Description|
|------|-----------|
|**Yes**|Deletes the related data, sets the status of anomaly detection to *New*, and closes the dialog box.|
|**No**|Cancels the deletion of data and closes the dialog box.|

## Generic Inquiries Table {#2 .section}

In the top table of the form, you select the generic inquiries for which you want to run the anomaly detection process.

|Column|Description|
|------|-----------|
|Included|A check box that you select to indicate that the system should run the anomaly detection for the generic inquiry in this row.|
|**Inquiry Title**|The name of the generic inquiry for which the anomaly detection process runs. This is the name specified in the box of the same name on the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form.|
|**Field for Analysis**|The data field that holds the value that the system analyzes to find anomalies. This is the value specified for the generic inquiry in the **Field for Analysis** box on the **Anomaly Detection** tab of the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form.|
|**Date Field for Timeline**|The date field whose values provide the data points on the timeline. This is the value specified for the generic inquiry in the **Date Field for Timeline** box on the **Anomaly Detection** tab of the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form.|
|**Grouping**|The data field or fields by which records in the generic inquiry are grouped. These are the values specified for the generic inquiry in the table in the **Grouping** section on the **Anomaly Detection** tab of the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form.|
|**Status**|The status of the anomaly detection process for this generic inquiry, which can be one of the following:

 1.  *New*: The process has not been performed yet.
2.  *Data Uploaded*: The data has been uploaded to the cloud service.
3.  *Calculation in Progress*: The cloud service is processing the uploaded data.
4.  *Downloading Results*: The processed results are being downloaded from the cloud service into Acumatica ERP.
5.  *Completed*: The process has been completed.
6.  *Error*: The process has not been completed for some reason.

|
|**Last Executed On**|The date and time when the anomaly detection was last performed for this generic inquiry.|
|**Last Uploaded On**|The date and time when the records for anomaly detection were last uploaded to the cloud service for this generic inquiry.|
|**Last Imported On**|The date and time when the processed data was last imported from the cloud service into Acumatica ERP for this generic inquiry.|
|**Next Run**|The date and time when the anomaly detection runs next for this generic inquiry according to the schedule.

 If *On Demand* is selected for this generic inquiry in the **Update Frequency** box on the **Anomaly Detection** tab of the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form, the value in this column is *On Demand*.

|

## Generic Inquiry Dataset List Table { .section}

In the bottom table of the form, you view the results and status of the anomaly detection process for the generic inquiry selected in the table with generic inquiries \(that is, the row that you click; initially, the first row is selected\). If you have not yet run the process for this generic inquiry, the table is empty.

During the manual processing, you can also use the bottom table \(which contains one row during this processing\) to initiate the next processing step for the selected generic inquiry by clicking **Execute Next Step** on the table toolbar.

|Button|Description|
|------|-----------|
|**Execute Next Step**|Initiates the next step of the processing of the generic inquiry selected in the table with generic inquiries.

 You click this button only when you are performing manual processing—that is, if you have selected *On Demand* in the **Update Frequency** box on the **Anomaly Detection** tab of the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form for the selected inquiry.

|

|Column|Description|
|------|-----------|
|**Status**|The status of anomaly detection process for this generic inquiry, which can be one of the following:

 1.  *New*: The process has not been performed yet.
2.  *Data Uploaded*: The data has been uploaded to the cloud service.
3.  *Calculation in Progress*: The cloud service is processing the uploaded data.
4.  *Downloading Results*: The processed results are being downloaded from the cloud service into Acumatica ERP.
5.  *Completed*: The process has been completed.
6.  *Error*: The process has not been completed for some reason.

|
|**Error Code**|The error code that the system returns if the detection fails. This column is filled in only if the status is *Error*.|
|**Last Uploaded On**|The date and time when the anomaly detection was last performed.|
|**Rows Uploaded**|The number of records in this generic inquiry that have been uploaded to the cloud service.|
|**Rows Skipped**|The number of records in this generic inquiry that have not been processed.|
|**Groups Uploaded**|The number of groups of records in this generic inquiry that have been uploaded to the cloud service.|
|**Groups Skipped**|The number of groups of records in this generic inquiry that have not been processed.|
|**Imported On**|The date and time when the processed data was last imported from the cloud service into Acumatica ERP.|
|**Rows Imported**|The number of records that have been imported from the cloud service into Acumatica ERP.|
