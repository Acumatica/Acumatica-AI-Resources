# GL Reversing Batches {#_51d10e22-1317-4d0b-b6b6-abb94753916b .reference}

Form ID: \(GL690010\)

This report displays the details of reversing batches for the specified batch.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Module**: The subledger the batch originated from; you must make a selection.
-   **Batch Number**: The number of the batch for which you want to view reversing batches. You must select a batch.
