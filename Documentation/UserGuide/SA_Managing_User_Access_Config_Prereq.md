# User Access: Configuration Prerequisites

Before starting to configuring user access, you must be sure that the system has been configured properly and that all required entities have been created, as described in the following sections.

## Basic Company Configuration

At minimum, you need to make sure that basic company configuration has been performed. For details on basic company configuration, see one of the following, depending on the structure of your organization:

-   [Company Without Branches](../ImplementationGuide/config_Basic_Company_Mapref.md)
-   [Company with Branches that Do Not Require Balancing](../ImplementationGuide/config_Company_with_Branches_No_Balancing_Mapref.md)
-   [Company with Branches that Require Balancing](../ImplementationGuide/config_Company_with_Branches_with_Balacing_Mapref.md).

## Access Configuration

Before you create user accounts in Acumatica ERP and define their level of access to the system, make sure that a set of user roles have been properly configured to comply with the security policies of your organization. For details, see [Configuring User Roles](User_Roles_Mapref.md).
