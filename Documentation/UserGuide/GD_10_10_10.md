# Privacy Tool Audit

Form ID: \(GD101010\)

This form is available only if the *GDPR Compliance Tools* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

By using this form, you can monitor the history of record changes, track who restricted the processing of personal data or erased personal data in the system, when this user restricted processing or erased personal data, and what data was restricted.

For more information about how you can handle personal data in Acumatica ERP, see [Handling Personal Data](GD__MNG_Handling_Personal_Data.md).
