# Email Processing Log {#_beebd218-8bf6-45f8-97b0-83fe220d7cbb .reference}

Form ID: \(SM404100\)

By using this inquiry form, you can view all log entries associated with email processing. These log entries are generated only if the *Enabled for Failed Emails* or *Enabled for All Emails* option is selected in the **Email Processing Logging** box on the [Email Preferences](SM_20_40_01.md) \(SM204001\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table {#1 .section}

This table contains a list of log entries associated with email processing.

|Column|Description|
|------|-----------|
|**Log Entry Date**|The date and time when the log entry was created.|
|**Operation**|The email processing operation that triggered the creation of the log entry.|
|**Message**|The information about the event or the error message.|
|**Message-ID**|The unique message identifier.|
|**Ext. ID**|The ID of the email message on the external server for which the log entry was created.|
|**From**|The author of the email.|
|**To**|The recipient of the email.|
