# Acumatica ERP Integration with Gmail: General Information {#_0dd48ff3-340e-41b2-8183-a2dab0a56de2 .concept}

You can work with the Acumatica ERP records directly in your Gmail mailbox. The Gmail integration connects your email account to the system, so you can access related records and create new records without leaving Gmail.

The integration includes two components. The first is a customization project installed in Acumatica ERP. It provides the *Gmail Integration* feature, which you must enable to use the functionality. For details, see [Acumatica ERP Integration with Gmail: Installation of the Gmail Integration Customization Project](INT_Gmail_Customization_Plugin_Installation.md).

You also need to set up the connected application in Acumatica ERP, so Gmail can securely connect to your Acumatica ERP instance. For details, see [Acumatica ERP Integration with Gmail: Configuration of the Connected Application](INT_Gmail_Configuration_Connected_Applications.md).

The second component is the Acumatica for Gmail add-on that you install in your Gmail mailbox. After installation, the Acumatica for Gmail icon appears in the side panel of your mailbox. You can click this icon to work with the selected email in the Acumatica for Gmail panel. For details, see [Acumatica ERP Integration with Gmail: Add-on Installation](INT_Gmail_Addon_Installation.md).
