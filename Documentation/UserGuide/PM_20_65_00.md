# Revenue Percentage Calculation Rules

Form ID: \(PM206500\)

If you use progress billing for projects, you review or modify predefined revenue percentage calculation rules on this form. You can also create new rules that the system will use to calculate the recommended completion percentages for revenue budget lines in progress billing.

**Attention:** You can't delete a predefined rule.

## Form Toolbar

The form toolbar includes only standard buttons.

## Summary Area

This area contains the settings of the revenue percentage calculation rule.

**Rule ID**

</td><td>

The identifier of the revenue percentage calculation rule.

 You can select one of the following predefined rules, which determine how the system calculates the recommended revenue completion percentage of the project’s budget lines:

 -   *REVISEDAMT*: By comparing the actual amount with the revised budgeted amount.
-   *REVISEDQTY*: By comparing the actual quantity with the revised budgeted quantity.
-   *PROJCOST*: By comparing the actual amount with the projected cost at completion. The system uses the projected costs from the latest released cost projection—dated on or before the current business date—on the [Cost Projection by Date](PM_30_55_00.md) \(PM305500\) form.
-   *PROGCOSTQTY*: By comparing the progress worksheet quantities recorded for the applicable cost budget lines with their revised budgeted quantities. The system uses quantities from released progress worksheets.
-   *PROGREVQTY*: By comparing the progress worksheet quantity recorded for the revenue budget line with its revised budgeted quantity. The system uses quantities from released progress worksheets.

 **Attention:** The *PROJCOST*, *PROGCOSTQTY*, and *PROGREVQTY* rules appear on the form if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 For a new rule, you enter the identifier manually.

</td></tr><tr><td>

**Budget Line Source**

</td><td>

The type of budget lines the system uses to calculate the recommended completion percentage.

 The following options are available:

 -   *Cost* \(default\): The system uses cost budget lines as the source of the recommended completion percentage.
-   *Revenue*: The system uses revenue budget lines as the source of the recommended completion percentage.

</td></tr><tr><td>

**Group by Task**

</td><td>

The type of a project task that the system uses to group cost budget lines when it calculates the recommended completion percentage for revenue budget lines. You can select one of the following options: *Revenue Task* \(default\) or *Project Task*.

 The box isn't shown for a rule with the *Revenue* budget line source because the rule calculates the recommended completion percentage directly from the revenue budget line and grouping isn't needed for this calculation.

 For details, see [Progress Billing: Automated Revenue Percentage Calculation](Projects_Billing_Project_by_Progress_Auto_Revenue_Percentage_Calculation.md).

</td></tr><tr><td>

**Group by Item**

</td><td>

A check box that indicates \(if selected\) that the system groups cost budget lines by inventory item within each task group.

 The check box isn't shown for a rule with the *Revenue* budget line source because the rule calculates the recommended completion percentage directly from the revenue budget line and grouping isn't needed for this calculation.

</td></tr><tr><td>

**Group by Cost Code**

</td><td>

A check box that indicates \(if selected\) that the system groups cost budget lines by cost code within each task group.

 This check box is shown only if the *Cost Codes* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 The check box isn't shown for a rule with the *Revenue* budget line source because the rule calculates the recommended completion percentage directly from the revenue budget line and grouping isn't needed for this calculation.
