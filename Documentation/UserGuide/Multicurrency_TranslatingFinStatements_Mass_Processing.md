# Translation of Financial Statements: Mass Processing {#_ac67d2d6-1bfa-4919-a30f-96bb5d55b243 .concept}

After you have prepared multiple translations on the [Prepare Translation](CM_50_10_00.md) \(CM501000\) form, you can release them at once on the [Release Translations](CM_50_20_00.md) \(CM502000\) form.

## To Release Multiple Translations {#section_yb1_jjv_vxb .section}

1.  Open the [Release Translations](../Shared/../UserGuide/CM_50_20_00.md) \(CM502000\) form.
2.  Select the unlabeled check box in the row of each translation you want to release. \(If you plan to release most of the listed translations, instead select the check box in the column header to select all check boxes on the page, and clear the check boxes in the rows of the translations you don't want to release.\)
3.  Click **Release**.
