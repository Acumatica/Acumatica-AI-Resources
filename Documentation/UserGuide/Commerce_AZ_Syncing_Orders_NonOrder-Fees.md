# Order Synchronization: Non-Order Fees {#_aa8a858a-c5a4-4c18-be51-1ab2faa0196e .concept}

Amazon charges merchants fees that are not related to particular orders, for example, storage or advertising fees. The details of these fees are available in the settlement reports provided by Amazon. You can import such fees into Acumatica ERP to gain greater visibility into per-unit profitability—that is, how much the company makes on the products it sells on Amazon and how much it is charged for each of the products.

## Setting Up the Import of Non-Order Fees { .section}

To set up the import of non-order fees to Acumatica ERP, you perform the following general steps:

1.  Activate the entity.

    To synchronize non-order fees, you must activate the *Non-Order Fees* entity on the **Entities** tab of the [Amazon Stores](BC_20_10_20.md) \(BC201020\) form.

2.  Specify a date to determine the settlement periods from which non-order fees are imported.

    On the **Orders** tab, enter a date in the **Earliest Report Date** box. The system will import non-order fees only from settlement reports closed on or after this date.

3.  Map the Amazon non-order fees.

    Initially, when no non-order fees are mapped, the synchronization of the *Non-Order Fees* entity fails. The Amazon connector adds a row for each supported non-order fee to the **Payment Fees** table of the **Payments** tab and populates the **Fee Type** column. You must map each Amazon fee type with an ERP entry type, which is defined on the [Entry Types](CA_20_30_00.md) \(CA203000\) form.

    An entry type can be used in the fee mapping if it meets the following criteria:

    -   The entry type has the *Disbursement* or *Receipt* type.
    -   A default offset account has been specified for the entry type.
    -   For the cash account specified in the mapping for the Amazon payment method in the upper table, the entry type has been added on the [Cash Accounts](CA_20_20_00.md) \(CA202000\) form.

## Synchronizing Non-Order Fees { .section}

Amazon fees that are not related to any particular Amazon order are imported during the synchronization of the *Non-Order Fees* entity. Imported non-order fees are displayed as a cash transaction on the [Cash Transactions](CA_30_40_00.md) \(CA304000\) form.

The **Sync Record Details** dialog box of the [Sync History](BC_30_10_00.md) \(BC301000\) form displays the following information about imported non-order fees:

-   The **ERP ID** column: the identifier of the cash transactions created for the settlement report
-   The **External ID** column: the identifier of the settlement report generated by Amazon
