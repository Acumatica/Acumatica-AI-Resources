# Site Map {#_44b364ef-7810-400b-b1c6-8f471c249401 .reference}

Form ID: \(SM200520\)

You use this form to view and edit the list of forms available in Acumatica ERP. For details about the site map, see [UI Navigation Options: Site Map](SA_Customizing_UI_Site_Map_Concept.md). Changes made on this form will affect the site map tree, which the system uses on other forms for clear representation of the main menu.

Wikis are not presented on the form. To view the map of any wiki, use the [Wiki Site Map](SM_20_20_10.md) \(SM202010\) form.

On this form, you can specify the UI to be used by default \(*Modern* or *Classic*\) for any number of forms; you can also copy the UI settings of the listed forms to other tenants. For details, see [Modern UI Development: Switching a Form Between the Modern UI and the Classic UI](../DeveloperGuide/UIDev_ModernUI_SwitchUI.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Copy UI Settings to Tenants**|Opens the **Copy UI Setting to Tenants** dialog box, which you can use to copy the **UI** settings of the listed forms to other tenants. In the dialog box, you select the target tenants in the **Tenants** box and then click **Copy**. As a result, the forms in these tenants will open with the selected UI.

 The button is available only if multiple tenants are configured in the system.

|

## Table {#2 .section}

In the table, you can view and edit the settings of the forms, including the URLs of the forms on the website, assigned workspaces, and category.

|Column|Description|
|------|-----------|
|**Screen ID**|The screen ID \(that is, form ID\) of the item.

 You can modify the screen ID of any form by specifying a new ID in this column. When you have modified it, the system updates the screen ID in all related entities, such as filters and dashboards.

|
|**Title**|The name of the form displayed in the Classic UI and the Modern UI.|
|**UI**|The UI in which a form is opened.

 You can use this setting to specify the look and feel of the form. The available options are *Modern*, *Classic*, or *Default*. The later option means that the form will use the UI specified by the **Default UI** setting on the [Site Preferences](SM_20_05_05.md) \(SM200505\) form.

|
|**URL**|The URL of the form.|
|**Graph Type**|The identifier of the system graph that provides the functionality for the form.|
|**Workspaces**|The workspaces from which the form can be accessed.|
|**Category**|The category under which the form will be displayed in each selected workspace.|
|**Is Substitute**|Read-only. A check box that indicates \(if selected\) that the form is substituted for some entry or maintenance form. That is, when a user clicks the name of the entry or maintenance form in a workspace or a search result, the substitute form opens instead.|
