# Fixed Assets Reports {#_6053a06c-4150-47ec-a65f-174b46389696 .concept}

With the wide variety of Acumatica ERP reports related to fixed assets, you can promptly get detailed information about fixed asset acquisitions, disposals, depreciation, net value, and transactions. Fixed asset reports provide you with asset balance projections by account and by class. You can also track fixed assets for different locations, custodians, and departments. If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All reports related to fixed assets can be generated in different formats, including PDFs, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
