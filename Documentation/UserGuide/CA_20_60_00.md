# Synchronize Cards

Form ID: \(CA206000\)

You use this form to synchronize new credit cards registered to the Acumatica Payments processing center with Acumatica ERP. When you synchronize cards, customer-specific payment methods are created with the entered data. This form is accessible to only users assigned to the *AR Admin* or *System Administrator* role \(or both roles\).

**Attention:** This form appears in the system if the *Integrated Card Processing* and *Acumatica Payments* features have been enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Summary Area

You use the elements in this area to select the processing center from which you want to load credit cards.

|Element|Description|
|-------|-----------|
|**Processing Center**|The processing center from which you want to load credit cards, which you select from the list of processing centers that use the tokenized plug-in.|
|**Load Expired Card Data**|A check box that indicates \(if selected\) that all cards will be loaded on the form, including expired cards. When the check box is cleared \(the default value\), the system loads only cards with an expiration date that is later than the current date.|
