# Ledgers {#_a5c9f3f5-7dc4-4b1b-a50c-396729a12e4e .reference}

Form ID: \(GL201500\)

You use this form to enter and maintain information about financial ledgers used in the system. For details, see [Managing Ledgers](GL__MNG_Managing_Ledgers.md).

**Important:** If a ledger has any transactions posted to it, you cannot delete the ledger or change its currency or ledger type.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Change ID**|Brings up the **Specify New ID** dialog box, so that you can change the ID of the currently selected ledger.|

## Summary Area { .section}

In this area, you can assign a unique identifier to a new ledger and specify its description and type.

|Element|Description|
|-------|-----------|
|**Ledger ID**|An alphanumeric string of up to 10 characters used to identify the ledger. You should follow your company's internal rules when naming ledgers.

 For information on how to change this ID, see [To Change a Ledger ID](GL__HOW_To_Change_Ledger_ID.md).

|
|**Description**|A description of the ledger. This alphanumeric string can be up to 60 characters.|
|**Type**|The type of the ledger, which can be one of the following predefined types:

 -   *Actual*: A ledger of this type is updated through the posting of journal transactions. Journal transactions are organized in batches, and the double-entry bookkeeping rule is enforced for these batches. The system supports multiple actual ledgers in the General Ledger module; however, journal transactions generated by modules other than General Ledger will be posted to only the default posting ledgers specified for each branch on the [Inter-Branch Account Mapping](GL_10_10_10.md) \(GL101010\) form.
-   *Budget*: A budget ledger is used to store budget information. You update this type of ledger directly on the [Budgets](GL_30_20_10.md) \(GL302010\) form. You cannot enter journal transactions to a budget ledger.
-   *Reporting*: A reporting ledger is used to store translated financial information. This option is available only if the *Multicurrency Accounting* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.
-   *Statistical*: A statistical ledger is used to store statistical information. Ledgers of this type are updated through journal entries on the [Journal Transactions](GL_30_10_00.md) \(GL301000\) form.

|
|**Currency**|The default currency of the ledger. All transactions in other currencies posted to the ledger will be converted to the base currency by using the currency rate effective on the date of transaction.

 If the *Multiple Base Currencies* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, this box is available for an actual ledger if there are no companies associated with the ledger. For a new ledger of the *Actual* type, this box is required and empty by default.

 If the *Multiple Base Currencies* feature is disabled, this box is unavailable for an actual ledger. To a newly created actual ledger, the system will insert the tenant currency.

|
|**Consolidation Source**|A check box that indicates \(if selected\) that the ledger should be used as a source ledger for consolidation.

 This check box is available only if the *General Ledger Consolidation* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|

## Companies Tab { .section}

This tab displays the list of companies associated with the selected ledger. If the *Multiple Base Currencies* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, for an actual ledger, you can select only a company with the same base currency as the ledger's currency.

|Column|Description|
|------|-----------|
|**Company**|The identifier of the company.|
|**Company Name**|The name of the company.|
|**Active**|A check box that indicates \(if selected\) that the company is active.|
|**Company Type**|The type of the company, which can be one of the following: *Without Branches*, *With Branches Not Requiring Balancing*, or *With Branches Requiring Balancing*.

 For more information, see [Companies and Branches](OS__con_Companies.md).

|

## Branches Tab { .section}

This tab displays the list of branches that can post to the selected ledger.

This tab appears if the *Multibranch Support* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|Column|Description|
|------|-----------|
|**Branch ID**|The identifier of the branch.|
|**Branch Name**|The name of the branch.|
|**Active**|A check box that indicates \(if selected\) that the branch is active.|
|**Company Name**|The name of the company to which the branch belongs.|
