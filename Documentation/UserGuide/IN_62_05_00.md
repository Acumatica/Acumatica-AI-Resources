# Physical Count Sheets {#_9c247090-09ad-4ef0-837c-b6bdda9a6749 .reference}

Form ID: \(IN620500\)

**Attention:** This report is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

This report displays the physical count sheets generated for the physical inventory. You run this report to preview and print the sheets to be used to enter the data during inventory counting.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Reference Nbr.**: The reference number of the physical inventory for which you want to display count sheets.
-   **Hide Book Qty.**: A check box that you select to hide the **Book Qty.** column on the generated count sheets.
