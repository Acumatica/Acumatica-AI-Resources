# Portals {#_dac38113-80bd-4b31-8c64-0e402bf57b3e .reference}

Form ID: \(SP701000\)

**Who uses this form:** An Acumatica ERP administrator of a portal owner

After you've created a portal, you use the current form to control the availability of portal forms, specify the portal's settings, set up branding and a landing page, and make sure portal users can access the portal.

**Attention:** The form is available only if the *Modern Customer Portal* or *Shop Floor Kiosk* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

In this area, you can specify or modify the basic settings of the portal.

|Element|Description|
|-------|-----------|
|**Portal Name**|The unique name of the portal, which you entered while creating it.|
|**Portal URL**|The address where the portal is hosted. You entered the portal URL on the Instance Configuration page of the Acumatica ERP Configuration wizard while creating the portal.

 Portal users enter this address in a browser to access the portal.

|
|**Online**|A check box that you select \(the default state\) to make the portal available to portal users. When you clear this check box, the portal becomes unavailable.|
|**Portal Description**|A short description of the portal, which you enter during portal creation.|
|**Portal Type**|The type of the portal.

 The following options may be available:

 -   *Customer Portal*

**Attention:** This option is available only if the *Modern Customer Portal* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

-   *Shop Floor Kiosk*

**Attention:** This option is available only if the *Shop Floor Kiosk* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.


|
|**Portal Access Role**|The user role required for accessing the portal.

 You can select one of the following predefined user roles:

 -   *Portal User*: Allows users to sign in to the Modern Customer Portal.
-   *SFK App Access*: Allows the Shop Floor Kiosk app to access the Acumatica ERP data.

 Each user role defines portal-specific permissions aligned with the employee’s job responsibilities and determines which forms a portal user can access. For the *Portal External User* user type, you select a user role or multiple roles on the [Contacts](CR_30_20_00.md) \(CR302000\) form \(**Access to Portal** tab\).

|

## General Tab { .section}

You use this tab to control which categories and forms are available in the portal. The tab shows a navigation pane with check boxes for these categories \(top-level nodes\) and forms.

By default, all check boxes on the tab are selected. If you clear a check box for a category, the check boxes for its forms become cleared and unavailable for selection. If a form’s check box is cleared, the form is hidden from the portal navigation and can’t be opened—even by direct URL. If you then select a category’s check box, the check boxes for all its forms are selected but can be cleared.

For a portal of the *Customer Portal* type, you can select any of the following check boxes to select the forms of the category \(any of which can be cleared\):

-   **Admin**: Contains the forms related to system administration, including license management, customization projects, system monitoring and diagnostics, classic dashboards, and system updates.
-   **System**: Contains the forms for managing a customer's company information, portal user profiles, contacts, and dashboards.
-   **B2B Ordering**: Enables the *B2B Ordering* feature. Contains the forms for browsing the catalog, viewing item details, managing the cart, placing orders, and reviewing them.

    **Important:** Before selecting the category, make sure the *Inventory and Order Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. Otherwise, the category won’t be visible on the current tab.

-   **Financials**: Contains the forms for viewing open documents, invoices, payments, statements, balances, and overdue charges.
-   **Payments**: Contains the forms that support payment in the portal.
-   **Case Management**: Contains the list of forms related to customer relationship management \(CRM\).

    **Important:** Before selecting the category, make sure the *Case Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. Otherwise, the category won’t be visible on the current tab.

-   Other: Contains the list of uncategorized forms. You can select a form in the list to make it visible in the portal.

    **Attention:** Forms added to this section may expose Acumatica ERP data to external portal users. Review the filters, visible UI elements, and row-level security on the form to ensure that portal users can access only the data they are authorized to access based on their assigned roles. For more information, see [Modern Customer Portal: Completing Portal Setup](Modern_Customer_Portal_Configuration_Settings.md).


For a portal of the *Shop Floor Kiosk* type, only the **Shop Floor Kiosk** category is available.

## Portal Users Tab { .section}

On this tab, you can view a read-only list of contacts—that is, users who can access the portal—along with each user’s basic settings. The system copies these settings from the [Contacts](CR_30_20_00.md) \(CR302000\) form.

If a portal contact is assigned the *Portal External User* user type and one or more user roles on the [Contacts](CR_30_20_00.md) form, the system displays the user on this tab.

|Column|Description|
|------|-----------|
|**Email**|The email address of the portal user, which is used for authentication, notifications, and user account management in the portal.|
|**Contact**|The name of the portal user.

 Click the name, which is a link, to open the [Contacts](CR_30_20_00.md) \(CR302000\) form, where you can view and edit the contact’s settings, including their access rights to the portal.

|
|**Business Account**|The name of the business account to which the portal user’s contact record is related.

 Click the business account, which is a link, to open the [Business Accounts](CR_30_30_00.md) \(CR303000\) form, where you can review and edit the business account’s settings.

|
|**User Roles**|The role or roles assigned to the portal user on the **Access to Portal** tab of the [Contacts](CR_30_20_00.md) \(CR302000\) form. These roles define this user's access to their company’s data and portal functionality.|
|**Status**|The status of the portal user, which can be one of the following:

 -   *Active*: This active user can sign in to the portal and work in it.
-   *Online*: This active user can see the portal and is currently signed in to it.
-   *Disabled*: This user account is disabled. The user cannot sign in to the portal.
-   *Temporarily Locked*: This user account is locked, which occurs when a portal user attempts to sign in with an incorrect password more than three times. On the sign-in page of the portal, the system displays a warning message indicating that the user must contact the system administrator.

|

## Portal Settings Tab { .section}

On this tab, you can specify UI, branding, and landing page settings of the portal.

|Element|Description|
|-------|-----------|
|**Interface Theme**|The color theme applied to the portal to align with your corporate branding. The system inserts *Default*—the default theme in the system—but you can select another theme.|
|**Primary Color**|The default color of the portal UI elements. The system inserts *\#007acc*—the default color in the system—but you can override this value.|
|**Portal Logo**|The image of your company’s logo, which is displayed on the sign-in page of the portal.|
|**Sign-In Page Image**|The image to be used for the portal's sign-in page.|

|Element|Description|
|-------|-----------|
|**Default Home Form**|The portal form displayed to the user after they sign in to the portal. By default, the *Home Page \(SP000001\)* form is displayed when the user signs in.

 For a portal of the *Shop Floor Kiosk* type, the Shop Floor Kiosk \(AM000000\) form must be selected.

|
|**Display Navigation Panels**|A check box that you select \(the default state\) to make the main menu panel and workspace menu items visible in the portal.|
|**Display Top Message**|A check box that you select \(the default state\) to make an informational message visible on the Home Page \(SP000001\) form of the portal. This message is used for important announcements.

 **Important:** Clear this check box if a different home page is specified in the **Default Home Form** box.

|
|**Top Message Image**|The image to be displayed with the informational message on the Home Page \(SP000001\) form when the portal user signs in.|
|**Top Message Text**|The informational message to be displayed on the Home Page \(SP000001\) form when the portal user signs in. This message is used for important announcements.|
|**Display Go to Catalog Button**|A check box that you select \(the default state\) to make the **Go to Catalog** button visible on the Home Page \(SP000001\) form of the portal. In the portal, a user clicks this button to open the [Catalog](SP_50_40_01.md) \(SP504001\) form.|
|**Go to Catalog Image**|The image to be displayed on the **Go to Catalog** button on the Home Page \(SP000001\) form when the portal user signs in.|
|**Go to Catalog Text**|The text to be displayed on the **Go to Catalog** button on the Home Page \(SP000001\) form of the portal.|

## Customer Portal Tab {#section_fsc_msp_vsb .section}

This tab appears only if *Customer Portal* is selected in the **Portal Type** box in the Summary area.

On this tab, you can specify finance, order, and customer relationship management \(CRM\) settings for the portal. You can also select a plug-in to validate and auto-fill addresses in the portal.

|Element|Description|
|-------|-----------|
|**User Type**|The user type assigned to users who can access the portal.

 For the Modern Customer Portal, you should specify the *Portal External User* user type.

|

|Element|Description|
|-------|-----------|
|**Source of Financial Documents**|Your organization’s company or branch in Acumatica ERP to provide financial data for documents shown in the portal. These documents include sales orders, invoices, credit and debit memos, payments, refunds, and statement reports.|
|**Default Branch**|Your organization’s branch to provide financial data for documents shown in the portal. These documents include sales orders, invoices, credit and debit memos, payments, refunds, and statement reports.

 This box appears only if both of the following conditions are met:

 -   On the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the *Inventory and Order Management* and *Multiple Warehouses* features are enabled.
-   On the **General** tab of the current form, the **B2B Ordering \(Modern Portal\)** check box is selected.

|
|**Sales Order Type**|The default order type automatically assigned to sales orders that customers create by using the portal. The order type determines how sales orders of the type are processed.

 By default, the system inserts *SO*, but you can select another type.

 This box appears only if both of the following conditions are met:

 -   On the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the *Inventory and Order Management* feature is enabled.
-   On the **General** tab of the current form, the **B2B Ordering \(Modern Portal\)** check box is selected.

|
|**Visible Warehouses**|The warehouses available for selection in the following places in the portal:

 -   The **Item Details** dialog box of the [Catalog](SP_50_40_01.md) \(SP504001\) form
-   The [Cart](SP_50_40_03.md) \(SP5040033\) form

 Items can be delivered to customers from one or more warehouses selected in the drop-down list.

 You can select any number of warehouses. If only one warehouse is selected, a warehouse selector doesn’t appear on the [Catalog](SP_50_40_01.md) \(SP504001\) and [Cart](SP_50_40_03.md) \(SP504033\) forms; the selected warehouse is always used.

 This box appears only if both of the following conditions are met:

 -   On the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the *Inventory and Order Management* and *Multiple Warehouses* features are enabled.
-   On the **General** tab of the current form, the **B2B Ordering \(Modern Portal\)** check box is selected.

|
|**Default Stock Item Warehouse**|The warehouse shown by default for stock items in the **Item Details** dialog box of the [Catalog](SP_50_40_01.md) \(SP504001\) form of the portal.

 This box appears only if both of the following conditions are met:

 -   On the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the *Inventory and Order Management* and *Multiple Warehouses* features are enabled.
-   On the **General** tab of the current form, the **B2B Ordering \(Modern Portal\)** check box is selected.

|
|**Default Non-Stock Item Warehouse**|The warehouse shown by default for non-stock items in the **Item Details** dialog box of the [Catalog](SP_50_40_01.md) \(SP504001\) form of the portal.

 This box appears only if both of the following conditions are met:

 -   On the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the *Inventory and Order Management* and *Multiple Warehouses* features are enabled.
-   On the **General** tab of the current form, the **B2B Ordering \(Modern Portal\)** check box is selected.

|
|**Show Available Quantities**|A check box that you select \(the default state\) to display the available quantity of a stock item on the [Catalog](SP_50_40_01.md) \(SP504001\) and [Cart](SP_50_40_03.md) \(SP504003\) forms of the portal. This quantity is shown after *In Stock:*, such as *In Stock: 256*. This information can help users make informed buying decisions. When the check box is selected, the system shows the available quantity in the selected warehouse if warehouse selection is available.

 If the check box is cleared, the availability of a stock item is reflected only by its status: *In Stock* or *Out of Stock*. \(The available quantity isn’t shown.\) Portal users can order out-of-stock items; they’ll be shipped once they’re in stock.

 This box appears only if both of the following conditions are met:

 -   On the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the *Inventory and Order Management* feature is enabled.
-   On the **General** tab of the current form, the **B2B Ordering \(Modern Portal\)** check box is selected.

|
|**Allow Only Sales Unit for Purchase**|A check box that you select to restrict item selection to the sales UOM in the **Item Details** dialog box of the [Catalog](SP_50_40_01.md) \(SP504001\) form of the portal. By default, the check box is selected, so the **Unit** box displays the sales UOM and is unavailable for all items.

 This box appears only if both of the following conditions are met:

 -   On the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the *Inventory and Order Management* feature is enabled.
-   On the **General** tab of the current form, the **B2B Ordering \(Modern Portal\)** check box is selected.

|

|Element|Description|
|-------|-----------|
|**Address Lookup Plug-In**|The plug-in that validates and auto-fills address information in the portal by connecting to an external address verification service. It helps ensure that portal users enter accurate and complete addresses by suggesting or completing values based on partial input.|

|Element|Description|
|-------|-----------|
|**Default Case Class**|The case class assigned by default to cases created in the portal. A case class groups cases with similar characteristics and supplies default values for boxes.|
|**Case Notification Template**|The email template that is used for notifying users about support case updates processed in Acumatica ERP.|
|**Default Contact Class**|The contact class assigned by default to contacts created in the portal. A contact class groups contacts with similar characteristics and provides default values for boxes on the [Company Contact](SP_20_10_20.md) \(SP201020\) form of the portal.|

|Element|Description|
|-------|-----------|
|**Processing Center**|The payment gateway or external provider that authorizes and processes electronic payments initiated in the portal. It handles credit card transactions and returns results to Acumatica ERP for further financial processing and recordkeeping.|
|**Default CC Payment Method**|The default credit card payment method used for the payments customers create in the portal.|
|**Default CC Cash Account**|The default cash account used for processing customers’ credit card payments in the portal.|
