# Application Resources

Form ID: \(SM301010\)

You can use this form to create a page for external application resources \(for example, Microsoft Power BI reports\) or to edit the settings of an existing page that displays resources. Before adding a resource in Acumatica ERP, you should set up integration with the external application that contains this resource on the [External Applications](SM_30_10_00.md) \(SM301000\) form. For more information, see [Integration with External Applications](SM__con_Integration_External_Applications.md).

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**View Resource**|Displays the Acumatica ERP page with the external application resource selected on the form. You can click this button before selecting a site map location to see how the resource looks in Acumatica ERP.|
|**Publish to the UI**|Opens the **Publish to the UI** dialog box, in which you can modify the site map title and screen ID for the resource, change default workspace and category, and specify access right.|
|**Unpublish**|Removes the respective node from the site map, clears the assignment of screen identifier and deletes all configured access rights from the database.|

## User Roles Table

The table contains the full list of user roles in the system. This list appears after you select a site map location and save your changes. In this table, you can manage access rights of user roles to the resource page in Acumatica ERP.

The table toolbar has only standard buttons.

</th></tr></thead><tbody><tr><td>

**Access Rights**

</td><td>

The access rights level of the user role for the selected resource. You can select one of the following access right levels:

 -   *Revoked*: Denies the role access to the resource page; for users with the role, the resource page does not appear on the screen.
-   *Granted*: Allows the role access to the resource page.
