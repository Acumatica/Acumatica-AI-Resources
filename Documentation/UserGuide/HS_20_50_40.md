# HubSpot Sync State {#_da082bd9-852d-4f50-8e57-f4e4a6e34894 .reference}

Form ID: \(HS205040\)

You use this form to review information about the current status of data synchronization between HubSpot and Acumatica ERP. Also, on this form, you can start the synchronization process for particular records in the table or for all listed records.

This form is available in the system only if the *HubSpot Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Sync**|Initiates the synchronization process for the records that you have selected in the table.|
|**Sync All**|Initiates the synchronization process for all records listed in the table.|
|**Reset Sync**|Removes the synchronization records for which the unlabeled Included check box is selected in the table.

 Acumatica ERP treats a reset record as a record whose data has not been modified or synchronized with HubSpot. Thus, after you click this button, the records that were selected are excluded from the list on this form.

|

## Selection Area { .section}

You use the elements in this area to specify selection criteria for the records to be displayed in the table.

|Element|Description|
|-------|-----------|
|**Entity**|The entity type of the records to be listed in the table. The following options are available: *All* \(default\), *Business Account*, *Contact*, *Lead*, and *Marketing List*. If you select any of these options except *All*, the table will include only records with the selected value in the **Entity** column \(if they meet other selection criteria\).|
|**Status**|The status of the records that you want to be listed in the table. The following options are available:-   *Any* \(default\): All modified records are listed in the table regardless of their status.
-   *Pending Sync*: Only records pending synchronization are listed in the table \(that is, those with the *Pending Sync* status\).
-   *Synchronized*: Only records whose data has been synchronized are listed in the table \(that is, those with the *Synchronized* status\).
-   *Skipped*: Only those records are listed in the table that have been skipped during the latest synchronization process because they meet the source or target restrictions specified for the related integration scenario. That is, only those records with the *Skipped* status are listed in the table.

|
|**Errors Only**|A check box that indicates \(if selected\) that the table will include only the records that failed to synchronize during the latest attempt because of some error. If this check box is selected, the table will include only records with a value in the **Error** column \(if they meet other selection criteria\). By default, the check box is selected.|

## Table { .section}

The records listed in this table represent particular records of entity types that are synchronized with HubSpot—that is, particular business accounts, contacts, leads, or marketing lists. The table lists only the records that meet the selection criteria you have specified.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include this record if you click **Sync** on the form toolbar.|
|**Entity**|The Acumatica ERP entity that is synchronized with HubSpot, which is one of the following options: *Business Account*, *Contact*, *Lead*, or *Marketing List*.|
|**Document**|The display name of the entity, which is a link to the synchronized Acumatica ERP entity. If you click the link, the system opens the entity record on the appropriate form in a new browser tab.|
|**Modified**|The date and time when the record data was modified in Acumatica ERP.|
|**Ext. Ref.**|The external reference number of the corresponding record in HubSpot, which is a link to the synchronized record in HubSpot. If you click the link, the system opens the HubSpot record in a new tab.**Note:** To view data in the column, it is required that you set the **PortalID** parameter on the [Data Providers](SM_20_60_15.md) \(SM206015\) form for the instance.

|
|**Ext. Modified**|The date and time when the data of this record was modified in HubSpot.|
|**Status**|The current status of the synchronization record.|
|**Last Modified In**|The system where the data was last modified \(Acumatica ERP or HubSpot\).|
|**Last Operation**|The type of operation that modified the data of this record. The following options are available: *Update*, *Delete*, and *Insert*.**Note:** If a synchronized record has been deleted on the HubSpot server, the record will not be deleted in Acumatica ERP when it is synchronized.

|
|**Error**|The error message displayed for this record if synchronization has failed.|
