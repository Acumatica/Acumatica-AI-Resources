# Service Order History {#_845b4f89-1294-4d19-b515-e07466b60b03 .reference}

Form ID: \(FS400300\)

On this form, you can see the service orders registered in the system and their details.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

You can use the elements in this area to view in the table the service orders that are most relevant to the information you need. Most of these boxes can be left blank to view a broader range of information.

|Element|Description|
|-------|-----------|
|**Branch**|The branch for which you want to view service orders.|
|**Branch Location**|The branch location for which you want to view service orders.|
|**Customer**|The unique identifier of the customer for whom you want to view service orders.

 The list of customers available for selection may be limited based on the role or roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. In this case, the **Restrict Visibility To** box appears on the **Financial** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form. With the feature enabled, a customer is available for selection if one of the following is true:

-   The **Restrict Visibility To** box is empty for the customer—that is, the customer’s visibility is not restricted.
-   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer, and your user account has the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.

|
|**Location**|The unique identifier of the customer location for which you want to view service orders.|
|**Source Service Contract ID**|The unique identifier of the service contract for which you want to view service orders.|
|**Source Schedule ID**|The reference number of the schedule for the service contract for which you want to view service orders.|
|**From Date**|The start date for which you want to view data. By default the first date of the current month is selected.|
|**To Date**|The end date for which you want to view data. By default the last date of the current month is selected.|

## Table { .section}

This table displays the service order summary data according to the criteria you have specified in the Selection area.

|Element|Description|
|-------|-----------|
|**Branch ID**|The branch that provided the services.|
|**Branch Location ID**|The branch location that provided the services.|
|**Service Order Type**|The type of the service order.|
|**Service Order Nbr.**|The number of the service order.|
|**Description**|A description of the service order.|
|**Customer ID**|The unique identifier of the customer that ordered the service.|
|**Location ID**|The unique identifier of the customer location where the appointment takes place.|
|**Date**|The date when the service order document was created.|
|**Status**|The status of the service order, which is one of the following options: -   *Open*: The service order has been created but has not yet occurred.
-   *Completed*: All the activities related to the service order have been completed.
-   *On Hold*: The service order is on hold for a time; therefore,the service order will not be completed.
-   *Canceled*: The service order has been canceled.
-   *Closed*: All the administrative activities related to the service order have been completed.
-   *Quote*: The service order is a quote; therefore, it is not ready to be performed and cannot have an assigned appointment.

|
|**Appointments Needed**|A check box that indicates \(if selected\) that a new or follow-up appointment needs to be created for the service order.|
|**Workflow Stage ID**|The identifier of the current workflow stage of the service order.|
|**Estimated Duration**|The total estimated time that the service is expected to last.|
|**Appointment Duration**|The actual time of performing the appointments to which the service is related.|
|**Estimated Total**|The total amount estimated for the service order.|
|**Appointment Total**|The total amount defined during the appointments.|
|**Document Type**|The source where the service order was created, which is one of the following: -   *FS Order*: The service order was created on the [Service Orders](FS_30_01_00.md) \(FS300100\) form, was created from a quote, or was generated when a new appointment was created on the [Appointments](FS_30_02_00.md) \(FS300200\) form.
-   *SO Order*: The service order was created from a sales order on the [Sales Orders](SO_30_10_00.md) \(SO301000\) form.
-   *Case*: The service order was created from a case on the [Cases](CR_30_60_00.md) \(CR306000\) form.
-   *Opportunities*: The service order was created from a case on the [Opportunities](CR_30_40_00.md) \(CR304000\) form.

|
|**Billing Cycle ID**|The identifier of the billing cycle assigned to the customer who ordered these services.|
|**Source Service Contract ID**|The identifier of the service contract for which the service order has been generated from its schedule.|
|**Service Contract**|The service contract for which the service order has been created on the fly.|
|**Project Description**|The description of the project related to the service order.

 This column appears on the form only if the*Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 **Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Project ID**|The identifier of the project related to the service order.

 This column appears on the form only if the*Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 **Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Task Description**|The description of the project task that is assigned to the service order.

 This column appears on the form only if the*Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 **Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Task ID**|The identifier of the project task that is assigned to the service order.

 This column appears on the form only if the*Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 **Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Promised Date**|The date when the service order is planned to be fulfilled.

 **Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**SLA**|The latest date when the service order can be completed according to service-level agreements.

 **Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
