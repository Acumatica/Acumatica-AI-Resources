# Workflow Stages {#_6e55096e-7c68-42c0-adb9-99e23bf586c9 .reference}

Form ID: \(FS202100\)

**Important:** Starting with Acumatica ERP 2024 R2, the settings defined for the workflow stages of a specific service order type on this form are no longer supported. These settings remain available for reference only, to assist users in migrating to the new workflow.

You can use this form to create a workflow for a particular service order type. Each workflow consists of stages that represent a step in processing a service order of a particular type. For the service order type, you can specify the operations \(on appointments and service orders related to the type\) that will not be allowed during each workflow stage.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

In this area, you can select the service order type whose workflow stages you want to view, add, edit, or remove.

|Element|Description|
|-------|-----------|
|**Service Order Type**|The unique identifier of the service order type whose workflow stages you want to modify or create.|

## Workflow Stages Pane { .section}

In this pane, the existing workflow stages are represented as nodes of the selected service order type. You can click a node icon to the left of any workflow and view the hierarchical structure of the workflow stage. Some workflows have a one-level list of stages, while others have multiple levels. Click a node to view the settings of the workflow stages in the Stages table.

|Button|Description|
|------|-----------|
|**Up**|Moves the selected node \(that is, the workflow stage in the table row you have clicked\) one position up in the list.|
|**Down**|Moves the selected node \(that is, the workflow stage in the table row you have clicked\) one position down in the list.|

|Column|Description|
|------|-----------|
|**Workflow Stage ID**|The identifier of the workflow stage.|
|**Allow Complete**|A check box that indicates \(if selected\) that during this stage, the appointment or service order associated with the service order type can be completed.|
|**Allow Cancel**|A check box that indicates \(if selected\) that during this stage, the appointment or service order associated with the service order type can be canceled.|
|**Allow Reopen**|A check box that indicates \(if selected\) that during this stage, the appointment or service order associated with the service order type can be reopened.|
|**Allow Close**|A check box that indicates \(if selected\) that during this stage, the appointment or service order associated with the service order type can be closed.|
|**Allow Update**|A check box that indicates \(if selected\) that during this stage, the appointment or service order associated with the service order type can be updated.|
|**Allow Delete**|A check box that indicates \(if selected\) that during this stage, the appointment or service order associated with the service order type can be deleted.|
|**Description**|A description of the workflow stage. The description is entered by the user.|
