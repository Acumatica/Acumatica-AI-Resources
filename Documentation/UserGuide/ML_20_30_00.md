# LLM System Instructions {#_3d25cb73-49e7-405f-93c4-ef96c9299930 .reference}

Form ID: \(ML203000\)

You use this form to create reusable system instructions, which can help centralize security, safety, and governance guidance for your prompts.

You define template instructions once and make them available to prompt engineers, who can then insert and adapt the text directly in their LLM prompts. This approach promotes consistent AI behavior, supports compliance efforts, and speeds up prompt creation across the system.

This form is available only if the *AI Automation* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

For details, see [Integration with LLM Providers: Use of System Instructions](LLM_Providers_System_Prompts.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

This area contains the basic settings of a set of system instructions.

|Element|Description|
|-------|-----------|
|**Instruction Name**|Required. The name of the set of system instructions.|
|**Description**|Required. The description of the set of system instructions.|
|**Active**|A check box that you select to make the set of system instructions active and to make it available for selection on the [LLM Prompts](ML_20_20_00.md) \(ML202000\) form. By default, it’s cleared for a new set.

 You can select this check box for multiple sets of instructions.

|
|**Default**|A check box that you select to indicate that the set of system instruction is a default one, meaning that it will be added to each new prompt created on the [LLM Prompts](ML_20_20_00.md) \(ML202000\) form. By default, it’s cleared for a new set.

 You can select this check box for multiple sets of instructions. Adding new default instructions does not affect the existing prompts. If there are multiple default instructions, the system inserts all of them into the prompt.

|

## Instruction Section {#2 .section}

On this tab, you enter the text of a set of instructions in the text area.

By default, the text area contains the **\#\# System Instruction** section header. You can add your own sections \(for example, **Safety instructions**, **Security instructions**, or **General instructions**.

The section toolbar includes only standard buttons.
