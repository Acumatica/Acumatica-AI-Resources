# Agent System Instructions

Form ID: \(ML203000\)

You use this form to create reusable system instructions, which can help centralize security, safety, and governance guidance for your agents.

You define template instructions once and make them available to prompt engineers, who can then insert and adapt the text directly in their agents. This approach promotes consistent AI behavior, supports compliance efforts, and speeds up agent creation across the system.

The form contains the predefined *Execution-Rules* and *Data-Masking* instructions. The system adds the *Execution-Rules* instructions to each new agent on the [Agents](ML_20_20_00.md) \(ML202000\) form, after you select tools for this agent. It adds the *Data-Masking* instructions when you add masked fields to the agent.

**Attention:** We recommend that you keep the default instructions unless your testing confirms that the agent performs equally well without them.

This form is available only if the *AI Automation* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

For details, see [Integration with LLM Providers: Use of System Instructions](LLM_Providers_System_Prompts.md).

## Instruction Section

In this section, you enter the text of a set of instructions in the text area.

By default, the text area contains the **\#\# System Instruction** section header. You can add your own sections \(for example, **Safety instructions**, **Security instructions**, or **General instructions**.

The section toolbar includes only standard buttons.
