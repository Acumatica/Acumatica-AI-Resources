# Projects {#_63993445-4475-4b24-a6c0-c27095a136dd .concept}

The projects accounting functionality is available if the *Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. This functionality supports and automates the process of managing the organization's projects in four main areas:

-   Collecting the project-related transactions \(primarily expenses\) as they are processed in other Acumatica ERP areas
-   Billing the customers for work performed for projects
-   Allocating the costs, calculating the burdens, overheads, and billable amounts
-   Reporting

This part of the Project Accounting Guide contains all the information you need to configure and use the projects accounting functionality.
