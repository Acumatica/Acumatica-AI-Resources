# Commitment Details by Vendor {#_b062752c-beb7-4dca-948b-4d4c5b23bda1 .reference}

Form ID: \(PMGI0015\)

**Attention:** This form is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

The inquiry lists the detail lines of open project commitments \(purchase orders, project drop-ship orders, and subcontracts associated with projects\). You can filter the list of vendor commitment detail lines by using selection criteria. For instance, you can display only commitments associated with a specific project, vendor, inventory item, or date range \(or any combination of these criteria\).

## Table Toolbar {#section_lkm_nfz_tmb .section}

The table toolbar has only standard buttons.

## Selection Area {#Selection .section}

You use the elements in this area to specify the criteria of the vendor commitment detail lines you want to view.

|Element|Description|
|-------|-----------|
|**Start Date**|The start date of the period for which vendor commitments will be displayed. The start date of the current year is displayed by default.|
|**End Date**|The end date of the period for which vendor commitments will be displayed. The end date of the current year is displayed by default.|
|**Vendor**|The vendor, by its ID, for which documents will be displayed.|
|**Inventory ID**|The inventory item for which you want to review commitments. If you want to see commitment detail lines associated with all items, leave this box blank.|
|**Project**|The identifier of the project whose vendor commitment detail lines you want to view.|

## Table {#section_hd4_yfz_tmb .section}

The table shows the list of lines of subcontracts and purchase orders that match the criteria specified in the Selection area. The table on each tab has the following columns.

|Column|Description|
|------|-----------|
|**Vendor ID**|The ID of the vendor.|
|**Vendor Name**|The vendor name as it appears on the documents.|
|**PO/Subcontract No**|The reference number of the purchase order, project drop-ship order, or subcontract.|
|**Description**|The description of the purchase order, project drop-ship order, or subcontract.|
|**Line No**|The number of the line in the purchase order, project drop-ship order, or subcontract.|
|**Line Type**|The type of the line in the purchase order, project drop-ship order, or subcontract.|
|**Status**|The status of the purchase order, project drop-ship order, or subcontract.|
|**Account Group/Item**|The account group or inventory item specified in the purchase order, project drop-ship order, or subcontract line.|
|**Project**|The unique identifier of the project.|
|**Cost Code**|The cost code specified in the purchase order, project drop-ship order, or subcontract line.

 The column appears if the *Cost Code* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Order Qty.**|The quantity of the item that has been ordered.|
|**Open Qty.**|The open quantity of the purchase order, project drop-ship order, or subcontract line.|
|**Line Total**|The total amount of the purchase order, project drop-ship order, or subcontract line.|
