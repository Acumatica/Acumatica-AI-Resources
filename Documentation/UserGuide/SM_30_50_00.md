# Teams Channels {#_60176df2-02f0-42e1-bec0-85906e04e135 .reference}

Form ID: \(SM305000\)

You use this form to display teams and channels available in Microsoft Teams, and to specify webhooks for the channels.

This form is available in the system only if the *Teams Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Delete All**|Deletes all teams and channels from the form, and deletes all Teams members from the [Teams Members](SM_30_50_30.md) \(SM305030\) form. You invoke this button if you are no longer using the integration.|
|**Synchronize**|Starts the process of loading the list of teams, channels, and Teams members from Microsoft Teams to this form and the [Teams Members](SM_30_50_30.md) \(SM305030\) form.

 **Tip:** This process can take several minutes.

|

## Teams Pane {#2 .section}

This pane displays all teams available in Microsoft Teams.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that the team is active in Acumatica ERP.

 This check box is selected by default. You clear this check box for a channel if you do not want to send messages to it.

|
|**Picture**|Read-only. The image that is used for the team in Microsoft Teams.|
|**Team**|Read-only. The name of the team in Microsoft Teams.|
|**Description**|Read-only. The description of the team in Microsoft Teams.|

## Channels Pane { .section}

This pane displays the channels of the team that you have selected on the **Teams** pane by clicking its row.

|Button|Description|
|------|-----------|
|**Test Notification**|Sends a notification to the channel selected on the pane so that you can test this functionality.|

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that the channel is active in Acumatica ERP.|
|**Channel**|Read-only. The name of the channel in Microsoft Teams.|
|**Incoming Webhook URL**|The URL of the incoming webhook that is used to establish the connection between Microsoft Teams and Acumatica ERP.

 You must specify this URL if you want to send notifications to the channel.

 You configure a webhook for the channel in Microsoft Teams and then specify its URL in this column. For details, see [To Configure Acumatica ERP for Teams Integration](US__HOW_Teams_Integration_Configuring_Teams_Features.md).

|
