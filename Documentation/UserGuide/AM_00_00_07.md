# Work Center Dispatch {#_8ad69ba9-65fd-4d19-9818-d5783afec874 .reference}

Form ID: \(AM000007\)

This form lists the production orders that require operations in work centers.

## Form Toolbar {#_0c81e889-4c4d-4855-abcf-39373baa99fb .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

In this area, you can specify the criteria for production orders to be displayed in the table below.

|Element|Description|
|-------|-----------|
|**Work Center**|The work center for which information is displayed in the table. In this box, you can select a particular work center to view information only for this work center or leave this box blank to view information for all work centers.|
|**Order Type**|The type of a production order for which information is displayed in the table. In this box, you can select a particular order type to view information only for orders of this type or leave this box blank to view information for all order types.|

## Table { .section}

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Work Center**|The work center specified in the production order.|
|**Order Type**|The type of the production order.|
|**Production Nbr.**|The number of the production order.|
|**Status**|The status of the production order.|
|**Operation ID**|The identifier of the operation in the production order.|
|**Order Description**|The operation description.|
|**Qty. to Produce**|The quantity to produce at the operation.|
|**Qty. Complete**|The quantity completed to date at the operation.|
|**Qty. Scrapped**|The quantity scrapped if any at the operation.|
|**Start Date**|The start date of the operation.|
|**End Date**|The end date of the operation.|
|**Inventory ID**|The identifier of the item being manufactured.|
|**Description**|The description of the inventory item.|
|**Subitem**|The subitem of the item specified in the **Inventory ID** box.

 This column is visible only if the *Inventory Subitems* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

**Important:** The **Inventory Subitems** check box has been removed from the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form because the functionality associated with the *Inventory Subitems* feature will be phased out. If you have this feature enabled in your system, the associated functionality remains available. To disable the feature, contact your Acumatica support provider.

|
|**SO Order Nbr.**|The number of the sales order if the production order was created for the sales order.|
|**Customer ID**|The customer specified in the sales order displayed in the **SO Order Nbr.** box|
|**Customer Name**|The customer name.|
|**Dispatch Priority**|The operation priority.|
|**Control Point**|A check box that indicates \(if selected\) that the operation is a control point. If it is, for this operation, workers must record the quantity of completed items.|
|**Branch**|The branch with which the production order is associated.

 This column is displayed only when the *Multibranch Support* feature or the *Multicompany Support* feature is enabled \(or both features are enabled\) on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

|
