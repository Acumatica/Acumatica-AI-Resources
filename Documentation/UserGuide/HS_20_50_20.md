# HubSpot Sync {#_28c4f726-491e-47b5-835d-66dc73a8c040 .reference}

Form ID: \(HS205020\)

You use this form to add rows and specify their settings, to configure real-time data synchronization between Acumatica ERP and HubSpot for entities of particular types or for all entities that can be synchronized.

This form is available in the system only if the *HubSpot Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Table { .section}

You use this table to select the types of entities whose data you want to synchronize between Acumatica ERP and HubSpot.

|Button|Description|
|------|-----------|
|**Save**|Saves the changes made to the entity.|

|Column|Description|
|------|-----------|
|**Entity**|The type of entity for which you can initiate or stop the real-time synchronization process, which is one of the following:-   *Business Account*: In Acumatica ERP, entities of this type are created and edited on the [Business Accounts](CR_30_30_00.md) \(CR303000\) form.
-   *Contact*: In Acumatica ERP, entities of this type are created and edited on the [Contacts](CR_30_20_00.md) \(CR302000\) form.
-   *Marketing List*: In Acumatica ERP, entities of this type are created and edited on the [Marketing Lists](CR_20_40_00.md) \(CR204000\) form.
-   *Lead*

|
|**Import Scenario**|The import scenario to be used for real-time synchronization of records of the selected entity type. In this column, you can select any scenario that has been created on the [Import Scenarios](SM_20_60_25.md) \(SM206025\) form.|
|**Export Scenario**|The export scenario to be used for real-time synchronization of records of the selected entity type. In this column, you can select any scenario that has been created on the [Export Scenarios](SM_20_70_25.md) \(SM207025\) form.|
|**Number of Attempts**|The number of synchronization attempts that will be made each time a process is run.|
|**Polling Period, Sec.**|The time interval the system uses to check whether there are any data changes on the HubSpot server.**Tip:** If web hook notifications are not configured \(or it is not possible to configure web hooks, as might be the case, for example, if the server is protected with a firewall\), then setting a polling period in the **Polling Period, sec** column is the only option to receive notifications about HubSpot data changes.

|
|**Master Source**|The master source to be used if there are any conflicts between the data in the two sources. While the system is performing synchronization, if there are changes both in HubSpot and in Acumatica ERP for a record of this entity type, the system checks whether HubSpot or Acumatica ERP is set as master in this column and applies the changes from the master source.|
|**Latest Failed &amp; Missed Data Resync Attempt**|The date of the most recent attempt to synchronize the records of the selected type that were previously missed or failed to synchronize.

 The value of this column is updated automatically on a resynchronization attempt. You can change this date to set or reset the timespan of the synchronization.

|
|**Latest Full Data Resync Attempt**|The date of the latest attempt to resynchronize all records of the selected type.

 The value of this column is updated automatically on a resynchronization attempt. You can change this date to set or reset the timespan of the synchronization.

|
