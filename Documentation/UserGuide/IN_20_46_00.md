# Warehouse Planning Strategies

Form ID: \(IN204600\)

**Attention:** This form is available only if the *Warehouse Planning Strategies* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this form to create and edit picking strategies. A *picking strategy* is a rule that matches units of handling to warehouse zones. It tells the system which locations to search for pallets, cases, and base units and in which order when you create a shipment. The system applies the lines of a strategy in the order in which they are listed, so the order of the lines determines the sequence in which the zones are searched.

The form toolbar has only standard buttons.

## Details Tab

This table contains lines for the warehouse zone–handling unit pairs that make up the picking strategy. When you create a shipment for an item to which the strategy is assigned, the system applies the lines in the order in which they are listed in the table. You can change this order by dragging a line to a new position; the system updates the **Priority** column accordingly. Each pair of a unit of handling and a warehouse zone can be added to the picking strategy only once.

You can add lines to this table only if a warehouse is selected in the Summary area.

The table toolbar has only standard buttons.

**Priority**

</td><td>

The order in which the system uses this line when it plans picking locations during shipment creation. The system assigns this number based on the position of the line in the table.

</td></tr><tr><td>

**Unit of Handling**

</td><td>

The physical packaging type that the system looks for in the locations of the warehouse zone specified in this line. The column contains one of the following options:

 -   *Pallet*: The unit of measure is handled as a pallet load.
-   *Case*: The unit of measure is handled as a case or carton.
-   *Base*: The unit of measure is handled as an individual package.
-   *None*: The unit of handling is not defined.

</td></tr><tr><td>

**Warehouse Zone**

</td><td>

The warehouse zone whose locations the system searches for the unit of handling specified in this line. Only the zones of the warehouse selected in the Summary area are available for selection.

 If the selected zone has subzones, the system also searches the locations of all the zones below it in the hierarchy.

</td></tr></tbody>
</table>
