# Wiki Articles by Status {#_f8a19041-63c7-457e-bc71-d5f3cf1f51fd .reference}

Form ID: \(SM652500\)

This report lists all articles of the selected wiki created by the selected user. Also, you can select articles by their status and language.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Wiki**: The wiki from which articles should be selected; leave the box blank to view the data for all the wikis.
-   **Status**: The status of the articles you want to view; leave the box blank to view articles with all statuses.
-   **Created By**: The user who created the articles you want to view; leave the box blank to view articles created by all users.
-   **Language**: The language of the articles you want to view; a language must be selected.
