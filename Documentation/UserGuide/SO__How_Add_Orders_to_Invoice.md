# To Add Sales Orders to an Invoice {#_19ec5453-33e2-4cb6-9fc5-10dff52711f2 .task}

You can create an invoice manually on the [Invoices](SO_30_30_00.md) \(SO303000\) form, and add to it the lines of one sales order or multiple sales orders of the same customer.

## To Add Sales Orders to Invoice { .section}

1.  Open the [Invoices](SO_30_30_00.md) \(SO303000\) form.
2.  In the **Type** box in the Summary area, select *Invoice*.
3.  Select the customer in the **Customer** box.
4.  In the **Date** box, specify the date on which the invoice should be prepared.
5.  On the **Details** tab, add the lines of each order to be invoiced as follows:
    1.  Click **Add Order** on the table toolbar. The **Add Order** dialog box appears.
    2.  Select the unlabeled check boxes in the rows of the orders to be added to the invoice.
    3.  Click **Add &amp; Close** at the bottom of the dialog box.
6.  Save the invoice.
