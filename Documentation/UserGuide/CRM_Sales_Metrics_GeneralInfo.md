# Opportunity Reports: General Information {#_c8124aa2-7d8e-4d66-bc53-7f8351abf012 .concept}

In Acumatica ERP, you can use several reports to analyze opportunity-related sales metrics, such as the distribution of opportunities between stages, salespeople, and estimated close dates.

## Learning Objectives { .section}

In this chapter, you will do the following:

-   Learn about types of opportunity metrics and reports that can be used for sales analysis
-   Become familiar with the opportunity metrics

## Applicable Scenarios { .section}

You may want to learn how to use the opportunity metrics in Acumatica ERP in scenarios that include the following:

-   You need to analyze how many opportunities are estimated to be closed as won in the specific month for the company in total.
-   You need to analyze how many of opportunities for each salesperson are estimated to be closed as won in the selected period of time.

## Opportunity Reports {#section_mqv_cyk_hwb .section}

Acumatica ERP provides the following reports, which have been designed as generic inquiries form and pivot tables for sales personnel to monitor multiple opportunity data and metrics, and track sales goals:

-   [Opportunity Summary by Close Date](CR_30_40_SM.md) \(СR3040SM\)
-   Opportunity Summary by Salesperson \(CR3041SM\)
-   Opportunity List \(CR3042SM\)
-   Opportunity Summary by Class \(CR3040PT\)

For more information about the use of these reports to analyze opportunity metrics, see [Opportunity Reports: Opportunity Estimation](CRM_Sales_Metrics_Opporunities_by_Close_Date.md).

## Flexible Use of Opportunity Reports {#section_nqv_cyk_hwb .section}

The opportunity reports are displayed on generic inquiry forms and a pivot table. You can filter data by any column in a pivot table depending on the information that you would like to view, and configure dashboards that show opportunity metrics.

If needed, a user with the *Administrator* role can make changes to these generic inquiry forms and pivot tables, as well as build other pivot tables to be used as filter tabs of these generic inquiry forms. This user can also create new generic inquiries and pivot tables to display opportunity metrics.
