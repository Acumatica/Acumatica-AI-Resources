# Project Tag Templates {#_e04231de-7a26-4e5f-9313-0075755565f3 .reference}

Form ID: \(PM204500\)

**Attention:** This form appears only if the *Document Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to create reusable tag hierarchies for projects. A tag template defines which tags are used by default and how they’re organized. When you assign a tag template to a project or project template, the system copies this tag hierarchy.

## Form Toolbar { .section}

The form toolbar includes the following button in addition to standard ones.

|Button|Description|
|------|-----------|
|**Copy**|Opens the **Copy Tag Template** dialog box, where you create a template by copying the currently one and specifying its settings \(such as the template ID and description\).|

|Element|Description|
|-------|-----------|
|**Template ID**|The identifier of the new template.|
|The dialog box has the following buttons.|
|**Copy**|Closes the dialog box, saves the copied template as a new one, and opens it on the current form.|
|**Cancel**|Cancels the changes and closes the dialog box.|

## Summary Area {#1 .section}

In this area, you can specify the identifier and description of the project tag template and activate or deactivate it.

|Element|Description|
|-------|-----------|
|**Template ID**|The identifier of the project tag template.|
|**Description**|The description of the template.|
|**Active**|A check box that indicates \(if selected\) that the template is active and can be used for project and project templates.|

## Left Pane: Tags { .section}

In this pane, you create tags under the **All Tags** top-level node, which appears when the tag template is saved. You can create a hierarchical or single-level structure.

## Tag Properties Section { .section}

In this section, you can view and edit the properties of the selected tag.

|Element|Description|
|-------|-----------|
|**Tag Name**|The name of the selected tag.|
|**Description**|The description of the selected tag.|
|**Parent Tag**|The parent tag of the selected tag in the hierarchy.|

## Access Rights Section { .section}

In this section, you can assign each user role’s access level to the selected tag. Users with the role have the specified level of access to files with this tag.

|Column|Description|
|------|-----------|
|**Role**|The name of the role.|
|**Guest Role**|A check box that indicates \(if selected\) that the role is a guest role.|
|**Description**|The role’s description.|
|**Access Rights**|Read-only. The access level, which determines what users with the role assigned can do with files that have the selected tag. One of the following options can be selected:

 -   *Revoked*: Users can't access the tag or its files.
-   *View Only*: Users can view and download files with the tag.
-   *Create Version \(Project Files\)*: Users can view, download, and check out files with the tag; they can also upload new versions.
-   *Upload \(Project Files\)*: Users can view, download, and check out files with the tag. They can also upload new files or versions and assign the tag.
-   *Delete \(Project Files\)*: Users can perform all actions permitted by the *Upload* role plus deleting files.

 **Attention:** If a file has multiple tags with different access levels, the system applies the most permissive level.

|
