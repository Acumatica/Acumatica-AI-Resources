# Route Document Details {#_b26fcf32-359a-4ef3-97e4-ab697fcfcdb1 .reference}

Form ID: \(FS304000\)

You use this form to create new route executions manually or edit existing ones. You can assign a driver and vehicle, create appointments, delete or move existing appointments, and adjust their sequence.

## Form Toolbar { .section}

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Calculate Route Statistics**|Recalculates the statistics of the route, which are displayed in the **Route Statistics** section of the Summary area, if you have made changes to the route. This button is available only if the **Calculate Route Statistics Automatically** check box is cleared on the **Routes** tab of the [Service Management Preferences](FS_10_01_00.md) \(FS100100\) form.

|
|**Cancel**|Changes the route execution status to *Canceled*. You can cancel routes with the *Open* or *In Process* status only. After you invoke this action, the route can now be reopened or closed.|
|**Complete**|Changes the status of the route execution to *Completed,* indicating that all the activities related to the route are completed. This action automatically completes all the appointments associated with the route if they have not been completed. After you invoke this action, the route can be reopened or closed.|
|**Delete**|Opens the **Confirm Delete Current Route** dialog box, in which you can confirm deleting the route executions document with all related appointments and service orders by clicking **YES**, or cancel deleting by clicking **NO**.|
|**Open Driver Calendar**|Opens the [Staff Calendar Board](FS_30_04_00.md) \(FS300400\) form for the driver assigned to execute the route.|
|**Open Route on Map**|Opens the [Routes on Map](FS_30_09_00.md) \(FS300900\) form, which displays the executed route on a map.|
|**Reopen**|Changes the route execution status to *Open*, which is the initial status. The route can now be started, canceled, or completed. This action is available only if the route has the *Completed* or *Canceled* status.|
|**Start**|Changes the status of the route execution to *In Process*, indicating that the route is being attended. This action is available only if the route has the *Open* status. After you invoke this action, you can process the route appointments and complete the route.|
|**Unclose**|Changes the status of the previously closed route execution to *Completed*. This action is available only if the route has the *Closed* status.|

## Summary Area { .section}

Here you can create a new route execution or select an existing route execution for modification. In this area, you can also view the general statistics of the route, as well as assign drivers or vehicles to the route.

|Element|Description|
|-------|-----------|
|**Route Nbr.**|The reference number of the route execution. When a new route execution is saved, the system generates this number based on the numbering sequence specified in the **Route Numbering Sequence** box on the [Service Management Preferences](FS_10_01_00.md) \(FS100100\) form.|
|**Status**|The current status of the route execution. The system updates this status based on user actions. It can be one of the following: -   *Open* \(default\): The route execution has been created but it has not been started yet. You can edit, start, complete, or cancel a route execution with this status.
-   *In Process*: The route execution has been started. You can edit, complete, reopen, or cancel this route execution.
-   *Canceled*: The route execution has been canceled. You can reopen the route execution.
-   *Completed*: All the activities related to the route execution have been completed. You can edit the details of the route execution , and you can close or reopen the route execution.
-   *Closed*: All the data of the route is filled in and correct. If needed, you can unclose the route execution.

|
|**Branch**|The identifier of the branch associated with the route execution.|
|**Route**|The identifier of the route to be executed.|
|**Trip Nbr.**|The trip number for the selected route on the specified date.|
|**Scheduled Start Date**|The date when the route is executed and the scheduled start time of the route execution. By default, this value comes from the route definition on the [Routes](FS_20_37_00.md) \(FS203700\) form.|
|**Driver**|The primary driver assigned to execute the route.|
|**Additional Driver**|The secondary driver assigned to the route, if the route requires multiple drivers.|
|**Vehicle**|The primary vehicle assigned to the route.|
|**Additional Vehicle 1**|The second vehicle assigned to the route if multiple vehicles are used.|
|**Additional Vehicle 2**|The third vehicle assigned to the route if multiple vehicles are used.|
|**Number of Appointments**|The number of appointments in the route.|
|**Total Services**|The total number of services that are performed during the appointments of the route.|
|**Total Distance \[\*\]**|The total estimated distance in miles of the route.|
|**Total Services Duration**|The total estimated time needed to perform the services of the route.|
|**Total Driving Duration \[\*\]**|The total estimated driving time needed to perform the route.|
|**Total Route Duration \[\*\]**|The total estimated time needed to perform the route. This is the sum of the duration times of the driving and services.|

|Element|Description|

## Appointments Tab { .section}

On this tab, you can view details about appointments related to the route execution, as well as change their order, reassign them, or delete them.

|Button|Description|
|------|-----------|
|**Add**|Opens the **Select Service Order Type for New Appointment** dialog box, where you select the type of an appointment to add and proceed to the [Appointments](FS_30_02_00.md) \(FS300200\) form to create the appointment.|
|**Unassign**|Opens the **Confirm Unassign Appointment** dialog box, where you can confirm the deletion of the selected appointment by clicking **Yes**, or cancel the deletion and close the dialog box by clicking **No**.|
|**Move Up**|Moves up the selected appointment within the route execution.|
|**Move Down**|Moves down the selected appointment within the route execution.|
|**Reassign**|Opens the **Route Appointment Assignment** dialog box, in which you can reassign the selected appointment to another route execution.|

|Column|Description|

|**Service Order Type**|The service order type of the appointment. Only appointments with service order types of the *Route* behavior can be selected here.|

|**Description**|A brief description of the appointment.|

## Additional Info Tab { .section}

On this tab, you can specify additional information about route, such as the distance traveled, the weight of goods transferred, and fuel information.

|Element|Description|
|-------|-----------|
|**Miles**|The total distance \(in miles\) of the route execution.|
|**Weight**|The weight of the transferred goods.|
|**Fuel Qty.**|The amount of fuel used during the execution of the route.|
|**Fuel Type**|The type of the fuel used by the vehicle during the execution of the route, which is one of the following options:-   *Regular Unleaded*
-   *Premium Unleaded*
-   *Diesel*
-   *Other*

|
|**Oil**|The amount of oil used during the execution of the route.|
|**Antifreeze**|The amount of antifreeze used during the execution of the route.|
|**DEF**|The amount of diesel exhaust fluid used during the execution of the route.|
|**Propane**|The amount of propane used during the execution of the route.|

|Element|Description|
|-------|-----------|
|**Actual Start Time**|The actual time when the route execution begins.|
|**Actual End Time**|The actual time when the route execution ends.|
|**Actual Duration**|The actual duration of the route execution, which the system calculates based on the actual start and end times.|

## Attributes Tab { .section}

On this tab, you can view the list of attributes for the route execution, specify the values of these attributes, and change these values, if necessary. This tab is populated with the list of active attributes \(and any default values\) that have been defined for the selected route on the **Attributes** tab of the [Routes](FS_20_37_00.md) \(FS203700\) form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Attribute**|The description of the attribute.|
|**Required**|A read-only check box that indicates \(if selected\) that a value must be specified for the attribute. This setting is copied from the **Attributes** tab of the [Routes](FS_20_37_00.md) \(FS203700\) form for the selected route.|
|**Value**|The value of the attribute. If the system has inserted a default value for the attribute, you can overwrite it, if necessary. The default value is defined on the **Attributes** tab of the [Routes](FS_20_37_00.md) \(FS203700\) form for the selected route.|

## Location Tab { .section}

On this tab, you can view the GPS coordinates of the start and end locations.

|Element|Description|
|-------|-----------|
|**Start Location**|Read-only. The latitude and the longitude of the start location address.|
|**End Location**|Read-only. The latitude and the longitude of the end location address.|
|The section has the following button.|
|**View on Map**|A button you can click to open the map and fill in the latitude and longitude.|
