# Accounts Payable Reports {#_937ead64-b973-4c31-bcd4-303ef8734c06 .concept}

With the wide variety of Acumatica ERP reports related to accounts payable, you can promptly get vital information, analyze financial data by various criteria, and review transactions efficiently. Some reports have both a standard version and a multicurrency \(MC\) version. If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All accounts payable reports can be generated in different formats, including PDFs, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
