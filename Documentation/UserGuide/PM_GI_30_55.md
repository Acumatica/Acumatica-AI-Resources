# Cost Projections by Date Report {#_4552f1f9-f7d5-4fe4-9026-02ff1bb3bc75 .reference}

Form ID: \(PMGI3055\)

You use this form to view the list of released cost projections for the particular projection date.

## Table Toolbar {#section_irs_cmk_32c .section}

The table toolbar has only standard buttons.

## Selection Area {#section_jrs_cmk_32c .section}

You can use the element in this area to narrow the range of cost projections to be displayed in the table.

|Element|Description|
|-------|-----------|
|**Actual to Date**|The projection date for which the latest released cost projections are shown.|

## Table {#section_krs_cmk_32c .section}

The table contains the list of cost projections for the selected date. The table has the following columns.

|Column|Description|
|------|-----------|
|**Owner**|The project manager of the project for which the cost projection has been released.|
|**Project ID**|The unique identifier of the project for which the cost projection has been released.|
|**Project Currency**|The currency of the project.|
|**Reference Nbr.**|The reference number of the last date-sensitive cost projection that has been prepared with a projection date that is earlier than or the same as the specified date.|
|**Projection Date**|The date that the system used to calculate the projected values in the cost projection.|
|**Projected Cost to Complete**|The total projected remainder of the budgeted cost of the project as calculated in the cost projection.|
|**Projected Cost at Completion**|The total projected final cost on project completion as calculated in the cost projection.|
|**Completed \(%\)**|The total projected percentage of completion in the cost projection.|
|**Revised Budgeted Cost**|The total revised amount of the cost budget lines of the project as calculated in the cost projection.|
|**Actual Cost to Date**|The total amount of released cost transactions related to the cost projection.|
|**Committed Open Cost**|The total amount of released project commitments related to the cost projection.|
|**Anticipated Cost**|The total anticipated cost calculated in the cost projection.|
|**Cost Budget Backlog**|The total amount of the revised budgeted costs of the project calculated in the cost projection.|
|**Performance \(%\)**|The total actual performance percentage of the project as calculated in the cost projection.|
|**Anticipated Performance \(%\)**|The projected performance percentage of the project as calculated in the cost projection.|
|**Revised Budget Revenue**|The total revised amount of the revenue budget lines of the project as calculated in the cost projection.|
|**Billed Revenue**|The total billed revenue amount of the project as calculated in the cost projection.|
|**Revenue Budget Backlog**|The revised budgeted amount for the revenue lines of the project as calculated in the cost projection.|
|**Expected Current Revenue**|The amount of the projected revenue of the project as calculated in the cost projection.|
|**Overbilling or Underbilling**|The overbilling or underbilling amount of the project calculated in the cost projection.|
|**Projected Margin**|The amount of the projected margin|
|**Projected Margin \(%\)**|The percentage of the projected margin.|
|**Pending CO Revenue**|The total pending amount of change orders for the revenue budget lines of the project.|
|**Pending CO Cost**|The total pending amount of unreleased change orders for the cost budget lines of the project.|
|**Pending CO Commitments**|The pending amount of change orders to the project commitments of the project.|
