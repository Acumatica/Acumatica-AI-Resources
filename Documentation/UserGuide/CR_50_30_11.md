# Assign Contacts {#_473cd925-4b0f-46bb-b75f-e742aa584b57 .reference}

Form ID: \(CR503011\)

On this form, you can perform mass assignment of unassigned contacts. For this assignment, the system uses the assignment map specified for contacts on the [Customer Management Preferences](CR_10_10_00.md) \(CR101000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the assignment process for the records that you have selected in the table.|
|**Process All**|Initiates the assignment process for all records listed in the table.|

## Table { .section}

This table contains the list of contacts that meet the conditions of the applied reusable filter \(if any\). If no filter is applied, all available contacts are listed.

|Column|Description|
|------|-----------|
|Selected|An unlabeled check box that you select to include the record in processing if you click **Process**.|
|**Contact**|The display name of the contact.|
|**Title**|The contact's courtesy title \(which is one of the following options: *Dr.*, *Miss*, *Mr.*, *Mrs.*, *Ms.*, or *Prof.*\).|
|**First Name**|The first name of the contact.|
|**Last Name**|The last name of the contact.|
|**Job Title**|The job title of the contact.|
|**Duplicate**|The duplicate validation status of the record.|
|**Business Account**|The business account that the contact is associated with \(if any\).|
|**Account Name**|The company name associated with the contact.|
|**Parent Business Account**|The customer account that the contact is associated with \(if any\).|
|**Parent Business Account Name**|The customer company name.|
|**Active**|A check box that indicates \(if selected\) that the contact is active.|
|**Status**|The status of the contact.

 This box contains one of the following options :

 -   *Active*: The contact is active, appears on all selection lists, and can be used in documents.
-   *Inactive*: The contact is inactive and cannot be used in documents.

|
|**Reason**|The reason the status of this contact has been changed.|
|**Contact Class**|The identifier of the contact class to which the contact belongs.|
|**Source**|The source of the contact.|
|**State Name**|The state of the contact.|
|**Country**|The country of the contact.|
|**City**|The city of the contact.|
|**Postal Code**|The postal code of the contact.|
|**Address Line 1**|The first line of the contact's address.|
|**Address Line 2**|The second line of the contact's address.|
|**Email**|The email address of the contact.|
|**Phone 1**|The primary phone number of the contact.|
|**Phone 2**|The secondary phone number of the contact.|
|**Phone 3**|Another phone number of the contact.|
|**Fax**|The fax number of the contact.|
|**Workgroup**|The workgroup for the contact.|
|**Owner**|The owner of the contact.|
|**Last Incoming Activity**|The date of the latest incoming activity that is associated with the contact.|
|**Last Outgoing Activity**|The date of the latest outgoing activity that is associated with the contact.|
|**Created On**|The date when the contact record was created.|
|**Last Modified On**|The date when the contact record was modified most recently.|
