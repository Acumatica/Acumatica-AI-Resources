# MPS Type {#_ebed96e6-5eab-4852-b8f7-6ac1b1237426 .reference}

Form ID: \(AM203000\)

Master production schedule \(MPS\) types are used to specify the default numbering sequence and the *dependent* state when you create master production schedule orders. **MPS Type** is a required field on the [Master Production Schedule](AM_20_10_00.md) \(AM201000\) form.

**Important:** This form is available only if the *Material Requirements Planning* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## MPS Types Table { .section}

|Column|Description|
|------|-----------|
|**Type ID**|This is the identifier of the type and can be up to 20 alphanumeric characters. You can specify the default MPS type on the [Inventory Planning Preferences](AM_10_00_00.md) \(AM100000\) form.|
|**Description**|A description of the type.|
|**Numbering Sequence**|The numbering sequence used by the system to generate identifiers of MPS orders assigned to this type.|
|**Dependent**|A check box that indicates \(if selected\) that the MPS quantities are consumed by real production orders; it means that the MPS order will be reduced by actual production orders that are scheduled to be completed prior to the MPS planning date. If the check box is cleared, the MPS quantities are independent of production.|
