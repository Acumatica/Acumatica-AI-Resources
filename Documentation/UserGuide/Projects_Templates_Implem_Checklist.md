# Project Templates and Common Tasks: Implementation Checklist {#_d14a0111-16a1-4385-a86e-d9aead34d4c0 .concept}

To ensure that the system is configured properly for creating project templates and common tasks, make sure that the features and settings listed in the table are configured as described in the following table.

|Form|Task to Perform|
|----|---------------|
|[Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form|Make sure that the **Projects** check box is selected.|
|[Projects Preferences](PM_10_10_00.md) \(PM101000\) form|Make sure that all necessary settings of project accounting have been specified.|
|[Account Groups](PM_20_10_00.md) \(PM201000\) form|Make sure that all the necessary account groups have been configured.|
