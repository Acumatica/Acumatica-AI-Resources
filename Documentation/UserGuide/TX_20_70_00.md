# Tax Periods

Form ID: \(TX207000\)

On this form, you can configure a tax year structure for each particular combination of the company and tax agency, review tax periods and their statuses for the current and past tax years, view net tax amounts for prepared and closed periods, and shorten the duration of a tax year.

<table id="table_zql_2qn_t1b"><thead><tr><th>

Command

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Prepare Tax Report**

</td><td>

Opens the [Prepare Tax Report](TX_50_10_00.md) \(TX501000\) form, where you prepare a tax report for the selected company and tax agency.

 The availability of this button depends on the state of the **File Taxes by Branch** check box specified for the selected company on the **Company Details** tab \(the **Tax Registration Info** section\) of the [Companies](https://help.acumatica.com/(W(1))/Wiki/ShowWiki.aspx?wikiname=HelpRoot_FormReference&PageID=fedad435-8496-4397-b8a3-50a473629f76) \(CS101500\) form:

-   Check box is **cleared:** The button is not available if there is a period with the *Prepared* status for the selected company and tax agency; if there is no *Prepared* period, the button is available.
-   Check box is **selected:** The button is always available.

</td></tr><tr><td>

**Release Tax Report**

</td><td>

Opens the [Release Tax Report](TX_50_20_00.md) \(TX502000\) form, where you release a tax report prepared for the selected company and tax agency.

 The button is not available if there is no period with the *Prepared* status for the selected company and tax agency. If there is a period with the *Prepared* status, the button is available.

</td></tr><tr><td>

**Synchronize Periods with GL**

</td><td>

Synchronizes the tax year structure with the company's financial year— which is specified on the [Master Financial Calendar](GL_20_10_00.md) \(GL201000\) form, or on the [Company Financial Calendar](GL_20_11_00.md) \(GL201100\) form if the *Multiple Calendar Support* feature is enabled—starting from the first open tax period: It deletes the existing tax periods and generates new tax periods for the year. If the next tax year has been generated and the end date of the selected tax year does not immediately precede the start date of the next tax year, the next tax year will be deleted upon confirmation.

 This command is available if *Financial Periods* is selected in the **Tax Period Type** box of the current form for the company specified in the **Company** box and the tax agency selected in the **Tax Agency** box.

 For details, see [Tax Periods: Synchronization with Financial Periods](../ImplementationGuide/Taxes_TaxPeriods_Synchronization_with_Financial_Periods.md).

</td></tr><tr><td>

**Tax Details**

</td><td>

Opens the [Tax Details](TX_62_05_00.md) \(TX620500\) report for the selected company, tax agency, and tax period.

</td></tr><tr><td>

**Tax Summary**

</td><td>

Opens the [Tax Summary](TX_62_10_00.md) \(TX621000\) report for the selected company, tax agency, and tax period.

</td></tr></tbody>
</table>

## Summary Area

In the Summary area, you can select a company, a tax agency, and various tax year settings to configure a tax year structure.

<table id="table_mqj_2nh_t1b"><thead><tr><th>

Element

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Company**

</td><td>

The company whose tax periods are shown in the table \(in respect of the selected tax agency\).

 This box appears on the form if the *Multicompany Support* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

</td></tr><tr><td>

**Tax Agency**

</td><td>

The tax agency whose tax periods are shown in the table \(in respect of the selected company\).

 If the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the list of values may be limited based on the company selected on the current form. A vendor is available for selection if the **Restrict Visibility To** box on the **Financial** tab of the [Vendors](AP_30_30_00.md) \(AP303000\) form is empty or contains this company, a branch of the company, or a company group that contains this branch.

 If the tax agency has the **CIS Tax Agency** check box selected on the [Vendors](AP_30_30_00.md) \(AP303000\) form:

 -   The **Tax Period Type** box is filled in with *Month* and is unavailable.
-   The system sets the **Start Date** box to the 6th of the first tax period.
-   The system sets the **Start Date** column in the table to the 6th of each tax period.
-   If no tax periods exist for the tax agency when you opens the [Submit CIS Return](AP_50_77_00.md) \(AP507700\) form, the system generates the tax periods of the tax year that includes the current business date. Thus you can prepare and submit a nil return without generating the tax periods manually on the current form.
-   The tax periods of a tax year remain available after the tax report for the first period of that year is voided.

</td></tr><tr><td>

**Tax Year**

</td><td>

The tax year for which tax periods are displayed in the table, which you select from the list of the years available for the selected company and tax agency. By default, the current tax year is selected.

 If no tax years exist in the system for the selected company and tax agency, by default, the system uses the tax year of the earliest taxable document. If no tax year and no taxable documents exist, the system uses the year of the current business date.

</td></tr><tr><td>

**Short Tax Year**

</td><td>

A check box that indicates \(if selected\) that the tax year is short. By default, this check box is cleared.

 If this check box is selected, the **Delete Period** and **Add Period** buttons become available on the table toolbar. This check box is available only if all tax periods of the tax year have the *Open* status.

</td></tr><tr><td>

**Start Date**

</td><td>

The first day of the tax year selected in the **Tax Year** box.

 This date is available for editing only if there are no tax years in the system for the selected company and tax agency. Otherwise, it is an informational setting.

</td></tr><tr><td>

**Tax Period Type**

</td><td>

The tax period type, which defines the tax period duration for the selected tax year. If you change the type of tax period in this box and save your changes, the system updates the list of tax periods in the table. The following options can be selected:

 -   *Half a Month*
-   *Month*
-   *Two Months*
-   *Quarter*
-   *Half a Year*
-   *Year*
-   *Financial Period*

 This setting is available for editing only if all of the periods of the selected tax year have the *Open* status.

 **Tip:** If you change the tax period type for a short tax year, the system will restore the length of the tax year to a full calendar year and will clear the **Short Tax Year** check box.

</td></tr></tbody>
</table>

## Table

This table contains the list of tax periods of the selected company, tax agency, and tax year.

<table id="table_z22_gnx_3p"><thead><tr><th>

Button

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**x** \(**Delete Period**\)

</td><td>

In the table, deletes the last period of the year if its status is *Open*.

 This button is available only if the **Short Tax Year** check box is selected in the Summary area of the current form.

</td></tr><tr><td>

**+** \(**Add Period**\)

</td><td>

In the table, adds a new tax period after the last one in the table.

 This button is available only if the **Short Tax Year** check box is selected in the Summary area of the current form.

</td></tr></tbody>
</table>

|Column|Description|
|------|-----------|
|**Tax Period**|The number of the tax period.|
|**Start Date**|The start date of the tax period.|
|**End Date**|The end date of the tax period.|
|**Status**|The current status of the tax period.|
|**Net Tax Amount**|The amount accumulated in the line for which the **Net Tax** check box is selected on the **Report Lines** tab of the [Reporting Settings](TX_20_51_00.md) \(TX205100\) form. When you click the amount, the system navigates to the [Tax Report Details](TX_50_20_10.md) \(TX502010\) form, which displays the data for the selected company, tax agency and tax period.|
