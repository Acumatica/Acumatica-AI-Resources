# Routes Pending for Closing {#_8f6b7fd4-45c2-4696-908b-7530d8266856 .reference}

Form ID: \(FS404000\)

You use this form to view the routes that have the *Completed* and *Closed* status.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

In this area, you can select a date to view only the routes for that specific day.

|Element|Description|
|-------|-----------|
|**Date**|The date of the routes to be displayed in the list. You can leave this box empty to view routes for all dates.|

## Table { .section}

In this table, you can view the list of routes that are completed or closed.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Route Nbr.**|The reference number of the route. You can click the link in this column to navigate to the [Route Document Details](FS_30_40_00.md) \(FS304000\) form, on which you can view and edit the details of the route, and close it.|
|**Route**|The identifier of the route definition.|
|**Route Short**|The short identifier of the route definition.|
|**Trip Nbr.**|The number of the trip in the related route execution for the specified date.|
|**Status**|The status of the route, which is one of the following: *Completed* or *Closed*.|
|**Scheduled Start Date**|The date when the route execution was performed.|
|**Start Time**|The start time of the route.|
|**Driver**|The assigned driver that performed the route.|
|**Additional Driver**|The second assigned driver that performed the route, if any.|
|**Vehicle**|The assigned vehicle that was used to perform the route.|
|**Number of Appointments**|The number of the appointment in the route.|
|**Total Services**|The total number of services performed during the appointments of the route.|
|**Total Driving Duration**|The total estimated driving time needed to perform the route.|
|**Total Service Duration**|The total estimated time needed to perform the services of the route.|
|**Total Route Duration**|The total estimated time needed to perform the route. This is the sum of the driving and service duration times.|
