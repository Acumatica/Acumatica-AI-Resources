# To Add Attributes to a Class

You can add user-defined attributes to a class. Every instance of this class will possess all class attributes. Do the following:

## To Add Attribute to a Class

1.  In your Acumatica ERP instance, navigate to the form of the class where you want to add an attribute \(for the list of class where it can be done, see [Attributes](CS__con_Attributes.md)\).
2.  On the form toolbar, in the box with the class type, select the class where you want to add the attribute.
3.  On the **Attributes** tab, on the table toolbar, click **Add Row**.
4.  In the **Attribute ID** column, select the attribute you want to add to the class.

    **Tip:** The same attribute can be used for multiple classes.

5.  If needed, select the **Required** column.
6.  If needed, in the **Sort Order** column, type the number for sorting.
7.  If needed, select the **Internal** column.
8.  Save your changes.

You have added an attribute to a class. All the entities of this class will possess this attribute.

**Tip:** If you need to delete an attribute from the class, first clear the **Active** check box for it, because an active attribute cannot be deleted. Deleting an attribute from a specific class does not delete this attribute from the system.
