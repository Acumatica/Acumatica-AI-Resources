# Marketing Categories

Form ID: \(CR305000\)

On this form, you can create or update marketing categories. These categories are used to categorize mass emails on the [Mass Emails](CR_30_80_00.md) \(CR308000\) form and to map categories with the SendGrid unsubscribe groups on the [SendGrid Connections](SG_20_50_00.md) \(SG205000\) form.

## Form Toolbar

The form toolbar has only standard buttons.

## Marketing Categories Table

This table contains the marketing categories defined in the system.

|Column|Description|
|------|-----------|
|**Marketing Category**|The unique identifier of the marketing category, which you enter manually for a new marketing category.|
|**Description**|The description of the marketing category.|
|**Active**|A check box that indicates \(if selected, the default state\) that the marketing category is active. Active marketing categories are available for selection on the [Mass Emails](CR_30_80_00.md) \(CR308000\) form.|
|**Channel**|Read-only. The communication channel. The only possible value is *Email*.|
