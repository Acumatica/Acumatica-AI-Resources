# Location Labels {#_3c81f2c4-9910-488f-b287-5460eb803294 .reference}

Form ID: \(IN619000\)

**Attention:** This report is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

This report displays the inventory labels for each warehouse, location, and primary item–primary item class combination. \(The primary item is the item that is issued or received the most often or stored at this location in the highest volumes.\) The report uses data from the **Locations** tab of the [Warehouses](IN_20_40_00.md) \(IN204000\) form. You can use this report to preview and print the location labels for a warehouse or all warehouses.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameter to select the information to be displayed on the report:

-   **Warehouse**: The warehouse the report will cover. Select a warehouse to display and print only the labels for it, or leave the box blank to display and print labels for all warehouses.
