# Production Order View {#_9f100693-8c5d-4f60-894b-27491dcb36d7 .reference}

Form ID: \(AM215580\)

**Attention:** This form is available only if the *Advanced Planning and Scheduling* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This form provides a graphical overview of material and scheduling statuses at every level of the production process—from top-level orders to subassemblies.

For additional information about this form and its use, see [Advanced Planning and Scheduling: Production Order View](MFG_APS_Production_Order_View.md).

## Form Toolbar { .section}

The toolbar includes the buttons described below.

|Element|Description|
|-------|-----------|
|**Refresh**|A button that reloads the list to reflect the latest data.|
|**Search**|A search box with an icon that opens the [Production Orders](#_e36e1051-0cb9-443f-bde8-e71166ab6467) dialog box where you can select a particular order whose data you want to view.|
|**Display Remaining Materials**|A check box that indicates \(if selected\) that remaining materials are shown in both the Gantt chart and the **Operations &amp; Materials** table.The check box is selected by default.

|
|**Hours**|A button you click to show a single day, broken down by hour, in the calendar pane.|
|**Days**|A button you click to show a specific week in the calendar pane.|
|**Weeks**|A button you click to show a specific month in the calendar pane.|
|**Filter Settings**|Displays the filter bar so you can create a quick or advanced filter. The created filter will narrow the data displayed on the current pane.

 Multiple filter criteria are available, including *Constraint*, *Dispatch Priority*, *Due Date*, *Inventory ID*, *Production Order Status*, *Qty. to Produce*, *Project*, and *Scheduling Method*.

|

|Element|Description|
|-------|-----------|
|**Order Type**|A box where you select an active production order type to narrow down the list of production orders available for selection.|
|**Production Nbr.**|A box where you select a top level production order of the *Regular* or *Disassemble* function with the *Planned*, *Released*, *In Process*, or *On Hold* status.|
|**Select**|A button you click to confirm the selection.|
|**Cancel**|A button you click to discard the selection and close the dialog box.|

## Upper Pane {#1 .section}

The upper pane displays a Gantt chart of materials for orders of the *Regular* function that have a non-zero remaining quantity, drive material demand, are not by-products, and have a status other than *Completed*, *Locked*, *Closed*, or *Canceled*. These materials are shown when the **Display Remaining Materials** check box is selected.

|Column|Description|
|------|-----------|
|**Orders &amp; Operations**|Displays a list of production orders and linked subassemblies in a tree view, which you can expand or collapse.|
|Calendar|The calendar visually displays scheduling statuses of production orders and their subassemblies.|

## Lower Pane {#2 .section}

The lower pane contains the **Operations &amp; Materials** table that displays the operations, and, conditionally, unissued materials of the selected production order.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Order Type|The type of the production order.|
|Production Nbr.|The reference number of the production order.|
|Operation|The operation identifier.|
|Work Center|The active work center where the operation takes place.|
|Actual Labor|The actual labor cost, which the system calculates based on the actual labor time and fixed and variable labor costs.|
|Planned Labor|The sum of the planned fixed and variable labor costs that are applied to the operation.|
|Qty. to Produce|The quantity of the items to be produced at the operation.|
|Completed Qty.|The quantity of the item units that have been completed and moved in inventory.|
|Scrapped Qty.|The quantity of item units that have been recorded as scrap in labor or move transactions,|
|Remaining Qty.|The remaining quantity of the item units to be produced.|
|Start Date|The date on which the item production should start.|
|End Date|The date on which the item production should be completed.|
|Material ID|The stock item to be produced.|
|Material Scheduled Start|The material's start date.|
|Material Scheduled End|The material's end date.|
|Warehouse|The warehouse from which this material should be issued.|
|Required Material Qty.|The material quantity needed to produce the item.|
|Issued Material Qty.|The material quantity issued to produce the item.|
|Remaining Material Qty.|The remaining quantity of the material to be produced.|
