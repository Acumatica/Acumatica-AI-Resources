# Segment Values {#_00338857-dd1a-41be-aa07-4cbce24c635e .reference}

Form ID: \(CS203000\)

By using this form, you can populate the lists of segment values for segmented keys defined in the system and view and edit these lists. Segments are components of the segmented key, which was defined on the [Segmented Keys](CS_20_20_00.md) \(CS202000\) form, and segment values can be used to create different identifiers. For each segment with the **Validate** option selected on the [Segmented Keys](CS_20_20_00.md) form, you should populate the list of possible values before users start to create new objects by specifying their identifiers.

You can add new values to the list of segment values at any time. Some values in the list may be marked as inactive \(by clearing the **Active** check box for them\). Inactive values will not be used for creating new objects, but they can appear in old objects.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

You can use the Summary area to select the segment for viewing or editing its values.

|Element|Description|
|-------|-----------|
|**Segmented Key ID**|The ID of the segmented key that contains segments.|
|**Segment ID**|The number representing the order of the segment in the segmented key.|
|**Description**|The user-defined description of the selected segment.|

## Table {#2 .section}

This table contains the list of possible values for the selected segment. You can add new values to the segment or edit or delete existing values.

|Button|Description|
|------|-----------|
|**Load Records from File**|Gives you the ability to upload a file that contains the values for the segment.|

|Column|Description|
|------|-----------|
|**Value**|The string that is the value of the selected segment. The type and length of the segment are defined on the [Segmented Keys](CS_20_20_00.md) \(CS202000\) form for the particular segmented key.

 **Important:** For the *SUBACCOUNT* segmented key, we do not recommend typing spaces in any position of the segment value. The system treats any spaces as wildcard characters in reports and generic inquires. When a user runs a report or generic inquiry and enters a subaccount as a report parameter or selection criterion, the system treats a space as a wildcard character. As a result, the report or inquiry includes multiple subaccounts rather than this particular subaccount.

|
|**Description**|The description of the value.|
|**Active**|A check box that indicates \(if selected\) that the value is active. Active values can be selected in the list of values on the [Segmented Keys](CS_20_20_00.md) form. Inactive values are not shown in the list and cannot be selected for newly created objects, although they may still be present in the identifiers of existing objects.

 **Attention:** If the **Validate** check box on the [Segmented Keys](CS_20_20_00.md) form is cleared, users can enter any values, including inactive ones, in a newly created segment.

|
|**Aggregation**|A check box that indicates \(if selected\) that the value is used as an aggregating value for the segment.

 This column is available for segments of the *INSUBITEM* segmented key only.

 For details, see [Inventory Subitems](IN__con_Inventory_IDs_and_Subitem_Codes.md).

|
|**Mapped Value**|The value used for consolidation in a subsidiary company \(that is, a consolidation unit\) for mapping the subaccounts against the subaccounts of the parent company.

 This column is available for segments of the *SUBACCOUNT* segmented key only. This column is available only if the *General Ledger Consolidation* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 For details, see [GL Consolidation: Subaccount Mapping](Finance_GL_Consolidation_Subaccount_Mapping.md).

|
