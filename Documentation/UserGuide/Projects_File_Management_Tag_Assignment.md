# Managing Project Files: Tag Assignment {#_4c6e5281-64b6-4b0c-86eb-f180b8e950ad .concept}

You can assign tags to files in multiple ways, depending on the form you’re using. The following sections describe these ways.

## Assigning Tags to Files { .section}

You can edit the tags assigned to a file or multiple files on the [Manage Project Files by Tag](PM_50_90_00.md) \(PM509000\) form.

To edit the tags assigned to a single file, you:

1.  Select the project.
2.  Select the node whose files you want to view in the central pane.
3.  Click the file row.
4.  Click the magnifier button in the **Tags** box.
5.  Select the tags in the **Select Tags** lookup table.

Alternatively, you can start typing the tag name in the **Tags** box, and the system opens a list of tags matching this string; you select the needed tag.

To assign the same tag or tags to multiple files, you:

1.  Select the project.
2.  Select the node whose files you want to view in the central pane.
3.  Select the files.
4.  On the toolbar of the central pane, click **Assign Tags**, which opens a dialog box.
5.  In the **Tags** box, click the magnifier button and select the tags in the lookup table.
6.  Click **Assign**.

To remove all the tags from one file or from multiple files, you select the needed files and click **Untag**.

On the [Manage Project Files by Record Type](PM_50_95_50.md) \(PM509500\) form, you can also edit the tags for a file. To do this, click the file row and add the needed tags to the **Tags** box—similar to the workflow on the [Manage Project Files by Tag](PM_50_90_00.md) form.

## Using Additional Tagging Options { .section}

You can also assign tags on other forms in the system. When uploading a file on the [File Maintenance](SM_20_25_10.md) \(SM202510\) form, you can assign its tags to ensure that users have the needed access level to it.

Also, if a form has the **Files** button on the form title bar, you can click it to open the **Files** dialog box. In the list of files attached to the record, you can add or remove any file’s tags in the **Tags** column. When you select the tags, you don’t need to save the form—the system adds the selected tags automatically.

**Attention:** In the **Files** dialog box, you can select only files with tags to which at least one of your user roles has the *Edit and Upload \(Project Files\)* or *Delete \(Project Files\)* access.

Also, you can add tags to files attached to the [Drawing Log](PJ_30_30_00.md) \(PJ303000\), [Photo Log](PJ_30_50_00.md) \(PJ305000\), and [Photo](PJ_30_50_10.md) \(PJ305010\) forms by using the **Tags** box on these forms.
