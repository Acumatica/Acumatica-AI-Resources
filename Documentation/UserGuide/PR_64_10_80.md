# Union Hours &amp; Rates

Form ID: \(PR641080\)

This report displays information about worked union hours and about the rates used to calculate wages, with a breakdown by paycheck and union.

Data from voided paychecks in not included in the report.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Tax Registration ID**: The EIN for which you want to view information.

    You enter EINs that are specified for companies and branches in the **Tax Registration ID** box on the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form and on the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form, respectively.

-   **Company/Branch**: The company or branch for which you want to view information. By default, the current company or branch is selected.
-   **Select By**: The date to which the specified date range should be applied, with the following options available: *Transaction Date* and *Period Start/End Date*.
-   **Date From**: The start date of the date range.
-   **Date To**: The end date of the date range.
-   **Include Unreleased**: A check box that you select if the data from unreleased documents should be included in the report.
-   **Union ID**: The identifier of the union for which you want to view information. This box cannot be empty.
-   **Employee**: The employee for which you want to view information. Select an employee, or make no selection to request information for all employees.
-   **Labor Item**: The labor item for which you want to view information. Select a labor item, or make no selection to request information for all available labor items.
-   **Show Hours Details**: A check box that you select if you want the report to show details about the hours worked and the projects with which the hours are associated.
-   **Group Results**: The way the report data is grouped. The following options are available: *By Labor Item* and *By Employee*.
