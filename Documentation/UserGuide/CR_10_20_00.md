# Activity Types {#_cd6e990d-e2b9-4138-a789-a9b4fb09ed1f .reference}

Form ID: \(CR102000\)

You use this form to add, view, edit, and delete activity types that can be used for tracking the time that employees spend.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table { .section}

|Column|Description|
|------|-----------|
|**Class**|The type of the activity.|
|**Type ID**|The unique code for the activity type. A code of up to five alphanumeric characters can be used.|
|**Description**|The name of the activity type that will be used on data entry forms.

 You should avoid giving similar names to activity types, or users may not be able to distinguish them when they create new activities.

|
|**Active**|A check box that indicates \(if selected\) that this activity type is active and can be used in the system.|
|**System Default**|A check box that indicates \(if selected\) that the system uses this activity type by default when activities are generated automatically.

 One default activity type should be defined for back-end activities and one for the portal. For back-end use or for portal use, if you select multiple default types, only one will be used in each case, and the system will select it at random.

|
|**Originated By**|The creator of activities of this type. You can select one of the following options: -   *ERP Users*: Activities of this type can be created by Acumatica ERP users.
-   *Portal Users*: Activities of this type can be created by Acumatica Self-Service Portal users.
-   *System*: Activities of this type can be created by the system.

|
|**Image**|The icon for activities of this type. The specified icon will be displayed next to the activity type and summary on the data entry forms.|
|**Color**|The background color of the activity type's icon. It is used in the Activity Stream, which can be opened in the side panel of the [Opportunities](CR_30_40_00.md) \(CR304000\), [Sales Quotes](CR_30_45_00.md) \(CR304500\), [Cases](CR_30_60_00.md) \(CR306000\), and [Contacts](CR_30_20_00.md) \(CR302000\) forms.|
|**Internal**|A check box that indicates \(if selected\) if you do not want portal users to view activities of this type.

 By default, new activities of this type will be marked as hidden from portal users, but this setting can be overridden for a particular activity on the [Activity](CR_30_60_10.md) \(CR306010\) form.

|
|**Track Time and Costs**|A check box that indicates \(if selected\) that tracking time and costs is enabled by default for new activities of this type.

 This column is available only if the *Time Management* feature has been enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Incoming**|A check box that indicates \(if selected\) that activities of this type will be considered incoming activities by the system. Incoming activities are logged as they arrive in the system from customers, other users, or the system itself. Incoming activities often serve as the starting point for subsequent actions or case creation.When a new activity of this type is created for the lead, case, opportunity, or business account record, it will be marked as the last incoming activity for the record \(until another activity is created for the record\).

|
|**Outgoing**|A check box that indicates \(if selected\) that activities of this type will be considered outgoing activities by the system. The outgoing activity is logged when it is sent from the system or internal users, representing a response to an incoming activity or an initiation of communication with an external party.When a new activity of this type is created for the lead, case, opportunity, or business account record, it will be marked as the last outgoing activity for the record \(until another activity is created for the record\).

|
