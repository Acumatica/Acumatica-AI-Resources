# Recalculate Account History {#_3753bb33-96dd-46e4-b53b-73a0b55dddfe .reference}

Form ID: \(GL509900\)

On this form, you can recalculate the account history in the selected ledgers. Balances are recalculated based on the account history records, and are matched to the account balances stored in the database. You can recalculate the balances of ledgers of all types—*Actual*, *Budget*, *Reporting*, and *Statistical*.

**Tip:** We recommend that you run this process only if a system error has occurred and the account balances are incorrect. For details on the account history in a specific ledger, use the [GL Edit Detailed](GL_61_05_00.md) \(GL610500\) report. For the list of transactions of a particular account, use the [Account Details](GL_40_40_00.md) \(GL404000\) form.

To recalculate the account history in all ledgers, select the financial period and click **Process All**. To recalculate the account history in particular ledgers, select the financial period, select the check boxes next to the ledgers whose history you want to recalculate, and click **Process**.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Recalculates the history of the accounts in the ledgers you have selected in the table.|
|**Process All**|Recalculates the history of the accounts in all ledgers listed in the table.|

## Selection Area { .section}

You use the element in this area to specify the financial period that the system uses for recalculation of account balances.

|Element|Description|
|-------|-----------|
|**Fin. Period**|The financial period starting in which you want to recalculate the account balances in the ledgers. By default, the first period that is open in the general ledger is selected in this box.|

## Table { .section}

The table lists all the ledgers available in the system.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include the current ledger for recalculation if you click **Process** on the form toolbar.|
|**Ledger ID**|The ledger, by its identifier.|
|**Description**|The description of the ledger.|
