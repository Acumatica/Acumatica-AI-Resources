# Efficiency of Picking and Packing {#_b293e563-5b76-4340-9a5e-ca928caa7ecf .reference}

Form ID: \(SO402020\)

**Attention:** This form is available only if the *Fulfillment* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this form to review the picking and packing statistics that can help you review the productivity metrics of warehouse workers and build a well-coordinated process of picking or packing.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

You can use the settings in this area to narrow the range of records listed in the table or to expand the displayed data to provide additional information.

|Element|Description|
|-------|-----------|
|**Warehouse**|The warehouse in which users performed the picking or packing operations for which you want to review statistics.|
|**Date Range**|The earliest and latest dates for the documents to be displayed. The earliest date is mandatory.|
|**Expand by Day**|A check box that you select to expand the results of the inquiry with the dates of the picking or packing operations. That is, the system displays a separate row for each date on which picking and packing operations were performed within the selected range of dates.

 If this check box is selected, the **Day** column appears in the table with the inquiry results.

 By default, this check box is cleared.

|
|**Expand by User**|A check box that you select to expand the results of the inquiry with the usernames of warehouse workers. That is, the system displays a separate row for each user who performed picking and packing operations.

 If this check box is selected, the **User** box in the Selection area becomes available, and the **User** column appears in the table with the inquiry results.

 By default, this check box is cleared.

|
|**User**|The name of the user whose picking or packing statistics you want to review.

 This box is available only if the **Expand by User** check box is selected.

|
|**Expand by Pick List**|A check box that you select to expand the results of the inquiry with the reference numbers of pick lists for which the picking or packing operations were performed. This pick list may contain a single shipment or a may be a part of a picking worksheet. You can select the applicable document as follows:

 -   If you select the **Shipment Nbr.** option in the adjacent box, you can select a shipment in the rightmost box in the line.
-   If you select the **Worksheet Nbr.** option in the adjacent box, you can select a picking worksheet in the rightmost box in the line.

 If this check box is selected, the **Pick List Nbr.** column appears in the table with the inquiry results.

 By default, this check box is cleared.

|

|Column|Description|
|------|-----------|
|**Day**|The date when the picking or packing operations were performed.

 This column appears only if the **Expand by Day** check box is selected in the Selection area, which causes a separate row to be shown for each date within the date range.

|
|**Start Date**|The start date and time of the range for which the picking or packing statistics are shown.

 This column appears if the **Expand by Day** check box is cleared in the Selection area.

|
|**End Date**|The end date and time of the range for which the picking or packing statistics are shown.

 This column appears only if the **Expand by Day** check box is cleared in the Selection area.

|
|**Total Time**|The value in this column depends on the states of the **Expand by Day**, **Expand by User**, and **Expand by Shipment** check boxes.

 -   If the **Expand by Day**, **Expand by User**, and **Expand by Shipment** check boxes are cleared, this column shows the total time spent on the picking or packing operations within the selected date range.
-   If the **Expand by Day** check box is selected, this column shows the total time spent on picking or packing the operations for the date whose statistics are shown in this row.
-   If the **Expand by User** check box is selected, the column shows the total time of the user whose statistics are shown in this row.
-   If the **Expand by Shipment** check box is selected, the column shows the total time of the shipment whose statistics are shown in this row.

 This column is hidden by default.

 The total time is the difference between the time of the first activity and the last activity on the [Pick, Pack, and Ship](SO_30_20_20.md) \(SO302020\) form calculated for the selection criteria you have specified, which may include the date range, day, shipment, or user.

|
|**Operation Type**|The type of the performed operations.|
|**User**|The user who performed the picking or packing operations.

 This column appears only if the **Expand by User** check box is selected in the Selection area.

|
|**Warehouse**|The warehouse for which the pick list is created \(which means that the shipments in this pick list are of this warehouse\).|
|**Pick List Nbr.**|The number of the pick list for which the picking or packing operations were performed.

 This column appears only if the **Expand by Pick List** check box is selected in the Selection area.

|
|**Number of Lines**|The number of picked or packed lines in the shipment or shipments whose data is shown in this row.|
|**Number of Packages**|The number of packages that were confirmed for the shipment or shipments whose data is shown in this row.|
|**Number of Unique Items**|The number of unique stock items that were picked or packed for the shipment or shipments whose data is shown in this row.|
|**Number of Unique Locations**|The number of unique warehouse locations that were specified in the lines of the shipment or shipments whose data is shown in this row.|
|**Total Qty.**|The total quantity of stock items that were picked or packed for the shipment or shipments whose data is shown in this row.|
|**Number of Useful Operations**|The number of useful operations required to pick or pack the shipment or shipments whose data is shown in this row.

 **Note:** *Useful* means that operations required to pick or pack items in the pick list without errors have been completed without errors. For example, scanning an item is considered a useful operation, but item removal is not because this means that the user has previously made a mistake that resulted in an error, and is trying to correct it.

|
|**Number of Actual Operations**|The number of all the scanning operations that a user performs for a pick list.|
|**Number of Errors**|The number of all the scanning operations per shipment or per pick list that have resulted in an error.|
|**Actual Time**|The actual time spent on the picking or packing operations within the selected date range if the **Expand by Day**, **Expand by User**, and **Expand by Shipment** check boxes are cleared.

 If the **Expand by Day** check box is selected, this column shows the actual time spent on picking or packing the operations for the date whose statistics are shown in this row.

 If the **Expand by User** check box is selected, this column shows the actual time for the user whose statistics are shown in this row.

 If the **Expand by Shipment** check box is selected, the column shows the actual time on picking or packing operations for the shipment shown in this row.

 The actual time is the sum of the differences between the start time and end time of activities on the [Pick, Pack, and Ship](SO_30_20_20.md) \(SO302020\) form calculated for the selection criteria you have specified, which may include the date range, day, shipment, or user.

|
|**Efficiency \(Operations per Min.\)**|The efficiency of the picking and packing operations for the shipment or shipments whose data is shown in this row. The system calculates this efficiency as the number of useful operations divided by the number of minutes of the actual time.|
