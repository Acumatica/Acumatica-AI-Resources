# Target Equipment List {#_d17df416-f591-436e-a5ea-cc97e853d023 .reference}

Form ID: \(FS659000\)

This report displays information about all target equipment in the system. You can filter the data by equipment type.

The system displays records related to customers that are visible to the current user or to the branches to which the user's access role is assigned \(the **Restrict Visibility To** box on the **General Info** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form contains this company or branch, or is empty\).

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Equipment Type**: The type of equipment for which you want to view data. Leave the box blank to view information on all customers. Leave the box blank to view information on all target equipment.
-   **Component Details**: A check box that indicates \(if selected\) that the report will display information about the components of the target equipment.
