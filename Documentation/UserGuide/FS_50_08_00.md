# Close Routes {#_2f773a55-102c-4ace-862f-cb7096e6f0d2 .reference}

Form ID: \(FS500800\)

You use this form to close routes. Only routes with the *Completed* status can be closed.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the closure of the routes selected in the table.|
|**Process All**|Initiates the closure of all routes listed in the table.|

## Selection Area {#1 .section}

You use the elements in the Selection area to display in the table the routes that match the selected criteria.

|Element|Description|
|-------|-----------|
|**Date**|The date to display routes for in the table. Leave this box empty to view all routes that are not closed.|
|**Show Closed Routes**|A check box that indicates \(if selected\) that only closed routes are displayed in the table.|

## Table {#2 .section}

In this table, you select routes for processing, which will close the selected routes. If you click **Process All** on the form toolbar, all listed routes will be processed.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include the route in processing if you click **Process**.|
|**Route Nbr.**|The number of the route.|
|**Route**|The identifier of the route.|
|**Route Short**|The short identifier of the route.|
|**Status**|The status of the route.|
|**Scheduled Start Date**|The date when the services for the route were performed.|
|**Start Time**|The start time of the route.|
|**Driver**|The driver who performed the route services.|
|**Additional Driver**|The second driver who performed the route services.|
|**Vehicle**|The vehicle used to perform the route services.|
|**Additional Vehicle 1**|The second vehicle used to perform the route services.|
|**Additional Vehicle 2**|The third vehicle used to perform the route services.|
|**Number of Appointments**|The number of appointments in the route.|
|**Total Services**|The total number of services performed for the route.|
|**Total Driving Duration**|The total driving time, in hours and minutes.|
|**Total Service Duration**|The total time spent performing services, in hours and minutes.|
