# Assignment and Approval Maps {#_54d9618b-c27b-47d5-9748-24441084e99e .reference}

Form ID: \(EP205500\)

On this form, you can view a list of all assignment and approval maps available in the system. By using toolbar buttons, you can start creating a new assignment or approval map.

## Form Toolbar { .section}

|Button|Description|
|------|-----------|
|**Add Approval Map**|Opens the [Approval Maps](EP_20_50_15.md) \(EP205015\) form, which you use to create a new approval map. This button appears on the form only if the *Approval Workflow* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.|
|**Add Assignment Map**|Opens the [Assignment Maps](EP_20_50_10.md) \(EP205010\) form, which you use to create a new assignment map.|

## Table { .section}

The table displays a list of all available assignment and approval maps.

|Column|Description|
|------|-----------|
|**Name**|The name of the map, which is also a link that you can click to open the map on the form where it was created to view its details \(and, if needed, to modify them\).|
|**Map Type**|The type of the map, which can be one of the following:-   *Assignment Map*: Used for assigning business accounts, cases, contacts, email activities, leads, opportunities, purchase receipts, requests, or requisitions to owners for further processing.
-   *Approval Map*: Used for assigning approvers to projects or documents, such as bills and adjustments, employee time cards, equipment time cards, expense claims, expense receipts, projects, purchase orders, requests, requisitions, sales orders, or transactions.

|
|**Entity Type**|The type of entity for which assignment or approval rules are specified in the map.|
