# Getting Started {#_004432da-e259-4416-8809-aabf230ee9b7 .concept}

This guide provides information about access to Acumatica ERP, its user interface, and basic operations in the system. By using the guide, you can become familiar with the system search capabilities, data entry forms, reports, and dashboards. You can also personalize your basic working environment and learn about Acumatica educational resources. This information helps you fine-tune the system according to your work tasks and make your work easier and more comfortable.
