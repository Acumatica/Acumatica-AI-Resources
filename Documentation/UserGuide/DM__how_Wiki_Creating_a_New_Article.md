# To Add an Article {#_dcfdd521-a054-47f2-a9a6-026099301efd .task}

You can add a new article in one of the following ways:

-   By using the wiki toolbar button.
-   By using the **Create a New Article** link.

## To Add an Article by Using the Wiki Toolbar Button {#_f2862694-ec3f-47f9-8538-61c998721d27 .section}

To create an article in any folder or to create a wiki folder, do the following:

1.  Open any wiki article or folder.
2.  On the wiki toolbar, click **Add New Article** to open the Wiki Editor form for a new article or folder. The **Parent Folder** and **Category** boxes have the same settings as those of the article or folder you opened; change these settings if necessary.
3.  On the **Content** tab, in the **Article ID** and **Name** boxes, type the ID and name for the new article. You can use the same value in both boxes.
4.  Optional: If you're creating a folder, select the **Folder** check box.
5.  In the text box, type the article text. For more information about wiki markup, see [Wiki Markup Reference](DM__con_Wiki_Using_Wiki_Markup.md).

    **Note:** If you save the article without adding any text, the article will still be displayed in the wiki tree, but it will have no content.

6.  Optional: On the **Properties** tab, fill in the **Summary** and **Keywords** boxes. This step helps users find information when they perform quick searches \(for which the system searches article properties and not full text\).
7.  On the Wiki Editor form toolbar, click **Save**.

## To Add an Article by Using the Create a New Article Link { .section}

To create a new article by using the link in the navigation pane, do the following:

1.  Open the wiki to which you want to add an article.
2.  In the navigation pane, click **Create a new article**.
3.  On the **Contents** tab, in the **Parent Folder** box, select the folder to hold the new article.
4.  Optional: Select a category for the article based on your corporate requirements.
5.  Follow Steps 3 through 7 in the [To Add an Article by Using the Wiki Toolbar Button](#_f2862694-ec3f-47f9-8538-61c998721d27) section of this topic.
