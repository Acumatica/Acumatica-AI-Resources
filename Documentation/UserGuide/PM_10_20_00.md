# Project Access

Form ID: \(PM102000\)

By using this form, you can create restriction groups for managing the visibility of projects to users, or modify existing restriction groups by adding or removing users or projects. For more information, see [Project Security](RS__con_Project_Security.md).

**Attention:** You can also use the [Restriction Groups by Project](PM_10_20_10.md) \(PM102010\) form to manage the visibility of projects to users, but you cannot create restriction groups on this form.

For more information about restriction groups, see [Restriction Groups in Acumatica ERP](SM__con_Overview_of_Restriction_Groups.md).

## Form Toolbar

The form toolbar has only standard buttons.

## Users Tab

On this tab, you can view the list of users defined in the system and select those to be included in the restriction group.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that indicates \(if selected\) that this user is included in the restriction group.|
|**Login**|Read-only. The username of the user.|
|**Full Name**|Read-only. The full name of the user.|
|**Comment**|Read-only. The additional information that has been specified for the user on the [Users](../Shared/../UserGuide/SM_20_10_10.md) \(SM201010\) form.|

## Project Groups Tab

By using this tab, you can view the list of project groups defined in the system and select those to be included in the restriction group.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that indicates \(if selected\) that this project group is included in the restriction group.|
|**Project Group ID**|Read-only. The identifier of the project group.|
|**Description**|Read-only. The description of the project group.|
