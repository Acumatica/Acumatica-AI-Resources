# Picking Queue {#_6b99dd9a-25b5-4e8e-9c45-da29958ca8c2 .reference}

Form ID: \(SO503080\)

**Note:** This form is available only if the *Paperless Picking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to view and edit the active pick lists intended for picking and packing.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Command|Description|
|-------|-----------|
|**Start Watching**|Starts refreshing the data in the table below until you cancel watching to show the overall progress of the picking.|

## Selection Area {#1 .section}

In this area, you can define the criteria for the pick lists to be displayed in the table below

|Element|Description|
|-------|-----------|
|**Warehouse**|The warehouse from which the items will be picked.|
|**Picker**|The picker to whom the picking list is assigned.|
|**Pick List Type**|The type of the pick list. This column can have the following values:

 -   *All*
-   *Shingle-Shipment*
-   *Wave*
-   *Batch*

|

## Pack Tab {#2 .section}

On this tab, you can view and edit the list of pick lists intended for picking.

|Button|Description|
|------|-----------|
|**Remove from Queue**|Removes the selected pick list from the picking queue. You can remove only pick lists with the *Open*, *Assigned*, and *Returned to Queue* statuses.|

|Column|Description|
|------|-----------|
|**Pick List Type**|The type of the pick list. This column can have the following values:

 -   *Single-Shipment*: The pick list has been generated for a single shipment which is not included into wave or batch.
-   *Wave*: The pick list is generated by the wave-picking worksheet.
-   *Batch*: The pick list is generated by the batch-picking worksheet.

|
|**Pick List Nbr.**|The reference number of the pick list. You can click this number to open the details of the pick list in a dialog box.|
|**Status**|The status of the pick list.|
|**Priority**|The priority of the picking list which shows the urgency of the picking. This column can have the following values:

 -   *Urgent*
-   *High*
-   *Medium*
-   *Low*

|
|**Assigned Picker**|The user account of a picker to whom the manager has assigned the pick list.|
|**Actual Picker**|The user account of a picker who picked the items in the pick list.|
|**Pick List Date**|The date of the pick list.|
|**Time in Queue**|The duration of time for which the picking list remains in the picking queue.|
|**Path Length**|The total length of the path that a picker will pass while picking the pick list.|
|**Picking Started**|The date and time when the picking started.|
|**Automatic Shipment Confirmation**|A check box that indicates \(if selected\) that when the picker confirms a pick list on the [Pick, Pack, and Ship](SO_30_20_20.md) \(SO302020\) form, the system automatically confirms the related shipment. This check box can be selected for single-shipment pick lists only.

 If the check box is cleared, the picker has to confirm the pick list on the [Pick, Pack, and Ship](SO_30_20_20.md) \(SO302020\) form and then confirm the shipment on the [Shipments](SO_30_20_00.md) \(SO302000\) form.

 This check box is not available for editing for pick lists with *Wave* or *Batch* type specified in the **Pick List Type** column.

|
|**Customer ID**|The unique identifier of the customer that ordered the goods or services.

 This column is hidden by default. It can contain a value only for pick lists with the *Single-Shipment* status.

|
|**Customer Location ID**|The identifier of the customer's location that is specified in the shipment.

 This column is hidden by default. It can contain a value only for pick lists with the *Single-Shipment* status.

|
|**Customer Location Name**|The description of the customer's location that is specified in the shipment.

 This column is hidden by default. It can contain a value only for pick lists with the *Single-Shipment* status.

|
|**Customer Name**|The name of the customer that ordered the goods or services.

 This column is hidden by default. It can contain a value only for pick lists with the *Single-Shipment* status.

|
|**Quantity**|The total volume of the items in the pick list.

 This column is hidden by default. It can contain a value only for pick lists with the *Single-Shipment* status.

|
|**Ship Via**|The carrier through which the items are shipped.

 This column is hidden by default. It can contain a value only for pick lists with the *Single-Shipment* status.

|
|**Ship Via Description**|The description provided for the carrier.

 This column is hidden by default. It can contain a value only for pick lists with the *Single-Shipment* status.

|
|**Shipment Date**|The date of a shipment related to the pick list.

 This column is hidden by default. It can contain a value only for pick lists with the *Single-Shipment* status.

|
|**Volume**|The total volume of the items in the pick list.

 This column is hidden by default. It can contain a value only for pick lists with the *Single-Shipment* status.

|
|**Weight**|The weight of the items in the pick list.

 This column is hidden by default. It can contain a value only for pick lists with the *Single-Shipment* status.

|
