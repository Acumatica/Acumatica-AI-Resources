# Picking Queue

Form ID: \(SO503080\)

**Note:** This form is available only if the *Paperless Picking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to view and edit the active pick lists intended for picking and packing.

The form toolbar includes the buttons described below.

## Pick Tab

On this tab, you can view and edit the list of pick lists intended for picking.

<table id="table_bgw_wqf_bj"><thead><tr><th>

Button

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Remove from Queue**

</td><td>

Removes the selected pick list from the picking queue. You can remove only a pick list with the *Open*, *Assigned*, or *Returned to Queue* status.

</td></tr><tr><td>

**Clear Picker**

</td><td>

Clears the values in the **Assigned Picker** and **Actual Picker** columns for the selected pick list, returns it to the picking queue, and changes the pick list's status to *Returned to Queue*. This button is available only if the pick list has an actual picker specified and its status is one of the following:

 -   *Being Picked*
-   *Assigned*
-   *Added to Queue*
-   *Returned to Queue*

</td></tr></tbody>
</table>

<table id="_9e453575-1414-47a9-802b-814220ff976a"><thead><tr><th>

Column

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Pick List Type**

</td><td>

The type of the pick list. This column can have the following values:

 -   *Single-Shipment*: The pick list has been generated for a single shipment that is not included in a wave or batch.
-   *Wave*: The pick list is generated by the wave-picking worksheet.
-   *Batch*: The pick list is generated by the batch-picking worksheet.

</td></tr><tr><td>

**Pick List Nbr.**

</td><td>

The reference number of the pick list. You can click this number to open the details of the pick list in a dialog box.

</td></tr><tr><td>

**Status**

</td><td>

The status of the pick list.

</td></tr><tr><td>

**Priority**

</td><td>

The priority of the pick list that shows the urgency of the picking. This column can have the following values:

 -   *Urgent*
-   *High*
-   *Medium*
-   *Low*

</td></tr><tr><td>

**Assigned Picker**

</td><td>

The user account of a picker to whom the manager has assigned the pick list.

</td></tr><tr><td>

**Actual Picker**

</td><td>

The user account of a picker who picked the items in the pick list.

</td></tr><tr><td>

**Pick List Date**

</td><td>

The date of the pick list.

</td></tr><tr><td>

**Time in Queue**

</td><td>

The duration for which the pick list remains in the picking queue.

</td></tr><tr><td>

**Path Length**

</td><td>

The total length of the path that a picker will travel while picking the pick list.

</td></tr><tr><td>

**Picking Started**

</td><td>

The date and time when the picking was started.

</td></tr><tr><td>

**Automatic Shipment Confirmation**

</td><td>

A check box that indicates \(if selected\) that when the picker confirms a pick list on the [Pick, Pack, and Ship](SO_30_20_20.md) \(SO302020\) form, the system automatically confirms the related shipment. This check box can be selected for single-shipment pick lists only.

 If the check box is cleared, the picker has to confirm the pick list on the [Pick, Pack, and Ship](SO_30_20_20.md) \(SO302020\) form and then confirm the shipment on the [Shipments](SO_30_20_00.md) \(SO302000\) form.

 This check box is not available for editing if the pick list has the *Wave* or *Batch* type.

</td></tr><tr><td>

**Customer ID**

</td><td>

The unique identifier of the customer that ordered the goods or services.

</td></tr><tr><td>

**Customer Location ID**

</td><td>

The identifier of the customer's location that is specified in the shipment.

</td></tr><tr><td>

**Customer Location Name**

</td><td>

The description of the customer's location that is specified in the shipment.

</td></tr><tr><td>

**Customer Name**

</td><td>

The name of the customer that ordered the goods or services.

</td></tr><tr><td>

**Quantity**

</td><td>

The total quantity of the items in the pick list.

</td></tr><tr><td>

**Ship Via**

</td><td>

The carrier through which the items are shipped.

</td></tr><tr><td>

**Ship Via Description**

</td><td>

The description provided for the carrier.

</td></tr><tr><td>

**Shipment Date**

</td><td>

The date of a shipment related to the pick list.

</td></tr><tr><td>

**Volume**

</td><td>

The total volume of the items in the pick list.

</td></tr><tr><td>

**Weight**

</td><td>

The weight of the items in the pick list.

</td></tr></tbody>
</table>
