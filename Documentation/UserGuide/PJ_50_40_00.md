# Load Weather Conditions {#_1bd4f144-e5fa-4f68-bb08-3f66041c85f8 .reference}

Form ID: \(PJ504000\)

**Attention:** This form is available if the *Weather Services* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this form to get weather conditions from the API of the integrated weather service for the selected daily field reports or for all daily field reports.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Command|Description|
|-------|-----------|
|**Process**|Initiates the obtaining of the weather conditions for the daily field reports you have selected in the table. As a result of the process, for each daily field report selected for processing, one record is created on the **Weather** tab of the [Daily Field Report](PJ_30_40_00.md) \(PJ304000\) form.|
|**Process All**|Initiates the obtaining of the weather conditions for all daily field reports in the table. As a result of the process, for each listed daily field report, one record is created on the **Weather** tab of the [Daily Field Report](PJ_30_40_00.md) \(PJ304000\) form.|

## Table {#2 .section}

The table contains the list of daily field reports with the *On Hold* status and for the current business date.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you can use to include the daily field report in processing if you click **Process**.|
|**DFR ID**|The daily field report, by its identifier. The table contains the list of daily field reports with the *On Hold* status and for the current business date.|
|**Status**|The status of the daily field report.|
|**DFR Date**|The date of the daily field report.|
|**Project**|The project to which the daily field report is related.|
|**Project Manager**|The person who is responsible for managing the project and authorized to approve the daily field report \(if necessary\).|
|**Created By**|The name of the employee who created the daily field report in the system.|
