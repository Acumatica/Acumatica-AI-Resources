# Generate Route Appointments

Form ID: \(FS500200\)

On this form, you can generate appointments for the schedules created on the [Route Service Contract Schedules](FS_30_56_00.md) \(FS305600\) form.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Generates appointments according to the specified date range for the schedules you have selected in the table.|
|**Process All**|Generates appointments according to the specified date range for all schedules listed in the table.|

## Selection Area

In the Selection area, you can select the date range for which the appointments are generated and filter the schedules in the table by the route definition.

|Element|Description|
|-------|-----------|
|**Route**|The route for which you want to view and generate the appointments. You can select the route or leave this box blank to view the appointments for multiple routes.|

|Element|Description|
|-------|-----------|
|**Generate From**|The start date of the date range for which the appointments will be generated.|
|**Generate Up To**|The end date of the date range for which the appointments will be generated.|

## Run History Tab

The table contains the history of generation processes.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Generation ID**|The identifier of the generation process.|
|**Up to Date**|The date up to which the appointments were generated in the system.|
|**Generation Date**|The date when the generation process took place.|

## Generation Error Log Tab

On this tab, you can view the errors that have occurred during the generation processes.

|Buttons|Description|
|-------|-----------|
|**Clear All Errors**|Clears the table with the log of errors.|

|Column|Description|
|------|-----------|
|**Generation ID**|The identification number of the generation process.|
|**Customer**|The customer of the route service contract.|
|**Service Contract ID**|The identifier of the route service contract.|
|**Schedule Nbr.**|The reference number of the route service contract schedule.|
|**Generation Date**|The date when the generation process took place.|
|**Error Message**|Any error message that occurred during the generation process.|
