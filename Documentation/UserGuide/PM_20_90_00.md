# External Commitments {#_08e48343-6757-47a0-a766-4a845843fdf9 .reference}

Form ID: \(PM209000\)

On this form, you can create a new external commitment or edit or delete an existing external commitment.

You can open this form only through the [Commitments](PM_30_60_00.md) \(PM306000\) form, by clicking **Create External Commitment** on the form toolbar or by clicking the reference number in the **External Ref. Nbr.** column for an external commitment.

**Attention:** If you need to use this form in an import scenario to import commitment records from an external system into Acumatica ERP, on the [Import Scenarios](SM_20_60_25.md) \(SM206025\) form, you can find this form under the first-level **Hidden** node of the system tree.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area { .section}

In this area, you enter the details of the external commitment to be created, or review the existing one.

|Element|Description|
|-------|-----------|
|**Branch**|The branch of your company with which this commitment is associated.This box is displayed only when the *Multibranch Support* feature or the *Multicompany Support* feature is enabled \(or both features are enabled\) on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

|
|**External Ref. Nbr.**|The identifier of the external commitment.|
|**Status**|The status of the external commitment. The status can be one of the following options: *Open*, *Closed*, or *Canceled*.|
|**Account Group**|The account group of the account to be updated with this commitment.|
|**Project**|The project associated with this commitment.|
|**Project Task**|The project task associated with this commitment. If you select a project that has the default project task, this task is automatically populated in the column.|
|**Inventory ID**|The stock item, non-stock item, or the empty item code to be used in the created commitment. You can change the default value in the **Empty Item Code** box on the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form.|
|**UOM**|The unit of measure of the commitment. If an inventory item is selected in the **Inventory ID** box, the system automatically fills this box with the base unit of measure of this inventory item; it can be changed to another UOM available for the item.|
|**Project Currency**|The project currency. The column is read-only.

 This column appears on the form if the *Multicurrency Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Original Committed Amount**|The original amount of the commitment. On the [Projects](PM_30_10_00.md) \(PM301000\) form, this amount is included in the **Original Committed Amount** of the budget line associated with the same project, project task, account group, and inventory item.|
|**Original Committed Quantity**|The original quantity of the commitment. On the [Projects](PM_30_10_00.md) \(PM301000\) form, this quantity is included in the **Original Committed Quantity** of the budget line associated with the same project, project task, account group, and inventory item if the budget line has a UOM that the system can convert to the UOM of the commitment.

 For more information about how the system selects the unit conversion rules, see [Project Transactions: Update of the Project Budget Structure](../Shared/../UserGuide/Projects_Transactions_Project_Budget_Update.md).

|
|**Revised Committed Amount**|The original amount of the commitment. On the [Projects](PM_30_10_00.md) \(PM301000\) form, this amount is included in the **Revised Committed Amount** of the budget line associated with the same project, project task, account group, and inventory item.|
|**Revised Committed Quantity**|The revised quantity of the commitment. On the [Projects](PM_30_10_00.md) \(PM301000\) form, this quantity is included in the **Revised Committed Quantity** of the budget line associated with the same project, project task, account group, and inventory item if the budget line has a UOM that the system can convert to the UOM of the commitment.

 For more information about how the system selects the unit conversion rules, see [Project Transactions: Update of the Project Budget Structure](../Shared/../UserGuide/Projects_Transactions_Project_Budget_Update.md).

|
|**Committed Open Amount**|The open amount of the commitment that has not been received yet, which is included in the **Committed Open Amount** of the budget line associated with the same project, project task, inventory item, and account group.|
|**Committed Open Quantity**|The open quantity of the commitment that has not been processed yet. On the [Projects](PM_30_10_00.md) \(PM301000\) form, this quantity is included in the **Committed Open Quantity** of the budget line associated with the same project, project task, inventory item, and account group if the budget line has a UOM that the system can convert to the UOM of the commitment.For more information about how the system selects the unit conversion rules, see [Project Transactions: Update of the Project Budget Structure](../Shared/../UserGuide/Projects_Transactions_Project_Budget_Update.md).

|
|**Committed Received Quantity**|The processed quantity of the commitment \(for example, the quantity that has been processed or shipped\). On the [Projects](PM_30_10_00.md) \(PM301000\) form, this quantity is included in the **Committed Received Quantity** of the budget line associated with the same project, project task, inventory item, and account group if the budget line has a UOM that the system can convert to the UOM of the commitment.For more information about how the system selects the unit conversion rules, see [Project Transactions: Update of the Project Budget Structure](../Shared/../UserGuide/Projects_Transactions_Project_Budget_Update.md).

If purchase order lines and subcontract lines have non-stock items that do not require receipt, these lines do not update the received quantity of the commitment.

|
|**Committed Invoiced Amount**|The invoiced amount of the commitment, which is included in the **Committed Invoiced Amount** of the budget line associated with the same project, project task, inventory item, and account group.|
|**Committed Invoiced Quantity**|The invoiced quantity of the commitment. On the [Projects](PM_30_10_00.md) \(PM301000\) form, this quantity is included in the **Committed Invoiced Quantity** of the budget line associated with the same project, project task, inventory item, and account group if the budget line has a UOM that the system can convert to the UOM of the commitment.For more information about how the system selects the unit conversion rules, see [Project Transactions: Update of the Project Budget Structure](../Shared/../UserGuide/Projects_Transactions_Project_Budget_Update.md).

|
