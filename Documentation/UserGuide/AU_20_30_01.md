# Data Access

Page ID: \(AU203001\)

On the Data Access page, you manage the *DAC* items in the customization project. A *DAC* item contains data in XML format used by the platform to create an appropriate extension for the original data access class \(DAC\).

**Tip:** You open the Data Access page by clicking **Data Access** in the navigation pane of the Customization Project Editor.

You cannot create a custom data access class on this page. Instead, you have to use the [Code](AU_20_40_00.md) page of the editor. Custom DACs are added to the project as *Code* items. See [To Create a Custom Data Access Class](../CustomizationPlatform/CG_GL_Items_Code_CustomDAC.md) for details.

**Tip:** You can customize *DAC* items for the Self-Service Portal as well.
