# Project Transactions {#_a2c1cc92-b205-4ab3-ab74-84407524db39 .reference}

Form ID: \(PM633000\)

**Note:** This report is available only if the *Projects* group of features is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This report lists the history of project transactions grouped by projects and project tasks, along with key information about these project transactions. For each project transaction line, the system shows the reference number and date of the project transaction, as well as the inventory item, employee, branch. unit of measure, quantity, billable quantity, unit rate, and amount. Also, the report shows project transaction total by each project task and project total for each project included in the report.

**Note:** The report shows the project transactions that the signed-in user has permissions to view.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Project**: The project whose transaction history you want to view. You can select a project to view the transaction history for this project, or leave the box blank to view the report for all projects. Projects with the *Active*, *Suspended*, and *Completed* status are available for selection.
-   **Customer**: The identifier of the customer for whose projects you want to view the report. Select a customer to view the transaction history of projects related to this customer, or leave the box blank to view the report for the projects of all customers.

    The list of customers available for selection may be limited based on the role or roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. In this case, the **Restrict Visibility To** box appears on the **Financial** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form. With the feature enabled, a customer is available for selection if one of the following is true:

    -   The **Restrict Visibility To** box is empty for the customer—that is, the customer’s visibility is not restricted.
    -   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer, and your user account has the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.
-   **Project Manager**: The project manager for whose projects you want to view the transaction history. You can select a project manager to view the transaction history of projects assigned to this project manager, or leave the box blank to view the report for the projects of all project managers.
-   **Show Active Projects Only**: A check box that you select to include the project transactions of only the active projects in the report.
