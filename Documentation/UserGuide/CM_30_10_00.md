# Currency Rates {#_cc4f6c18-cc29-4e58-a5dc-6c41770e6d48 .reference}

Form ID: \(CM301000\)

On this form, you can view the currency rates that were effective on a specific date for a specific target currency \(**To Currency**\) and enter new effective rates for multiple source currencies \(those specified in the **From Currency** column\). You can update the exchange rates of foreign source currencies for the target base currency on daily basis. For details on currency rate entry, see [Configuration of Rate Types and Rates: To Configure Rates](../ImplementationGuide/config_Multicurrency_Configuring_Rates_Activity1.md).

**Tip:** You can also define rates with target currencies other than the base currency; these rates are used for translations only.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#CurrencySelection .section}

In the Selection area, you can select a target currency and a date, so you can enter and view the exchange rates of source currencies effective on that date for the selected target currency.

|Element|Description|
|-------|-----------|
|**To Currency**|The identifier of the target currency for which the exchange rates of source currencies are entered and listed on the **Currency Rate Entry** and **Effective Currency Rates** tabs, respectively.

 By default, the system selects the base currency in this box.

|
|**Effective Date**|The effective date of the exchange rates:

 -   On the **Currency Rate Entry** tab, this value is used as the default effective date, which the system inserts in the **Currency Effective Date** column when you add a row and enter the rate details in the table. This value can be overridden.
-   On the **Effective Currency Rates** tab, the system displays the list of currency pairs with the rates that are effective on the specified date.

|

## Currency Rate Entry Tab {#CRE .section}

On this tab, you can enter the exchange rate for the source currency to be used with the selected target currency.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**From Currency**|The ID of the currency whose exchange rate is shown for the **To Currency**.|
|**Currency Rate Type**|The currency rate type specified for the selected currency pair.|
|**Currency Effective Date**|The date on which the currency rate in this row becomes effective.|
|**Currency Rate**|The currency exchange rate. For currency conversion, the system uses it along with the operation specified in the **Mult./Div.** column. When a value is converted from the **From Currency** to the **To Currency**, the value is multiplied or divided by the rate you specify here.|
|**Mult./Div.**|The operation to be used for currency conversion: *Multiply* or *Divide*. The operation is applied to the currency to which the conversion is performed to get the currency selected in the row.

 For details, see [Configuration of Rate Types and Rates: General Information](../ImplementationGuide/config_Multicurrency_Configuring_Rates_GeneralInfo.md).

|
|**Rate Reciprocal**|The value that is inverse to the specified exchange rate. This automatically calculated value is listed for informational purposes.|

## Effective Currency Rates Tab {#ECR .section}

The table on this tab lists the exchange rates that are effective on the selected effective date.

The table toolbar includes only standard buttons.

|Column|Description|
|------|-----------|
|**From Currency**|The currency whose exchange rate is shown for the **To Currency**.|
|**Currency Rate Type**|The currency rate type specified for the selected currency pair.|
|**Currency Effective Date**|The date on which the currency rate in this row has become effective.|
|**Currency Rate**|The currency exchange rate. For currency conversion, the system uses it along with the operation specified in the **Mult./Div.** column.|
|**Mult./Div.**|The operation to be used for currency conversion: *Multiply* or *Divide*.

 For details, see [Configuration of Rate Types and Rates: General Information](../ImplementationGuide/config_Multicurrency_Configuring_Rates_GeneralInfo.md).

|
|**Rate Reciprocal**|The value that is inverse to the specified exchange rate. This automatically calculated value is listed for informational purposes.|
