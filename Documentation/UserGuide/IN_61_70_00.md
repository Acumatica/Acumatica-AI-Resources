# Historical Inventory Valuation {#_26dc0f85-1f5a-486e-b1d9-457630db0be8 .reference}

Form ID: \(IN617000\)

**Attention:** This report is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

This report displays information about how the balances of the inventory accounts and the costs of the inventory items at different warehouses have changed in the selected time period or range of periods.

The report is available in two formats: summary and detail. In the summary format, the report displays summary data for each inventory account \(and subaccount, if applicable\) resulting from operations with inventory items. In the detailed format, the report displays information about each cost subitem in each warehouse involved, and includes the quantities and costs of the items with subitems moving through the warehouse during the selected financial period or range of periods.

**Attention:** In the report, the quantity and amount totals for released purchase returns are deducted from the corresponding receipt totals rather than added to the issue totals.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Company/Branch**: The company, branch, or company group for which you want to view information. By default, the current company or branch is selected. You can select another branch, company, or company group to which you have access or leave the box blank to view information about all companies in the tenant.

    This parameter is required if the *Multiple Base Currencies* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

-   **Format**: The format for the report, which can be *Summary* or *Detail*. If you select *Detail*, you need to select an inventory ID.
-   **Start Period**: The starting financial period for the report.
-   **End Period**: The ending financial period for the report.
-   **Inventory ID**: The inventory ID of the item the report will cover. Select an ID to view only data related to this item, or leave the box blank to view a broader range of data.
-   **Include Goods in Transit**: A check box that indicates \(if selected\) that the report includes transactions posted to the in-transit account.
