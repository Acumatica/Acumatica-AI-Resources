# Agents

Form ID: \(ML202000\)

You use this form to create, configure, and test an AI Automation agent. An agent can retrieve the current record, update the record and its detail lines, and retrieve supporting data from published generic inquiries. After you test the agent, you select the **Active** check box and save your changes. The system adds the corresponding command to the More menu of the target form. When a user clicks this command, the agent executes the task described in its instructions.

This form is available only if the *AI Automation* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar has only standard buttons.

For a predefined agent, the Clipboard menu can contain the **Reset to Default** command. This command restores the predefined instruction text, name, and default settings and discards the changes made to the agent.

## Result Tab \(Bottom Right Pane\)

This tab displays the result of the most recent test. For an agent that updates a record, the tab identifies the affected entity and shows the differences between the values before and after the intended update. Changes to detail lines are grouped by line, and records that would be created are labeled as added.

For the predefined *Expense Receipt Recognition* agent, this tab displays the field names and values extracted from the uploaded receipt file.

When you test an agent that contains masked fields and the LLM sends the processed data back to Acumatica ERP, the system replaces the masked content with the actual data.

## Processing Log Tab \(Bottom Right Pane\)

This tab displays the processing details of the most recent test, including the data sent to the LLM, tool schemas and descriptions, tool calls and responses, errors, step duration, and token consumption.

The log includes the following sections:

-   **Agent Processing Started**: The first request sent to the LLM, including the agent instructions, tool schemas, and tool descriptions.
-   Tool-calling steps: The tools called by the LLM, the order of the calls, and the messages exchanged during processing.
-   **Agent Processing Completed**: The complete message thread and the token totals for the execution.

Individual request sections show the token counts calculated by the system. The **Agent Processing Completed** section shows totals calculated by the system and totals reported by the LLM provider. For details, see [Integration with LLM Providers: Collection of Statistics](LLM_Providers_Statistics.md)
