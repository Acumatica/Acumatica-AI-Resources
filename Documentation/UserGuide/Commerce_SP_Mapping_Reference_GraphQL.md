# Shopify GraphQL Mapping {#_d308d13b-b0ca-4d60-cd48-42864f8c1af5 .concept}

Shopify is deprecating the REST API for apps and integrations and switching to GraphQL. The corresponding changes have been implemented in the ecommerce connector.

In this chapter, you will find topics that show the changes to the field mapping that take place because of the migration from REST API to GraphQL. Some fields that were available through the REST API are not available in GraphQL. Because of this, after the upgrade to 2026 R1, we recommend to review your mappings on the [Entities](BC_20_20_00.md) \(BC202000\) form.
