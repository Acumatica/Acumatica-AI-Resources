# Audit History by Screen {#_6bb16129-f548-4b68-98b7-f46fb31eec6a .reference}

Form ID: \(SM205530\)

You can use this form to view the audit trail of the audited form—that is, the recorded database table changes that are associated with the modifications of the records created by using the audited form. The audit trail shows the user who modified the record, the date and time of the update, and the details of the modification of the selected database table. You can filter the modifications that you view in any audited database table by user and by date range.

## Form Toolbar {#section_pfg_x2v_djc .section}

|Button|Description|
|------|-----------|
|**Manage**|Opens the [Audit](SM_20_55_10.md) \(SM205510\) form for the selected audit.|

## Selection Area {#1 .section}

You use this area to specify the form and database table associated with the form for which you want to view the audit trail. You can also specify a particular user and date range.

|Element|Description|
|-------|-----------|
|**Screen ID**|Required. The ID and the name of the screen \(form\) whose audit trail you want to see.|
|**User**|The user who made the changes. Select a user if you want to view the changes made by the user. You can leave the box blank to view all recorded changes.|
|**Start Date**|The start date of the date range during which the changes took place. Specify a date if you want to view the changes made starting with this date.|
|**Table Name**|Required. The database table for which you want to see the audit trail. The drop-down lists only the database tables that are associated with the selected screen and have auditing enabled on the [Audit](SM_20_55_10.md) \(SM205510\) form.|
|**End Date**|The end date of the date range during which the changes took place. Specify a date if you want to view the changes made up to this date.|

## Records Table {#2 .section}

This table displays the records of the modifications of the selected database table. The contents of this table depend on the database table you selected in the **Table Name** box.

## Events Table {#section_qfg_x2v_djc .section}

This table shows who changed the record, when the changes were made, what operation was done, and which columns of the database table were modified.

|Column|Description|
|------|-----------|
|**Operation**|The type of recorded operation.|
|**Date and Time**|The date and time of the event.|
|**Username**|The user who modified the record.|
|Record Columns|Columns that represent form elements and that display the changes in the selected record. If a column is blank, the corresponding value was unmodified.|

## Update History Dialog Box {#section_rfg_x2v_djc .section}

If auditing is turned off for a form and you click **Settings** &gt; **Audit History** on the form title bar, the **Update History** dialog box opens instead of the **Audit History** page. In this dialog box, you can see information about the creation and last modification of the selected record. You can click **Enable Field Level Audit** to turn on auditing of the form.

|Element|Description|
|-------|-----------|
|**Created By**|The user who created the selected record.|
|**Created Through**|The ID of the form used to create the selected record.|
|**Created On**|The date and time when the selected record was created.|
|**Last Modified By**|The user who made the last modifications to the selected record.|
|**Last Modified Through**|The ID of the last form used to modify the selected record.|
|**Last Modified On**|The date and time of the last modification to the selected record.|
|The dialog box has the following buttons.|
|**Enable Field Level Audit**|Opens the [Audit](../Shared/../UserGuide/SM_20_55_10.md) \(SM205510\) form for the selected form.|
|**Cancel**|Closes the dialog box.|
