# Service Templates {#_a9b066ee-d519-454a-98d3-51706c09f894 .reference}

Form ID: \(FS204900\)

On this form, you can create a new service template or view the properties of an existing one. For details, see [Service Templates](FS__CON_Service_Templates.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

In this area, you can view the general properties of a service template.

|Element|Description|
|-------|-----------|
|**Service Template ID**|The identifier of the service template.|
|**Description**|A description of the service template.|
|**Service Order Type**|The service order type of the services that are going to be added to the template.|

## Details Section { .section}

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Line Type**|The type of line involved in the service template. Depending on the type of line, other columns may or may not be available. The options are: -   *Service*: The line is a service.
-   *Non-Stock Item*: The line is a non-stock item with a type other than service.
-   *Inventory Item*: The line is a stock item.

**Tip:** You can add stock items only if **Sales Orders** or **None** is selected in the **Billing Settings** section on the [Service Order Types](../Shared/../UserGuide/FS_20_23_00.md) \(FS202300\) form for the service order type specified in the service template.

-   *Comment*: The line is a comment. You can use it to indicate a remark about the service to the staff member.
-   *Instruction*: The line is an instruction. You can use it to indicate an instruction about the service for the staff member.

|
|**Inventory ID**|The identifier of the item.|
|**Quantity**|The number of items. This column is available only if *Service* or *Non-Stock Item* is selected in the **Line Type** box.|
|**UOM**|The unit of measure used for the item selected in the **Inventory ID** column. When you select an item in the **Inventory ID** column on the current tab, the system populates this column with the UOM specified i the **Sales Unit** box of the **General** tab of the [Non-Stock Items](IN_20_20_00.md) \(IN202000\) or [Stock Items](IN_20_25_00.md) \(IN202500\) form.

|
|**Transaction Description**|A description of the line item. If the line type is *Service* or *Non-Stock Item*, the system automatically completes this field with the service description. If the line type is *Comment* or *Instruction*, you enter a comment or instruction in this field.|
