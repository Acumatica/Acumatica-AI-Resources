# Reminders Dialog Box {#_24c486ee-f77e-4709-a5ec-a64cd14bcb94 .reference}

The Reminders dialog box opens when you click the Reminders button \(![](Images/Reminders_Button.png)\) in the info area. The Reminders dialog box lists upcoming events and tasks that are overdue or approaching their due dates, if reminders have been configured for them.

## Reminders Dialog Box { .section}

In the Reminders dialog box, you can manage reminders.

|Element|Description|
|-------|-----------|
|**Refresh**|Refreshes the list of tasks and events.|
|**View Details**|Displays the details of the selected task or event.|
|**Dismiss**|Removes the selected task or event from the list.|
|**Snooze**|Postpones the selected reminder for the time interval you select from the list.|
|**All Tasks**|Opens the Tasks \(EP4040PL\) form.|
|**All Events**|Opens the Events \(EP4041PL\) form.|
|**Close**|Closes the Reminders dialog box.|
