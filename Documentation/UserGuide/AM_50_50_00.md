# Regenerate Inventory Planning {#_588d4939-b533-4b84-8016-cf34e2be17d5 .reference}

Form ID: \(AM505000\)

**Attention:** This form is available only if the *Material Requirements Planning* or *Distribution Requirements Planning* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this form to initiate inventory planning regeneration. You can run this process at any time. However, it may impact the performance of your Acumatica ERP instance. The duration of this process may depend on the volume of the incoming item plans and the value specified in the **Planning Horizon** box on the [Inventory Planning Preferences](AM_10_00_00.md) \(AM100000\) form, which can be used to restrict the number of records to be processed.

**Attention:** Note the following about the inventory planning regeneration process:

-   Only one instance of it can run at a time.
-   It should run only when no users or processes may be modifying order data.
-   We recommend scheduling it to run when most users are signed out.

You can determine if this process is running by using the [System Monitor](SM_20_15_30.md) \(SM201530\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Command|Description|
|-------|-----------|
|**Process**|Starts the inventory planning regeneration.|
|**Schedules**|You can select one of the following options:

 -   *Add*
-   *View*
-   *History*

 For details, see [Inventory Planning Configuration: General Information](../ImplementationGuide/config_Inventory_Planning_GeneralInfo.md).

 **Attention:** The [Automation Schedules](SM_20_50_20.md) \(SM205020\) form is available only if the *Scheduled Processing* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**History**|Opens the [Inventory Planning History](AM_00_00_16.md) \(AM000016\) form with information about all inventory planning generation processes.|

## Selection Area { .section}

This area contains information about the last inventory planning regeneration.

|Element|Description|
|-------|-----------|
|**Last Completed At**|The date and time of the last inventory planning regeneration that has been completed.|
|**Last Completed By**|The username of the user who performed the last inventory planning regeneration that has been completed.|

## Table { .section}

The table displays the steps of the process. The system updates the steps when inventory planning regeneration is completed.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Created At**|The date and time of the step in the process of inventory planning regeneration. The date and time is displayed in the time zone of the user who initiated the process.|
|**Message**|The message that indicates which step in the inventory planning regeneration has been executed.|
|**Created By**|The username of the user who started the inventory planning regeneration.

 This column is hidden by default.

|
|**Message Type**|The type of the message, which can be one of the following:

 -   *Started*
-   *Information*
-   *Added*

 This column is hidden by default.

|
|**Process ID**|The identifier assigned to the process by the system.

 This column is hidden by default.

|
