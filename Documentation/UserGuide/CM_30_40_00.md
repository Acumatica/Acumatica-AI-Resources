# Translation Worksheets

Form ID: \(CM304000\)

You can use this form to view the details of existing translation worksheets and to edit the details of the unreleased translations, if needed. You can also release a translation worksheet on this form.

**Attention:** This form is available only if the *Translation of Financial Statements* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Release**|Releases the translation worksheet and generates the appropriate batch.|
|**Translation Details**|Opens the [Translation Details](CM_65_15_00.md) \(CM651500\) report that shows the details of the translation worksheet.|

</td><td>

**Transaction Debit Amount**

</td><td>

The debit amount of the adjusting transaction for the account-subaccount pair. This amount is calculated as the amount in the **Translated Amount** column minus the result of the previous translation with the same translation definition in the **Orig. Translated Amount** column. If the difference is positive, it is recorded as a debit amount, and if the difference is negative, it is recorded as a credit amount and the debit amount is set to zero.

</td></tr><tr><td>

**Transaction Credit Amount**

</td><td>

The credit amount of the adjusting transaction for the account-subaccount pair. This amount is calculated as the amount in the **Translated Amount** column minus the result of the previous translation with the same translation definition in the **Orig. Translated Amount** column. If the difference is negative, it is recorded as a credit amount; if the difference is positive, it is recorded as a debit amount and the credit amount is set to zero.

</td></tr></tbody>
</table>
