# Payroll Time Details by Paycheck {#_2edc7dc0-f9b4-4ce4-a74a-ff00c5906de4 .reference}

Form ID: \(PR641020\)

This report displays information about the hours reported by employees along with the details, such as earning codes, rates, and wages, which are required for the payroll calculation.

Data from voided paychecks is not included in the report.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Company/Branch**: The company or branch for which you want to view information. By default, the current company or branch is selected.
-   **Select By**: The date to which the specified date range should be applied, with the following options available: *Transaction Date* and *Period Start/End Date*.
-   **Date From**: The start date of the date range.
-   **Date To**: The end date of the date range.
-   **Employee**: The employee for which you want to view information. Select an employee, or make no selection to request information for all employees.
-   **Earning Type Code**: The earning type for which you want to view information. Select an earning type code, or make no selection to request information for all earning codes used in reported employee activities.
-   **Work Location**: The work location for which you want to view information. Select a work location, or make no selection to request information for all available work locations.
-   **Pay Rate**: The pay rate for which you want to view information. Specify a pay rate, or leave the box empty to request information for all pay rates.
-   **Project**: The project for which you want to view information. Select a project, or make no selection to request information for all projects associated with reported employee activities.
-   **WCC**: The workers' compensation code for which you want to view information. Select an employee, or make no selection to request information for all workers' compensation codes used in reported employee activities.
-   **Include Unreleased**: A check box that you select if the data from unreleased documents should be included in the report.
