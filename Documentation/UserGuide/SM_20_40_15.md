# Exchange Integration Configuration {#_2d8bad8a-abc8-476a-9d8a-09e6d5497658 .reference}

Form ID: \(SM204015\)

You use this form to configure the synchronization between your Microsoft Exchange Server and the Acumatica ERP instance.

After you configure the synchronization, you select the employees whose accounts will be synchronized and the synchronization policies to be applied.

Acumatica ERP can be integrated with Microsoft Exchange Server 2013 or later.

The license for your Acumatica ERP instance must include the following features, which must be enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form:

-   *Exchange Integration*: Required for the configuration and management of integration with Exchange Server
-   *Scheduled Processing*: Required for the setup of synchronization schedules

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Test Server**|Tests the server configuration.|
|**Initialize Server**|Configures the Exchange mailboxes of the users that are selected in the table. Based on the specified synchronization policy, the system adds the category that will be used to mark the exported records from Acumatica ERP and the folders for contacts, emails, tasks, and events.|
|**Sign In**|Signs in to the external email service.|
|**Sign Out**|Signs out from the external email service.|

## Summary Area {#1 .section}

You can use this area to add accounts for Exchange servers you want to synchronize the Acumatica ERP instance with, or to select an existing account to view and edit its details.

|Element|Description|
|-------|-----------|
|**Name**|Required. The account name of the Exchange server with which you want to synchronize the Acumatica ERP instance.|
|**Is Active**|A check box you select to enable synchronization with the selected Exchange server.|
|**Web Services**|The type of web service API to be used for Exchange server synchronization. The following options are available:-   *EWS \(Exchange On-Premises\)*: The system uses the Exchange Web Services API for synchronization.
-   *Microsoft Graph \(Microsoft 365\)*: The system uses the Microsoft Graph API for synchronization.

**Note:** Microsoft plans to retire the Exchange Web Services API, so we recommend using the Microsoft Graph API for new integrations.

|
|**Default Sync Policy**|The synchronization policy that would be used by default.**Note:** You use the [Exchange Integration Policies](SM_20_40_10.md) \(SM204010\) form to add, delete, and manage synchronization policies.

|

## Configuration Tab {#section_rh5_bxq_m3c .section}

By using this tab, you can configure accounts for Exchange servers or view and possibly update existing ones.

|Element|Description|
|-------|-----------|
|**Username**|The username of the delegated mailbox on the Exchange server to be used for synchronization.**Note:** The delegate must have permissions to read, send, and delete messages on behalf of the employee accounts. The account must be enabled and verified and may not require a password change on the next sign-in.

The box is available if the *EWS \(Exchange On-Premises\)* option is selected in the **Web Services** box.

|
|**Authentication Method**|The authentication method to be used to access the email account. The following options are available:-   *Basic Authentication*: The system uses the username and password specified in the **Username** and **Password** boxes, respectively.
-   *OAuth2*: The system uses the OAuth 2.0 method.

The box is available if the *EWS \(Exchange On-Premises\)* option is selected in the **Web Services** box.

|
|**Password**|The password for the delegated mailbox you specified in the **Email Address** box.

 The box is available if the *Basic Authentication* option is selected in the **Authentication Method** box.

|
|**Azure Tenant ID**|The identifier of the Azure tenant in which the connector to Exchange Server or Exchange Online \(Office 365\) is registered.

 The box is available in the following cases:

 -   If the *Microsoft Graph \(Microsoft 365\)* option is selected in the **Web Services** box.
-   If the *OAuth2* option is selected in the **Authentication Method** box.

|
|**External Application**|The connector to Exchange Server or Exchange Online \(Office 365\) configured on the [External Applications](SM_30_10_00.md) \(SM301000\) form.

 The box is available in the following cases:

 -   If the *Microsoft Graph \(Microsoft 365\)* option is selected in the **Web Services** box.
-   If the *OAuth2* option is selected in the **Authentication Method** box.

|

|Element|Description|
|-------|-----------|
|**Mail Server \(Optional\)**|The URL of the Exchange server. Generally, the server URL is automatically detected when you test the account; if the URL has not been detected, you must specify the server URL. You can also specify the URL to speed the testing.**Note:** For a standalone installation, you must specify the server URL.

|
|**Logging Level**|The level of diagnostic logging. The following options are available:-   *Default*: Critical issues, warnings, and errors are logged.
-   *Informational*: The basic events are logged, which includes critical issues, warnings, and errors.
-   *Verbose*: All events are logged. This is the highest level of logging.
-   *None*: Nothing is logged.

|
|**Max Attachment Size**|The limit of the attachment size that would by downloaded to Acumatica ERP, specified in KB. By default, the max attachment size is set to 10240 KB.|

|Element|Description|
|-------|-----------|
|**Accounts in Batch**|The quantity of accounts in the batch.|
|**Update Batch Size**|The quantity of elements in the batch uploaded to the Exchange server. The default batch size is 25 elements.|
|**Select Batch Size**|The quantity of elements in the batch downloaded from the Exchange server. The default batch size is 100 elements.|

## Mailboxes Tab {#section_qf4_fzq_m3c .section}

On this tab, you can see the employees whose mailboxes are synchronized with the selected Exchange server. You can also see the synchronization policies that are applied when synchronization is performed.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Sync Account**|A check box you select to perform synchronization for the selected employee account.|
|**Employee ID**|The ID of the employee.|
|**Employee Name**|The name of the employee.|
|**Status**|The status of the employee.|
|**Email Address**|The email address of the employee.|
|**Policy Name**|The synchronization policy that is applied when synchronization is performed.|
