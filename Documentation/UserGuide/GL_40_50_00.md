# Reclassification History

Form ID: \(GL405000\)

On this form, you can view the list of transactions generated by the reclassification process for a particular original transaction. The original general ledger transaction is displayed in the first row of the table.

## Form Toolbar

The form toolbar includes the buttons described below.

</th></tr></thead><tbody><tr><td>

</td><td>

</td></tr><tr><td>

**Reclassify All**

</td><td>

Opens the [Reclassify Transactions](GL_50_60_00.md) \(GL506000\) form with all transactions displayed that can be reclassified.

 This button appears on the form only if the reclassification history contains split transactions.

</td></tr><tr><td>

**Reclassification History**

</td><td>

 This button appears on the form only if the reclassification history contains split transactions.

</td></tr></tbody>
</table>
