# Photo

Form ID: \(PJ305010\)

**Attention:** This form is available only if the *Construction Project Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this form to review the details of a photo uploaded in a photo log and to upload a new version of the photo. For more information on working with photo logs, see [Photo Logs: General Information](Construction_Photo_Logs_GeneralInfo.md).

## Summary Area

In this area, you can review the settings of an existing photo, upload a new version of this photo, or upload a new photo to a photo log.

<table id="_5b36108b-e9c1-483d-80a8-21fa680546ba"><thead><tr><th>

Element

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Photo Log ID**

</td><td>

The identifier of the photo log to which the photo is uploaded. You can move the uploaded photo from one photo log to another by changing the identifier in this box.

</td></tr><tr><td>

**Change Photo**

</td><td>

A button you can click to open the **Upload New Photo** dialog box, in which you can select a new version of the photo to be uploaded to the current photo record. By default, you can upload a file whose size is up to 25 MB, and the files with the `.gif`, `.ico`, `.jpg`, `.png`, and `.tif` file extensions can be uploaded. An administrative user can change the maximum file size and the list of the supported file extensions on the [File Upload Preferences](SM_20_25_50.md) \(SM202550\) form.

</td></tr><tr><td>

**Photo ID**

</td><td>

The unique identifier of the photo. When you save a new photo, the system inserts this ID based on the numbering sequence selected on the **Photo Log** tab of the [Project Management Preferences](PJ_10_10_00.md) \(PJ101000\) form.

</td></tr><tr><td>

**Name**

</td><td>

The name of the uploaded file.

</td></tr><tr><td>

**Description**

</td><td>

A brief description of the photo.

</td></tr><tr><td>

**Tags**

</td><td>

The tags that are assigned to the file.

 You can add or delete tags if you have a user role with the *Edit* access level to a tag assigned to the file. User roles’ access rights to tags are specified on the [File Tags](SM_20_25_60.md) \(SM202560\) form.

</td></tr><tr><td>

**Uploaded On**

</td><td>

The business date when the photo was uploaded. When you upload the photo, the system inserts the current business date.

</td></tr><tr><td>

**Uploaded By**

</td><td>

The username of the employee that has uploaded the photo.

</td></tr><tr><td>

**Main Photo**

</td><td>

A check box that indicates \(if selected\) that the photo is the main photo of the log. That is, with the check box selected, if the photo log of this photo is selected in the right pane of the **Photos** tab of the [Photo Logs](PJ_40_50_00.md#) \(PJ405000\) form, this photo is shown as a preview photo for the photo log in the preview area in the right pane of the same tab.

 This check box can be selected only for one photo in the log. If no photo is selected as the main photo of the photo log, the preview area of the [Photo Logs](PJ_40_50_00.md#) form will be empty if a user selects the photo log in the left pane on the **Photos** tab of that form.

</td></tr></tbody>
</table>

|Column|Description|
|------|-----------|

|**Value**|The value of the attribute for the photo.|

|Element|Description|
|-------|-----------|
|Preview area|An area that displays the preview of the photo.|
