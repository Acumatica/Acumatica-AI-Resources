# Mobile Workspaces

Form ID: \(AU220012\)

You use this form to manage workspaces for the Acumatica mobile app. You can add new workspaces, remove existing ones, and change the order in which workspaces are displayed on the main menu of the mobile app. From this form, you can also view the settings of the workspaces. For details, see [Mobile Workspace](AU_22_00_13.md).
