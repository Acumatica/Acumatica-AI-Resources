# Subcontract Agreement \(LF\) {#_a0c32927-083e-4acf-a857-faf610dc3fe9 .reference}

Form ID: \(SC643000\)

**Note:** This report is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

By using this report, you can prepare the printable subcontractor agreement for the selected subcontract.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameter {#section_v25_hdz_tmb .section}

On the **Report Parameters** tab, use the following parameter to select the information to be displayed on the report:

-   **Subcontract Number**: The number of the subcontract for which the subcontract agreement will be prepared; this is a required element.
