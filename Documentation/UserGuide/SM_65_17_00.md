# Access Rights by Screen {#_c6643d30-0251-450b-8352-9a6fc61d358d .reference}

Form ID: \(SM651700\)

This report lists all system forms with user roles for which access rights to the form have been set up explicitly at the form, module, or suite level. Each role's level of access rights to the form is displayed.

The report has no report-specific parameters.
