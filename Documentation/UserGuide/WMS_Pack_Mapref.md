# Automated Packing Operations {#_e83b1513-b9ee-49ed-b84e-7e7e06caa8a7 .concept}

In Acumatica ERP, you can process the packing of items for shipment in an automated mode by using barcode scanners or mobile devices with a scanning option on the [Pick, Pack, and Ship](SO_30_20_20.md) \(SO302020\) form or the Pick, Pack, and Ship screen in the Acumatica mobile app. This functionality becomes available when the *Fulfillment* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

The topics of this chapter describe the workflow that you can configure to support the automated processing of shipments with the automated packing of items for shipment.

-   **[Packing Operations: Implementation Checklist](../UserGuide/WMS_Pack_Implem_Checklist.md)**  

-   **[Packing Operations: Process Activity](../UserGuide/WMS_Pack_Process_Activity.md)**
