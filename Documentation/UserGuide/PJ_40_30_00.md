# Drawing Logs {#_2ab927f9-e455-4e02-a6ef-e337c73f09c2 .reference}

Form ID: \(PJ403000\)

**Attention:** This form is available if the *Construction Project Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this form to view all the drawing logs created in the system or the drawing logs for a specific project, project task, or discipline. You can also create new drawing logs for a project.

For drawing logs selected in the table, you can also create requests for information or project issues. You can download a ZIP file with all the files of the selected drawing logs.

## Form Toolbar { .section}

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Create RFI**|Opens the [Request for Information](PJ_30_10_00.md#) \(PJ301000\) form with the new request for information and links the drawing logs for which the Included check box is selected in the table to this request for information.|
|**Create Project Issue**|Opens the [Project Issue](PJ_30_20_00.md#) \(PJ302000\) form with the new project issue and links the drawing logs for which the Included check box is selected in the table to this project issue.|
|**Export Drawings**|Downloads a ZIP file with the files of the drawing logs for which the Included check box is selected in the table to your device.|

## Selection Area {#1 .section}

You use the elements in this area to select the criteria of drawing logs to be displayed in the table.

|Element|Description|
|-------|-----------|
|**Project**|The project to which drawings are related.|
|**Project Task**|The project task to which drawings are related.

 This box is available only if the project is selected in the **Project** box.

|
|**Discipline**|The discipline related to the drawing log.|
|**Show Latest Revisions Only**|A check box that indicates \(if selected\) that only the drawing logs marked as current is current \(that is, the **Latest Revision** check box is selected for the drawing log on the [Drawing Log](PJ_30_30_00.md#) \(PJ303000\) form\).|

## Table { .section}

In this table, you can review the list of existing drawing logs, modify their details, or add new drawing logs.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include this drawing log for processing if you create a new request for information or project issue or click **Export Drawings** on the table toolbar.|
|**Drawing Log ID**|The identifier of the drawing log.|
|**Project**|The project related to the drawing log.|
|**Project Task**|The project task related to the drawing log.|
|**Discipline**|The discipline of the drawing log.|
|**Drawing Number**|The drawing number.|
|**Revision**|The revision number of the drawing log.|
|**Sketch**|The identifier of the sketch.**Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Title**|The title of the drawing log.|
|**Description**|The description of the drawing log.**Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Status**|The status of the drawing log.|
|**Drawing Date**|The business date when the drawing log was created.|
|**Received Date**|The business date when the drawing log was received.**Attention:** This column is hidden by default. You can display this column in the table by using the **Column Configuration** dialog box. For details, see [Adjustment of the Acumatica ERP UI: To Personalize a View of a Form](../Shared/../UserGuide/GS_ModernUI_User_Interface_Personalization_Activity.md).

|
|**Original Drawing**|The identifier of the preceding version of the drawing log.|
|**Owner**|The owner of the drawing log.|
