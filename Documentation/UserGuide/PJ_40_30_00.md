# Drawing Logs

Form ID: \(PJ403000\)

**Attention:** This form is available if the *Construction Project Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this form to view all the drawing logs created in the system or the drawing logs for a specific project, project task, or discipline. You can also create new drawing logs for a project.

For drawing logs selected in the table, you can also create requests for information or project issues. You can download a ZIP file with all the files of the selected drawing logs.

## Form Toolbar

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Create RFI**|Opens the [Request for Information](PJ_30_10_00.md#) \(PJ301000\) form with the new request for information and links the drawing logs for which the Included check box is selected in the table to this request for information.|
|**Create Project Issue**|Opens the [Project Issue](PJ_30_20_00.md#) \(PJ302000\) form with the new project issue and links the drawing logs for which the Included check box is selected in the table to this project issue.|
|**Export Drawings**|Downloads a ZIP file with the files of the drawing logs for which the Included check box is selected in the table to your device.|
