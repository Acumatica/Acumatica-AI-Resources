# Managing Integration with External Applications {#_b083cff6-70c6-44a9-92af-1619ecb79cd3 .concept}

In Acumatica ERP, you can build external applications into the product. For example, you can build Microsoft Power BI reports into Acumatica ERP so that users of your Acumatica ERP instance have these reports at hand when they work in Acumatica ERP.

Acumatica ERP supports integration with Microsoft Power BI. For more information, see [Managing Power BI Integration](RP__Integration_Power_BI.md).
