# Employee Time Billing: Generated Transactions

To be able to bill customers for employee time spent on particular projects, you configure time tracking in projects. When project-related time cards are released, the system generates the transactions described in the following sections.

**Attention:** The transactions generated during release depend on the following settings:

-   For non-payroll employees, if *Post PM and GL Transactions* is selected in the **Project Time for Non-Payroll Employees** box on the [Time and Expenses Preferences](EP_10_10_00.md) \(EP101000\) form, the system generates project and GL transactions.
-   For payroll employees, the **Time Posting Option** box on the [Payroll Preferences](PR_10_10_00.md) \(PR101000\) form determines which transactions are generated. If *Post PM Transactions from Time Activities and Override Them with Payroll Information* is selected, the system generates project transactions only. If *Post PM and GL Transactions from Time Activities and Override Them with Payroll Information* is selected, the system generates project and GL transactions.

Project-branch alignment can affect the branch and processing of these transactions. For details, see [Employee Time Billing: Branch Alignment in Time Tracking and Correction](Projects_Tracking_Time_Branch_Alignment.md).

## Project Transaction Generated for a Time Card

When you release a project-related time card, the system generates the following project transaction for each time activity in the time card line.

|Project and Project Task|Account Group|Inventory ID|Billable Quantity|Unit Rate|Amount|
|------------------------|-------------|------------|-----------------|---------|------|
|Project and project task in the time card line|Account group mapped to Expense account|Labor item in the time card line|Reported billable hours in the time card line|Labor cost rate defined on the [Labor Rates](PM_20_99_00.md) \(PM209900\) form|Billable quantity \* unit rate|

You can review the project transaction that was generated on release of a particular time card by opening a time card on the [Employee Time Cards](EP_30_50_00.md) \(EP305000\) form and clicking **View Transactions** on the form toolbar.

## GL Transaction Generated from a Project Transaction

When a project transaction related to time card is released, the system creates a batch of the following accounting transactions.

|Account|Project|Project Task|Debit|Credit|
|-------|-------|------------|-----|------|
|Expense account defined by the **Expense Account Source** setting on the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form|The value in the time card line|The value in the time card line|Billable quantity \* unit rate|0.00|
|Expense Accrual account defined by the **Expense Accrual Account Source** setting on the [Projects Preferences](PM_10_10_00.md) form|Non-project code|Empty|0.00|Billable quantity \* unit rate|

You can view the reference number of the GL batch in the **GL Batch Nbr.** box in the project transaction line on the [Project Transactions](PM_30_40_00.md) \(PM304000\) form. You can click the link in this box to view the details of the batch on the [Journal Transactions](GL_30_10_00.md) \(GL301000\) form.

## GL Transaction Generated from an AR Invoice

When an AR invoice generated by the project billing procedure is released, the system creates a batch of the following accounting transactions.

|Account|Project|Project Task|Debit|Credit|
|-------|-------|------------|-----|------|
|Accounts Receivable account of the customer|Non-project code|Empty|Invoiced amount|0.00|
|Sales account of the labor item|The value in the time card line|The value in the time card line|0.00|Invoiced amount|

You can view the reference number of the GL batch in the **GL Batch Nbr.** box in the project transaction line on the [Project Transactions](PM_30_40_00.md) \(PM304000\) form. You can click the link in this box to view the details of the batch on the [Journal Transactions](GL_30_10_00.md) \(GL301000\) form.

## Project Transactions Generated from GL Transaction

When the batch of GL transactions generated on release of an AR invoice generated by the project billing procedure is released, the system generates the following project transaction for each invoice line.

|Project and Project Task|Account Group|Inventory ID|Amount|Debit Account|
|------------------------|-------------|------------|------|-------------|
|The values in the time card line|Account group mapped to the Sales account|Labor item assigned to the employee|Amount calculated by billing rule|Sales account of the labor item|

You can review the project transaction that was generated on release of a particular time card by opening a time card on the [Employee Time Cards](EP_30_50_00.md) \(EP305000\) form and clicking **View Transactions** on the form toolbar.

## Transactions Generated for Corrective Time Cards

When project-branch alignment applies, and you correct a released time card, the generated transactions depend on the changes made in the corrective time card. The transaction-affecting settings include:

-   Project
-   Project task
-   Cost code
-   Union
-   Labor item
-   Shift code
-   Work class compensation code
-   Calculated labor cost rate
-   State of the **Billable** check box

Time activities that haven't been changed in a corrective time card don't generate additional project or GL transactions.

|Change in the Time Card|Project Transaction Line|Branch|
|-----------------------|------------------------|------|
|A transaction-affecting setting is changed|An opposite-sign line for the original values|The branch of the original project transaction|
|A new line for the corrected values|The branch of the new project transaction|
|Only time or billable time is changed|A line for the difference between the original and corrected values|The branch of the original project transaction|

When the project transaction lines generated from a corrective time card are released, the system generates the following GL transaction lines. The amount can be positive or negative, depending on the amount of the corresponding project transaction line.

|Change in the Time Card|Account|Branch|Debit|Credit|
|-----------------------|-------|------|-----|------|
|A transaction-affecting setting is changed; an opposite-sign project transaction line is generated for the original values.|Expense account|Branch of the original project transaction|0.00|Original amount of the project transaction line|
|Liability account|Original employee branch|Original amount of the project transaction line|0.00|
|A transaction-affecting setting is changed; a new project transaction line is generated for the corrected values.|Expense account|Branch of the new project transaction|Corrected amount of the project transaction line|0.00|
|Liability account|Employee branch determined during release of the corrective time card|0.00|Corrected amount of the project transaction line|
|Only time or billable time is changed; a project transaction line is generated for the difference between the original and corrected values.|Expense account|Branch of the original project transaction|If the amount is positive, the difference between the original and corrected amounts of the project transaction line; otherwise, 0.00|If the amount is negative, the difference between the original and corrected amounts of the project transaction line; otherwise, 0.00|
|Liability account|Original employee branch|If the amount is negative, the difference between the original and corrected amounts of the project transaction line; otherwise, 0.00|If the amount is positive, the difference between the original and corrected amounts of the project transaction line; otherwise, 0.00|
