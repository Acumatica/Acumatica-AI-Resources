# Deferral Schedule Summary {#_6b1992fa-1346-4773-9f83-5fd7fc49add2 .reference}

Form ID: \(DR401000\)

On this form, you can view the details of revenue or expense recognition.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

You can use the Selection area to specify selection criteria for schedules and then view the schedules matching the criteria in the table.

|Element|Description|
|-------|-----------|
|**Code Type**|The type of deferral code. Select one of the following options:

 -   *Revenue*: To view the details of revenue recognition
-   *Expense*: To view the details of expense recognition

|
|**Deferral Account**|The account used to hold unrecognized amounts.|
|**Deferral Sub.**|The corresponding subaccount used to flag the unrecognized amounts.|
|**Deferral Code**|A deferral code assigned to document lines. Select a code from the list of codes defined in the system, or leave the box blank to view documents with any codes of the type.|
|**Business Account**|The customer or vendor \(by its ID\) that is associated with the document.

 In this box, you can select a customer or vendor whose settings permit the use of the branch selected in the document—that is, a customer or vendor for which the **Restrict Visibility To** box on the **Financial** tab of the [Customers](AR_30_30_00.md) \(AR303000\) or [Vendors](AP_30_30_00.md) \(AP303000\) form is empty or contains the branch specified in this document \(or the company or company group that contains this branch\).

 **Attention:** These visibility restrictions are applicable only if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Company/Branch**|The company, branch, or company group for which you want to view information. By default, the current company or branch is selected. You can select another branch, company, or company group to which you have access. This setting is required if the *Multiple Base Currencies* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.|
|**Component**|The component of the package, if the item is a package. For details about packages, see [Managing Recognition for Packages](DR__con_Revenue_Recognition_for_Packages.md).

|
|**Total Scheduled**|The total amount for the schedules that match the selection criteria, which the system calculates automatically.|
|**Total Deferred**|The total deferred amount for the schedules that match the selection criteria, which the system calculates automatically.|

## Table {#2 .section}

This table contains a list of schedules that meet the criteria specified in the Selection area.

|Column|Description|
|------|-----------|
|**Schedule Number**|The unique number of the deferral schedule. When you click the link, the system opens the [Deferral Schedule](DR_20_15_00.md) \(DR201500\) form and displays the details of the schedule for the selected line of the original document \(if different deferral codes were assigned to different lines of the original document\).|
|**Doc. Type**|The type of the original document for which the schedule was generated.|
|**Ref. Nbr.**|The reference number of the document.|
|**Branch**|The branch for which the deferral schedule was generated.|
|**Component ID**|The component if the line item is a package and consists of components; otherwise, the inventory ID of the line item.|
|**Line Nbr.**|The transaction number in the database record, which may be different from the line in the document.|
|**Date**|The date of the document.|
|**Status**|The status of the document.|
|**Total Amount**|The total amount of the document. The amounts on credit memos for the *Revenue* code type and on debit adjustments for the *Expense* code type are shown as negative values.|
|**Deferred Amount**|The part of the amount that was deferred. The amounts on credit memos for the *Revenue* code type and on debit adjustments for the *Expense* code type are shown as negative values.|
|**Deferral Code**|The deferral code used for the line.|
|**Deferral Account**|The account that holds the deferral amount.|
|**Deferral Sub.**|The corresponding subaccount.|
|**Account**|The account to which the recognized amounts will be posted.|
|**Subaccount**|The corresponding subaccount.|
|**Business Account**|The identifier of the business account \(which can be, for example, a customer or a vendor\) associated with the document.|
|**Business Account Name**|The name of the business account associated with the document.|
