# Archiving Old Documents {#_00f7317c-2639-4423-a0ca-2a42868de76f .concept}

Every year, users create many documents, such as sales orders and shipments, on Acumatica ERP data entry forms, and their corresponding records are stored in the database. Each document entity is stored in different database tables. For example, one sales order may be associated with sets of records—such as detail lines, line splits, discounts, and taxes—each of which is stored in a different database table. The size of each of these tables increases quickly, which can affect the performance of everyday operational activities, such as opening lists of records, inquiry forms, or lookup tables that require loading a large number of records.

To optimize the performance of the system within the users' daily activities, in Acumatica ERP, the document archival functionality can be used. The topics of this chapter describe this functionality in detail.
