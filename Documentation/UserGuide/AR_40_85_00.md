# Dunning Letter History by Document

Form ID: \(AR408500\)

By using this form, you can view the history of produced dunning letters for documents of the selected customer account. For more information on producing dunning letters, see [Preparation of Dunning Letters: General Information](CreditPolicy_Preparing_Dunning_Letters_GeneralInfo.md).

This form is available only if the *Dunning Letter Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**View Dunning Letter**|Opens the [Dunning Letter](AR_30_60_00.md) \(AR306000\) form, where you can view the list of documents included in the letter.|
