# Vendor Locations

Form ID: \(AP303010\)

By using this form, you can add a new location for a particular vendor or view the details of an existing location. You can change a vendor location’s settings only if the related vendor has the *On Hold* status.

**Attention:** This form is available only if the *Business Account Locations* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.
