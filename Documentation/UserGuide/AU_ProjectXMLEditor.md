# Project XML Editor {#_aa0fc077-1a8a-445c-8a84-5ad86c282a4f .reference}

You use the Project XML Editor to edit and review the content of a customization project in XML format.

**Tip:** You open the editor by clicking **File** &gt; **Edit Project XML** on the main menu of the Customization Project Editor. The actual name shown on the page is the name of the customization project.

## Page Toolbar { .section}

The page toolbar contains the name of the customization project and the following buttons.

|Button|Description|
|------|-----------|
|**Download Package**|Saves the project locally as a deployment package.|
|**Save to Database**|Saves the XML code of the project to the database.|
|**Upload Package**|Opens the **Open Package** dialog box, in which you select a deployment package file. The deployment package is a ZIP file with the contents of a customization project. After you have selected the package, you click **Upload** to upload it to the system and display the XML code of the customization project in the Project XML Editor.|

## Source Code Pane { .section}

You use this pane of the page to view and edit the contents of the customization project.
