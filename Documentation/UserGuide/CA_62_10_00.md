# CA Batch Register Detailed {#_986a1e99-aed9-4772-ba85-1b361e3bfcfd .reference}

Form ID: \(CA621000\)

This report displays the details of cash management transactions generated during the specified financial period. Batches are listed by their dates and are shown with all their details, including the users who created and edited the batches.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Company/Branch**: The company or branch for which you want to view information. You can select a company or make no selection to view information about all companies in the tenant.

    By default, the system inserts the company or branch selected on the Company and Branch Selection menu.

-   **Ledger**: The ledger for which you want to display data. You must select a ledger.

    By default, the actual ledger is selected.

-   **From Period**: The first financial period of the period range the report will cover. You must select a period.

    By default, the current financial period is used.

-   **To Period**: The last financial period of the period range the report will cover. You must select a period.

    By default, the current financial period is used.

-   **Created By**: The user who created a batch for whom you want to view information.
-   **Last Modified By**: The user who last modified a batch for whom you want to view information.
-   **Include Unposted Transactions**: A check box that indicates \(if selected\) that information about unposted transactions will be included in the report. This setting takes effect if the **Automatically Post on Release** check box is cleared on the [Cash Management Preferences](CA_10_10_00.md) \(CA101000\) form.
