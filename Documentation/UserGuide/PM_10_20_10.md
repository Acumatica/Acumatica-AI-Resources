# Restriction Groups by Project {#_83e76b71-284e-4c58-9441-7af75ab2dd29 .reference}

Form ID: \(PM102010\)

On this form, you can view the restriction groups that contain a particular project. You can also change the visibility of the project in the system by including it in other restriction groups or excluding it from groups that currently contain it. You can access this form if the *Administrator*, *CS Admin*, or *AcumaticaSupport* role is assigned to your user account on the [User Roles](SM_20_10_05.md) \(SM201005\) form.

**Attention:** You can create restriction groups for managing the visibility of projects by using the [Project Access](PM_10_20_00.md) \(PM102000\) form.

For more information on restriction groups, see [Restriction Groups in Acumatica ERP](SM__con_Overview_of_Restriction_Groups.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

In this area, you can select the project for which you want to view or edit its membership in restriction groups. You can also view additional information about the selected project.

|Element|Description|
|-------|-----------|
|**Project ID**|The project \(by its identifier\) whose membership in restriction groups you want to view \(and edit, if needed\) in the table.|
|**Status**|Read-only. The status of the selected project.|
|**Description**|Read-only. The description of the selected project.|
|**Customer**|Read-only. The customer for the selected project, if the project is external. For an internal project, this box is empty.|
|**Template**|Read-only. The project template that has been used for creating the selected project, if applicable.|
|**Project Group**|Read-only. The project group associated with the selected project.|

## Table {#2 .section}

In this table, you can view the full list of restriction groups in the system, along with basic information about each group. The check box in the unlabeled Included column is selected for each group that contains the project. You can select and clear these check boxes to change the membership of the project in restriction groups.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that indicates \(if selected\) that the selected entity is included in the restriction group.|
|**Group Name**|Read-only. The name of the restriction group.|
|**Description**|Read-only. The description of the restriction group.|
|**Active**|Read-only. A check box that indicates \(if selected\) that the restriction group is active. The system does not enforce restrictions imposed by inactive groups.|
|**Group Type**|Read-only. The type of the restriction group: *A*, *A Inverse*, *B*, or *B Inverse*. For more information, see [Types of Restriction Groups](../Shared/../UserGuide/SM__con_Types_of_Restriction_Groups.md).|
