# Inventory Planning Exceptions {#_05634ed3-1a22-4751-960d-1782a9b08056 .reference}

Form ID: \(AM403000\)

On this form, you can view exceptions that the system generated during the last execution of inventory planning regeneration. These exceptions describe possible issues with supply documents, such as late delivery dates. More than one exception can be generated for the same document. For example, when a document is late and no longer needed, the system generates a *Late*exception and a *Delete* exception related to this document.

**Important:** This form is available only if the *Material Requirements Planning* or *Distribution Requirements Planning* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

The list of exceptions is updated each time inventory planning regeneration is run on the [Regenerate Inventory Planning](AM_50_50_00.md) \(AM505000\) form.

## Table { .section}

In this table, you can view the exceptions that have been generated by the system during inventory planning regeneration.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Inventory ID**|The identifier of the item related to the exception.|
|**Description**|The description of the item related to the exception.|
|**Subitem**|The subitem of the item specified in the **Inventory ID** column.

 This column is visible only if the *Inventory Subitems* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

**Important:** The **Inventory Subitems** check box has been removed from the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form because the functionality associated with the *Inventory Subitems* feature will be phased out. If you have this feature enabled in your system, the associated functionality remains available. To disable the feature, contact your Acumatica support provider.

|
|**Type**|The reason that caused the exception or the suggested action that you can take to resolve the exception; the value is generated automatically.

 The column value can be one of the following:

 -   *Defer*: The supply order is within the period specified in the **Grace Period** box but outside of the period specified in the **Days Before** box on the [Inventory Planning Preferences](AM_10_00_00.md) \(AM100000\) form. The supply order can be deferred to a later date.
-   *Delete*: The supply order is outside the period specified in the **Grace Period** box on the [Inventory Planning Preferences](AM_10_00_00.md) \(AM100000\) form. The supply order can be deleted. This exception is displayed along with the *Late Order* exception.
-   *Expedite*: The supply order is within the period specified in the **Grace Period** box but outside of the period specified in the **Days After** box on the [Inventory Planning Preferences](AM_10_00_00.md) \(AM100000\) form but outside of the period specified in the **Days After** box on this form. The supply order must be expedited to meet the requirement date of a demand document.
-   *Order on Hold*: The purchase order or production order is on hold. This exception is generated only if the **Include On Hold Purchase Orders** or **Include On Hold Production Orders** check box is cleared on the [Inventory Planning Preferences](AM_10_00_00.md) \(AM100000\) form.
-   *Late Order*: The supply order has the current date \(if the inventory planning has been regenerated today\) or an earlier date.
-   *Transfer Available*: The demand document is past due, the required quantity of items in the document is not available in the specified warehouse, and the required quantity is available in another warehouse. In the **Supply Warehouse** column, you can view the warehouse from which the items can be transferred, and in the **Supply Qty.** column, you can view the item quantity available in the warehouse.
-   *Order Without Sched. Shipment Date*: One or both of the following conditions is met for the blanket sales order:
    -   The **Sched. Shipment Date** column of a blanket sales order line is empty on the **Details** tab of the [Sales Orders](SO_30_10_00.md) \(SO301000\) form.
    -   The **Sched. Shipment Date** column is empty for a line detail of any line in the **Line Details** dialog box on the same form.
-   *Transfer without Repl. Warehouse*: A source of *Transfer* has been specified for an item–warehouse combination on the **Inventory Planning** tab of the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form, but no **Source Warehouse** is specified on the same tab.
-   *Circular Transfer*: A circular transfer has been set up in the system—that is, the source warehouse and the destination warehouse are the same.

|
|**Related Document**|The type and the identifier of the supply document related to the exception. You can click the identifier to view document details on the appropriate entry form.|
|**Quantity**|The open item quantity on the supply order whose number is displayed in the **Related Document** box.|

## Side Panel { .section}

By using the side panel, you can continue viewing the list of exceptions generated during inventory planning on the form while simultaneously viewing information related to the exception whose row is selected in the table.

The side panel has one tab, which you can view by clicking the tab's icon. This tab is described below.

|Tab|Description|
|---|-----------|
|**Results by Item**|The [Inventory Planning Results by Item](../Shared/../UserGuide/AM_40_40_00.md) \(AM404000\) form, which displays information about the demand documents and planning recommendations that include the combination of the inventory item and warehouse copied from the selected row.|
