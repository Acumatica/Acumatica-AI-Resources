# Scanners

Form ID: \(SM206540\)

**Note:** This form is available only if the *DeviceHub* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can review and update the list of scanners that have been configured in Acumatica ERP through integration with DeviceHub.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Update Scanner List**|Receives the list of configured scanners from DeviceHub.|

## Table

This table displays the list of scanners that have been configured in Acumatica ERP through integration with DeviceHub.

|Column|Description|
|------|-----------|
|**DeviceHub ID**|The ID of the DeviceHub application in which the scanner has been configured.|
|**Scanner ID**|The unique identifier assigned to the scanner in the DeviceHub settings.|
|**Description**|The brief description assigned to the scanner in the DeviceHub settings.|
|**Active**|A check box that specifies \(if selected\) that the scanner can be used for scanning documents.|
|**Paper Source \(Default\)**|The default paper source to be used for scan jobs performed with this scanner \(as specified in the DeviceHub settings\).|
|**Color Mode \(Default\)**|The default color mode to be used for scan jobs performed with this scanner \(as specified in the DeviceHub settings\).|
|**Resolution \(Default\)**|The default resolution to be used for scan jobs performed with this scanner \(as specified in the DeviceHub settings\).|
|**File Type \(Default\)**|The default file type to be used for scan jobs performed with this scanner \(as specified in the DeviceHub settings\).|
