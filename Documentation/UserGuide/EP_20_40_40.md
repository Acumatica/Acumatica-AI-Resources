# Event and Task Categories {#_c7e0522b-2a46-4089-80a4-0d85d42c1302 .reference}

Form ID: \(EP204040\)

You use this form to add, view, edit, and delete the informational categories to be used for events and tasks. The event and task categories help users prioritize tasks and events. The event categories and highlighting \(if the event has a category for which highlighting has been defined\) can help users easily identify the importance of the event.

On the Events \(EP4041PL\) or Tasks \(EP4040PL\) form, if highlighting has been defined for the category of a listed event or task, you can see the highlighting in the **Category** column.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table { .section}

The form has a table that lists the categories and their settings.

|Column|Description|
|------|-----------|
|**Description**|Required. You enter the category description manually.|
|**Style**|The color to be used to highlight an event or task on the Events \(EP4041PL\) or Tasks \(EP4040PL\) form. You can select one of the predefined options or leave the column blank. The colors corresponding to the predefined options are shown in the following diagram.For more details on the styles for the highlighted elements, see the *Formulas* section of the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form.

|
