# Buildings {#_fba3e351-1011-4fd2-8330-7611903db5aa .reference}

Form ID: \(CS205010\)

By using this form, you can view which buildings belong to which branches and assign available buildings to specific branches.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

In this area, you can select a branch to view the list of its buildings or to assign buildings to it.

|Element|Description|
|-------|-----------|
|**Branch**|The branch for which you want view buildings or assign to which you want to assign buildings.|

## Table {#2 .section}

By using this area, you can add buildings to the list of those assigned to the selected branch or remove the buildings.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Building**|The building to be assigned to the selected branch. Select the building from the list of fixed assets defined as buildings.|
|**Description**|The description of the building.|
