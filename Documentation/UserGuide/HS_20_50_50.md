# HubSpot Marketing List Members {#_93e20ef1-a5b8-43e6-a6f2-acd23e2281e3 .reference}

Form ID: \(HS205050\)

You use this form for the synchronization of marketing list member records with HubSpot.

This form is available only if the *HubSpot Integration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the synchronization process for the records \(that is, the marketing list members\) that you have selected in the table.|
|**Process All**|Initiates the synchronization process for all records \(that is, all marketing list members\) listed in the table.|
|**Fetch**|Updates the list of the records \(that is, the marketing list members\) that you have selected in the table. If the the table lists outdated data, you click the button to request the latest available data.|
|**Fetch and Process All**|Updates the list of the records \(that is, the marketing list members\) in the table and initiates the real-time synchronization process for records of the types for which unlabeled check boxes are selected in the table.|

## Selection Area { .section}

You use the elements in this area to specify selection criteria for the records to be displayed in the table. This area also contains elements that you can use to specify how the processing is performed if any action involving processing is invoked \(**Process**, **Process All**, or **Fetch and Process All**\).

|Element|Description|
|-------|-----------|
|**Marketing List**|The marketing list whose members you want to list in the table \(and thus make available for synchronization\). In this box, you can select any marketing list that has a synchronization state defined. **Note:** A marketing list has to be synchronized in order to be available for selection in this box.

|
|**Action**|The type of action to be applied to the record if the record is processed when you click **Process**, **Process All**, or **Fetch and Process All**. Select one of the following options:-   *Pull Members from HubSpot*: If the marketing list selected in this area is one that is synchronized, the table lists the members of the marketing list in HubSpot.
-   *Push Members to HubSpot*: If the marketing list selected in this area is one that is synchronized,the table lists the members of the marketing list in Acumatica ERP.

|
|**Remove Unprocessed Members from Target List**|A check box that indicates \(if selected\) that after the system processes the selected \(or all\) records in the grid \(when you click **Process**, **Process All**, or **Fetch and Process All**\), all unprocessed or failed record members are removed from the list. For example, if you have selected only two records for processing in the grid, and processed the records by clicking **Process**, the target list will contain only the two selected records.By default, this check box is cleared.

|
|**HubSpot List**|Read-only. The HubSpot contact list that is synchronized with the marketing list you have selected in the **Marketing List**box.|
|**Subscribed Members Only**|A check box that you select to list in the table only marketing list members for which the **Subscribed** check box selected in the members list on the **List Members** tab of the [Marketing Lists](CR_20_40_00.md) \(CR204000\) form.By default, this check box is selected.

The system ignores this check box if the *Pull Members from HubSpot* action is selected. The state of this check box is considered only when the *Push Members to HubSpot* action is selected.

|

## Table { .section}

This table contains a list of marketing list members that meet any criteria you have specified in the Selection area.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include this marketing list member in the synchronization process if you click **Process** or **Fetch** on the form toolbar.|
|**Subscribed**|Read-only. The subscription status of the marketing list member. This column indicates if the membership in this list has been activated for the marketing list member. The state of this column is copied from the **List Members** tab of the [Marketing Lists](CR_20_40_00.md) \(CR204000\) form.|
|**Entity**|Read-only. The list member entity Acumatica ERP. The state of this column is copied from the **List Members** tab of the [Marketing Lists](CR_20_40_00.md) \(CR204000\) form.|
|**Document**|Read-only. The display name of the record in Acumatica ERP. This column contains a link to the entity record in Acumatica ERP, if the entity record exists in Acumatica ERP.|
|**Ext. Ref.**|Read-only. The display name of the record in HubSpot.|
|**Entity Sync Status**|Read-only. The current status of the synchronization of the record.|
|**Membership Sync Status**|Read-only. The current status of the membership synchronization indicating where the member record exists:-   *HubSpot Only*: The entity is a member of HubSpot contact list, but not a member of marketing list in Acumatica ERP.
-   *Acumatica ERP Only*: The entity is a member of Acumatica ERP marketing list, but not a member of HubSpot contact list.
-   *Both Systems*: The entity is a member of list in both HubSpot and Acumatica ERP systems.

|
