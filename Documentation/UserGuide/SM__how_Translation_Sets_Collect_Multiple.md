# To Collect Strings of Multiple Translation Sets {#_eb83e4bf-82d4-487c-8b51-9ab8b718ad0c .task}

You can collect strings from multiple translation sets by using the [Collect Translation Sets](SM_51_15_00.md) \(SM511500\) form. You can also collect strings for translation sets one set at a time on the [Translation Sets](SM_21_15_00.md) \(SM211500\) form, as described in [To Collect the Strings of a Translation Set](SM__how_Translation_Sets_Collect.md). For more information, see [Translation Process](SM__con_Translation_Process.md).

## To Collect Strings of Translation Sets { .section}

1.  Open the [Collect Translation Sets](SM_51_15_00.md) \(SM511500\) form.
2.  Do one of the following:

    -   In the table, select the check boxes next to the sets whose strings you want to collect. If you plan to collect strings from most of the listed sets, instead select the check box in the column header \(to select all check boxes on the page\), and then clear the check boxes preceding the sets whose strings you don't want to collect. \(If the list spans multiple pages, you need to do this on each page.\) Click **Collect**.
    -   Click **Collect All** to collect strings from all the listed sets.
    **Note:** Collecting the strings of a translation set \(or multiple sets\) may take a significant amount of time, depending on the volume of data in the selected sets.


After the collection process is finished, you can view the new and updated strings on the [Translation Dictionaries](SM_20_05_40.md) \(SM200540\) form.
