# To Publish the Analytical Report {#_7c526367-736f-4a8d-b191-e8c980124435 .task}

An analytical report can be published on the Acumatica ERP site to become available to the Acumatica ERP application users. To publish the report, use the [Report Definitions](CS_20_60_00.md) \(CS206000\) form.

## To publish an Analytical Report using Report Definitions Form { .section}

1.  Open the [Report Definitions](CS_20_60_00.md) \(CS206000\) form.
2.  In the **Code** box, select the report to publish.
3.  On the form toolbar, click **Publish to the UI**. In the dialog box that opens, do the following:
    1.  In the **Site Map Title** box, enter the report title that will be displayed in the menu.
    2.  In the **Workspace** and **Category** boxes select needed workspace and category.
    3.  In the **Screen ID**, leave the automatically assigned identifier.
    4.  In the **Access Rights** section, select the **Set to Revoked for All Roles** option button.
    5.  Click **Publish** to publish the dashboard and close the dialog box.

After the report is published, the users who will generate the report must be granted access rights to this report. For more information about access rights, see [Access Rights by Screen](SM_20_10_20.md).
