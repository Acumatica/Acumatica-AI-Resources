# Vendor Shipment Packing List {#_eea6a509-5e82-4ddd-95b3-d7daa5b340cc .reference}

Form ID: \(AM642000\)

This report can accompany the items being shipped to a vendor for an outside process. The [Vendor Shipments](AM_31_00_00.md) \(AM310000\) form is used to create and process the shipment and this report can be printed from that form.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Shipment Nbr**: Select the vendor shipment you wish to print.
