# Managing Parent-Child Projects

The topics of this chapter describe how to manage parent-child projects after the project hierarchy has been configured.

Parent-child project management helps you work with related projects as one hierarchy without creating duplicate project transactions in the parent project. You can roll up child project transactions to update parent project budgets, review consolidated actual values, bill work from the parent or from a child project, and undo rollup before parent-level billing when corrections are needed.
