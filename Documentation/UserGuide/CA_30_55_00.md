# Anticipated Cash Transactions {#_50e43f1b-01b6-4d39-bd97-d49b587aeb79 .reference}

Form ID: \(CA305500\)

You can use this form to enter information about cash transactions that you expect in the near future. This information is used only to improve cash flow forecasts that otherwise would be based on documents available in the system. For details, see [Cash Flow Forecasting](CA__con_Cash_Flow_Forecasting.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

In this area, select a cash account and a start date to view only the transactions with later dates in the Cash Transactions area.

|Element|Description|
|-------|-----------|
|**Cash Account**|The cash account for which you want to view available transactions or enter new ones.|
|**Currency**|The currency of the cash account.|
|**Start Date**|The earliest date for the transactions to be shown in the list.|

## Table {#2 .section}

In this table, you can view the cash transactions entered with dates later than the specified start date and enter new expected cash transactions.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Tran. Date**|The date of the cash transaction.|
|**Disb./Receipt**|The type of the transaction: *Disbursement* or *Receipt*.|
|**Description**|The description provided for the cash transaction.|
|**Amount**|The amount of the cash transaction.|
