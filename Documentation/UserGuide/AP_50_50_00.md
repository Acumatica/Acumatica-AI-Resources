# Process Payments / Print Checks

Form ID: \(AP505000\)

You use this form to:

-   Print checks for payment documents \(AP payments and cash purchases\). For details, see [To Print Checks](AP__how_Printing_Checks.md).
-   Create a batch of ACH payments for the appropriate payment method. For details on configuring and processing these payments, see [ACH Payments](AP__con_ACH_Payment_Support.md).
-   Schedule payments for processing in BILL. For more information on the setup of BILL integration, see [Setup of Integration with BILL](AP__CON_BillCom_Integration_Setup.md) and [International Payments with BILL](AP__CON_BILL_International_Payments.md). For details on processing international payments, see [Processing International Payments](AP__con_BILL_International_Payments_Processing.md).
-   Send payments for processing in AvidXchange. For more information on the setup of AvidXchange integration, see [Integration with AvidXchange](AP__CON_Integration_with_AvidXchange.md). For details on processing payments, see [Processing Payments Through AvidXchange](AP__con_Create_Doc_AvidXchange.md).

To use this form, you select payments by their cash account and payment method in the Selection area, and view the list of payments that meet the criteria in the table. You can then process all listed payments or only those you select.

</td></tr><tr><td>

|Element|Description|
|-------|-----------|
|**Apply Today's Rate and Schedule Payments**|An option button you select for the system to apply today's exchange rate to all payments with expired rates, recalculate their amounts accordingly, and schedule the payments.|
|**Apply Today's Rate Without Scheduling**|An option button you select for the system to process only payments with valid exchange rates. All payments with expired exchange rates are recalculated but not processed. After you close this dialog box, you should review the recalculated payments again in the table.|
|**Skip Payments**|An option button you select for the system to process only payments with valid exchange rates. All payments with expired exchange rates will be displayed in the table with the same warnings.|
|This dialog box has the following buttons.|
|**Process**|Processes the selected documents.|
|**Cancel**|Closes the dialog box without applying any changes.|
