# Sales Prices {#_62bfca2c-0893-495b-bb1d-125b64899afc .reference}

Form ID: \(AR202000\)

You can use this form to review and edit all prices for inventory items that match the criteria you specify. Changes made on this form become effective immediately. Also, with one click, you can create a price worksheet containing all prices for inventory items matching the selected criteria. For more information on sales prices, see [Sales Prices: General Information](Prices_Reviewing_Sales_Prices_GeneralInfo.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Create Price Worksheet**|Navigates to the [Sales Price Worksheets](AR_20_20_10.md) \(AR202010\) form, where you continue working with the created price worksheet, which contains all price records matching the criteria that you have selected on the current form. By default, the new worksheet is created with the *On Hold* status and the current business date.

 When you create a price worksheet by clicking this button, the system copies the value selected in the **Tax Calculation Mode** box in the Summary area of this form to the created worksheet. If *All Modes* is selected in this box, the system displays an error message indicating that a tax calculation mode must be selected.

 **Tip:** If the selection of records contains multiple records that have been defined for the same inventory item but are effective on different dates, the system forces you to specify a particular date in the **Effective As Of** box to eliminate duplicates \(all records in the worksheet are to be effective on the selected date.\)

|

## Selection Area {#1 .section}

In the Selection area, you can select sales prices for viewing—and possibly revising—by their price type, inventory item, and effective date. You can display only the prices of items assigned to your workgroup \(or another specific workgroup\), or you can display only the prices of the items assigned to you.

|Element|Description|
|-------|-----------|
|**Price Type**|The type of prices you want to view. Select one of the following options:

 -   *All Prices*: Prices of all available types are displayed.
-   *Base*: Prices of the base type are displayed. You use this price type for prices that are not related to a specific customer or customer price class. This price type does not have any price codes.
-   *Customer*: Customer-specific prices are displayed. You can select a particular customer account in the **Price Code** box to create a price list for this customer or to narrow the list of prices you want to view in the table.
-   *Customer Price Class*: Prices specific to the price classes are displayed. You can select a particular price class in the **Price Code** box to create a price list for all customers from this price class or to narrow the list of prices you want to view in the table. For an item, you can set different prices for different customer price classes, which can be created and modified on the [Customer Price Classes](AR_20_80_00.md) \(AR208000\) form.

|
|**Price Code**|The customer or a customer price class for which you want to create or edit a price list. This box is available if the *Customer* or the *Customer Price Class* option is selected in the **Price Type** box.

 The list of values may be limited based on the current user's access role. You can select a price code of a customer whose settings permit the use of the branch or company to which the user's role is assigned \(the **Restrict Visibility To** box on the **Financial** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form contains this branch, company, or a company group, or is empty\).

|
|**Tax Calculation Mode**|The tax calculation mode of the prices displayed in the table. The following options can be selected:

 -   *All Modes* \(default\): Prices with all available tax calculation modes are shown.
-   *Not Set*: Only prices with the *Not Set* tax calculation mode are shown.
-   *Gross*: Only prices with the *Gross* tax calculation mode are shown.
-   *Net*: Only prices with the *Net* tax calculation mode are shown.

 This box appears on the form if the *Net/Gross Entry Mode* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Effective As Of**|A date that you select to view or edit prices effective on this exact date.|
|**Item Class ID**|The class of stock or non-stock inventory items, by its ID, for which you want to review sales price information. Leave the box blank to view information on items of all item classes.|
|**Inventory ID**|The inventory item for which you want to view or edit prices.|
|**Warehouse**|The warehouse for which you want to review sales price information.

 This box appears if the *Multiple Warehouses* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Price Class**|The item price class of the items for which you want to review sales price information. You can leave the box blank to view information on items in all item price classes.|
|**Price Manager**|The price manager of a stock or non-stock item.

 In this box, you can select any user from the workgroups to which you are added on the [Company Tree](EP_20_40_61.md) \(EP204061\) form. If you are not added to any workgroup, you can select only yourself. If this box is empty, the system shows all lines for which a purchase order can be created.

|
|**Me**|A check box that indicates \(if selected\) that the table contains only lines with stock or non-stock items in whose settings you are selected in the **Product Manager** box on the [Stock Items](IN_20_25_00.md) \(IN202500\) or [Non-Stock Items](IN_20_20_00.md) \(IN202000\) form.|
|**Price Workgroup**|The price workgroup of a stock or non-stock item.

 In this box, you can select any workgroup to which you are added on the [Company Tree](EP_20_40_61.md) \(EP204061\) form. If the box is empty, the table contains lines with stock or non-stock items that have one of the following settings on the [Stock Items](IN_20_25_00.md) \(IN202500\) or [Non-Stock Items](IN_20_20_00.md) \(IN202000\) form:

 -   In the **Product Workgroup** box in the Summary area, the specified workgroup is one of your workgroups on the [Company Tree](EP_20_40_61.md) \(EP204061\) form.
-   The **Product Workgroup** box is empty.

 If you are not added to any workgroup, the table contains only lines with stock or non-stock items that do not have an assigned workgroup.

|
|**My**|A check box that indicates \(if selected\) that the table contains only lines in which stock or non-stock items have the same workgroup in the **Product Workgroup** box on the [Stock Items](IN_20_25_00.md) \(IN202500\) or [Non-Stock Items](IN_20_20_00.md) \(IN202000\) form as one of your workgroups on the [Company Tree](EP_20_40_61.md) \(EP204061\) form.|

## Sales Prices Table {#2 .section}

This table displays the sales prices for items that match the criteria you have specified. You can view and edit the existing items and add new records. You can turn on or turn off automatic line discount calculation for a particular price.

The visibility of records with the *Customer* price type may be limited based on the roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. With the feature enabled, the **Restrict Visibility To** box appears on the **Financial** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form. The system displays the prices of the customers for which one of the following is true:

-   The **Restrict Visibility To** box is empty for the customer—that is, the customer’s visibility is not restricted.
-   A branch, company, or a company group is specified in the **Restrict Visibility To** box for the customer, and your user account is assigned to the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Price Type**|The type of the price. Select one of the following options.

 -   *Base*: You use this price type for prices that are not related to a specific customer or customer price class. This price type does not have any price codes.
-   *Customer*: You use this price type for a price that is applicable to the item only if it is sold to a particular customer. This price type requires a price code to be specified in the **Price Code** column of the form. In this case, the price code is the identifier of a customer that has been defined in the system.
-   *Customer Price Class*: You use this price type for a price that is applicable to the item only if it is sold to a customer of the particular price class. This price type requires a price code to be specified in the **Price Code** column of the form. In this case, the price code is the identifier of a customer price class that has been defined in the system.

|
|**Price Code**|The code of the price, which can be either the price class ID of the customer \(if *Customer Price Class* is selected in the **Price Type** column\) or the customer ID \(if **Price Type** is set to *Customer*\).

 The list of price codes may be limited based on the roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. With the feature enabled, the **Restrict Visibility To** box appears on the **Financial** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form. The system displays the price code of customers for which one of the following is true:

-   The **Restrict Visibility To** box is empty for the customer—that is, the customer’s visibility is not restricted.
-   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer, and your user account is assigned to the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.

|
|**Inventory ID**|The ID of the stock or non-stock inventory item for which price information is listed. If the **Load Sales Prices by Alternate ID** check box is selected on the **Pricing** tab of the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR101000\) form, you can enter an alternate ID of an items in this column.

 For more details, see [Uploading Prices with Alternate IDs and Creating Alternate IDs from Price Worksheets](IN__con_Item_Cross-References.md#IDworksh).

|
|**Description**|The description of the inventory item.|
|**UOM**|The unit of measure \(UOM\) used for the item. You can select any of the units defined for this item and set a separate price for it.|
|**Warehouse**|The warehouse for which the price is defined. If this box is empty, the price applies to all warehouses.

 This column appears if the *Multiple Warehouses* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Promotion**|A check box that indicates \(if selected\) that the price for this item is promotional. Promotional prices, which may overlap with regular prices, should have expiration dates after which they are not used.

 The check box is not available when the **Fair Value** check box is selected in the line.

 If this check box is selected in the row, the **Ignore Automatic Line Discounts** check box will be selected automatically.

|
|**Ignore Automatic Line Discounts**|A check box that indicates \(if selected\) that automatic line discounts are turned off \(that is, not calculated\) for this price.

 The check box appears on the form if the *Customer Discounts* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 This check box is selected automatically if the **Promotional** check box is selected in this row.

 The check box is cleared and unavailable when the **Fair Value** check box is selected in this row. \(That is, if in this row, one of these check boxes is selected, the other check box is cleared and not available for selection\).

|
|**Fair Value**|A check box that indicates \(if selected\) that the price in this row will be used by the price selection algorithm as a fair value price in the revenue reallocation process.

 This column appears on the form if the *Revenue Recognition by IFRS 15/ASC 606* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. The check box becomes available for selection if the **Promotion** check box is cleared \(in this row\) for the price.

 The check box is cleared and unavailable when the **Promotional** or **Ignore Automatic Line Discounts** check box is selected in this row.

|
|**Prorated**|A check box that indicates \(if selected\) that the fair value price is prorated. A price can be prorated when the system calculates the fair value price for inventory items with a deferral code of a flexible type \(*Flexible by Period*, *Prorate by Days*, or *Flexible by Days in Period*\).

 This column appears on the form if the *Revenue Recognition by IFRS 15/ASC 606* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. The check box becomes available for selection when the **Fair Value** check box is selected.

 **Tip:** On the same date, a stock item cannot have two prices one of which is prorated and the other one is not.

|
|**Apply Discounts to Fair Value**|A check box that indicates \(if selected\) that for the discount codes for which the **Apply to Deferred Revenue** check box is selected on the [Discount Codes](AR_20_90_00.md) \(AR209000\) form, the system will apply the discounts defined on the [Discounts](AR_20_95_00.md) \(AR209500\) form.

 This check box can be selected only for prices for which the **Fair Value** check box is selected. The discounts will be applied to fair value prices to get the effective fair value prices to be used in the calculation of deferred revenue.

 This column appears on the form if the *Revenue Recognition by IFRS 15/ASC606* and *Customer Discounts* features have been enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Break Qty.**|The quantity to define a lower bound for a quantity tier with the specific price.

 This column appears if the *Volume Pricing* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Price**|The price for the item, which becomes effective immediately after you save your changes on this form. You can specify any price as long as minimum markup validation is *not* configured for sales orders, which is the case when the *No Validation* option is selected in the **Validate Min. Markup** box on the [Sales Orders Preferences](SO_10_10_00.md) \(SO101000\) form. If minimal markup validation is configured \(that is, if the *Warning* or *Set to Minimum* option is selected in the **Validate Min. Markup** box\) and you enter a pending price lower than that allowed by the **Min. Markup %** value for the inventory item, you will get a warning or the pending price will be set to the minimum allowed.

 The **Min. Markup %** for the item is specified on the **Price/Cost** tab on the [Stock Items](IN_20_25_00.md) \(IN202500\) form or the similarly named tab on the [Non-Stock Items](IN_20_20_00.md) \(IN202000\) form.

|
|**Tax Calculation Mode**|The tax calculation mode of the particular price. The following options can be selected:

 -   *Not Set* \(default\): The price either includes a tax or does not, depending on the tax settings.
-   *Gross*: The tax amount is included in the item price.
-   *Net*: The tax amount is not included in the item price.

 The system displays prices with the tax calculation modes selected in the **Tax Calculation Mode** box in the Summary area.

 This column appears in the table if the *Net/Gross Entry Mode* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Tax Category**|The tax category specified for the stock item or non-stock item on the **General** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) or [Non-Stock Items](IN_20_20_00.md) \(IN202000\) form. This column is read-only.

 This column appears in the table if the *Net/Gross Entry Mode* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Currency**|The currency in which this price is specified.|
|**Tax**|The identifier of the tax whose amount is included in the sales price. This tax ID is used only for information purposes and does not affect tax calculation.|
|**Effective Date**|The date when the price became effective.|
|**Expiration Date**|The date when the price expires.|
