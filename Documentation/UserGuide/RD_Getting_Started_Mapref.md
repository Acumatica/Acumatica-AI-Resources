# Getting Started with the Report Designer {#_e15a22db-126f-40f7-a362-e02a4ea7e4ad .concept}

The Acumatica Report Designer is a standalone application that you use to create, edit, and save reports, thus extending the list of standard reports provided with Acumatica ERP. When the standard reports do not include the needed data, or when their look and layout doesn't meet your needs, you can design a report.

In the topics of this chapter, you will learn how to install the Acumatica Report Designer.
