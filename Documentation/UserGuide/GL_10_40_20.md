# Restriction Groups by GL Account {#_ab8f3b5b-a373-4d8e-9a42-49077b4f84f2 .reference}

Form ID: \(GL104020\)

On this form, you can view the restriction groups that contain a particular General Ledger \(GL\) account. You can also change the visibility of the account in the system by including it in other restriction groups or excluding it from groups that currently contain it.

**Tip:** You can create restriction groups for managing the visibility of GL accounts by using the [GL Account Access](GL_10_40_00.md) \(GL104000\) form.

For more information on restriction groups, see [Restriction Groups in Acumatica ERP](SM__con_Overview_of_Restriction_Groups.md).

**Important:** By restricting the visibility of accounts, subaccounts, and branches, you also restrict the visibility of the cash accounts that are linked to the restricted entities. We recommend that you carefully configure restriction groups that contain accounts, subaccounts, and branches because including these entities in different restriction groups may block the processing of the associated cash accounts.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

In this area, you can select the GL account for which you want to view or edit its membership in restriction groups. You can also view additional information about the selected GL account.

|Element|Description|
|-------|-----------|
|**Account**|The GL account whose membership in restriction groups you want to view \(and edit, if needed\) in the table.|
|**Type**|Read-only. The type of the selected account. For more information about account types, see [Modification of the Chart of Accounts](GL__CON_Modification_of_Cart_of_Accounts.md).|
|**Description**|Read-only. The description of the selected account.|
|**Account Class**|Read-only. The class of the selected account. For more information about account classes, see [Modification of the Chart of Accounts](GL__CON_Modification_of_Cart_of_Accounts.md).|
|**Currency**|Read-only. The specific currency if the selected GL account is a currency-denominated account. \(If this box is blank, the base currency is used for the account.\)|

## Table {#2 .section}

In this table, you can view the full list of restriction groups in the system, along with some basic information about each group. The check box in the unlabeled Included column is selected for each group that contains the GL account. You can select and clear these check boxes to change the membership of the GL account in restriction groups.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that indicates \(if selected\) that the selected entity is included in the restriction group.|
|**Group Name**|Read-only. The name of the restriction group.|
|**Description**|Read-only. The description of the restriction group.|
|**Active**|Read-only. A check box that indicates \(if selected\) that the restriction group is active. The system does not enforce restrictions imposed by inactive groups.|
|**Group Type**|Read-only. The type of the restriction group: *A*, *A Inverse*, *B*, or *B Inverse*. For more information, see [Types of Restriction Groups](../Shared/../UserGuide/SM__con_Types_of_Restriction_Groups.md).|
