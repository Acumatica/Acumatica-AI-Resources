# To Export a Count Sheet to an Excel Spreadsheet {#_882da2cf-bb31-4b26-9dbd-a1377e333ed9 .task}

You can export count sheets to Microsoft Excel spreadsheets by using the [Physical Inventory Review](IN_30_50_00.md) \(IN305000\) form, as described in this topic.

**Attention:** To open any form, you can navigate to it or search for it \(by its name or by its form ID without periods\).

## Before You Proceed { .section}

1.  Open the [Prepare Physical Count](IN_50_40_00.md) \(IN504000\) form by searching for or navigating to it.
2.  Make sure that the required count sheet has been generated on this form.

## To Export a Count Sheet to an Excel Spreadsheet { .section}

1.  Open the [Physical Inventory Review](../Shared/../UserGuide/IN_30_50_00.md) \(IN305000\) form.
2.  In the **Reference Nbr.** box of the Summary area, select the identifier of the required physical inventory document.
3.  Make sure that the physical inventory document has the *Counting in Progress* status.
4.  On the table toolbar of the **Physical Inventory Details** tab, click **Export to Excel**.
5.  Open the downloaded file and review its contents.
