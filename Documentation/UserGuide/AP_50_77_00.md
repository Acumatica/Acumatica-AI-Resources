# Submit CIS Return

Form ID: \(AP507700\)

You use this form to prepare data for a Construction Industry Scheme \(CIS\) return and the subcontractor's deduction statement.

The form appears in the system if all of the following conditions are met:

-   The *UK Localization* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.
-   On the [Companies](CS_10_15_00.md) \(CS101500\) form, *United Kingdom* is selected in the **Localization** box on the **Company Details** tab for the company.

Users with the following roles can access this form: *Acumatica Support*, *Administrator*, *AP Admin*, *AP Clerk*, and *AP Viewer*.

## Selection Area

You use the elements in this area to specify the contractor and the tax period of the CIS return that you prepare and submit to HMRC. The subcontractors whose payments are reported for the selected contractor and tax period appear on the **Details** tab. The area also contains the **Date Range**, **Filing Type**, and **Nil Return** elements, which the system fills in during the preparation and submission of the return.

<table id="_5b36108b-e9c1-483d-80a8-21fa680546ba"><thead><tr><th>

Element

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Contractor**

</td><td>

The company or branch for which you prepare and submit the CIS return. When you click the magnifier button, the lookup table lists the companies and branches for which *United Kingdom* is selected in the **Localization** box on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form. For a company that has the **File Taxes by Branch** check box selected on the [Companies](CS_10_15_00.md) form, the lookup table lists that company's branches. For a company that has the **File Taxes by Branch** check box cleared, it lists only the company.

 By default, this box contains the current company or branch.

</td></tr><tr><td>

**Tax Period**

</td><td>

The tax period that the CIS return covers. A tax period runs from the 6th of one month to the 5th of the next month, and the monthly return for a period must reach HMRC within 14 days of the end of that period. \(For example, a return covering payments made to subcontractors between 6 May and 5 June must reach HMRC by 19 June.\)

 When you click the magnifier button, the lookup table lists the last 12 tax periods, starting with the period before the one that includes the current business date. If any returns have been prepared in the system, the lookup table also lists the tax periods of those returns.

 If no tax periods exist for the CIS tax agency when you open this form, the system generates the tax periods of the tax year that includes the current business date. Thus you can prepare and submit a nil return without generating the tax periods manually on the [Tax Periods](TX_20_70_00.md) \(TX207000\) form.

</td></tr><tr><td>

**Date Range**

</td><td>

The first and last dates of the selected tax period. For example, for the tax period *03-2026*, the range is 6 March 2026 through 5 April 2026.

 This element is unavailable for editing. The system fills it in with the date range defined for the tax period on the [Tax Periods](TX_20_70_00.md) \(TX207000\) form once you select a tax period in the **Tax Period** box. Until then, the element is empty.

</td></tr><tr><td>

**Filing Type**

</td><td>

The type of the CIS return. The box contains *Original* for the original filing of the return, or *Amended* for a return that you have amended after the original was submitted to HMRC.

 This element is unavailable for editing. It contains *Original* until you prepare an amended return, at which point the system changes the value to *Amended*.

</td></tr><tr><td>

**Nil Return**

</td><td>

A check box that, when selected, indicates that the CIS return is a nil return. It means that no subcontractor payments are reported for the selected tax period and no rows appear on the **Details** tab.

 This check box is unavailable for editing. The system selects it when you prepare a return that has no data for the selected tax period, and clears it if you then record payments for the period and prepare the return again.

</td></tr><tr><td>

**CIS Return Status**

</td><td>

The status of the CIS return, which reflects how far the return has progressed through preparation and submission. The system sets this status to one of the following:-   *Not Prepared*: The return has not yet been prepared for the selected contractor and tax period.
-   *Not Submitted*: The return has been prepared but not yet submitted to HMRC. The return has this status after you prepare the original return, and again after you prepare an amended return.
-   *Submitted*: The return has been submitted to HMRC. The return has this status after you submit the original return, and again after you submit an amended return.

</td></tr></tbody>
</table>

## Details Tab

On this tab, you can review the subcontractor payments and deductions included in the CIS return for the selected contractor and tax period, and select the **Unmatched Tax Rate Indicator** check box for a subcontractor whose tax rate could not be matched.

The table toolbar has only standard buttons.

<table id="_9e453575-1414-47a9-802b-814220ff976a"><thead><tr><th>

Column

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Subcontractor**

</td><td>

The subcontractor whose payments and deductions are reported in this row. The system copies the name from the **Legal Name** box on the **General** tab of the [Vendors](AP_30_30_00.md) \(AP303000\) form.

</td></tr><tr><td>

**Unique Taxpayer Ref. Nbr.**

</td><td>

The Unique Taxpayer Reference \(UTR\) of the subcontractor in this row. The system copies this value from the **Unique Taxpayer Ref. Nbr.** box on the **CIS Details** tab of the [Vendors](AP_30_30_00.md) \(AP303000\) form.

</td></tr><tr><td>

**National Insurance Nbr.**

</td><td>

The National Insurance number of the subcontractor in this row. The system copies this value from the **National Insurance Nbr.** box on the **CIS Details** tab of the [Vendors](AP_30_30_00.md) \(AP303000\) form.

</td></tr><tr><td>

**Unmatched Tax Rate Indicator**

</td><td>

A check box that you select to indicate that the tax rate of the subcontractor in this row could not be matched. The system selects this check box by default if the **Unmatched Tax Rate Indicator** check box is selected for the subcontractor on the [Vendors](AP_30_30_00.md) \(AP303000\) form, and you can change it for this return.

</td></tr><tr><td>

**Cost of Materials**

</td><td>

The cost of materials paid to the subcontractor in this row during the tax period.

 The system calculates this amount as the total of the line amounts of all the bills paid to the subcontractor within the period whose tax category has the **CIS Type** set to *Material* on the [Tax Categories](TX_20_55_00.md) \(TX205500\) form, minus the document discount allocated to those lines proportionally. If a bill is only partially paid, the system calculates the amount in proportion to the paid portion. If a cash discount has been taken for a payment, the system reduces this amount in proportion to the discount.

</td></tr><tr><td>

**Liable to Deduction**

</td><td>

The amount paid to the subcontractor in this row during the tax period that is liable to CIS deduction.

 The system calculates this amount as the total of the line amounts of all the bills paid to the subcontractor within the period whose tax category has the **CIS Type** set to *Labour* on the [Tax Categories](TX_20_55_00.md) \(TX205500\) form, minus the document discount allocated to those lines proportionally. If a bill is only partially paid, the system calculates the amount in proportion to the paid portion. If a cash discount has been taken for a payment, the system reduces this amount in proportion to the discount.

</td></tr><tr><td>

**Deduction Rate**

</td><td>

The CIS deduction rate applied to the subcontractor in this row. The system copies this value from the rate of the tax selected in the **CIS Withholding Tax** box on the [Vendors](AP_30_30_00.md) \(AP303000\) form.

</td></tr><tr><td>

**Amount Deducted**

</td><td>

The total CIS deduction withheld from the subcontractor in this row during the tax period.

 The system calculates this amount as the total of the withholding tax amounts of all the released payments made to the subcontractor within the period. These amounts are copied from the **With. Tax** column on the **Documents to Apply** tab of the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form.

</td></tr><tr><td>

**Amount Paid**

</td><td>

The total net amount paid to the subcontractor in this row during the tax period, including non-CIS items and VAT, minus the CIS tax withheld.

 The system calculates this amount as the total of the payment amounts of all the released payments made to the subcontractor within the period. These amounts are copied from the **Payment Amount** box on the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form.

 If you click the amount in this column, the system opens the [CIS Payment Details](AP_40_78_00.md) \(AP407800\) form that shows the individual payments made to the subcontractor within the date range, including, for each payment, the total payments, cost of materials, amount liable to deduction, deduction rate, and amount deducted.

</td></tr></tbody>
</table>
