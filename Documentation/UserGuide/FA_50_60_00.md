# Split Assets {#_55cd3d70-138c-42fe-89ad-f64488b04e91 .reference}

Form ID: \(FA506000\)

On this form, you can divide an asset into two or more separate assets.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Split**|Based on the options that you have specified, splits an asset into new separate assets.|

## Selection Area {#opt .section}

In the Selection area, you can select the fixed asset you want to split and specify options for the split.

|Element|Description|
|-------|-----------|
|**Fixed Asset**|The fixed asset to be split into separate assets.|
|**Cost**|A read-only box that shows the current cost of the asset that you have selected.|
|**Quantity**|A read-only box that shows the current quantity of the asset that you have selected.|
|**Split Date**|The date of the split. By default, this box contains the current date, but you can specify another date.|
|**Split Period**|The financial period of the split. By default, this box contains the financial period that corresponds to the date, but you can select another period.|
|**Depreciate Before Split**|A check box that you select to depreciate the asset before splitting it.

 This check box is available for editing only if the **Automatically Release Depreciation Transactions** check box is selected on the [Fixed Assets Preferences](FA_10_10_00.md) \(FA101000\) form.

|

## Table {#1 .section}

You can use this table to define the percentage, quantity, and amount for the new assets being split from the fixed asset.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Cost**|The base currency amount to be assigned as the cost to the new asset.|
|**Quantity**|The quantity to be assigned to the new asset.|
|**Ratio**|The percentage of the original asset cost to be assigned to the new asset.|
|**Asset ID**|The unique identifier of the new asset.|
