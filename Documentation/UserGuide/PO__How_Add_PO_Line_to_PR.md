# To Add Purchase Order Lines to an Existing Purchase Receipt {#_be390122-0257-4328-9688-a09baa04952e .task}

On the [Purchase Receipts](PO_30_20_00.md) \(PO302000\) form, you can add any number of lines from a particular purchase order or multiple purchase orders to an existing purchase receipt of the same vendor specified for the purchase order or orders.

## To Add a Purchase Order Line to an Existing Purchase Receipt { .section}

1.  Open the [Purchase Receipts](PO_30_20_00.md) \(PO302000\) form.
2.  Select the needed purchase receipt by its reference number.
3.  On the table toolbar of the **Details** tab, click **Add PO Line**. In the **Add Purchase Order Line** dialog box, which opens, do one of the following:
    -   To add lines from one particular purchase order of the vendor: In the **Order Nbr.** box, select the reference number of the particular purchase order whose line or lines you want to add. In the table, select the unlabeled check box in the row of each purchase order line to be added to the purchase receipt. Click **Add &amp; Close**.
    -   To select lines from all available purchase order lines of the vendor: In the table, select the unlabeled check box in the row of each purchase order line to be added to the purchase receipt. Click **Add &amp; Close**.
4.  On the **Details** tab, review the information in the added line or lines, and make any needed changes.
5.  Optional: In the **Control Qty.** box on the Summary area, enter the total quantity in all purchase receipt lines.
6.  On the form toolbar, click **Save** to save the purchase receipt.
