# 1099-NEC Form {#_0e2a430e-f97f-428f-abd9-350a2d6a3cb1 .reference}

Form ID: \(AP653100\)

**Attention:** This report is available only if the *1099 Reporting* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This report displays the 1099-NEC \(Nonemployee Compensation\) form for 2020 or any later year. If you need to generate the 1099-NEC report for 2019 or any earlier year, you use the [1099-MISC Form](AP_65_30_00.md) \(AR653000\) form with *All Boxes* selected in the **NEC \(Box 7\)** parameter. \(Before 2020, nonemployee compensation was reported on Box 7 of the 1099-MISC report.\)

If the amount in Box 9 exceeds the minimum reporting amount specified in the **Minimum Report Amount** box on the **1099 Settings** tab of the [Accounts Payable Preferences](AP_10_10_00.md) \(AP101000\) form, *X* is printed in Box 2 of the current form or in Box 7 of the [1099-MISC Form](AP_65_30_00.md) form, depending on the **Report Direct Sales On** option selected on the [Accounts Payable Preferences](AP_10_10_00.md) form. *X* indicates that the vendor has direct sales recorded within the 1099 year, with the total amount exceeding $5,000.

**Attention:** This report complies with the changes that IRS introduced in tax year 2022.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Company/Branch**: The company or branch for which you want to view information. By default, the current branch is selected. This box is available only if the *Multibranch Support* feature is enabled in your system on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.
-   **1099 Year**: The 1099 year for which the 1099-NEC form will be displayed. Select the year from the list, which contains both open and closed 1099 years.

If you are printing the generated report, you must select the following printing parameters:

-   **Paper size**: *Letter*
-   **Scale**: *Default*

For details on adjusting the printing parameters, see [Configuring 1099 Reporting](AP__con_Support_for_U.S._1099-MISC_Form.md).
