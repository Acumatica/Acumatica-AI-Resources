# Route Appointment Forecasting {#_073385ad-29b8-4afd-a73e-612143e66870 .reference}

Form ID: \(FS404070\)

On this form, you can view a projection of the dates and details of appointments that could later be generated on the [Generate Route Appointments](FS_50_02_00.md) \(FS500200\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Generate a Projection**|Generates a list of appointments that can be generated based on the criteria specified in the Selection area.|

## Selection Area {#1 .section}

You use the elements in the Selection area \(described in the following table\) to specify the criteria for the forecasting process.

|Element|Description|
|-------|-----------|
|**Route ID**|The route definition for which you want to view data.|
|**Inventory ID**|The identifier of the inventory item for which you want to view data.|
|**Customer**|The identifier of the customer for which you want to view data.

 The list of customers available for selection may be limited based on the role or roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. In this case, the **Restrict Visibility To** box appears on the **Financial** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form. With the feature enabled, a customer is available for selection if one of the following is true:

-   The **Restrict Visibility To** box is empty for the customer—that is, the customer’s visibility is not restricted.
-   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer, and your user account has the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.

|
|**Customer Location**|The unique identifier of the customer location associated with the contract.

 This box is available only if the *Business Account Locations* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**From Date**|The start date of the date range for which you want to view the appointments to be generated.|
|**To Date**|The end date of the date range for which you want to view the appointments to be generated.|

## Table { .section}

In this table, you can view the list of appointments that can be generated.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Start Date**|The start date of the route appointment.|
|**Route ID**|The identifier of the route definition related to the appointment.|
|**Schedule ID**|The identifier of the schedule according to which the appointment will be generated.|
|**Service Contract ID**|The reference number of the service contract related to the schedule.|
|**Customer Contract Nbr.**|The reference number of the service contract, which the system automatically generates for every new service contract of this customer.|
|**Customer**|The customer for which the appointment will be performed.|
|**Location**|The customer location where the appointment will be performed.

 This box is available only if the *Business Account Locations* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
