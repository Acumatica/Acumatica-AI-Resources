# Staff Appointments on Map {#_fb372257-a821-47d7-96f9-9dd6bb1e6337 .reference}

Form ID: \(FS301100\)

On this form, for a particular date, you can view on the map the appointments to which the staff members are assigned.

## Staff Pane { .section}

On this pane, you can view staff members and details about the appointments assigned to them.

The toolbar includes standard elements.

|Column|Description|
|------|-----------|
|**Route List**|The list displays routes along with the assigned staff members and appointments. Clicking a staff member's name highlights their route on the map, while clicking the arrow button to the left of the name reveals the included appointments.|
|**Route/Customer**|The name of the customer for whom the appointment is scheduled.|
|**Location**|The identifier of the branch location.|
|**Service Duration**|The total estimated time required to perform the services.|

|Element|Description|
|-------|-----------|
|**Show or Hide Route Appointment Information on the Map**|Shows or hides the appointment information on the map for the staff member you have selected.|
|**Show or Hide GPS Location on Map**|Shows or hides the latest location \(indicated with the *D* icon\) on the map for the staff member you have selected.

 This menu command is available only if the **Show Location Tracking** check box is selected on the [Service Management Preferences](../Shared/../UserGuide/FS_10_01_00.md#) \(FS100100\) form.

|

|Element|Description|
|-------|-----------|
|**Appointment Information**|Opens the [Appointments](../Shared/../UserGuide/FS_30_02_00.md) \(FS300200\) form, where you can view and modify details on the appointment you have selected.|

## Map Pane { .section}

In the map area, you can view the appointments of the staff members for the date and branch selected on the map toolbar. On the map, you can click any appointment icon \(a number within a circle\) to view the identifier of the assigned staff member and the appointment number, and you can view the suggested routes between appointments.

You can also view the most recent tracked location of each staff member, which is identified with a *D* \(the driver location icon\) on the map. You click this icon to see the staff member's name and the time when the location was registered.

For you to be able to view the most recent staff locations, the **Show Location Tracking** check box has to be selected on the **Calendars and Maps** tab \(the**Map Settings** section\) of the [Service Management Preferences](FS_10_01_00.md) \(FS100100\) form. Also, location tracking has to be turned on for each user whose locations you want to track, which is done on the [Users](SM_20_10_10.md) \(SM201010\) form. For details, see [User Access: Mobile Devices](SA_Managing_User_Access_Mobile_Devices_Concept.md).

The map toolbar includes standard and form-specific elements. The form-specific element is listed below.

|Button|Description|
|------|-----------|
|**Branch**|A box in which you can select the branch for which routes are shown on the map.

 A staff member's routes will be shown on the map if for the staff member, this branch is selected in the **Branch** box of the [Employees](EP_20_30_00.md) \(EP203000\) form.

|

## Route Pane { .section}

In this pane, you can view data on the route duration, distance, and number of appointments for the staff member you have selected in the **Staff** pane of the current form. You have to select a staff member to view the data.

**Tip:** When you select a staff member, the system changes the name of the pane to *Route for* followed by the name of the staff member.

## Appointments Pane { .section}

In this section, you can view data on each appointment on the route of the selected staff member in the **Staff** tab of the current form. You have to select a staff member to view the data.

**Tip:** When you select a staff member, the system changes the name of the pane to *Appointments for* followed by the name of the staff member and the number of appointments in parentheses.

|Column|Description|
|------|-----------|
|**Appointment**|A combination of the staff member identifier, as specified on the [Employees](../Shared/../UserGuide/EP_20_30_00.md) \(EP203000\) form, and the number of the appointment, as specified on the [Appointments](../Shared/../UserGuide/FS_30_02_00.md) \(FS300200\) form. For example, if the staff member ID is *0001* and the number of the appointment is *001234-1*, the combination displayed in this column is *0001-001234-1*.|
|**Route/Customer**|The name of the customer with which the appointment takes place.|
|**Service Type**|A description of the service.|
|**Travel Time**|The time that is needed to get from the appointment location listed in this row to the next appointment location.|
|**Service Duration**|The total time that performing the services of the appointment is expected to take.|
|**Actual Start Time**|The actual time when the appointment started.|
|**Actual End Time**|The actual time when the appointment ended.|
|**Location**|The identifier of the appointment location.|
|**Postal Codes**|The postal code of the appointment location.|
|**Address**|The address of the appointment location.|
