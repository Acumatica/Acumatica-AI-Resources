# InsightXL: General Information

InsightXL is an Excel add-in that lets you create and work with connected financial reports in Microsoft Excel. You can export an ARM report to Excel or create a new report from scratch. You can then update report parameters as needed and refresh the workbook at any time to retrieve current values from Acumatica ERP.

This lets you handle the most common financial reporting tasks in Excel while continuing to work with current data from Acumatica ERP.

**Attention:** InsightXL is:

-   Available only if the *InsightXL \(Excel-Based Financial Reporting\)* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form
-   Supported only on Windows

## Applicable Scenarios

-   You want to export an existing ARM report to Excel to make minor adjustments—such as annotating values or changing financial periods—while still being able to refresh the report with current data from Acumatica ERP.
-   You want to design a new financial report in Excel that retrieves up-to-date balances and amounts \(such as beginning balance, debit, credit, turnover, ending balance\). The report can use filtering parameters—for example, ledger, branch, account or subaccount, and financial period. You have experience with report design and are comfortable using functions.
