# InsightXL: General Information {#_c638e218-3973-4a15-a520-b5c7baca9491 .concept}

You can export an ARM report to Excel or create a new report from scratch, update report parameters as needed, and refresh the workbook at any time to pull the latest values from Acumatica ERP. This lets you handle most common financial reporting tasks in Excel while continuing to work with current data from Acumatica ERP.

**Attention:** This functionality is available only if the *InsightXL \(Excel-Based Financial Reporting\)* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and is supported only on Windows.

## Applicable Scenarios { .section}

You use the InsightXL functionality in the following cases:

-   You want to export an existing ARM report to Excel \(for example, *Balance Sheet* or *Profit &amp; Loss*\), for example, to make minor adjustments \(such as annotating values or changing financial periods\) while still being able to refresh the report and get the latest data from Acumatica ERP.
-   You want to design a new financial report directly in Excel and connect it to the Acumatica ERP database to retrieve up-to-date calculated balances and amounts \(such as beginning balance, debit, credit, turnover, ending balance\) based on filtering parameters \(such as ledger, branch, account or subaccount, and financial period\). You have experience with report design and are comfortable with using functions.
