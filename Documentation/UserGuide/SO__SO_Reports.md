# Sales Orders Reports {#_f7884e02-93d0-48c6-bafa-cb0cae31f6bb .concept}

With the wide variety of Acumatica ERP reports, you can meet your organization's reporting needs as they relate to sales orders, shipments, and SO invoices. If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All reports related to sales orders can be generated in different formats, including PDF and HTML, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
