# Reclassify Project Transactions

Form ID: \(PM509100\)

On this form, you can initiate the reclassification of project transactions. You start by clicking **Load Transactions** on the form toolbar, specifying selection criteria in the **Load Transactions** dialog box, and loading transactions you may want to reclassify.

Initially, each loaded project transaction contains the original values in the **To** and **From** columns. You can specify target values in most of the **To** columns. You then reclassify all loaded transactions or only those you select.

The result of reclassification depends on the option selected in the **Reclassification Posting** box of the [Projects Preferences](PM_10_10_00.md) \(PM101000\) form. If *Post PM Transactions Only* is selected, the system releases and posts only reversing and reclassification project transactions. If *Post PM and GL Transactions* is selected, the system also releases and posts the corresponding general ledger transactions.

-   Specify the selection criteria used to determine which project transactions will be loaded to the form and available for reclassification. \(You can then process all the loaded project transactions or only those you select.\)
