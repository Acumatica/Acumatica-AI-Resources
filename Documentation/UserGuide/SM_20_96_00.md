# Excluded Email Domains {#_33c6bceb-412a-4c0d-9849-2eeeeb8e8746 .reference}

Form ID: \(SM209600\)

You use this form to modify the list of excluded email domains. The list is used to optimize the search for a vendor account by the domain part of a sender's email address. By default, the form lists the most popular domains used for registering an email account.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table {#2 .section}

The table lists excluded email domains.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Domain Name**|The name of domain used for email services.|
