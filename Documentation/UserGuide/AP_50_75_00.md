# Create E-File

Form ID: \(AP507500\)

**Attention:** This form is available only if the *1099 Reporting* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

By using this form, you can generate a file that contains the Form 1099-MISC or Form 1099-NEC information on all your 1099 vendors for providing it to the Internal Revenue Service \(IRS\) electronically.

Before you prepare the necessary e-file—Form 1099-MISC or Form 1099-NEC in the electronic format prescribed by the IRS—you need to select the company or branch to be used when the system generates the e-file. This company or branch is used to create the transmitter record, the 1099 year, and other needed settings. You then select a 1099 vendor or multiple 1099 vendors in the table and click **Process**, which generates the e-file.

If only one CSV file is generated on this form, it's downloaded directly. If there are multiple files, they’re packaged together in a single ZIP file. You need to download the generated CSV file or files and upload them to the IRS IRIS Taxpayer Portal. For details, see [Filing 1099 Forms Electronically](AP__con_1099_Electronic_Filing.md).

## Selection Area

In this area, you can specify the companies and the 1099 year for which you are preparing the e-file, and select any needed check boxes that define the type of the required file \(for example, a test file or a correction file\).

<table id="table_ghz_5yn_kq"><thead><tr><th>

Element

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Transmitter**

</td><td>

The company or branch whose information will be used to create the transmitter record in the file.

 This box appears on the form if the *Multibranch Support*, *Multicompany Support*, or both features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

</td></tr><tr><td>

**1099 Year**

</td><td>

The reporting year \(which is always a calendar year\) during which information on Form 1099-MISC or Form 1099-NEC payments was collected. A 1099 year is initialized by the system when a user enters the first transactions for a 1099 vendor.

</td></tr><tr><td>

**File Format**

</td><td>

The format of the electronic file. The following options are available:

 -   *MISC* \(default\): The system prepares the e-file in the Form 1099-MISC format.
-   *NEC*: The system prepares the e-file in the Form 1099-NEC format.

 **Tip:** If you select *2019* or an earlier year in the **1099 Year** box, *MISC* is automatically selected in this box and cannot be changed.

</td></tr><tr><td>

**Prepare For**

</td><td>

A setting that defines the companies for which 1099 data should be included in the file. The following options are available:-   *Transmitter Only*: The 1099 data of only the branch specified as the transmitter will be used to generate the payer record in the file.
-   *All 1099 Payers*: The 1099 data of all companies that have the **1099-MISC Reporting Entity** check box selected on the [Companies](CS_10_15_00.md) \(CS101500\) form will be used to generate the payer records in the file.

</td></tr><tr><td>

**Direct Sales Only**

</td><td>

A check box that controls the reporting of direct sales. When this check box is selected:

 -   Only vendors for which the *Direct Sales Over $5,000* indicator is reportable are included in the output:
    -   **Box 7 - Direct sales of $5,000 or more of consumer products to a recipient for resale** when the file format is MISC
    -   **Box 2 - Payer made direct sales totaling $5,000 or more of consumer products to a recipient for resale** when the file format is NEC
-   All other 1099 box amounts are reported as *0*

 The *Direct Sales Over $5,000* indicator is reportable only when the direct sales amount exceeds the **Minimum Report Amount** on the **1099 Settings** tab of the [Accounts Payable Preferences](AP_10_10_00.md) \(AP101000\) form. Which file the indicator appears in—MISC or NEC—is determined by the **Report Direct Sales On** setting on the [Accounts Payable Preferences](AP_10_10_00.md) \(AP101000\) form.

 **Attention:** When the indicator is reported, the related field in the generated file is populated with *Y*; otherwise, it is populated with *N*.

 If this check box is cleared, all the vendors are included in the report and all 1099 box amounts are reported if they exceed the minimum report amount.

</td></tr></tbody>
</table>
