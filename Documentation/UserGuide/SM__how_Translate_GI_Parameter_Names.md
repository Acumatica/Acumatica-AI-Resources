# To Translate Parameter Display Names for a Generic Inquiry {#_efdc063e-48ca-4e59-994a-18ac25071fe2 .task}

In Acumatica ERP, you can translate the display names for the parameters of a generic inquiry, as described in this topic. You need to use the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form for translation. For more information, see [Locales and Languages](SM__CON_Locales_and_Languages.md).

## Before You Begin { .section}

You need to enable multilingual user input, as described in [Locales and Languages](../Shared/../UserGuide/SM__CON_Locales_and_Languages.md).

## To Translate Parameter Display Names for a Generic Inquiry { .section}

1.  Open the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form.
2.  In the **Inquiry Title** box, select the generic inquiry whose elements you want to translate.
3.  In the **Display Name** column of the **Parameters** tab, click the language ISO code link to open the **Translations** dialog box.
4.  Type the translations of the parameter name in the necessary languages.
5.  Close the **Translations** dialog box.
6.  On the form toolbar, click **Save**.
7.  Repeat Steps 2–6 for every parameter whose name you want to translate.
