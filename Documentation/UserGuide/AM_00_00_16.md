# Inventory Planning History {#_9d8978b5-10c5-4f51-b734-b22282275aa8 .reference}

Form ID: \(AM000016\)

**Note:** This form is available only if the *Material Requirements Planning* or *Distribution Requirements Planning* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You can use this form to compare the numbers of records that the system processed during multiple previous runs of inventory planning regeneration including all records, generated exceptions, inventory items, and created planning orders against the duration of the inventory planning regeneration process. This comparison will be useful when you investigate a significant change in the run time duration of the inventory planning regeneration process on the [Regenerate Inventory Planning](AM_50_50_00.md) \(AM505000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table {#1 .section}

This table contains information about the number of records processed during the runs of inventory planning regeneration.

|Column|Description|
|------|-----------|
|**Start Date**|The start date of the inventory planning regeneration.|
|**End Date**|The end date of the inventory planning regeneration.|
|**Start Time**|The start time of the inventory planning regeneration.|
|**End Time**|The end date of the inventory planning regeneration.|
|**Duration**|The duration of the inventory planning regeneration.|
|**Has Errors**|A check box that indicates \(if selected\) that errors have occurred during the inventory planning regeneration.|
|**Created By**|The name of the user who started the inventory planning regeneration.|
|**Detail Count**|The number of incoming item plan records that the system processed during inventory planning regeneration.|
|**First Pass Detail Count**|The number of incoming item plan records that the system processed during inventory planning regeneration.|
|**Detail Plan Count**|The number of item plan records that the system processed and created during inventory planning regeneration.|
|**Exceptions Count**|The number of exceptions displayed on the [Inventory Planning Exceptions](AM_40_30_00.md) \(AM403000\) form.|
|**Inventory Count**|The number of item and item-warehouse pairs that were processed by the system during inventory planning regeneration.|
|**Plan Count**|The number of all item plans including existing items plans and items plans that were created during inventory planning regeneration.|
