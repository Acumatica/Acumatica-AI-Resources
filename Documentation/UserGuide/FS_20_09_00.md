# License Types {#_b39739b0-85f5-444c-8b86-4935738b0b0a .reference}

Form ID: \(FS200900\)

By using this form, you can define new license types in the system that can later be assigned to the licenses of staff members or used as a requirement to perform a service. You can also view and edit the settings of existing license types.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table { .section}

|Element|Description|
|-------|-----------|
|**License Type ID**|The unique identifier of the type of license.|
|**Description**|A description of the license type.|
