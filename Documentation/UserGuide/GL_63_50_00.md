# Profit &amp; Loss {#_5807a745-abae-423e-8024-3d711b42d003 .reference}

Form ID: \(GL635000\)

This report displays your company's profits and losses for the specified period in period-to-date \(PTD\) and year-to-date \(YTD\) amounts, versus the PTD and YTD amounts of the previous year, as calculated for the same date.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Ledger**: The ledger to be reported on. You must select a ledger.
-   **Financial Period**: The financial period for which you want to view information. You must select a period from the list, which contains all the periods defined in the system, including the closed ones.

    By default, the current financial period is selected.
