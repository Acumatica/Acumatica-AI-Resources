# eSign Accounts

Form ID: \(ES301000\)

On this form, you create electronic signing accounts that are used to connect Acumatica ERP to an esignature provider. You can create multiple accounts for the same provider—for example, one per employee or one shared account for a team.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Connect**|Starts the OAuth authorization flow and connects Acumatica ERP to the selected esignature provider.|
|**Disconnect**|Disconnects Acumatica ERP from the esignature provider.|

## Employees Tab

On this tab, you add the employees who share the selected esign account. The tab is available only if the *Shared* option is selected in the **Type** box of the Summary area.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Employee ID**|The identifier of the employee.|
|**Employee Name**|The name of the employee.|
