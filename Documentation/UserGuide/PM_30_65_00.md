# Project Materials

Form ID: \(PM306500\)

**Attention:** This form is available in the Modern UI if the *Material Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This form lets you manage project materials throughout their lifecycle. You can purchase and issue stock items and non-stock items requiring shipment, as well as track their quantities and costs against the related project budget lines.

## Form Toolbar

The form toolbar includes only standard buttons.

## Selection Area

This area contains the basic settings of the selected project.

|Element|Description|
|-------|-----------|
|**Project**|The project for which you’re managing and tracking materials.|
|**Start Date**|The start date of the selected project.|
|**End Date**|The end date of the selected project.|
|**Quote Ref. Nbr.**|The reference number of the project quote if the project was created from a quote.|
|**Project Manager**|The project manager assigned to the selected project.|
|**Customer**|The customer associated with the selected project.|
|**Description**|The description of the selected project.|
|**Required Qty.**|The budgeted quantity of materials for the selected project.|
|**Estimated Total Cost**|The budgeted cost of materials for the selected project.|
|**Total Budgeted Amount**|The total budgeted amount of materials related to cost budget lines whose expense account group is assigned to the *Material* reporting group.|
|**Estimated Variance**|The variance between the total budgeted amount and the estimated total cost.|

## Details Tab

On this tab, you can add and manage material lines with items required for the project. You can create documents for a material line, such as purchase orders and material issues, and track each material line’s quantities, costs, and status.

## Side Panel

By using the side panel, you can view all material issues, material transfers, purchase receipts, inventory issues, and inventory transfers related to the project’s material lines. To view these documents for a particular material line:

1.  You add the **Line Nbr.** column to the visible columns of the [Project Materials](PM_30_65_00.md) \(PM306500\) form to view the number of a particular line.
2.  You select this line number in the **Project Material Line Nbr.** box of the side panel tab.
