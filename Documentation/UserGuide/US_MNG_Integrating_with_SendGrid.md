# Integrating Acumatica ERP with SendGrid {#_1c81f3fd-c507-43b3-8f09-1be4d48da679 .concept}

In Acumatica ERP, you can configure integration with the [SendGrid](https://sendgrid.com/) email platform. With this integration configured, a user can send emails by using the SendGrid account and can track the following:

-   The status of email delivery
-   An email bouncing and an email being marked as spam
-   The opening of each email and the clicking of links within it

A user can view the tracking details by using the SendGrid portal or within Acumatica ERP.
