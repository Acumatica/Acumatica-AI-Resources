# Deferral Schedules {#_383e5745-b78a-432c-b115-b48d6294f054 .reference}

Form ID: \(DR201510\)

On this form, you can initiate creation of a new deferral schedule or select an existing one to view its details.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table { .section}

This form has a table with the list of deferral schedules that the system has automatically generated for documents whose lines have deferral codes assigned.

The list of values is limited based on the current user's access role. The system displays deferral schedules of customers and vendors whose settings permit the use of the branch, company, or a company group that contains the branch to which the user's access role is assigned \(the **Restrict Visibility To** box on the **Financial** tab of the [Customers](AR_30_30_00.md) \(AR303000\) and [Vendors](AP_30_30_00.md) \(AP303000\) forms contains this branch, company, company group, or is empty\).

|Column|Description|
|------|-----------|
|**Schedule Number**|The unique number of the deferral schedule. To open a particular schedule on the [Deferral Schedule](DR_20_15_00.md) \(DR201500\) form, you can double-click anywhere in the corresponding row.|
|**Status**|The status of the schedule.|
|**Entity Type**|The type of the business account associated with the original document, which can be one of the following: *Customer* or *Vendor*.|
|**Business Account**|The identifier of the business account associated with the document.|
|**Doc. Type**|The type of the original document, which can be one of the following options: *Invoice*, *Credit Memo*, *Debit Memo*, *Cash Sale*, *Cash Return*, *Bill*, *Credit Adj.*, *Debit Adj.*, *Cash Purchase*, or *Voided Cash Purchase*.|
|**Ref. Nbr.**|The reference number of the document. By clicking the number, you can navigate to a respective form and view the document details.|
