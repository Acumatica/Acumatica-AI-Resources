# Work Calendar {#_9d01d650-0b68-4994-8146-c80fb5e34bbb .reference}

Form ID: \(CS209000\)

By using this form, you can create calendars for various uses. For example, calendars are assigned to contract templates and contracts for calculations of work time and overtime spent by your organization employees for servicing contracts.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area {#1 .section}

You use the elements in this area to specify an identifier and description for a new calendar, or to select an existing calendar. Once you select a calendar, you can view the calendar settings on the tabs and make any needed edits. Also, you can see the total duration of a workday and override the number of work hours per day, if needed.

|Element|Description|
|-------|-----------|
|**Calendar ID**|The unique identifier of the calendar. Acumatica ERP provides the following predefined work calendars:

 -   *24H7WD*: In this calendar, the work week is set to 24 hours a day and 7 days a week.
-   *EASTERN*: In this calendar, the work week is set to 8 hours a day \(9:00 AM to 6:00 PM, with a break duration of 1 hour\) and 5 days a week \(Monday through Friday\).

|
|**Description**|A description of the calendar.|
|**Time Zone**|The time zone associated with the calendar. Select the proper time zone from the list of all time zones available.|
|**Workday Hours**|The duration of the work time \(in hours and minutes\) during the workday. The system calculates the time duration as the sum of the durations in the **Hours Worked** column for each selected day divided by the number of selected days on the **Calendar** tab. If the duration in the **Hours Worked** column changes, the system recalculates the duration in the box.

 You can edit the duration in the box only if the **Override** check box is selected.

|
|**Override**|A check box that indicates \(if selected\) that you can override the duration of the work time during the workday for the current calendar. By default, the check box is cleared.|

## Calendar Tab {#2 .section}

On this tab, you define the working hours of the company, its branch or employees, or business partners, depending on the particular calendar. The elements are grouped into seven rows; each row represents a day of the week. For each day, the duration of the work time and the duration of breaks during the working day are also displayed.

|Element|Description|
|-------|-----------|
|**Day of Week**|The day of the week. Select the check box for the day if it is a workday.|
|**Start Time**|The time when the working hours start on this day of the week.|
|**End Time**|The time when the working hours end on this day of the week.|
|**Hours Worked**|Read-only. The duration of work time in hours and minutes for a particular day. The value is calculated by using the formula.

 ```
Hours Worked = End Time - Start Time - Break Duration
```

 If a value in the **Start Time**, **End Time**, or **Break Duration** column \(or all of them\) is changed, the system recalculates the duration in the column.

**Tip:** If you specify an end time of the workday that is earlier than the start time, the system considers the end of the workday to be on the following day. Suppose that the start time is set for *9:00 PM* and the end time for *9:00 AM*. Then the system calculates *12* hours in the **Hours Worked** column for that workday.

|
|**Break Duration**|Read-only. The duration of a break \(or multiple breaks\) in hours and minutes within the working hours for a particular day. The system populates the column by using the data on the **Break Times** tab of the current form. If you change the break times on the **Break Times** tab, the system updates the durations in the column accordingly.|

|Column|Description|
|------|-----------|
|**Day of Week**|The day of the week for which you are specifying the break duration. If you select the *All* option, the system applies the break duration to every day of the week.|
|**Start Time**|Required. The time when the break starts.|
|**End Time**|Required. The time when the break ends.|
|**Break Duration**|The duration of a break for the particular day \(or for all days if *All* is the specified day of the week\). The duration is expressed in hours and minutes and calculated by using the following formula.

 ```
Break Duration = End Time - Start Time
```

|
|**Description**|Optional description of the break time.|

## Exceptions Tab {#3 .section}

You use this tab to configure exceptions to the normal calendar for a particular year. Holidays, for example, may preempt workdays or shift them to days when the employees generally do not work. Exceptions may also include changes in working hours for particular days, such as early closings.

|Element|Description|
|-------|-----------|
|**Year**|The year for which the exceptions shown in the table below are applied.|

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Date**|The date of the exception.|
|**Day of Week**|Read-only. The day of the week on the specified date.|
|**Description**|A description of the exception.|
|**Work Day**|A check box that indicates \(if selected\) that this day is a work day. If this check box is not selected, the day is considered a non-working day.|
|**Start Time**|Required. The start time of the working hours.|
|**End Time**|Required. The end time of the working hours.|
|**Break Duration**|Required. The break duration for a particular day, expressed in hours and minutes. This break duration does not affect the calculated workday hours displayed in the Summary area.|
