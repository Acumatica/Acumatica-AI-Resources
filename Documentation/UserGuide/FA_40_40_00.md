# Asset Transaction History

Form ID: \(FA404000\)

By using this form, you can get a detailed view of the transaction history of a specific asset for the selected account \(and subaccount, if any\) within the specified range of periods.

## Form Toolbar

The form toolbar has only standard buttons.

## Selection Area

In this area, you can specify the criteria for selecting the transactions to be displayed in the table.

<table><thead><tr><th>

Element

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Asset ID**

</td><td>

The fixed asset for which transactions will be displayed.

</td></tr><tr><td>

**Period From**

</td><td>

The starting financial period in the range of periods the history will cover.

 By default, the current financial period is selected.

</td></tr><tr><td>

**Period To**

</td><td>

The ending financial period in the range of periods the history will cover.

 By default, the current financial period is selected.

</td></tr><tr><td>

**Book**

</td><td>

The book which asset transactions you want to view.

 By default, the Fixed Asset posting book is selected.

</td></tr><tr><td>

**Account**

</td><td>

The account which asset transactions you want to view.

</td></tr><tr><td>

**Subaccount**

</td><td>

The subaccount used for such transactions.

 This box appears on the form only if the *Subaccounts* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

</td></tr></tbody>
</table>
