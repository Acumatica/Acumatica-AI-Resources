# Subcontracts Preferences

Form ID: \(SC101000\)

**Attention:** This form is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to provide the general settings for the subcontract functionality, such as numbering sequences for subcontracts, validation requirements for subcontracts, approval and mailing settings, and the list of attributes for subcontracts.

## Form Toolbar

The form toolbar has only standard buttons.

## Mailing &amp; Printing Tab

The tab contains the list of predefined mailings that can be used for sending subcontracts to vendors by email. Mailing settings specified on this tab are used as the default values for mailing and printing settings specified for vendor classes on the [Vendor Classes](AP_20_10_00.md) \(AP201000\) form, which in turn are used as the default values for setting up mailing and printing for particular vendors on the [Vendors](AP_30_30_00.md) \(AP303000\) form

For an overview of this functionality, see [Mailings for Vendors: General Information](Finance_PredefinedMailings_Vendors_GeneralInfo.md). For details on setting up vendor mailings, see [Mailings for Vendors: To Set Up a Mailing for a Vendor Class](Finance_PredefinedMailings_Vendors_Activity1.md) and [Mailings for Vendors: To Set Up a Mailing for a Vendor](Finance_PredefinedMailings_Vendors_Activity2.md).

## Attributes Tab

The **Attributes** tab contains the list of attributes that can be assigned to subcontracts. For more information see [Attributes](CS_20_50_00.md) \(CS205000\) form. The table toolbar includes only standard buttons.

<table id="_b7139c0d-adad-47e7-a640-f5234cb45f3f"><thead><tr><th>

The title of the attribute.

</td></tr><tr><td>

</td></tr><tr><td>

**Required**

</td><td>

A check box that indicates \(if selected\) that the attribute is required.

</td></tr><tr><td>

**Control Type**

</td><td>

The control type of the attribute. The attribute can have one of the following control types:

 -   *Text*: The control is a text box in which the user can type text. For this type, you can specify an input validation option: an input mask or a regular expression.
-   *Number*: The control is a text box in which the user can enter numeric values.
-   *Combo*: The control is a combo box, which is a text box with a list box attached, so users can type or select the attribute value. For this type, you can enter a list of possible values.
-   *Multi Select Combo*: The control is a list box with a check box against each attribute value so users can select multiple options. For this type, you can enter a list of possible values.
-   *Checkbox*: The control is a check box that can be selected or cleared to turn the option on or off.
-   *Datetime*: The control is used to enter a date.
-   *Selector*: The control is a lookup box in which users select a value from a list of values of a data field selected from a data access class. The data access class and data field are specified in the **Schema Object** and **Schema Field** boxes that are available on the form if this option is selected.

</td></tr></tbody>
</table>
