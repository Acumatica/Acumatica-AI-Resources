# Reversing Transactions: Related Reports and Inquiries {#_b5db0607-d442-4ebc-adb9-d58579a8ff24 .concept}

In this topic, you can find the list of reports and inquiries related to reversing batches.

## Finding Reversing Batches for an Original Batch {#section_gdh_mjv_vxb .section}

To view the list of reversing batches related to an original batch, you can use the [GL Reversing Batches](../Shared/../UserGuide/GL_69_00_10.md) \(GL690010\) report. On the report form, you run the report for the original batch, and you can then view the list of reversing batches and their details.

You can also open this report by clicking the link in the **Reversing Batches** box of the [Journal Transactions](../Shared/../UserGuide/GL_30_10_00.md) \(GL301000\) form for the original batch. The system opens the [GL Reversing Batches](../Shared/../UserGuide/GL_69_00_10.md) \(GL690010\) report with the list of reversing batches and their details.
