# Printers

Form ID: \(SM206510\)

**Note:** This form is available only if the *DeviceHub* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can review \(and update\) the list of printers configured in Acumatica ERP through integration with DeviceHub.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Update Printer List**|Receives the list of configured printers from the DeviceHub application.|

## Table

This table displays the list of printers that have been configured in Acumatica ERP through integration with the DeviceHub application.

|Column|Description|
|------|-----------|
|**DeviceHub ID**|The unique identifier of the DeviceHub application in which the printer is configured.|
|**Printer**|The identifier of the printer.|
|**Description**|The brief description that has been provided for the printer.|
|**Default Number of Copies**|The default number of copies of a document to be printed via DeviceHub.|
|**Active**|A check box that specifies \(if selected\) that the printer can be used for printing documents.|
