# Overview of the Acumatica Add-In for Outlook {#_170da3aa-7709-4887-a4aa-25542d7a6f02 .concept}

The Acumatica add-in for Outlook processes the incoming and outgoing mail in your Outlook mailbox and searches for records, such as leads and contacts, in Acumatica ERP that correspond to the sender and recipient addresses in the emails.

If you use the add-in with the Modern UI, you can:

-   Link an email to a selected record and create an email activity associated with that record. For details, see [Acumatica Add-In for Outlook: Email Activity Management](OU_AddIn_Email_Activity_Management.md) and [Acumatica Add-In for Outlook: Project Management](OU_AddIn_Project_Management.md).
-   Submit PDF attachments for recognition so that AP documents can be created automatically based on those attachments. \(For more information, see [Acumatica Add-In for Outlook: Incoming Document Management](OU_AddIn_Incoming_Documents_Management.md).\)
-   Create a new record of one of the following types based on the selected email address:
    -   Contact. For details, see [Acumatica Add-In for Outlook: Contact Management](OU_AddIn_Contact_Management.md).
    -   Business account. For details, see [Acumatica Add-In for Outlook: Business Account Management](OU_AddIn_Account_Management.md).
    -   Lead. For details, see [Acumatica Add-In for Outlook: Lead Management](OU_AddIn_Lead_Management.md).
    -   Opportunity. For details, see [Acumatica Add-In for Outlook: Opportunity Management](OU_AddIn_Opportunity_Management.md).
    -   Case. For details, see [Acumatica Add-In for Outlook: Case Management](OU_AddIn_Case_Management.md)
    -   Request for information. For details, see [Acumatica Add-In for Outlook: Requests for Information Management](OU_AddIn_Requests_for_Information_Management.md).
    -   Project Issue. For details, see [Acumatica Add-In for Outlook: Project Issue Management](OU_AddIn_Project_Issue_Management.md).

If you use the add-in with the Classic UI, you can:

-   View details on lead, contact, and employee records that already exist in Acumatica ERP. \(For details, see [Review of Record Details](OU__con_Viewing_Record_Details.md).\)
-   Create new records of the same types as in the Modern UI, except for business accounts. \(For more information, see [Record Entry](OU__con_Creating_Leads_Contacts.md).\)
-   Log your communication activities. \(For details, see [Logging of Communication Activities](OU__con_Logging_Email_Activities.md).\)
-   Submit PDF attachments for recognition so that AP documents can be created automatically based on those attachments. \(For more information, see [Submitting Documents for Recognition](OU__con_Submitting_Attachments_for_Recognition.md).\)

You can also customize the appearance of the Acumatica ribbon button in Outlook in accordance with your company's branding.

## Limitation { .section}

The Acumatica add-in for Outlook does not support shared mailboxes.
