# Route Appointment GPS Location {#_d3dac09e-ea5a-4d57-9cad-52a90eff2600 .reference}

Form ID: \(FS404080\)

On this form, you can view the GPS coordinates of the appointments that are associated with a particular route and translate the coordinates to the address.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Generate**|Displays a list of appointments that shows their address details and GPS coordinates according to the criteria that is specified in the Selection area and translate the coordinates to the address.|
|**View as Report**|Opens a list of appointments in the PDF or HTML format with their address details and GPS coordinates in a report format.

 This button is available only after the **Generate** button is clicked.

|

## Selection Area {#1 .section}

You use the elements in the Selection area \(described in the following table\) to specify the criteria according to which the data is filtered in the table.

|Element|Description|
|-------|-----------|
|**Route**|The route definition for which you want to view data.|
|**Route Nbr.**|The number of the route for which you want to view data.|
|**Service**|The service for which you want to view data.|
|**Customer**|The customer for which you want to view data.

 The list of customers available for selection may be limited based on the role or roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. In this case, the **Restrict Visibility To** box appears on the **Financial** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form. With the feature enabled, a customer is available for selection if one of the following is true:

-   The **Restrict Visibility To** box is empty for the customer—that is, the customer’s visibility is not restricted.
-   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer, and your user account has the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.

|
|**Customer Location**|The customer location for which you want to view data.|
|**From Date**|The start date of the date range for which you want to view the routes to be displayed.|
|**To Date**|The end date of the date range for which you want to view the routes to be displayed.|

## Table { .section}

In this table, you can view the list of appointments related to the routes with their GPS coordinates.

The table toolbar has only standard buttons.

|Columns|Description|
|-------|-----------|
|**Appointment Nbr.**|The reference number of the appointment.|
|**Customer**|The customer for which the appointment is performed.|
|**Location**|The customer location where the appointment takes place.|
|**Actual Start Date**|The actual date when the appointment is performed.|
|**Address**|The address of the customer location where the appointment takes place.|
|**GPS Start Coordinate**|The GPS coordinate of the start location of the route related to the appointment.|
|**GPS Start Address**|The address \(translated from the **GPS Start Coordinate**\) of the start location of the route related to the appointment.|
|**GPS Complete Coordinate**|The GPS coordinate of the end location of the route related to the appointment.|
|**GPS Complete Address**|The address \(translated from the **GPS Complete Coordinate**\) of the end location of the route related to the appointment.|
