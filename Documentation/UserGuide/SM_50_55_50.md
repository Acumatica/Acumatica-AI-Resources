# Purge Audit History

Form ID: \(SM505550\)

Use this form to control the growth of field-level auditing history: calculate the current number of audit history records, change the retention period, purge obsolete records on demand, or schedule automated purging.

**Note:** To preserve audit trail integrity, the system purges history only at the table level and does not allow selective deletion of individual users or partial audit entries.

## Summary Area

This area contains information about the last audit history calculation and purge settings.

|Element|Description|
|-------|-----------|
|**History Last Calculated On**|Read-only field displaying the date the audit history was last calculated.|
|**Purge After \(Months\)**|Defines the retention period for storing the complete audit history.|
|**Purge Audit History Before**|Read-only field displaying the date before which logs will be purged.|

## Table

This table lists the database tables that have auditing enabled on the [Audit](SM_20_55_10.md) \(SM205510\) form. You can select which tables to include in processing.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|A check box you select to include the audit record in processing when you click **Process**.|
|**Table Name**|The name of the database table with auditing enabled.|
|**Screen IDs**|The ID of the source form.|
|**Latest History Record Count**|The number of audit history records for the given database table, calculated during the last **Calculate History** action.|
|**Purged Up To**|The date until which logs were previously purged.|
|**Last Purged On**|The date when the last purge operation occurred.|
|**Last Purged By**|The username of the user who performed the last purge operation.|
