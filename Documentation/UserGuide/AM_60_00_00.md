# Lot/Serial Hierarchy {#_05179961-716f-4929-a1d5-9f15dd7af48b .reference}

Form ID: \(AM600000\)

This report lists the lot and serial numbers of parent and component items.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Order Type:** Select the particular order type to be displayed in the report. You can blank this box to remove the filter.
-   **Production Order**: A particular production order. Select a production order to view only this order, or leave it blank to view all orders.
-   **Inventory ID**: A particular inventory item. Select an inventory item to view all production orders for this item, or leave it blank to view all inventory items.
