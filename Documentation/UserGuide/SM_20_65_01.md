# Manage Print Queue

Form ID: \(SM206501\)

**Note:** This form is available only if the *DeviceHub* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can delete, reprint, or update multiple print jobs created for DeviceHub

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the processing \(based on the **Action** you select\) for the print jobs you have selected in the table.|
|**Process All**|Initiates the processing \(based on the **Action** you select\) for all print jobs listed in the table.|

## Selection Area

You can use the settings in this area to narrow the range of print jobs listed in the table. The area also contains parameters used during the processing of print jobs.
