# Create Equipment for Sold Items {#_f7e00c4b-904d-4e54-bae0-089e09a28133 .reference}

Form ID: \(FS500900\)

On this form, you can designate stock items sold by your company as target equipment, which can then be serviced. For details, see [Target Equipment](FS__CON_Target_Equipment.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Creates equipment records for the stock items that you have selected in the table.|
|**Process All**|Creates equipment records for all stock items in the list.|

## Selection Area { .section}

By using the elements in this area, you can filter the sold stock items that will be displayed in the table of this form, and you can define the period of time for which you want to view the stock items.

|Element|Description|
|-------|-----------|
|**Item Class ID**|The item class of the model equipment \(that is, the item class with the **Model Equipment Item Class** selected on the [Item Classes](IN_20_10_00.md) \(IN201000\) form\) that will be displayed in the table.|
|**Sold After**|The invoice date from which sold stock items will be displayed in the table.|

## Table { .section}

This table displays the sold stock items that meet the criteria you have specified.

The table toolbar has only standard buttons.

|Element|Description|
|-------|-----------|
|Included|A check box that you select to include the stock item to the process.|
|**Inventory ID**|The identifier of the inventory item \(stock item, in this case\) that was sold.|
|**Description**|The description of the stock item.|
|**Lot Serial Number**|The lot or serial number of the stock item.|
|**Item Class ID**|The item class assigned to the stock item on the [Stock Items](IN_20_25_00.md) \(IN202500\) form.|
|**Invoice Ref. Nbr.**|The reference number of the invoice related to the stock item.|
|**Billing Date**|The date when the invoice was issued.|
|**Customer**|The customer to which the stock item has been sold.|
|**Location**|The location of the customer to which the stock item has been sold.|
