# To Assign a Stock Item to a Physical Inventory Cycle {#_f549d307-7c58-4549-abfb-b3a2b5fcaed0 .task}

After you have created the necessary PI cycles, you must assign each stock item that should be included in a cycle to the PI cycle by using the [Stock Items](IN_20_25_00.md) \(IN202500\) form, as described in this topic.

**Attention:** To open any form, you can navigate to it or search for it \(by its name or by its form ID without periods\).

## To Assign a Stock Item to a Physical Inventory Cycle { .section}

1.  Open the [Stock Items](../Shared/../UserGuide/IN_20_25_00.md) \(IN202500\) form.
2.  Select the stock item by its inventory ID.
3.  In the **Physical Inventory** section of the **General** tab, in the **PI Cycle** box, select the appropriate physical inventory cycle.
4.  On the form toolbar, click **Save**.
