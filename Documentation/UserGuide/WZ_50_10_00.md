# Activate Recurring Scenarios

Form ID: \(WZ501000\)

By using this form, you can automate the process of running the scenario schedules created on the [Recurring Scenarios](WZ_30_10_00.md) \(WZ301000\) form. To do this, you should create the automation schedule according to which the system will run the scenario schedules automatically.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Runs the selected scenario schedule or schedules.|
|**Process All**|Runs all listed scenario schedules.|

## Table

The table contains the list of schedules \(each of which includes at least one scenario\) that you have created on the [Recurring Scenarios](WZ_30_10_00.md) \(WZ301000\) form.

|Column|Description|
|------|-----------|
|Included|A check box that you select to include the schedule in processing when you click **Process**.|
|**Schedule ID**|The ID of the schedule, which was automatically generated by the system when you created the schedule for the scenario.|
|**Description**|The description of the schedule, which was specified during schedule creation.|
|**Start Date**|The date starting from which the schedule can be used.|
|**Expiration Date**|The date that, if set, indicates when the schedule expires.|
|**Executed \(times\)**|The number of times the schedule was executed—that is, how many times the scenarios included in the schedule were activated. A *0* here indicates that the schedule was not executed yet and no scenarios were activated.|
|**Execution Limit \(times\)**|The maximum number of times the schedule can be executed.|
|**Last Executed**|The date when the schedule was last executed \(if applicable\).|
|**Next Execution**|The date when the schedule should be executed next.|
