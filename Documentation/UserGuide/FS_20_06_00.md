# Skills

Form ID: \(FS200600\)

This form displays a list of skills available in the system. You can use the form to add new skills or modify existing ones. The skills can be assigned to a staff member and can be used as requirement to perform a service.

## Form Toolbar

The form toolbar has only standard buttons.

## Table

|Column|Description|
|------|-----------|
|**Skill ID**|The unique identifier of the specific skill that staff members can have.|
|**Description**|A description of the skill.|
|**Driver Skill**|A check box that indicates \(if selected\) that the skill is a skill associated with driving a vehicle.|
