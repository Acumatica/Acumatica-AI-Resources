# Inventory Management {#_1873e99d-a763-43ad-b6c9-dbdf26867637 .concept}

The inventory management functionality provides a wide range of add-on features that will help your business to more effectively manage its inventory. With the *Inventory* feature enabled in the *Inventory and Order Management* group of features on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, you can create and maintain stock and non-stock items, perform receipts and issues, and prepare and complete full physical counts. Other add-on features give you the ability to do the following:

-   Track items by lot or serial numbers and expiration dates
-   Use multiple units of measure \(base, sales, and purchase units\) for each item and configure the rules for conversion between these units of measure
-   Define multiple warehouses, each with multiple locations
-   Set up automated replenishment
-   Configure automatic packaging to facilitate shipping
-   Create matrix items

This guide contains all the information you need to use the inventory functionality.
