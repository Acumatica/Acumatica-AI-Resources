# Staff Routes on Map {#_e2c22a91-5e7c-4269-8134-e890dbba7d3a .reference}

Form ID: \(FS301000\)

On this form, for a particular date, you can view on a map the routes to which the drivers are assigned. You can also view the current locations of staff members.

## Staff Pane { .section}

In the table on this pane, you can view the staff members \(that is, drivers\) and information about the routes and appointments to which they are assigned. You can also move an appointment on this tab by dragging its line to the required place.

The toolbar includes standard elements.

|Column|Description|
|------|-----------|
|**Route List**|The list of staff members \(drivers\) and the routes to which they are assigned. You can view the appointment details of a particular driver if you click the arrow button left of the driver's name.|
|**Route/Customer**|The name of the route created on the [Routes](FS_20_37_00.md) \(FS203700\) form or the customer with which the appointment takes place.|
|**Location**|The identifier of the appointment location.|
|**Service Duration**|The total expected time of performing the services of the appointment in this row.|

|Element|Description|
|-------|-----------|
|**Show or Hide Route Appointment Information on the Map**|Shows or hides the appointment information on the map for the route of the driver you have selected.|
|**Show or Hide GPS Location on Map**|Shows or hides the latest location \(indicated with the *D* icon\) on the map for the route of the driver you have selected.

 This menu command is available only if the **Show Location Tracking** check box is selected on the [Service Management Preferences](FS_10_01_00.md#) \(FS100100\) form.

|

|Element|Description|
|-------|-----------|
|**Appointment Information**|Opens the [Appointments](FS_30_02_00.md) \(FS300200\) form, where you can view and modify the details of the appointment you have selected.|

## Map Pane { .section}

In the map area of the pane, you can view the routes of the drivers for the date and branch that are selected on the map toolbar. On the map, you can click any appointment icon \(a number within a circle\) to view information about an appointment of a route.

You can also view the most recent tracked location of each driver, which is identified with a *D* \(the driver location icon\) on the map. You click this icon to see the driver's name and the time when the location was registered.

For you to be able to view the most recent staff locations, the **Show Location Tracking** check box has to be selected on the **Calendars and Maps** tab \(the**Map Settings** section\) of the [Service Management Preferences](FS_10_01_00.md) \(FS100100\) form. Also, location tracking has to be turned on for each user whose locations you want to track, which is done on the [Users](SM_20_10_10.md) \(SM201010\) form. For details, see [Managing User Access](SA_Managing_User_Access_Mapref.md).

The map toolbar includes standard and form-specific elements. The form-specific element is listed below.

|Button|Description|
|------|-----------|
|**Branch**|A box in which you can select the branch for which routes are shown on the map.

 A staff member's routes will be shown on the map if for the staff member, this branch is selected in the **Branch** box of the [Route Document Details](FS_30_40_00.md) \(FS304000\) form.

|

## Route Pane { .section}

In this pane, you can view data on the route duration, distance, and number of appointments for the staff member you have selected in the **Staff** pane of the current form. You have to select a staff member to view the data.

**Tip:** When you select a staff member, the system changes the name of the pane to *Route for* followed by the name of the staff member.

## Appointment Information Table {#_58dbc2d9-d9cb-4c14-8bb4-d889915401e4 .section}

In this section, you can view data on each appointment on the route of the selected staff member in the **Staff** tab of the current form. You have to select a staff member to view the data.

**Note:** The name of this pane is initially **Appointment Information**, and the pane contains no data. When you select a staff member, the system changes the name of the pane to *Appointments for* followed by the name of the staff member with the number of appointments in parentheses. For example, if the staff member has three appointments with customers \(this means five appointments overall, including the start and end locations of the route execution\), the updated name of this pane is *Appointments for Andrews Michael, Mr. \(5\)*.

|Column|Description|
|------|-----------|
|**Appointment**|The number of the appointment, as specified on the [Appointments](../Shared/../UserGuide/FS_30_02_00.md) \(FS300200\) form, or the start or end location of the route specified in parenthesis.|
|**Route/Customer**|The name of the customer with which the appointment takes place.|
|**Service Type**|A description of the service.|
|**Travel Time**|The time that is needed to get from the appointment location listed in this row to the next appointment location.|
|**Service Duration**|The total time that performing the services of the appointment is expected to take.|
|**Actual Start Time**|The actual time when the appointment started.|
|**Actual End Time**|The actual time when the appointment ended.|
|**Location**|The identifier of the appointment location.|
|**Postal Codes**|The postal code of the appointment location.|
|**Address**|The address of the appointment location.|
