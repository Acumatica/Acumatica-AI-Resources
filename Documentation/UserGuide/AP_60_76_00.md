# T5018 Preview Report {#_20020641-6738-4cb3-b6bf-8380d4a41bbf .reference}

Report ID: \(AP607600\)

**Note:** This report appears in the system if the *Canadian Localization* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This report contains all the boxes that are required on the T5018 Statement of Contract Payments form. You can run this report to preview the T5018 information before generating the T5018 e-file and submitting this information to the Canada Revenue Agency \(CRA\).

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Transmitter**: The company ID of the company acting as the report transmitter.
-   **T5018 Tax Year**: The tax year for which T5018 report will be generated. The list includes only years for which T5018 data is available.
-   **Revision**: The revision of the T5018 report that you want to run.
