# Estimate Summary

Form ID: \(AM641000\)

This report is intended to be used as a document to send to a customer or prospect.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Estimate ID:** Enter or select estimate you with to print.
-   **Revision ID:** Enter or select the revision of the estimate to print.
-   **Print Material:** If selected the materials are included in the report.
