# Transactions with Subaccounts: General Information

If subaccounts are used in your system, you can enter and process GL batches in which journal entries to one account are split between multiple subaccounts. When you enter a GL batch with subaccounts on the [Journal Transactions](GL_30_10_00.md) \(GL301000\) form, you perform the same steps as you do when you add a GL batch that does not involve subaccounts, except that you enter a subaccount for each entry in the batch. For details on GL batch processing, see [GL Transactions: General Information](Finance_Processing_Batch_GeneralInfo.md).

## Learning Objectives

In this chapter, you will learn how to do the following:

-   Create a GL batch that includes subaccounts
-   Release the batch
-   Review the changes on an inquiry form

## Applicable Scenarios

You create a transaction with subaccounts if you want to manually enter a GL batch and subaccounts have been configured in the system.
