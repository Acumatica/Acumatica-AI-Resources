# AI Automation History

Form ID: \(ML400000\)

You use this form to view statistics on your agents, agent LLM connections, and commands. Each time you perform an operation with AI Automation, the system adds the appropriate record to the table on the form.

Real-time monitoring can help you avoid budget overruns, prevent errors caused by excess token usage, and understand your usage patterns. These insights can help you refine agents and decide whether a more efficient LLM is worth considering.

This form is available only if the *AI Automation* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar has only standard buttons.
