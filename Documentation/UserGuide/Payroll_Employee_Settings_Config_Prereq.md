# Employee Payroll Settings: Configuration Prerequisites {#_66b19389-a02f-4b35-a2bd-c4dd43c27c4a .concept}

Before you start specifying employee payroll settings, you must be sure that the system has been configured properly and that all required entities have been created, as described in the following sections.

## Enabling the Needed Features { .section}

On the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the *Payroll* feature has been enabled.

## Configuring the System { .section}

The following tasks have been performed in Acumatica ERP:

-   On the [Chart of Accounts](GL_20_25_00.md) \(GL202500\) form, necessary GL accounts have been created.
-   On the [Work Calendar](CS_20_90_00.md) \(CS209000\) form, the work calendar has been defined.
-   On the [Payroll Preferences](PR_10_10_00.md) \(PR101000\) form, the numbering sequences have been specified and saved to the system.
-   On the [Work Locations](PR_10_10_40.md) \(PR101040\) form, necessary work locations have been created and their addresses have been specified.
-   On the [Tax Maintenance](PR_20_80_00.md) \(PR208000\) form, taxes have been defined and brought up to date.
-   On the [Earning Type Codes](PR_10_20_00.md) \(PR102000\) form, necessary earning types have been defined.
-   On the [Pay Groups](PR_20_50_00.md) \(PR205000\) form, the necessary pay groups have been created.
-   On the [Workers' Compensation Codes](PR_20_98_00.md) \(PR209800\) form, the workers' compensation codes have been configured.
-   On the [Union Locals](PR_20_97_00.md) \(PR209700\) form, the union records have been created.
-   On the [Overtime Rules](PR_10_40_00.md) \(PR104000\) form, the overtime rules have been configured.
-   On the [PTO Banks](PR_20_40_00.md) \(PR204000\) form, the necessary PTO banks have been defined.
-   On [Positions](EP_20_10_00.md) \(EP201000\) form, positions have been created.
-   On the [Employees](EP_20_30_00.md) \(EP203000\) form, employees have been configured.
-   On the [Employee Payroll Class](PR_20_20_00.md) \(PR202000\) form, employee payroll classes have been defined.
-   On the [Payment Methods](CA_20_40_00.md) \(CA204000\) form, payment methods and a cash account for each payment method to be used to generate paychecks for an employee have been defined.
