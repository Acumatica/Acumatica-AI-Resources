# Pick List for Purchase Return

Form ID: \(PO644000\)

**Attention:** This report is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

This report displays a pick list for the selected purchase return as a ready-to-print document. The document provides the locations, items, lot or serial numbers \(if applicable\), and quantities that a warehouse worker uses to pick the items for return to the vendor. The pick list also provides the unit and total weight and volume of the items, and has empty fields in which the worker can record picked quantities.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters

On the **Report Parameters** tab, you use the following parameter to select the information to be displayed on the report.

-   **Purchase Return Nbr.**: The reference number of the purchase return for which the pick list is to be printed. You can select a purchase return with the *Balanced* or *Picked* status.
