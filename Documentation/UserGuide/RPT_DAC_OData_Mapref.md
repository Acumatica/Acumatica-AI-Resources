# Accessing DACs Through OData {#_642945d9-df36-429b-8784-0f1bcf0e5495 .concept}

Acumatica ERP provides the following types of OData interfaces:

-   *Generic inquiry–based*: Retrieves data from generic inquiries.
-   *DAC-based*: Retrieves data from data access classes \(DACs\).

This chapter describes the DAC-based OData interface. For details about the generic inquiry-based OData interface, see [Accessing the Exposed Inquiry Results Through OData](GI_Access_to_Exposed_Inquiry_Through_OData_Mapref.md).
