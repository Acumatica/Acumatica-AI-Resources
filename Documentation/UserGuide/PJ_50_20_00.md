# Assign Project Issue {#_ee607d4f-0a37-4210-8ca9-4ea862c4c44f .reference}

Form ID: \(PJ502000\)

**Attention:** This form is available if the *Construction Project Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can assign owners to project issues if the assignment map is selected in the **Project Issue Assignment Map** box of the [Project Management Preferences](PJ_10_10_00.md#) \(PJ101000\) form. You create assignment maps on the [Assignment Maps](EP_20_50_10.md#) \(EP205010\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Command|Description|
|-------|-----------|
|**Process**|Initiates the assigning owners to the project issues you have selected \(by using the unlabeled check boxes\) in the table.|
|**Process All**|Initiates the assigning owners to all project issues in the table.|

## Table {#2 .section}

The table contains the list of all project issues with the *Open* status. You can assign owners to all project issues or only to those you select.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you can use to include the project issue in processing if you click **Process**.|
|**Project Issue ID**|The project issue, by its identifier.|
|**Summary**|The summary of the project issue.|
|**Status**|The status of the project issue.|
|**Priority**|The priority of the project issue.|
|**Due Date**|The due date of the project issue.|
|**Class ID**|The identifier of the class to which the project issue is related.|
|**Owner**|The currently assigned owner.|
|**Workgroup**|The workgroup to work on the project issue.|
|**Created On**|The date when the project issue was created in the system.|
