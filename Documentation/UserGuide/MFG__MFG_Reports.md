# Manufacturing Reports {#_545bf1b7-2ff3-45fc-bf7c-143d764f87a4 .concept}

With the wide variety of Acumatica ERP reports related to manufacturing, you can promptly get detailed information about transactions related to manufacturing processes, as well as summary information about documents and entities involved in manufacturing. If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All manufacturing reports can be generated in different formats, including PDF and HTML, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
