# Tenant List

Form ID: \(SM203530\)

You use this form to view a table of related tenants that are current tenants of your website. The tenants to which you do not have access do not appear in the list, although the tenants store their data in the same database.

The order of the records in the table defines the order of appearance of the tenants on the Sign-In page.

## Table

The table toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Insert Tenant**|Opens the [Tenants](SM_20_35_20.md) \(SM203520\) form so you can insert a new tenant.|
|**Move Up**|Moves the selected tenant one position up in the table, thus changing its place in the list of tenants on the Sign-In page.|
|**Move Down**|Moves the selected tenant one position down in the table, thus changing its place in the list of tenants on the Sign-In page.|
