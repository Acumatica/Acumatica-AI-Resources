# Clock Entry {#_db7bfb7a-c3d8-43e6-aca8-023936b8240d .reference}

Form ID: \(AM315000\)

You use this form to record the labor time that you spend on a single operation of a particular production order. To record this time, you clock in for the operation when you start working on it and clock out for the operation when you complete it. You must clock out for the operation before clocking in for another operation of a production order \(the same order or another one\).

All labor time is recorded and processed in seconds regardless of the time format selected on the [BOM Preferences](AM_10_10_00.md) \(AM101000\) form.

You can also record the quantity of completed items, but you cannot record scrap by using this form. For scrap recording, you should use the [Labor](AM_30_10_00.md) \(AM301000\) or [Move](AM_30_20_00.md) \(AM302000\) form.

All clock entries that you create on the current form must be approved by using the [Approve Clock Entries](AM_51_60_00.md) \(AM516000\) form.

## Mobile App Support { .section}

The screen corresponding to this form exists in the Acumatica mobile app with the following limitations:

-   A password change cannot be forced during a user's sign-in.
-   Completed clock entry records cannot be displayed.

This command is available only when you click a line with a production order operation for which both of the following conditions are met:

 -   It is the last operation in the production order routing.

## Summary Area { .section}

In this area, you select the employee, the production order operation for which you would like to record labor time, and the other settings related to the time recording. Optionally, you can also enter the quantity of completed items before you clock out for the operation.

|Element|Description|
|-------|-----------|
|**Employee ID**|The identifier of the employee for whom you would like to record labor time. An employee is available in this box only if the **Production Employee** check box selected on the [Employees](EP_20_30_00.md) \(EP203000\) form.

 The system fills in this box automatically with the employee assigned to your user account on the [Users](SM_20_10_10.md) \(SM201010\) form if either of the following conditions is met:

 -   The **Restrict Clock Entry to Current User** check box is selected on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form. In this case, you cannot change the employee.
-   The **Default User Employee ID** check box is selected on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form. You can select another employee, if needed, unless the previous condition is met.

 If the box is empty by default, you can manually select an employee from the list.

 Additionally, in the table, the system displays only clock entries assigned to the employee.

|
|**Current User**|A button you click to insert the employee ID assigned to your user account in the **Employee ID** box if the **Production Employee** check box is selected on the [Employees](EP_20_30_00.md) \(EP203000\) form for the employee.|
|**Order Type**|The type of the production order for which you are recording labor time.|
|**Production Nbr.**|The reference number of the production order that contains the operation for which you are recording labor time. A production order is available for selection in this box only if its status is *Released*, *In Process*, or *Completed*.|
|**Operation ID**|The operation of the production order for which you are recording labor time.|
|**Shift**|The shift in which the employee works. The system uses the shift settings to calculate the labor cost.|
|**Quantity**|Optional. The quantity of items completed for this operation. If you would like to correct the quantity specified in one of the previous clock entries, you type a negative value.|
|**UOM**|The unit of measure for the item quantity specified in the **Quantity** box.|
|**Start Time**|The time when the employee clocked in for the operation.|
|**Duration**|The elapsed time since the employee clocked in for the operation.|

## Table { .section}

The table displays the operations with the recorded labor time for the employee selected in the **Employee ID** box. The system adds a row to the table when you clock out for the production operation.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Transaction Date**|The date when the clock entry has been created.|
|**Start Time**|The selected employee's clock-in time for the production operation.|
|**End Time**|The employee's clock-out time for the production operation.|
|**Labor Time**|The automatically calculated amount of time during which the employee was clocked in for the operation of the production order.|
|**Order Type**|The type of the production order for which the labor time was recorded.|
|**Production Nbr.**|The reference number of the production order that contains the operation for which the labor time was recorded.|
|**Operation ID**|The production operation for which the labor time was recorded.|
|**Inventory ID**|The item being produced, which is specified in the production order.|
|**Subitem**|The subitem of the item specified in the **Inventory ID** box.

 This column is visible only if the *Inventory Subitems* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

**Important:** The **Inventory Subitems** check box has been removed from the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form because the functionality associated with the *Inventory Subitems* feature will be phased out. If you have this feature enabled in your system, the associated functionality remains available. To disable the feature, contact your Acumatica support provider.

|
|**Shift**|The shift in which the employee worked when processing the items.|
|**Quantity**|The quantity of items completed for this operation.|
|**UOM**|The unit of measure for the item quantity specified in the **Quantity** column.|
|**Warehouse**|The warehouse to which the system will move the completed items when the last operation in the routing is completed. The system copies the warehouse from the production order.|
|**Location**|The warehouse location to which the system will move the completed items when the last operation in the routing is completed. The system copies the location from the production order.|
|**Approved**|A check box that indicates \(if selected\) that the clock entry has been approved on the [Approve Clock Entries](AM_51_60_00.md) \(AM516000\) form.|
