# File Upload Preferences {#_83ab66ec-f00e-4487-bbe7-969734a99693 .reference}

Form ID: \(SM202550\)

On this form, you can create a list of file types the system will allow to be imported to the website. Also, you can specify the maximum file size for import.

**Important:** If you have changed the list of supported file extensions on the current form, to apply the changes in the list of files that can be uploaded, you need to clear the system cache by clicking **Reset Caches** on the More menu of the [Apply Updates](SM_20_35_10.md) \(SM203510\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

Use this area to restrict the size of files that can be uploaded.

|Element|Description|
|-------|-----------|
|**Maximum File Upload Size in KB**|The maximum file size \(in KB\) that is allowed for import. Only files with smaller sizes may be imported. The default value is *25.000*.|

## Table { .section}

This table holds the file types that may be uploaded in the system. Optionally, you can select an icon to be used with the file type and specify whether files of the type are images.

|Column|Description|
|------|-----------|
|**File Extension**|The extension, which indicates the file type.|
|**Icon URL**|The URL of the icon to be used to designate files of this type.|
|**Forbidden**|A check box that you select to prohibit files of this type for importing.|
|**Image**|A check box that you select if files of the type are images.|
|**Default Application**|The mime type that is used for a specific file extension. It identifies which type of a file is downloaded, and determines which application can be used for opening the file once it is downloaded.|
