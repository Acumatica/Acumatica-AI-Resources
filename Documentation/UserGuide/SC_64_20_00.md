# Subcontract {#_9483efa9-d472-4fa9-8008-0d20c0382b52 .reference}

Form ID: \(SC642000\)

**Note:** This report is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

By using this report, you can prepare a printable form of a subcontract order with document details and total amounts. On the report form, you select the reference number of the particular subcontract you want to view.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters {#section_b5y_3dz_tmb .section}

On the **Report Parameters** tab, use the following parameter to select the information to be displayed on the report:

-   **Subcontract Number**: The number of the subcontract for which you want to prepare the printable document; this is a required element.
