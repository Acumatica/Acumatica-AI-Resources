# Service Billing History

Form ID: \(FS405000\)

This form shows the list of billing documents that have been generated from the field service documents, including deleted billing documents.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Run Appointment Billing**|Opens the [Run Appointment Billing](FS_50_01_00.md) \(FS500100\) form, where you can process billing for customers whose billing cycle is configured to run appointment billing, according to the cycle's settings on the [Billing Cycles](FS_20_60_00.md) \(FS206000\) form.|
|**Run Service Order Billing**|Opens the [Run Service Order Billing](FS_50_06_00.md) \(FS500600\), where you can process billing for customers whose billing cycle is configured to run service order billing, according to the cycle's settings on the [Billing Cycles](FS_20_60_00.md) \(FS206000\) form.|
|**Run Service Contract Billing**|Opens the [Run Service Contract Billing](FS_50_13_00.md) \(FS501300\) form, where you can process billing for service contracts with the *End-Period Plus*, *Beginning-Period Fixed*, and *Beginning-Period Plus* billing types.|
