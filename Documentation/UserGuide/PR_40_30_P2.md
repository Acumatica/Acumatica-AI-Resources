# Employee Pay Rates and Earnings {#_5a2eb9ad-ccff-49fd-8428-86776d301879 .reference}

Form ID: \(PR4030P2\)

On this form, you can review employee information about active pay rates combined with earning hours and amounts summarized by quarter. For each quarterly total, you can view details at the paycheck level.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

By using the elements in this area, you can specify filters, such as a specific year, for the information to be displayed in the table. The following table summarizes the elements of this area.

|Element|Description|
|-------|-----------|
|**Company/Branch**|The company or branch for which you want to view information. By default, the current company or branch is selected.|
|**Year**|The year for which information should be displayed in the table.|
|**Include Unreleased Paychecks**|A check box that indicates \(if selected\) that data from unreleased paychecks should also be included in the table.|

## Table {#2 .section}

The table displays a list of employees and related pay rates and earnings within the selected year.

Above the table is the Filter List drop-down menu. It contains a list of the following filters to display information about specific types of earnings in the table:

-   **All Records**: All available earnings \(The filter is applied by default when you open the form.\)
-   **Amount-Based** : The earnings of the *Amount-Based* type
-   **Overtime**: The earnings of the *Overtime* type
-   **Piecework**: The earnings of the *Piecework* type
-   **Time Off**: The earnings of the *Time Off* type
-   **Wage**: The earnings of the *Wage* type

|Column|Description|
|------|-----------|
|**Employee ID**|The identifier of the employee.|
|**Employee Name**|The name of the employee, as defined on the [Employees](EP_20_30_00.md) \(EP203000\) form.|
|**Status**|The status of the employee.

 The column is hidden by default.

|
|**Position**|The position the employee held in the company between the start date and the termination date.

 The column is hidden by default.

|
|**Position Start Date**|The date when the employee was appointed to this position.

 The column is hidden by default.

|
|**Termination Date**|The date when the employee’s employment in the company was terminated.

 The column is hidden by default.

|
|**Class ID**|The identifier of the payroll class.

 The column is hidden by default.

|
|**Pay Group**|The employee's pay group.

 The column is hidden by default.

|
|**Code**|The identifier of the type of earnings that this employee is eligible for.|
|**Description**|The name of the earning type.|
|**Manual Rate**|A check box that indicates \(if selected\) that the rate has been specified manually.|
|**Certified Job**|A check box that indicates \(if selected\) that the earning is for work performed on a certified project.

 This column is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Pay Rate**|The pay rate for the employee, based on the unit type.|
|**Unit Type**|The way the pay rate is applied, which can be one of the following: *Hour*, *Year*, or *Miscellaneous*.|
|**Effective From**|The date when this earning type came into effect for the employee.|
|**Work Location**|The identifier of the employee's work location.|
|**Q1 Hrs**|The number of working hours in the first quarter of the year.|

|**Q2 Hrs**|The number of working hours in the second quarter of the year.|
|**Q2 Amount**|The total amount for the second quarter of the year, which is calculated as the number of hours or pieces multiplied by the rate.|
|**Q3 Hrs**|The number of working hours in the third quarter of the year.|
|**Q3 Amount**|The total amount for the third quarter of the year, which is calculated as the number of hours or pieces multiplied by the rate.|
|**Q4 Hrs**|The number of working hours in the fourth quarter of the year.|
|**Q4 Amount**|The total amount for the fourth quarter of the year, which is calculated as the number of hours or pieces multiplied by the rate.|
|**YTD Hrs**|The year-to-date number of working hours.|
|**YTD Amount**|The year-to-date total amount, which is calculated as the number of hours or pieces multiplied by the rate.|
