# Create Labor Time Activities {#_e52606e3-2d20-4abb-b42a-c06d34f36957 .reference}

Form ID: \(AM513000\)

On this form, you can run a process that creates employee time activities on the [Employee Time Activities](EP_30_70_00.md) \(EP307000\) form from direct or indirect production labor transactions. If the production order references a project, the project and task are passed to the time activities.

**Attention:** In activities created by using this form, labor time is rounded to minutes, even if the original time was reported in seconds.

This process is available only if the *Time Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Creates time activities for the selected labor transactions in the list.|
|**Process All**|Creates time activities for all labor transactions in the list.|
|**Skip Selected**|Creates time activities for all labor transactions in the list except those selected.|

## Summary Area { .section}

|Element|Description|
|-------|-----------|
|**Show All Items**|A check box that you select to review all labor transactions in the table. If this check box is cleared, labor transactions with a status of *Unprocessed* are included.|

## Table { .section}

The table lists all labor batches and their transaction lines. The default is to only list the labor transactions with a time card status of *Unprocessed*.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|A check box that you select to include the labor transaction line in processing when you click **Process** or exclude it from processing when you click **Skip Selected**.|
|**Batch Nbr.**|The labor batch in which this transaction line resides.|
|**Tran. Date**|The transaction date of the labor batch.|
|**Order Type**|The production order type for direct labor transactions.|
|**Production Nbr.**|The production order number for direct labor transactions.|
|**Operation ID**|The operation ID for direct labor transactions.|
|**Employee ID**|The production employee from the transaction line.|
|**Labor Time**|The labor time from the transaction line.|
|**Labor Rate**|The labor rate is either from the work center standard cost or from the employee cost rate dependent on the **Use Labor Rate** setting on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form.|
|**Labor Amount**|The labor time multiplied by the labor rate.|
|**Project**|The project from the production order or the non-project code.|
|**Project Task**|The task from the project.|
|**Time Card Status**|The status of the labor transaction, which can be one of the following:-   *Processed:* The employee time activity has been created and no further action can be taken.
-   *Unprocessed:* The employee time activity has not been created.
-   *Skipped:* This labor transaction was skipped the last time the process was run but can be processed.

|
|**Warehouse**|The warehouse from the direct labor transaction.|
|**Inventory ID**|The inventory item from the production order for direct labor transactions.|
|**Labor Code**|The labor codes from the labor transaction.|
