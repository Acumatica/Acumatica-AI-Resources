# Bank Transactions History

Form ID: \(CA402000\)

You can use this form to view the history of imported bank transactions being processed in the system. You can filter the list of transactions by cash account, date range, or statement number.

## Selection Area

You use the elements in this area to select the cash account and, if needed, the particular statement number and the date range for which you want to view the history.

|Element|Description|
|-------|-----------|
|**Cash Account**|The cash account for which you want to view transactions.|
|**Date Range**|The start and end dates of the date range for which you want to display transactions.|
|**Statement Nbr.**|The reference number of the imported bank statement for which you want to view transactions.|
