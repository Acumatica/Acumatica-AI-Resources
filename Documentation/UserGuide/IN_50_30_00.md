# Change Stock Status of Items {#_4bac652e-177f-4518-90ee-b1819fc45ed7 .reference}

Form ID: \(IN503000\)

You can use this form to change the stock status of multiple items at once. That is, you can convert stock items to non-stock items and vice versa.

**Attention:** This form does not appear if at least one of the following features is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form: *Manufacturing*, *Projects*, *Time Management*, *Service Management*, *Payroll*.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the conversion of selected items.|
|**Process All**|Initiates the conversion of all items listed in the table.|

## Selection Area {#1 .section}

In this area, you can define the criteria for items to be displayed in the table and specify the settings that will be configured for converted items. The elements of this area are summarized below.

|Element|Description|
|-------|-----------|
|**Action**|The action to be taken on the items if you click **Process** or **Process All** on the form toolbar. Select one of the following options:

 -   *Convert Stock to Non-Stock*: Converts stock items to non-stock items.
-   *Convert Non-Stock to Stock*: Converts non-stock items to stock items.

|
|**Item Class**|The item class of the items to be converted.|
|**Inventory ID**|The inventory ID of the item to be converted. You can leave the box blank to view all items that can be converted, or select and convert a particular item; alternatively, you can click the **List** button next to the box, and in the dialog box that opens, add multiple inventory items.|
|**List**|Opens the **Inventory Item List** dialog box so that you can add the items to be listed in the table and available for processing. In the dialog box, you add rows for each item you want to include; only items that meet the selection criteria are available for selection. When you have finished adding items, you simply exit the dialog box.|
|The **Non-Stock Item Settings** sectionThis section appears only if the *Convert Stock to Non-Stock* option is selected in the **Action** box

|
|**Item Class**|The item class of the non-stock item, to which the stock item will be converted.|
|**Posting Class**|The posting class of the non-stock item, to which the stock item will be converted.|
|The **Stock Item Settings** sectionThis section appears only if the *Convert Non-Stock to Stock* option is selected in the **Action** box

|
|**Item Class**|The item class of the stock item, to which the non-stock item will be converted.|
|**Posting Class**|The posting class of the stock item, to which the non-stock item will be converted.|
|**Valuation Method**|The valuation method of the stock item, to which the non-stock item will be converted.|
|**Lot/Serial Class**|The lot/serial class of the stock item, to which the non-stock item will be converted.|

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include this item for processing if you click **Process**.|
|**Inventory ID**|The inventory ID of the item to be converted.|
|**Description**|The description of the item to be converted.|
|**Type**|The type of the item to be converted.|
|**Valuation Method**|The method used for the valuation of the item to be converted.|
|**Item Class**|The item class of the item to be converted.|
|**Posting Class**|The posting class of the item to be converted.|
|**Lot/Serial Class**|The lot/serial class of the item to be converted.|
|**Base Unit**|The base unit of measure of the item to be converted.|
|**Tax Category**|The tax category of the item to be converted.|

|Element|Description|
|-------|-----------|
|**Inventory ID**|The inventory ID of the stock item to be listed in the table.|
|**Description**|Read-only. A brief description of the stock item.|
