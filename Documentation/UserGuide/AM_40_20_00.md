# Where Used in BOM {#_bbdb5bff-ec82-42b8-a211-ed3559b566b6 .reference}

Form ID: \(AM402000\)

On this form, you can view the bills of material \(BOMs\) in which a particular component \(or material\) is assigned. You can also use this form when you need to alter a component or replace it with a different component, so you need to know the bills of material that contain it.

## Form Toolbar {#section_hpt_ztw_swb .section}

The form toolbar includes only a standard button.

## Selection Area { .section}

You can use the elements in this area to narrow the range of BOMs that are listed in the table. For example, you can select an item class to view bills of material that contain components assigned to this class. You can also select a component in the **Inventory ID** box to view the specific BOM to which the component is assigned or to display all levels of the BOM in which the component is assigned.

|**Element**|**Description**|
|-----------|---------------|
|**Inventory ID**|The identifier of the item for which you want to view BOMs in the table. You can select a stock or non-stock item or leave the box empty if you would like to view a boarder range of data in the table.|
|**Subitem**|The subitem of the item selected in the **Inventory ID** box for which you want to view BOMs in the table.

 This column is visible only if the *Inventory Subitems* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

**Important:** The **Inventory Subitems** check box has been removed from the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form because the functionality associated with the *Inventory Subitems* feature will be phased out. If you have this feature enabled in your system, the associated functionality remains available. To disable the feature, contact your Acumatica support provider.

|
|**Show Multilevel Results**|A check box that you select so that the table lists all levels of each BOM in which the component is used, including higher-level BOMs.|
|**BOM Warehouse**|The warehouse where the item selected in the **Inventory ID** box is stored. You select a specific warehouse if you want to view the components stored only in this warehouse.|
|**Item Class**|The item class for whose items you would like to view BOMs in the table.|
|**Show Active BOMs Only**|A check box that you select to view the active revisions of parent BOMs in the table.|

## Table { .section}

This table displays the list of BOMs that meet the selection criteria you have specified.

When a component is used in a subassembly, the table displays the immediate BOM with the component and the higher-level BOM containing the subassembly.

The settings shown in the table are copied from the [Bill of Material](AM_20_80_00.md) \(AM208000\) form and is read-only.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Inventory ID**|The inventory ID of the component.|
|**Subitem**|The subitem of the component.

 This column is visible only if the *Inventory Subitems* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

**Important:** The **Inventory Subitems** check box has been removed from the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form because the functionality associated with the *Inventory Subitems* feature will be phased out. If you have this feature enabled in your system, the associated functionality remains available. To disable the feature, contact your Acumatica support provider.

|
|**Level**|The level of the bill of material that is generated by the system. The level can be one of the following values:-   1: The immediate parent subassembly or assembly of the component
-   2 : The immediate parent of the level 1 assembly or subassembly

|
|**Parent Inventory ID**|The identifier of the parent item.|
|**Parent Subitem**|The subitem of the parent item.

 This column is visible only if the *Inventory Subitems* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

**Important:** The **Inventory Subitems** check box has been removed from the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form because the functionality associated with the *Inventory Subitems* feature will be phased out. If you have this feature enabled in your system, the associated functionality remains available. To disable the feature, contact your Acumatica support provider.

|
|**BOM ID**|The identifier of the parent BOM.|
|**Parent Item Class**|The item class of the parent inventory item.|
|**BOM Warehouse**|The warehouse specified for the parent bill of material.|
|**Revision Status**|The status of the parent BOM revision.|
|**Revision Start Date**|The start date of the parent BOM revision.|
|**Revision End Date**|The end date of the parent BOM revision.|
|**Warehouse**|The warehouse from which the component is issued.|
|**Effective Date**|The date when the system starts using the component for the item production. This date is independent of the start and end dates of the BOM.|
|**Expiration Date**|The date when the system stops using the component for the item production. This date is independent of the start and end dates of the BOM.|
|**Required Qty.**|The component quantity needed to produce the item. The system calculates the final quantity based on the combination of this value and the value of the **Batch Size** column.

 A negative quantity indicates that the row represents a by-product.

|
|**UOM**|The unit of measure for the component specified for the parent BOM. This does not have to be the base unit of measure of the component inventory item.|
|**Unit Cost**|The unit cost for the component.|
|**Item Class**|The item class to which the component belongs.|
|**Stock**|A check box that indicates \(if selected\) that the component is a stock item. If the check box is cleared, the component is a non-stock item.|
|**Source**|The replenishment source code of the component for the warehouse indicated for the component.|
|**Description**|The description of the stock item that represents the component.|
|**Parent Desc.**|The description of the inventory item from the parent BOM.|
|**Planned Cost**|The planned cost of the inventory item.|
|**Phantom Routing**|The way of adding operations of the component that is a phantom subassembly to production orders based on the BOM.|
|**Material Type**|The type of the component.|
|**Backflush Materials**|A check box that indicates \(if selected\) that the component is backflushed. When the check box is cleared, the components can be issued for the operation on the [Materials](AM_30_00_00.md) \(AM300000\) form before workers can record labor time or produced item quantities.|
|**Comp. BOM ID**|This column displays the **Comp BOM ID** value if the bill of material that is used to produce the component is a subassembly.|
|**Location**|The warehouse location from which the component is issued.|
|**Subcontract Source**|The source of the component.|
|**Comp. BOM Revision**|The revision of the BOM that is specified in the **Comp BOM ID** column.|
|**Scrap Factor**|The scrap or shrinkage factor for the component.|
|**Bubble Nbr.**|The number of the component on the engineering drawing that relates to the BOM.|
