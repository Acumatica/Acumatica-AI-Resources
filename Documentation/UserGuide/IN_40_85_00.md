# Item Conversion Log {#_e5023abf-0f34-493d-a244-be29afa63674 .reference}

Form ID: \(IN408500\)

On this form, you can review the details of each item conversion operation including the date of the conversion and the user who converted the item.

**Attention:** This form does not appear if at least one of the following features is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form: *Manufacturing*, *Projects*, *Time Management*, *Service Management*, *Payroll*.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table Toolbar {#2 .section}

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Inventory ID**|The inventory ID of the item which was converted.|
|**Description**|The description of the item which was converted.|
|**Converted To**|The current stock status of the item.|
|**User Name**|The login of the user who converted the item.|
|**Full Name**|The user who converted the item.|
|**Conversion Date and Time**|The date and time when the item was converted.|
|**Converted On**|The form on which the item was converted.|
