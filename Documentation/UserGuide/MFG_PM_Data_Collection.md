# Manufacturing Data Collection {#_41652f45-8364-46d4-8e97-9974bd0d0688 .concept}

Production transactions may be entered using hand held devices supporting the Acumatica mobile app similar to transactions for sale orders, purchasing, and inventory. The *Data Entry* rules specified for the production order types on the [Production Order Types](AM_20_11_00.md) \(AM201100\) form are enforced.

## Transactions Supported { .section}

The following transactions are available:

-   Scan materials on the [Scan Materials](AM_30_00_30.md) \(AM300030\) form
-   Scan moves on the [Scan Move](AM_30_20_10.md) \(AM302010\) form
-   Scan labor on the [Scan Labor](AM_30_20_20.md) \(AM302020\) form

## Setup and Configuration { .section}

The *Manufacturing Data Collection* feature is optional and must be enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You configure the default options for this feature on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form.

The User Settings on each transaction manage settings specific for the current working mode.

In addition, production employees can clock on and off production orders using the mobile version of the [Clock Entry](AM_31_50_00.md) \(AM102000\) form without having the *Manufacturing Data Collection* feature enabled.
