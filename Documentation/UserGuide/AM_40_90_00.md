# Production Orders by Build Capability

Form ID: \(AM409000\)

By using this form, you can review data on material availability in real time and make informed production planning decisions.

## Form Toolbar

The form toolbar has only standard buttons.

You can use the settings in this area to narrow the range of production orders listed in the table. The elements of this area are summarized below.

## Side Panel

By using the side panel, you can view information related to the production order.

The side panel has multiple tabs, each of which you can view by clicking the tab's icon. These tabs are described below.

|Tab|Description|
|---|-----------|
|**Critical Materials**|The [Critical Materials](AM_40_10_00.md) \(AM401000\) form, which displays the list of the materials of the current production order that are not available in stock. This tab enables you to create supply records for addressing material shortages.|
|**Production Tickets**|The [Production Ticket](AM_62_50_00.md) \(AM625000\) report, which you can use to print necessary documents for production orders being released into production.|
|**Production Order Maintenance**|The [Production Order Maintenance](AM_20_15_00.md) \(AM201500\) form, which displays information for the current production order. This tab provides quick access to additional production information for detailed review.|
