# Routes Closing {#_8c504a04-ae5a-4d4c-a8c9-8d980f1d5578 .reference}

Form ID: \(FS304010\)

On this form, you can view the details of a completed or closed route execution, close a route execution, or reopen it if needed.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Command|Description|
|-------|-----------|
|**Close**|Changes the route's status to *Closed*. This command is available only if the route has the *Completed* status.|
|**Unclose**|Changes the status of the route to *Completed* after a route has already been closed. This command is available only if the appointment has the *Closed* status.|

## Summary Area { .section}

In this area, you can select a route of the *Completed* or *Closed* status, view its details, and change the actual times of the route.

|Element|Description|
|-------|-----------|
|**Route Nbr.**|The reference number of the route execution.|
|**Status**|The status of the route, which can be one of the following: -   *Completed*: All route activities have been completed. You can edit route details, and close or reopen the route.
-   *Closed*: All route data has been finalized and verified. You can reopen the route, which changes its status to *Completed*.

|
|**Scheduled Start Date**|The date when the route is scheduled to be performed.|
|**Start Time**|The planned start time of the route. By default, this is the time specified in the route definition on the [Routes](FS_20_37_00.md) \(FS203700\) form.|
|**Actual Start Time**|The actual time when the route execution began.|
|**Actual End Time**|The actual time when the route execution ended.|
|**Branch**|The branch that performs the route.|
|**Route**|The selected route definition.|
|**Driver**|The driver assigned to perform the route.|
|**Vehicle**|The vehicle assigned to the route.|
|**Trip Nbr.**|The trip number for the selected route definition on the specified date.|
|**Actual Duration**|Read-only. The actual time taken to complete the route.|

## Appointments Tab { .section}

On this tab, you can view details of the appointments associated with the route.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Service Order Type**|The service order type of the appointment. Only appointments with service order types configured with the *Route* behavior appear here.|
|**Service Contract ID**|The identifier of the route service contract associated with the route.|
|**Customer Contract Nbr.**|he unique reference number of the service contract created for the customer. The system generates this number automatically when a new service contract is created.|
|**Schedule ID**|The identifier of the contract schedule used to generate the route.|
|**Appointment Nbr.**|The reference number of the appointment.|
|**Description**|A brief description of the appointment.|
|**Customer**|The customer for whom the appointment is performed.|
|**Customer Location**|The location of the customer where the appointment is performed.This box is available only if the *Business Account Locations* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Status**|The status of the appointment, which is one of the following: *Completed* or *Closed*.|
|**Scheduled Start Date**|The date on which the appointment is scheduled to take place.|
|**Scheduled Start Time**|The time the staff member is expected to begin the appointment.|
|**Scheduled End Time**|The time the staff member is expected to complete the appointment.|
|**Address Line 1**|The first line of the customer's address where the appointment is performed, typically including the street address.|
|**Address Line 2**|The second line of the customer's address, used for additional location details such as suite number, building, or floor.|
|**City**|The city where the customer's location for the appointment is situated.|
|**State**|The state or province where the appointment location is situated.|
|**Postal Code**|The postal code of the appointment location.|

## Additional Info Tab { .section}

On this tab, you can view additional information about the route execution.

|Element|Description|
|-------|-----------|
|**Miles**|The total distance \(in miles\) of the route execution.|
|**Weight**|The weight of the transferred goods.|
|**Fuel Qty.**|The amount of fuel used during the execution of the route.|
|**Fuel Type**|The type of the fuel used by the vehicle during the execution of the route, which is one of the following options:-   *Regular Unleaded*
-   *Premium Unleaded*
-   *Diesel*
-   *Other*

|
|**Oil**|The amount of oil used during the execution of the route.|
|**Antifreeze**|The amount of antifreeze used during the execution of the route.|
|**DEF**|The amount of diesel exhaust fluid used during the execution of the route.|
|**Propane**|The amount of propane used during the execution of the route.|
