# Scenarios {#_6f2af9e6-b381-42c1-9836-dbe5e7f78d16 .reference}

Form ID: \(WZ201000\)

The business process scenario is a plan of tasks to be executed to complete some complicated process in Acumatica ERP. To complete the process in the system, you need first to create a scenario and specify the general parameters for it, and then to add appropriate tasks to the scenario on the [Tasks](WZ_20_20_00.md) \(WZ202000\) form.

On this form, you can create a new scenario as well as manage existing scenarios. You can activate, suspend, or complete an existing scenario, or change its site map location and the access role.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Activate Scenario**|Activates the selected scenario. When you have activated a scenario, its status changes to *In Progress* and it becomes available to users for execution.

 You can activate scenarios that have the following statuses: *Pending*, *Suspended*, and *Completed*.

|
|**Suspend Scenario**|Suspends the execution of the selected scenario. When you have suspended a scenario, its status changes to *Suspended*. The statuses of its tasks remain the same and cannot be changed. A suspended scenario cannot be activated by running the schedule.

 You can suspend scenarios that have the following statuses: *Pending*, *In Progress*, and *Completed*.

|
|**Complete Scenario**|Completes the selected scenario by force. When a scenario is completed, its status changes to *Completed*. Its *Pending* tasks remain *Pending*; the *Open* and *In Progress* tasks change statuses to *Skipped*. Completed scenarios can be activated manually or by running the schedule. You can edit the settings of the completed scenarios. **Note:** The system also assigns a scenario the *Completed* status automatically when all the tasks of the scenario are completed.

You can complete scenarios that have the *In Progress* status only.

|

## Table {#1 .section}

The table contains the scenarios that you create in the system.

|Column|Description|
|------|-----------|
|**Scenario Name**|The name of the scenario. For a new scenario, enter any name that will help users to easily recognize the process to be completed by the scenario. This name will be displayed in the navigation pane when the scenario entry is saved.|
|**Status**|The execution status of the scenario, which is assigned by the system. It can be one of the following:-   *Pending*: The scenario has never been executed and is pending for activation. The system assigns this status to a newly created and saved scenario.
-   *In Progress*: The scenario is activated. The system assigns this status to a scenario after you have clicked the **Activate Scenario** button.
-   *Suspended*: The scenario is suspended. The system assigns this status to a scenario after you have clicked the **Suspend Scenario** button.
-   *Completed*: The scenario is completed. The system assigns this status to a scenario after you have clicked the **Complete Scenario** button. This status is also assigned to the scenario automatically when all the tasks of the scenario are completed.

|
|**Execution Date**|The date when the scenario was first activated. This date is filled in automatically by the system.|
|**Execution Period**|The financial period that corresponds to the execution date; this box is filled in automatically by the system. If the financial period is not active, the execution period box remains empty.|
|**Role Name**|The scenario access role. Only users granted with this role have an access to the scenario. If no role name is specified, the scenario is available to all users.|
|**Site Map Location**|The location of the scenario on the Acumatica ERP site map where it is available to users for execution.|
