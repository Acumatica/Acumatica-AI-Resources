# Sales Territories

Form ID: \(CS204100\)

On this form, you can create a new sales territory in which your organization has operations. You can also view, modify, or delete existing sales territories. In Acumatica ERP, a sales territory can consist of a state or a group of states of a country, or a country or a group of countries in which your organization conducts sales. The information provided on this form is used to define the sales territories of your organization, which can be assigned to leads, contacts, business accounts and opportunities during their creation or at a later time.

If the selected sales territory is specified in at least one record—such as a lead, contact, business account or opportunity—you cannot delete the sales territory. In this case, the system displays an error message if you try to delete it. If the sales territory is not selected in any record, you can delete it. In this case, the system also removes the sales territory from the [Countries/States](CS_20_40_00.md) \(CS204000\) form.

This form is available if the *Customer Management* and *Sales Territory Management* features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar has only standard buttons.

This area contains the summary settings of the sales territory. You can enter the settings of a new sales territory or select a sales territory by its ID to view or edit its information.

## Table

The contents of this table depend on the territory type selected in the Summary area:

-   If *By State* is selected in the **Territory Type** box, the system populates the table with the states of the country selected in the Summary area. For each listed state that you want to include in the sales territory, you select the unlabeled check box in its row before saving the sales territory. The states with this check box selected are displayed at the top of the list.
-   If *By Country* is selected in the **Territory Type** box, the system populates the table with the countries that have been defined in the system. For each listed country that you want to include in the sales territory, you select the unlabeled check box in its row before saving the sales territory. The countries with this check box selected are displayed at the top of the list.
-   If *Other* is selected in the **Territory Type** box, no table area is displayed.

Each state or country can be included in only one sales territory. If you select the unlabeled check box for at least one state or country that has been assigned to another sales territory and attempt to save the current sales territory, the system displays a confirmation dialog box. You can click one of the following buttons in the dialog box:

-   **Update**: The system assigns all selected states or countries to the sales territory. If any selected state or country has been assigned to another sales territory, the system reassigns it to the new sales territory, removes it from the previous sales territory, and updates the value in the **Territory Name** column and the **Sales Territory ID** column, if it is shown, of the row.
-   **Skip**: The system assigns to the sales territory only the selected states or countries that have not already been assigned to another sales territory. For the selected states or countries that have already been assigned to other sales territories, the unlabeled check box is cleared, and the **Territory Name** values and the **Sales Territory ID** values, if this column is shown, of the rows do not change.
-   **Cancel**: The system does not apply or save any changes.

The table toolbar has only standard buttons.
