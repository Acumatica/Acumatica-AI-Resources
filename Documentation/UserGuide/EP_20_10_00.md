# Positions {#_5cd7ab06-48f2-4418-b66b-3372d7f06e95 .reference}

Form ID: \(EP201000\)

On this form, you can add, view, edit, and delete positions available in your company.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Position Table { .section}

You use this table to add, view, edit, and delete positions and their descriptions.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Position ID**|The unique identifier for the position.|
|**Staff for Service Management**|A check box that indicates \(if selected\) that the employees with this position are staff members and can be assigned to perform services on the [Appointments](FS_30_02_00.md) \(FS300200\) and [Service Orders](FS_30_01_00.md) \(FS300100\) forms. This column is available only if the *Service Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. You can select this check box only if the *Unlimited Staff Member* pack is selected under the *Service Management* feature.

|
|**Description**|A detailed description of the position|
