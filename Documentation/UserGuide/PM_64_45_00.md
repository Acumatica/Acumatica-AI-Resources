# AIA Report with Quantity {#_e31a1f68-de3b-4c0e-86b1-459dadfa286b .reference}

Form ID: \(PM644500\)

**Important:** This report is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This report displays the printable version of the American Institute of Architects \(AIA\) report prepared for the projects that have the **Show Quantity in AIA Report** check box selected on the [Projects](PM_30_10_00.md) \(PM301000\) form. The report includes the AIA Document G702™–1992, Application and Certificate for Payment form, the G703™–1992, Continuation Sheet form, and the AR Invoices sheet. The continuation sheet lines are specified with the quantities.

You generate this report for a particular pro forma invoice from the **Invoices** tab of the [Projects](PM_30_10_00.md) form or from the [Pro Forma Invoices](PM_30_70_00.md) \(PM307000\) form. Based on the value of the **AIA Level** box specified in the corresponding project on the [Projects](PM_30_10_00.md) form, the lines in the continuation sheet are grouped by project tasks \(if *Summary* is selected in the **AIA Level** box\), or shown as they are presented in the corresponding pro forma invoice \(if *Detail* is selected\). For more information, see [Construction Reports: AIA Reports](Construction_Reports_AIA.md).

Depending on the date for which the AIA report is prepared, the report could include the retainage that has been fully or partially released in the middle of the project, or all released retainage at the end of the project. The invoice date of the original AR invoices and AR retainage invoices on the AR Invoices sheet is earlier than or the same as the invoice date of the pro forma invoice for which the AIA report is prepared. For more information, see [Construction Reports: AIA Reports for Released Retainage](Construction_Reports_AIA_Released_Retainage.md).
