# Deferred Revenue Reports {#_3a39cc44-7c30-4724-8334-c021de154ad7 .concept}

With the wide variety of Acumatica ERP reports on deferred revenue, you can view projections of revenue and expenses by period. If a report contains data links, you can easily drill down from the report to any supporting details.

**Note:** A report includes only the objects or entities that the user running the report is authorized to access, based on the user's roles and membership in restriction groups.

All deferred revenue reports can be generated in different formats, including PDFs, and can be printed or sent by email.

Each of the topics of this chapter provides reference information about a particular Acumatica ERP report, including details about the applicable report parameters you can use to select the exact data you want to view and analyze.
