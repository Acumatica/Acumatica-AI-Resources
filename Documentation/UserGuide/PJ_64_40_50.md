# Daily Field Report by Project Form {#_45e77634-4921-46cc-b078-81b393b4e19c .reference}

Form ID: \(PJ644050\)

This report lists daily field reports for the project and date you specify.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameter to select the information to be displayed on the report:

-   **Project**: The project for which the daily field report to be displayed. Select a project identifier for which you want to build the report.
-   **Date**: The date for which the daily field reports will be displayed. By default, the current date is selected.
-   **Include Completed DFRs Only**: A check box that indicates \(if selected\) that only completed daily field reports will be included in the report.
