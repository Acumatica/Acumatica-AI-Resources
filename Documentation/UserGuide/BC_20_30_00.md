# Attribute Mapping for Template Item Import

Form ID: \(BC203000\)

On this form, you define the rules for mapping Acumatica ERP attributes and their values to product variants and their values from an external ecommerce system. These mappings are used while creating template items during product import from the external system.

The system adds rows to the table on the form after product import is prepared from the external ecommerce system on the [Prepare Data](BC_50_10_00.md) \(BC501000\) form if the products to be imported have variants in the external system. The system deletes rows from the table on the form when the corresponding mappings are successfully used to create the template and matrix items.

**Important:** This form is available only if the *Retail Commerce* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**View Attributes**|Opens the [Attributes](CS_20_50_00.md) \(CS205000\) form in a pop-up window. You can use this form to review and update existing attributes and their values, as well as to create new attributes and values.|
|**Update Item Class**|Populates the **ERP Item Class** column in the table with the item class selected in the **Item Class to Assign** box in the Summary area for the rows with the check box selected in the Selected column.|

## Summary Area

In this area, you can select the item class to be assigned to the mappings shown in the table.

|Element|Description|
|-------|-----------|
|**Item Class to Assign**|The item class the system assigns to mappings shown in the table when you click **Update Item Class** on the form toolbar.|
