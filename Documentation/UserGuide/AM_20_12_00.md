# Inventory Planning Buckets {#_f99bce75-ff7b-4ba3-9e03-b35381719712 .reference}

Form ID: \(AM201200\)

**Attention:** This form is available only if the *Material Requirements Planning* or *Distribution Requirements Planning* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This form is used to define inventory planning *buckets* that correspond to periods of time for the [Inventory Planning Requirements by Item](AM_40_12_00.md) \(AM401200\) form. You can create as many buckets as needed, including past due, and each bucket can have a different interval, such as days, weeks, months, or years.

Inventory planning data, supply and demand, is aggregated for each bucket. You can define buckets consisting of one or more intervals. The start date of a bucket is the previous period's ending date. Negative values show periods in the past, and positive values show periods in the future.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area { .section}

You can create multiple bucket definitions.

|Element|Description|
|-------|-----------|
|**Bucket ID**|This is the name of the definition that can be selected for the inquiry.|
|**Active**|This indicates the status of the definition; only active definitions are available to selection by the inquiry|
|**Description**|The description of the bucket definition shown when selecting a definition.|

## Table { .section}

In this table, you can define the size and interval for each bucket.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Bucket**|An integer value used to sort the buckets for the inquiry as follows:-   A negative number indicates a period in the past. Zero or the negative number closest to zero starts from the previous day.

Suppose that buckets -3, -2, and -1 are created. In this case, -1 is the closest bucket to 0, so the -1 bucket will start from the previous day and extend into the past.

-   A positive number indicates a period in the future. The positive number closest to zero starts from today.

Suppose that buckets 1, 2, and 3 are created. In this case, 1 is the closest bucket to 0, so the 1 bucket will start from today and extend into the future.


|
|**Value**|The number of intervals for the bucket. For example, if the interval is a week, then this represents the number of weeks for this bucket.|
|**Interval**|A period of time, which may be one of the following options:-   *Day*
-   *Week*
-   *Month*
-   *Year*

|
