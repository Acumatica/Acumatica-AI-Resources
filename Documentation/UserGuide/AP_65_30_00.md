# 1099-MISC Form {#_8666d930-4030-402f-8e74-30489e315bae .reference}

Form ID: \(AP653000\)

**Attention:** This report is available only if the *1099 Reporting* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This report displays the 1099-MISC \(Miscellaneous\) form for the selected 1099 year.

If the amount in Box 9 exceeds the minimum reporting amount specified in the **Minimum Report Amount** box on the **1099 Settings** tab of the [Accounts Payable Preferences](AP_10_10_00.md) \(AP101000\) form, *X* is printed in Box 7 of the current form or in Box 2 of the [1099-NEC Form](AP_65_31_00.md) \(AP653100\) form, depending on the **Report Direct Sales On** option selected on the [Accounts Payable Preferences](AP_10_10_00.md) form. *X* indicates that the vendor has direct sales recorded within the 1099 year, with the total amount exceeding $5,000.

**Attention:** This report complies with the changes that IRS introduced in tax year 2022.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Company/Branch**: The company or branch for which you want to view information. You can select a company or make no selection to view information about all companies in the tenant.

    By default, the system inserts the company or branch selected on the Company and Branch Selection menu.

-   **1099 Year**: The 1099 year for which the 1099-MISC form will be displayed. Select the year from the list, which contains both open and closed 1099 years.
-   **Include**: The way the report will be generated with regard to non-employee compensation \(NEC\). Select one of the following options:
    -   *All Boxes* \(default\): The system generates the report for all vendors with all boxes displayed; the *NEC01* box amounts are not given special consideration.
    -   *Only Nonemployee Compensation*: The report will include only data from the *NEC01 Nonemployee Compensation* box \(and thus only vendors for which this box is filled in\). Even if multiple boxes are filled in for a vendor, if this option is selected, only the *NEC01* box amounts for the vendor will be shown in the report. You select this option to create a 1099-MISC filing for 2019 or any earlier year. For 2020 and any later year, the report will be empty.
    -   *Except Nonemployee Compensation*: The report will include the data from all boxes except the *NEC01 Nonemployee Compensation* box. If multiple boxes are filled in for a vendor and this option is selected, all these boxes except *NEC01* will be shown in the report. You select this option to create a 1099-MISC filing for 2019 or any earlier year. For 2020 and any later year, the report will be empty.
