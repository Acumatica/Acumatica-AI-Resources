# Shop Floor Kiosk: Operation Details and Resources {#_9d5535bf-488e-4853-b3f7-786cf0062a58 .concept}

The Shop Floor Kiosk provides access to operation-related instructions and supporting documents directly from the **Production Reporting** page. While you are working on an operation, you can review production steps, setup notes, drawings, PDFs, and other attached files without leaving the kiosk workflow. The kiosk displays this information in a read-only format to help you follow established production procedures and reference supporting documentation as needed.

## Viewing Operation Steps { .section}

The **Steps** tab of the **Production Reporting** page displays the operation instructions that are associated with the selected production order operation. These instructions are the same step records that are maintained in Acumatica ERP for the operation.

The **Steps** tab may include the following information for each step:

-   Step number
-   Step description
-   Instruction notes
-   File attachments related to the step

The steps are displayed in sequence order so that you can follow the required production process in the intended order. Notes entered for each step are displayed as read-only text.

To view operation steps:

1.  Open the **Production Reporting** page for an operation.
2.  Select the **Steps** tab.
3.  Review the listed steps and notes for the operation.
4.  If a step includes attached files, select the attachment to open it in the appropriate application.

The kiosk supports scrolling through all available steps and related content. Attached documents open in the appropriate viewer or application, depending on the file type. Supported file types may include PDFs, images, videos, Microsoft Office documents, and similar file formats.

**Attention:**

-   The **Steps** tab is always available on the **Production Reporting** page.
-   Step information is displayed in read-only mode.
-   Image thumbnails for step attachments are not supported.

## Viewing Attached Files and Documents { .section}

The **Files** tab of the **Production Reporting** page provides centralized access to files related to the selected production order operation. The kiosk combines attachments from multiple production records into a single file list so that you can quickly locate supporting documentation during production.

The **Files** tab can display attachments associated with:

-   The production order
-   The production order operation
-   Production materials
-   Operation steps
-   Operation tools

Files are displayed in alphabetical order and may include engineering drawings, work instructions, setup documents, inspection forms, and other supporting resources.

To view attached files:

1.  Open the **Production Reporting** page for an operation.
2.  Select the **Files** tab.
3.  Review the list of available files.
4.  Select a file name to open the attachment.

The **Files** tab displays the following details for each attachment:

-   File name
-   Source record
-   File creation date

You can use the search box to narrow the file list by entering part of the file name, extension, source, or date. The list updates automatically as you type.

The kiosk respects file access permissions defined in Acumatica ERP. If you do not have access to a file, the file is not displayed in the list.
