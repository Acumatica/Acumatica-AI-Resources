# Emails Pending Processing {#_7eef26bd-6efb-43fe-a70e-912f55942206 .reference}

Form ID: \(SM507000\)

You can use this form to perform manual processing of the incoming and outgoing emails that you select. By default, the system processes incoming emails based on the built-in functionality that assigns emails to employees by using information available in the subject, the **To** and **From** boxes, and the body of the email; for details, see [Incoming Mail Processing](EM__con_Mail_Processing.md). Also, by using this form, you can initiate repeated processing of outgoing emails with the *Failed* status.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Processes the emails you have selected for the selected email account.|
|**Process All**|Processes all the emails listed for the selected email account.|

## Selection Area { .section}

By using the elements in this area, you can define criteria to display only particular emails in the table.

|Element|Description|
|-------|-----------|
|**Account**|The system email account for which emails will be displayed. You can leave this box blank to view emails for all accounts.|
|**Assigned To**|A **Me** check box and unlabeled box, which you use as follows to select the user to whom the emails to be displayed are assigned: -   Select the **Me** check box to view the emails assigned to you. The box will contain your username.
-   Clear the **Me** check box and select another user to view the emails assigned to the user.
-   Leave the elements blank to view emails assigned to all users.

|
|**Type**|Select the type of emails to be displayed: *All*, *Incoming*, or *Outgoing*.|
|**Include Failed**|A check box that indicates \(if selected\) that the emails with the *Failed* status are also listed in the table. If the check box is cleared, only emails with the *Pending Processing* status can be processed on this form.|

## Table {#2 .section}

This table contains the list of emails that match the selection criteria you have specified in the Selection area.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Account Name**|The name of the system email account.|
|**Subject**|The subject or summary of the email.|
|**From**|The author of the email.|
|**To**|The recipient of the email.|
|**Start Date**|The date of the email.|
|**Owner**|The username of the employee to whom the email has been assigned.|
|**Email Status**|The status of the email, which can be *Pending Processing* or *Failed*.|
