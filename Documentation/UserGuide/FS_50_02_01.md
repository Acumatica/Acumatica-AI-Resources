# Clone Appointments {#_03d8660a-796b-4a90-9add-0ad5d7e2ed4d .reference}

Form ID: \(FS500201\)

On this form, you create new appointments based on the settings of the cloned appointment.

This form opens when you click **Clone Appointment** on the [Appointments](FS_30_02_00.md) \(FS300200\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the creation of a new appointment or multiple appointments based on the settings of the existing appointment.|

## Summary Area { .section}

|Element|Description|
|-------|-----------|
|**Service Order Type**|The service order type of the appointment being cloned.|
|**Appointment Nbr.**|The number of the appointment being cloned.|
|**Service Order Nbr.**|The number of the service order associated with the appointment being cloned.|
|**Customer**|The customer of the appointment being cloned.|
|**Location**|The location of the appointment being cloned.|
|**Branch Location**|The branch location of the appointment being cloned.|
|**Number of Appointments**|The number of appointments to be created:-   **Single**: An option button you select to create one copy of the original appointment.
-   **Multiple**: An option button you select to create multiple copies of the original appointment.

|
|**Date**|The date of the new appointment.

 This box is available if *Single* is selected in the **Cloning Type** section.

|
|**From Date**|The start date of the range for the new appointments.

 This box is available if *Multiple* is selected in the **Cloning Type** section.

|
|**To Date**|The end date of the range for the new appointments.

 This box is available if *Multiple* is selected in the **Cloning Type** section.

|
|Day of Week|Check boxes that you use to select the day or days of the week of the new appointments: **Sunday**, **Monday**, **Tuesday**, **Wednesday**,**Thursday**, **Friday**, and **Saturday**.

 These check boxes are available if *Multiple* is selected in the **Cloning Type** box.

|
|**Appointment Start Time**|The time when the new appointment is scheduled to start \(or the new appointments are scheduled to start\).|
|**Appointment Duration**|The scheduled duration of the new appointment \(or the new appointments\). By default, the scheduled duration of the new appointment is the same as the scheduled duration of the appointment to be cloned.|
|**Override**|A check box that you select to make the **Scheduled Duration** box available for editing. If this check box is selected, the scheduled end time of the created appointment is the start time plus the scheduled duration, and the **Handle Manually** check box is selected in the **Scheduled Date and Time** section of the [Appointments](FS_30_02_00.md) \(FS300200\) form. If this check box is cleared, the system copies the schedule duration from the original appointment and the **Handle Manually** check box inherits the state of this check box in the original appointment.|

The table displays the read-only settings of the appointments that have been cloned from the selected appointment.

|Column|Description|
|------|-----------|
|**Service Order Type**|The service order type of the new appointment.|
|**Service Order Nbr.**|The number of the service order associated with the new appointment.|
|**Appointment Nbr.**|The number of the new appointment.|
|**Scheduled Start Date**|The date when the appointment is planned to be attended.|
|**Scheduled Start Time**|The time when the new appointment is scheduled to start.|
|**Scheduled End Date**|The date when the new appointment is planned to be ended.|
|**Scheduled End Time**|The time when the new appointment is scheduled to end.|
|**Status**|The current status of the appointment.|
