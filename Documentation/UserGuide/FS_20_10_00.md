# Licenses {#_874fbbfb-a373-4787-b04c-959849ecb11c .reference}

Form ID: \(FS201000\)

You can use this form to enter a new license or view and modify an existing one. A license is a document proving that a particular person has permission to perform work of a certain kind or has a knowledge in a certain area.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area { .section}

You use the elements in this area to define a new license and its settings, or to select an existing license by its number and view its settings.

|Element|Description|
|-------|-----------|
|**License Nbr.**|The unique identifier assigned to the license based on the numbering sequence assigned to licenses in the **License Numbering Sequence** box on the [Service Management Preferences](FS_10_01_00.md) \(FS100100\) form|
|**License Type**|The unique identifier of the license type of license, which was defined on the [License Types](FS_20_09_00.md) \(FS200900\) form.|
|**Description**|A description of the license.|
|**Staff Member**|The staff member who owns the license.|
|**Issue Date**|The date when the license was issued.|
|**Expiration Date**|The date when the license will expire.

 This box is available only if the **Never Expires** check box is cleared.

|
|**Never Expires**|A check box that indicates \(if selected\) that the license does not have an expiration date.|
