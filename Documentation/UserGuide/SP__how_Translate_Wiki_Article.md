# To Create a Localized Version of a Wiki Article {#_83afd928-b0ca-4333-811c-58117c9418c9 .task}

For a newly added locale, all wiki articles will be displayed in the locale's base language until you create locale-specific versions of the articles. You can translate wiki articles to the languages defined in the system by using the [Wiki Editor Form for Articles](DM__con_Wiki_Wiki_Editor_Form_for_Articles.md).

## To Create a Localized Version of a Wiki Article { .section}

1.  Sign in to the portal with the locale, to which you want to translate a wiki article.
2.  Locate the article in the wiki, and click **Edit** on the wiki toolbar to open the article in the [Wiki Editor Form for Articles](DM__con_Wiki_Wiki_Editor_Form_for_Articles.md).
3.  Replace the article name in English with an article name in the locale language.
4.  Translate the article text into the locale language.
5.  Save the article.
