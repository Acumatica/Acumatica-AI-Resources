# Drawing Log Details {#_a78122f9-b2c4-46e6-869a-23acacfeb537 .reference}

Form ID: \(PJ653000\)

In this report, you can view the details of the drawing logs, which are grouped by project manager, project, and discipline. You can click a link in the report and view the drawing log on the [Drawing Log](PJ_30_30_00.md#) \(PJ303000\) form.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Project**: The project for which the drawing logs will be displayed. You can select the identifier of the project for which you want to run the report, or leave the box blank to view drawing logs for all projects.
-   **Project Manager**: The project manager for whom the drawing logs will be displayed. You can select the identifier of the employee for whom you want to run the report, or leave the box blank to view drawing logs for all project managers.
-   **Discipline**: The discipline for which the drawing logs will be displayed. You can select the discipline for which you want to run the report, or leave the box blank to view drawing logs for all disciplines.
-   **Show Latest Revisions Only**: A check box that indicates \(if selected\) that only up-to-date drawing logs will be listed in the report. That is, a drawing log will be listed if the **Latest Revision** check box is selected for the drawing log on the [Drawing Log](PJ_30_30_00.md#) \(PJ303000\) form. By default, this check box is selected.
