# Machine Capacity {#_7fe80371-c8e5-4513-946a-2c6d31bd4c9f .reference}

Form ID: \(AM406000\)

This form shows the capacity available and current load for machines.

**Important:** This form is only available when the *Advanced Planning and Scheduling* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area { .section}

|Element|Description|
|-------|-----------|
|**Machine ID**|Select a machine to view or leave this block blank to select all machines.|
|**Range**|Select the level of detail to display; the options are the following:-   *Daily:* Show the capacity for each working calendar day.
-   *Weekly:* Show the capacity for each week.
-   *BiWeekly:* Show the capacity in two week buckets.
-   *Monthly:* Show the capacity for each calendar month.

|
|**From Date**|Select the starting date; the default is the current business date.|
|**To Date**|Select the ending date; the default is the current business date plus 30 days.|

## Table { .section}

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Machine ID**|The list of machines. Only machines with orders scheduled are shown.|
|**Schedule Date**|The schedule date or range of dates.|
|**Total Blocks**|Available schedule blocks based on the block size set on the [Production Preferences](AM_10_20_00.md) \(AM102000\) form.|
|**Plan Blocks**|Total of both infinitely scheduled blocks.|
|**Scheduled Blocks**|Total of finitely scheduled blocks.|
|**Available Blocks**|**Total Blocks** minus **Scheduled Blocks**.|
|**Plan Utilization \(%\)**|The percentage of **Plan Blocks** of **Total Blocks**.|
|**Scheduled Utilization \(%\)**|The percentage of **Scheduled Blocks** of **Total Blocks**.|
|**From Date**|From the corresponding element in the Summary area. By default this column is not visible.|
|**To Date**|From the corresponding element in the Summary area. By default this column is not visible.|
