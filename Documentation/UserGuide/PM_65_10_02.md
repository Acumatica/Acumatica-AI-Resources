# Project AR Details {#_998fd899-163c-474f-97b4-3c4e14aaf148 .reference}

Form ID: \(PM651002\)

**Attention:** This generic inquiry form is available if the *Extended Financial Data Collection* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this generic inquiry form, you can view the AR amounts—such as unbilled amounts, paid amounts, and unreleased retainage—for each listed document line. The system calculates these values as of the date you specify; you can also select a project and vendor to view only their document lines.

You can use the form to verify the AR amounts the system has calculated on the [Project Cash Flow](PM_65_10_10.md) \(PM651010\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

In this area, you select the date through which the system shows document lines in the table. By specifying a particular project or vendor \(or both\), you can narrow the range of document lines listed in the table.

|Element|Description|
|-------|-----------|
|**Date**|The date through which the data is displayed—that is, you’ll see document lines up to and including this date. By default, the system inserts the current business date.|
|**Project**|The project for which you want to view the AR amounts.|
|**Customer**|The customer for which you want to view the AR amounts.|

## Table {#2 .section}

In the table, you can view the AR data for the selection criteria you’ve specified. You can use this information to verify the AR amounts that the system has calculated on the [Project Cash Flow](PM_65_10_10.md) \(PM651010\) form. Each row represents a document line.

Below you’ll find descriptions of the columns that show information about the listed documents, their currency rates, and their calculated values, along with calculation formulas the system uses.

**Attention:**

-   The leftmost columns of the table aren't described in this topic. These columns display the document's basic information—such as company, branch, project, project task, account group, and cost code. If you need information about these UI elements, see their descriptions on the document's data entry form.
-   The amounts are calculated in **the project currency**. The form shows values in the base, project, and document currencies if the *Multicurrency Accounting* and *Multicurrency Projects* features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Date**|The creation date of the document.|
|**Record Type**|The type of the record, which is:

 -   *AR Invoice* for a document created on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\)
-   *Payment* for a document created on the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form

|
|**Document Type**|The specific type of the document, which is copied from the **Type** box of the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) or [Payments and Applications](AR_30_20_00.md) \(AR302000\) form.|
|**Ref. Nbr.**|The reference number of the document created on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form or [Payments and Applications](AR_30_20_00.md) \(AR302000\) form.|
|**Line Nbr.**|The line number of the document.|
|**AR Document Type**|The type of the AR document, such as *Invoice*, *Debit Memo*, *Credit Memo*, *Overdue Charge*, *Credit WO*, or *Prepmt. Invoice*.|
|**AR Document Ref. Nbr.**|The reference number of the AR invoice.|
|**AR Document Line Nbr.**|The line number of the AR document.|
|**Base Currency**|The base currency used for accounting in the branch associated with the project specified in this document line.|
|**Document Currency**|The currency of the document.|
|**Customer**|The customer specified in the AR invoice or payment.|
|**Retainage Document**|A check box that indicates \(if selected\) that the AR invoice is a retainage document: an invoice or memo that releases the retainage amount withheld from the original invoice. The system copies the state of the check box from the AR invoice on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form.|
|**Rate \(Project Curr.\)**|The rate used to convert document amounts to the project currency.The system uses the applicable rate on one of these dates:

-   The creation date for an AR invoice on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form
-   The date of the original invoice for a retainage invoice, debit memo, or credit memo on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form
-   The payment date of a payment on the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form
-   The original payment date for a voided payment on the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form

|
|**Rate \(Base Curr.\)**|The rate used to convert document amounts to the base currency of the project.The system uses the applicable rate on one of these dates:

-   The creation date for an AR invoice on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form
-   The date of the original invoice for a retainage invoice, debit memo, and credit memo on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form
-   The payment date of a payment on the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form
-   The original payment date for a voided payment on the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form

|
|**AR Document Qty.**|The quantity specified in the line of the released AR invoice on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form:-   For an AR invoice of the *Invoice* or *Debit Memo* type, it’s the line quantity.
-   For an AR invoice of the *Credit Memo* type, it’s the quantity specified in the document line shown as a negative value.

|
|**UOM**|The unit of measure specified in the line of the invoice.|
|**Unit Price \(Project Curr.\)**|The price per UOM of the inventory item, which the system calculates by using this formula: `Extended Price (Project Curr.) / AR Document Qty.`**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Unit Price \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Extended Price**|The extended price specified in the line of the released AR invoice on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form:-   For an invoice of the *Invoice* or *Debit Memo* type, it’s the extended price specified in the document line.
-   For an invoice of the *Credit Memo* type, it’s the extended price specified in the document line shown as a negative value.

|
|**Extended Price \(Project Curr.\)**|The extended price specified in the line of the released AR invoice, which the system calculates by using this formula: `Extended Price * Rate (Project Curr.)`**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Extended Price \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Inclusive Taxes on AR \(Project Curr.\)**|The tax amount applied to the project's AR invoice, which the system proportionally spreads across the lines of the invoice with the tax category that requires this tax calculation.For a document of the *Credit Memo* type, the amount is shown as a negative value.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Inclusive Taxes on AR \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Exclusive Taxes on AR \(Project Curr.\)**|The tax amount on the amount of the AR, which the system calculates by using this formula: `(Amount Paid + Cash Discount Taken) * Billed Tax (Project Curr.) of each paid bill line / Amount of the paid bill`.-   `Amount Paid` and `Cash Discount Taken` are specified on the **Application History** tab of the document on the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form.
-   `Amount` is specified in the Summary area of the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Exclusive Taxes on AR \(Base Curr.\)** column. showing the value in the base currency. The system calculates it similarly.

|
|**AR Retained Amount \(Project Curr.\)**|The retainage amount specified in the AR invoice, which the system calculates by using one of these formulas depending on the type of the document:-   For an original invoice, `Retainage Amount * Rate (Project Curr.)`.

`Retainage Amount` is the amount of each line of the invoice.

-   For a credit memo, `Retainage Amount * Rate (Project Curr.) * (-1)`.
-   For a retainage credit memo, `Ext. Price * Rate (Project Curr.)`.

`Ext. Price` is the external cost of each line of the retainage debit adjustment.

-   For a retainage invoice with the **Pay by Line** check box selected on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form, `Ext. Price of each line * Rate (Project Curr.) * (-1)`.
-   For a retainage invoice with the **Pay by Line** check box cleared on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form, the extended price is applied to the lines of the original invoice proportionally to the retainage amount of each line and multiplied by the rate in the project currency and shown as a negative value.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **AR Retained Amount \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**AR Retained Taxes \(Project Curr.\)**|The retained tax amount applied to the project's AR invoice and credit memos, which the system proportionally spreads across the lines of the AR invoice.For a document of the *Credit Memo* type, the amount is shown as a negative value.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **AR Retained Taxes \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**AR Amount**|The amount specified in the lines of the released AR invoice, which the system calculates by using this formula: `AR Amount = SUM of Amount values + Inclusive Taxes on AR (Project Curr.)`.For a document of the *Credit Memo* type, the amount is shown as a negative value.

|
|**AR Amount \(Project Curr.\)**|The amount specified in the released AR invoice, which the system calculates by using this formula: `AR Amount / Rate (Project Curr.)`.If the project currency is the same as the document currency, this value is the same as the **AR Amount**.

If the project currency is the same as the document’s base currency, the system multiplies the **AR Amount** by the base currency rate specified on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **AR Amount \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**AR Paid Amount**|The paid amount specified in the AR invoice, which can be one of the following, depending on the state of the **Pay by Line** check box on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form:-   If that check box is selected: The amount specified on the **Application History** tab applied directly to the invoice line specified in the **Line Nbr.** column
-   If that check box is cleared: The amount specified on the **Application History** tab distributed among the original invoice lines in proportion to the **AR Amount**
-   For a payments on the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form whose currency differs from the invoice currency, the payment amount in the invoice currency

|
|**AR Paid Amount \(Project Curr.\)**|The paid amount specified in the AR invoice, which the system calculates by using this formula: `AR Paid Amount * Rate (Project Curr.)`.**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **AR Paid Amount \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**AR Cash Discount \(Project Curr.\)**|The AR cash discount, which can be either of the following, depending on the state of the **Pay by Line** check box on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form:-   If the check box is selected: The discount specified on the **Application History** tab of the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form applied directly to the invoice line specified in the **Line Nbr.** column and multiplied by the **Rate \(Project Curr.\)**
-   If the check box is cleared: The amount specified on the **Application History** tab of the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form distributed among the original invoice lines in proportion to the **AR Amount** and multiplied by the **Rate \(Project Curr.\)**

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **AR Cash Discount \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Write-Off Amount \(Project Curr.\)**|The write-off amount, which can be either of the following, depending on the state of the **Pay by Line** check box on the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form:-   If the check box is selected: The write-off amount specified on the **Application History** tab of the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form applied to the invoice line specified in the **Line Nbr.** column and multiplied by the **Rate \(Project Curr.\)**
-   If the check box is cleared: The write-off amount specified on the **Application History** tab of the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form distributed among the original invoice lines in proportion to the **AR Amount** and multiplied by the **Rate \(Project Curr.\)**

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Write-Off Amount \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Paid Inclusive Tax \(Project Curr.\)**|The paid inclusive tax amount, which the system calculates by using this formula: `(Amount Paid + Cash Discount Taken) * Inclusive Taxes on AR (Project Curr.) of each paid AR invoice line / Amount of the paid invoice`.-   `Amount Paid` and `Cash Discount` are specified on the **Application History** tab of the document on the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form.
-   `Amount` is specified in the Summary area of the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) form.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Paid Inclusive Tax \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Exclusive Taxes on Paid AR \(Project Curr.\)**|The tax amount on the paid amount of the invoice, which the system calculates by using this formula: `(Amount Paid + Cash Discount Taken) * Exclusive Taxes on AR (Project Curr.) of each paid invoice line / Amount of the paid invoice`.-   `Amount Paid` and `Cash Discount Taken` are specified on the **Application History** tab of the document on the [Payments and Applications](AR_30_20_00.md) \(AR302000\) form.
-   `Amount` is specified in the Summary area of the [Invoices and Memos](AR_30_10_00.md) \(AR301000\) \(AP301000\) form.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Exclusive Taxes on Paid AR \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.

|
|**Realized Gain/Loss \(Project Curr.\)**|The realized gain or loss, which the system calculates by using this formula: `AR Paid Amount * Rate (Project Curr.) on the original invoice's date - Rate (Project Curr.) on the payment date`.If the project currency is the same as the AR invoice's currency, the realized gain or loss is *0*.

If the project currency is the same as the AR invoice's base currency, the realized gain or loss is the same as the one specified in the GL transaction.

**Tip:** This value is calculated in the project currency. If multicurrency projects are set up in your system, you'll also see the **Realized Gain/Loss \(Base Curr.\)** column showing the value in the base currency. The system calculates it similarly.
