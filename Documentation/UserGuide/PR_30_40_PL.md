# Tax Form History {#_7330166b-c24b-4981-b3fa-6cd0a3eadc8f .reference}

Form ID: \(PR3040PL\)

By using this form, you can review existing batches for submission that have been generated through the [Prepare Tax Forms](PR_50_20_00.md) \(PR502000\) form.

This form appears only if the *Canadian Payroll* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

|Element|Description|
|-------|-----------|
|**Legal Entity For Payroll Tax Reporting**|The company or branch for which you want to view the batches.

 This box is available if the *Multicompany Support*, *Multibranch Support*, or both features are enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Year**|The year for which you want to view the batches.|
|**CRA Payroll Account Number**|The CRA payroll account number defined for companies or branches for which you want to view the batches.|

|Column|Description|
|------|-----------|
|**Batch ID**|The identifier of the batch for submission, which is also a link that you click to open the batch on the [Batch for Submission](PR_30_40_00.md) \(PR304000\) form.|
|**Form Name**|The name of the tax form.|
|**Document Type**|The type of the document, which can be *Original*, *Amendment*, or *Cancellation*.|
|**Year**|The year of the batch.|
|**Legal Entity for Payroll Tax Reporting**|The company or branch of the employees included in the batch.|
|**Number of Employees**|The number of employees included in the batch.|
|**Created On**|The date when the batch was created.|
