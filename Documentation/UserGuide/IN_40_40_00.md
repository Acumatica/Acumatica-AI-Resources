# Inventory Transaction Details {#_9597ff92-0419-4420-afa9-7f66a6d33f5c .reference}

Form ID: \(IN404000\)

**Attention:** This form is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

You can use this form to view summary information about inventory transactions posted within a selected financial period. You can set up criteria to display only specific data.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Allocation Details**|Navigates to the [Inventory Allocation Details](IN_40_20_00.md) \(IN402000\) form, where you can view how the inventory item from the inventory transaction is distributed among warehouses and warehouse locations.|
|**Inventory Summary**|Navigates to the [Inventory Summary](IN_40_10_00.md) \(IN401000\) form, where you can view the availability data of the inventory item.|

## Selection Area {#1 .section}

By using the elements in this area, you can view in the table the data that is most relevant to your information needs.

|Element|Description|
|-------|-----------|
|**Company/Branch**|The company, branch, or company group for which you want to view information. By default, the current company or branch is selected. You can select another branch, company, or company group to which you have access. This setting is required if the *Multiple Base Currencies* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

 This box appears only if the *Multiple Base Currencies* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Period**|The financial period for which you want to view inventory transactions.|
|**By Financial Period**|A check box that you select to display the inventory transactions by financial period, and to display the running values \(**Beginning Quantity**, **Ending Quantity**, **Beginning Balance**, and **Ending Balance**\) in the table. If the check box is cleared, the inventory transactions will be selected by the date range in the specified financial period and the running values will not be displayed.|
|**Warehouse**|The warehouse for which you want to view inventory transactions.

 This box appears only if the *Multiple Warehouses* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Inventory ID**|The inventory item for which you want to view inventory transactions.|
|**Subitem**|The subitem of the inventory item for which you want to view inventory transactions.

 This box is available only if the *Inventory Subitems* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 **Important:** The **Inventory Subitems** check box has been removed from the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form because the functionality associated with the *Inventory Subitems* feature will be phased out. If you have this feature enabled in your system, the associated functionality remains available. To disable the feature, contact your Acumatica support provider.

|
|**Date Range**|The earliest and latest dates of the records to be displayed.

 These dates are available for editing only if the **By Financial Period** check box is cleared.

|
|**Period Date Range**|The read-only start and end dates of the date range for the selected financial period.|
|**Summary by Day**|A check box that you select to view only summary values for each day in the specified period. Clear this check box to display detailed information for each day within the specified period.|
|**Include Unreleased \(Without Costs\)**|A check box that you select to view unreleased transactions along with posted transactions. All types of transactions will be displayed without costs.|

## Table {#2 .section}

This table displays the details of inventory transactions that meet the criteria you've specified in the Selection area.

Values for columns marked with `[*]` are calculated based on the estimated per-unit cost, which depends on the valuation method selected for the inventory item. For details about valuation methods and per-unit costs, see [Item Costs and Valuation Methods: General Information](Item_Costs_Valuation_Methods_GeneralInfo.md).

|Column|Description|
|------|-----------|
|**Inventory ID**|The inventory item for which the transaction information is shown.|
|**Date**|The date when the inventory transaction was performed.|
|**Tran. Type**|The inventory transaction type, which can be one of the following: *Receipt*, *Issue*, *Transfer*, or *Adjustment* for transactions originating in the Inventory module; or *Invoice*, *Credit Memo*, or *Return* for transactions originating in another system module.|
|**Reference Nbr.**|The reference number of the transaction.|
|**Subitem**|The subitem that applies to the transaction.

 This column appears only if the *Inventory Subitems* feature is enabled in your system on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

 **Important:** The **Inventory Subitems** check box has been removed from the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form because the functionality associated with the *Inventory Subitems* feature will be phased out. If you have this feature enabled in your system, the associated functionality remains available. To disable the feature, contact your Acumatica support provider.

|
|**Warehouse**|The warehouse where the inventory transaction was performed.

 This column appears only if the *Multiple Warehouses* feature is enabled in your system on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Location**|The location where the inventory transaction was performed.

 This column is available only if the *Multiple Warehouse Locations* feature is enabled in your system on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Lot/Serial Number**|The lot or serial number involved in the inventory transaction.

 This column appears only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Fin. Period**|The financial period to which the transaction was posted.|
|**Tran. Period**|The financial period in which the transaction was created.|
|**Released**|A check box that, if selected, indicates that the transaction was released.|
|**Release Date**|The date on which the transaction was posted.|
|**Beginning Qty.**|The quantity of the inventory item in the beginning of the selected period.|
|**Qty. In**|The quantity of the inventory item accepted at the warehouse within the selected period.|
|**Qty. Out**|The quantity of the inventory item removed from the warehouse within the selected period.|
|**Ending Qty.**|The quantity of the inventory item at the end of the selected period.|
|**Beginning Balance \[\*\]**|The inventory balance in the beginning of the selected period.|
|**Cost In \[\*\]**|The cost of the inventory items accepted at the warehouse within the selected period.|
|**Cost Out \[\*\]**|The cost of the inventory items removed from the warehouse within the selected period.|
|**Ending Balance \[\*\]**|The inventory balance at the end of the selected period.|
|**In/Out Unit Cost \[\*\]**|The cost per base unit of the item in the inventory transaction.|
|**SO Order Type**|The type of the sales order involved.|
|**SO Order Nbr.**|The reference number of the sales order involved.|
|**PO Receipt Nbr.**|The reference number of the purchase order involved.|
