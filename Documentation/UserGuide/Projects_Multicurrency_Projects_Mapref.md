# Managing Multicurrency Projects {#_09216420-efbb-4123-80df-a32ea52ec84c .concept}

In Acumatica ERP, you can track projects in the project currency, which can differ from the base currency of the company that manages the project. You can review project costs and revenues both in the project currency and in the base currency. This chapter describes how to configure and manage projects in different currencies.
