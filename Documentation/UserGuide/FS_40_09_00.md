# Service Classes

Form ID: \(FS400900\)

On this form, you can view the service classes entered into the system and the related billing rules. From this form, you can navigate to the [Item Classes](IN_20_10_00.md#) \(IN201000\) form to create a new service class or change the settings of an existing class.

## Form Toolbar

The form toolbar includes only standard buttons.

## Table

|Column|Description|
|------|-----------|
|**Class ID**|The unique identifier of the service class; you can click this link to navigate to the [Item Classes](IN_20_10_00.md#) form, where you can view the settings of the class.|
|**Default Billing Rule**|The default billing rule used for the service, which can be *Time*, *Flat Rate*, or *None*.|
|**Route Service**|A check box that indicates \(if selected\) that the service is used for route management.|
