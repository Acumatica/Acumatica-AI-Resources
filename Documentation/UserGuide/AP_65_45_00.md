# 1099 Year Details {#_4d18c0bc-a7d1-49ce-be22-f8c741d2e547 .reference}

Form ID: \(AP654500\)

**Attention:** This report is available only if the *1099 Reporting* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This report displays the list of all 1099 vendors and the related payment documents for each. For each vendor, the report shows the amounts paid for the AP bill lines that have the 1099 box specified.

The report includes payments based on their payment dates, not on the dates of the related AP bills. For example, if a bill is created on January 3, 2025 and the payment for the bill is dated December 31, 2024, the report will include the payment amount in the 2024 year.

**Tip:** The **Payment Date** column of the report shows the date when the listed bill was paid. That is, the report displays the **Payment Date** of the payment, which is displayed in the **Payment Date** box on the **Financial** tab of the [Checks and Payments](AP_30_20_00.md) \(AP302000\) form.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Company/Branch**: The company or branch for which you want to view information. You can select a company or make no selection to view information about all companies in the tenant.

    By default, the system inserts the company or branch selected on the Company and Branch Selection menu.

-   **1099 Year**: The 1099 year for which information will be displayed. You must select a year from the list, which contains both open and closed 1099 years.
