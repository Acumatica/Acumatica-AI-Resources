# Expiring Customer Contracts {#_0c79b8cd-646b-43ee-8660-2f36fccd6768 .reference}

Form ID: \(CT401000\)

On this form, you can view contracts that will expire soon, as well as auto-renewable contracts \(those that have the **Mass Renewal** check box selected\). Contracts may be selected by customer class, contract template, and expiration period.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

You use the elements in this area to specify the criteria for selecting contracts.

|Element|Description|
|-------|-----------|
|**Expiration Date Range**|The start and the end date of the date range for which you want to display contracts.|
|**Show Contracts Available for Mass Renewal**|A check box that you select to include the auto-renewable contracts that will expire during the specified date range. This check box is selected by default.|
|**Customer Class**|The class of the customers with similar settings. Leave the box blank to show information on all classes.

 The list of classes may be limited based on the roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. With the feature enabled, the **Restrict Visibility To** box appears on the **General** tab of the [Customer Classes](../Shared/../UserGuide/AR_20_10_00.md) \(AR201000\) form. You can select a customer class if one of the following is true:

-   The **Restrict Visibility To** box is empty for the customer class—that is, the visibility of the customer class is not restricted.
-   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer class, and your user account is assigned to the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.

|
|**Contract Template**|A contract template used for contracts with similar settings. Leave the box blank to show information on all templates.|

## Table {#2 .section}

This table contains the list of contracts matching the criteria set in the Selection area. You can select a contract and view its details.

|Column|Description|
|------|-----------|
|**Contract ID**|The unique alphanumeric identifier of the contract.|
|**Description**|A description of the contract.|
|**Contract Template**|The template used for the contract.|
|**Contract Type**|The type of contract.|
|**Customer**|The customer associated with the contract, by ID.|
|**Customer Name**|The name of the customer.|
|**Status**|The status of the contract, which can be *Draft*, *Pending Approval*, *Active*, *Expired*, *Canceled*, *Pending Upgrade*, or *Pending Activation*.|
|**Setup Date**|The date of the contract setup.|
|**Expiration Date**|The date when the contract expires.|
|**Mass Renewal**|A check box that indicates \(if selected\) that the contract is available for mass processing and is to be displayed on the [Renew Contracts](CT_50_20_00.md) \(CT502000\) form.|
|**Last Billing Date**|The date of the most recent billing for the contract.|
|**Next Billing Date**|The date of the next billing for the contract.|
