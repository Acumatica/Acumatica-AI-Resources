# Substitution Lists {#_e1b0125f-cb2f-4451-91af-c5eeaff3b5ac .reference}

Form ID: \(SM206026\)

You use this form to view, add, remove, and edit substitution lists. A substitution list consists of pairs of source values \(which may be found in the data prepared for import or export\) and the corresponding substitution values \(which serve as replacements for the source values during data import to Acumatica ERP or data export from Acumatica ERP, respectively\). For example, suppose that the data for import contains country codes that are different from the country codes registered in Acumatica ERP. You can add a substitution list that defines the correspondence between the country codes in the data and the country codes registered in Acumatica ERP.

You can use the substitution lists in the `SubstituteListed (sourceField, substitutionList)` and `SubstituteAll (sourceField, substitutionList)` functions in formulas in mappings of import and export scenarios. For details about the functions, see [Functions](../Shared/../UserGuide/IS__con_IS_Functions.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area { .section}

In this area, you can enter the name of a new substitution list or select the name of an existing one to edit the list.

|Element|Description|
|-------|-----------|
|**Substitution List**|Required. The name of the substitution list.|
|**Table Name**|The name of the table where a field for the substitution value is located.|
|**Field Name**|The name of the field whose values should be used as substitution values.|

## Table Toolbar { .section}

The table toolbar has only standard buttons.

## Table Columns { .section}

|Column|Description|
|------|-----------|
|**Original Value**|The value that you want to replace in the data prepared for import or export.|
|**Substitution Value**|The value that replaces the value specified in the **Original Value** box.|
