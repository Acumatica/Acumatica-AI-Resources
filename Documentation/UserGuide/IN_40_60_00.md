# Inventory Transaction Summary

Form ID: \(IN406000\)

**Attention:** This form is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

You use this form to check the inventory balance for the selected financial period and to view summary information about inventory transactions posted within this period. You can use selection criteria to display only particular data.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Transaction Details**|Navigates to the [Inventory Transaction Details](IN_40_40_00.md) \(IN404000\) form, where you can view summary information about the inventory transaction.|
|**Inventory Summary**|Navigates to the [Inventory Summary](IN_40_10_00.md) \(IN401000\) form, where you can view the availability data of the inventory item.|
|**Allocation Details**|Navigates to the [Inventory Allocation Details](IN_40_20_00.md) \(IN402000\) form, where you can view how the inventory item from the inventory transaction is distributed among warehouses and warehouse locations.|

## Table

This table displays the transaction summary data by using the criteria you have specified in the Selection area.

|Button|Description|
|------|-----------|
|**Inventory Item**|Navigates to the [Stock Items](IN_20_25_00.md) \(IN202500\) form to display information about the selected inventory item.|
|**Summary**|Navigates to the [Inventory Summary](IN_40_10_00.md) \(IN401000\) form to display the availability data of the inventory item.|
|**Allocation Details**|Navigates to the [Inventory Allocation Details](IN_40_20_00.md) \(IN402000\) form to display information about the allocation of the selected inventory item at the specific warehouse.|
|**Inventory Transaction Details**|Navigates to the [Inventory Transaction Details](IN_40_40_00.md) \(IN404000\) form to display detailed transaction data for the selected inventory item.|
