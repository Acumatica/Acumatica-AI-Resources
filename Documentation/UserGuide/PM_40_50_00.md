# Project Financial Vision

Form ID: \(PM405000\)

**Important:** This form is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can analyze project expenses and revenues and investigate the financial performance of the project in the specified date range. The form shows aggregated project transactions broken down by the selected time period—year, quarter, month, or day—and grouped by the criteria that you specify in the Selection area.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**View Transactions**|Opens the [Project Transaction Details](PM_40_10_00.md) \(PM401000\) form. This form shows the list of project transactions that correspond to the selected row.|
|**Zoom In**|Switches the period of data aggregation to shorter time period, refining the data scope in the table to a finer granularity.|
|**Zoom Out**|Switches the period of data aggregation to a broader time period, expanding the data scope in the table to a higher-level view.|
|**Show Chart**|Opens the **Chart** dialog box, which shows a graphical representation of the cumulative project costs or revenues over the date range being analyzed.|
