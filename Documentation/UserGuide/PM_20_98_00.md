# Workers' Compensation Codes {#_3bcc9979-ef23-4331-9085-babe1111edc8 .reference}

Form ID: \(PM209800\)

You use this form to define the workers' compensation codes. You can add workers' compensation codes manually or upload a list of workers' compensation codes from an Excel file.

This form is available if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Codes Pane { .section}

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates \(if selected\) that the workers' compensation code is available for selection on entry forms. If the check box is cleared, the workers' compensation code is inactive and is unavailable for selection on any data entry form.|
|**WCC Code**|The unique identifier of the workers' compensation code.|
|**Description**|A brief description of the workers' compensation code.|

## Sources Pane { .section}

By using this pane, you can specify the sources for the workers' compensation codes that the system inserts by default when a time activity is created.

|Column|Description|
|------|-----------|
|**Project**|The project to be used as the source of the default WCC code. If a project is selected but no specific project task is specified in the next column, the system will use the WCC code from the project for all project tasks related to that project.|
|**Project Task**|The project task to be used as the source of the default WCC code.|

|Column|Description|
|------|-----------|
|**Labor Item**|The labor item to be used as the source of the default WCC code.|

|Column|Description|
|------|-----------|
|**Cost Code From**|The starting cost code of the range of cost codes to which the workers' compensation code is applicable.|
|**Cost Code To**|The last cost code of the range of cost codes to which the workers' compensation code is applicable.|
