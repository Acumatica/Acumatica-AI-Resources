# Automation Schedule Statuses

Form ID: \(SM205030\)

On this form, you can view all active automation schedules available in the system, with information about their execution dates and start and end times.

## Table

The table displays all the schedules that are active in the system.

<table id="table_jn5_hjs_gj"><thead><tr><th>

Button

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**View Screen**

</td><td>

Opens the form that is the object of automation.

 This button is shown if the selected automation schedule is associated with any screen.

</td></tr><tr><td>

**View History**

</td><td>

Opens the [Automation Schedule History](SM_20_50_35.md) \(SM205035\) form with the history of the selected scheduler.

</td></tr><tr><td>

**Initialize Scheduler**

</td><td>

Activates schedulers after you have uploaded a database backup from another site on your Acumatica ERP site. When you back up a database on one site and upload it to another site, all schedulers are automatically deactivated on the site where you upload the backup. Therefore, you need to activate them by clicking this button.

 This button appears only if your Acumatica ERP database has been restored from a backup taken on another site.

</td></tr></tbody>
</table>

|Column|Description|
|------|-----------|
|**Status**|The status of the latest execution of the automation schedule.|
|**Schedule ID**|The description of the schedule. You can click the description to open the corresponding automation schedule on the [Automation Schedules](SM_20_50_20.md) \(SM205020\) form.|
|**Screen ID**|The screen ID of the form that has an automation schedule assigned.|
|**Active**|A check box that indicates \(if selected\) that the schedule is active.|
|**Starts On**|The start date of the schedule.|
|**Expires On**|The date when the schedule expires.|
|**Time Zone**|The time zone in which the schedule operates.|
|**Last Executed**|The most recent date when the schedule has been executed.|
|**Last Execution Result**|The message describing the result of the last execution.|
|**Next Execution Date**|The date of the next execution of the schedule.|
