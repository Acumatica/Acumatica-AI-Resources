# Selling an Optional Component of Target Equipment {#_af78b44c-ba28-4e23-afc9-5c4347c16acd .concept}

In Acumatica ERP, you can process an appointment to provide the installation of optional components to existing equipment at a customer's site, along with installation services. To do this, you will specify the *Selling Optional Component* equipment-related action for the selected stock item in an appointment created on the [Appointments](FS_30_02_00.md) \(FS300200\) form.
