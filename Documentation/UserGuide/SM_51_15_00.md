# Collect Translation Sets {#_b94db5dc-bf84-4f7c-a8b8-c32d2d47f5bc .reference}

Form ID: \(SM511500\)

By using this form, you can collect strings from all existing translation sets or only the sets you select. For more information on translation sets, see [Translation Process](SM__con_Translation_Process.md).

Additionally, by using the [Automation Schedules](SM_20_50_20.md) \(SM205020\) form, you can schedule the process of collecting the strings of a particular set \(or particular sets\) to be performed automatically. Thus, the collection of new strings for the set \(or sets\) will be performed automatically according to your schedule. For more information about automation schedules, see [Automated Processing: General Information](SA_Scheduling_Automated_Processing_GeneralInfo.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Collect**|Runs the process of collecting the strings for the translation sets selected in the table.|
|**Collect All**|Runs the process of collecting the strings for all translation sets listed in the table.|

## Table { .section}

The table lists all the translation sets created in the system. For each set, you can also see the details of the last successful run of the collection process \(if applicable\).

|Button|Description|
|------|-----------|
|**View Translation Set**|Opens the [Translation Sets](SM_21_15_00.md) \(SM211500\) form with the selected translation set open.|

|Column|Description|
|------|-----------|
|**Selected**|A check box that includes \(if selected\) this translation set in the string collection process if you click **Collect** on the form toolbar. Clear the check box to exclude the set from the collection process if you click **Collect**.|
|**Name**|The name of the translation set.|
|**Is Collected**|A read-only check box that indicates \(if selected\) that all strings associated with the system resources included in the selected translation set were collected.|
|**System Version**|The version of the system in which the translation set was collected most recently.|
|**System Time**|The date and the time when the string collection was performed most recently.|
