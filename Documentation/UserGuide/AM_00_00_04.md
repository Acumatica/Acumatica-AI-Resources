# MPS Listing

Form ID: \(AM000004\)

**Note:** This form is available only if the *Material Requirements Planning* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

MPS orders are created by using the [Master Production Schedule](AM_20_10_00.md) \(AM201000\) form.

## Form Toolbar

The form toolbar has only standard buttons.

## Selection Area

In this area, you can specify the criteria for MPS orders to be displayed in the table below.

|Element|Description|
|-------|-----------|
|**Inventory ID**|Select a specific inventory item or leave blank to list all.|
|**Warehouse**|Select a specific warehouse or leave blank to list all.|
|**Type**|The default is from MRP preferences. You can select a different type or clear the field to select all.|
