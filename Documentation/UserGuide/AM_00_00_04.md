# MPS Listing {#_89ebde1a-8557-4d87-9130-0313307ec80b .reference}

Form ID: \(AM000004\)

**Note:** This form is available only if the *Material Requirements Planning* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

MPS orders are created by using the [Master Production Schedule](AM_20_10_00.md) \(AM201000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

In this area, you can specify the criteria for MPS orders to be displayed in the table below.

|Element|Description|
|-------|-----------|
|**Inventory ID**|Select a specific inventory item or leave blank to list all.|
|**Warehouse**|Select a specific warehouse or leave blank to list all.|
|**Type**|The default is from MRP preferences. You can select a different type or clear the field to select all.|

## Table { .section}

|Column|Description|
|------|-----------|
|**Inventory ID**|The inventory ID for this MPS order.|
|**Description**|Description of the inventory item.|
|**Active**|Indicates if the MPS order is active; only active MPS orders are used in MRP.|
|**Plan Date**|The date the MPS order is expected to be completed.|
|**Warehouse**|The warehouse for this MPS order.|
|**Quantity**|The quantity to produce for this MPS order.|
|**UOM**|The unit of measure for the value specified in the **Quantity** box.|
|**Type**|The MPS type for this order.|
|**Branch**|The branch with which the MPS order is associated.

 This column is displayed only when the *Multibranch Support* feature or the *Multicompany Support* feature is enabled \(or both features are enabled\) on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.
