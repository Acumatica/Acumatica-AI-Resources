# Administering Dashboards {#_324b9ad1-6481-4633-8d45-f520f054dfe7 .concept}

In Acumatica ERP, a dashboard is a form to which you can add a collection of widgets that give you needed information at a glance.

To be able to manage dashboards, your user account must be designed a role with full access rights to the [Dashboards](SM_20_86_10.md) \(SM208610\) or [Classic Dashboards](SM_20_86_00.md) \(SM208600\) forms. By default, the built-in *Administrator* role provides the access rights for working with dashboards.

In this part of the guide, you will learn how to create a dashboard and how to configure access rights to dashboards.
