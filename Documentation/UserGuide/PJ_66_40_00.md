# RFIs Outstanding {#_2e67369e-008a-4ab7-8774-5f4ac9f5cfb7 .reference}

Form ID: \(PJ664000\)

This report displays the list of outstanding requests for information. You can filter the report by the project, status, and reason.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Project**: The project for which the report to be displayed. You can select a project identifier for which you want to build the report, or leave this box empty to view the report for all projects.
-   **Status**: The status for which the report to be displayed. You can select a status for which you want to build the report, or leave this box empty to view the report for all statuses.
-   **Reason**: The reason of the request for information for which the report to be displayed. You can select a reason for which you want to build the report, or leave this box empty to view the report for all reasons.
