# Route Inquiry {#_283166f6-f271-4c4e-a600-d7085023d50a .reference}

Form ID: \(FS404100\)

On this form, you can see the route executions defined in the system and their details.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

In this area, you can specify the criteria that is used to filter the routes displayed in the table.

|Element|Description|
|-------|-----------|
|**Route ID**|The route definition for which you want to view data. You can leave this box empty to view the data for all route definitions.|
|**From**|The start date of the date range for which you want to view the generated routes. You can leave this box blank to view the routes generated from the first date when routes were generated.|
|**To**|The end date of the date range for which you want to view the generated routes. You can leave this box blank to view the routes generated until the last date when routes were generated.|

|Element|Description|
|-------|-----------|
|**Open**|A check box that indicates \(if selected\) that routes with the *Open* status are displayed in the table.|
|**In Process**|A check box that indicates \(if selected\) that routes with the *In Process* status are displayed in the table.|
|**Canceled**|A check box that indicates \(if selected\) that routes with the *Canceled* status are displayed in the table.|
|**Completed**|A check box that indicates \(if selected\) that routes with the *Completed* status are displayed in the table.|
|**Closed**|A check box that indicates \(if selected\) that routes with the *Closed* status are displayed in the table.|

## Table { .section}

In this table, you can view the list of routes that meet the criteria you have selected.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Route Nbr.**|The reference number of the route. You can click the link in this column to navigate to the [Route Document Details](FS_30_40_00.md) \(FS304000\) form, on which you can view and edit details of the route.|
|**Route**|The identifier of the route definition. You can click the link in this column to navigate to the [Routes](FS_20_37_00.md) \(FS203700\) form. on which you can view and edit details of the route definition.|
|**Trip Nbr.**|The number of the trip for the route definition on the date when the route was performed.|
|**Status**|The status of the route.|
|**Scheduled Start Date**|The date when the route was performed.|
|**Start Time**|The start time of the route.|
|**Driver**|The driver that executed the route.|
|**Additional Driver**|The second driver that executed the route.|
|**Vehicle**|The assigned vehicle that was used to execute the route.|
|**Additional Vehicle 1**|The second assigned vehicle that was used to execute the route.|
|**Additional Vehicle 2**|The third assigned vehicle that was used to execute the route.|
|**Number of Appointments**|The number of appointments in the route.|
|**Total Services**|The total number of services performed during the appointments of the route.|
|**Total Route Duration**|The total estimated time needed to perform the route. This is the sum of the duration times of the driving and the services.|
|**Total Services Duration**|The total estimated time needed to perform the services of the route.|
|**Total Driving Duration**|The total estimated driving time needed to perform the route.|
