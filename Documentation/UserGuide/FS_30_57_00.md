# Service Contracts {#_11932f17-56fe-4a4e-8b66-e839bb21f402 .reference}

Form ID: \(FS305700\)

On this form, you can create new service contracts and view or edit the details of existing ones. For each service contract, you must specify the customer, billing settings, and create a schedule outlining when services are required. You will also define the services to be provided, any inventory items to be sold as part of each service order \(if applicable\), and the pricing for the included services and inventory items.

## Summary Area { .section}

This area contains general information about the contract, such as the customer, customer location, branch, branch location, and status.

|Element|Description|
|-------|-----------|
|**Service Contact ID**|The identifier of the contract; the system generates this identifier by using the numbering sequence specified in the **Service Contract Numbering Sequence** on the [Equipment Management Preferences](../Shared/../UserGuide/FS_10_03_00.md) \(FS100300\) form.|
|**Status**|Read-only. The status of the service contract, which the system sets to one of the following: -   *Draft*: The contract is a draft and has not yet been activated, so you cannot generate service orders, appointments, and invoices for the contract. You can activate or delete a contract with this initial status.
-   *Active*: The contract is active in the system, so you can generate service orders, appointments, and invoices for the contract. You can suspend or cancel a contract with this status.

The contract is assigned this status when the **Activate Contract** action is invoked on this form.

-   *Suspended*: The contract is on hold and can be activated at any time. You cannot generate service orders, appointments, or invoices for a contract with this status. You can activate or cancel a contract with this status.

The contract is assigned this status when the **Suspend Contract**action is invoked on this form.

-   *Canceled*: The contract has been terminated and cannot be reactivated on this form; it is read-only. You cannot generate service orders and appointments from a canceled contract.

The contract was canceled when the **Cancel Contract**action was invoked on this form.

-   *Expired*: The expiration date specified for the contract has passed, and no further activities for the contract can be performed.

|

|**Upcoming Status**|Read-only. The status that the contract will have after the date specified in the **Effective Until Date** box.|
|**Effective Until Date**|Read-only. The date until which the current status of the contract is effective in the system.|
|**Customer Contract Nbr.**|Read-only. The reference number of the service contract for the particular customer. The system automatically generates this number for each customer independently of its generation of the number for other customers. Thus, multiple customers can have service contracts with the same customer contract number, such as *00001*.|

 The list of values is limited based on the current user's access role. You can select a customer whose visibility is not restricted for the branch or company to which the user's role is assigned \(the **Restrict Visibility To** box on the **General Info** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form contains this company or branch, or is empty\).

|
|**Location**|The unique identifier of the customer location associated with the contract.This box appears on the form only if the *Business Account Locations* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

|
|**Project**|The project to which this service contract is related.

 This box appears on the form only if the *Projects* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) form.

|**Default Project Task**|The project task to be used by default for items associated with the contract. If a default project task is specified on the **Task** tab of the [Projects](../Shared/../UserGuide/PM_30_10_00.md) \(PM301000\) form for the project specified in the **Project** box, the system fills in the identifier of the default task in this box.

 This box appears on the form only if the identifier of a project is selected in the **Project** box.

Any additional services or inventory items that have been used in appointments during this period are billed separately. ## Services per Period Tab { .section}

On this tab, you define information for service contracts of the *End-Period Plus*, *Beginning-Period Fixed* and *Beginning-Period Plus* billing types. This includes the hours or quantity of services and non-stock items to be provided, as well as the item prices. For service contracts of the *End-Period Plus* billing type, you can also specify the overage item price \(that is, the price the system will use if the contract amount is exceeded\) and track the number of items scheduled, used, and remaining in the selected billing period.

You can edit the specified settings for service contracts with the *Active* status by using the *Modify Upcoming Billing Periods* action in the **Actions** box on the toolbar of the current tab, so that the system will use the updated prices when billing the service contract in the next billing period. To review the settings for upcoming billing periods, you click the *Search by Billing Periods* action in the **Actions** box of the current form.

This tab appears on the form only if *End-Period Plus*, *Beginning-Period Fixed* or *Beginning-Period Plus* is selected in the **Billing Type** box on the **Summary** tab of this form.

|-------|-----------|
|**Actions**|The action that is performed in the table of the tab:-   *Search by Billing Periods*: Makes it possible to select a period in the **Billing Period** box and view in the table the service and non-stock item details related to the period.
-   *Modify Upcoming Billing Period*: Makes it possible to modify the details of the next billing period in the table and activate it. If you change any prices and save them, the system will use the updated values when billing the service contract in the next period.

|**Scheduled Period Quantity**|The estimated quantity of an item for the current period when the billing rule specified in the line is *Flat Rate*. This column is available for service contracts of the *End-Period Plus* billing type.

|
|**Scheduled Period Time**|The scheduled time planned for the line item when the billing rule specified in the line is *Time*. The system calculates this value by multiplying the **Scheduled Period Quantity** by 60. This column is available for service contracts of the *End-Period Plus* billing type.

|
|**Used Period Quantity**|The total quantity used during the period, including both the quantity of the line item that exceeds the amount covered by the service contract and the quantity covered by the service contract. This value is calculated if the billing rule is *Flat Rate*. This column is available for service contracts of the *End-Period Plus* billing type.

|
|**Used Period Time**|The total time used during the period, including both the time that exceeds the time covered by the service contract and the time covered by the service contract. This value is calculated if the billing rule is *Time*. This column is available for service contracts of the *End-Period Plus* billing type.

|
|**Deferral Code**|The deferral code assigned to the item specified in this line.

 On release of the billing document, the system generates a deferral schedule or multiple schedules based on the settings specified for this deferral code. For details, see [Processing Deferrals](../Shared/../UserGuide/DR__con_Processing_of_Deferrals.md).

 The column appears on the form only if the *Deferred Revenue Management* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form and if the *Beginning-Period Fixed* or *Beginning-Period Plus* option is specified for a service contract in the **Billing Type** box of the **Summary** tab of the current form.

 By default, the system inserts the deferral code specified for the item in the **Deferral Code** box on the **Deferral** tab on the [Non-Stock Items](../Shared/../UserGuide/IN_20_20_00.md) \(IN202000\) form.
