# Marketing Reports: General Information {#_1af95c86-f60a-4887-b692-16108b942324 .concept}

In Acumatica ERP, you can use several reports to analyze the data and metrics related to lead sources, lead processing, and campaigns.

## Learning Objectives { .section}

In this chapter, you will do the following:

-   Learn about the types of marketing metrics and reports that can be used for marketing goals
-   Become familiar with the marketing metrics

## Applicable Scenarios { .section}

You may want to learn how to use the marketing metrics in Acumatica ERP in scenarios that include the following:

-   You need to analyze how many new leads have been added to the system and which activities the marketing team has performed for the leads over a period of time.
-   You need to analyze the effectiveness of the marketing campaign and number of related sales orders or invoices created as a result of the campaign.

## Marketing Reports {#section_kwd_2y1_hwb .section}

Acumatica ERP provides the following reports designed as generic inquiry forms for marketing and sales personnel to monitor multiple marketing data and metrics, and track marketing goals:

-   Leads BI \(CR3010BI\)
-   Lead Conversion BI \(CR3011BI\)
-   Campaign Summary \(CR2020BI\)
-   Campaign Sales Orders \(CR203010\)
-   Campaign Invoices \(CR203000\)

For more information about the use of these reports to analyze marketing data and metrics, see [Marketing Reports: Lead Generation and Processing Analysis](CRM_Marketing_Reports_Lead_Acquisition_Lead_Response_Metrics.md), [Marketing Reports: Lead Conversion and Qualification Analysis](CRM_Marketing_Reports_Lead_Conversion_Metrics.md), and [Marketing Reports: Campaign Analysis](CRM_Marketing_Reports_Campaign_Metrics.md).

## Flexible Use of Marketing Reports {#section_wf5_1yk_hwb .section}

The marketing reports are displayed on generic inquiry forms and pivot tables. You can filter data by any column in a pivot table depending on the information that you would like to view, and configure dashboards that show marketing metrics.

If needed, a user with the *Administrator* role can make changes to these generic inquiry forms and pivot tables, as well as build other pivot tables to be used as filter tabs of these reports. This user can also create new generic inquiries and pivot tables to display marketing metrics.
