# Production Summary

Form ID: \(AM625200\)

This report displays the open production orders in your system. It can be used as a manual form to record completions and scrap.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Order Type:** Only list the orders with the specified type. You can blank this box to remove the filter.
-   **Inventory ID**: A particular inventory item. Select an inventory ID to view the production orders for only this inventory item, or leave it blank to view to view all orders.
-   **Status:** The report has predefined selections to filter the open orders by their status:
    -   *Plan, Release, In Process*
    -   *Plan*
    -   *Release*
    -   *In Process*
-   **Include on Hold:** If selected, orders on hold are included.
