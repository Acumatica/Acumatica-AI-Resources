# Acumatica ERP Access: To Change Your Password {#_89595c06-bf38-4457-a18a-7f2c7b972a9e .task}

You can change your password anytime if your organization's security policies allow this. To do this, you use the [User Profile](SM_20_30_10.md) \(SM203010\) form, as described in this topic.

## To Change Your Password { .section}

1.  In the right part of the top pane, click the User menu button \(where your username appears\).
2.  On the User menu, which opens, click **My Profile**.
3.  On the **General Info** tab of the [User Profile](SM_20_30_10.md) \(SM203010\) form, which opens, click **Change Password** to open the **Change Password** dialog box.
4.  Enter your old password and new password, and retype the new password to confirm it.
5.  Click **OK** to change the password.
6.  On the form toolbar, click **Save**.

The next time you sign in to the system, you should use your new password.
