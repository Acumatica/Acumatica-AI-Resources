# Lists as Entry Points {#_c1c04db7-e205-452d-a3b3-e08e19ca508d .reference}

Form ID: \(SM208500\)

By using this form, you can view the list of entry forms that have substitute forms and activate or cancel the replacement of the entry forms.

**Note:** If you delete a row in the table, you cancel the replacement of the entry form; the entry and the substitute forms themselves are not deleted.

For more information, see [Making a Generic Inquiry a Substitute Form](GI_Gi_as_Entry_Point_Mapref.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Table { .section}

The table displays the list of data entry forms that have the substitute forms. By using this table, you can manage the replacement of the data entry forms.

|Column|Description|
|------|-----------|
|**Active**|A check box that you select to replace the entry form with the corresponding substitute form when a user clicks the name of the entry form on the navigation pane. Clear the check box to cancel the replacement.**Note:** For generic inquiries that are used as substitute forms, selecting or clearing the **Active** check box selects or clears, respectively, the **Replace Entry Screen with This Inquiry in Menu** check box on the **Entry Point** tab of the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form.

|
|**Entry Screen ID**|The unique ID of the entry form.|
|**Substitute Screen ID**|The unique ID of the substitute form.|
