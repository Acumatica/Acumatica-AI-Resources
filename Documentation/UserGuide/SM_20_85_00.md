# Lists as Entry Points

Form ID: \(SM208500\)

By using this form, you can view the list of entry forms that have substitute forms and activate or cancel the replacement of the entry forms.

**Note:** If you delete a row in the table, you cancel the replacement of the entry form; the entry and the substitute forms themselves are not deleted.

For more information, see [Making a Generic Inquiry a Substitute Form](GI_Gi_as_Entry_Point_Mapref.md).

## Form Toolbar

The form toolbar has only standard buttons.

The table displays the list of data entry forms that have the substitute forms. By using this table, you can manage the replacement of the data entry forms.
