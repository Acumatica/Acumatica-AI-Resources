# Project Variance

Form ID: \(PM651020\)

**Attention:** This generic inquiry form is available if the *Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

On this form, you can view where and why the project is over or under budget, schedule, or scope—and compare budgeted or scheduled values with actual values.

## Form Toolbar

The form toolbar has only standard buttons.

## Selection Area

In this area, you select the project whose data you want to view in the table and the date through which data is calculated.

|Element|Description|
|-------|-----------|
|**Project**|The project for which you want to view variance data.|
|**Date Through**|The date as of which data is displayed. By default, the system inserts the current business date.|

## Table

In the table, you can see how quantities and unit rates influence project cost and revenue variances. This information is presented as of the selected date, including for projects with incomplete tasks. Each row represents a cost or revenue budget line of the project.

**Attention:**

-   The leftmost columns of the table aren't described in this topic. These columns display the project task's basic information—such as description, completion percentage, status, and start and end dates. They also show the revenue task, inventory item, and cost code. If you need information about these UI elements, see their descriptions on the [Projects](PM_30_10_00.md) \(PM301000\) form.
-   This topic also doesn’t cover the separate column sets for account groups used to record expenses—labor, material, subcontract, and equipment. Each expense type has the same set of columns. The system calculates their values similarly to the project expenses described below.
