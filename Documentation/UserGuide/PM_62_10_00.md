# Project Balance {#_c70c26ab-20cb-4b15-9652-c11b49f693fd .reference}

Form ID: \(PM621000\)

**Note:** This report is available only if the *Projects* group of features is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This report lists budgeted, revised, and actual quantities and amounts totaled by account groups. The account group balances for each project are grouped by the account group type \(*Income*, *Expense*, *Asset*, or *Liability*\). Also, the report includes the project totals and the calculated margin totals for each of the values.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Report Format**: The format of the report to be displayed. Select one of the following options:
    -   *Summary*: To view project balances summarized by account group
    -   *Detailed*: To view project balances at the project task level of detail along with the total project balances
-   **Project**: The project for which you want to view balances. You can select a project to view only balances for this project, or leave the box blank to view the report for all projects. Only projects with the *Active* status are available for selection.
-   **Project Task**: If a project is selected in the **Project** box, you can select the project task for which you want to view the report. You can leave this box blank to view the report for all project tasks of the selected project \(if a project is selected\). If a project task is selected, the system shows the balances of this project task and total project balance.
-   **Include Potential CO Values in Revised Values**: A check box that you select to include the change orders that have the *Open* status in the revised amounts and quantities.
