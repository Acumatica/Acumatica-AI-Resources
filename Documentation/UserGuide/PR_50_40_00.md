# Government Reporting {#_023bb6a0-c1ff-480d-8a91-18efe237bbe3 .reference}

Form ID: \(PR504000\)

By using this form, you can generate an Aatrix report based on the information about ACA coverage, wages paid and taxes collected for each worker and for the entire company that is stored in the system. You can also edit the report data and print the report or electronically submit it to the appropriate government body.

**Attention:** Before running reports, we recommend updating taxes on the [Tax Maintenance](PR_20_80_00.md) \(PR208000\) form by clicking **Update Taxes** on the form toolbar.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**View History**|Opens the Aatrix website where you can review a log of the operations performed on a specific form.|

## Summary Area { .section}

Here you can filter by the EIN that you want to report on, the reporting period, and the state. The following table summarizes the elements of this area.

|Element|Description|
|-------|-----------|
|**EIN**|A EIN of a company or branch specified in the **Tax Registration ID** box on the **Company Details** tab of the [Companies](CS_10_15_00.md) \(CS101500\) form or on the **Branch Details** tab of the [Branches](CS_10_20_00.md) \(CS102000\) form, respectively. The system will use this EIN to generate a report for.

 You can select only the EINs of companies and branches you have access to. If multiple entities share the same EIN, it's available only if you have access to all the included entities.

 For reporting, the system automatically uses information and the legal name of the company or branch associated with the selected EIN if the **Registered Entity for Government Payroll Reporting** check box is selected for that entity on the [Companies](CS_10_15_00.md) or [Branches](CS_10_20_00.md) form.

|
|**Show Only Federal Forms**|A check box that indicates \(if selected\) that only federal forms are shown in the table on this form.|
|**State**|The state for which a report is to be generated.|
|**Reporting Period**|The reporting period.|

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Form**|The name of the reporting form, which is also a link that you click to open the [Run Report](#_c33c62bb-411e-43fd-a3a7-e150b945d311) dialog box.|
|**Description**|The description of the report.|
|**State**|The state in which the report applies. For federal reports, *FED* is displayed in the column.|
|**Reporting Period**|The reporting period.|

|Element|Description|
|-------|-----------|
|**Form**|A read only box with the name of the report form.|
|**Year**|The year for which you want to generate the report.|
|**Month**|The year for which you want to generate the report.|
|**Quarter**|The year for which you want to generate the report.|
|**Date From**|The starting date of the range for which you want to generate the report.|
|**Date To**|The ending date of the range for which you want to generate the report.|
| | |
|This dialog box has the following buttons.|
|**Run Report**|Opens the Aatrix form prefilled with automatically collected information for the specified period. From there, you will be able to print the report or send it electronically to the appropriate government body.|
|**Cancel**|Discards the specified information and closes the dialog box.|
