# Integrating Acumatica ERP with OpenID Identity Providers {#_ef559879-9907-4ec4-826e-13854e094114 .concept}

In Acumatica ERP, you can configure integration with multiple OpenID providers for a System tenant or multiple tenants.

**Attention:** The configuration of this integration is available if the *OpenID Connect* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This chapter describes how to integrate Acumatica ERP with OpenID identity providers.
