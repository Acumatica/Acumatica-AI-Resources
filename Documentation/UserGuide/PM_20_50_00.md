# Rate Table Sequences {#_00406219-0fa7-4f06-9959-b2265a4cb8da .reference}

Form ID: \(PM205000\)

By using this form, you can specify the sequences in which Acumatica ERP searches the rate in rate tables, as well as the type of factors that affect rate selection for each sequence. For details on defining rates and rate tables, see [Billing Rates: General Information](Billing_Rates_GeneralInfo.md).

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area {#1 .section}

You use the elements in this area to select a rate table and a specific rate type. You can then view or modify the sequences for the rate table when used with this rate type.

|Element|Description|
|-------|-----------|
|**Rate Table Code**|The rate table code for which you want to view or specify sequences.|
|**Rate Type**|The rate type for which you want to view or specify sequences. By using these rate types, which are defined on the [Rate Types](PM_20_41_00.md) \(PM204100\) form, you can use different rates in different steps of billing and allocation rules.|

## Table {#2 .section}

In this table, you create rate sequences that the system will use to find the rate in the rate table. Each sequence specifies the types of factors to which the rate is applicable. You can select specific factors of these types by using the [Rate Tables](PM_20_60_00.md) \(PM206000\) form. For instance, if you want to use different rates for different tasks \(that is, if the task is a factor\), you can select the **Project Task** check box in a sequence and then use the [Rate Tables](PM_20_60_00.md) form to define the rate and specify particular tasks to which this rate is applicable.

**Attention:** A rate application condition is defined as follows: Conditions on particular projects, tasks, items, employees, or account groups are joined by OR operators, while conditions on different types of factors are joined by AND operators. For instance, suppose that a special rate is valid for tasks *1*, *2*, and *3* of Project *1* and Project *2* if employee *JOHN* or *JACK* is involved. The resulting condition is expressed as follows.

```
((Project=Project1) OR (Project=Project2))AND  
((Employee=JOHN) OR (Employee=JACK))AND
((Task=Task1) OR (Task=Task2)OR(Task=Task3))
 
```

The sequence number defines the priority of the factors for searching for the rate. The sequences are used for searching in the order of their numbers.

|Button|Description|
|------|-----------|
|**View Rates**|Navigates to the [Rate Tables](PM_20_60_00.md) \(PM206000\) form, from which you can view and modify the rate for the selected sequence.|

|Column|Description|
|------|-----------|
|**Rate Table Sequence**|The sequence number of the rate table sequence for the selected rate table code and rate type. The system processes rate sequences in the order of their numbers.|
|**Description**|A short description of the rate sequence.|
|**Project**|A check box that indicates \(if selected\) that projects are a type of factor that can affect rate selection. If you select this check box, the [Rate Tables](PM_20_60_00.md) \(PM206000\) form will show the **Projects** tab for this rate sequence. On this tab, you select the projects to which the rate will be applied.|
|**Project Task**|A check box that indicates \(if selected\) that project tasks are a type of factor that can affect rate selection. If you select this check box, the [Rate Tables](PM_20_60_00.md) \(PM206000\) form will show the **Tasks** tab for this rate sequence. On this tab, you select the tasks to which the rate will be applied.|
|**Account Group**|A check box that indicates \(if selected\) that account groups are a type of factor that can affect rate selection. If you select this check box, the [Rate Tables](PM_20_60_00.md) \(PM206000\) form will show the **Account Groups** tab for this sequence. On this tab, you select the account groups to which the rate will be applied.|
|**Inventory**|A check box that indicates \(if selected\) that inventory items are a type of factor that can affect rate selection. If you select this check box, the [Rate Tables](PM_20_60_00.md) \(PM206000\) form will show the **Inventory** tab for this sequence. On this tab, you select the inventory items to which the rate will be applied.|
|**Employee**|A check box that indicates \(if selected\) that employees are a type of factor that can affect rate selection. If you select this check box, the [Rate Tables](PM_20_60_00.md) \(PM206000\) form will show the **Employee** tab for this sequence. On this tab, you select the employees to which the rate will be applied.|
