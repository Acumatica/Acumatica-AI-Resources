# Release Time Activities {#_6c9e64df-a6d7-47f9-8a8d-7f3b102e08c6 .reference}

Form ID: \(EP507020\)

This form lists all time activities that are ready for release. You can release either selected time activities or all of them. After successful completion of the release, the status of the processed time activities changes to *Released*.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Release**|Releases the time activities you have selected in the table and changes their status to *Released*.|
|**Release All**|Releases all the time activities listed in the table and changes their status to *Released*.|

## Selection Area {#2 .section}

By using the elements in this area, you can select time activities from a specific date range for specific project and employee. The table lists time activities that are ready for release, that is, are assigned the *Completed* status.

**Note:** If the *Construction Project Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, time activities linked to a daily field report can be released only if this daily field report is completed. For more information on processing daily field reports, see [Reporting On-Site Work Progress](Construction_Daily_Field_Reports_Mapref.md).

|Element|Description|
|-------|-----------|
|**Employee**|The ID of the employee whose time activities you want to list.|
|**From Date**|The start date of the date range for which you want to view the time activities.|
|**Until Date**|The end date of the date range for which you want to view the time activities.|
|**Project**|The project for which you want to list the time activities.|
|**Project Task**|The project task for which you want to list the time activities.|
|**Contract**|The contract for which you want to list the time activities.

 If the *Multiple Base Currencies* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form and a contract is selected, when you select any activities to process them and create contract usage, the system verifies whether the current branch has the same base currency as the bill-to customer of the contract. If these base currencies are different, the system displays an error message.

 If the contract has a bill-to customer without a base currency—that is, if the customer has been extended from a branch—the activity can be processed regardless of the current branch.

|

|Element|Description|
|-------|-----------|
|**Spent**|The total hours \(regular and overtime\) spent on the listed time activities.|
|**Billable**|The total billable hours \(regular and overtime\) spent by the employee on the listed time activities.|

## Details Tab { .section}

This tab contains the table with the list of time activities that are ready for release.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Selected|A check box that indicates \(if selected\) that the time activity will be included in the release process when you click **Release** on the form toolbar.|
|**Date**|The date the time activity was started.|
|**Owner**|The identifier of the employee that is the owner of the time activity.|
|**Employee Name**|The name of the employee that is the owner of the time activity.|
|**Earning Type**|The type of the work time spent by the employee on the time activity.|
|**Task**|The task associated with the time activity.|
|**Project**|The project associated with the time activity.|
|**Project Task**|The project task associated with the time activity.|
|**Cost Code**|The cost code that is associated with the time activity.

 The column is shown if the *Cost Code* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Shift Code**|The work shift during which the time activity was performed. This column appears only if the *Shift Differential* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Time Spent**|The total time spent by the employee on the time activity.|
|**Billable**|A check box that indicates whether the case is billable.|
|**Billable Time**|The total billable time spent by the employee on the activity.|
|**Summary**|The description of the activity.|
|**Workgroup**|The workgroup to which the employee belongs.|
|**Approver**|The identifier of the person who approved the time activity.|
|**Approved Date**|The date when the time activity was approved.|
|**Case ID**|The identifier of the case with which the activity is associated.

 This column is available only if the *Case Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Case Status**|The status of the case, which can be one of the following: *New*, *Pending Customer*, *Open*, or *Closed*.

 This column is available only if the *Case Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Contract ID**|The identifier of the contract with which the activity is associated.|
|**Reported in Time Zone**|The original time zone in which the time activity was created.|
|**Reported On**|The reported date in the original time zone.|
|**Reported At**|The reported time in the original time zone.|

## Totals Tab { .section}

On this tab, you review the total hours spent by employees on the regular and overtime work.

|Element|Description|
|-------|-----------|
|**Time Spent**|The regular work hours spent on the listed time activities.|
|**Billable**|The billable hours spent by the employee on the listed time activities.|

|Element|Description|
|-------|-----------|
|**Time Spent**|The overtime spent on the listed time activities.|
|**Billable**|The billable overtime spent by the employee on the listed time activities.|
