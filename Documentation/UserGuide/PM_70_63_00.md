# Projects Pending Billing {#_277dd69b-ebe7-499f-9cbf-a38f15a6af80 .reference}

Form ID: \(PM706300\)

This report displays the projects that have not yet been billed in the specified period of time—that is, the projects that have amounts pending billing in the period, and the projects that are billed on demand. For each project, the report displays the description, customer, project manager, last activity date, last billing date, next billing date, and the project part that has been billed \(as a percent\).

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, use the following parameters to select the information to be displayed on the report:

-   **Company/Branch**: The company or branch for which you want to view information. You can select a company or make no selection to view information about all companies in the tenant.

    By default, the system inserts the company or branch selected on the Company and Branch Selection menu.

-   **Customer**: The identifier of the customer for whom you want to view the report. Select a customer from the list of active customers, or leave the box blank to view information about all customers.

    The list of customers available for selection may be limited based on the role or roles assigned to the user account to which you are signed in if the *Customer and Vendor Visibility Restriction* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form. In this case, the **Restrict Visibility To** box appears on the **Financial** tab of the [Customers](../Shared/../UserGuide/AR_30_30_00.md) \(AR303000\) form. With the feature enabled, a customer is available for selection if one of the following is true:

    -   The **Restrict Visibility To** box is empty for the customer—that is, the customer’s visibility is not restricted.
    -   A branch, company, or company group is specified in the **Restrict Visibility To** box for the customer, and your user account has the role specified in the **Access Role** box of the **Configuration Settings** section of one of the following: the **Branch Details** tab of the [Branches](../Shared/../UserGuide/CS_10_20_00.md) \(CS102000\) form for the branch, or the **Company Details** tab of the [Companies](../Shared/../UserGuide/CS_10_15_00.md) \(CS101500\) form for the company or a company within the company group.
-   **Project**: The project for which the billing information will be displayed. Select the project for which you want to view the billing information, or leave the box blank to view billing information for all projects. Projects with the *Active*, *Suspended*, and *Completed* status are available for selection.
-   **Project Manager**: The project manager for whose projects billing information will be displayed. Select the project manager for whom you want to view the report, or leave the box blank to view billing information on the projects of all project managers.
-   **Start Date**: The start date of the date range for which billing information will be displayed. By default, the first date of the current period is specified.
-   **End Date**: The end date through which billing information will be displayed. By default, the current business date is specified.
-   **Show Active Projects Only**: A check box that you select to include only the active projects and their details in the report.
