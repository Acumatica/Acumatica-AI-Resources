# Tax Categories

Form ID: \(TX205500\)

You can use this form to create tax categories, or to view or edit existing tax categories. A tax category groups the taxes that are applied to products or services of the same type.

## Form Toolbar

The form toolbar has only standard buttons.

## Summary Area

In the Summary area, you can specify an identifier and description for a new tax category, or select an existing category to view or edit its details.

**CIS Type**

</td><td>

The CIS type of the tax category, which determines how amounts under this tax category are treated in Construction Industry Scheme \(CIS\) calculations. The system uses this setting on the [Bills and Adjustments](AP_30_10_00.md) \(AP301000\) form to calculate the CIS deduction and other CIS amounts reported on the [Submit CIS Return](AP_50_77_00.md) \(AP507700\) form. Select one of the following options:

 -   *None* \(default\): Not included in CIS calculations.
-   *Labour*: Treated as labor and subject to CIS deductions.
-   *Material*: Treated as materials and excluded from CIS deductions.

 If you change the CIS type of a tax category that is used in an open bill, the system displays a warning, because the change can affect CIS calculations and returns.

 This box appears on the form only if the *UK Localization* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Table

This table contains the list of individual taxes for the tax category. These taxes are generally included unless the **Exclude Listed Taxes** check box is selected for the category.

The table toolbar has only standard buttons.

**Tax ID**

The ID of the tax included in the category. Once you select a tax by its ID, the other columns of the row are filled in.

</td></tr><tr><td>

**Description**

The detailed description of the tax item.

</td></tr><tr><td>

**Tax Type**

</td><td>

The type of tax, which defines how it is processed. The following options are available: *Sales*, *Use*, *VAT*, and *Withholding*.

</td></tr><tr><td>

**Calculation Rule**

</td><td>

The way the tax amount is calculated, which can be one of the following options: -   *Inclusive Line-Level*: The tax amount is included in item amounts and should be extracted.
-   *Exclusive Line-Level*: This is a first-level tax calculated on item amounts.
-   *Compound Line-Level*: This is a second-level tax calculated on item amounts and the amounts of the first-level-taxes.
-   *Inclusive Document-Level*: This is a first-level tax that is included in the document amount and should be extracted. This tax is calculated on the sum of the line amounts of all the items to which the same tax applies.
-   *Exclusive Document-Level*: This is a first-level tax calculated on the document amount, not on a per-line basis.
-   *Compound Document-Level*: This is a second-level tax calculated on the document amount and the amount of the first-level tax.

</td></tr><tr><td>

**Cash Discount**

</td><td>

The method of calculating the taxable amount if a discount is applied \(based on the credit terms\). It can be one of the following options: -   *Reduces Taxable Amount*: The discount is taken on the total amount calculated for the document. The taxable amount is decreased by the discount.
-   *Does Not Affect Taxable Amount*: The discount is taken on the document total, but the tax is also calculated on the document total. The taxable amount is not affected by the discount.

</td></tr><tr><td>

-   [Landed Costs](../Shared/../UserGuide/PO_30_30_00.md) \(PO303000\)

For details, see [Direct Tax Payment: General Information](../Shared/../UserGuide/Taxes_Paying_Tax_Directly_GeneralInfo.md).
