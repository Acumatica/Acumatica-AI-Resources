# Route Service Contracts {#_9036b4a6-98fe-42dd-bf5d-f1808e6bb122 .reference}

Form ID: \(FS300800\)

You use this form to create new route service contracts or to view and edit existing ones. A route service contract defines the services to be performed at a specified frequency for a particular customer. For each contract with the *Open* status, you can generate appointments according to the contract schedule.

|**Status**|The status of the service contract, which the system sets to one of the following: -   *Draft*: The contract is a draft and is not yet activated, and you cannot generate service orders, appointments, and invoices for the contract. You can activate or delete a contract with this initial status.
-   *Active*: The contract is active in the system and you can generate service orders, appointments, and invoices for the contract. The contract was assigned this status when the **Activate Contract** action was invoked. You can suspend or cancel a contract with this status.

## Services per Period Tab { .section}

On this tab, you define information for service contracts of the *End-Period Plus*, *Beginning-Period Fixed* and *Beginning-Period Plus* billing types. This includes the hours or quantity of services and non-stock items to be provided, as well as the item prices. For service contracts of the *End-Period Plus* billing type, you can also specify the overage item price \(that is, the price the system will use if the contract amount is exceeded\) and track the number of items scheduled, used, and remaining in the selected billing period.

You can edit the specified settings for service contracts with the *Active* status by using the *Modify Upcoming Billing Periods* action in the **Actions** box on the toolbar of the current tab, so that the system will use the updated prices when billing the service contract in the next billing period. To review the settings for upcoming billing periods, you click the *Search by Billing Periods* action in the **Actions** box of the current form.

This tab appears on the form only if *End-Period Plus*, *Beginning-Period Fixed* or *Beginning-Period Plus* is selected in the **Billing Type** box on the **Summary** tab of this form.

## Attributes Tab { .section}

On this tab, you can view the list of attributes for the service contract, specify the values of the attributes, and change these values, if necessary. This tab is populated with the list of active attributes \(and any default values\) that have been defined for the *Service Contract* entity type on the [Project Attributes](../Shared/../UserGuide/PM_20_20_00.md) \(PM202000\) form.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|

|**Value**|The value of the attribute.|
