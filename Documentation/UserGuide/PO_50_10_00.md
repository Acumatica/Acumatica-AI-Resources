# Release Purchase Receipts {#_a65e7a2b-08ff-42fd-80ff-0e26078b1f3b .reference}

Form ID: \(PO501000\)

**Attention:** This form is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

You can use this form to view and release selected purchase receipt or return documents with the *Balanced* status. The list of documents displayed on this form includes the purchase receipts or returns that were created on the [Purchase Receipts](PO_30_20_00.md) \(PO302000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Releases the documents you have selected in the table.|
|**Process All**|Releases all the documents listed in the table.|

## Table {#1 .section}

In this table, you can view the list of the purchase receipts generated according to the purchase orders, as well as return documents. You can select the documents to be released or release all the listed documents.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that \(if selected\) includes the document among the selected documents that can be released.|
|**Receipt Nbr.**|The number of the purchase receipt or return document.|
|**Type**|The type of the document, which can be *Receipt* or *Return*.|
|**Vendor**|The vendor \(by its ID\) from which the goods are received or to which they are returned.|
|**Vendor Name**|The name of the vendor.|
|**Location**|The vendor location from which the goods are received or to which they are returned.

 This column appears only if the *Multiple Warehouses* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Date**|The date when the document was created.|
|**Currency**|The currency of the purchase receipt or return document.|
|**Workgroup**|The workgroup to which the document owner belongs.|
|**Owner**|The owner of the purchase receipt or return document.|
