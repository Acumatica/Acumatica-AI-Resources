# Contacts

Form ID: \(CR302000\)

On this form, you can create a new contact record, or view and modify the settings of an existing contact record. In Acumatica ERP, a contact represents a person. A contact record can have multiple settings, such as a name, address, and contact information, such as an email address and phone number.

**Attention:** This form is available only if the *Customer Management* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Summary Area

This area contains the summary settings of the contact, such as its status and owner. In the **Contact** box, you can select an existing contact to view and edit its settings.

<table><thead><tr><th>

Element

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Contact**

</td><td>

The unique identifier of the contact, which the system generates automatically.

 When you add a new contact, leave this box blank. After you have added a new contact, the system hides the unique identifier and shows the name of the contact in this box.

</td></tr><tr><td>

**Status**

</td><td>

The status of the contact.

 You can select one of the following options:

 -   *Active*: The contact is active, meaning that it appears on all **Contact** lookup tables and can be specified in documents and other records.
-   *Inactive*: The contact is inactive, meaning that it does not appear in **Contact** lookup tables and cannot be specified in documents and other records.

</td></tr><tr><td>

**Contact Class**

</td><td>

The contact class that the contact belongs to.

 A contact class, which is defined on the [Contact Classes](CR_20_50_00.md) \(CR205000\) form, determines which default settings are applied to a contact of this class, such as the default owner, assignment map, and attributes.

</td></tr><tr><td>

**Business Account**

</td><td>

The business account that the contact is associated with.

</td></tr><tr><td>

**Owner**

</td><td>

The owner of the contact. If a workgroup has been specified on the **General** tab of this form, you can select the owner from only its members; if no workgroup is specified, you can select any user.

 The system fills in the default setting as follows, based on the option selected in the **Default Owner** box \(in the **Data Entry Settings** section of the **Details** tab\) of the [Contact Classes](CR_20_50_00.md) \(CR205000\) form for the contact class:

 -   If the *Do Not Change* option is selected for the contact class, the system does not change the value in this box automatically.
-   If the *Creator* option is selected for the contact class, the system fills in the username of the user who created the current contact.
-   If the *From Source Entity* option is selected for the contact class and this contact has been created from another entity \(such as a business account\), the system copies the owner and workgroup \(if specified\) from the source entity.
-   If the *Assignment Map* option is selected for the contact class, the system fills in the owner based on the assignment map of the contact class. This assignment map is specified in the **Assignment Map** box on the **Details** tab of the [Contact Classes](CR_20_50_00.md) \(CR205000\) form.

</td></tr><tr><td>

**Duplicate**

</td><td>

Read-only. The duplicate validation status of the record.

 The default value is *Not Validated*, indicating that the record has not been validated yet.

 If a user clicks **Check for Duplicates** on the More menu, the system searches for duplicates of the record and inserts one of the following:

 -   *Possible Duplicate*: The record has been validated, and at least one possible duplicate has been found.
-   *Validated*: The record has been validated, and no duplicates have been found.
-   *Duplicated*: The record has been closed as a duplicate, and its status has been set to *Disqualified*.

 This box is displayed on the form only if the *Duplicate Validation* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

</td></tr></tbody>
</table>

This tab is available only if the *HubSpot Integration* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

<table id="d30317e31"><thead><tr><th>

Description

**Sync With HubSpot**

</td><td>

Synchronizes the data with HubSpot.

 During this synchronization, the system checks whether there are any data changes in either HubSpot or Acumatica ERP. Then the system either pulls the data from HubSpot or pushes the data to HubSpot from Acumatica ERP, so that the latest version is used for both entities. If there are data changes in both HubSpot and Acumatica ERP, then the system checks what is set as the master source for the entity type in the **Master Source** column on the [HubSpot Sync](../Shared/../UserGuide/HS_20_50_20.md) \(HS205020\) form and applies the changes from the master source.

 This button is available if the *HubSpot Sync* data provider is marked active on the [Data Providers](../Shared/../UserGuide/SM_20_60_15.md) \(SM206015\) form and only for entity types listed on the [HubSpot Sync](../Shared/../UserGuide/HS_20_50_20.md) form.

</td></tr><tr><td>

**Push to HubSpot**

</td><td>

Pushes the data from Acumatica ERP to HubSpot for the selected record \(that is, the record you clicked in the table before clicking this button\).

 While pushing the data, the system replaces the current version of the item in HubSpot with the selected item from Acumatica ERP.

</td></tr><tr><td>

**Pull from HubSpot**

</td><td>

## Locations Tab

In the table of this tab, you can specify the contacts associated with the customer location and assign roles to them.

This tab is available only if the *Shopify B2B Integration* or *BigCommerce B2B Integration* feature \(or both of these features\) is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

The table toolbar has only standard buttons.

<table id="_d5bdcc55-6100-4abc-af29-99776edd426d"><thead><tr><th>

Column

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Location**

</td><td>

The customer location that the contact is associated with.

</td></tr><tr><td>

**Role**

</td><td>

The role assigned to the contact in the location.

 The contact can be assigned either of the following roles:

 -   *Admin*: The contact has administrative permissions in the location.
-   *User*: The contact does not have administrative permissions in the location.

 These roles are specified for informational purposes and are only used for the export of business customers and sales orders that have been created for business customers to a Shopify store.

</td></tr></tbody>
</table>

## Side Panel: Projects Tab

You can click **Projects** in the side panel to see which projects the selected contact is involved in.

The side panel is shown only if the *Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Side Panel: Activity Stream Tab

You open the **Activity Stream** side panel tab by clicking the **Activities** icon in the side panel. The tab shows the activities related to the selected record as a collection of activity tiles.

Each activity tile consists of the activity’s data \(some represented by icons\), its summary and description, and buttons and commands. By default, the activity tiles are collapsed, but you can expand any tile to see more information.
