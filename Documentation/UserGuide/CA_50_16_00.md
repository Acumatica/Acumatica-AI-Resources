# Calculate Taxes {#_73fb5a17-61ed-4b7b-b1af-828b5d9d3196 .reference}

Form ID: \(CA501600\)

This form can be used only if your system is integrated with the AvaTax online service by Avalara. For an overview of this integration, see [Integrating Acumatica ERP with Avalara Avatax](config_Avalara_Integration_Mapref.md).

You use this form to calculate sales and use taxes on cash transactions by using AvaTax. The form displays a list of released transactions for which AvaTax has not yet calculated taxes, and you can select the specific transactions for tax calculation or calculate taxes for all listed transactions. After that, you use the [Post Taxes](TX_50_15_00.md) \(TX501500\) form to post to AvaTax the transactions that you want to include in tax reports.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the calculation of taxes by AvaTax for the selected transactions.|
|**Process All**|Initiates the calculation of taxes by AvaTax for all listed transactions.|

## Table { .section}

This table displays the list of released cash transactions for which AvaTax has not yet calculated taxes. To include a transaction for processing, you select the check box that precedes it. To select all the transactions on the page, select the check box in the column header. You then click **Process** or **Process All** to begin the tax calculation.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that, if selected, includes the transaction in tax calculation if you click **Process**.|
|**Tran. Type**|The type of the Accounts Receivable transaction, which can be one of the following: *Invoice*,*Credit Memo*, *Debit Memo*, and *Overdue Charge*.|
|**Reference Nbr.**|The transaction's reference number.|
|**Status**|The status of the transaction.|
|**Disbursement/Receipt**|The type of the transaction: *Receipt* or *Disbursement*.|
|**Tran. Date**|The date when the transaction was created.|
|**Fin. Period**|The financial period to which the transaction transactions should be posted.|
|**Amount**|The amount of the transaction.|
|**Currency**|The currency of the transaction.|
|**Description**|A user-provided description for the transaction.|
