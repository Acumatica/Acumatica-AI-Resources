# Processing Purchase Requests and Requisitions {#_2f31ca79-d902-46d5-ba28-78f1fd473bf7 .concept}

By using purchase requisitions, your organization can create and process customer requests and employee requests for goods and services and prevent cost overruns. You can use budget validation for employee requests and process bids from multiple vendors for a particular requisition.
