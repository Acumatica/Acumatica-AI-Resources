# Integrating Acumatica ERP with PDF Annotator {#_29319d4b-cd4b-4f9b-bfce-c7c4c10bbf83 .concept}

You can review and annotate PDF attachments directly in Acumatica ERP by using the PDF Annotator integration.

This integration allows you to:

-   Open PDF files from records on forms that have the **Files** button
-   View and navigate PDF documents
-   Access document details and bookmarks
-   Add comments and text notes
-   Use standard editing tools to mark up files

You can also save annotated PDF files as new file versions to preserve the attachment history without downloading the file or using an external PDF editor.
