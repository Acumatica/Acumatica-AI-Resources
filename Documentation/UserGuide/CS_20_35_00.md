# Units of Measure {#_c25c9971-01e2-4021-aa3b-8809f8045e58 .reference}

Form ID: \(CS203500\)

On this form, you specify unit conversions for the units of measure \(UOMs\) used in Acumatica ERP. You add a new unit of measure by specifying how it can be converted to other units of measure available in the system. For information about units of measure, see [Units of Measure: General Information](UOMs_GeneralInfo.md).

For each unit of measure, you can add a translation into other languages, one per locale enabled on the [System Locales](SM_20_05_50.md) \(SM200550\) form.

If a customer is set up to receive printable documents in a different language—that is, if the **Locale** setting on the **General** tab of the [Customers](AR_30_30_00.md) \(AR303000\) form has been set to a locale other than the default locale—the translated UOM description \(if it exists for the selected locale\) will appear on the following printable reports:

-   *ProInvoice/Memo* *\(PM641000\)*
-   [Invoice/Memo](AR_64_10_00.md) \(AR641000\)
-   [Sales Quote](CR_60_45_00.md) \(CR604500\)
-   [Project Quote](PM_60_45_00.md) \(PM604500\)
-   [Pro Forma Invoice](PM_64_20_00.md) \(PM642000\)
-   [Change Order](PM_64_30_00.md) \(PM643000\)
-   [Purchase Order](PO_64_10_00.md) \(PO641000\)
-   [Request for Proposal](RQ_61_10_00.md) \(RQ611000\)
-   [Quote](SO_64_10_00.md) \(SO641000\)
-   [Sales Order](SO_64_10_10.md) \(SO641010\)
-   [Matrix Sales Order](SO_64_10_20.md) \(SO641020\)
-   [Shipment Confirmation](SO_64_20_00.md) \(SO642000\)
-   [Invoice &amp; Memo](SO_64_30_00.md) \(SO643000\)
-   [Matrix Invoice/Memo](SO_64_30_10.md) \(SO643010\)

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area { .section}

In this area, you can select a unit of measure to view its conversions and add translations of the unit description into other languages.

|Element|Description|
|-------|-----------|
|**Unit ID**|The unit to be converted.|
|**Description for Reports**|The description of the unit that will appear in printable versions of reports in the default language.|
|**Level 3 Unit ID**|The unit of measure for level 3 processing that corresponds to the selected unit of measure. This value is a level 3 parameter required by the payment gateway for payments to qualify for level 3 interchange rates.

 For details, see [Level 3 Data Transmission During Card Payments](AR__con_Level3_Data_Transmission.md).

|

## Translation Dialog Box { .section}

In this dialog box, you add translations of the selected unit of measure into other languages. The first box contains the description in the language of the locale to which you are signed in, and subsequent boxes hold translations into each additional locale that is activated on the [System Locales](SM_20_05_50.md) \(SM200550\) form. Any changes you make to the translations in this box are saved automatically.

This dialog box is opened when you click the link with the ISO 639-1 language code right of the **Description for Reports** box.

|Element|Description|
|-------|-----------|
|**Native Language Name \(ISO Code\)**|The name of the language in the language itself, followed by a lowercase ISO 639-1 code of the language.|

## Table { .section}

This table displays the relationships among the units of measure defined in the system. Each line in the table defines a rule used to perform a conversion of the selected unit of measure to another unit of measure. Units from this table will appear on the list of UOMs used to define item classes.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**To Unit**|The unit to which the unit specified in the **Unit ID** box will be converted with the use of the specified operation and specified conversion factor.|
|**Multiply/Divide**|The operation to be performed for conversion of the **From Unit** to the **To Unit**. You can select the *Multiply* or *Divide* option to perform conversions between those units of measure.|
|**Conversion Factor**|The factor to be used for the unit conversion with the specified operation.|
