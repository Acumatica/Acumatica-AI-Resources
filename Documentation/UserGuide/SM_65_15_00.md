# Access Rights by Role {#_6baad670-92fa-433e-8b19-e89872448d4b .reference}

Form ID: \(SM651500\)

This report lists the roles available in the system and their access rights to system forms. Only those forms for which access rights were set up explicitly at the form, module, or suite level are displayed in the report.

The report has no report-specific parameters.
