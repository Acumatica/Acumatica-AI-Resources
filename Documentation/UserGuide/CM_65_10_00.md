# Currency Rate History by Date {#_094a8e0d-a22e-406c-a4a4-d7674996e1f8 .reference}

Form ID: \(CM651000\)

This report shows the fluctuations of the exchange rate of the selected currency during the date range you select. Exchange rates are listed by effective date and rate type.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters { .section}

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **From Date**: The start date of the date range to be used for the report.
-   **To Date**: The end date of the date range.

    By default, the current date is filled in.

-   **Currency**: The currency to be reported on, by its identifier. If you leave this box empty, exchange rates for all the foreign currencies will be listed in the report.
-   **Rate Type**: The rate type of exchange rates to be shown in the report. Select a rate type to review the exchange rates of the particular rate type, or leave this box blank to view information on all rate types.
