# Update Preferences

Form ID: \(SM203505\)

You use this form to manage software updates.

## Form Toolbar

The form toolbar has only standard buttons.

## Update Settings Area

You use the elements in this area to configure how updates will be stored and whether updates should be imported from the server that stores the available Acumatica ERP updates.

<table><thead><tr><th>

Element

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Use Update Server**

</td><td>

A check box that indicates to the system whether updates will be imported from the Acumatica server whose address is specified in the **Update Server Address** box.

</td></tr><tr><td>

**Update Server Address**

</td><td>

The web address of the server that stores Acumatica ERP updates.

 The default address is *update.acumatica.com*.

</td></tr><tr><td>

**Check for Updates**

</td><td>

A check box that you select to indicate that the system should check for available updates automatically.

</td></tr></tbody>
</table>

## Storage Settings Area

You use the **Storage Settings** area to configure access to the selected storage provider.

<table id="table_zl1_wcv_x3"><thead><tr><th>

Element

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Storage Provider**

</td><td>

The storage provider; your selection defines the contents of the lower table. You can select one of the following options: -   *LocalStorage*: Updates will be stored in a local folder.
-   *AzureStorage*: Updates will be stored in a public cloud with Microsoft Azure.
-   *AmazonS3Storage*: Updates will be stored in a cloud with Amazon.

</td></tr></tbody>
</table>

|Button|Description|
|------|-----------|
|**Reload Parameters**|Reloads parameters for the providers if you change the provider settings.|

<table><thead><tr><th>

Column

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Name**

</td><td>

The name of the provider settings. For a local file folder and for the Microsoft Azure Cloud Service, different sets of names \(described below\) are shown.

</td></tr><tr><td>

**Value**

</td><td>

The values for each of the boxes in the **Name** column, which are the following:-   For *AzureStorage*:
    -   *Account*: The name of your account in Microsoft Azure Cloud Services
    -   *Container*: The name of the container to store files in Microsoft Azure Cloud Services
    -   *Key*: The key to your Microsoft Azure Cloud Services.
-   For *AmazonS3Storage*:
    -   *AWSAccessKey*
    -   *AWSRegionEndpoint*
    -   *AWSSecretKey*
    -   *BucketName*
    -   *PathPrefix*
-   For *LocalStorage*:
    -   *Folder*: The path to a local folder
    -   *Login*: The login to be used to access the folder
    -   *Password*: The password to be used to access the folder

</td></tr></tbody>
</table>
