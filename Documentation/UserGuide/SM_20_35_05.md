# Update Preferences {#_a422db08-7847-4748-a9d1-0ebd0c264899 .reference}

Form ID: \(SM203505\)

You use this form to manage software updates.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Update Settings Area {#1 .section}

You use the elements in this area to configure how updates will be stored and whether updates should be imported from the server that stores the available Acumatica ERP updates.

|Element|Description|
|-------|-----------|
|**Use Update Server**|A check box that indicates to the system whether updates will be imported from the Acumatica server whose address is specified in the **Update Server Address** box.|
|**Update Server Address**|The web address of the server that stores Acumatica ERP updates.

 The default address is *update.acumatica.com*.

|
|**Check for Updates**|A check box that you select to indicate that the system should check for available updates automatically.|

## Storage Settings Area {#2 .section}

You use the **Storage Settings** area to configure access to the selected storage provider.

|Element|Description|
|-------|-----------|
|**Storage Provider**|The storage provider; your selection defines the contents of the lower table. You can select one of the following options: -   *LocalStorage*: Updates will be stored in a local folder.
-   *AzureStorage*: Updates will be stored in a public cloud with Microsoft Azure.
-   *AmazonS3Storage*: Updates will be stored in a cloud with Amazon.

|

|Button|Description|
|------|-----------|
|**Reload Parameters**|Reloads parameters for the providers if you change the provider settings.|

|Column|Description|
|------|-----------|
|**Name**|The name of the provider settings. For a local file folder and for the Microsoft Azure Cloud Service, different sets of names \(described below\) are shown.|
|**Value**|The values for each of the boxes in the **Name** column, which are the following:-   For *AzureStorage*:
    -   *Account*: The name of your account in Microsoft Azure Cloud Services
    -   *Container*: The name of the container to store files in Microsoft Azure Cloud Services
    -   *Key*: The key to your Microsoft Azure Cloud Services.
-   For *AmazonS3Storage*:
    -   *AWSAccessKey*
    -   *AWSRegionEndpoint*
    -   *AWSSecretKey*
    -   *BucketName*
    -   *PathPrefix*
-   For *LocalStorage*:
    -   *Folder*: The path to a local folder
    -   *Login*: The login to be used to access the folder
    -   *Password*: The password to be used to access the folder

|
