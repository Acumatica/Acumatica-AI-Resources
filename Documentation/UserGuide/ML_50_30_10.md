# AI Assistant Data Processing {#_39b856cc-1d27-4539-a35e-a647a0f03bb2 .reference}

Form ID: ML503010

You use this form to process generic inquiries and make them available to AI Assistant. You start the processing after you expose the inquiries to AI assistant on the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form.

This form is available only if the *AI Assistant* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

|Button|Description|
|------|-----------|
|**Process**|Initiates the processing of the records you’ve selected in the table. After the system processes the inquiries, their data can be used by AI Assistant.|
|**Process All**|Initiates the processing of all records listed in the table. After the system processes the inquiries, their data can be used by AI Assistant.|
|**Clear Cloud Data Before Processing**|A check box that you select to clear the data in the cloud service before processing it.|

## Table {#2 .section}

|Column|Description|
|------|-----------|
|**Data Source**|The generic inquiry whose data is being processed.|
|**Site Map Title**|The site map title of the generic inquiry.|
|**Status**|The processing status of the generic inquiry. If you modify the generic inquiry, the system changes this status, indicating that the inquiry should be processed again.

 The status can be one of the following:

 -   *AI Description Pending Update*: The description of the generic inquiry has been modified and needs to be processed.
-   *AI Description Up to Date*: The description of the generic inquiry has been processed, and the inquiry can be used by AI Assistant.
-   *AI Description Pending Deletion*: The description of the generic inquiry has been deleted, and the changes need to be processed.

|
|**Last Upload Date**|The date and time when the inquiry was last uploaded.|
