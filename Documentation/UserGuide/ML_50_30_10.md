# AI Assistant Data Processing

Form ID: ML503010

You use this form to process generic inquiries and make them available to AI Assistant. You start the processing after you expose the inquiries to AI Assistant on the [Generic Inquiry](SM_20_80_00.md) \(SM208000\) form.

You also process an exposed generic inquiry after you modify its structure or its AI descriptions.

This form is available only if the *AI Assistant* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

The processing status of the generic inquiry. If you expose the inquiry to AI Assistant or modify its structure or AI descriptions, the system changes this status, indicating that the inquiry should be processed again.

 The status can be one of the following:

 -   *AI Description Pending Update*: The generic inquiry has been exposed, or its structure or AI descriptions have been modified and need to be processed.
-   *AI Description Up to Date*: The description of the generic inquiry has been processed, and the inquiry can be used by AI Assistant.
-   *AI Description Pending Deletion*: The description of the generic inquiry has been deleted, and the changes need to be processed.
