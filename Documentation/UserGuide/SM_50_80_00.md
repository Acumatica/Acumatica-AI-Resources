# Generate Models for Text Completion {#_8708580f-3d50-4a13-8e62-b8b97e85b740 .reference}

Form ID: \(SM508000\)

On this form, you can start generating the intelligent text completion models that will suggest the continuation of a phrase that each processed user starts typing in a rich text editor of a data entry form.

By default, the system performs the generation of models for all users every week on Saturday. This default schedule has been predefined for the System company and is active for all tenants that are created. A system administrator can also invoke the generation manually for certain users or for all users by using the current form. Also, the system administrator can add a new schedule by clicking **Schedules** &gt; **Add** on the form toolbar.

If multiple tenants are created for the Acumatica ERP instance, the system generates separate models for each tenant. If more than one locale is specified for an instance, the system generates a single model for all locales.

The form is available only for users with the *Administrator* or *Acumatica Support* roles if the *Intelligent Text Completion* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the generation of intelligent text completion models for the users that you have selected in the table.

 If the system does not collect new training data for a particular user, the system does not generate a new model; instead, it continues to use the last generated model.

|
|**Process All**|Initiates the generation of intelligent text completion models for all users listed in the table.

 If the system does not collect new training data for a particular user in the list of all users, the system does not generate a new model for this user; instead, it continues to use the last generated model.

|

## Table {#2 .section}

This table contains the list of all available users, along with the date when the last model was generated for each and the result of model generation.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include the user in processing if you click **Process**.|
|**User**|The username of the user.|
|**Last Generated On**|The date when the latest intelligent text completion model record was generated. If no new text input data has been added to the system since the last model was generated for a particular user, the date in the column remains the date when the latest model was generated. The column is empty if no model has ever been generated for the user.|
|**Generation Result**|The result of the model generation for the user in this row, which can be one of the following:

 -   *Success*: The model was generated successfully.
-   *Failed*: The model was not generated as a result of the last processing. The system uses the base model or the previous model that was generated successfully.

 The column is empty if no model has ever been generated for the user.

|
