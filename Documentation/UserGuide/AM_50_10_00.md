# Rough Cut Planning

Form ID: \(AM501000\)

This form is only available when the *Advanced Planning and Scheduling \(Classic\)* or *Advanced Planning and Scheduling \(Optimized\)* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

By using this form, you finite schedule open production orders. You can also release the orders after the system schedules them.

Orders are loaded and scheduled in the following sequence:

-   Dispatch priority ascending
-   End date ascending
-   Production order number ascending

The availability of materials is considered by default. Supply orders \(that is, purchase orders, transfer orders, or production orders\) that are allocated to the order being scheduled constrain the order start date.

-   If a supply order line is allocated to the production order, then the supply order promise date is the first day an order can be scheduled.
-   If material is not already allocated, then allocate available material as *Production Demand Prepared.*
-   Finally, look for supply orders without allocations and use their promise date as a start date constraint. The supply orders are not allocated to the production order.

If materials cannot be allocated, then the order will not be scheduled.

**Tip:** You can exclude the check for available materials as follows:

-   For an entire production order type by setting the **Scheduling** settings on the [Production Order Types](AM_20_11_00.md) \(AM201100\) form.
-   For specific materials by setting the **Scheduling** settings on the **Manufacturing** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form.

## Form Toolbar

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Allocation Details**|Opens the [Inventory Allocation Details](IN_40_20_00.md) \(IN402000\) form in the new tab for the stock item in the highlighted production order.|
|**Critical Material**|Opens the [Critical Materials](AM_40_10_00.md) \(AM401000\) form in the same tab for the highlighted production order.|
|**Order Schedule**|Opens the [Work Center Schedule](AM_00_00_01.md) \(AM000001\) form in the new tab for the highlighted production order.|
|**Production Detail**|Opens the [Production Order Details](AM_20_90_00.md) \(AM209000\) form in the new tab for the highlighted production order.|
|**Production Schedule Board**|Opens the [Production Schedule Board](AM_21_55_55.md) \(AM215555\) form, where you can view a visual representation of the production schedule.|
|**Process**|Schedules only the selected production orders you have selected in the table.|
|**Process All**|Schedules all production orders displayed in the table.|
