# Bidding Responses

Form ID: \(RQ303000\)

**Attention:** This form is available only if the *Purchase Requisitions* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

You use this form to enter vendors' bidding responses. See [Processing Purchase Requests and Requisitions](OrderMgmt_Purchase_Requests_Mapref.md) for more information.

**Attention:** This form does not allow you to select the vendor and does not show the selected vendor. To select the vendor or see the selected vendor, use the [Complete Bidding](RQ_50_30_00.md) \(RQ503000\) form.

The form toolbar has only standard buttons.

A box for searching for the company's address.

 The web service selected as an address provider on the [Site Preferences](../Shared/../UserGuide/SM_20_05_05.md) \(SM200505\) form searches for the information that matches your search criteria and lists all the search results below this box.
