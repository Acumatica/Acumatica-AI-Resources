# Inventory Planning with DRP: Related Report and Inquiry Forms {#_88a9fbc4-bce5-45eb-9de2-fac255e2998e .concept}

In the following sections, you can find details about the reports and inquiry forms you may want to review to gather information about distribution requirements planning—that is, inventory planning that does not include production orders.

**Attention:** If you don’t see a particular report or form that is described, you may have signed in to the system with a user account that doesn’t have access rights to the report or form. Contact your system administrator to obtain access to any needed reports or forms.

## Printing the List of Planning Recommendations { .section}

To prepare a printable list of the planning recommendations the system creates when you regenerate inventory planning, you can use the [Inventory Planning Display](AM_63_20_00.md) \(AM632000\) report. You can also view the list of these documents on the [Inventory Planning Display](AM_40_00_00.md) \(AM400000\) form.

## Viewing Documents That Include a Particular Stock Item { .section}

To view the list of supply and demand documents that include a specific stock item in a specific warehouse, you can use the [Inventory Planning Results by Item](AM_40_40_00.md) \(AM404000\) form. On this form, the system displays only the documents that have been created during the last inventory planning regeneration process.

## Viewing Generated Forecasts { .section}

To view the forecasts generated by using the [Generate Forecasts](AM_50_20_00.md) \(AM502000\) form, you can use the [Forecast Listing](AM_00_00_05.md) \(AM000005\) form. You can narrow the list of forecasts by item, warehouse, and customer.

## Viewing Inventory Planning Regeneration Results for Stock Items by Period { .section}

To view the results of inventory planning regeneration for a specific item–warehouse pair grouped by periods \(or buckets\), you can use the [Inventory Planning Requirements by Item](AM_40_12_00.md) \(AM401200\) form.
