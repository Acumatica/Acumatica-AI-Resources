# Sorting and Grouping Data {#_e1470ffa-0d91-4e41-afbd-181b9032dc29 .concept}

You can divide report data into groups and specify the sort order for each group, which determines how the data will be displayed. You can also specify sorting criteria for the report as a whole. In the topics of this chapter, you will learn how to specify the sorting and grouping of data in a report.
