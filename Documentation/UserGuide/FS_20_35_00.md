# Rooms {#_5950e7e4-32a5-428a-ad04-14c7507b86bc .reference}

Form ID: \(FS203500\)

You can use this form to create a room within a branch location of your company. A room is a physical space where a service can be performed, such as an office, surgery room, or classroom. To be able to use rooms in the system, you must select the **Enable Rooms** check box on the [Service Management Preferences](FS_10_01_00.md) \(FS100100\) form.

You open this form by clicking the identifier of the room, which details you want to view or edit, on the **Rooms** tab of the [Branch Locations](FS_20_25_00.md) \(FS202500\) form.

## Form Toolbar { .section}

The form toolbar includes only standard buttons.

## Summary Area { .section}

In this area, you can assign a unique identifier to a room and specify its description. To define a new room, you select the branch location and then specify the room identifier and its description. To bring up an existing room, you select the branch location and the room identifier.

|Element|Description|
|-------|-----------|
|**Branch Location ID**|The unique identifier of the branch location of the room. If you are creating a new room, select the branch location to which the room belongs.|
|**Room ID**|The unique identifier of the room. If you are creating a new room, specify a new identifier up to 10 symbols.|
|**Description**|A description of the room.|
|**Floor Nbr.**|The floor where the room is.|
