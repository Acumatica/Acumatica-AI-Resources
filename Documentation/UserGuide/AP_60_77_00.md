# Subcontractor Deduction Statement

Form ID: \(AP607700\)

You use this report to generate a deduction statement under the Construction Industry Scheme \(CIS\) for a subcontractor. The report produces the statement as a PDF document formatted for standard A4 paper.

This report is available if the *UK Localization* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameters

On the **Report Parameters** tab, you use the following parameters to select the information to be displayed on the report:

-   **Contractor**: The company or branch that acts as the contractor for the deduction statements.

    By default, this box contains the current company or branch. The lookup table for this box includes only the companies and branches that have submitted a CIS return in any tax period. If the report is opened by clicking the **Deduction Statement** button on the [Submit CIS Return](AP_50_77_00.md) \(AP507700\) form, it inherits that form's contractor.

-   **Tax Period**: The tax period for which the deduction statements are generated.

    By default, this box contains the last tax period that has a submitted CIS return for the selected contractor. The lookup table for this box includes only the tax periods that have a submitted CIS return for the selected contractor.

-   **Subcontractor**: The subcontractor for which a deduction statement is generated.

    The lookup table for this box includes only the vendors that have the **CIS Subcontractor** check box selected on the [Vendors](AP_30_30_00.md) \(AP303000\) form. All such vendors appear in the lookup table regardless of whether they had activity in the selected tax period. If you leave this box empty, the report generates a statement for each CIS subcontractor that had payments in the selected tax period, and an empty statement for each CIS subcontractor that had no activity in the period.

-   **Duplicate Statement**: A check box that you select to print *DUPLICATE STATEMENT* on the generated deduction statements. By default, this check box is cleared.
