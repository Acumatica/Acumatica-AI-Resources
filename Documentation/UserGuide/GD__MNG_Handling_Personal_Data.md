# Handling Personal Data {#_11cd9736-be54-4791-8bd2-d09a5f0509aa .concept}

Because Acumatica ERP holds the personal data of individuals, it should be able to comply with the requirements of the General Data Protection Regulation \(GDPR\). Acumatica ERP provides GDPR compliance tools that simplify the handling of personal data and give you the ability to protect personal data and restrict its processing, if needed.
