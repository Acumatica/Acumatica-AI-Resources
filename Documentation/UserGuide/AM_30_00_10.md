# Select Production Orders

Form ID: \(AM300010\)

This form is invoked from the [Materials](AM_30_00_00.md) \(AM300000\) form and is not a menu item. The steps you perform on this form are part of the process that does not do any updating of the production order or inventory but is a tool to facilitate the creation of the actual material issues. If you are using allocations for production materials you can also use the [Unreleased Material Allocations](AM_30_55_00.md) \(AM305500\) form to create a materials batch particularly when you have created purchase orders from the [Critical Materials](AM_40_10_00.md) \(AM401000\) form.

It will create a list of open material requirements for production orders in a *Released*, *In Process*, or *Closed* status with a remaining quantity to produce.

By entering in a different *Quantity to Produce* in the Wizard, it will recalculate the necessary components based on making a quantity that is less than what the production order requires. This allows you to release only the materials you need for the quantity currently being produced.
