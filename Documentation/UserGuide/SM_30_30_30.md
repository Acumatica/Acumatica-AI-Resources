# OpenID Connect Preferences {#_53955d0e-e2f3-4d78-832e-d2e762d97771 .reference}

Form ID: \(SM303030\)

You use this form to review the existing keys that Acumatica ERP uses for signing and validating JSON Web Tokens \(JWTs\). By using this form, you can also generate a new key that Acumatica ERP will use for signing JWTs. At this, the former active key becomes invalid for signing JWTs and can be deactivated for validating JWTs immediately, or after some period.

Acumatica ERP uses the last generated key for signing JWTs. Acumatica ERP validates a JWT with active keys one by one until it finds the key that signed the JWT.

**Attention:** The form is available if the *OpenID Connect* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar and More menu include the buttons and commands described below.

|Command|Description|
|-------|-----------|
|**Generate New Key**|Opens the **Generate New Key** dialog box, where you can either deactivate the former active key immediately or specify the period for its deactivation, and click **OK**.|

|Element|Description|
|-------|-----------|
|**Deactivate Old Key Immediately**|The check box that indicates whether the former key must be deactivated immediately. If the check box is selected, the **Expiration Period for Old Key \(Days\)** box is unavailable.|
|**Expiration Period for Old Key \(Days\)**|The period \(in days\) after which the former key will expire for validating JWTs.|
|The dialog box has the following buttons.|
|**OK**|Closes the dialog box and prepares data as follows: generates a new key, deactivates the former key for signing JWTs, and sets the expiration period for deactivating the former key for validating JWTs. These changes will come into effect after the data is saved on the form. Alternatively, you can cancel the changes.|
|**Cancel**|Closes the dialog box without generating a new key.|

## Keys Section { .section}

You use the table in the **Keys** section to review the available keys.

|Column|Description|
|------|-----------|
|**Signing Key**|The check box that indicates whether the key is valid for signing JWTs.|
|**Key ID**|The identifier of the key.|
|**Creation Date \(UTC\)**|The date and time when the key was created.|
|**Expiration Date \(UTC\)**|The date and time when the key expires. Expired keys remain in the table and are not deleted automatically.|
