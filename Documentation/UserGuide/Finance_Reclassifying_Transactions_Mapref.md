# Reclassifying Transactions {#_31491479-f6ad-4a11-9374-63de6256dbd5 .concept}

If the batch was posted to the wrong GL account, subaccount, or branch, you can correct it by reclassifying the batch.

In this chapter, you will find general information on how to reclassify transactions, a checklist for system implementation, an activity that describes how to reclassify transactions in the system, and reports and inquiries that can be useful to find and view related transactions.
