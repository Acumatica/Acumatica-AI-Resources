# Scan and Transfer {#_a110f8a7-acca-496f-98e9-8f5f84f42279 .reference}

Form ID: \(IN304020\)

By using this form, you can transfer inventory items between locations in the same warehouse or between warehouses located in the same building by scanning barcodes for the origin and destination locations and the inventory items to be transferred. All of this information is reflected on the form as you work in a new inventory transfer. When you have scanned all items and the information on the form is correct, you scan the barcode to release this inventory transfer. You can view the released inventory transfer on the [Transfers](IN_30_40_00.md) \(IN304000\) form.

**Note:** This form is available only if the *Inventory Operations* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Reset**|Resets the processing flow for the current inventory transfer document, keeping the warehouse and reference number, and preserving the confirmed lines on the **Transfer** tab. The system does not preserve any unconfirmed lines that were in progress.|
|**OK**|Confirms the line that is currently being processed.

 This button is displayed only when the **Use Explicit Line Confirmation** check box is selected on the [Inventory Preferences](IN_10_10_00.md) \(IN101000\) form.

|
|**Remove**|Activates Remove mode, in which you can remove the specified item quantity for the currently selected line.|
|**Set Qty,**|Specifies the quantity you have entered as the quantity for the currently selected line if the **Use Default Quantity in Transfers** check box is cleared on the [Inventory Preferences](IN_10_10_00.md) \(IN101000\) form; specifies the quantity you have entered for the current line as the default quantity to be used in all lines of the current document if the **Use Default Quantity in Transfers** check box is selected on the form.|
|**Release**|Releases the inventory transfer document you are currently processing.|
|**User Settings**|Opens [Table 1](#_bad98671-d837-4818-9ff4-25da051a7023), in which you can specify your personal user settings for the current working mode.|

|Element|Description|
|-------|-----------|
|**Default Warehouse from User Profile**|A check box that indicates \(if selected\) that the system copies a warehouse to the **Warehouse** box from the **Default Warehouse** box of the [User Profile](SM_20_30_10.md) \(SM203010\) form for the user account to which you are signed in.

 The default value of this check box is copied from the check box of the same name on the [Inventory Preferences](IN_10_10_00.md) \(IN101000\) form. You can change the check box value for the current working mode.

|
|**Use Default Lot/Serial Nbr.**|A check box that indicates \(if selected\) that the system automatically inserts an available lot or serial number of an item when the user scans the item barcode.

 If the check box is cleared, a user must scan the barcode of the lot or serial number after scanning the item barcode.

 This check box is available only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) form.

|
|The dialog box provides the following buttons.|
|**Save**|Applies your selected options and closes the dialog box.|
|**Cancel**|Closes the dialog box without applying any changes you have made.|

## Summary Area { .section}

This area displays the warehouse you scanned, the reference number of the inventory transfer \(when the system fills it in\), and the results of barcode scanning as you work.

|Element|Description|
|-------|-----------|
|**Scan**|A box in which you can enter commands to initiate operations and switch between working modes. The results of barcode scanning are also entered automatically into this box. This is the only entry box on the form.

 For the list of commands supported in each mode, see [Working Modes and Supported Commands](WMS_Commands_List.md).

|
|**Reference Nbr.**|The reference number of the inventory transfer document. The system inserts this number for a new inventory transfer document after you add lines and click **Save** or **Release** on the form toolbar.|
|**Warehouse**|The warehouse in which you are transferring inventory items. If a default warehouse is specified in your user profile on the [User Profile](SM_20_30_10.md) \(SM203010\) form, the system inserts your default warehouse in this box.|
|Notification Area|An area that displays information that is pertinent to what you are doing, which can be any of the following:-   The result of the last operation
-   The next suggested operation

|

## Transfer Tab { .section}

This tab shows the lines of the inventory transfer document that is currently being processed.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Inventory ID**|The identifier of the inventory item in the inventory transfer you are currently processing.|
|**Description**|The description of the inventory item.|
|**Lot/Serial Nbr.**|The lot or serial number of the inventory item \(if applicable\).

 This column is displayed only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Expiration Date**|The expiration date of the item \(if applicable\).

 This column is displayed only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Location**|The origin location in the selected warehouse where the inventory item is stored.|
|**To Location ID**|The destination location in the selected warehouse to which the inventory item will be transferred.|
|**Reason Code**|The reason code for the inventory transfer.|
|**Quantity**|The quantity of the inventory item to be transferred. It is always *1* for items with serial numbers.|
|**UOM**|The unit of measure for the inventory item.|

## Scan Log { .section}

This tab displays the history of the most recent performed operations in the current working mode. The log is cleared when you close the form or switch to another working mode.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**Time**|The date and time when the operation was performed.|
|**Mode**|The working mode that was active when the system was performing the operation.|
|**Prompt**|The message describing the operation to be performed \(as was shown in the notification area\).|
|**Scan**|The command that was entered in the **Scan** box, or the barcode that was scanned.|
|**Message**|The result of the operation \(as was shown in the notification area\).|
