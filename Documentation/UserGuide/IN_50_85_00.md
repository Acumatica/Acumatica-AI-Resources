# Calculate Replenishment Parameters

Form ID: \(IN508500\)

**Attention:** This form is available only if the *Inventory Replenishment* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. This form only displays items where *Inventory Replenishment* has been specified as the planning method.

You use this form to calculate replenishment parameters for the stock items for which automated replenishment was configured in your system. The system calculates the parameters according to the selected demand forecast model and the seasonality settings assigned to each item on the **Replenishment** tab of the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form.

**Attention:** If the *Project-Specific Inventory* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form, the system calculates replenishment quantity and lead time only for stock items whose quantities are not tracked for a project. That is, if a stock item is included in a project for which on the **Summary** tab of the [Projects](PM_30_10_00.md) \(PM301000\) form, *Track by Project Quantity* or *Track by Project Quantity and Cost* is selected in the **Inventory Tracking** box, the project's item quantity is excluded from the replenishment quantity.

For more information, see [Replenishment for Stock Items](../ImplementationGuide/config_OrderMgmt_Replenishment_Mapref.md) and [Configuration of Replenishment: Example of Parameter Calculation](../ImplementationGuide/config_OrderMgmt_Replenishment_Calculation_Example.md).

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|For the items you have selected in the table, calculates the replenishment parameters according to the demand forecast method assigned to the item on the [Stock Items](IN_20_25_00.md) \(IN202500\) form.|
|**Process All**|Calculates the replenishment parameters for all items listed in the table.|
