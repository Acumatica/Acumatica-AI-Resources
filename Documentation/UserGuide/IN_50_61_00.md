# Update Movement Classes {#_8c13461c-bb60-4b9c-9600-69818b363d89 .reference}

Form ID: \(IN506100\)

**Attention:** This form is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

You use this form to calculate and update movement class assignments for stock items at a particular warehouse. The calculation of movement classes is based on the items’ turnover during the selected period.

When a movement class is calculated, the system records this class in the database for the item, the warehouse, and the period of the calculation. If you select a warehouse and an end period in the Selection area and the system finds the recorded calculation of the movement class for this warehouse and period, it shows each item’s calculated movement class in the **Projected Movement Class** column.

When you update movement class assignments on this form, the system assigns the projected movement class to each item, based on the movement class definitions on the [Movement Classes](IN_20_86_00.md) \(IN208600\) form.

**Attention:** If a stock item has no transactions in the selected period, the projected movement class is not calculated, and the current movement class is not updated for this item on the current form.

You can review and manually change the assigned movement class of the item in a particular warehouse on the **General** tab of the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form.

For more information on calculation of movement classes, see [Inventory Ranking Methods](IN__con_Inventory_Ranking_Methods.md).

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates processing \(based on the action you select\) for the stock items you have selected in the table.|
|**Process All**|Initiates processing \(based on the action you select\) for all stock items listed in the table.|

## Selection Area {#1 .section}

In this area, you select the warehouse where the movement class assignments will be updated and the range of financial periods that will be used to calculate the movement class. You can also narrow down the list of items to be processed by the class of the items or by selecting a specific item or list of items.

|Element|Description|
|-------|-----------|
|**Action**|The action to be taken on each processed stock item if you click **Process** or **Process All** on the form toolbar. Select one of the following options:

 -   *Calculate Movement Class*: The system calculates the movement classes to be assigned to the processed inventory items and displays them in the **Projected Movement Class** column.
-   *Calculate and Update Movement Class*: The system calculates the movement classes to be assigned to the processed stock items and updates the movement classes of the items. When the processing is completed, both the **Current Movement Class** column and the **Projected Movement Class** column show the movement classes that have been calculated and assigned to the processed stock items.

|
|**Warehouse**|The warehouse in which the stock items are stored.

 The value in this box is mandatory.

|
|**End Period**|The period for which you want to calculate or update the movement classes of the stock items.

 The value in this box is mandatory. By default, the system inserts the current financial period according to the calendar defined on the [Master Financial Calendar](GL_20_10_00.md) \(GL201000\) form.

|
|**Item Class**|The class of the stock items for which you want to calculate or update the movement class.|
|**Inventory ID**|The inventory ID of a stock item for which you want to calculate or update the movement class. You can leave the box blank to process any item that meets the specified selection criteria or select a particular item to be processed.Alternatively, you can click the **List** button next to this box and compose a list of items. Once you have done this, the box contains *&lt;LIST&gt;*. \(If you clear this value, the list you composed will no longer be used.\)

|
|**List**|Opens the **Inventory Item List** dialog box so that you can add the stock items to be listed in the table and available for processing. In the dialog box, you add rows for each item you want to include; only items that meet the selection criteria are available for selection. When you have finished adding items, you simply exit the dialog box.|

## Table {#2 .section}

This table holds the read-only list of items for which the movement class assignments will be updated.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|Included|An unlabeled check box that you select to include this record in processing if you click **Process**.|
|**Inventory ID**|The stock item for which the movement class assignment can be updated.|
|**Description**|The description of the stock item.|
|**Current Movement Class**|The movement class that is currently assigned to the stock item.|
|**Fixed**|A read-only check box that indicates \(if selected\) that the movement class is fixed for the stock item, which means that its movement class assignment cannot be updated. The state of this check box is copied from the **Fixed Movement Class** check box in the **Physical Inventory** section on the [Stock Items](IN_20_25_00.md) \(IN202500\) form.|
|**Projected Movement Class**|The movement class to be assigned to the stock item.|
