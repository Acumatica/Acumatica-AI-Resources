# Storage Summary {#_ff039591-b8d1-4313-9578-6e198a26e195 .reference}

Form ID: \(IN409010\)

You can use this form to view a list of inventory items in a particular warehouse and filter these items by any of the following: the particular storage location or cart, the specific inventory item, and the lot or serial number of the inventory item. This form is useful, for example, in the following cases:

-   For a particular inventory item, you can view the locations and carts where the item is stored and the quantity of this item in each location and cart.
-   For a particular location, you can view the full list of items and the quantities of these items.
-   If you use the cart-tracking functionality, for a particular cart, you can view the list of items and the quantities of these items.

**Attention:** This form is available only if the *Multiple Warehouse Locations* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Selection Area { .section}

In this area, you can select settings to narrow the list of inventory items.

|Element|Description|
|-------|-----------|
|**Warehouse**|Required. The warehouse that contains the items to be displayed in the table.|
|**Expand by Lot/Serial Number**|A check box that indicates \(if selected\) that the system displays the lot or serial number and expiration date of the inventory item in the table, and that the **Lot/Serial Nbr.** box is available for editing in the Selection area.|
|**Location**|The identifier of the warehouse location that contains the items to be displayed in the table. If you select a location, the system will display only the items that are stored in this warehouse location.|
|**Cart**|The identifier of the cart that contains the items to be displayed in the table. If you select a cart, the system will display only the items that are stored in this cart.

 This box is displayed only if the *Cart Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Inventory ID**|The identifier of the inventory item for which the system is displaying data in the table. Select an item if you want the table to display the data for only this item in the warehouse.|
|**Lot/Serial Nbr.**|The lot or serial number of an item to be displayed in the table. Specify a lot or serial number of an inventory item if you want the table to display the data for only the item with that number in the warehouse.

 This box is available for editing only if the **Expand by Lot/Serial Number** check box is selected.

 This box is displayed only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|

## Table { .section}

In this table, you can view the list of inventory items that meet the selection criteria you specified in the Selection area, as well as basic settings for each item.

|Column|Description|
|------|-----------|
|**Warehouse**|The warehouse where the inventory item is stored.|
|**Storage ID**|The identifier of the storage location or cart where the inventory item is stored.|
|**Inventory ID**|The identifier of the inventory item.|
|**Description**|The description of the inventory item.|
|**Qty. On Hand**|The quantity of the inventory item that is on hand.|
|**Qty. Picked to Carts**|The quantity of the inventory item that has been picked to carts.

 This column is displayed only if the **Location** check box is selected in the Selection area and the *Cart Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Base Unit**|The base unit of measure for the inventory item.|
|**Lot/Serial Nbr.**|The lot or serial number of the inventory item.

 This column is filled in only if the **Expand by Lot/Serial Number** check box is selected in the Selection area.

 This column is displayed only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Expiration Date**|The expiration date of the item \(if applicable\).

 This column is filled in only if the **Expand by Lot/Serial Number** check box is selected in the Selection area.

 This column is displayed only if the *Lot and Serial Tracking* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
