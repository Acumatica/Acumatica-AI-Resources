# Reclassifying Project Transactions

Correcting a misclassified project expense usually means reversing the original transaction and recreating it from scratch. If a released project transaction has to be moved to another project or project task or its settings need to be corrected, you can reclassify the transaction and update its project, billing, inventory, or accounting information.

This chapter shows you how to load eligible transactions, specify their target values, and process the reclassification.
