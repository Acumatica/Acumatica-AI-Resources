# Integrating with LLM Providers {#_f2c4890d-00d1-4069-be36-7e16a531a9a5 .concept}

Once you’ve deployed a large language model \(LLM\) through a provider, you want to make the most of it. Through *AI Automation*—a tool that connects your LLM to the system—you can support users’ everyday tasks directly in Acumatica ERP.

In this chapter, you’ll learn how to integrate Acumatica ERP with your LLM to do the following:

-   Work with and test prompts
-   Generate text
-   Create commands
-   Update records
-   Generate new values for boxes and columns
