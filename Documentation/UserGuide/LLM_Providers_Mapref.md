# Integrating with LLM Providers

Once you’ve deployed a large language model \(LLM\) through a provider, you want to make the most of it. Through *AI Automation*—a functionality that connects your LLM to the system—you can support users’ everyday tasks directly in Acumatica ERP.

You can also include agents in configured business processes so that they run in response to a data change, a schedule, an import, or a workflow action.

In this chapter, you’ll learn how to integrate Acumatica ERP with your LLM to do the following:

-   Configure and test agent LLM connections
-   Create and test agents
-   Create reusable system instructions for agents
-   Use tools that retrieve and update the current record
-   Add generic inquiries as agent data sources
-   Mask sensitive field values retrieved from the current record
-   Review results, processing logs, and provider token statistics
-   Make agents available as commands and invoke agent actions from configured processes
