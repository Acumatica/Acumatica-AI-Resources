# Update Contacts {#_de0846a3-f87e-4714-acef-88e01abacb0a .reference}

Form ID: \(CR503021\)

On this form, you can mass-update contact records by selecting the settings you want to update in the **Mass Update** wizard.

## Form Toolbar { .section}

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the update process for the contacts that you have selected in the table. When you click this button, the **Update Contacts** wizard opens, which you use to update a setting or multiple settings in the selected contacts.|
|**Process All**|Initiates the update process for all contacts listed in the table. When you click this button, the **Update Contacts** wizard opens, which you use to update a setting or multiple settings in all the listed contacts.|

## Update Contacts Wizard { .section}

You can use this wizard to update a setting or multiple settings in the contacts. You can open the wizard in one of the following ways:

-   By selecting a record or multiple records in the table and clicking **Process** on the form toolbar
-   By clicking **Process All** on the form toolbar

This wizard consists of two pages with the elements and attributes of the contacts that you might want to update, and a review page with the changes the system will apply to the selected contacts if you click **Finish**.

|Element|Description|
|-------|-----------|
|Included|An unlabeled check box that you can select to cause the system to insert the value you specify for this element in all processed contacts.|
|**Field**|The name of the element whose value or state you can update in the processed contacts if you select the unlabeled check box and specify a new value or state.|
|**Value**|The value \(or state\) that will be applied to the element in the processed contacts if the element is selected.|
|To proceed, you click one of the following buttons.|
|**Next**|Goes to the next page of the wizard.|
|**Cancel**|Closes the wizard and cancels any changes.|

|Element|Description|
|-------|-----------|
|Included|An unlabeled check box that you select to cause the system to insert the value you specify for this attribute in all processed contacts.|
|**Field**|The name of the attribute whose value or state you can update in the processed contacts if you select the unlabeled check box and specify a new value or state.|
|**Value**|The value \(or state\) of the attribute that will be applied to the processed contacts if this attribute is selected.|
|**Required**|A check box that you can select to make the attribute required for the selected contacts.|
|To proceed, you click one of the following buttons.|
|**Next**|Goes to the next page of the wizard.|
|**Prev**|Goes to the previous page of the wizard.|
|**Cancel**|Closes the wizard and cancels any changes.|

|Element|Description|
|-------|-----------|
|Change area|An area where you can view all the changes that you are going to apply to the processed contacts.|
|To proceed, you click one of the following buttons.|
|**Finish**|Closes the wizard and applies the changes to the processed contacts.|
|**Prev**|Goes to the previous page of the wizard.|
|**Cancel**|Closes the wizard and cancels any changes.|

## Table { .section}

This table contains the list of all contacts. If a reusable filter has been applied, the table lists the contacts that meet the conditions of the filter.

|Column|Description|
|------|-----------|
|Selected|An unlabeled check box that you select to include the contact in processing if you click **Process**.|
|**Contact**|The name of the contact, which is a link you can click to open the [Contacts](CR_30_20_00.md) \(CR302000\) form in a pop-up window and view the details of the contact.|
|**Title**|The contact's courtesy title, which is one of the following options: *Dr.*, *Miss*, *Mr.*, *Mrs.*, *Ms.*, or *Prof.*|
|**First Name**|The first name of the contact.|
|**Last Name**|The last name of the contact.|
|**Job Title**|The job title of the contact.|
|**Duplicate**|The duplicate validation status of the contact.

 This column is displayed on the form only if the *Duplicate Validation* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Business Account**|The business account that the contact is associated with.|
|**Account Name**|The business name of the contact's company.|
|**Parent Business Account**|The identifier of the parent business account, if applicable.|
|**Parent Business Account Name**|The business name of the parent business account, if applicable.|
|**Active**|A check box that indicates \(if selected\) that the contact is active, which means that it appears in all **Contact** lookup tables, and can be selected in documents and other records.|
|**Status**|The status of the contact.

 This box contains one of the following options:

 -   *Active*: The contact is active, appears on all **Contact** lookup tables, and can be used in documents.
-   *Inactive*: The contact is inactive and cannot be specified in documents and other records.

|
|**Reason**|The reason the status of this contact has been changed.|
|**Contact Class**|The identifier of the contact class to which the contact belongs.|
|**Source**|The source of the contact.|
|**State Name**|The state of the contact.|
|**Country**|The country of the contact.|
|**City**|The city of the contact.|
|**Postal Code**|The postal code of the contact.|
|**Address Line 1**|The first line of the contact's address.|
|**Address Line 2**|The second line of the contact's address.|
|**Email**|The email address of the contact.|
|**Phone 1**|The primary phone number of the contact.|
|**Phone 2**|The secondary phone number of the contact.|
|**Phone 3**|Another phone number of the contact.|
|**Fax**|The fax number of the contact.|
|**Workgroup**|The workgroup for the contact.|
|**Owner**|The owner of the contact.|
|**Last Incoming Activity**|The date of the latest incoming activity that is associated with the contact.|
|**Last Outgoing Activity**|The date of the latest outgoing activity that is associated with the contact.|
|**Created On**|The date when the contact record was created.|
|**Last Modified On**|The date when the contact record was modified most recently.|
