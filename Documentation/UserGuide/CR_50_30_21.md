# Update Contacts

Form ID: \(CR503021\)

On this form, you can mass-update contact records by selecting the settings you want to update in the **Mass Update** wizard.

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Process**|Initiates the update process for the contacts that you have selected in the table. When you click this button, the **Update Contacts** wizard opens, which you use to update a setting or multiple settings in the selected contacts.|
|**Process All**|Initiates the update process for all contacts listed in the table. When you click this button, the **Update Contacts** wizard opens, which you use to update a setting or multiple settings in all the listed contacts.|

## Update Contacts Wizard

You can use this wizard to update a setting or multiple settings in the contacts. You can open the wizard in one of the following ways:

-   By selecting a record or multiple records in the table and clicking **Process** on the form toolbar
-   By clicking **Process All** on the form toolbar

This wizard consists of two pages with the elements and attributes of the contacts that you might want to update, and a review page with the changes the system will apply to the selected contacts if you click **Finish**.

|Element|Description|
|-------|-----------|
|Included|An unlabeled check box that you can select to cause the system to insert the value you specify for this element in all processed contacts.|
|**Field**|The name of the element whose value or state you can update in the processed contacts if you select the unlabeled check box and specify a new value or state.|
|**Value**|The value \(or state\) that will be applied to the element in the processed contacts if the element is selected.|
|To proceed, you click one of the following buttons.|
|**Next**|Goes to the next page of the wizard.|
|**Cancel**|Closes the wizard and cancels any changes.|

|Element|Description|
|-------|-----------|
|Included|An unlabeled check box that you select to cause the system to insert the value you specify for this attribute in all processed contacts.|
|**Field**|The name of the attribute whose value or state you can update in the processed contacts if you select the unlabeled check box and specify a new value or state.|
|**Value**|The value \(or state\) of the attribute that will be applied to the processed contacts if this attribute is selected.|
|**Required**|A check box that you can select to make the attribute required for the selected contacts.|
|To proceed, you click one of the following buttons.|
|**Next**|Goes to the next page of the wizard.|
|**Prev**|Goes to the previous page of the wizard.|
|**Cancel**|Closes the wizard and cancels any changes.|

|Element|Description|
|-------|-----------|
|Change area|An area where you can view all the changes that you are going to apply to the processed contacts.|
|To proceed, you click one of the following buttons.|
|**Finish**|Closes the wizard and applies the changes to the processed contacts.|
|**Prev**|Goes to the previous page of the wizard.|
|**Cancel**|Closes the wizard and cancels any changes.|
