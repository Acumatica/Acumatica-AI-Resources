# ABC Codes

Form ID: \(IN208500\)

**Attention:** This form is available only if the *Advanced Physical Count* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

This form holds the definitions of the ABC codes used to group inventory items for various inventory management tasks. In Acumatica ERP, ABC analysis is based on the relative stock values of inventory items. For each code to be used in your system, you can specify the threshold value of the criteria to be used to assign items to it, and the frequency of physical counts required for inventory items assigned to it.

To assign codes for the first time or to update code assignment for items at a particular warehouse, based on the stock values for the selected financial period, use the [Update ABC Codes](IN_50_60_00.md) \(IN506000\) form. For details on using ABC codes, see [Inventory Ranking Methods](IN__con_Inventory_Ranking_Methods.md) and [Configuration of Physical Inventory](IN__con_Planning_for_Physical_Inventory.md).

## Form Toolbar

The form toolbar has only standard buttons.

## Table

|Column|Description|
|------|-----------|
|**ABC Code**|The code defined in the system.|
|**Description**|A brief description of the code.|
|**Counts Per Year**|The number of physical counts to be performed per year for the items with this code assigned.|
|**ABC Code %**|A threshold value \(%\) of the criteria to be used to assign the inventory items to this code. For details, see [Inventory Ranking Methods](IN__con_Inventory_Ranking_Methods.md).|

|Element|Description|
|-------|-----------|
|**Total ABC Code %**|The total percentage of the criteria used to assign inventory items to all ABC codes, 100%.|
