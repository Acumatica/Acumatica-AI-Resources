# Discrepancies by Account

Form ID: \(AP409010\)

You can use this form to find any discrepancies between AP and GL accounts in a particular range of financial periods. This table shows the list of accounts that meet the criteria you have specified and that were updated within the specified range of periods.

## Form Toolbar

The form toolbar has only standard buttons.

## Selection Area

In this area, you select the settings that determine the AP accounts \(and their discrepancies, if applicable\) to be listed in the table.

## Table

This table contains the list of accounts that were updated within the specified range of financial periods, one row for each account that was updated and each financial period of update, including any discrepancies associated with each account in the date range.

The amount of the transactions posted to the account listed in this row by subledgers other than accounts payable.

The discrepancy between the GL turnover, according to GL records, and the AP turnover, which is based on accounts payable documents \(excluding the amount of the transactions posted by non-AP subledgers, which is displayed in the **Non-AP Transactions** column\).

 If you click this link, the system opens the [Discrepancies by Vendor](AP_40_90_20.md) \(AP409020\) form in a separate window, where you can review the list of the vendors for which at least one document has been created that caused this discrepancy.
