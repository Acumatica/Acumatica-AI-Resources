# Project Summary {#_b9a88a51-3f6d-4ba1-a821-f765cdda5ba7 .reference}

Form ID: \(PMGI0025\)

**Attention:** This form is available only if the *Construction* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

The inquiry lists the projects with their cost budget amounts, revenue budget amounts, change order amounts, estimated amounts, and calculated profits.

## Table Toolbar {#section_lkm_nfz_tmb .section}

The table toolbar has only standard buttons.

## Selection Area { .section}

You use the element in this area to select the project manager of the projects to be displayed.

|Element|Description|
|-------|-----------|
|**Project Manager**|The project manager whose commitments you want to view. If you want to see the commitments associated with projects assigned to all project managers, leave this box blank.|

## Table {#section_hd4_yfz_tmb .section}

The table shows the list of projects, along with detail information about each project. The table has the following columns.

|Column|Description|
|------|-----------|
|**Project**|The unique identifier of the project.|
|**Description**|The description provided for the project.|
|**Project Manager**|The project manager associated with the project.|
|**Project Currency**|The project currency.

 This column is available if the *Multicurrency Projects* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|
|**Revised Estimate**|The sum of the revised budgeted amounts of the project cost budget.|
|**Costs to Date**|The sum of the actual amounts of the project cost budget through the current business date.|
|**Open Committed Costs**|The sum of the open committed amounts of the project cost budget.|
|**Remaining Estimate**|The remaining expense amount for the project, which is the difference between the revised budgeted costs and the actual and open committed amounts for the project.|
|**Remaining Estimate %**|The percentage of the remaining expense amount for the project \(which is the ratio of the **Remaining Estimate** to the revised budgeted amount of the project cost budget\).|
|**Original Budgeted Amount**|The sum of the original budgeted amounts of the project revenue budget.|
|**Budgeted CO Amount**|The sum of the change order amounts of the project revenue budget.|
|**Revised Budgeted Amount**|The sum of the revised budgeted amounts of the project revenue budget.|
|**Billed to Date**|The sum of the actual amounts of the project revenue budget through the current business date.|
|**Est. Gross Profit**|The originally planned profit for the project, which is the difference between the sum of the revised budgeted amounts of the project revenue budget and sum of the revised budgeted amounts of the cost budget.|
|**Est. Gross Profit %**|The percentage of the originally planned profit for the project that has been reached \(that is, the ratio of the difference between the sum of the revised budgeted amounts of the project revenue budget and sum of the revised budgeted amounts of the cost budget\).|
|**Original Estimate**|The sum of the original budgeted amounts of the project cost budget.|
