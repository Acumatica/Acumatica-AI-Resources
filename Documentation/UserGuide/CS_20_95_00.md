# Shipping Zones {#_1e3dfbc0-0a99-41b7-bec8-f8cb8a81288c .reference}

Form ID: \(CS209500\)

You use this form to create and maintain the list of shipping zones used for the following purposes:

-   To calculate freight charges when your company ships goods to customers
-   To provide the system with information about the countries and states included in a shipping zone when you orchestrate a sales order.

**Attention:** This form is available only if the *Order Orchestration* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form. It replaces the [Shipping Zones](CS_20_75_10.md) \(CS207510\) form.

## Form Toolbar { .section}

The form toolbar has only standard buttons.

## Summary Area { .section}

In this area, you can select a zone by its ID to view its information or create a new zone.

|Button|Description|
|------|-----------|
|**Zone ID**|The unique identifier of the shipping zone.|
|**Description**|The description of the shipping zone.|

## Table {#2 .section}

The table toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Add Country/State**|Opens the **Add Country/States** dialog box in which you can select and add countries and states of the shipping zone.|

|Button|Description|
|------|-----------|
|The Selection area of the dialog box includes the following elements.|
|**Country ID**|The unique two-letter country identifier. If you select an identifier, the system displays the list of states that are specified for it on the [Countries/States](CS_20_40_00.md) \(CS204000\) form.|
|**Country Name**|The full name of the country.|
|The dialog box also has a table with the following columns.|
|**Selected**|A check box that indicates \(if selected\) that the state in this row will be added to the shipping zone's settings.|
|**State ID**|The unique identifier of the administrative unit of the country \(the state or province\).|
|**State Name**|The complete name of the administrative unit.|
|The dialog box has the following button.|
|**Add**|Adds the selected states to the shipping zone.|
|**Add&amp;Close**|Adds the selected states to the shipping zone and closes the dialog box.|
|**Cancel**|Closes the dialog box without making additions to the shipping zone.|

|Column|Description|
|------|-----------|
|**Country**|The unique two-letter country identifier. For the predefined list of countries, the identifier is the two-letter country code in accordance with international standard ISO 3166.|
|**Country Name**|The full name of the country.|
|**State**|The unique identifier of the administrative unit of the country \(the state or province\).|
|**State Name**|The complete name of the administrative unit.|
