# Archived Cost Rollups {#_60fd3665-3c8e-41f4-a57a-a14452bfa07b .reference}

Form ID: \(AM408000\)

This form displays the archived cost roll history. After you run the cost roll process on the[Process Cost Rollup Results](AM_50_80_00.md) \(AM508000\) form, you have to option to archive the data to the cost history. The archive function must be enabled on the [BOM Preferences](AM_10_10_00.md) \(AM101000\) form.

## Cost Roll History Table { .section}

The table lists all of the archived cost rolls. You can use the filter capability to reduce the list.

The table toolbar has only standard buttons.

|Column|Description|
|------|-----------|
|**BOM ID**|The ID of the bill of material whose costs were rolled up.|
|**Default BOM**|A check box that indicates \(if selected\) that this is the default bill of material for the item.

 This column is hidden by default.

|
|**Date**|The date when the cost rollup process was run.|
|**Last Updated Date Time**|The date and time the cost rollup result was archived.|
|**Warehouse**|This is the warehouse for the BOM ID.|
|**Inventory ID**|The ID of the stock item for the BOM ID.|
|**Subitem**|This column is visible only if the *Inventory Subitems* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

**Important:** The **Inventory Subitems** check box has been removed from the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form because the functionality associated with the *Inventory Subitems* feature will be phased out. If you have this feature enabled in your system, the associated functionality remains available. To disable the feature, contact your Acumatica support provider.

|
|**Unit Cost**|The new calculated unit cost.|
|**Material**|The calculated total cost of materials for the **Lot Size**.|
|**Manufactured Material**|The level total cost of all subassemblies.

 This column is hidden by default.

|
|**Purchase Material**|The level total cost of all purchased items.

 This column is hidden by default.

|
|**Fixed Labor**|The calculated total cost of setup hours x work center standard rates for the **Lot Size**.|
|**Variable Labor**|The calculated total cost of labor only x work center standard rates for the **Lot Size**.|
|**Fixed Overhead**|The total cost of fixed overhead for the **Lot Size**.|
|**Variable Overhead**|The total cost of variable overheads for the **Lot Size**.|
|**Tools**|The total cost of tooling for the **Lot Size**.|
|**Machine**|The total cost of machines \(machine hours \* the machine per hour rate\) for the **Lot Size**.|
|**Subcontract**|The cost of materials with a material type of *Subcontract* and a subcontract source of *Purchase*, *Purchase and Move* or *Ship to Vendor*.|
|**Ref. Material**|Reference materials have a material type of *Subcontract* and a subcontract source of *Vendor Supplied*. The cost of these items is not included in the product cost totals because they are supplied by the vendor.|
|**Lot Size**|The lot size used for allocating the fixed cost elements. The value is copied from the **Lot Size** box on the on the [Stock Items](IN_20_25_00.md) \(IN202500\) or [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form. If zero, then the **Min Order Qty.** is used. If both are zero, then a lot size of *1* is used.The **Batch Size** and **Quantity Round Up** are used with the **Lot Size** to calculate the cost of each material. For more information, see [Bills of Material: Operations](BOM_Operations.md).

**Attention:** The [Item Warehouse Details](../Shared/../UserGuide/IN_20_45_00.md) \(IN204500\) form is used only if the *Multiple Warehouses* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form and the warehouse-specific settings have been specified for the item.

|
|**Current Status**|The status of the bill of material and revision.|
|**Description**|The bill of material description.|
|**Level**|The level of the assembly relative to the parent level.|
|**Fixed Labor Time**|The total setup time for this level.|
|**Variable Labor Time**|The total labor run time for this level based on the min/max/lot size values.|
|**Machine Time**|The total machine time for this level based on the min/max/lot size values.|
|**Item Class**|The item class of the stock inventory item.|
|**Current Cost**|The Item Warehouse Details Current Cost for items using the standard cost valuation method.|
|**Pending Cost**|The Item Warehouse Details Pending Cost for items using the standard cost valuation method. This value will be updated when you select **Update Pending**.|
|**Last Cost**|The last cost of the stock item used in the BOM.

 If the *Multiple Warehouses* feature is enabled on the \(CS100000\) form, this value is copied from the **Last Cost** box on the **Price/Cost** tab of the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form. If this feature is disabled, this value is copied from the **Last Cost** box on the **Price/Cost** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form.

|
|**Average Cost**|The average cost of the stock item used in the BOM.

 If the *Multiple Warehouses* feature is enabled on the \(CS100000\) form, this value is copied from the **Average Cost** box on the **Price/Cost** tab of the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form. If this feature is disabled, this value is copied from the **Average Cost** box on the **Price/Cost** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form.

|
|**Min. Cost**|The minimal cost of the stock item used in the BOM.

 If the *Multiple Warehouses* feature is enabled on the \(CS100000\) form, this value is copied from the **Min. Cost** box on the **Price/Cost** tab of the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form. If this feature is disabled, this value is copied from the **Min. Cost** box on the **Price/Cost** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form.

|
|**Max. Cost**|The maximum cost of the stock item used in the BOM.

 If the *Multiple Warehouses* feature is enabled on the \(CS100000\) form, this value is copied from the **Max. Cost** box on the **Price/Cost** tab of the [Item Warehouse Details](IN_20_45_00.md) \(IN204500\) form. If this feature is disabled, this value is copied from the **Max. Cost** box on the **Price/Cost** tab of the [Stock Items](IN_20_25_00.md) \(IN202500\) form.

|
