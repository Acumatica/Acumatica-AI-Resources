# Archived Cost Rollups

Form ID: \(AM408000\)

This form displays the archived cost roll history. After you run the cost roll process on the[Process Cost Rollup Results](AM_50_80_00.md) \(AM508000\) form, you have to option to archive the data to the cost history. The archive function must be enabled on the [BOM Preferences](AM_10_10_00.md) \(AM101000\) form.

## Cost Roll History Table

The table lists all of the archived cost rolls. You can use the filter capability to reduce the list.

The table toolbar has only standard buttons.
