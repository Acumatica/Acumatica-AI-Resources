# Access Rights by DAC

Form ID: \(SM201076\)

On this form, you can view the access rights of roles to particular data access classes \(DACs\). For more information about setting up user access rights, see [Managing User Access](SA_Managing_User_Access_Mapref.md).

## Form Toolbar

The form toolbar includes the buttons described below.

|Button|Description|
|------|-----------|
|**Open in DAC Schema Browser**|Opens the currently selected DAC in [DAC Schema Browser](DAC_Schema_Browser_Reference.md).|

## Access Rights Pane

In this pane, you can view the access rights of the roles for the selected DAC.

**Tip:** Advanced filtering functionality is available for the list of roles. For details, see [Managing Advanced Filters](GI_Reusable_Filters_Mapref.md).

<table id="table_qzw_3j5_bkc"><thead><tr><th>

Element

</th><th>

Description

</th></tr></thead><tbody><tr><td>

**Role**

</td><td>

The name of the role.

</td></tr><tr><td>

**Description**

</td><td>

A description of the role.

</td></tr><tr><td>

**Access Rights**

</td><td>

The access rights of the role for the selected object.

 Restriction levels vary by object type. For some objects, you can specify a more granular level; for others, you can either allow or deny the access. For details, see [User Roles: Restriction Level Options](../Shared/../UserGuide/User_Roles_Access_Levels.md).

</td></tr><tr><td>

**Record-type Filtering**

</td><td>

Lists the record types this role can retrieve. Effective only when the **Access determined by** box has the *Multiple Primary Screens* value.

 Possible values are:

 -   *&lt;Blank&gt;* - indicates that the role has restricted access level
-   *All* - indicates that the role has full access level
-   Comma-separated list of record types the role has access to

</td></tr></tbody>
</table>
