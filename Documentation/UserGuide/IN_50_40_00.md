# Prepare Physical Count

Form ID: \(IN504000\)

**Attention:** This form is available only if the *Inventory* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

By using this form, you can generate a physical inventory document that lists the inventory items in a particular warehouse for physical counting. You can select the physical inventory type, the warehouse \(if it is not defined by the type\), and particular warehouse locations. The method of generating the list of items to be counted is defined by the physical inventory type.

Generating a physical inventory document starts a new physical inventory \(PI\) process and "freezes" all operations with the inventory items in the specified warehouse until the physical inventory count is completed or until all the count data is entered, depending on whether the **Unfreeze Stock When Counting Is Finished** check box is selected for the physical inventory type on the [Physical Inventory Types](IN_20_89_00.md) \(IN208900\) form.

**Important:** Unfreezing stock items before releasing an adjustment may cause discrepancies in the quantity or cost of stock items.

If the selected physical inventory type is based on the **Full Physical Inventory** generation method and no particular location is selected on the **Location Selection** tab of this form, the whole warehouse will be in the frozen state; if specific locations are selected, only those locations will be in the frozen state.

## Location Selection Tab

On this tab, you can view the warehouse locations included in the physical inventory count and select any locations whose items will be excluded from the physical inventory count. This tab appears only if the *Multiple Warehouse Locations* feature is enabled on the [Enable/Disable Features](CS_10_00_00.md) \(CS100000\) form.

|Column|Description|
|------|-----------|
|**Location ID**|The warehouse location where the physical count will be performed. The structure of the warehouse is defined on the [Warehouses](IN_20_40_00.md) \(IN204000\) form.|
|**Description**|The description of the warehouse location.|

|Column|Description|
|------|-----------|
|**Location ID**|The warehouse location whose items will be excluded from the physical inventory.|
|**Description**|The description of the warehouse location.|

## Item Selection Tab

On this tab, you can view the list of inventory items and exclude particular items from the physical inventory. The system derives these items from the location-item pairs included in the physical inventory listed on the **Preview** tab.

|Column|Description|
|------|-----------|
|**Inventory ID**|The identifier of the inventory item included in the physical inventory.|
|**Description**|The description of the inventory item.|

|Column|Description|
|------|-----------|
|**Inventory ID**|The identifier of the inventory item excluded from the physical inventory.|
|**Description**|The description of the inventory item.|
