# AR Batch Register Detailed {#_718d2bcb-c4c0-4f69-a08e-428665cb77dd .reference}

Form ID: \(AR621000\)

This report displays the details of AR transactions generated during the specified financial period \(or range of periods\) that meet any other selection criteria you specify. Batch details include accounts, subaccounts, document reference numbers, and debit and credit amounts. The batches are listed by their dates.

See the following section for a description of each parameter on the **Report Parameters** tab of the report form.

## Report Parameter { .section}

You use the following parameters to select the information to be displayed on the report:

-   **Company/Branch**: The company, branch, or company group for which you want to view information. By default, the current company or branch is selected. You can select another branch, company, or company group to which you have access or leave the box blank to view information about all companies in the tenant.

    This parameter is required if the *Multiple Base Currencies* feature is enabled on the [Enable/Disable Features](../Shared/../UserGuide/CS_10_00_00.md) \(CS100000\) form.

-   **Ledger**: The ledger for which you want to display data. You must select a ledger.
-   **From Period**: The first financial period of the period range the report will cover.
-   **To Period**: The last financial period of the period range the report will cover. By default, the current financial period is used.
-   **Created By**: The user who created the batches for which you want to view information.
-   **Last Modified By**: The user who last modified the batches for which you want to view information.
-   **Include Unposted Transactions**: A check box that indicates \(if selected\) that information about unposted transactions will be included in the report. This setting takes effect if the **Automatically Post on Release** check box is cleared on the [Accounts Receivable Preferences](AR_10_10_00.md) \(AR101000\) form.
