# To Create a Case {#_098d2cfd-2ab2-437b-bd04-f1260d8f2996 .task}

In this topic, you will learn how to create and submit cases in the Acumatica Self-Service Portal. You can use the [New Case](SP_20_30_00.md) \(SP203000\) form to enter and submit cases. For more information, see [Case Management](SP__con_Case_Management.md).

## To Create a Case { .section}

1.  Open the [New Case](SP_20_30_00.md) \(SP203000\) form.
2.  Optional: In the **Contract** box, select a contract from the list.

    **Attention:** In the box, you can only see the contracts with the **Active** status.

3.  In the **Priority** box, select the case priority.
4.  In the **Class ID** box, select the case class.
5.  In the **Subject** box, enter the subject of the case.
6.  On the **Details** tab, in the text editor area, describe the problem that you are reporting.
7.  On the **Attributes** tab, select the values for the available attributes. You can also add and remove attributes.
8.  Specify the value of each attribute in the **Value** column of the **Attributes** tab.
9.  Optional: To attach files to the case, on the form title bar, click **Files** and in the **Files** dialog box, do the following:
    1.  Click **Browse**.
    2.  In the window that opens, select the needed file.
    3.  Click **Upload**. The file is uploaded to the system; notice that the information about the uploaded file is displayed in the table of the dialog box.
    4.  Close the dialog box. On the form title bar, you can see the number of attached files in parentheses right of the **Files** button.
10. Optional: To attach a note to the case, click **Notes** on the form title bar and enter the note in the **Enter Record Note** dialog box. Click **OK**.
11. On the form toolbar, click **Submit**.

When you submit the case, the created case opens on the [Case Details](SP_20_30_10.md) \(SP203010\) form. The status of the case is set to **New**.
