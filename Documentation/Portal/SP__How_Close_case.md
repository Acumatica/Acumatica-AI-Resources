# To Close a Case {#_cf7f0332-626c-4ab2-b156-ca1703dd2436 .task}

In this topic, you will learn how to close a case in the Acumatica Self-Service Portal. You can use the [Open Cases](SP_20_40_00.md) \(SP204000\) form to close a case. For more information, see [Case Management](SP__con_Case_Management.md).

## To Close a Case { .section}

1.  Open the [Open Cases](SP_20_40_00.md) \(SP204000\) form.
2.  In the Selection area, make selections to view open cases based on the user that submitted them:
    -   To view the open cases you have submitted, leave the **Me** check box selected.
    -   To view the open cases another user has submitted, clear the **Me** check box and select the user in the **Created By** box.
    -   To view all open cases submitted by the users of your company, clear the **Me** check box and leave the **Created By** box blank.
3.  Optional: In the **Contract** box, select a contract to view the cases associated with the contract, or leave the box blank to view all cases.
4.  In the **Case ID** column of the table, click the identifier of the case you want to close. The [Case Details](SP_20_30_10.md) \(SP203010\) form opens for the selected case.
5.  On the form toolbar, click **Close Case**.
6.  In the **Close Case** dialog box, click **Yes**.
