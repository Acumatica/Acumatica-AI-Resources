# Catalog {#_dc4beb0c-77a4-447f-b54b-0d0dd59c8db1 .reference}

Form ID: \(SP700000\)

On this form, you can browse the full list of items, view the descriptions of the items, search for specific items, and add the items you want to buy to your cart.

## Form Toolbar { .section}

The form toolbar includes a form-specific button.

|Button|Description|
|------|-----------|
|**Open Cart**|Goes to the [My Cart](SP_70_00_01.md) \(SP700001\) form, which displays the items you have added to your cart and the order’s subtotal.|

## Selection Area { .section}

By using this area, you can search for specific items, filter items by category, show or hide the items that are not available in stock, and monitor the amounts of the items you plan to add to your cart.

|Element|Description|
|-------|-----------|
|Cart Information area|An area that displays the quantity of items in your cart and their total cost.|
|**Find Item**|A box in which you can start typing part of the item’s identifier or description. As you type, the table displays the inventory items whose ID or description contains the string you have typed.|
|**Category**|The category whose items you want to view.|
|**Selection Total**|The total cost of the items for which the check box is selected in the **Add To Cart** column of the table.|
|**Show Available Items Only**|A check box that you select to view only items that are in stock.

 This check box is visible if the **Show Available Quantities** check box is selected on the **B2B Ordering Settings** tab of the [Portal Preferences](SP_80_00_00.md) \(SP800000\) form.

|

## Table { .section}

In this table, you can browse the items, view detailed information about available items, and make preliminary selections by selecting the check box in the **Add to Cart** column for any item. When you click the **Add to Cart** button on the table toolbar, the selected items are added to your cart.

**Attention:** You can add inventory items to the cart only if the *Inventory* feature is enabled on the Enable/Disable Features form \(CS100000\) in Acumatica ERP. If this feature is disabled, you can see the catalog and inventory items in the Self-Service Portal, but when you click the **Add to Cart** button, the system will display a warning message.

|Column|Description|
|------|-----------|
|**Refresh**|Updates the information in the table.|
|**Add to Cart**|Adds to the cart the items in the table for which you have selected the **Add to Cart** check box and specified a nonzero quantity. When each item is added to the cart, the **Add to Cart** check box is cleared for the item, and the item’s quantity is changed to *0.00* again.|

|Column|Description|
|------|-----------|
|**Add to Cart**|A check box that you select to indicate that the entered quantity of the item should be added to the cart when you click **Add to Cart** on the table toolbar.

 Note that when you select this check box, it is a preliminary selection until you click the **Add to Cart** button: The item is not yet added to the cart, but the amount in the **Total** column is included in the **Selection Total** in the Selection area.

|
|**Qty.**|The quantity of units of the item to be added to your cart, measured in the unit of measure specified in the **Unit** column.

 By default, the column contains *0.00*. You must specify the needed quantity before you add the item to the cart.

|
|**Inventory ID**|The identifier of the stock or non-stock item available for purchase.

 You can click the ID to open the **Item Details** dialog box and view the detailed description of the item.

|
|**Description**|A description of the item.|
|**Price**|The price of a single unit of the item.|
|**Unit**|The unit of measure \(UOM\) used for the item. If multiple units are available, you can view the available UOMs and select the one that you need.|
|**Discount Pct, %**|The percent of the discount based on the line amount or quantity.|
|**Discount Amt.**|The discount amount based on the line amount or quantity.|
|**Total**|The amount calculated for the item, which is the unit price multiplied by the quantity.|
|**All Warehouses**|The quantity of the item available in all warehouses.|
|**This Warehouse**|The quantity of the item that is available in the warehouse specified in the **Warehouse** column.

 **Attention:** This column appears on the form if the *Multiple Warehouses* feature is enabled on the Enable/Disable \(CS100000\) form in Acumatica ERP.

|
|**Warehouse**|The default warehouse from which the specified item should be delivered.

 The default warehouse for your company is inserted in this column if both of the following conditions are met on the [Portal Preferences](SP_80_00_00.md) \(SP800000\) form \(the **B2B Ordering Settings** tab\):

 -   The **Include in Warehouse List** check box is selected for the warehouse in the table.
-   The warehouse is selected as the default one in the **Default Stock Item Warehouse** or **Default Non-Stock Item Warehouse** box \(the **General Settings** section\).

**Attention:** These boxes appear on the [Portal Preferences](SP_80_00_00.md)form if the *Multiple Warehouses* feature is enabled on the Enable/Disable \(CS100000\) form in Acumatica ERP.


 You can select another warehouse in the column from the list of available warehouses.

 **Attention:** This column appears on the form if the *Multiple Warehouses* or *Multiple Warehouse Locations* feature is enabled \(or both features are enabled\) on the Enable/Disable \(CS100000\) form in Acumatica ERP.

|

|Element|Description|
|-------|-----------|
|The dialog box contains the following areas and elements.|
|Image area|An area where you can view any images associated with the item. You can click the arrows to the right and to the left of the image to view additional images.

 The images for the item are specified in Acumatica ERP in the Image area of the Stock Items \(IN202500\) or Non-Stock Items \(IN202000\) form \(**Attributes** tab\).

|
|Description area|The detailed description of the item.

 The description of the item is specified in Acumatica ERP on the **Description** tab of the Stock Items \(IN202500\) or Non-Stock Items \(IN202500\) form.

|
|The dialog box also has the **Attributes** table, where you can view any attributes that apply to the item and their values.

 The attributes listed in the table are those specified for the item class, and their values have been specified for the item on the **Attributes** tab of the Stock Items \(IN202500\) or Non-Stock Items \(IN202000\) form in Acumatica ERP.

 This table has the following columns.

|
|**Attribute**|The attribute available for this item.|
|**Value**|The value of the attribute that has been specified for the item.|
|The dialog box also has elements you can use to add the item to your cart.

 You specify the quantity of the item \(and the unit of measure, if the item can be purchased in different units\); you then click the **Add to Cart** button.

|
|**Qty.**|The quantity of this item that you want to add to your cart.|
|**Unit**|The unit of measure of the item you are adding to your cart.|
|**Add to Cart**|A button that you click to add the item to your cart in the specified quantity and unit of measure.|
