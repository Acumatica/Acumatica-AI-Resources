# To Add Items to the Shopping Cart {#_a1667632-fb11-49a1-97bb-6e4d11fac30d .task}

In this topic, you will learn how to browse the catalog and add selected items to the shopping cart in the Acumatica Self-Service Portal.

**Attention:** You can view the [Catalog](SP_70_00_00.md) \(SP700000\) form and browse a catalog if you are signed in to the Self-Service Portal with a user account that has the *Customer Admin* or *Customer User* role assigned.

## To Add Items to the Cart { .section}

1.  Open the [Catalog](SP_70_00_00.md) \(SP700000\) form. In the table, view the list of items in all product categories.
2.  In the Selection area, click the **Show Available Items Only** check box to see all items that are currently available to be ordered.

    **Tip:** This check box is shown if the **Show Available Quantities** check box is selected on the **B2B Ordering Settings** tab of the [Portal Preferences](SP_80_00_00.md) \(SP800000\) form.

3.  In the table, for every item that you want to add to your cart, do the following :

    1.  Select the **Add to Cart** check box.
    2.  In the **Qty.** column, specify the quantity of the item that you want to order.
    3.  Optional: In the **Warehouse** column, select the warehouse from which you want the item to be shipped. For more information, see [To Browse the Catalog and Select a Warehouse](SP__how_Shopping_Browse_by_category.md) and [To View an Item’s Details](SP__how_Shopping_Item_details.md).
    **Tip:** In the **Selection Total** box of the Selection area, you can see the total cost of the items for which the check box is selected in the **Add to Cart** column of the table.

4.  On the table toolbar, click the **Add to Cart** button to add the selected items to the shopping cart.

    When the items have been added to your cart, in the Cart Information area of the [Catalog](SP_70_00_00.md) form, you can review the quantity and the cost of the items you added to the shopping cart.


You have browsed the catalog and added selected items to the shopping cart. Now you can continue shopping or go to the shopping cart for placing an order in the Self-Service Portal. For more information, see [Placing Orders](SP__con_Shopping_Orders.md).
