# Column Filters and Sorting {#_f70ae29b-579a-435d-b3b3-8ee61470fb9c .concept}

You can set up a column filter for almost any table to display only table rows for which this column meets particular criteria; you can then sort the data to best meet your information needs. Those filters cannot be saved and then reused at a later time.

## To Set Up a Column Filter { .section}

1.  In the table, click the column heading.
2.  Select the filter condition from the list of available conditions.
3.  In the box at the bottom of the menu, type the filter value.
4.  Click **OK** to apply the filter.

Now in the table you see only the rows that satisfy the filter condition. The column header is highlighted and displays the filter icon \(![](Images/filter_icon_filter.png)\).

You can set up filters for any number of table columns.

## To Clear a Column Filter { .section}

1.  In the table, click the column heading, and then click **Clear Filter**.
2.  Repeat Step 1 for every filter you want to turn off.

## To Turn On Column Sorting { .section}

1.  In the table, click the column heading.
2.  Select the sorting order—ascending or descending \(that is, A to Z or Z to A for text, lower to higher or higher to lower for numbers, or newest to latest or latest to newest for dates\).

The column heading displays the ascending \(![](Images/filter_icon_ascending.png)\) or descending \(![](Images/filter_icon_descending.png)\) sorting icon.

**Note:** You can turn on sorting for only one column.

## To Turn Off Column Sorting { .section}

-   In the table, click the column heading and click the sorting option you'd previously selected.

The column sorting is now turned off.
