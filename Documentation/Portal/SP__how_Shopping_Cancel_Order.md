# To Cancel an Order {#_a6593b5c-2e12-4b96-a439-b40c66e454f6 .task}

In this topic, you will learn how to cancel an order in the Acumatica Self-Service Portal. You can cancel any order that has not been processed—that is, an order with the *Open*, *On Hold*, or *On Credit Hold* status.

## To Cancel an Order { .section}

1.  In the Self-Service Portal, open the [My Orders](SP_70_00_03.md) \(SP700003\) form.

    All the orders placed with your company account are displayed in the table.

2.  Click the row with the order you want to cancel to select it; it must have the *Open*, *On Hold*, or *On Credit Hold* status.
3.  On the form toolbar, click **Cancel Order**.
4.  Review the status of the order, which is changed to *Canceled*.
