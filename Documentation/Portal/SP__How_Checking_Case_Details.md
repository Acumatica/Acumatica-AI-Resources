# To View and Edit Case Details {#_52932f80-c068-4ae5-a069-a60e8e5b1812 .task}

In this topic, you will learn how to view and modify cases with the **New** or *Open* status in the Acumatica Self-Service Portal. You can use the [Open Cases](SP_20_40_00.md) \(SP204000\) form to view or open the case.

## To View and Update the Details of an Open Case { .section}

1.  Open the [Open Cases](SP_20_40_00.md) \(SP204000\) form.
2.  In the Selection area, make selections to view open cases based on the user that submitted them:
    -   To view the open cases you have submitted, leave the **Me** check box selected.
    -   To view the open cases another user has submitted, clear the **Me** check box and select the user in the **Created By** box.
    -   To view all open cases submitted by the users of your company, clear the **Me** check box and leave the **Created By** box blank.
3.  Optional: In the **Contract** box, select a contract to view the cases associated with the contract, or leave the box blank to view all cases.
4.  In the table, click **Case ID** of a case which details you want to view and edit.
5.  On the [Case Details](SP_20_30_10.md) \(SP203010\) form, which opens, do the following:
    1.  In the Summary area, view the case details.
    2.  In the **Subject** box, edit the case subject.
    3.  Optional: In the **Contract** box, change the contract associated with the case.
    4.  In the **Priority** box, change the case priority.
    5.  On the **Activity** tab, check the case activities.
    6.  To add a note, click **Add Comment** on the form toolbar, and then enter the note contents in the **New Comment** dialog box.
    7.  Click **Save and Close**.
    8.  On the **Attributes** tab, check the attributes and update them.
    9.  To review or edit the details of another case, in the **Case ID** box of the Summary area, select another case in the **Case ID** column of the lookup box.
