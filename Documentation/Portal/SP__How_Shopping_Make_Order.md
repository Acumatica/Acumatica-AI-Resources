# To Place an Order {#_e0b545bf-c368-4feb-92b5-666e0574bf5b .task}

In this topic, you will learn how to place an order in the Acumatica Self-Service Portal.

**Attention:** You can view the [My Cart](SP_70_00_01.md) \(SP700001\) form if you are signed in to the Self-Service Portal with a user account that has the *Customer Admin* or *Customer User* role assigned.

## To Review and Enter Shipping Details { .section}

To review the list of items in your cart and enter shipping details for the order, do the following:

1.  In the Self-Service Portal, open the [My Cart](SP_70_00_01.md) \(SP700001\) form.
2.  In the table, view the list of items that you want to order.
3.  On the form toolbar, click **Proceed to Checkout**. On the [Checkout](SP_70_00_02.md) \(SP700002\) form, the Shipping Details page of the wizard opens.
4.  Optional: If you need to change the settings in the **Ship-To Info** section, do the following:
    1.  Select the **Edit Address** check box. This gives you the ability to override the default contact information for the shipment.
    2.  Do one of the following:
        -   To select one of the predefined locations, in the **Location** box, select the location you want the goods to be shipped to.
        -   For each setting that needs to be changed, specify the updated information in the needed box.
5.  In the **Shipping Information** section, do the following:
    1.  In the **Line Total**, **Tax Total**, and **Order Total** boxes, review the order totals calculated for the order you are placing.
    2.  In the **Ship Via** box, select a code representing a carrier from the predefined list.
    3.  In the **Delivery Date** box, specify the needed delivery date.
    4.  Select the **Residential Delivery** check box if the shipment will be delivered to a residential area.
    5.  In the **Comment** box, enter any necessary comments.
    6.  In the **Ship Complete** box, select the way how shipment should be fulfilled.

**Tip:** If you want to change the contents of the order, click the **Go Back to Cart** button. For more information, see [To Change the Contents of the Cart](SP__How_Shopping_Change_Cart.md).

You have reviewed the list of items and entered shipping details for the order. Now you can proceed to submitting the order.

## To Place an Order { .section}

To review the shipping information and place the order, while you are still on the Shipping Details page of the wizard, do the following:

1.  On the form toolbar, click **Continue**, which opens the Shipping Information page of the wizard. Review the shipping information, totals, and items of the order.

    To make any changes to the order before you submit it, click the **Return to Shipping Detail** button, and then make the necessary changes. For more information, see [To Change the Contents of the Cart](SP__How_Shopping_Change_Cart.md).

2.  On the form toolbar, click the **Submit Order** button to place the order in the system. A printable version of the order opens.
3.  Review the order information.

    **Tip:** You can review and print the order on the [My Orders](SP_70_00_03.md) \(SP700003\) form at any time.


You have reviewed and placed the order in the Self-Service Portal. Now you can proceed to tracking the order. For more information, see [Tracking Orders](SP__con_Tracking_Orders.md).
