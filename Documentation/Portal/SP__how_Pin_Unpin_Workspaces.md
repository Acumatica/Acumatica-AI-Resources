# To Pin and Unpin a Workspace Menu Item on the Main Menu Panel {#_169f507b-aecf-4c4e-a74c-e8563742e8bb .task}

In this topic, you will learn how to pin and unpin the workspace menu items that are displayed on the main menu panel in the Self-Service Portal.

**Attention:** You can personalize the workspaces by signing in to your Self-Service Portal instance with a user account that has the *Administrator* or *Portal Admin* role assigned.

## To Pin a Workspace Menu Item { .section}

To pin a workspace menu item to the main menu panel, do the following:

1.  On the main menu panel, click **More Items**. A menu is opened with tiles, grouped by broader functional areas, that represent all of the possible workspaces.
2.  Click the menu item whose workspace you want to pin to the main menu. The workspace opens.
3.  On the workspace title bar, click the **Pin to Main Menu Panel** \(![](../Shared/Images/Workspace_Pin.png)\) button.

## To Unpin a Workspace Menu Item { .section}

1.  On the main menu panel, click the menu item whose workspace you want to unpin. The workspace opens.
2.  On the workspace title bar, click **Unpin from Main Menu Panel** \(![](../Shared/Images/Workspace_TitleBar_Unpin.png)\).
