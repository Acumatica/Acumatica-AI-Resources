# Contact {#_095b54af-b4a5-4021-95fe-4408a888e5cd .reference}

Form ID: \(SP408041\)

On this form of the Acumatica Self-Service Portal, you can do the following:

-   Create a contact of your company and enter or edit the contact’s settings.

    Any changes you make to a contact are reflected on the Contacts \(CR302000\) form of Acumatica ERP when you save these changes.

    **Attention:** Additions or changes to the user settings on this form are reflected on the Users \(SM201010\) form in Acumatica ERP.

-   Enter the settings that cause the system to create a Self-Service Portal user account associated with the contact, including the username and the user type of the user account linked to the contact.
-   Enable or disable the user account. Thus, a contact on this form may be a current Self-Service Portal user, a prospective user that has not been enabled, or a former user that has been disabled.

You can open this form in any of the following ways:

-   By clicking the **Add New** button on the [Contacts](SP_40_80_40.md) \(SP408040\) form.

    **Attention:** The [Contacts](SP_40_80_40.md) form is available only for users with the *Customer Admin*, *Administrator*, or *Portal Admin* roles.

-   By clicking a contact in the **Contact** column of the [Contacts](SP_40_80_40.md) form.
-   By clicking the [Contact](SP_40_80_41.md) \(SP408041\) form in the workspace or using the search.

**Tip:** If your user account has the *Customer User* role assigned but none of the administrative roles, you can see contacts on the form, but can edit only your own contact settings.

## Summary Area { .section}

In this area, you can create a new contact or select an existing contact for editing.

|Element|Description|
|-------|-----------|
|**Contact ID**|The identifier of the contact, which the system generates automatically when a new contact is saved, based on the entered name and courtesy title. When you create a contact, leave this box blank.

 You can change the identifier by editing the name information in the **Last Name** box of the **Details** tab, if needed.

|
|**Active**|A check box you select to activate the contact. You can clear the check box to disable the contact.|

## Details Tab { .section}

On this tab, you can enter, review, and change the basic settings of the contact.

|Element|Description|
|-------|-----------|
|**First Name**|The contact's courtesy title \(which is *Dr.*, *Miss*, *Mr.*, *Mrs.*, *Ms.*, or *Prof.*\) and first name.|
|**Last Name**|The last name of the contact.|
|**Job Title**|The job title or position of the contact in your company.|

|Element|Description|
|-------|-----------|
|**Email**|The email address of the contact.|
|**Web**|The website of the contact.|
|**Phone 1**|The primary phone number of the contact.|
|**Phone 2**|An additional phone number of the contact.|
|**Phone 3**|Another phone number of the contact.|
|**Fax**|The fax number of the contact.|

|Element|Description|
|-------|-----------|
|**Same as in Account**|A check box that you select to populate the contact's address with the address of your company.

 If this check box is selected, the system populates the boxes in this section with the address settings that are specified in the **Main Address** section of the [Company Profile](SP_40_80_30.md) \(SP408030\) form.

|
|**Address Line 1**|The first address line of the contact.|
|**Address Line 2**|The second address line of the contact.|
|**City**|The city of the contact’s address.|
|**Country**|The two-letter code representing the country of the contact’s address. You can select a code from the predefined list.|
|**State**|The two-letter code representing the state of the contact’s address. You can select a code from the predefined list.|
|**Postal Code**|The postal code included in the contact’s address.|
|**View on Map**|A button you can click to view this address on the map provided by the Google Maps or Azure Maps web map service. The map is opened in a new window.|

## User Info Tab { .section}

On this tab, you can create and manage the user account associated with the contact.

|Element|Description|
|-------|-----------|
|**Time Zone**|The contact’s time zone, which will be used to display the time stamps when the contact uses the Self-Service Portal. If a time zone is specified for the user, these time stamps will be converted to the user's specified time zone. If no time zone is specified, documents will be time-stamped by using the time settings on the server.|

|Element|Description|
|-------|-----------|
|**Status**|A box that shows the status of the user account. The following options are available:-   *Not Created*: The contact is not associated with any user account.
-   *Active*: The user account is active. That is, it has been enabled. The user account is assigned this status when you have clicked the **Enable User** button.
-   *Online*: The user has been enabled and is signed in to the system.
-   *Disabled*: The user account has been disabled. The system assigns this status to the user account when you have clicked the **Disable User** button.
-   *Temporarily Locked*: The active user account is temporarily locked out.

|
|**User Type**|The user type of the user, which determines the set of roles available to the user and the creation rules of the user account.

 In this box, you select a user type that has been created on the User Types \(EP202500\) form of Acumatica ERP.

|
|**Login**|The username for signing in to the Self-Service Portal.

 If no user account has yet been defined for the contact, the box is empty.

|
|**Password**|The password the new user should use when initially signing in.

 This box appears during the creation of the user account. The box is available only if you clear the **Generate Password** check box.

|
|**Generate Password**|A check box that you select to have the system generate the password automatically.

 This check box appears only during the creation of a new user account.

|
|**Reset Password**|A button that you can click to open the **Reset Password** dialog box. You can reset the password for the selected user and enter a new one.

 The button is available only after the user account has been created.

|
|**Enable User**|A button that you click to enable the selected user account.|
|**Disable User**|A button that you click to disable the selected user account.|
|**Unlock User**|A button that you click to unlock the user account if the system temporarily locked it.|

|Element|Description|
|-------|-----------|
|**Selected**|A check box that you select to assign the user role to the selected user.|
|**Role Name**|The name of the user role.|
|**Role Description**|The description of the user role.|

|Element|Description|
|-------|-----------|
|The dialog box contains the following elements.|
|**New Password**|The new password for the selected user.|
|**Confirm Password**|The new password for the selected user, which you retype to confirm it to the system.|
|The dialog box has the following buttons.|
|**OK**|Replaces the password with the new one and closes the dialog box.|
|**Cancel**|Closes the dialog box without saving any entered settings or resetting the password.|
