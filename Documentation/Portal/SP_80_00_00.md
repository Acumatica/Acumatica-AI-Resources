# Portal Preferences {#_fc6cb0c6-af85-4264-9157-8be3c9eb6613 .reference}

Form ID: \(SP800000\)

You use this form to configure your company's Acumatica Self-Service Portal instance. You select the company or branch that the portal user can access, specify the default case settings, select the email templates for automatic mailing, and configure the online ordering.

To access this form, you must be signed in to the Self-Service Portal instance with a user account that has the *Administrator*, *Customer Admin*, or *Portal Admin* role assigned to it.

## Form Toolbar { .section}

The form toolbar includes only standard buttons.

## General Settings Tab {#1 .section}

On this tab, you can specify portal and CRM settings for this customer account.

|Element|Description|
|-------|-----------|
|**Portal ID**|The ID of the Self-Service Portal to which you are currently signed in.|
|**Portal Name**|A description of the portal.|
|**Display Financial Documents**|The set of financial documents that can be displayed on the [My Documents](SP_40_20_00.md) \(SP402000\), [My Statements](SP_40_46_00.md) \(SP404600\), and [My Orders](SP_70_00_03.md) \(SP700003\) forms. This setting also affects the visibility of documents in reports that may be opened from these forms, such as Invoice/Memo \(AR641000\), AR Balance by Customer \(AR632500\), and AR Aged Past Due \(AR631000\).

 This setting also affects the set of documents that are used to determine the **Outstanding Invoices and Memos**, **Unapplied Payments**, and **Net Balance** amounts on the [My Documents](SP_40_20_00.md) \(SP402000\) form.

 The following options are available:

 -   *From All Companies and Branches*: The portal user can see documents associated with any company and branch set up in the system.
-   *From Company*: The portal user can see documents associated with a particular company \(which you select in the **Portal Site Company** box\) and its branches.
-   *From Branch*: The portal user can see documents associated with a particular branch \(which you select in the **Portal Site Branch** box\).

|
|**Portal Site Company**|The company whose documents a portal user may see.

 This box appears if the *From Company* option is selected in the **Display Financial Documents** box.

|
|**Portal Site Branch**|The branch whose documents a portal user may see.

 This box appears if the *From Branch* option is selected in the **Display Financial Documents** box.

|
|**Home Page**|The portal home page. The following options are available:

 -   *Company* node \(that is, the top node of the tree\): The built-in Welcome to Acumatica page.

This page provides links to the Acumatica external resources, such as Acumatica announcements and news, the Acumatica Community, and the Acumatica Development Platform website.

-   *Knowledge base*: The Welcome Knowledge Base article.
-   *Self-Service Portal Guide*: The Help topic.

|

|Element|Description|
|-------|-----------|
|**Default Case Class**|The case class assigned to a new case by default.|
|**Priority**|The default case priority.

 The following options are available: *Low*, *Medium*, and *High*.

|
|**Case Activity Notification Template**|The template that is used to send notifications to the case owner about changes customers have made to their cases.|
|**Default Contact Class**|The contact class assigned to a new contact by default.|

|Element|Description|
|-------|-----------|
|**Portal External Access Link**|The URL that will be included in the emails sent to new users and the username and password recovery emails if the user account is marked as a *guest account*.

 This setting is also available on the *Site Preferences* \(SM200505\) form in Acumatica ERP.

|

## B2B Ordering Settings Tab { .section}

On this tab, you specify the default settings for the online ordering functionality of the Self-Service Portal.

You can specify the warehouses from which the portal users can order items and the default warehouses for stock and non-stock items. You can also select the default sales order type, indicate whether the portal users will be able to view the quantities of items in stock, and upload a default image for the items in the catalog.

**Attention:** This tab appears on the form if the *B2B Ordering* feature is enabled on the Enable/Disable Features \(CS100000\) form in Acumatica ERP.

|Element|Description|
|-------|-----------|
|**Default Branch for New Orders**|The branch to be associated by default with new sales orders created in the Acumatica Self-Service Portal.

 If this setting is modified while portal users are shopping, the customer cart on the [My Cart](SP_70_00_01.md) \(SP700001\) form becomes cleared for all users.

 If the *From Branch* option is selected in the **Display Financial Documents** box of the **General Settings** tab of the current form, the branch specified in the **Portal Site Branch** box is automatically inserted in this box and cannot be changed.

|
|**Default Stock Item Warehouse**|The warehouse from which stock items will be ordered by default.

 In this box, you select the default warehouse from the list of warehouses. This list of warehouses displays all warehouses that you selected in the **Include in Warehouse List** column of the table below.

 **Attention:** This box is available if the *Multiple Warehouses* feature is enabled on the Enable/Disable \(CS100000\) form of Acumatica ERP.

|
|**Default Non-Stock Item Warehouse**|The warehouse from which non-stock items will be ordered by default.

 In this box, you select the default warehouse from the list of warehouses. This list of warehouses displays all warehouses that you selected in the **Include in Warehouse List** column of the table below.

 **Attention:** This box is available if the *Multiple Warehouses* feature is enabled on the Enable/Disable \(CS100000\) form of Acumatica ERP.

|
|**Sales Order Type**|The type of sales order that will be generated when the customer submits an order. By default, the system uses the *SO* order type.|
|**Show Available Quantities**|A check box that you select to show the quantity of items left in stock.

 When you select this check box, the **Show Available Items Only** check box becomes visible in the Selection area of the [Catalog](SP_70_00_00.md) \(SP700000\) form.

|
|**Allow Only Sales Unit for Purchases**|A check box that you select so that the customer can order items in only the units of measure specified as the items’ sales units.|

|Element|Description|
|-------|-----------|
|**Browse**|A button you click to open the file selection window, where you can select an image to upload.|
|**Upload**|A button you click to upload the selected image to the system.|
|Image|The small version of the uploaded image that is used as a default image. Click on the image to see the large version of it.

 To upload an image, drag it to the Image area. Alternatively, you can click **Browse** to select an image, and then click **Upload** to upload the selected image. After you have uploaded the images, click **Save** on the form toolbar to save the changes.

 If you upload multiple images, the image that is displayed when you click **Save** on the form toolbar is used by default. To browse images, click on the arrows under the image.

|

|Element|Description|
|-------|-----------|
|**Include in Warehouses List**|A check box that indicates \(if selected\) that the warehouse is available for selection on the [Catalog](SP_70_00_00.md) \(SP700000\) form.|
|**Branch**|The branch with which the warehouse is associated.|
|**Company**|The company with which the warehouse is associated.|
|**Description**|The description of the warehouse.|
|**Warehouse ID**|The identifier of the warehouse.|
