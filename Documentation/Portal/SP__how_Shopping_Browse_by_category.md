# To Browse the Catalog and Select a Warehouse {#_da5afe62-1d36-4650-a3df-2acd19a79e94 .task}

In this topic, you will learn how to view your vendor's catalog, which lists the items available for ordering, and select the warehouse from which you want items to be shipped.

**Attention:** You can view the [Catalog](SP_70_00_00.md) \(SP700000\) form and browse a catalog if you are signed in to the Acumatica Self-Service Portal with a user account that has the *Customer Admin* or *Customer User* role assigned.

## To View the Catalog { .section}

To browse the catalog, do the following:

1.  In the Self-Service Portal, open the [Catalog](SP_70_00_00.md) \(SP700000\) form. The list of items in all categories opens.
2.  In the **Category** box of the Selection area, select the category of the items you want to view.
3.  Select the **Show Available Items Only** check box to view the items that are available for ordering.

    **Tip:** This check box is shown if the **Show Available Quantities** check box is selected on the **B2B Ordering Settings** tab of the [Portal Preferences](SP_80_00_00.md) \(SP800000\) form.


## To Select the Warehouse { .section}

To view items available for ordering in a particular warehouse and select the warehouse from which you want items to be shipped, while you are still viewing the catalog on the [Catalog](SP_70_00_00.md) \(SP700000\) form, do the following:

1.  In the table, in the row with the item that you want to add to the shopping cart, double-click the **Warehouse** column and then click the magnifier button.
2.  In the **Qty. Available** column of the lookup table that opens, make sure that the item is in stock at the warehouse, and then click the row with the warehouse.
3.  In the upper left corner of the dialog box, click the **Select** button. The dialog box closes.
4.  In the **This Warehouse** column of the table, review the quantity of items available for ordering in the selected warehouse.

You have browsed the catalog and selected the warehouse from which you want items to be shipped. Now you can add items to the shopping cart and place an order in the Self-Service Portal. For more information, see [To View an Item’s Details](SP__how_Shopping_Item_details.md).
