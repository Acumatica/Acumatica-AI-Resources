# Contacts {#_d4cdc3c8-cda2-471b-a117-b5384c912a8b .reference}

Form ID: \(SP408040\)

On this form, you can see your organization’s contacts, which are users that can access the Acumatica Self-Service Portal. These users are defined on the Contacts \(CR302000\) form in Acumatica ERP. The system inserts the information it copies from the Contacts form of Acumatica ERP by default.

You can click the **Add New** button to open the [Contact](SP_40_80_41.md) \(SP408041\) form in the Self-Service Portal and create a contact, as well as a Self-Service Portal user account associated with the new contact.

You can click a contact in a row to open the individual contact on the [Contact](SP_40_80_41.md) form to view or edit it.

**Attention:** To access the current form, you must be signed in to the Self-Service Portal instance with a user account that has any of the following roles assigned: *Customer Admin*, *Administrator*, or *Portal Admin*.

## Form Toolbar { .section}

The form toolbar includes standard and form-specific buttons. The form-specific button is listed below.

|Button|Description|
|------|-----------|
|**Add New**|Opens the [Contact](SP_40_80_41.md) \(SP408041\) form, which you can use to enter the settings of the contact and create a user account associated with the contact.|

## Selection Area { .section}

You can use the element in this area to narrow the range of contacts listed in the table.

|Element|Description|
|-------|-----------|
|Selection box|A box in which you can start typing part of a contact’s name. As you type, the table displays the contacts whose name contain the string you have typed. You can leave this box blank to view the list of all contacts.|

## Table { .section}

The table toolbar includes only standard buttons.

|Column|Description|
|------|-----------|
|**Contact**|The name of the contact and a link that you can click to open the individual contact on the [Contact](SP_40_80_41.md) \(SP408041\) form.|
|**Job Title**|The job title or position of the contact in your company.|
|**Email**|The email address of the contact.|
|**Phone 1**|The phone number of the contact.|
|**Login**|The username for authorization within the Self-Service Portal.

 This column is empty if no user account has been created for the contact yet.

|
|**User Type**|The user type of the user, which determines the set of roles available to the user and the creation rules of the user account.

 User types are defined on the User Types \(EP202500\) form of Acumatica ERP.

|
|**Active**|A read-only check box, which reflects whether the contact is active.

 You can clear or select the **Active** check box on the [Contact](SP_40_80_41.md) \(SP408041\) form to change the status of the contact.

|
