# Open Cases {#_577b4ec2-f7fc-4554-af7e-455df7d45f7e .reference}

Form ID: \(SP204000\)

On this form of the Acumatica Self-Service Portal, you can make quick inquiries about open cases. You can view the following:

-   The cases you have created
-   The cases a user in your company has created
-   All cases created by users in your company

## Form Toolbar { .section}

The form toolbar includes only standard and form-specific buttons.

## Selection Area {#1 .section}

You can use the elements in this area to specify the criteria of the cases you want to view.

|Element|Description|
|-------|-----------|
|**Created By**|A box and the **Me** check box, which you can use as follows: -   Select the **Me** check box to view cases you have created.
-   Clear the **Me** check box and select another user to view cases the user has created.
-   Leave the box blank and clear the **Me** check box to view all cases created by all users of your company.

|
|**Contract**|The contract associated with the cases you want to view. Leave the box blank to view cases associated with all contracts.|

## Table {#2 .section}

This table lists the cases that meet the criteria specified in the Selection area of the current form.

The table toolbar includes only standard buttons.

|Column|Description|
|------|-----------|
|**Case ID**|The identifier of the case, which is also a link you can click to view the settings of the case.

 If you click the link, the system opens the case on the [Case Details](SP_20_30_10.md) \(SP203010\) form.

|
|**Subject**|The description of the case that was provided when the case was reported.|
|**Status**|The status of the case, which can be one of the following options:

 -   *New*: The case has been created in the system, but no work has been done on it yet.
-   *Open*: The case is being worked on by the support team.

|
|**Reason**|The reason for last changing the status of the case, which can be one of the following options:

 -   *Unassigned* \(default\): The new case has not been assigned to an owner. If you select this reason and an owner is specified, the system will not generate a warning or error, so be sure no owner is specified. A case with this reason has the *New* status.
-   *Assigned*: The case has been assigned to an owner.
-   *In Process*: The case is being worked on.

|
|**Contract**|The contract associated with the case.|
|**Severity**|The severity level of the case, which is one of the following options: *High*, *Low*, and *Medium*.|
|**Priority**|The priority of the case. The following options are available: *High*, *Low*, and *Medium*.|
|**Class ID**|The class the case belongs to.|
|**Assigned To**|The name of the support representative who is assigned to work on the case.|
|**Last Activity**|The date of the last activity on the case.|
|**Contact**|The employee of your company who submitted the case.|
|**Account ID**|The ID of the business account associated with the case.|
|**Account Name**|The name of the business account associated with the case.|
