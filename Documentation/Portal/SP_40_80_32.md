# Customer Account {#_cd403087-0ff4-43c5-9161-94a24647203e .reference}

Form ID: \(SP408032\)

On this form, acting as an employee of the company that uses the Acumatica ERP instance, you can create customer contacts. In the Self-Service Portal, you can open the form by clicking a business account identifier on the [Customer Accounts](SP_40_80_33.md) \(SP408033\) form.

*Customer contacts* are the employees of your company added by the administrator to the [Contacts](SP_40_80_40.md) \(SP408040\) form of the Self-Service Portal. *Customer accounts* are business accounts of your customers whose employees \(contacts\) can be set up to access the Self-Service Portal.

To enter or edit the information on this form, you must be signed in to the Self-Service Portal with a user account that has the *Administrator* role assigned to it.

## Form Toolbar { .section}

The form toolbar includes standard and form-specific buttons.

The form-specific button is listed below.

|Button|Description|
|------|-----------|
|**Create Contact**|Opens the **Create Contact** dialog box, where you can create a contact associated with your customer account and specify the settings of this contact.|

## Create Contact Dialog Box { .section}

In this dialog box, you can create a contact associated with your customer's account and specify the main contact information for this person. This dialog box opens when you click the **Create Contact** button on the form table toolbar of the current form.

|Element|Description|
|-------|-----------|
|**First Name**|The first name of the new contact.|
|**Last Name**|The last name of the new contact.

 You must specify a value in this box to create a contact.

|
|**Account Name**|The legal business name of the customer's company, as registered with the appropriate tax agency.|
|**Job Title**|The contact's job title or position.|
|Type and Phone Number|The type and the phone number for the contact; you select the type \(which is filled in by default\) and then enter the phone number.

 You select one of the following options as the type of the phone number: *Business 1*, *Business 2*, *Business 3*, *Cell*, *Assistant*, *Fax*, *Home*, or *Home Fax*.

 There are two elements to enter phone number types and phone numbers for the contact.

|
|**Email**|The email address of the contact.|
|**Contact Class**|The contact class that the contact belongs to.

 A contact class defines which additional elements appear on the **Attribute** tab of this form, so that you can enter information pertinent to the contact.

|

|Column|Description|
|------|-----------|
|**Name**|The attribute available for this customer contact.|
|**Value**|The value of the attribute for the new contact.|

|Column|Description|
|------|-----------|
|**Name**|The name of the user-defined field.|
|**Value**|The value of the user-defined field for the new contact.|

|Button|Description|
|------|-----------|
|**Create and Review**|Creates the contact whose settings you have specified. You can review and update the existing information about the contact.|
|**Create**|Creates the contact whose settings you have specified. The system closes the dialog box and returns you to the current form.|
|**Cancel**|Closes the dialog box and cancels the process of creating a contact associated with the customer account.|

## Account Summary Area {#1 .section}

In this area, you can review the settings of the customer account and edit the account name of your company.

|Element|Description|
|-------|-----------|
|**Business Account**|The identifier of the customer account.|
|**Account Name**|The business name of the customer.|
|**Type**|The type of the customer account.|

## Details Tab {#2 .section}

On this tab, you can view contact information for the customer account, including the main address and contact information.

|Element|Description|
|-------|-----------|
|**Account Name**|The legal business name of your customer company to appear on the documents.|
|**Attention**|The attention line as it is used in the business letters of your customer company, which would be used to direct a letter to the intended recipient of a letter. The box may contain something like *Purchase Orders Department* or the recipient’s name.|
|**Email**|The email address used for the customer account.|
|**Web**|The website address of the customer account.|
|**Phone 1**|The primary phone number associated with the customer account.|
|**Phone 2**|An additional phone number used for the customer account.|
|**Fax**|The fax number used for the customer account.|

|Element|Description|
|-------|-----------|
|**Class ID**|The class the customer account belongs to.

 Once you select a class for a new customer, the system populates some elements with default values for the class. The customer class defines which attributes are available on the **Attributes** tab of the current form.

|

|Element|Description|
|-------|-----------|
|**Address Line 1**|The first line of the customer account's main address.|
|**Address Line 2**|The second line of the customer account's main address.|
|**City**|The city of your customer.|
|**Country**|The two-letter code representing the country of the customer address. You can select a code from the predefined list.|
|**State**|The two-letter code representing the state of the customer address. You can select a code from the predefined list.|
|**Postal Code**|The postal code included in the address of your customer.|
|**View on Map**|A button you can click to view this address on the map provided by the Google Maps or Azure Maps web map service. The map is opened in a new window.|

## Attributes Tab {#734 .section}

On this tab, you can view and update the values of the attributes associated with the customer account.

*Attributes* are elements that hold additional information about the customer account. This tab contains a list of attributes, which are determined by the class selected for the customer account on the **Details** tab of the current form.

The table toolbar includes only standard buttons.

|Column|Description|
|------|-----------|
|**Attribute**|The attribute available for this customer account.|
|**Required**|A check box that indicates \(if selected\) that this attribute has been defined as required. That is, a value must be specified.|
|**Value**|The value of the attribute for the customer account.|

## Contacts Tab {#5 .section}

On this tab, you can see all customer contacts associated with the selected customer account.

The table toolbar includes standard and table-specific buttons.

|Column|Description|
|------|-----------|
|**Active**|A check box that indicates, if selected, that this is an active contact of your customer.|
|**Contact**|The name of the contact.|
|**Job Title**|The job title or position of the contact person in your customer company.|
|**Primary**|A check box that indicates \(if selected\) that the current contact is considered as a main.|
|**Email**|The customer contact's email address.|
|**Phone 1**|The customer contact's phone number.|
|**City**|The city of the customer contact.|
