# Filters {#_f74bfcf5-24bd-4729-87f5-dfe5e782181c .concept}

In the Self-Service Portal, forms often use tables to present data in ways that users can easily comprehend. But when a single table becomes several pages long, gleaning needed information from it becomes a challenge. Filters give you a means to display only those records that you want to see at the moment.

The Self-Service Portal has three types of filters, described in this section. The major difference in filter functionality is related to the way the filters can be used:

-   [Column Filters and Sorting](SP_Column_Filter.md) \(simple filters that are available on most form tables\): Quickly add filters and sorting to table columns. Such filters cannot be saved.
-   [Ad Hoc Filters](SP_Using_Ad_Hoc_Filters.md) \(filters that are available on data entry forms\): Create and apply complex filters when you want to; such filters cannot be saved.
-   [Advanced Filters](SP_Using_Reusable_Filters.md) \(filters that are available on processing forms\): Create and apply complex filters, and save them for future use. You can create such filters for your personal use and for sharing with other users. Also, you can set an advanced filter as the default one. For details, see [Managing Advanced Filters](../UserGuide/GI_Reusable_Filters_Mapref.md).

For the description of the filtering by using the **Filter Settings** dialog box, see [Filter Settings Dialog Box](../UserGuide/GS__ref_Reusable_Filter_Settings_dialog.md).
