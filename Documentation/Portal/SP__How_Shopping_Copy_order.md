# To Copy an Existing Order {#_ecda7a1e-0a2e-454e-be88-9cfd2acf113f .task}

In some cases, you need to quickly create an order based on an existing one in the system.

In this topic, you will learn how to copy the items in an existing order to the shopping cart in the Acumatica Self-Service Portal.

## To Copy an Existing Order { .section}

1.  In the Self-Service Portal, open the [My Orders](SP_70_00_03.md) \(SP700003\) form.
2.  Click the row with the order you want to copy.
3.  On the form toolbar, click **Copy Order to Cart**.

    The system copies the contents of the order to your cart and opens the [My Cart](SP_70_00_01.md) \(SP700001\) form. Here you can make additional changes or proceed with placing the order. For more information, see [To Change the Contents of the Cart](SP__How_Shopping_Change_Cart.md) and [To Place an Order](SP__How_Shopping_Make_Order.md).

    **Attention:** You can view the [My Cart](SP_70_00_01.md) \(SP700001\) form if you are signed in to the Self-Service Portal with a user account that has the *Customer Admin* or *Customer User* role assigned.


You have copied an order’s items to the shopping cart in the Self-Service Portal. Now you can proceed with placing an order. For more information, see [To Place an Order](SP__How_Shopping_Make_Order.md).
