# New Case {#_1f9c4fb1-bc1d-4921-ad22-e82eaaf0b7aa .reference}

Form ID: \(SP203000\)

On this form of the Acumatica Self-Service Portal, you can create a case.

## Form Toolbar { .section}

The form toolbar includes standard and form-specific buttons.

The form-specific buttons are listed below.

|Button|Description|
|------|-----------|
|**Submit**|Submits the case you have entered, causing it to be saved to the system.|

## Summary Area {#1 .section}

By using this area, you can enter basic information about the new case.

|Element|Description|
|-------|-----------|
|**Contract**|The contract associated with the case.|
|**Priority**|The priority of the case. The following options are available: *Low*, *Medium*, and *High*.|
|**Class ID**|The class the case belongs to.

 Once you select a case class, the system populates some elements with the default values of the class. The case class determines which attributes and their values are available on the **Attributes** tab of the current form.

|
|**Subject**|A description of the new case.|

## Details Tab {#2 .section}

On this tab, you can describe the new case.

The tab includes the following:

-   The formatting toolbar.
-   The text area, where you enter a detailed description of the case or relevant notes.

## Attributes Tab {#734 .section}

On this tab, you can select appropriate values for the attributes associated with the new case.

*Attributes* are elements that hold an additional information about the case. The list of available attributes and their possible values is determined by the case class you have selected in the **Class ID** box of the Summary area.

The table toolbar includes only standard buttons.

|Column|Description|
|------|-----------|
|**Required**|A check box that indicates \(if selected\) that this attribute is defined as required. That is, a value must be specified.|
|**Attribute**|The attribute for the new case.|
|**Value**|The value of the attribute that has been specified for the case.|
