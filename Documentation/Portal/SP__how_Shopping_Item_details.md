# To View an Item’s Details {#_f0df1524-0bff-4220-8622-0ccaf88e3eeb .task}

In this topic, you will learn how to view detailed information about any item listed on the [Catalog](SP_70_00_00.md) \(SP700000\) form and add items to your shopping cart.

**Attention:** You can view the [Catalog](SP_70_00_00.md) \(SP700000\) form and browse the catalog if you are signed in to the Acumatica Self-Service Portal with a user account that has the *Customer Admin* or *Customer User* role assigned.

## To View an Item’s Details { .section}

To view an item’s details, do the following:

1.  In the Self-Service Portal, open the [Catalog](SP_70_00_00.md) \(SP700000\) form. The list of items in all categories opens.
2.  In the **Inventory ID** column, click any item identifier to view the item’s details. The **Item Details** dialog box opens.
3.  Review the item’s extended description and attributes.

## To Add Items to the Cart { .section}

While you are still in the **Item Details** dialog box viewing an item’s details, you will add the required quantity of the item to the shopping cart and select a warehouse. Do the following:

1.  In the **Qty.** box, specify the item quantity.
2.  Optional: In the **Warehouse** box, select the warehouse from which you want the item to be shipped.
3.  Click **Add to Cart**.
4.  In the confirmation dialog box that opens, click **Yes** to confirm the adding of the item to the shopping cart. The dialog box closes.

If you are done adding items to the shopping cart, you can go to the shopping cart and place an order in the Self-Service Portal. For more information, see [Using the Shopping Cart](SP__con_Shopping_Cart.md) and [Placing Orders](SP__con_Shopping_Orders.md).
