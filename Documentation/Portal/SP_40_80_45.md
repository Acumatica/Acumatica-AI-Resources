# User Profile {#_336340af-1e72-4460-a483-6ce5a53ef4a7 .reference}

Form ID: \(SP408045\)

On this form of the Acumatica Self-Service Portal, you can enter or edit your contact and user information, including name, email address, phone number, time zone, and password.

The system inserts the information it copies from the Contacts \(CR302000\) form of Acumatica ERP by default. Any changes you make to your own profile are reflected on the Contacts form of Acumatica ERP when you save these changes.

You can open this form by doing either of the following:

-   Clicking your username in the Info area \(in the top right corner of the Self-Service Portal screen\) and then clicking **My Profile** \(for users with any role\).
-   Clicking the [User Profile](SP_40_80_45.md) \(SP408045\) form in the workspace or using the search

## Form Toolbar { .section}

The form toolbar includes only standard buttons.

## Details Tab { .section}

On this tab, you can enter or edit your basic contact information.

|Element|Description|
|-------|-----------|
|**First Name**|Your courtesy title \(which is one of the following options: *Dr.*, *Miss*, *Mr.*, *Mrs.*, *Ms.*, or *Prof.*\) and first name.|
|**Last Name**|Your last name.|
|**Job Title**|Your job title or position in your company.|

|Element|Description|
|-------|-----------|
|**Email**|Your email address.|
|**Web**|Your company's website.|
|**Phone 1**|Your primary phone number.|
|**Phone 2**|Your additional phone number.|
|**Phone 3**|Another phone number where you can be reached.|
|**Fax**|Your fax number.|

|Element|Description|
|-------|-----------|
|**Same as in Account**|A check box that you select to have the system populate your address with the address of the business account.

 If this check box is selected, the system populates the boxes in the current section with the address settings that are specified in the **Main Address** section of the [Company Profile](SP_40_80_30.md) \(SP408030\) form.

|
|**Address Line 1**|The first address line of your address.|
|**Address Line 2**|The second address line of your address.|
|**City**|The city of your address.|
|**Country**|The two-letter code representing the country of your address. You can select a code from the predefined list.|
|**State**|The two-letter code representing the state of your address. You can select a code from the predefined list.|
|**Postal Code**|The postal code included in your postal address of the user.|
|**View on Map**|A button you can click to view this address on the map provided by the Google Maps or Azure Maps web map service. The map is opened in a new window.|

## User Info Tab { .section}

On this tab, you can view your user information and your status. You can also use this tab to manage your time zone and password.

|Element|Description|
|-------|-----------|
|**Time Zone**|The contact’s time zone, which will be used to display the time stamps. If a time zone is specified for the user, these time stamps will be converted to the user's specified time zone. If no time zone is specified, documents will be time-stamped by using the time settings on the server.|

|Element|Description|
|-------|-----------|
|**Status**|The account status. The following options are available:-   *Pending Activation*: The new user account is awaiting activation.
-   *Active*: The user account is active.
-   *Online*: The user account is active and the user is signed in to the system.
-   *Disabled*: The user account is disabled.
-   *Temporarily Locked*: The user account is temporarily locked out.

|
|**User Type**|The user type of your user account, which determines the roles available to your user account and the creation rules of the user account.|
|**Login**|Your username in the Self-Service Portal.|
|**Password**|The masked password to be used to sign in to your account.|
|**Generate Password**|A check box that you select to have the system generate the password automatically.

 If you clear this check box, you must enter a password for the new user in the **Password** box. The information to sign in will be sent to your email address when you save the user account.

|
|**Reset Password**|A button that you can click to open the **Reset Password** dialog box, in which you can reset your password and enter a new one.|

|Element|Description|
|-------|-----------|
|The dialog box contains the following elements.|
|**New Password**|The new password, which must meet the security requirements set for passwords in your company.|
|**Confirm Password**|The new password again; enter the same new password you typed above.|
|The dialog box contains the following buttons.|
|**OK**|Replaces your password with the new one and closes the dialog box.|
|**Cancel**|Closes the dialog box without saving any entered settings or resetting your password.|
