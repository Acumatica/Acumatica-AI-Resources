# To Search for Specific Items {#_4ef67502-3053-4971-aba6-750a540d36c6 .task}

In this topic, you will learn how to search for specific items on the [Catalog](SP_70_00_00.md) \(SP700000\) form.

**Attention:** You can view the [Catalog](SP_70_00_00.md) \(SP700000\) form and browse a catalog if you are signed in to the Acumatica Self-Service Portal with a user account that has the *Customer Admin* or *Customer User* role assigned.

## To Search for Items { .section}

1.  In the Self-Service Portal, open the [Catalog](SP_70_00_00.md) \(SP700000\) form.
2.  In the Selection area, in the **Find Item** box, enter the name or part of the name of the item you are searching for.

    Only the items that satisfy the search conditions will be displayed in the table. You can narrow the search by specifying more specific criteria.

3.  To narrow your results, in the **Category** box, select a category of the items you want to view.
4.  Select the **Show Available Items Only** check box to view the items that are available for ordering.

    **Tip:** This check box is shown if the **Show Available Quantities** check box is selected on the **B2B Ordering Settings** tab of the [Portal Preferences](SP_80_00_00.md) \(SP800000\) form.


Now you can add items to the shopping cart and place an order in the Self-Service Portal. For more information, see [Using the Shopping Cart](SP__con_Shopping_Cart.md) and [Placing Orders](SP__con_Shopping_Orders.md).
