# User Interface Personalization {#_872d8233-78fb-4dbb-a782-cb5e6d9639e0 .concept}

In this topic, you will read about specifying your personal settings in the Acumatica Self-Service Portal so that the user interface better corresponds to your preferences and work responsibilities.

## Personal Settings of the User Interface { .section}

You can personalize the user interface of the system as follows:

-   Personalize the list of workspaces shown in the main menu.

    For details, see [Personalization of Workspaces](#_e5a1a566-0cb3-492b-967f-b63839ab6319).

-   Personalize the list of forms and reports shown in the quick menu for each workspace.

    For more information, see [Using of a Quick Menu](#_c51a9b52-0101-4695-8864-d53a2d175fc1).

-   Change the location and size of the main menu.

    For details, see [Changing of Location and Size of the Main Menu Panel](#_973a0a9b-9c6e-4ec8-b9f8-5bf44e6542a3).


## Personalization of Workspaces {#_e5a1a566-0cb3-492b-967f-b63839ab6319 .section}

In the Self-Service Portal, the links to forms are organized in workspaces, each of which corresponds to a type of functionality. The main menu panel displays menu items corresponding to these workspaces. You can access other workspaces by using the **More Items** menu item.

**Attention:** You can personalize the workspaces by signing in to your Self-Service Portal instance with a user account that has the *Administrator* or *Portal Admin* role assigned.

For your convenience, you can configure and pin to the main menu panel the items whose workspaces you use frequently in your work. You can also unpin menu items that you do not use.

For more information, see [To Pin and Unpin a Workspace Menu Item on the Main Menu Panel](SP__how_Pin_Unpin_Workspaces.md).

## Using of a Quick Menu {#_c51a9b52-0101-4695-8864-d53a2d175fc1 .section}

When you click a menu item in the main menu, the system opens the quick menu of the workspace that corresponds to the menu item. You can use this menu to quickly access the forms that you use during your work. You can change the list of forms in the quick menu for each workspace.

By clicking the workspace header, you can view the links to all forms of the workspace to which you have access.

For more information, see [To Personalize the Quick Menu](SP__how_Configure_Quick_Menu.md).

## Changing of Location and Size of the Main Menu Panel {#_973a0a9b-9c6e-4ec8-b9f8-5bf44e6542a3 .section}

By default, the main menu is located on the left side of the screen and is displayed in its maximum size. To change the location and size of the main menu panel, do one of the following:

-   Collapse the main menu panel so that only the icons of menu items are displayed by clicking ![](Images/Main_Menu_Collapse_to_Left_Button.png) in the bottom right corner of the main menu panel.
-   Collapse the main menu panel to a button in the top left corner of the screen by clicking ![](Images/Main_Menu_Dots.png) in the bottom left corner of the main menu panel and clicking **Collapse to Top**.
-   Display only icons on the **Menu** button and in titles of the main menu items. To do this, you click **Menu** and then click ![](Images/Main_Menu_Collapse_to_Left_Button.png) in the bottom right corner of the main menu panel.
-   Expand the main menu panel to the left by clicking ![](Images/Main_Menu_Dots.png) in the bottom left corner of the main menu panel and then clicking **Expand to Left**.

For the procedure that describes how to minimize the menu panel on the screen, see [To Use the Maximum Screen Space](SP__how_Minimize_Main_Menu_Panel.md).
