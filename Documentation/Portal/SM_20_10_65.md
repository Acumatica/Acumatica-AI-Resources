# Identity Provider Preferences {#_513d4b03-420e-4340-a542-78bc05e0a17a .reference}

Form ID: \(SM201065\)

By using this form, you can configure and enable single sign-on \(SSO\) with the supported external identity providers for the users of the Self-Service Portal.

To see this form, you must be signed in to the Acumatica Self-Service Portal instance with a user account that has the *Administrator* role assigned to it.

For more information, see [Integrating Acumatica ERP with OpenID Identity Providers](../UserGuide/US__MNG_Integrating_with_Open_ID_Identity_Providers.md).

## Form Toolbar { .section}

The form toolbar includes only standard buttons.

## Table { .section}

In this table, you can see the supported identity providers. You can set up SSO with any number of identity providers, and then enable or disable SSO with them.

|Column|Description|
|------|-----------|
|**Provider Name**|The external identity provider.

 Acumatica ERP supports the following external identity providers:

-   Google
-   Microsoft Account

|
|**Active**|A check box that indicates \(if selected\) that a user can sign in with the external identity provider credentials.

 Clear the check box to disable single sign-on with the selected external identity provider.

|
|**Realm**|The full URL of the Acumatica ERP instance—for example, *https://www.example.com/my\_instance*.|
|**Application ID**|The client ID provided when you registered your application instance with the external identity provider.|
|**Application Secret**|The client secret provided when you registered your application instance with the external identity provider.|
