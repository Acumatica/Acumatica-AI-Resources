# Closed Cases {#_4a77731b-1a0c-417f-845b-24472e33c07d .reference}

Form ID: \(SP204010\)

On this form, you can make quick inquiries about closed cases that had been submitted by your company's users.

**Tip:** You can use the Selection area to specify the criteria of the cases you want to view in the table. You can click any case identifier in the table to open the [Case Details](SP_20_30_10.md) \(SP203010\) form and view the details of the case.

## Form Toolbar { .section}

The form toolbar includes only standard and form-specific buttons.

## Selection Area {#1 .section}

You can use the elements in this area to limit the cases that are listed in the table.

|Element|Description|
|-------|-----------|
|**Created By**|A box and the **Me** check box, which you can use as follows: -   Select the **Me** check box to view those cases that you created.
-   Clear the **Me** check box and select another user to view those cases that the selected user created.
-   Leave the box blank and clear the check box to view the closed cases owned by all of your company's users.

|
|**Contract**|The contract associated with the cases you want to view.|

## Table {#2 .section}

In this table, you can view the list of closed cases that meet the criteria specified in the Selection area.

The table toolbar includes only standard buttons.

|Column|Description|
|------|-----------|
|**Case ID**|The identifier of the case, which is also a link to the case.

 If you click the link, the system opens the case on the [Case Details](SP_20_30_10.md) \(SP203010\) form.

|
|**Subject**|The short description of the case that was provided when the case was reported.|
|**Status**|The status of the case, which the system assigns automatically based on user \(on the Self-Service Portal\) or staff member actions \(in Acumatica ERP\) during the case workflow.

 The status can be one of the following:

 -   *Closed*: The customer's problem has been resolved, a solution has been found, or no further work is expected to be done on the case.
-   *Released*: The AR invoice for the work performed has been generated for the customer on the Invoices and Memos \(AR301000\) form in Acumatica ERP.

|
|**Reason**|The reason for the status of the case.

 The reason can be one of the following:

 -   *Closed on Portal*: The user closed the case on the Self-Service Portal.
-   *Resolved*: The staff member resolved the case in Acumatica ERP.

|
|**Contract**|The contract the case is associated with.|
|**Severity**|The severity level of the case.|
|**Priority**|The priority of the case. The following options are available: *Low*, *Medium*, and *High*.|
|**Class ID**|The class the case belongs to.|
|**Full Name**|The user who created the case.|
|**Last Activity**|The date of the last activity on the case.|
|**Contact**|The employee of your company who created the case.|
|**Account ID**|The ID of the business account associated with the case.|
|**Account Name**|The name of the business account associated with the case.|
