# Customer Contact {#_a36820b2-9cca-4793-bb9a-89112daad518 .reference}

Form ID: \(SP408042\)

On this form, you can create new customer contacts.

*Customer contacts* are employees of your company who may interact with the vendor; optionally, they can be configured to access the Acumatica Self-Service Portal.

## Form Toolbar { .section}

The form toolbar includes standard and form-specific buttons. The form-specific buttons are listed below.

|Button|Description|
|------|-----------|
|**Save and Close**|Saves the contact information and closes the form.|

## Summary Area {#1 .section}

In this area, you can review the contact identifier and check the status of the contact.

|Element|Description|
|-------|-----------|
|**Contact ID**|The unique identifier of the contact, which the system generates automatically when a new contact is saved, based on the entered name and courtesy title.|
|**Active**|A check box that indicates \(if selected\) that the contact is active and the user can access the system.|

## Details Tab { .section}

On this tab, you can view the basic information about the customer contact.

|Element|Description|
|-------|-----------|
|**Business Account**|The identifier of the business account.|
|**Business Account Name**|The name of the business account related to the contact.|

|Element|Description|
|-------|-----------|
|**First Name**|The contact's courtesy title \(which is *Dr.*, *Miss*, *Mr.*, *Mrs.*, *Ms.*, or *Prof.*\) and first name.|
|**Last Name**|The last name of the contact.|
|**Job Title**|The job title or position of the contact in your company.|
|**Class ID**|The business account class that the contact belongs to.

 Once you select a class, the system populates some elements with default values for the class. The class defines which attributes and their values are listed on the **Attributes** tab of the current form.

|

|Element|Description|
|-------|-----------|
|**Email**|The email address of the contact.|
|**Web**|The website of the contact.|
|**Phone 1**|The primary phone number of the contact.|
|**Phone 2**|An additional phone number of the contact.|
|**Fax**|The fax number of the contact.|

|Element|Description|
|-------|-----------|
|**Same as in Account**|A check box that you select to populate the contact's address with the address of the business account.|
|**Address Line 1**|The first line of the contact's address.|
|**Address Line 2**|The second line of the contact's address.|
|**City**|The city of the contact's address.|
|**Country**|The two-letter code representing the country of the contact’s address. You can select a code from the predefined list.|
|**State**|The two-letter code representing the country of the contact’s address. You can select a code from the predefined list.|
|**Postal Code**|The postal code included in the contact’s address.|
|**View on Map**|A button you can click to view this address on the map provided by the Google Maps or Azure Maps web map service. The map is opened in a new window.|

## Attributes Tab {#734 .section}

The tab contains the list of attributes for the contact, which are determined by the class selected for the customer contact on the **Details** tab of the current form.

*Attributes* are elements that hold additional information about the customer contact. On the current tab, you can view, add, change, or delete attribute values to store additional information about customer contacts.

The table is populated with the required attributes \(that is, those for which the **Required** check box is selected\) that have been defined on the **Attributes** tab of the Contact Classes \(CR205000\) form in Acumatica ERP for the contact class selected on the **Main** tab of the current dialog box; you need to select their values for the contact you are creating.

The table toolbar includes only standard buttons.

|Column|Description|
|------|-----------|
|**Attribute**|The attribute for this customer contact.|
|**Required**|A check box that indicates \(if selected\) that this attribute has been defined as required. That is, a value must be specified.|
|**Value**|The value of the attribute that has been specified for the customer contact.|

## User Info Tab { .section}

On this tab, you can create and manage the user account associated with the customer contact.

You can see this tab only when you create a new customer contact.

|Element|Description|
|-------|-----------|
|**Time Zone**|The contact’s time zone, which will be used to display the time stamps when the contact uses the Self-Service Portal. If a time zone is specified for the user, these time stamps will be converted to the user's specified time zone. If no time zone is specified, documents will be time-stamped by using the time settings on the server.|

|Element|Description|
|-------|-----------|
|**Status**|The user account status. The following options are available:-   *Not Created*: The contact is not associated with any user account.
-   *Active*: The user account is active. That is, it has been enabled. The user account is assigned this status when you have clicked the **Enable User** button.
-   *Online*: The user has been enabled and is signed in to the system.
-   *Disabled*: The user account has been disabled. The system assigns this status to the user account when you have clicked the **Disable User** button.
-   *Temporarily Locked*: The active user account is temporarily locked out.

|
|**User Type**|The user type of this user, which determines the set of roles available to the user and the creation rules of the user account.

 In this box, you select a user type that has been created on the User Types \(EP202500\) form of Acumatica ERP.

|
|**Login**|The username for signing in to the Self-Service Portal.|
|**Password**|The password the new user should use when initially signing in.

 This box appears \(and is required\) during the creation of the user account. The box is available only if you clear the **Generate Password** check box.

|
|**Generate Password**|A check box that you select to have the system generate the password automatically.

 This check box appears only during the creation of a new user account. If the check box is selected, the information to sign in will be sent to the user's email address when you save the user account.

|
|**Reset Password**|A button that you can click to open the **Reset Password** dialog box. You can reset the password for the selected user and enter a new one.

 The button becomes available after the new customer contact has been created.

|
|**Enable User**|A button that you click to enable the selected user account.|
|**Disable User**|A button that you click to disable the selected user account.|
|**Unlock User**|A button that you click to unlock the user account if the system temporarily locked it.**Note:** For example, the system locks the user account if the user has entered the password incorrectly three times in a row.

|

|Element|Description|
|-------|-----------|
|**Selected**|A check box that you select to assign the role to the selected user.|
|**Role Name**|The name of the user role.|
|**Role Description**|The description of the user role.|

|Element|Description|
|-------|-----------|
|The dialog box contains the following elements.|
|**New Password**|The new password for the selected user.|
|**Confirm Password**|The new password for the selected user, which you retype to confirm it to the system.|
|The dialog box has the following buttons.|
|**OK**|Replaces the password with the new one and closes the dialog box.|
|**Cancel**|Closes the dialog box without saving any entered settings or resetting the password.|
