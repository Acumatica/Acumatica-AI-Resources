# New Comment {#_a63c1b0e-98b7-4f28-bcec-eddc8e16def8 .reference}

Form ID: \(SP500000\)

On this form of the Acumatica Self-Service Portal, you can add comments to the selected case.

## Form Toolbar { .section}

The form toolbar includes standard and form-specific buttons. The form-specific buttons are listed below.

|Button|Description|
|------|-----------|
|**Save and Close**|Saves the comment and closes the form.|
|**Close**|Closes the form without saving the comment.|

## Text Area { .section}

Use this area to add a comment.

|Element|Description|
|-------|-----------|
|**Summary**|The summary of the comment.|
|Details|The contents of the comment.|
