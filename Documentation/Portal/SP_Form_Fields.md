# Form Elements {#_9e62f2a2-423d-46a3-bcee-8836d8acc73e .concept}

In the Self-Service Portal, you use the form elements to enter information or settings to be stored in the database or used as selection criteria for presenting information on the form.

## Types of Form Elements { .section}

The Self-Service Portal supports the following types of form elements:

-   *Data boxes*: These boxes are designed to let you enter dates. For more information, see [Date Boxes](SP_Using_Date_Fields.md).
-   *Lookup boxes*: You use these boxes to select values from a list of predefined values or from another information table from the database. For more information, see [Lookup Boxes](SP_Using_Lookup_Fields.md)
-   *Check boxes*: You select or clear a check box to turn on or turn off an option.

If a box is marked with asterisk \(\*\), you are required to fill it in.

## Unavailable Elements { .section}

When you enter data on Self-Service Portal forms, you may notice that some elements are unavailable and appear dimmed. Some of these unavailable elements are *info boxes*, read-only boxes that contain system-generated values, such as document statuses and total amounts. Other unavailable elements can be used only if a specific option is selected in another element on this form or another form.
