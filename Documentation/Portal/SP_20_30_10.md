# Case Details {#_bc12d262-26bc-413b-bb4f-9a371e05142e .reference}

Form ID: \(SP203010\)

On this form, you can view the details and progress of a case, enter additional information, and close or reopen the case.

**Tip:** In the Self-Service Portal, you can open the current form by clicking a case identifier in the **Case ID** column of the All Cases \(GIP00000\) list of record.

## Form Toolbar { .section}

The form toolbar includes standard and form-specific buttons. The form-specific buttons are listed below.

|Button|Description|
|------|-----------|
|**Add Comment**|Opens the **New Comment** dialog box so that you can enter a comment about the selected case.|
|**Close Case**|Closes the selected case. The system changes the case’s status to *Open* and the reason to *Pending Closure*.

 This button appears for a new and open case only.

|
|**New Support Case**|Goes to the [New Case](SP_20_30_00.md) \(SP203000\) form so that you can create and submit a case.|
|**Reopen**|Reopens the selected case.|

|Element|Description|
|-------|-----------|
|This dialog box has the following elements.|
|**Summary**|A summary of the new comment, which the system composes based on the entered comment.

 You can see the summary on the **Activities** tab of the current form.

|
|Comment|An unlabeled text area where you can enter your comment about the case.

 You can see the comment in the bottom part of the **Activities** tab of the current form when you click the row with the comment on this tab.

|
|This dialog box has the following buttons.|
|**Save and Close**|Saves your comment and closes the dialog box.|
|**Close**|Closes the dialog box without saving the comment.|

## Summary Area {#1 .section}

In this area, you can specify or modify basic settings of the selected case.

|Element|Description|
|-------|-----------|
|**Case ID**|The unique identifier the system has assigned to the case.|
|**Reported On**|The date and time of the case creation. When you submit the case, the system automatically inserts the current date and time.|
|**Last Activity**|The date and time of the most recent activity on the case, that the system inserts automatically.|
|**Assigned To**|The support team member the case is assigned to.|
|**Subject**|A description of the case.|
|**Class ID**|The class the case belongs to.|
|**Business Account**|The customer associated with the case, that the system inserts automatically.|
|**Contract**|The contract associated with the case.|
|**Contact**|The user associated with the case.|
|**Status**|The status of the case. This box contains one of the following options:

 -   *New*: The case has been created in the system, but no work has been done on it yet.
-   *Open*: The case is being worked on by the support team.
-   *Closed*: Your problem has been resolved, a solution has been found, or no further work is expected to be done on the case. A case with this status has the *Closed on Portal* reason.

|
|**Reason**|The reason why the status of the case has been changed.|
|**Severity**|The severity level of the case. The following options are available: *Low*, *Medium*, and *High*.|
|**Priority**|The priority of the case. The following options are available: *Low*, *Medium*, and *High*.|

## Activities Tab { .section}

This tab has a table with the list of the activities associated with the case. When you add a comment, the system displays it in the table. You can click any activity to view the contents of the comment in the lower area of the tab.

The table toolbar includes only standard buttons.

|Column|Description|
|------|-----------|
|**Type**|The type of the activity, which can be one of the following: *Note*, *Email*, *Event*, *Chat*, *Message*, or *Phone Call*.|
|**Summary**|The brief description of the activity.|
|**Start Date**|The start date and time of the activity.|
|**Created At**|The date and time when the activity was created.|
|**Created By**|The username of the person who created the activity.|

## Case Description Tab { .section}

This tab has a description of the case.

The description appears on the tab of the current form in the following cases:

-   When a user created a case and entered the details of the case on the **Details** tab of the [New Case](SP_20_30_00.md) \(SP203000\) form.
-   When an employee of the support team has entered or overwrote the details of the case on the **Details** tab of the Cases \(CR306000\) form in Acumatica ERP.

## Attributes Tab {#734 .section}

On this tab, you can view and update the values for the attributes associated with the case. *Attributes* are elements that hold additional information about the case. The list of available attributes is defined by the case class selected in the **Class ID** box.

Once you select an attribute for the case on this tab, it appears on the **Attributes** tab of the Cases \(CR306000\) form in Acumatica ERP and can be viewed by the staff member.

The table toolbar includes only standard buttons.

|Column|Description|
|------|-----------|
|**Required**|A check box that indicates \(if selected\) that this attribute has been defined as required. That is, a value must be specified.|
|**Attribute**|The attribute for this case.|
|**Value**|The value of the attribute that has been specified for the case.|
