# To Track Closed Cases {#_de6ba180-f591-49b4-8046-d443bd908daa .task}

In this topic, you will learn how to track closed cases in the Acumatica Self-Service Portal. You can use the [Closed Cases](SP_20_40_10.md) \(SP204010\) form to view all closed cases and to check the details of a particular closed case. For more information, see [Case Management](SP__con_Case_Management.md).

## To Track Closed Cases { .section}

1.  Open the [Closed Cases](SP_20_40_10.md) \(SP204010\) form.
2.  In the Selection area, make selections to view closed cases based on the user that submitted them:
    -   To view the closed cases you have submitted, leave the **Me** check box selected.
    -   To view the closed cases another user has submitted, clear the **Me** check box and select the user in the **Created By** box.
    -   To view all closed cases submitted by the users of your company, clear the **Me** check box and leave the **Created By** box blank.
3.  Optional: In the **Contract** box, select a contract to view the cases associated with the contract, or leave the box blank to view all cases.
4.  In the **Case ID** column of the table, click identifier of the case which details you want to view. The [Case Details](SP_20_30_10.md) \(SP203010\) form opens for the selected case.
5.  To review the details of another case, in the **Case ID** box of the Summary area, select the case with the **Closed** status in the **Case ID** column of the lookup box.
