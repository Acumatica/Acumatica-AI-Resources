# Push Notifications {#_43fc945a-f762-4924-b538-21632beb8441 .concept}

Push notifications are notifications in JSON format that are sent by Acumatica ERP to notification destinations when specific data changes occur in Acumatica ERP. External applications can receive the notifications and process them to retrieve the information about the changes.

If you need to transfer push notification configuration to another Acumatica ERP instance, you need to include the push notification definitions and related data queries in a customization project and publish this customization project to this instance.

To include push notification definitions in a customization project, you use the [Push Notifications](../UserGuide/AU_21_00_00.md) \(AU210000\) page of the Customization Project Editor. For details about push notification in customization projects, see [Push Notifications: Inclusion in a Customization Project](../IntegrationDevelopmentGuide/IntegrationDev_PushNotifications_CustomizationProject.md).
