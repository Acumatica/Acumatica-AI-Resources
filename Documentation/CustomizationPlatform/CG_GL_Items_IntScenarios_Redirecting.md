# To Navigate to the Import Scenarios Form {#_71699c6e-cce1-4e96-b604-84cc9ea9c736 .concept}

You might need to add an import or export scenario to Acumatica ERP during customization. To manage import scenarios in Acumatica ERP, you use the [Import Scenarios](../UserGuide/SM_20_60_25.md) \(SM206025\) form.

In the [Customization Project Editor](../UserGuide/SM_20_45_10.md), to open this form, perform the following actions:

1.  Select **Import/Export Scenarios** in the navigation pane to open the [Import and Export Scenarios](../UserGuide/AU_20_55_00.md) page.
2.  On the page toolbar, click **Manage Scenarios**.

To manage export scenarios in Acumatica ERP, you use the [Export Scenarios](../UserGuide/SM_20_70_25.md) \(SM207025\) form.

As soon as you add an integration scenario to the system on the [Import Scenarios](../UserGuide/SM_20_60_25.md) or [Export Scenarios](../UserGuide/SM_20_70_25.md) form, you can add the scenario as an *XportScenario* item to the customization project. For more information about integration scenarios, see the [Preparing Data for Import and Export by Using Scenarios](../UserGuide/IS__mng_Data_Providers.md) in the Integrations guide.
