# To Navigate to the System Locales Form {#_790dbfc5-aee2-4705-92ac-5fef8d588093 .concept}

You might need to add a system locale to Acumatica ERP during customization. To manage system locales in Acumatica ERP, you use the [System Locales](../UserGuide/SM_20_05_50.md#) \(SM200550\) form.

In the [Customization Project Editor](../UserGuide/SM_20_45_10.md), to open the [System Locales](../UserGuide/SM_20_05_50.md#) form, perform the following actions:

1.  Click **System Locales** in the navigation pane to open the System Locales page of the editor.
2.  On the page toolbar, click **Manage Locales**.

As soon as you add a system locale to the system on the [System Locales](../UserGuide/SM_20_05_50.md#) form, you can add the locale as a *Locale* item to the customization project. For more information about system locales, see [System Locales](../UserGuide/SM_20_05_50.md#) in the User Guide.
