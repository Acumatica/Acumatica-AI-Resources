# Exploring the Source Code {#_8b029e01-6b17-401a-b680-46f9ab69c4cb .concept}

Before you start to customize an Acumatica ERP application instance, you should analyze your business requirements to identify the changes in business processes that must be made and to identify the application objects for the customization. We recommend that you learn about the structure of the involved webpages by exploring the `.aspx` pages \(if you are using the Classic UI\) or the HTML and TypeScript files \(if you are using the Modern UI\). Further, we recommend that you explore the code of the business logic controllers \(BLCs\) and the data access classes \(DACs\) that are used within the BLCs.

You can use the [Source Code](../UserGuide/SM_20_45_70.md) \(SM204570\) form to explore the original source code of the application for the following purposes:

-   To learn about the structure of the webpages involved in the customization
-   To understand which data views are bound with the customized form areas
-   To analyze the code that provides the business logic for a form to be customized
-   To find and analyze the data views used on a customized webpage
-   To understand which data access classes the form being customized is based on
-   To learn the attributes of the DAC fields and the relations between DACs

You can use the [DAC Schema Browser](../UserGuide/DAC_Schema_Browser_Reference.md) to explore the original source code of the application for the following purposes:

-   To learn the primary keys of the data tables
-   To discover a better way to join data tables
-   To obtain detailed information about a DAC
-   To learn the dependencies between DACs
-   To find where the data is used and understand the origin of the field data
-   To determine what fields have been added or modified by customization projects, and find out the names of these projects
