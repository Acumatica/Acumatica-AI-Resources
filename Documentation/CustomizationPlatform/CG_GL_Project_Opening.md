# To Open a Project {#_16a7ba41-cc79-4afd-bd68-0581a292d932 .concept}

If you have selected a customization project, you can open the project for editing in the [Customization Project Editor](../UserGuide/SM_20_45_10.md) in the following ways:

-   On the [Customization Projects](../UserGuide/SM_20_45_05.md) \(SM204505\) form: Click the project name in the table.
-   From the [Customization Menu](../UserGuide/AU_CustomizationMenu.md): Click **Customization** &gt; **Edit Project**.
-   From the [Element Properties Dialog Box](../UserGuide/AU_ElementInspector.md#_8ce780b0-243f-480c-8b4c-ed6431116e3f): Click **Customize**, **Actions** &gt; **Customize Business Logic**, or **Actions** &gt; **Customize Data Fields**.
