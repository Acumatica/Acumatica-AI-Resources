# To Navigate to the Access Rights by Screen Form {#_f04a2581-da57-45aa-9403-0aa61282f992 .concept}

You might need to change the access rights of roles in Acumatica ERP during customization. To manage access rights of roles by screen in Acumatica ERP, you use the [Access Rights by Screen](../UserGuide/SM_20_10_20.md) \(SM201020\) form.

To open this form from the [Customization Project Editor](../UserGuide/SM_20_45_10.md), perform the following actions:

1.  Click **Access Rights** in the navigation pane to open the [Access Rights](../UserGuide/AU_20_52_00.md) page.
2.  On the page toolbar, click **Manage Access Rights**.

As soon as you change the access rights of roles in Acumatica ERP, the system saves the changes in the database for your tenant, and you can add the access rights as a *ScreenWithRights* item to the customization project. For more information about the access rights of roles, see [Managing User Access](../UserGuide/SA_Managing_User_Access_Mapref.md) in the System Administration Guide.
