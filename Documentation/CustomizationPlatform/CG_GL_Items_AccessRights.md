# Access Rights {#_10902b74-6f4a-46c0-be0d-6765625e7499 .concept}

In Acumatica ERP, you can control access to system objects at broad and granular levels, down to the control of form elements, such as buttons, text boxes, and check boxes. Users are assigned the roles, and you give these roles the appropriate levels of access rights to system objects—functional areas, forms, and form elements. For more information, see [Managing User Access](../UserGuide/SA_Managing_User_Access_Mapref.md).

You use the [Access Rights](../UserGuide/AU_20_52_00.md) \(AU205200\) page of the [Customization Project Editor](../UserGuide/SM_20_45_10.md) to manage *ScreenWithRights* items in the customization project.

**Tip:** A *ScreenWithRights* item contains the data set of custom access rights of roles to a form, down to the control of form elements.

The [Access Rights](../UserGuide/AU_20_52_00.md) page displays the list of the custom access rights of roles that have been added to the customization project.

**Tip:** You can customize *ScreenWithRights* items for the Self-Service Portal as well.
