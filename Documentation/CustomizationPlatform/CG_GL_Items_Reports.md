# Custom Reports {#_b966829a-a21f-429e-b4fe-2b474dfef338 .concept}

You use the Custom Reports page of the [Customization Project Editor](../UserGuide/SM_20_45_10.md) to manage *Report* items in the customization project.

**Note:** A *Report* item contains the dataset of a custom report created with Acumatica Report Designer.

The Custom Reports page displays the list of the custom reports that have been added to the customization project.

On the page, you can perform the operations described in the following topics:

-   [To Add a Custom Report to a Project](CG_GL_Items_Reports_Adding.md)
-   [To Delete a Custom Report from a Project](CG_GL_Items_Reports_Deleting.md)
-   [To Navigate a Custom Report in a Project](CG_GL_Items_Reports_Updating.md)

**Note:** You can customize *Report* items for the Self-Service Portal as well.

-   **[To Add a Custom Report to a Project](../CustomizationPlatform/CG_GL_Items_Reports_Adding.md)**  

-   **[To Delete a Custom Report from a Project](../CustomizationPlatform/CG_GL_Items_Reports_Deleting.md)**  

-   **[To Navigate a Custom Report in a Project](../CustomizationPlatform/CG_GL_Items_Reports_Updating.md)**
