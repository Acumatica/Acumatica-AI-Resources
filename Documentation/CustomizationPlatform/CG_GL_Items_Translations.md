# System Locales {#_1c8e3964-1e9e-469e-8fa5-fe72010d481c .concept}

You use the [System Locales](../UserGuide/AU_20_50_00.md) \(AU205000 page of the [Customization Project Editor](../UserGuide/SM_20_45_10.md) to manage *Locale* items in the customization project.

**Tip:** A *Locale* item contains the dataset of a system locale, which is a set of parameters that defines the language and other local preferences—such as how to display numbers, dates, and times in the user interface—for a group of users.

The [System Locales](../UserGuide/AU_20_50_00.md) page displays the list of the system locales that have been added to the customization project.

On the page, you can perform various operations, as described in the following topics:

-   [To Add a System Locale to a Project](CG_GL_Items_Translations_Adding.md)
-   [To Delete a System Locale from a Project](CG_GL_Items_Translations_Deleting.md)
-   [To Update a Custom System Locale in a Project](CG_GL_Items_Translations_Updating.md)
-   [To Navigate to the System Locales Form](CG_GL_Items_Translations_Redirecting.md)

**Tip:** You can customize *Locale* items for the Self-Service Portal as well.
