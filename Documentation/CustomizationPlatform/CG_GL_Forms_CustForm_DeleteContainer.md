# To Delete a Container {#_fee6e99d-bf07-4948-9598-ff0eeaa88661 .concept}

You can delete a container from an Acumatica ERP form. To do this, perform the following actions:

1.  Open the form in the [Screen Editor](../UserGuide/AU_20_45_20.md), as described in [To Add a Page Item for an Existing Form](CG_GL_Items_Screens_Adding.md).
2.  In the Control Tree of the editor, select the container to be deleted.
3.  On the toolbar of the Control Tree, click **Remove** &gt; **Remove**.
4.  Click **Save** on the toolbar of the Screen Editor to save your changes to the customization project.
