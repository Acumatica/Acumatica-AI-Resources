# Wikis {#_d7448024-e022-4e7c-a01c-9151ee12120c .concept}

You use the [Wikis](../UserGuide/AU_20_60_01.md) \(AU206001\) page of the [Customization Project Editor](../UserGuide/SM_20_45_10.md) to manage *WikiArticle* items in the customization project.

**Note:** A *WikiArticle* item contains the dataset of a custom wiki and all the articles created within this wiki.

The [Wikis](../UserGuide/AU_20_60_01.md) page displays the list of the custom wikis that have been added to the customization project.

On the page, you can perform several operations, as described in the following topics:

-   [To Add a Custom Wiki to a Project](CG_GL_Items_Wiki_Adding.md)
-   [To Delete a Custom Wiki from a Project](CG_GL_Items_Wiki_Deleting.md)
-   [To Update a Custom Wiki in a Project](CG_GL_Items_Wiki_Updating.md)
-   [To Navigate to the Wiki Form](CG_GL_Items_Wiki_Redirecting.md)

**Note:** You can customize *WikiArticle* items for the Self-Service Portal as well.

-   **[To Add a Custom Wiki to a Project](../CustomizationPlatform/CG_GL_Items_Wiki_Adding.md)**
