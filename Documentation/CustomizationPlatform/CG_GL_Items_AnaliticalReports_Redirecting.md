# To Navigate to the Report Definitions Form {#_89238855-811b-4895-ba9c-0effe1106fe0 .concept}

You might need to add an analytical report to Acumatica ERP during customization. To manage analytical reports in Acumatica ERP, you use the [Report Definitions](../UserGuide/CS_20_60_00.md) \(CS206000\) form.

To open this form from the [Customization Project Editor](../UserGuide/SM_20_45_10.md), perform the following actions:

1.  Click **Analytical Reports** in the navigation pane to open the [Analytical Reports](../UserGuide/AU_20_60_03.md) page.
2.  On the page toolbar, click **Manage Report Definitions**.

As soon as you add a new analytical report to the system or change an existing analytical report on the [Report Definitions](../UserGuide/CS_20_60_00.md) form, the report is saved in the database for the current tenant, and you can add the report to the customization project as a *ReportDefinition* item. For more information about analytical reports, see [Managing Analytical Reports](../UserGuide/GL__GL_ARM_Reports.md) in the Reporting Tools Guide.
