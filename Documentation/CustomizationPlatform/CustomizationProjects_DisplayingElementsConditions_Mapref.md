# Defining Conditional Properties {#_4fc25cd0-eb53-4578-b510-76a10ccab030 .concept}

In this chapter, you will learn how to define the properties of fields and actions on a form to depend on whether the conditions that you specify are met.

As a result, you can conditionally determine any of the following for the UI element that corresponds to the field or action:

-   Whether the element is displayed or hidden on the form
-   Whether the element is required or optional
-   Whether the element is available or unavailable for editing
-   Which name is used for the element
-   What default value is used for the element \(if applicable\)
