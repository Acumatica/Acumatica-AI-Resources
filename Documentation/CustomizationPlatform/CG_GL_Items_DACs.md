# Customized Data Classes {#_46a9f940-e878-40c0-b717-c2ef313717d2 .concept}

You use the [Data Access](../UserGuide/AU_20_30_01.md) page of the [Customization Project Editor](../UserGuide/SM_20_45_10.md) to manage *DAC* items in a customization project.

**Tip:** A *DAC* item contains data in XML format used by the platform to create an appropriate extension for the original data access class.

The Customized Data Classes page displays the list of *DAC* items for existing data access classes of Acumatica ERP added to the project.

On the page, you can perform several operations with the customized data access classes, as described in the topics of this chapter.

**Note:** You cannot create a custom data access class on this page. Instead, you have to use the [Code](../UserGuide/AU_20_40_00.md) \(AU204000\) page of the editor. Custom classes are added to the project as *Code* items. See [To Create a Custom Data Access Class](CG_GL_Items_Code_CustomDAC.md) for details.
