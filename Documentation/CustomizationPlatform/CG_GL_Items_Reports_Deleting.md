# To Delete a Custom Report from a Project {#_03a8fa03-47e8-4c45-b8ec-63877a2210bf .concept}

To remove a custom report from a project, perform the following actions:

1.  Open the customization project in the Customization Project Editor. \(See [To Open a Project](CG_GL_Project_Opening.md) for details.\)
2.  Click **Reports** in the navigation pane to open the [Reports](../UserGuide/AU_20_70_00.md) page.
3.  In the page table, click the item to be deleted.
4.  On the page toolbar, click **Delete Row**.
5.  On the page toolbar, click **Save** to save the changes to the customization project.

If you have added a site map node for the custom report to the project, you also have to delete the appropriate *SiteMapNode* item on the [Site Map](../UserGuide/AU_20_80_00.md) page of the Customization Project Editor.
