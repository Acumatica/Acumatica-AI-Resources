# Customization Projects: To Create a Customization Project {#_8c47641f-9b0b-4017-b23e-97c9f238fda8 .task}

The following activity will walk you through the process of creating a customization project.

## Story { .section}

Suppose that you are a customizer in your company, and you have been asked to prepare a customization project as the first task in beginning a customization effort for Acumatica ERP.

## Process Overview { .section}

By using the [Customization Projects](../UserGuide/SM_20_45_05.md) \(SM204505\) form, you will create a customization project and open it in the Customization Project Editor.

## System Preparation { .section}

Before you begin performing the steps of this activity, you need to prepare an Acumatica ERP instance by performing the [Customization Projects: To Deploy an Instance](CustomizationProjects_GettingStarted_Activity_CreateInstance.md) prerequisite activity.

## Step: Creating a Customization Project { .section}

To create a customization project, do the following:

1.  In Acumatica ERP, open the [Customization Projects](../UserGuide/SM_20_45_05.md) \(SM204505\) form.
2.  On the form toolbar, click **Add Row**.
3.  In the **Project Name** column of the added row, enter the customization project name, `Yogifon`.
4.  On the form toolbar, click **Save**.

    The *Acumatica ERP* customization project is created. Now you can open the Customization Project Editor for the project by clicking the project name in the table.
