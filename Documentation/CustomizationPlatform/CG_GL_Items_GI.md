# Generic Inquiries

If you need to use a generic inquiry on another Acumatica ERP instance, you need to include the information about this generic inquiry in a customization project and publish this customization project to this instance.

To include the information about the generic inquiry in a customization project, you use the [Generic Inquiries](../UserGuide/AU_20_60_00.md) page of the Customization Project Editor. For details about generic inquiries in customization projects, see [Including Generic Inquiries in a Customization Project](../UserGuide/GI_CustomizationProject_Mapref.md).
