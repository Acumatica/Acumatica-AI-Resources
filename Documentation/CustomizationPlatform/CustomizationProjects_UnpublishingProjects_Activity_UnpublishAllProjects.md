# Project Unpublishing: To Unpublish All Projects {#_e4f34d3f-9c52-4f61-b3e2-7cad00bb7d66 .task}

The following activity will walk you through the process of unpublishing all published customization projects.

## Story { .section}

Suppose that you have published two customization projects \(*Yogifon* and *OpportunitiesForm*\) in your Acumatica ERP instance, and you want to revert the changes that have been introduced by both projects. You need to unpublish these customization projects.

## Process Overview { .section}

By using the [Customization Projects](../UserGuide/SM_20_45_05.md) \(SM204505\) form of the *Yogifon\_Staging* instance, you will unpublish the *Yogifon* and *YogifonExtra* projects.

## System Preparation { .section}

Before you begin performing the steps of this activity, do the following:

1.  Make sure that you have completed the [Project Publication: To Publish Two Customization Projects](CustomizationProjects_PublishingProjects_Activity_PublishTwoProjects.md) prerequisite activity.
2.  Launch the *Yogifon\_Staging* instance, and sign in by using the *admin* username and the password that you have specified for this instance.

## Step: Unpublishing All Customization Projects { .section}

To unpublish all customization projects, do the following:

1.  Open the [Customization Projects](../UserGuide/SM_20_45_05.md) \(SM204505\) form.
2.  On the form toolbar, you click **Unpublish All**.

The system removes all published customization projects from the Acumatica ERP instance.
