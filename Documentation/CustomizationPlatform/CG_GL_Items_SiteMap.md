# Site Map {#_424cd859-b216-4d88-ab5c-22fdba137f0c .concept}

You use the [Site Map](../UserGuide/AU_20_80_00.md) \(AU208000\) page of the [Customization Project Editor](../UserGuide/SM_20_45_10.md) to manage *SiteMapNode* items in the customization project.

**Note:** A *SiteMapNode* item contains the dataset of a custom site map node for a custom form or report included in the customization project. The item also includes information about the location of the form or report in the UI \(such as workspace to which the form or report included\).

The [Site Map](../UserGuide/AU_20_80_00.md) page displays the list of the custom site map nodes that have been added to the customization project.

**Note:** To customize *PortalMapNode* items for the Self-Service Portal, you use the [Portal Map](../UserGuide/SM_20_05_21.md) \(SM200521\) form.
