# PXCommandLine Tool: RemoveCustomization

You can use the *RemoveCustomization* value of the `/method` parameter to unpublish all customization projects of the current website. The unpublished projects will remain on the website and can be published again.

You can call the `RemoveCustomization` method by using the following syntax.

```
PX.CommandLine.exe [/website "path\to\web\site\root"] 
/method RemoveCustomization

```
