# Shared Filters {#_5e509a16-c6f8-4d0f-b5c6-eb4b7a839c73 .concept}

Users can create reusable filters, which are available on processing and inquiry forms in Acumatica ERP, to filter the data in the table part of the form; these filters can be reused anytime after creation. Reusable filters can be shared among all users of the system.

You use the [Shared Filters](../UserGuide/AU_20_51_00.md) \(AU205100\) page of the [Customization Project Editor](../UserGuide/SM_20_45_10.md) to manage *SharedFilter* items in the customization project.

**Note:** A *SharedFilter* item contains the dataset of a custom reusable shared filter created on a processing or inquiry form of Acumatica ERP.

The [Shared Filters](../UserGuide/AU_20_51_00.md) page displays the list of the custom reusable shared filters that have been added to the customization project.

On the page, you can perform several operations, as described in the following topics:

-   [To Add a Shared Filter to a Project](CG_GL_Items_SharedFilters_Adding.md)
-   [To Delete a Shared Filter from a Project](CG_GL_Items_SharedFilters_Deleting.md)
-   [To Update a Shared Filter in a Project](CG_GL_Items_SharedFilters_Updating.md)
-   [To Navigate to the Filters Form](CG_GL_Items_SharedFilters_Redirecting.md)

**Note:** You can customize *SharedFilter* items for the Self-Service Portal as well.
