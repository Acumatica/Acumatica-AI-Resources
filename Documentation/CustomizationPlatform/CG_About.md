# Customization Guide {#_316b14fa-f406-4788-993c-7b043b1c5bd9 .concept}

This guide describes the scope of the Acumatica Customization Platform and provides guidelines on how to use the platform capabilities for the customization of Acumatica ERP.

The guide is intended to answer the following questions:

-   *How should I start developing a customization project?* \(See [Getting Started](cg_gettingstarted.md).\)
-   *How does the Acumatica Customization Platform work?* \(For information, see [Acumatica Customization Platform](CG_Platform.md).\)
-   *How do I create, open, update, delete, publish, unpublish, export, and import a customization project?* \(You can find details on these tasks in [Managing Customization Projects](CG_GL_Projects.md).\)
-   *How can I create, add, update, and delete each type of item \(such as screens, data access classes, code, files, and reports\) in a customization project?* \(Find these details in [Managing Items in a Project](CG_GL_Items.md).\)
-   *How do I publish a single customization project or multiple projects for a site with a single tenant or multiple tenants?* \(For information, refer to [Publishing Customization Projects](CG_GL_Projects_Publishing.md).\)
-   *What do I do to create a custom form and customize the look and behavior of an existing form of Acumatica ERP?*\(You can find these details in [Customizing Elements of the User Interface](CG_GL_UI.md).\)
-   *How do I create custom code or extensions for an existing data access class or business logic controller?* \(For information about these processes, see [Customizing Business Logic](CG_GL_BL.md).\)
-   *How do I customize an existing table or create a custom table in the database?*\(See [Customizing the Database Schema](CG_GL_DBSchema.md).\)
-   *How do I use Microsoft Visual Studio to develop the customization code?*\(Find this information in [Integrating the Project Editor with Microsoft Visual Studio](CG_Platform_Studio.md).\)
-   *How can I integrate the Project Editor with TFS, Git, or another version control system?* \(For details, see [Integrating the Project Editor with a Version Control System](CG_GL_VCS.md).\)
-   *What can I do to solve an issue that occurs while I am developing or applying a customization?* \(This information is provided in [Troubleshooting Customization](CG_Troubleshooting.md).\)
-   *Where can I find examples to enhance my understanding of the customization tasks I will perform?* \(See [Examples](CG_Examples.md).\)
