# Publishing with the Cleanup Operation {#_c483eaf5-e909-4a24-91f5-434a4f993534 .concept}

In this chapter, you will learn how to publish customization projects with the cleanup operation. This will cause the platform to clean up all information about previously executed scripts of a customization project and execute the scripts once more during the publication of the project.
