# Workflow {#_ea3252e4-6b08-4cdb-9932-54c3c90d2f9f .concept}

A workflow is a definition of how the state of a record created on a particular form should change as a result of a user performing an action. You can define workflows by using the Customization Project Editor and in code. For details on creating and customizing workflow by using the Customization Project Editor, see [Getting Started with Workflows: General Information](../DeveloperGuide/WorkflowUI_GettingStarted_GeneralInfo.md). For more information about implementation of workflows in code, see [Getting Started with Workflow API: General Information](../DeveloperGuide/WorkflowAPI_Overview.md).
