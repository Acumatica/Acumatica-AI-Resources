# Import and Export Scenarios {#_66b77217-fe2c-459a-a00d-3789b27d4dbb .concept}

You use the [Import and Export Scenarios](../UserGuide/AU_20_55_00.md) \(AU205500\) page of the [Customization Project Editor](../UserGuide/SM_20_45_10.md) to manage *XportScenario* items in the customization project.

**Note:** An *XportScenario* item contains the data set of a custom export or import scenario used to perform data migration between a legacy application and Acumatica ERP.

The [Import and Export Scenarios](../UserGuide/AU_20_55_00.md) page displays the list of the integration scenarios that have been added to the customization project.

On the page, you can perform a variety of operations, including the following:

-   [To Add an Integration Scenario to a Project](CG_GL_Items_IntScenarios_Adding.md)
-   [To Delete an Integration Scenario from a Project](CG_GL_Items_IntScenarios_Deleting.md)
-   [To Update an Integration Scenario in a Project](CG_GL_Items_IntScenarios_Updating.md)
-   [To Navigate to the Import Scenarios Form](CG_GL_Items_IntScenarios_Redirecting.md)
