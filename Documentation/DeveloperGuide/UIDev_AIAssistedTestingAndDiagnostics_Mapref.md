# AI-Assisted Testing and Diagnostics with Test SDK for the Modern UI

Test SDK helps automate UI-level testing by interacting with Acumatica ERP forms through generated wrappers. In this chapter, you'll learn how to use AI as a practical assistant for inspecting generated wrappers of Modern UI forms. You'll also draft test code with AI's help, and validate and run the generated code. Finally, you'll use AI to analyze and classify test failures before deciding on the next diagnostic step.
