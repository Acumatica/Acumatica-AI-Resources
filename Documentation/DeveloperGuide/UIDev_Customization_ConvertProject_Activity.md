# Updating a Customization Project for the Modern UI: To Convert a Customization Project

This activity will walk you through the process of migrating the entire customization project to the Modern UI. You'll convert the entire project by using the customization project converter.

**Important:** The use of the customization project converter doesn't guarantee a perfect conversion of a form to the Modern UI. The converter provides **a baseline conversion that you should further fine-tune** based on your specific requirements. We strongly recommend that you:

-   **Make necessary backups** and use the converter **only in your development environment**.
-   **Always review the files** generated by the converter and **make any required corrections**.
-   Publish the converted form to your production environment **only after fully testing** its functionality in your development environment.

## Story

Suppose that you have a customization project that contains multiple changes in the Classic UI such as a customized [Stock Items](../UserGuide/IN_20_25_00.md) \(IN202500\) form and custom forms Repair Services \(RS201000\), Serviced Devices \(RS202000\), and Services and Prices \(RS203000\). You need to migrate all of those files to the Modern UI.

## Process Overview

You will use the customization project converter to convert the entire project. The converter will generate TypeScript and HTML files for custom forms and TypeScript and HTML extension files for the customized form. You will review the generated files and make necessary changes to them. You will then publish the corresponding customization project and view the Modern UI of the customized form.

## System Preparation

Before you begin converting the customization project, do the following:

1.  Deploy an instance of Acumatica ERP with the T100 dataset.
2.  Optional: If you plan to build code manually, perform the prerequisite actions and build the source code for the first time, as described in [Modern UI Development: To Build the Source Code of All Acumatica ERP Forms for Modern UI Development](UIDev_ModernUI_Activity_BuildingSourcesAll.md).
3.  Download the `T210.zip` archive that contains the customization project file from GitHub. The project contains the Classic UI files for the forms that are implemented and customized throughout the *T200 Maintenance Forms* and *T210 Customized Forms and Master-Details Relationships* courses.

## Step 1: Loading and Converting the Customization Project

To convert the customization project, do the following:

1.  On the Customization Projects \(SM204505\) form, import the customization project:
    1.  On the form toolbar, click **Import**.
    2.  In the **Open Package** dialog box, choose the `T210.zip` file.
    3.  Click **Upload**.

        The project is displayed on the Customization Projects form.

2.  Publish the customization project.
3.  On the form toolbar, click **Convert to Modern UI**.

    The system generates the TypeScript and HTML files for each form in the project.


## Step 2: Reviewing the Generated Files and Correcting If Necessary

To review the code that the system has generated in the previous step, do the following:

1.  On the Customization Projects \(SM204505\) form, open the `T210` project.

    The Customization Project Editor opens.

2.  On the [Modern UI Files](../UserGuide/AU_20_46_00.md) page, notice the following files:
    -   `IN202500_PhoneRepairShop_converted.ts`
    -   `IN202500_PhoneRepairShop_converted.html`
    -   `RS201000_PhoneRepairShop_converted.ts`
    -   `RS201000_PhoneRepairShop_converted.html`
    -   `RS202000_PhoneRepairShop_converted.ts`
    -   `RS202000_PhoneRepairShop_converted.html`
    -   `RS203000_PhoneRepairShop_converted.ts`
    -   `RS203000_PhoneRepairShop_converted.html`
3.  Review the code and make changes if necessary:
    -   Correct the generates IDs according to coding conventions for each control.
    -   Modify template names according to the layout recommendations for different types of forms.
4.  Save your changes.

## Step 3: Publishing the Project and Viewing the Form

Now you will publish the customization project and view the customized form in the Modern UI. Do the following:

1.  Publish the customization project.
2.  Open the following forms and make sure they are correctly displayed in the Modern UI:

    -   Repair Services \(RS201000\)
    -   Serviced Devices \(RS202000\)
    -   Services and Prices \(RS203000\)
    **Note:** If a form doesn't already open in the Modern UI, click **Tools** &gt; **Switch to Modern UI** on the form title bar. The Modern UI for the form will be displayed.

3.  Open the [Stock Items](../UserGuide/IN_20_25_00.md) \(IN202500\) form.
4.  Select the *BAT3310EX* item in the table.
5.  On the **General** tab \(**Item Defaults** section\), make sure the **Repair Item** check box and the **Repair Item Type** box are visible.
6.  Select the **Repair Item** check box. Make sure that the **Repair Item Type** box is available because the **Repair Item** check box is selected, as shown below.


7.  Make sure that the **Compatible Devices** tab is displayed, as shown below. \(The tab is displayed because the **Repair Item** check box is selected on the **General** tab.\)


8.  On the **Compatible Devices** tab, add the *Nokia3310* device to the list.
9.  Save your changes.
10. Select the *HEADSET* item and make sure that the **Compatible Devices** tab is not displayed for this item. \(This is because the **Repair Item** check box is cleared.\)
