# Updating Customization Projects for the Modern UI {#_e519ee2f-517e-4da9-bf61-3cc2cd491c14 .concept}

If your customization project introduces new Acumatica ERP forms or customized versions of existing Acumatica ERP forms built for the Classic UI, you need to convert them to the Modern UI to deliver these forms in Acumatica ERP 2026 R1. You can convert these forms individually or convert all of a customization project’s forms with a single action.
