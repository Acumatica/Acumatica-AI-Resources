# Modern UI Development: Switching a Form Between the Modern UI and the Classic UI

By default, the Classic UI is disabled starting in Acumatica ERP 2026 R2. Starting in Acumatica ERP 2027 R1, forms that support only Classic UI will no longer be available.

Administrators can temporarily enable the Classic UI by setting the `EnableLegacyUI=True` flag in the `web.config` file. When set, users can still switch between the Modern UI and the Classic UI as described below.

## Switching the UI of the Particular Form

While viewing a form in the Modern UI, you can click the Settings button on the form title bar and then **Switch to Classic UI** to switch the form to the Classic UI.


While viewing a form in the Classic UI, you can click **Tools** &gt; **Switch to Modern UI** on the form title bar to switch the form to the Modern UI.


**Attention:** The **Switch to Modern UI** command is available for only the forms that have been migrated to the Modern UI.
