# Modern UI Editor: Inserting Layout Controls

In the Modern UI Editor, you can use the **Insert Layout Control** drop-down menu on the **HTML** tab to insert ready-to-use HTML snippets for common layout controls. You can insert snippets for *Tab Bar*, *Tab*, *Field Set*, and *Grid* controls instead of typing the full HTML structure manually.

## Inserting a Layout Control

To insert an HTML snippet for a layout control, perform these general steps:

1.  Open the Modern UI Editor for the form.
2.  In the code editor on the **HTML** tab, place the cursor where you want to insert the layout control.
3.  On the tab toolbar, click **Insert Layout Control** \(Item 1 below\) and select the type of control you want to add \(Item 2\).


4.  In the dialog box that opens, specify the required settings for the selected control. Depending on the control type, you may need to specify the control's ID, caption, class, or other control-specific values.

    The following screenshot shows the dialog box for the *Tab* control.


5.  Click **Add**.

    The editor inserts the generated snippet at the cursor position. The inserted markup uses the values that you specified in the dialog box.


6.  Optional: Click **Preview HTML Extension** to review the difference between the original HTML code and the changes that you have made.
7.  Click **Save** on the page toolbar.

    The generated HTML extension file is added to your customization project and listed on the [Modern UI Files](../UserGuide/AU_20_46_00.md) page of the Customization Project Editor.

8.  To apply the changes, publish the customization project.

You can use the editor's undo, redo, and validation features with the inserted markup. For details about configuring the layout controls, see [Tab](UIDevRef_Tab_Mapref.md), [Fieldset](UIDevRef_Fieldset_Mapref.md), [Table \(Grid\)](UIDevRef_Grid_Mapref.md), and [Form Layout: Predefined Templates](UIDev_DesigningLayout_Templates.md).
