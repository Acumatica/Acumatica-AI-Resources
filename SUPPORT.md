# Support Policy

Use the structured GitHub issue forms only for defects and accepted proposals concerning this repository's skills, plugins, prompts, references, manifests, and automation on the latest published release branch.

This repository does not provide Acumatica product support. Do not submit product, installation, upgrade, configuration, licensing, account, implementation, or environment questions through its issues, pull requests, discussions, or security features.

Send corrections and other feedback about files under `Documentation/` to [training@acumatica.com](mailto:training@acumatica.com). Do not open a documentation issue or pull request.

Report suspected repository vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
