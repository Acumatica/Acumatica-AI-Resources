# agent-tooling — Agent Tooling

Plugin with tools for authoring and verifying agent skills: friction-pattern extraction and skill quality verification.

## Skills
- **[distill](skills/distill/)** — Extracts recurring friction from completed work into reusable skills
- **[verifying-skills](skills/verifying-skills/)** — Verifies a skill against best practices, skills docs, a complete guide, and Skill Creator guidance, producing a severity-bucketed review report
