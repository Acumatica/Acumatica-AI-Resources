# agent-tooling — Agent Tooling

Plugin with tools for authoring and verifying agent skills: friction-pattern extraction and skill quality verification.

## Skills
- **[distill](skills/distill/)** — Extracts friction patterns from the current conversation into reusable skills
- **[verifying-skills](skills/verifying-skills/)** — Verifies a skill against best practices, skills docs, and a complete guide, producing a severity-bucketed review report
